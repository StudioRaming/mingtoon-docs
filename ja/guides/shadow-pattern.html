シャドウパターン（スクリーントーン）

このページは影パターンを使用をはじめてオンにする方のためのものです。 影をマンガのスクリーントーンの網点に変えます。約 4 分かかります。

これは何ですか​

影を印刷マンガのような細かい点に変えます。 影が深くなるほど点が大きくなります。 点の代わりに線やクロスハッチに変えることもできます。

いつ使いますか​

  • 白黒マンガのコマのようなルックを作るとき。
  • 影の面積が広く、単色の塊に見えるとき。
  • 印刷物に重ね刷りしたポップアートの雰囲気を出すとき。

30 秒で試す​

  1. 変換したボディのマテリアルを選びます。
  2. 影パターンを使用をオンにします。
  3. パターン密度を 40 に下げます。
  4. パターン回転を 45 に合わせます。

影の場所に傾いた網点が見えれば成功です。 何も変わらない場合はトラブルシューティングへ進んでください。

使い方​

  1. 影パターンを使用をオンにします。既定値はオフです。
  2. パターン適用対象を選びます。Form はフォームシャドウ、Depth はデプスシャドウです。
  3. パターン密度で点の大きさを合わせます。
  4. パターン強度を確認します。0 だと何も見えません。
  5. 点の代わりに別の形を使うならパターン形状タイルを使用をオンにします。
回転は 45 度付近が自然です

0 度は画面のピクセル格子と重なり、まだら模様が出やすくなります。 既定値の 78 度も、同じ理由で格子を避けた値です。

パターン基準 — 表面に貼るか、画面に固定するか​

パターン基準は、格子が何に貼り付くかを決めます。既定値は Mesh です。

値格子がどこにあるか
Mesh表面に貼り付き、キャラクターと一緒に動きます。腕を上げれば網点も追従します
Screen画面に固定され、キャラクターがその下を通り過ぎます

距離補正と画角 / 投影補正は、2 つの基準で方向が逆になります。 Mesh ではカメラの安定性を引き、Screen では足します。 Screen で 1 なら、近くで決めた大きさが遠くでも保たれます。

Mesh 基準にはレストポーズアンカーが必要です​

Skinned Mesh で Mesh 基準を使うと、パターンが肌の上を滑ります。 レストポーズアンカーをベイクしておくと、アニメーション中も貼り付いたままになります。 ベイクは編集用の設定をアップロード用に焼くことであり、焼いたあとは値を変えられません。

  1. MingToon マネージャーを選択します。
  2. インスペクターに表示されるレストポーズアンカーをベイクボタンを押します。

ベイカーはレストポーズを収めた複製 Mesh を作り、アンカーの使用をオンにします。 既存のチャンネルと衝突して拒否された Renderer は、Console に別途表示されます。 Screen 基準ではアンカーは必要ありません。

パターン形状タイル​

パターン形状タイルを使用は既定値がオフです。 オフのままだと計算で描く円形の網点が使われ、テクスチャは読みません。 オンにするとセル内の形だけが変わり、格子と密度はそのままです。

同梱タイル 5 種は、インスペクターのボタンからすぐに入れられます。

ボタン形
網点標準ハーフトーン
細かい網点細い網点
線平行線
クロスハッチクロスハッチング
点描スティップル

タイルは絵ではなくしきい値マップです​

タイルを自作するとき、ここを誤解すると必ず失敗します。 タイルの各点は、その場所がインクに変わる濃度を保持しています。 そのためタイル 1 枚で、最初の点から埋まり切るまでのすべてを表現できます。

すでに白黒に二値化された点のパターンを入れると、トーンに反応しません。 影が深くなっても、同じ大きさの点しか出ません。

自作するときのインポート設定は 2 つです。

設定値理由
sRGB (Color Texture)オフsRGB 変換がトーンカーブを歪めます
Compressionオフブロック圧縮がグラデーションを潰し、まだらを作ります

すべての明るさの段階が同じ点の数を占める必要があります。 セル 1 マスがちょうどタイル 1 回の繰り返しなので、スロットに Tiling/Offset はありません。

よく触る値​

インスペクターのラベル何が変わるか推奨の開始値上げると / 下げると
パターン密度メッシュ 1 単位を埋めるセルの数40上げると点が細かくなり、下げると点が大きくなります
パターン回転格子の角度450 度付近は画面の格子と重なり、まだらが出ます
パターン強度元の影とパターンを混ぜる比率既定値のまま(1)下げるとパターンが薄くなり、0 だと見えません
パターン境界のぼかし点の縁のぼかし幅既定値のまま(0.14)上げると点が潰れ、0 だと階段状に割れます
距離補正カメラが遠ざかるときの大きさ補正既定値のまま(1)Mesh と Screen で方向が逆になります

最暗部の塗り量最暗部を単色で埋める量既定値のまま(1)下げると最も暗い場所にも点が残ります

よくある問題​

パターンがまったく出ません​

パターン形状タイルのスロットが空だと、白として読まれます。 白はどんな濃度でも越えられないしきい値です。 インスペクターがこれを警告し、同梱タイルのボタンも一緒に表示します。

Overlay を選んだのにインク色が出ません​

パターン適用対象が Depth の場合、Overlay は Recolor に下がります。 模様は刷られますが、インク色ではなく影の色を使います。 インク色を使うには、適用対象を Form または Both にしてください。

アニメーション中にパターンが肌の上を滑ります​

Mesh 基準なのに、レストポーズアンカーがない状態です。 上のアンカーのベイク手順を先に終えてください。
