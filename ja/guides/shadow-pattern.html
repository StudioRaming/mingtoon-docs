シャドウパターン（スクリーントーン）

このドキュメントを読むと シャドウを漫画スクリーントーンのようなハーフトーン網点に変え、好みの形のタイルを直接作成できます。

ライティングとシャドウグループ内のシャドウパターン（スクリーントーン）を扱います。全項目リストはライティングとシャドウリファレンスにあります。

どう動作するか​

フォームシャドウと2Dシャドウをハーフトーン網点で表現します。シャドウが深くなるほど点が大きくなります。

格子は計算で描く円形網点が基本で、任意で形状タイルを1回読みます。パターン基準がMeshならレストポーズ座標に貼り付き、Screenなら画面へ固定されます。

Skinned MeshでMesh基準を使う場合は、レストポーズアンカーがないとアニメーション中にパターンが皮膚上を滑ります。

統合シャドウと一緒に使っても大丈夫です

統合シャドウをオンにした状態でもシャドウパターンはそのまま保持されます。

ランタイム値​

項目機能
パターン適用対象フォームシャドウ、2Dシャドウ、または両方
パターン方式Recolor — シャドウカバレッジ自体を再描画します。点がシャドウ色をそのまま使用
Overlay — シャドウはそのままでインク色で上に重ねます
パターン密度画面1画面分を埋めるセル数。画面高さ基準なため解像度が変わっても同じサイズに見えます
パターン回転格子角度
パターン境界柔らかさ点の端の柔らかさ
パターン強度パターンが適用される強さ。0なら何も見えません
距離補正遠くなる時の点サイズ補正
画角/投影補正FOV変更時の補正
最も暗い場所にもパターンを保持最暗部までドット網点を保つかどうか。最も暗い場所の塗り詰め度で量を決定します
注意
2DシャドウではOverlayがRecolorに落ちます

パターン方式がOverlayでパターン適用対象がDepth2Dの場合、パターンはそのまま描かれますが、インク色ではなく影色を使います。Overlayは仕上がった陰影の上に線を重ねる方式で、合成地点を持つのはフォームシャドウ経路だけだからです。以前からこの動作でしたが、今回からその組み合わせでインスペクターが案内を表示します。

Overlayをそのまま使うには、パターン適用対象をFormまたはBothにしてください。

回転角度

45度近くがプリント用網点のように自然です。0度は画面ピクセル格子と重なりモアレが起きやすいです。

パターン基準 — 表面に貼るか、画面に固定するか​

パターン基準 — 既定は Mesh

値格子がどこにあるか
Mesh表面に貼り付き、キャラクターと一緒に動きます。 腕を上げれば腕の網点も付いてきます
Screen画面に固定され、キャラクターがその下を通ります。 印刷物への重ね刷り / ポップアート

形状タイル・密度・回転は両方で同じものを使います。変わるのは格子が何に貼り付いているかだけです。

Skinned MeshのMesh基準にはRest Pose Anchorが必要です

アンカーがない場合、Inspectorが欠落しているSkinned Renderer数を警告し、レストポーズアンカーをベイクボタンを表示します。先にMingToon Managerを選択してボタンを押すか、Tools > Studio Raming > MingToon > Advanced > Bake Rest Pose Anchorを実行してください。

ベイカーはUV2またはUV4の使用可能なpayloadへレストポーズを保存した複製Meshを作り、関連マテリアルのアンカー使用を有効にします。既存チャンネルと競合して拒否されたRendererはConsoleへ個別に表示されます。

Screenでは別途アンカーは不要です。画角を変えたり首を回したりしてもパターンが歪んだり点滅したりせず、画面のアスペクト比が変わってもセルを正方形に保ちます。

2つの基準で補正スライダーの意味が反転します​

距離補正 と 画角 / 投影補正 はどちらでも動作します。 反転するのは向きです。

  • Mesh ではカメラ安定性を取り除く値です。0では表面に完全に固定され、1ではカメラの動きに対して大きさを補正します。
  • Screen ではカメラ安定性を加える値です。既定の1では、近くで決めたマークの大きさと密度が遠くから見ても画角を変えても保たれます。0に下げると格子がピクセルに完全固定され、カメラが何をしても一切動きません。
近くで作って遠くで確認

Screen と 距離補正 1 がまさにその組み合わせです。近くで密度とサイズを決めたあと、遠くから見てもパターンが保たれるか確認してください。

パターン形状タイル​

パターン形状タイル使用 — 既定値オフ

  • オフにすると 計算で描く円形網点が使われ、テクスチャを1度も読みません。
  • オンにすると セル内に描かれる形状だけがタイル画像に変わります。格子・密度・トーン反応はそのままです。

付属タイル​

付属タイル5種をインスペクターのボタンから直接読み込めます。

ボタン形状
網点標準ハーフトーン
細かい網点細い網点
線平行線
交差線クロスハッチング
点描スティプル
タイルスロットが空いているとパターンが全く打たれません

空のスロットは白色で読まれ、白色はどの濃度でも越えられない閾値です。インスペクターがこれを警告して、付属タイルボタンと一緒に表示します。

タイルは画像ではなく閾値マップです​

ここを誤解するとタイルを直接作成するときは必ず失敗します。

タイルの各テクセルはそのテクセルがインクに変わる濃度を保持しています。「パターンを描いた画像」ではありません。そのためタイル1枚で最初の点から完全に塗られるまで全てが表現されます。

既に二値化された点パターンを入れると

シャドウ深度と無関係に同じサイズの点だけが出ます。トーンに反応しません。

直接作成する時のインポート設定​

設定値理由
sRGB (Color Texture)オフsRGB変換がトーン曲線を歪めます
圧縮（Compression）オフブロック圧縮がグラデーションを潰してパターンにムラを作ります

全ての明度段階が同じテクセル数を占める必要があります。そうすることで点がサンプリング限界より小さくなった時に元の濃度に収束します。

Tiling/Offsetがない理由​

セル1マスが正確にタイル1回の繰り返しです。したがって密度はパターン密度が、方向はパターン回転がそのまま決定します。スロットにTiling/Offsetがないのはこのためです。
