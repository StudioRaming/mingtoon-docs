複数マテリアルを一度に

このページは 一括設定 を初めて使う方のためのものです。 アバターの複数のマテリアルに同じ値を一度に入れます。5分ほどかかります。

これは何ですか​

アバター1体にマテリアルが20個以上付くことはよくあります。 アウトラインの色を変えるために、20回同じスライダーを触る必要はありません。 一括設定は条件に合うマテリアルを集め、一度に値を書き込みます。

いつ使いますか​

  • アバター全体のアウトライン色を1つのトーンに揃えるとき
  • 衣装すべての影の境界をまとめて動かすとき

30秒でオンにしてみる​

  1. MingToonマネージャーを選択します。
  2. インスペクターの表示を 一括設定 に切り替えます。
  3. 対象範囲 を MingToonマネージャー にしておきます。
  4. プレビューマテリアル数 が1より大きいことを確認します。

数字が表示されれば成功です。 0の場合は下の よくある問題 を見てください。

使い方​

  1. 対象範囲 と2つのフィルターを決めます。
  2. プレビューマテリアル数 を確認します。
  3. 衣装やシーンを変えた場合は プレビューを更新 を押します。
  4. 必要なら プレビューマテリアルを選択 で結果を選択状態にします。
  5. 共通外観 のグループを開いて値を変えます。

対象にはMingToonマテリアルだけが残り、同じマテリアルは一度だけ入ります。 複数のマテリアルに適用した値は、1回のUndoで元に戻せます。

対象範囲とフィルター​

インスペクターのラベル選べる値
対象範囲選択したオブジェクト / MingToonマネージャー / アクティブシーン / 読み込んだすべてのシーン
非アクティブを含むオフになっている衣装まで一緒に探します
マテリアル種別すべて / 一般 / 顔
サーフェス種別すべて / 不透明 / カットアウト / 透明

対象範囲 を MingToonマネージャー にすると、そのマネージャーの配下だけを探します。 アバターや衣装を編集するときは、アバター最上位のマネージャーを選んでください。

よく触る値​

共通外観 は4つのグループに分かれています。 各行は、そのプロパティを持つマテリアルにだけ書き込まれます。

インスペクターのラベル何が変わるか推奨する初期値上げると / 下げると
全体の明るさ倍率キャラクター全体の最終的な明るさ既定値のまま（1）上げるとまとめて明るくなり、下げると暗くなります
ベースカラーベースマップの上に重ねる色白色を入れると、選んだマテリアルすべてがその色に染まります
影の境界明るい面と陰の境界の位置既定値のまま（0）上げると陰が広がり、下げると狭くなります
影の柔らかさ境界がにじむ幅既定値のまま（0.3）上げると柔らかくにじみ、下げるとくっきりした線になります
アウトライン色線の色ベースより暗い色黒に近いほどマンガ風が強まります
アウトライン幅線の太さ既定値のまま（1）上げると太くなり、0にすると消えます
全体のエミッション強度発光全体の強さ既定値のまま（1）0にすると発光が消えます

行が多すぎるときは プロパティ検索 に名前の一部を入れてください。 検索中は該当するグループが自動で展開されます。

マテリアルプリセット​

値のまとまりをアセットとして保存し、別のアバターで再利用します。

  1. プリセットの保存と管理 を展開します。
  2. ユーザープリセットを保存 で、今のマテリアルの値を保存します。
  3. 別のマテリアルで プリセット のリストから選びます。
  4. 適用 を押します。
プリセットが上書きしない値があります

サーフェス描画とレイヤーの内容はマテリアル自身のものなので、そのまま残ります。 テクスチャとタイリング・オフセットにも触れません。

プリセットは数値と色だけを含みます。 レンダーキューとRenderTypeタグはそのまま残します。 適用はUndoで元に戻せます。

コピー / 貼り付け​

値1つやタブ1つだけを移したいときに使います。 プロパティやレイヤーの見出しを右クリックするとメニューが出ます。 詳しいルールは 値のコピー / 貼り付け にあります。

よくある問題​

症状原因対処
プレビュー数が0になる対象範囲がマネージャーの外を指しているアバター最上位のマネージャーを選びます
目的の行が表示されない選んだマテリアルにそのプロパティがないフィルターをすべてに広げて探し直します
値が一部にしか入らないそのプロパティがないマテリアルはスキップされる種別フィルターで分けて2回適用します

衣装やシーンを変えたあとは、まず プレビューを更新 を押してください。

さらに詳しく​

  • インスペクターの使い方 — 表示モードと一括設定の位置
  • MingToonマネージャー — キャラクター範囲の指定
  • テクスチャスロット共通UI — コピーメニューのルール
