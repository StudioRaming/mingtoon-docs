インスペクター使用法

MingToon Manager から始める

コンポーネント追加 → Face Mesh・Skin Mesh 指定 → ルック選択 → 色調または既存値選択 → 変換 → クイック設定。

Manager はアバタールートに残します。編集後に VRC SDK でアップロード、または WARUDO のモッドをビルドすると、自動最適化ベイクが実行されます。

順番に進める。衣装だけを編集する場合も、Manager は常にアバタールートに配置してください。更新も Manager で確認します。 VCC からインストールした場合、MingToon の更新は VCC で行います。 Manager の更新案内を使う前に、インストール方法を確認してください。顔・素肌のない衣装では、その役割を空欄にしてください。

Face SDF Studio はまだ未発売で、この導入手順には必要ありません。

このドキュメントを読むと MingToon Inspectorの表示モード、固定ツールバー、グループ構成、複数マテリアル編集のルールを理解できます。

マテリアルの役割​

Face・Skin・Common は、ルックプリセットのどの役割の値を適用するかを決めます。通常ビルドでもマテリアル Inspector 上部で役割を直接指定できます。 この行はシンプル・全設定・一括設定で共通です。初回変換では MingToon Manager で Renderer・マテリアルスロットごとに指定し、変換後はマテリアル Inspector からも変更できます。

複数マテリアルを選択したとき役割が異なる場合は混合状態で表示されます。役割を変更すると、選択中の全マテリアルへ適用されます。

表示モード​

モード表示される内容用途
シンプルサーフェス、ライティング、主要マップ、シャドウ・リム・顔・深度の代表項目変換直後のルック調整、すばやい修正
全設定すべてのユーザー向けワークフローグループと高度なレンダー状態本格的なオーサリング、問題解決
一括設定選択した複数マテリアルへ共通適用できる安全な値アバター全体の統一

シンプルは機能全体を要約した画面です。必要な項目がなければ全設定へ切り替えてください。診断情報、内部技術名、バリアントダンプなどのメンテナンス機能は正式ビルドには表示されず、MINGTOON_DEV開発ビルドでのみ表示されます。

固定ツールバー​

Inspectorを下へスクロールしても上部ツールバーが残ります。

ツール機能
検索現在の言語だけでなく、韓国語・英語・日本語の別名でも項目を検索します
お気に入りのみお気に入りに登録したセクションと行だけを表示します。全設定専用です
すべて折りたたむ / すべて展開ワークフローグループとセクションを一度に整理します
変更値のみシェーダーのデフォルト値と異なる行だけを残し、該当セクションを自動展開します
コピー / 貼り付けマテリアル設定を別のマテリアルへ移します
言語한국어 / English / 日本語を切り替えます

変更値のみは、自分で変更した値やプリセットが変更した候補を見つける診断ツールです。テクスチャのデフォルトfallbackと実際の割り当て状態も区別します。変更された項目がなければ変更された値なしと表示されます。

ツールバー下のカラーナビゲーションバーは各ワークフローグループの位置を示します。色の区間を押すと、そのグループへ移動します。

全体エフェクトとセクションマスター​

All Effectsは複数の追加効果の共通スイッチです。オフ時に影響を受ける項目は無効状態として表示されます。基本表面や独立した条件を使う全機能まで同じように無効になるとは考えないでください。

各セクションにも独自のマスターがあります。無効なセクションには(モジュールOFF)と表示され、検索で下位の行を見つけた場合はこのモジュールを有効化を使用できます。

値が反応しない場合

全体エフェクト → 該当セクションのマスター → 必要なプラットフォーム前提条件の順に確認してください。深度エフェクトなら深度の可用性も確認する必要があります。

クイック設定​

クイック設定は頻繁に調整するシャドウ境界、2Dリム、アウトライン、エミッションなどの値を一箇所にまとめます。実際の値を複製したUIなので、ここで変更すると元のセクションへ即時同期されます。

モジュールがOFFなら(モジュールOFF)、選択したマテリアルの値が異なる場合は(混合状態)と表示されます。

複数マテリアルの同時編集​

値が異なる行は混合値として表示されます。その行を変更すると、選択中の全マテリアルへ同じ値が記録されます。

顔プロキシのSceneView編集は、同じキャラクタールートにある互換性のあるFaceマテリアル同士で使用してください。異なるルートが混在すると、誤同期を防ぐため編集を開始しません。先にMingToon ManagerのFaceマテリアルのみ選択を使うと安全です。

プリセット​

マテリアルプリセットはルック値を選び、適用を押したときだけ適用します。選択やプレビューだけで自動適用されず、複数マテリアルを選択すると一括適用されます。

プリセット適用時は、次のようなキャラクター固有設定の保持状態を確認します。

  • サーフェスモード（不透明・カットアウト・半透明・透明）と描画キュー
  • アルファマスクとカットオフ
  • 顔プロキシの中心・半径・形状・軸・高さ
  • 割り当て済みのキャラクター固有テクスチャとタイリング/オフセット

Face / Skin / Commonの値はマテリアルに記録された役割に従います。Managerまたはマテリアルのインスペクターで確認してください。

コピー / 貼り付け​

コピー後、貼り付けメニューから範囲を選びます。

  • すべて
  • 値のみ（テクスチャを除く）
  • テクスチャのみ
  • キーワードのみ
  • レンダーキューのみ

貼り付けは選択中の全対象へ適用され、Undoに対応します。

マテリアル負荷​

代表値は、アップロードされるベイク後シェーダーの推定コストです。編集用シェーダーはすべてのオーサリング機能を保持するため、より重くなります。詳細表では現在の編集状態とベイク後状態を分けて確認できます。

編集パフォーマンスと開発用ツール​

編集用シェーダーは、トグルするたびに新しいバリアントを待たずに済むようオーサリング経路を保持します。未使用機能の削除と定数畳み込みはビルド時の自動最適化で行います。

正式パッケージでは、ユーザー作業に不要なバリアントダンプ・レコード、技術診断パネル、Depth Debug Post Process登録は表示されません。製品開発者がMINGTOON_DEVを定義したビルドでのみ再表示されます。
