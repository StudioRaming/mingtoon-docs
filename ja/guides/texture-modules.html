テクスチャスロット共通UI

この文書を読むと MingToonのすべてのテクスチャスロットに共通して付く調整項目を一度に理解できます。

ベースマップ、ノーマル、マスク、MatCap、エミッション、レイヤー — 名前は異なっても下の構造は同じです。一度学べば、残りのスロットは自動的に読めます。

テクスチャスロット
├─ テクスチャ詳細設定      ← チャンネルソース・反転・HSVG・ティント順序
└─ マスク詳細設定          ← マスクマップ・チャンネル・反転・リマップ・フェザー・グラデーション

テクスチャ詳細設定​

チャンネルソース​

このテクスチャからどのチャンネルを読むかを決めます。

値読むもの
RGBA 全体カラーそのまま
R / G / B / A対応するチャンネルのみ

複数のマスクを1つのテクスチャにパックした場合に使います。マスクスロット側にはRGBA 全体（輝度）オプションが追加で用意されており、RGBの明度を使います。

ソース色を反転​

読み込んだ値の黒白を反転させます。削除すべき場所が白色で描かれたマスクをそのまま使う場合に使用します。

HSVG​

項目既定値
色相0
彩度1
明度1
ガンマ1

既定値から外れた値だけが結果に影響を与えます。インスペクターは各項目の既定値をツールヒントで知らせ、「既定のHSVGは色相0、彩度1、明度1、ガンマ1です。」というガイダンスも表示します。

テクスチャを焼き直す代わりに

色を少し変えたいときは、テクスチャを編集するよりHSVGを使う方がはるかに速く、元と比較するのも簡単です。

HSVGの後にティントを適用​

ティント色をHSVG補正の前に掛けるか後に掛けるかを決めます。同じ値でも順序によって結果が変わります。

マスク詳細設定​

適用範囲を制限します。ほとんどのモジュールが専用マスクを持つことができます。

項目機能
マスクマップグレースケール画像
マスクチャンネルR / G / B / A / RGBA 全体（輝度）
反転黒白を反転
リマップ開始 · リマップ終了マスクのグレースケール範囲を再展開
境界のぼかしエッジのぼかし幅

リマップの使い方​

マスクがぼやけて描かれていたり、範囲が広すぎる場合に使います。

  • リマップ開始を上げる → 適用範囲が狭くなります
  • リマップ終了を下げる → エッジが急峻になります
  • 両方を同じにすると、エッジが完全にカリカリになります（バイナリマスク）

グラデーション​

マスク画像を使わずに方向性のあるフェードを作ります。

項目機能
グラデーションモード線形 / 放射状など
角度方向
開始 · 終了フェード区間
中心 (UV)放射状の場合の基準点

レイヤースロット​

テクスチャレイヤー・ノーマルレイヤー・MatCapレイヤーに共通です。

レイヤー数​

表示意味
0（無効）このモジュールが何も計算しない
1レイヤー
Nレイヤー
ここで設定した数より後ろのスロットは計算されません

テクスチャを入れたのに何も見えない場合は、ほとんどの場合レイヤー数が不足しています。インスペクターのツールヒントも同じことを言っています。

順序を変える​

各レイヤーに上へ / 下へボタンがあります。

合成順序が変わると結果が変わります

単純な整理機能ではありません。乗算の上に通常を置くのと、その逆は全く異なる絵です。

値をコピー / 貼り付け​

項目を右クリックすると出てきます。

メニュー範囲
値をコピー / 値を貼り付け1つの項目
レイヤー値をコピー / レイヤー値を貼り付けレイヤー全体
タブ値をコピー / タブ値を貼り付けセクション全体
プロパティ名をコピーシェーダープロパティ名（アニメーション作成時）

貼り付けの結果がログに出ます：値を貼り付け：8個適用、2個スキップ。

スキップされる場合
  • レイヤー — 同じモジュール種別のレイヤーを先にコピーしてください。MatCapレイヤーをノーマルレイヤーに貼り付けることはできません。
  • 値の型 — コピーした値の型に互換性がありません。色をスライダーに貼り付けることはできません。
  • 対象がない — 互換性のある貼り付け先プロパティがありません。

すべての貼り付けは1つのUndo単位です。
