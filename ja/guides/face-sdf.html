顔 SDF と Face SDF Studio

このドキュメントを読むと、フェイスシェーディングと顔 SDF の違いを理解し、別製品の Face SDF Studioがインストールされている場合に方向性のある顔の影を作成してマテリアルへ適用できます。

まず区別してください​

機能内容必要なデータ
フェイスシェーディング顔領域の法線、形状影の境界、キャスト動作を体と異なる方法で処理顔領域マスクまたはプロキシ
顔 SDF光源方向に応じた鼻・頬・まぶたの覆われる順序をテクスチャで制御顔 SDF マップ、必要に応じて正面 UV7
Face SDF Studioレイヤー編集、プレビュー、UV7 投影、最終 SDF ベイクEditor 専用ツール

SDF がなくてもフェイスシェーディングは動作します。まず フェイスシェーディング で顔を整え、光源の移動に合わせたアニメーションのような影の切り替えが必要な場合に SDF を追加してください。

Face SDF Studioは別製品です

MingToon 0.1.7パッケージにはStudioは同梱されません。別途インストールするとTools > Studio Raming > Face SDF Studio > OpenとMingToon連携ボタンが表示されます。StudioはEditor専用で、最終結果はテクスチャと任意の複製Meshのみなので、ランタイムスクリプトは追加しません。

インストールしなくても、既存のSDFテクスチャをMingToon Inspectorへ直接設定して使用できます。

他の別売り連携についてはMask Maker 連携とMing Light Controller 連携を参照してください。

SDF マップ形式​

SDF マップ形式 で次の 2 方式から 1 つを選びます。

形式チャンネル推奨する状況
Packed RGBAR=左、G=右、B=上、A=下上下の照明も使う MingToon の基本方式
Single Channel Mirrored UR 1 枚、反対側の水平光は U を反転既存の単一チャンネル SDF をすばやく取り込む場合

Single Channel は垂直光の影響を使用しません。上下方向の変化も必要な場合は Packed RGBA を使用してください。

ベイク結果を確認する​

Packed RGBA は1枚のテクスチャに4方向を保存します。R=左・G=右・B=上・A=下です。Single Channel Mirrored U はRだけを読み、反対側の水平光ではUを反転するため、垂直チャンネルは使用しません。

Baked Front UV7 では、正面投影の結果がメッシュのUV7（TEXCOORD6）に書き込まれます。そのRendererではUV7をFace SDFが所有するため、同じUV7を顔ノーマルのベイクにも同時に使わないでください。ベイク後は、Inspectorの形式と座標の選択がStudioで使った値と一致することを確認し、左右と上下の照明コントロールを別々に動かして4方向が入れ替わっていないか確認します。

座標の選択​

  • Base Texture UV (Legacy) — 既存の UV0 をそのまま読み取ります。
  • Baked Front UV7 — Scene の正面構図を UV7 に投影します。顔メッシュ UV が複数の断片に分かれている場合や、VRChat・Warudo で正面基準を安定して維持したい場合に推奨します。
UV7の所有権は1つだけです

0.1.7では顔ノーマルは編集中にLiveで動作し、VRChatアップロード用コピーにのみ自動ベイクされます。Face SDFがBaked Front UV7を使用する場合はSDFがUV7を所有し、アップロード時の顔ノーマルベイクはそのRendererをスキップします。

古いtangent-normal UV7が残るマテリアルでBaked Front UV7を選ぶと座標を誤読します。MingToon Managerの顔ノーマルをリアルタイムへ戻すを実行するか、StudioでUV7を再ベイクしてください。→ メッシュ UV ベイク

Face SDF Studio 作業手順​

1. 準備・正面 UV7​

  1. Tools > Studio Raming > Face SDF Studio > Open を開きます。
  2. 顔 Renderer とマテリアルスロットを選びます。
  3. 保存済みの制作プロファイルが自動で一致したら、そのまま使用します。新しい設定が本当に必要な場合だけ 新しいプロファイルを作成 (任意) を使用します。
  4. MingToon では MingToon Directional RGBA4 または必要な単一チャンネル形式を選択します。
  5. Baked Front UV7 を使うとき、元の Mesh に UV7 がなければ Scene ビューを顔の正面に合わせ、UV7 ベイクカードで複製 Mesh をベイクして適用します。
正面構図がそのまま座標になります

Scene ビューのカメラ方向が UV7 投影の基準です。顎を上げたり首を回した状態でベイクせず、目と鼻の中心線が画面中央に来るように合わせてください。

2. SDF 作成・プレビュー・ベイク​

基本の陰影と部位別レイヤーを 1 枚に合成します。

レイヤー役割備考
Base顔全体の明暗切り替え常に使用
Nose鼻筋・小鼻任意
Cheek頬・頬骨画面右側を基準に自動ミラー
Lip唇の周辺任意
Eye Socketまぶた画面右側を基準に自動ミラー

Nose・Cheek・Lip・Eye Socket は、各カードの 含める で最終合成への参加を決めます。テクスチャ・サイズ・位置・反転・滑らかさ・強度を変更すると、自動更新 がオンの一時マテリアルにすぐ反映されます。

レイヤーと最終的な SDF サイズ (中央基準)・SDF 位置 (中央基準) はすべて中央ピボットです。まずサイズを合わせ、小さな位置値で目と鼻の中心線を整列してください。

3. 全方向プレビュー​

一時プレビューを開始 を押して、2 つの照明スライダーを動かします。

  • 左右: -180°～180°
  • 上下: -178°～178°
  • Ming しきい値オフセット — マップ位置ではなく、全体の明暗切り替え時点
  • 境界の滑らかさ — 明るさから影へ移る幅
顔全体が一度に変わる場合

マップ位置を動かす前に 境界の滑らかさ を先に上げてください。切り替え位置が実際の顔の中心とずれている場合だけ、サイズと位置を修正します。

プレビューは元のマテリアルスロットを保存しません。停止、ウィンドウを閉じる、スクリプトのリロード、Play Mode への切り替え時に元のスロットを復元します。

4. 出力と適用​

  • テクスチャをベイク — PNG のみを作成します。
  • 確定して対象マテリアルに適用 — PNG を作成し、現在の顔マテリアルに接続します。

適用すると、SDF マップと座標、フェイスシェーディング・SDF トグル、境界・滑らかさ・影の量がまとめて設定されます。Unity Undo でマテリアルの変更は戻せますが、生成された PNG は残ります。

インスペクターで最後に調整​

  1. フェイスシェーディング をオンにします。
  2. SDF 顔の影を使用 をオンにします。
  3. 顔 SDF マップ が空でないことを確認します。
  4. SDF マップ形式 と 顔マップ座標 が制作時に選択した方式と同じか確認します。
  5. 境界オフセット・境界の滑らかさ・SDF 影の量 を実際のアバター照明で調整します。

顔 SDF マップ が空の場合、Inspector に警告と Face SDF Studio を開くボタンが表示されます。

トラブルシューティング​

フェイスシェーディングをオンにすると Base Pass が消える​

0.1.7正式ビルドでは内部コンパイル診断トグルは表示されません。次の順で確認してください。

  1. Consoleのシェーダー・C#コンパイルエラーを先に解決します。
  2. マテリアルを再選択し、スキーマとキーワードの同期を実行します。
  3. ベイク済みマテリアルならMingToon Managerで編集用マテリアルへ復元してから再ベイクします。
  4. それでも消える場合は、UnityバージョンとグラフィックスAPIを含むエラーログを提出してください。

メンテナンス用バリアントダンプと技術診断はMINGTOON_DEV開発ビルドでのみ使用できます。

左右が逆に動く​

Packed RGBA の R/G チャンネル配置と顔の正面方向を確認してください。Single Channel は反対側の光源で U を自動反転するため、元のマップ自体を左右反転しません。

顔の境界に白いジグザグが見える​

形状影の境界が跳ねる場合は、以前のMingToonシェーダーや古いベイク版が残っていないか確認してください。マテリアルを現在の0.1.7編集シェーダーへ戻し、Face SDFを再ベイクすると最新の境界補正が適用されます。

SDF を使うか判断する​

状況判断
光源が固定された演出フェイスシェーディングだけで十分な場合があります
VRChat ワールドを移動するアバター照明が予測できないため効果が大きいです
Warudo 配信照明方向を変えて使うなら効果が大きいです
作業時間が不足スキップしても残りの顔処理は正常に動作します
