  • Ming Light Controller を使う

すべての商用ライセンスにURPバージョンが含まれます。Personal Streaming・Personal CreatorのEarly Access Founders EditionにはMLCが含まれ、正式リリース後に構成が変更される場合があります。現在のオープンベータでは商用利用は禁止です。ライセンスと同梱構成をご確認ください。

Ming Light Controller を使う

Ming Light Controller（MLC）は、MingToon マテリアルの明るさ・色・バーチャルライト・パフォーマンス設定を VRChat の表現メニューから操作できるようにする 追加インストールするアドオンです。MingToon BRP ベータ本体とは別にインストールします。MLC はオープンベータ期間のみ Studio Raming 公式 BOOTH ページで無料配布し、Early Access 開始から有料販売します。無料配布に MingToon の商用ライセンスは含まれず、ファイル共有や再配布も許可しません。このガイドでは、アバターの設定、メニュー予算の確認、Play Mode とアップロードの確認を説明します。

無料配布と対応シェーダー​

MLCはオープンベータ期間限定で無料配布し、Early Access開始から有料販売する予定です。配布案内とパッケージは公式BOOTH商品ページでご確認ください。MingToonシェーダーは別途インストールが必要です。

シェーダー対応状況
MingToon現在のバージョンで対応
lilToon今後対応予定。現在のバージョンでは非対応
Poiyomi今後対応予定。現在のバージョンでは非対応

対応時期と詳しい範囲は後日ご案内します。MLCはシェーダーを別のシェーダーに変換するツールではありません。無料配布にMingToonの商用ライセンスは含まれず、ファイル共有・再配布は禁止です。

設定は元のアバターに保存します

Edit Mode の MLC コンポーネントはこのアバターの設定を保持します。実際のメニュー・パラメーター・FX と必要なマテリアル処理は、Play Mode またはアップロード用に作られたビルドクローンで行われます。元の FX、メニュー、パラメーター、マテリアルを上書きしません。編集中に Generated フォルダーが作られないのは正常です。

まず製品を区別してください​

製品役割
MingToon BRP ベータ本体マテリアルのレンダリング、インスペクターと Manager、ビルド最適化
Ming Light Controllerアバターごとの操作設定とゲーム内表現メニューの生成
URP アドオン現在のBRPオープンベータには含まれず、すべての商用ライセンスに含まれるURP対応パッケージ
Mask Maker / Face SDF Studio別売りの制作ツール。詳しくは別売アドオンを参照

Ming Light Controller とは​

MingToon でシェーダーのルックを作り、MLC で着用者がゲーム内で変更できる項目を選びます。メニューに入れる機能、同期状態、初期値、プリセットをアバターごとに決められます。

必要なもの​

VRChat で使うには、MingToon マテリアルのあるアバター、VRChat Avatars SDK、NDMF が必要です。既存のメニューと FX があるアバターでは Modular Avatar または対応する VRCFury 接続を使います。MLC はこれらの依存関係を自動でインストールしません。

Direct Descriptor は FX・表現メニュー・パラメーターが空のアバタークローンでのみ使えます。Standalone はアバターにメニューを付けないため、それだけを選んでもゲーム内操作は使えません。

クイックスタート​

  1. アバターのルートに MLC コンポーネントを追加します。またはルートを選び、GameObject → Studio Raming → Ming Light Controller → Add or Configure Component を実行します。
  2. クイックスタートで開始プリセットを選び、プロファイルを Auto にします。適用を押して設定へ反映します。
  3. メニュー構成で使う項目を有効にし、メニュー位置を決めます。必要な項目だけ 選択項目の設定で調整します。
  4. 予算・検証で MLC コスト、他機能のコスト、合計、生成可能性を確認します。赤いエラーや不明な外部コストを先に解決します。
  5. Play Mode で生成メニューと操作結果を確認してからアップロードします。Play Mode プレビューがオフの場合、プレビュークローンには MLC メニューを作りません。

プリセットは編集の出発点です。適用後も項目を編集でき、変更した構成がユーザー設定になります。適用は Undo で戻せます。プリセットの選択と 適用を押すことは別の操作です。

インストールで開放される MingToon 機能​

MLC に接続されたマスター調整・バーチャルライトのオーサリングと、Manager の MLC 設定入口が MingToon で利用できるようになります。ボタンがロックされたままなら、Console のコンパイルエラーとアドオンのインストール状態を確認してください。

MLC がなくてもできること​

MingToon の照明・影・リム・深度効果・アウトラインのレンダリングは MLC なしでも動作します。MLC の編集 UI がロックされても、マテリアルに保存済みの値が消えるわけではありません。

深度テクスチャの可用性とプラットフォーム別ビルドポリシーは MingToon Manager で確認します。MLC のパフォーマンスメニューは準備済みの深度効果をゲーム内で操作します。実際の条件は深度ベースの効果を参照してください。

プロファイルと予算​

プロファイル選択基準
Auto現在の設定とアバター予算を確認し、まず Smooth を検討し、必要なら Compact に切り替えます。
Smooth連続操作の精度を優先します。同期ビットを多く使う場合があります。
Compact同期ビットを減らす代わりに、操作の段階とローカル処理用パラメーター数が変わります。

同期ビットとパラメーター項目数は別々の上限です。ビットの少ないプロファイルが常に項目も少ないとは限りません。Compact を選ぶときは、節約量と UI に表示される精度・段階の説明を確認してください。

コストは有効な機能、Saved/Synced 設定、選択プロファイル、アバターの他のコンポーネントによって変わります。固定値ではなく現在のインスペクター計算値を基準にします。Auto は実際のプロファイル、MLC コスト、外部コスト、合計を一緒に表示します。

不明は利用可能という意味ではありません

他のコンポーネントが作るコストを読めない場合、全体の予算は保証できません。MLC 自体の推定値が見えても、アバター全体が上限内という意味ではありません。不明の原因になった統合状態を確認してから、もう一度検証してください。

メニュー構成​

おすすめの開始構成は Reset、Final Output、Hue/Saturation、Photo Looks、Virtual Light、Master Adjust、Performance です。追加・削除した機能とサブメニューによって最終構成は変わります。スロット数はメニューツリー表示で確認してください。

  • Enabled: 機能をメニューと生成対象に含めます。
  • Saved: 次回使用時まで値を保持します。
  • Synced: 他のユーザーへ同期します。予算に影響します。
  • 連続値・トグルの範囲と初期値は、選択した項目に合わせて表示されます。

コマンドは押したときに実行します​

Reset やパフォーマンスプリセットなどの Command は、ボタンを押したときにイベントとして実行されます。連続操作のような固定値・ピン・復元値は指定しないため、コマンド詳細にはそれらの値操作を表示しません。

以前の設定に無効なコマンド固定値が残っていると、警告と コマンド値設定を修復ボタンが表示されます。このボタンは Saved/Synced の選択を保ったままコマンド値設定を整理します。Undo で戻せます。警告を解決したら、もう一度生成可能性を確認してください。

テンプレートと再利用​

現在の構成をテンプレートファイル、またはコピー・貼り付けで別のアバターへ移せます。プリセット適用とテンプレート取り込みは選択した設定を変更するため、適用先を確認してから確定してください。読めないファイルや無効な内容はエラーになり、適用成功として扱われません。

Play Mode とアップロードで確認すること​

生成は NDMF が作るアバタークローン上で行われます。選んだ接続方式がクローンへメニュー・パラメーター・FXを付け、元のコンポーネントは編集用設定として残ります。必要な統合が利用できない場合、元のアバターへ代わりにインストールせず診断を表示します。

アップロード前にメニューを開き、操作方向・初期値・Reset・必要な同期と保存の動作を確認してください。エディターテストに通っても、実際の VRChat クライアントでの2ユーザー同期までは検証されません。現在の範囲は制限事項を確認してください。

以前のバージョンが残した Generated アセットや MLC 付着物があれば、ツールが表示する専用の整理操作を使います。所有権を確認できないフォルダーを一括削除しないでください。

Mask Maker​

Mask Maker はマスクとバーテックスペイントを作る別売りツールです。MLC の表現メニュー生成には必須ではありません。

インストールで開放される MingToon 機能​

マスクスロットの MM ボタン、シーンビューでのアウトライン幅ペイント、顔領域ペイントが接続箇所です。インストールと範囲は別売アドオンを参照してください。

Mask Maker がなくてもできること​

他のツールで作ったマスクテクスチャをスロットへ割り当てるか、準備済みのバーテックスカラーを使えます。Face SDF の制作は顔 SDF と Face SDF Studioを参照してください。

インストール確認​

  • メニューが表示されない場合は、Play Mode プレビュー、選択した接続方式、SDK・NDMF・接続アドオンのコンパイル状態を確認します。
  • Direct Descriptor が既存メニューや FX で停止する場合は、Modular Avatar または対応する VRCFury 経路を使います。
  • 外部コストが不明なら未解決として扱い、合計を確定と判断しません。
  • 無効なコマンドピンはコマンド修復ボタンで整理します。
  • 編集中に元のアバターへ FX やメニューが作られないのは正常です。Play Mode／アップロードクローンで確認します。
