キャラクター表現

このドキュメントを読むと 鼻影と前髪影を制御でき、顔だけを身体と異なるシェーディングルールで作成できます。

インスペクターのキャラクター表現グループ — フェイスシェーディング・キャラクター高さグラデーションを扱います。全項目リストはキャラクター表現リファレンスにあります。

フェイスシェーディング​

なぜ顔だけ別々に扱うのか​

顔は鼻と目の上が実際の曲がりを持っているため、身体と同じフォームシャドウ設定を使うと**ほぼ常に汚くなります。**アニメーション調ルックで顔がきれいに見えるのは、顔のシェーディングルールが身体と異なるからです。

MingToonはこれを2段階で処理します。

  1. どこまでが顔か — 顔領域を指定
  2. 顔に何を違う様にするか — 法線プレス、境界調整、シャドウ除去

1段階：顔領域を指定​

髪と身体が1つのマテリアルに混在していたら、どこまでが顔かを知らせる必要があります。

方法A — 顔領域マスク（推奨）​

  1. 顔領域マスク使用をオンにします。
  2. マスクテクスチャを入れます。
  3. マスクチャンネル（RGBA）にウェイトを入れます。Gチャンネルのみ使うなら(0, 1, 0, 0)。
  4. 顔が黒く描かれたマスクならマスク反転をオンにします。

境界を調整する項目：

  • マスク強度 — 0ならマスクを無視してマテリアル全体を顔と見なします。 1がマスクそのまま。
  • リマップ開始 / リマップ終了 — マスクのグレー範囲を再度広げます。開始を上げると顔の範囲が狭まり、終了を下げると境界が急になります。両者が同じと境界が完全にカチカチになります。

SceneViewで顔領域をペイント​

マスクテクスチャを作らず、Meshの頂点値で顔領域を指定できます。

  1. 頂点ペイントで顔領域を指定を有効にします。
  2. 顔領域のペイント開始を押します。
  3. SceneViewでPaintを使って顔を塗り、Shiftを押しながら塗ると消去します。
  4. 境界はHardenまたはSmoothで整え、三角形を即座に塗る場合はHard Faceを使います。
  5. 編集メッシュのみ表示で対象Rendererを隔離し、必要に応じてX対称やL/Shift+Lの連結アイランド塗りを使います。
  6. 終了時に保存・破棄・キャンセルのいずれかを選びます。
テクスチャ顔マスクが優先されます

顔領域マスクを使用が有効な場合、頂点ペイントは無視されます。ペイントを使う場合はテクスチャマスクを無効にしてください。マスクが有効なままテクスチャが未設定だと、マテリアル全体が顔として扱われます。

ペイントしたチャンネルはアウトライン圧力チャンネルと分けられるため、1つのMeshで両方の機能を使用できます。

方法B — プロキシボリューム​

マスクテクスチャを使わず、球・円柱・カプセルの内側を顔と見なします。

  1. プロキシを顔領域として使用をオンにします。
  2. プロキシ形状でSphere / Cylinder / Capsuleを選びます。
  3. SceneViewの顔プロキシツールで中心・半径・軸を合わせ、Capsuleでは高さも調整します。
  4. プロキシ境界の柔らかさで首とヘアラインの遷移幅を合わせます。
ボリュームが大きすぎると

首や手まで顔として処理されます。複数のFaceスロットが同じRendererを共有する場合は、プロキシ形状・ランタイム顔フレームを同じ値に揃えてください。異なる場合、アップロードベイクは安全にLive経路を維持します。

マスクの優先順位

テクスチャ顔マスク → 頂点ペイント → プロキシボリューム → マテリアル全体の順です。テクスチャマスク強度が0の場合は下位マスクへ進まず、マテリアル全体を顔として処理します。

2段階：鼻影を取る​

顔のジオメトリが作る鼻・まぶた周辺の影を、プロキシ形状の曲率に沿うノーマルで整えます。

  1. プロキシノーマル強度を上げます。0は元のMeshノーマル、1はプロキシ目標ノーマルです。
  2. 正面平坦化とプロキシ曲面を別方式で切り替える設定はありません。プロキシ形状の目標ノーマルと元のノーマルを、プロキシノーマル強度で1回だけブレンドします。
  3. 顔ノーマル整列と固定方向で正面・上方向の軸を合わせます。
  4. プロキシ曲面を使う場合は、球・円柱・カプセルの中心・半径・軸・高さを先に合わせます。

0.1.7ではこの計算は編集中にリアルタイムです。プロキシや強度を変えると、別途Meshをベイクせず即時反映されます。SceneView左上のパネルでは、ノーマル線とプロキシボリュームを個別に表示・非表示へ切り替え、線の長さ・密度を調整できます。Fitは対象メッシュにプロキシを合わせます。これらの表示設定はライティング計算へ影響しません。VRChatアップロード時はアップロード用コピーにのみUV7 payloadを自動生成し、シーンの元MeshとマテリアルはLive状態へ復元します。

テクスチャ顔領域マスクを使う場合、SceneViewのノーマル線もUV0、Tiling/Offset、HSVG、チャンネル、反転、リマップを反映します。GPUサンプルまたはUVを読み取れない場合は、実際の領域と異なる線を描かず、ノーマル線を非表示にしてパネルへ理由を表示します。

プロキシを動かしても反応しない場合

旧バージョンで顔ノーマルをUV7へベイクしたマテリアルの可能性があります。MingToon Managerの顔ノーマルをリアルタイムへ戻すを実行してください。テクスチャ顔領域マスクはピクセルサンプルが必要なため、アップロード時もLive経路を維持します。

3段階：顔専用シェーディング境界​

  • 顔の境界 — 範囲は0～1、既定値は0.25です。0に近いほど顔が遅く暗くなり、1に近いほど早く暗くなります。最もよく使う調整です。
  • 顔柔らかさ — 顔領域の境界のぼかし幅。
  • 基本フォームシャドウ除去 — 1なら顔領域のフォームシャドウを**完全に消します。**鼻・頬の影を消して2Dシャドウまたはシャドウテクスチャだけで顔の陰影を作る時に使用します。
フォームシャドウセクションがオフなら

顔境界と顔柔らかさは反映されません。

4段階：前髪影​

前髪と小物が顔に作る影をどのように描くか選ぶステップです。フェイスシェーディングの最上部の顔の影の方式グループに影の方式1行が入っています。

値結果用途
体と同じリアル影シーンのリアルタイム影をそのまま受け取ります顔だけ別に扱いたくない時
柔らかい2D影（顔補正）顔で2D影が柔らかく落ちるように補助押し出しを一緒にオンにしますアニメーション ルック。照明が変わっても前髪影の形が揺らぎません
カスタム関連する値を手で調整した状態上記の2つの組み合わせから外れると自動的にここに表示されます
1行が複数の値を一緒に使用します

この決定に必要な値は、元々2つのタブに散らばっていました。モードを選ぶと顔がリアルタイムシャドウをキャストと深度タブの顔補助押し出しが一緒に設定されます。1ユニットで戻し、選択したマテリアル全てに適用されます。

値を直接操作すると、セレクター表示がカスタムに変わります。これは不正な状態という意味ではなく、プリセット組み合わせではないという表示です。

柔らかい2D影（顔補正）はカメラ深度が必要です。深度がない画面では顔に影が残らないため、VRChat 通常画面を基準にするなら、影テクスチャも一緒に準備しておいてください。

実時間影の位置が顔とズレたら、実シャドウキャスターオフセットで顔領域の影キャスターをノーマル方向に押して微調整します。

顔キャストの調整​

0.1.7で動作していなかった顔均一キャストと顔キャスト安定化は削除されました。前髪の影は影の方式、実シャドウキャスターオフセット、2Dシャドウの顔アシスト、Face SDFで調整してください。→ ライティングとシャドウ

顔SDF — スクリプトなしで使う​

別製品のFace SDF Studioがインストールされていれば、Packed RGBA 4方向またはSingle Channelの顔SDFを作成できます。Base UVだけでも使用でき、Baked Front UV7を選ぶと正面投影座標を固定できます。→ 顔SDFとFace SDF Studio

先にフェイスシェーディングを整えてください

SDFは影が覆う順序を変える機能です。顔領域、法線の平坦化、顔の境界のずれを代わりに修正するものではありません。

キャラクター高さグラデーション​

キャラクタールートを基準とした高さをUV4に焼いておき、 その高さで色を染めます。足元を暗くしたり衣装の裾に色を乗せる時に使用します。

最初にUV4を焼く必要があります

キャラクター全体のルート基準高さがUV4.xにある必要があります。メッシ単位ではなくキャラクター単位です。→ メッシ UV ベイク — キャラクター高さ（UV4）

項目機能
下部カラー / 上部カラー2つの色
グラデーション方向上→下に変更すると2つの色の位置が入れ替わります
境界の高さ2つの色が半々に混ざる高さ
境界の柔らかさ境界を基準にぼかす幅。0なら完全に切れます
カーブ指数遷移曲線
影響度全体の適用量
よくある使用法

上部カラーを白（変化なし）にして下部カラーだけ暗くすると、足元に向かって自然と沈み込む接地感が生じます。
