ディテールマップ

このページは ディテールマップ を初めてオンにする方のためのものです。 ベースカラーの上に模様・凹凸・光沢を重ねます。5分ほどかかります。

これは何ですか​

ベースマップ1枚だけでは、布と金属が同じに見えてしまいます。 ディテールマップはその上にレイヤーを重ね、模様・凹凸・光沢を加えます。

いつ使いますか​

  • 衣装にロゴや紋様を重ねたいとき
  • 金属の装飾にだけ輝きを与えたいとき

30秒でオンにしてみる​

  1. 変換したマテリアルを1つ選びます。
  2. サーフェススタックを使用 をオンにします。
  3. サーフェススタックレイヤー数 を1に上げます。
  4. レイヤー01の 追加テクスチャ に画像を入れます。

入れた画像がベースカラーの上に見えれば成功です。 何も変わらない場合は 変換のトラブルシューティング へ進んでください。

オンにする手順 — 3つのモジュールはすべて同じ順序です​

  1. モジュールの使用スイッチをオンにします。
  2. レイヤー数を使う分だけ上げます。
  3. その番号のスロットにマップを入れ、強さを決めます。
モジュール使用スイッチレイヤー数の項目上限
追加テクスチャサーフェススタックを使用サーフェススタックレイヤー数10
ノーマルマップノーマルレイヤーを使用ノーマルレイヤー数5
MatCapMatCapレイヤーを使用MatCapレイヤー数5
マップを入れたのに何も表示されないとき

レイヤー数より後ろにあるスロットは計算自体をスキップします。 強さや不透明度が0のときも結果は同じです。

レイヤー数のリストは最初は0～2までしか表示されません。 さらに使うには、リスト横の レイヤーを増やす（最大N） ボタンを押してください。 Nはモジュールごとに異なります。サーフェススタックは10、ノーマルは5、MatCapは5です。

よく触る値​

インスペクターのラベル何が変わるか推奨する初期値上げると / 下げると
不透明度追加テクスチャ1枚が重なる量1下げると下の色が透け、0にするとそのスロットは計算されません
ノーマル強度凹凸が見える強さ1上げると起伏が誇張され、0にすると平らになります
強度MatCap1枚の光沢の量既定値のまま（0.74）上げるとテカり、0にするとそのスロットは計算されません
スムースネス反射のまとまり具合既定値のまま（0.5）上げるとハイライトが点のように小さくなります
スペキュラー強度PBR反射全体の強さ既定値のまま（1）0にするとハイライトと環境反射がまとめて消えます
トゥーンスペキュラー強度セルハイライトの明るさ既定値のまま（0.5）上げると白く飛んでしまいます
オクルージョン強度オクルージョンマップが暗くする量10にするとマップを入れても変化しません

全項目と範囲は ディテールマップリファレンス にあります。

光沢を作る2つの道​

PBRサーフェス​

金属・エナメル・濡れた唇のように物理的な反射が必要なときに使います。 PBRサーフェスを使用 をオンにして ワークフロー を選びます。 Metallicは メタリック から反射色を作り、Specularは色を直接指定します。

パックマスクを使用 をオンにすると、1枚からチャンネルごとに読み取ります。 既定の配置はRがメタリック、Gがオクルージョン、Aがスムースネスです。

パックマスクを使用をオフにすると

以下のチャンネル・反転の設定はすべて無視されます。 メタリックとスムースネスのスライダー値だけが使われます。

トゥーンスペキュラー​

PBR全体をオンにせず、光源方向のハイライトだけを加えます。 髪・瞳・布の薄い光沢に適しています。 トゥーンスペキュラーを使用 をオンにして トゥーンスペキュラーモード を選びます。

Isotropicは目や金属ボタンのような丸いハイライトを作ります。 Anisotropicは髪のように長く流れる帯を作ります。 形は トゥーンスペキュラーしきい値 と トゥーンスペキュラーのぼかし で整えてください。

ハイライトの色を部位ごとに変える​

トゥーンスペキュラー色の指定方法 を Mask Texture Color に変えます。 するとマスクに塗っておいたRGBの色がハイライトの色になります。 混ぜる量は トゥーンスペキュラーのマスク色適用量 が決めます。 マスクはすでに読み取っているため、テクスチャをもう一度読むことはありません。

領域マスク​

1つのマテリアル内の部位をRGBAの4領域に分け、別々に補正します。

  1. 領域マスクを使用 をオンにします。
  2. 領域マスクのスロットにRGBAテクスチャを入れます。
  3. 各領域の補正値を0から少しずつ上げます。
補正する対象が必要です

領域マスクは表面の反応を補正する機能です。 PBRサーフェスとトゥーンスペキュラーがどちらもオフだと、何も起こりません。

発光ときらめき​

エミッションを使用 をオンにして、マップ・色・強度を決めます。 エミッション色 が黒だと、マップがあっても光りません。 グリッターを使用 は グリッター色 と グリッター強度 の順で整えてください。

粒子の形を変える​

形マップを使用 をオンにして 形マップ にテクスチャを入れます。 Textures/Glitter/ に星・ハートなど6種類が入っています。 形チャンネル の既定値はAで、白黒画像ではRか輝度を使ってください。 向きのある形を立てるには 回転ランダム を0に下げます。

マスター調整とパフォーマンス距離​

パフォーマンス距離 (m) と パフォーマンス距離倍率 はシェーダーの機能です。 別売アドオンがなくてもいつでも編集できます。 境界は2つの値を掛けた距離で、その外側では基本のシェーディングだけが残ります。 マスター調整の残りの行はMing Light Controllerが提供します。

よくある問題​

症状原因対処
マップを入れたのに表示されないレイヤー数がそのスロット番号より小さいレイヤー数を上げます
ハイライトがまったく出ないスペキュラー強度が0になっているスペキュラー強度を1に戻します
発光が見えないエミッション色が黒になっている色を白に近づけます
