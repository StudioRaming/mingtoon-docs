ライティングとシャドウ

このドキュメントを読むと 3種類のシャドウを区別でき、どの順序で調整すべきかが分かります。

インスペクターのライティングとシャドウグループ — ライティング・影の色・フォームシャドウ・影投影を扱います。全項目リストはライティングとシャドウリファレンスにあります。

まず：シャドウは3種類です​

MingToonで「シャドウ」と呼ぶものは異なる3つです。これを区別できないと見当違いのスライダーを触り続けることになります。

種類インスペクターセクション何が作るのか
フォームシャドウフォームシャドウ表面法線と光源方向。キャラクター自身の曲がりで生じる明暗。トゥーンルックの本体
キャストシャドウ影投影Unityのリアルタイムシャドウマップ。他の物体と自分自身が落とすシャドウ
2Dシャドウ2Dシャドウ（深度ベースエフェクト）カメラ深度テクスチャ。スクリーン空間で計算

作業順序​

  1. フォームシャドウ境界 → 2. 影の色 → 3. 2次段階 → 4. 影投影 → 5. 顔の例外 → 6. 境界装飾

重なる影を確認する​

まずフォームシャドウとキャストシャドウを調整し、次に2DシャドウとSSAOを1つずつ有効にして重なる部分を確認してください。最後に統合シャドウの色と境界表現を調整すると、各効果の影響を区別しやすくなります。これは見た目を調整する手順であり、シェーダー内部の計算順序を示すものではありません。2DシャドウとSSAOにはカメラ深度が必要です。

原因を切り分けるときは、追加した効果を1つずつ一時的にオフにして比較してください。接触部が暗すぎる場合はSSAOをオフにした結果と比較し、投影シルエットに沿って帯が見える場合はキャストシャドウと2Dシャドウを別々にオフにして、どちらの効果で生じるか確認します。

1. フォームシャドウ境界 — 最初に​

1次シャドウ柔らかさがMingToonで最も頻繁に調整する値です。 ここでルックの性格が決まります。

値結果
0.001近くセルアニメーションのようにはっきり落ちる境界
0.05～0.15ほんのり柔らかいイラスト感
0.3以上柔らかいグラデーション

最初にこの値1つだけ動かして目的の性格を決定してから、残りに進んでください。クイック設定の1次シャドウ柔らかさが同じ値です。

2. 影の色​

1次シャドウ明るさを下げると暗くなります。ただし：

注意
影の色セクションがオフなら

1次シャドウ明るさは反映されません。キャストシャドウも同じく、このセクションがオフなら単に暗くなるだけでキャストシャドウ明るさは無視されます。

統合シャドウ — 重なると真っ黒になる問題​

フォーム・キャスト・2Dシャドウが同じ場所に重なると3回暗くなって真っ黒に潰れます。影の色内の**統合シャドウ使用をオンにするとこの3つが同じ色と調子に収束**してこの問題がなくなります。

統合モードで保持されるもの / 無視されるもの
  • 保持 — シャドウ境界の形態設定、シャドウパターン（スクリーントーン）
  • 無視 — 個別シャドウの色・ブレンド・明るさコントロール（値自体は保存されるのでオフにすると戻ります）

統合シャドウ色のアルファが適用量です。アルファが0なら色を選んでもシャドウはベース色のままです。

オフにするとルックが一度に変わることがあります

統合シャドウをオフにすると、各層に保存されていた色がそのまま戻ります。 統合で作業している間に個別の色を触っていなければ、オフにした瞬間に以前の値が一斉に現れます。

部位ごとに違う影色 — シャドウカラーマップ​

統合シャドウは色がひとつです。髪は赤み、肌は黄みのように部位ごとに違う影色が必要なら シャドウカラーマップ をオンにしてください。統合シャドウの1色を UV マップで分布させます。

  • 白が基準値です。 白い部分は統合シャドウの色そのままで出て、塗った部分だけがその色で乗算されます。オンにしただけでは結果は変わりません。
  • カラーマップ適用量 が0なら統合色ひとつだけ、1ならテクスチャの色をそのまま乗算します。テクスチャHSVGで色相・彩度・明度・ガンマを個別に調整できます。
統合シャドウ専用です

統合シャドウがオフの場合、シェーダーはこのテクスチャをまったく読みません。 レイヤー別シャドウモードは層ごとに色を持っているため分布させる対象がなく、取得コストもかかりません。

ハイライトマスクが残っているなら

このマップと併せてマットキャップやスペキュラーのマスクとしても使うことをおすすめします。色の分布と光沢を分けて調整できます。

3. 2次シャドウ — 3段セルシェーディング​

2次シャドウ使用をオンにすると最も暗い側にもう1段階が生じます。

  • 2次シャドウ明るさは1次より低くしておくべき段階が区別して見えます。
  • 2次シャドウ柔らかさを1次より狭くしておくと内側の段階がはっきりします。

4. 影投影（キャストシャドウ）​

リアルタイムシャドウはトゥーンルックで最も問題を起こしやすい部分です。キャストシャドウ受信グループから見ます。

受信強度が**0ならキャストシャドウが完全に消え、**下の明るさ・ブレンド・間接光補正も結果に表れません。

シャドウがトゥーンらしくない時​

PBR/トゥーン混合を1に上げるとUnity既定の柔らかい減衰の代わりにトゥーンバンドでぴったり切れます。バンド幅はキャストトゥーンバンド柔らかさが決定します。

ムラムラなシャドウ​

衣装の皺や身体にノイズのようなムラが出たら：

  1. セルフキャストシャドウ抑制をオンにします。
  2. セルフシャドウキャスターバイアスを0.01～0.03の間で調整します。
バイアスを上げすぎると

ムラは消えますが接地シャドウが浮き、薄い部分のシャドウが切れます。少しずつ上げてください。

顔の掠めるシャドウ​

影の方式には体と同じリアル影、2D影（顔補正）、カスタムがあります。顔の影は次の順で調整してください。

  1. フェイスシェーディングの影の方式で体と同じリアル影または2D影（顔補正）を選びます。
  2. 2Dアシストを使わない場合だけ実シャドウキャスターオフセットを調整します。アシストがOFFでない場合、この行は無効表示になります。
  3. 顔プロキシ中心・ノーマル整列・Face SDFの遷移を先に合わせます。

シャドウ境界がはしご状に粗い時​

投影フェザーグループの投影フェザー使用をオンにし、投影フェザー半径・投影フェザー強度を調整します。半径範囲は0～20pxです。Light3Tap・Standard5Tap・High9Tapはこの範囲全体で選択でき、高品質ほど境界サンプルが増えます。キャスト境界フェザー品質も一緒に確認してください。

フェザーは無い情報は復旧できません

低解像度のシャドウマップに元々なかったディテールは柔らかくしても戻りません。最初に光源のシャドウマップ解像度とbias/normal bias、カスケードを確認してください。

シーンごとにシャドウが強すぎたり弱すぎたり​

キャスト間接光補正を上げると環境光が明るい場所でキャストシャドウが薄れます。室内・屋外を行き来するアバターで照明差を自然に吸収します。

逆光で身体にキャラクター型シャドウが重なる時​

逆光シルエット抑制をオンにすると光源を向いた面にはキャストシャドウを描画しません。

2Dシャドウと色が別々に見える時​

2Dシャドウと統合をオンにすると2Dシャドウがキャストシャドウと同じ色を使い、重なる場所で2回暗くなるのも防ぎます。

5. 顔は別々に調整します​

→ キャラクター表現

6. 境界装飾 — 最後に​

明暗境界に色帯を重ねる演出です。ルックが全て決まった後にしてください。

  1. シャドウ境界使用をオンにします。
  2. 境界幅を上げます。0なら下の項目はすべて無視されます。
  3. 境界ブラーで、明るい側から強いバンドまで満ちる長さを合わせます。
  4. 境界強度で不透明度を合わせます。

キャスト境界は明るい側から滑らかに満ち、シャドウコア直前で最も強くなってからコアで消えます。フォーム・キャスト・2Dシャドウ・SSAOの合成後に最後のシャドウレイヤーとして描かれるため、重なる部分でも色が埋もれません。統合シャドウ内部を横切るオクルーダー輪郭は消去され、空の縁取りのように浮きません。

皮膚と髪が1つのマテリアルに混在してたら

境界ベースマップ混合を上げてください。0なら単色の境界、1ならベースマップ色と混ざって部位ごとに異なる境界色が出ます。

境界が見えない条件

影の色セクションがオンになっていて、フォームシャドウまたは投影シャドウのどちらかが実際に動作している必要があります。境界はすべてのシャドウ合成の最後に描画されます。

ライティング — 暗いシーンで真っ黒に潰れる時​

VRChatワールドは照明をアバタークリエイターが制御できません。ライティングセクションの下の項目が防御線です。

項目機能
ベース色保持
（シンプルモード：ベース色保存）		完成したベースカラーにシーン照明の色味をどれだけ混ぜるか。0では照明色をそのまま反映し、1ではベースカラーを優先します。照明の明るさやエネルギー自体は保持しません
シーンライト色影響
（シンプルモード：照明色反映）		0なら何色の照明でも白い照明のように見えます。明度ではなく色だけを扱います
間接光補正環境光の明度だけ分フォームシャドウを持ち上げます。フォームシャドウがオンの時のみ計算されます
VRC Light VolumesBuilt-in専用のエディター確認用トグルです。VRChatアバターのアップロード経路では値に関係なく自動でオンになり、ワールドのボリュームを読みます。ボリュームがなければUnity Probeへフォールバックし、URPマテリアルではこの行は表示されません
最終最小明るさいくら暗くてもこれ以下に下がりません
最終最大明るさいくら明るくてもこれ以上に上がりません。過度露光ワールド対策

明るい面の明るさは光を受ける面全体の乗数です。1が基準で、上げると明るい面が白色に潰れやすくなります。

追加光源​

ポイント/スポットライトへの反応は別項目です。

  • 追加光源受信・追加光源強度（シンプルモード）
  • 追加光源PBR/トゥーン混合・追加光源トゥーン閾値・追加光源トゥーン柔らかさ（全設定）
  • 追加光源最大明るさ — ベースカラー倍率ではなく、追加光結果の絶対HDRピーク上限

リム・追加光にも上限をオンにすると、同じ値がディレクショナル主光源と追加光源の両方からリム、バックライト、フロントライト、透過光、マットキャップ、エミッション、グリッターへ届くシーンライト強度も制限します。1なら強度1まで、3なら強度3まで反映します。オフにすると最終加算上限と効果入力上限の両方が解除されます。

主光と同じトーンを保つには追加光源側のトゥーン閾値も一緒に合わせてください。絶対上限は暗いマテリアルのスペキュラーをベースカラーで押し潰さず、複数ライトの過露光を制限します。

マスター調整とエッジリム​

マスター調整は明るい面・シャドウ・最終出力の色・明るさ・彩度を一箇所で補正します。エッジリムマスターは2Dリム・フレネルリム・バックライトなどシルエット系の強度、専用カラー、HDR上限をまとめて調整します。個別リム設定はリムを参照してください。

このグループのマスター強度・カラー行はMing Light ControllerのオーサリングUIが利用できる場合だけ表示されます。パフォーマンス距離はMLCなしでも表示されるMingToonの基本設定です。
