アウトライン

このドキュメントを読むと ノーマルアウトラインを設定し、部位ごとに太さを調整できます。

インスペクターのアウトライングループ — ノーマルアウトライン を扱います。全項目の一覧はアウトラインリファレンスにあります。

内側2Dエッジはここにはありません

表面内側の線を描く 内側2Dエッジ は画面深度を読み取るため深度エフェクトグループにあります。 → 深度エフェクト

ノーマルアウトライン​

メッシュを反転して拡張する方式です。追加パス1回で描画され、深度テクスチャなしで動作するため、どの環境でも安全です。VRChat通常画面のように深度が使えない場所でシルエットを捉える唯一の方法です。

基本設定​

  1. Classic Hullを使用をオンにします。
  2. 幅モードを選びます。
幅モード動作推奨
PixelStable画面ピクセル基準。距離に関わらず厚さ一定アバターはこちら
WorldSpaceワールドサイズ基準。遠くなると薄くなる固定カメラ演出
  1. アウトライン幅とアウトライン色を調整します。（クイック設定にもあります）

このようになれば正常です。 キャラクターシルエットの外側に線が描画されます。

線の太さを部位ごとに変える​

圧力ソースを選ぶ​

圧力ソースで太さを調整するペイントチャンネルを選びます。

ソース読み込み内容
VertexRed頂点カラー R
VertexAlpha頂点カラー A
WidthMask幅マスクテクスチャ
OutlineNormalUV8UV8にベイクされたアウトライン法線。長い面は太く、頂点は細く
線が完全に消えた場合

頂点カラーが黒でインポートされたメッシュで VertexRed を選んだ場合です。圧力が0なら幅も0になります。圧力ソースを変更するか、頂点カラーを確認してください。

ハル圧力コントラストは太さの差を大きくします。0なら圧力が完全に無視され、1が元値、高いほど細い部分がより細くなります。

Hull アウトラインに適用 / Inner Edge アウトラインに適用で圧力をどちらに反映させるか決めます。

注意
Inner Edge アウトラインに適用はノーマルアウトラインをオフにしても動作します

このトグルはノーマルアウトライングループ内にありますが、内側2Dエッジに作用し続けます。頂点カラーが黒いメッシュでオンになっていると、内側2Dエッジが完全に消えます。

シーンビューで直接塗る​

太さを手で塗ることができます。

準備​

  1. 圧力ソースをVertex AlphaまたはVertex Redにします。そうでなければ、インスペクターが 頂点ペイントで厚さを調整するにはPressure Sourceが Vertex Alpha または Vertex Red である必要があります。 と共に Vertex Alpha に切り替え ボタンを表示します。
  2. このマテリアルを使用するレンダラーが現在の選択項目の下にある必要があります。MingToon マネージャーを選択すればOKです。
  3. マテリアルは1つだけ選択します。
チャンネル競合警告が出た場合は進めないでください

圧力ソースがVertex Redで、ノーマルソースがVertexColorTSの場合、両方が同じ頂点カラーを読み込みます。このままペイントすると、RGBに保存されているアウトライン方向が上書きされ、深度エフェクトマスクも赤チャンネルを一緒に読み込みます。

インスペクターがこれを警告して それでも塗る ボタンを表示します。進む前に以下のいずれかをしてください。

  • 圧力ソースをVertex Alphaに変更
  • アウトライン法線をUV8TSに移す → メッシュUVベイク

塗る​

シーンビューでアウトライン幅を塗るをクリックするとシーンビューにオーバーレイが表示されます。

操作動作
ドラッグ塗る
Shift + ドラッグ消す
[ ]ブラシサイズ
Esc終了

オーバーレイで調整できる値：

項目機能
半径ブラシサイズ
強度一度に塗られる量
減衰ブラシ端のぼかし
裏面まで塗る画面に見えない裏面頂点も一緒に

現在のチャンネルが チャンネル: Vertex Red （Shift = 消す） のように常に表示され、Vertex Red の場合は 赤チャンネルは深度エフェクトのマスクからも読み取られます。 と一緒に通知されます。

終わったら アウトライン塗りを終了 または Esc。

知っておくこと​

頂点ペイントはメッシュアセットをディスクに直接書き込みます
  • プレイモードでは禁止されます。 Unityが戻してくれないためです。プレイを終了して再度開始してください。
  • 同じメッシュを使う他のレンダラーも一緒に変わります。 インスペクターがどのメッシュアセットが影響を受けるかをリストで警告します。このレンダラーのみに適用したい場合は、まずメッシュを複製してこのレンダラーに割り当ててから塗ってください。
インポートされたメッシュは自動的にコピーが作成されます

元のFBXは触れず、編集可能なコピーを作成してレンダラーに割り当てます。

塗る途中で Undo で元のメッシュが復元されるとペイントが中断されます（Undo で '{メッシュ}' の元のメッシュが復元され、塗っていたコピーは使用されなくなります。）。再度開始すればOKです。

塗れない場合と対策はトラブルシューティングにまとめられています。

角張った部分で線が切れる場合​

ノーマルソースが原因です。

ソース条件
MeshNormalメッシュ法線そのまま。ハードエッジで線が開きます
VertexColorTS / UV8TSスムーズされたアウトライン法線を頂点カラーまたはUV8にベイクしている場合のみ有効
危険
ベイクされていないメッシュで UV8TSを選ぶと

むしろ角張った部分で線がさらに切れます。ベイクされていなければ MeshNormal を使ってください。

注記
VertexColorTSなのに頂点カラーがないメッシュなら

メッシ法線に落ちて動作します。線が対角線で全体的にズレて出ません。

髪・スカートで線が形態を外れる時​

球や円筒からノーマルを移してきたモデルは、シェーディング用ノーマルが実際の形態と異なります。そのまま焼き込むとアウトラインがメッシュではなく移してきた球を追ってしまいます。

UV8を焼く時、ノーマルを編集したモデル用に計算をオンにするとメッシの面から方向を再計算します。シェーディングはそのままにしておきながら、外郭線だけメッシを追います。デフォルト値はオフです。 → メッシュUVベイク

方向をテクスチャで直接指定することもできます。指定ベクトル方向を使用をオンにしてベクトルUVとベクトルスケールを設定します。スケールを負の値にすると方向が反転します。オフにするとこの2項目は無視され、ノーマルソースが方向を決定します。

線が他のパーツに埋まる場合​

深度バイアスでハル全体をカメラ側に引き寄せます。引き寄せすぎると線が顔の前に浮いて見えます。

ボディ内側に不要な線が出た場合、内側線抑制オフセットでハルを表面側に沈めます。

アウトライン色が照明に従う​

シェーディングを含めるをオンにすると、本体の形態シャドウ色を追う軽い明暗バンドがアウトラインに適用されます。太いアウトラインで線が照明に従って暗くなる印象が残ります。オフにするとライティングに関わらず均一な色を保ちます。

アウトラインは本体シェーディングを複製しません

アウトラインはベースマップ色と照明応答だけで描かれます。本体のシャドウパターン・投影シャドウ・深度エフェクトを線の上に再度描きません。そのためピクセルコストが低いです。

スクリーントーンを線にも塗りたいなら、アウトラインシャドウパターンを別にオンにしてください。 → シャドウパターン

他のシェーダーと重なる場合​

ステンシル設定は他のシェーダーのマスクと連動する時だけ触ります。デフォルト値ではステンシルがアウトラインに影響を与えません。

カラーマスクが0ならアウトラインが画面に全く記録されません。デフォルト値15がRGBA全体です。
