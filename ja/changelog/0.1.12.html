0.1.12 下書き

配布前の下書き · 2026年9月30日作成

この文書は安定版 0.1.12 の配布前の下書きです。 公開パッケージの新規導入・更新の受け入れ検証後に確定します。 プレビューノートは内部検証記録として保持します。

幅の狭い画面の表示改善​

  • 幅の狭い Manager でもマテリアル選択ボタンに短い名前と説明のツールチップを表示します。
  • Play モードのビルド処理オプションを短いラベルにしました。初期値と動作は同じです。
  • 簡易モードでルック名と適用ボタンを一緒に表示します。保存したルック、High/Low の個別項目、色調プリセットも維持しています。

変換とアウトラインの改善​

  • 有効な法線とUV0がありタンジェントのないメッシュも、元を保ったまま生成コピーへタンジェントとUV8を用意して自動アウトラインベイクを行います。
  • 変換中に同じシェーダー準備プランを繰り返し解析する処理を減らしました。
  • 初回表示のウォームアップで、影のないディレクショナルライトの描画状態も準備します。環境によっては追加のコンパイル待ちが残ります。

要約​

元を残す変換と編集画面を整理しました。

更新前の確認
  • プロジェクトをバックアップし、元のマテリアルを残してください。
  • ベータ版は UI・機能・見た目が変わります。元からの再変換を推奨します。
  • 手動ベイクを復元して再ベイクし、VRChat へ再アップロードしてください。
  • マスクを使う既存マテリアルを開き、有効状態を確認してください。

新機能​

  • MingToon のコピーを作成 — 元の隣に独立したプレハブとマテリアルを作ります。→ ウィザード
  • 開始 · 見た目 · 軽量化 — Manager の作業を3タブに整理しました。→ Manager
  • 簡易 · 詳細 — 機能の行・折りたたみ・詳細編集を整理しました。→ Inspector
  • アップデート — 開くと最新情報を取得します。選択言語の Markdown 変更内容を表示します。

既定値と見た目の変更​

  • パフォーマンス距離を使うは新規マテリアルでオフです。距離最適化に使う場合はオンにしてください。

  • 最終最大明るさが効果を動かす光も制限します。強い照明で見た目を確認してください。

  • ノーマルマップの影はノーマルマップ設定内にあります。新しい 陰影の強さ の既定値は0.7です。

  • lilToon の新規変換のトゥーンスペキュラ合成不透明度は、以前の補正値の0.5倍です。既存の値は保持します。

  • キューブマップを使用は新規マテリアルでオフです。パターン・グリッターのスライダー上限が増えました。

  • Light Volumes v3 ネイティブ経路を追加しました。v2 経路も維持します。

  • 輪郭線はボリュームの基本色・明るさに従います。内部の個別ライトは反映しません。

  • ボリュームの暗化・明化応答の設定は画面から削除しました。保存値は残りますが使いません。

修正した問題​

  • 廃止されたマスクチャンネルのために Factory ルックの適用が拒否される問題を修正しました。
  • 静的な大きいテクスチャプレビューの重複 GPU 描画を削減しました。同じ入力100回で100→1回、比較ピクセルは一致しました。
  • 暗いライトボリュームで輪郭線だけ明るくなる問題を修正しました。
  • 明るい領域にシャドウ反射が誤って加わる問題を修正しました。
  • 準備済みシェーダーの組み合わせは有効な記録・パスキャッシュで再コンパイル要求を省きます。体感差は環境ごとに異なります。
  • VRChat ビルドでは MA 後・AAO 前にメッシュとテクスチャを準備し、最終変形後にシェーダーを解析します。

既知の制限​

  • 変換全体の時間・コールドシェーダーコンパイル・初回表示が常に短くなる保証はありません。非同期コンパイル中はシアンのプレースホルダーが残ることがあります。

  • プレビューの数値は静的な大きいカードの GPU 描画要求数です。全体の FPS や GPU 時間ではありません。

  • 実時間・ストリーミングテクスチャと小さいカードは引き続き更新します。

  • ウォームアップですべてのシェーダーの組み合わせのコンパイルがなくなるわけではありません。

  • Manager の 現在の負荷 は推定値で、実際の GPU 使用率ではありません。

  • 新規導入・更新の受け入れ検証と、実アバター・URP の検証は別の段階です。

  • 配布対象は BRP コアです。MLC・Face SDF Studio・Mask Maker は別製品です。
