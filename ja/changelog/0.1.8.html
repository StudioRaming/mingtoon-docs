0.1.8

オープンベータ · 2026-09-08

0.1.8​

固定リンク: 0.1.8 パッチノート

主な修正と使いやすさの改善​

  • 初回アップロード時間 — アップロードに過度に時間がかかる問題を改善しました。ユーザー計測では初回アップロードを基準に 3～50% 速くなったと報告されており、環境によって異なります。
  • VRC ベイク後の白表示 — VRC ベイク後にアップロードしたキャラクターが白く見える問題をほぼ修正しました。
  • MLC のビルド競合 — MLC と一部アセットの競合でビルドに失敗する問題をほぼ修正しました。
  • インストール方式の移行 — 予告していた VCC・VPM ベースのインストールと更新方式を今回のバージョンで導入しました。初回 DLL インポート後は追加のインストールボタンなしで必要な MingToon パッケージを自動インストールします。その後は Unity 起動時に新しいバージョンを自動確認し、未インストールかつスキップしていないバージョンの通知を表示します。通知の「更新」ボタンをユーザーが押した場合にのみインストールし、Unity を再起動しただけでは自動インストールしません。「スキップ」はそのバージョンだけに適用され、次の新しいバージョンでは再び通知します。VCC インストール版は VCC から手動で維持・更新します。
  • インストール失敗時の復旧 — インストールに失敗した場合は既存のシェーダーフォルダー Assets/StudioRaming/MingToon だけを削除して再インストールすると、作成済みマテリアルを維持したまま同じシェーダー GUID に再接続できます。フォルダー内に直接保存した .mat やテクスチャがあれば、先に別のフォルダーへ移してください。
  • 変換の安定性 — lilToon 変換で SSAO の色の純度が変わったり、発光マスクが無効になったり、マスクデータが圧縮で変化したりする問題を修正しました。
  • Manager の操作 — 更新状態と現在・最新バージョンを 2 行にまとめ、パネルの高さを以前の約 3 分の 1 にしました。同じ場所で 確認・更新・更新履歴 を使えます。
  • インストールと更新の経路 — DLL 経路では、unitypackage 内の DLL を初回インポートすると追加のインストールボタンなしで必要な MingToon パッケージを自動インストールします。その後は Unity 起動時に新しいバージョンを自動確認し、未インストールかつスキップしていないバージョンの通知でユーザーが「更新」ボタンを押した場合にのみインストールします。Unity が再生・コンパイル・ビルド中の場合は待機し、再読み込み後にもう一度確認します。Unity を再起動しただけでは自動インストールせず、「スキップ」はそのバージョンだけに適用され、次の新しいバージョンでは再び通知します。VCC からインストールしたユーザーは、これまでどおり VCC から手動で維持・更新します。
  • 既存アセットの保持 — 既存の 0.1.7 インストールとインベントリを認識し、パッケージが管理するファイルだけを更新します。既存のマテリアル・シーン・プレハブと Unity が生成した package.json.meta は保持されます。

新機能​

  • カラー・プリセット — カラー・プリセット でシャドウ・リム・深度・ティント・HSVG をまとめて適用し、ファクトリーパレットを選択したマテリアルに適用できます。テクスチャ・レンダー状態・キーワードは保持され、Undo で元に戻せます。
  • バンドとリムの色調整 — クイック設定で全体の彩度・全体の発光強度を調整し、リムシェードカラー とシャドウバンドの色を直接設定できます。
  • レイヤーごとの UV 選択 — ノーマルレイヤーとマスクが使う UV チャンネルをレイヤーごとに選択できます。

変更​

  • 言語表示 — インストール・更新メッセージはシステム言語に合わせて韓国語・日本語・その他の言語では英語を選択し、Manager のラベルはインスペクターの言語選択に従います。
  • 変換結果 — 変換したマテリアルで RGBA 発光マスク、表面アルファのブレンド、ノーマルとマスクの作成時 UV 選択を保持します。

改善​

  • シェーダーベイク — 同一のリクエストをまとめて処理し、繰り返しベイク時の重複作業を減らしながら既存の生成結果と状態を保持します。
  • 生成結果の復旧 — ベイクが中断しても不完全なファイルを残して次の生成シェーダーキャッシュを壊さないよう、復旧処理を強化しました。

ドキュメント​

  • Manager の 更新履歴 から最新のローカライズ済みドキュメントを開けます。現在のバージョンと最新バージョンも同時に確認できます。
