MingToon Manager から始める

MingToon で作業するアバターのルートには、常に MingToon Manager を配置してください。 対象メッシュ・変換・ルック・更新確認を Manager で管理します。このガイドではインストール直後の追加から変換、クイック設定による調整まで進めます。インストールを済ませてから始めてください。Face SDF Studio はまだ未発売で、この手順には必要ありません。

1. 最初にアバタールートへ Manager を追加​

Hierarchy で変換する作業するアバターのルートオブジェクトを選びます。Add Component で MingToon Manager を検索して追加してください。衣装だけを編集する場合も Manager はアバタールートに配置します。対象メッシュが配下にあることを確認し、Manager を1つ選択して進めます。変換後もコンポーネントを残し、更新と作業状態を確認してください。

VCC からインストールした場合、MingToon の更新は VCC で行います。 Manager の更新案内を使う前に、インストール方法を確認してください。

2. Face Mesh と Skin Mesh を指定​

Manager の Setup で、顔メッシュを Face、素肌メッシュを Skin に指定します。顔・肌レンダラーの指定欄を使い、スロットごとの役割プレビューで範囲を確認してください。目・まつ毛・衣装・髪まで一括で顔や肌に指定しないでください。

顔や素肌のない衣装だけを変換する場合は、指定を空欄にできます。1つの Renderer に素肌と衣装が混在する場合はスロットで分け、衣装を Regular にします。役割はプリセットの顔用・肌用・共通の値を適用する対象を決めます。

→ 役割指定の詳細

3. ルックプリセットを選択​

変換時のルックプリセットで出発点となるルックを選びます。まず希望の雰囲気に近いプリセットを選び、変換後に値を整えてください。元マテリアルから読み取った設定を出発点にし、ルックプリセットを適用しない場合は 適用しない を選択します。

4. 色調または既存マテリアルの値を選択​

出発点選択
プリセットの色で新しい雰囲気を作る色調プリセットで好みのトーンを選択
元マテリアルの色を基準に始める既存の値を使用を選択

既存の値を使用は、変換した元の色・影バンド・合成設定を保持します。ルックプリセット全体を無効にする 適用しない とは別の選択です。色調プリセットはルックの後に適用され、選択だけではマテリアルを変更しません。

5. 変換ボタンを押す​

対象メッシュ、役割、ルック、色調を確認して変換を押します。完了後は編集用 MingToon マテリアルが対象に適用されたことを確認してください。除外・失敗スロットがある場合は、該当マテリアルと理由を確認してから進めます。

6. クイック設定でルックを調整​

変換済みマテリアルを選び、Inspector のクイック設定を開きます。Manager のマテリアル選択機能で、顔や肌など必要な対象だけを選べます。最初は顔・肌・衣装を分けて調整し、全体へ同じ値を設定したいときに複数選択します。

色と明るさ → 影の境界 → アウトライン → リム・光沢・エミッションの順に、1項目ずつ動かしてモデルの変化を見ます。クイック設定にない項目は検索や全設定で探してください。下記の機能をすべて有効にする必要はありません。

よく調整するパラメーター​

変えたい印象最初に探す項目確認すること
全体の色味ベースマップ HSVG色相・彩度・明度・ガンマを少しずつ調整し、肌と衣装の色を確認
暗い場所の明るさベースカラー保持 · 最終最小輝度暗い光で色が埋もれないか、影が薄すぎないか確認
影の境界1次シャドウの柔らかさ下げるとくっきり、上げると柔らかく変化
影の色シャドウカラー肌・髪・衣装を個別に調整
外側の線アウトライン幅 · アウトライン色近距離と全身表示で線の太さを確認
輪郭の光リムライト · 2Dリムシルエットの強調量を確認。2Dリムはカメラ深度も必要
表面の光沢Matcap · トゥーンスペキュラー髪・衣装のハイライトが強すぎないか確認
自発光部分エミッション必要な範囲に適用し、色と強さを確認

値が反応しない場合は全体のエフェクト → 対象モジュール → 必要条件の順に確認します。2Dリム・2Dシャドウなどには深度ベースの効果に記載した準備が必要です。

7. 編集後は通常どおりアップロード・ビルド​

マテリアルの編集が終わったら、VRC SDK でアバターをアップロード、または WARUDO のモッドをビルドします。その工程で自動最適化ベイクが実行されます。最初から手動 Bake を別途押す手順ではありません。アバタールートの MingToon Manager を残し、ビルド／アップロード時の自動最適化状態を確認してください。

詳しい条件はビルド時の自動最適化と対象プラットフォームのガイドを確認してください。ベータ版の検証範囲は現在の制限に記載しています。
