リム

シルエットを立たせ、キャラクターを背景から切り離す項目です。重ねてオンにすると、すぐに過剰になります。

このページは値を探すための表です。オンにする順序が必要な場合は リムガイド を見てください。

見出しと目次は、インスペクターのセクション名と表示順をそのまま踏襲しています。

マップとマスクのスロット内の項目は、すべてのスロットで共通です。 チャンネル・リマップ・フェザー・マスクUVは テクスチャスロット共通UI に一度だけ記載しています。

リムシェード​

インスペクターのラベルプロパティ形式範囲既定値役割
リムシェードを使用_RimShadeEnabledオン/オフ-オフシルエット内側の陰影帯を形状影マスクへ加えます
リムシェードカラー_RimShadeColor色-白リムシェードの領域だけに塗る色です
リムシェード色合成モード_RimShadeColorBlendMode選択Normal / Multiply / Add / Screen / Color / OverlayMultiply-
ブレンド不透明度_RimShadeColorBlendOpacity実数0 ~ 10リムシェードの色をどれだけ適用するかです
明るさ_RimShadeColorBrightness実数0 ~ 10.8リムシェードの色の明るさです
リム影マスクを使用_RimShadeMaskEnabledオン/オフ-オフ-
影への寄与強度_RimShadeIntensity実数0 ~ 11シルエット内側の陰影帯の強さで、0ではリムシェードの計算自体を飛ばすため幅と柔らかさを変えても変化しません
幅_RimShadeWidth実数0 ~ 10.20では領域なし、1では領域全体を使います
反転_RimShadeAreaInvertオン/オフ-オフ-
柔らかさ_RimShadeSoftness実数0 ~ 10.40は硬い境界、1は選択した幅の内側の柔らかなグラデーションです
ノーマルマップ影響_RimShadeNormalInfluence実数0 ~ 110 = メッシュ法線、1 = 積層ノーマルマップを完全適用

影の中の反射 (影内部リフレクション)​

インスペクターのラベルプロパティ形式範囲既定値役割
影反射を使用_ShadowReflectionEnabledオン/オフ-オン照明・キャスト・デプスシャドウで暗くなった領域の中だけに反射帯を加えます

影反射基本​

インスペクターのラベルプロパティ形式範囲既定値役割
影反射色_ShadowReflectionColor色-1.5, 1.5, 1.5, 1HDR影内部反射の色で、既定値は(3.81, 3.81, 3.81)です
影内部反射の合成モード_ShadowReflectionBlendMode選択Normal / Multiply / Add / Screen / Color / OverlayAddNormal・Multiply・Add・Screen・Color・Overlayから影内部反射の合成方法を選びます
ブレンド不透明度_ShadowReflectionBlendOpacity実数0 ~ 11影の内部反射レイヤーが結果に混ざる割合です
色純度_ShadowReflectionColorPurity実数0 ~ 101ベース色と影内反射ティントを合成した後の彩度です
ベースカラー影響_ShadowReflectionBaseColorInfluence実数0 ~ 10.70では反射色のみ、1ではベースマップ色を完全に掛けます
強度_ShadowReflectionIntensity実数0 ~ 200.5反射の明るさ倍率です

マスク​

インスペクターのラベルプロパティ形式範囲既定値役割
マスクを使用_ShadowReflectionMaskEnabledオン/オフ-オフオフではマスクテクスチャ取得を省略します
影反射マスク_ShadowReflectionMaskテクスチャ-なし-

形状と範囲​

インスペクターのラベルプロパティ形式範囲既定値役割
幅_ShadowReflectionWidth実数0 ~ 10.80では領域なし、1では領域全体を使います
反転_ShadowReflectionAreaInvertオン/オフ-オフ-
影しきい値_ShadowReflectionShadowThreshold実数0 ~ 10.8このしきい値を超える影領域で反射が現れ、影の柔らかさで境界をなじませます
柔らかさ_ShadowReflectionSoftness実数0 ~ 10.80は硬い境界、1は選択した幅の内側の柔らかなグラデーションです
影の柔らかさ_ShadowReflectionShadowSoftness実数0.001 ~ 11明部と影内部反射の間の遷移幅です

照明への反応​

インスペクターのラベルプロパティ形式範囲既定値役割
光源側の強調_ShadowReflectionLightDirectionInfluence実数0 ~ 110は反射輝度を全周で均一にし、1はメイン・追加ライトが当たる側だけを残します
ノーマルマップ影響_ShadowReflectionNormalInfluence実数0 ~ 110ではメッシュノーマル、1では積み重ねたノーマルマップを反射形状に使います
シーン照明影響_ShadowReflectionSceneLightInfluence実数0 ~ 110ではシーン輝度から独立し、1ではシーン照明に合わせて暗くなります
環境光色の影響_ShadowReflectionAmbientInfluence実数0 ~ 110はライトプローブと環境SHの色を無視し、1は環境色を影内部の反射に完全に加えます
追加ライトの影響_ShadowReflectionAdditionalLightInfluence実数0 ~ 10.50は追加のポイント・スポットライトを無視し、1は各ライトの方向、色、影、減衰を反射に完全に反映します
キャストシャドウ内の表示量_ShadowReflectionCastShadowVisibility実数0 ~ 110ではキャストシャドウ内で内部反射を非表示、1では完全に表示します（既定値）
デプスシャドウ内の表示量_ShadowReflectionDepthShadowVisibility実数0 ~ 100ではデプスシャドウ内で内部反射を非表示（既定値）、1では完全に表示します
マスク強度_ShadowReflectionMaskStrength実数0 ~ 11フレネルリムのマスクマップをエッジリム・影内部反射・バックライト・透過が共有します

リムライト​

インスペクターのラベルプロパティ形式範囲既定値役割
フレネルリムを使用_FresnelRimEnabledオン/オフ-オン斜めに見えるシルエットの縁へリム光を合成します

フレネル基本​

インスペクターのラベルプロパティ形式範囲既定値役割
フレネルリム色_FresnelRimColor色-2.67, 2.67, 2.67, 1HDRリム光の色で、既定値は(26.17, 26.17, 26.17)です
フレネルリムの合成モード_FresnelRimBlendMode選択Normal / Multiply / Add / Screen / Color / OverlayOverlayNormal・Multiply・Add・Screen・Color・Overlayからリムの合成方法を選びます
ブレンド不透明度_FresnelRimBlendOpacity実数0 ~ 11フレネルリムが結果に混ざる割合です
色純度_FresnelRimColorPurity実数0 ~ 101ベース色とFresnelリムティントを合成した後の彩度です
ベースカラー影響_FresnelRimBaseColorInfluence実数0 ~ 10.50ではリム色をそのまま使い、1ではベースマップの色を掛けて素材ごとに異なるリム色になります
強度_FresnelRimIntensity実数0 ~ 201フレネルリムの明るさ倍率で、0ではリムの色や幅を変えても画面に現れません

形状と範囲​

インスペクターのラベルプロパティ形式範囲既定値役割
幅_FresnelRimWidth実数0 ~ 10.50では領域なし、1ではフレネル領域全体を使います
反転_FresnelRimAreaInvertオン/オフ-オフ-
柔らかさ_FresnelRimSoftness実数0 ~ 10.20は硬い境界、1は選択した幅全体を使う柔らかなグラデーションです

マスク​

インスペクターのラベルプロパティ形式範囲既定値役割
リムライトマスクを使用_FresnelRimMaskEnabledオン/オフ-オフ-
フレネルリムマスク_FresnelRimMaskテクスチャ-なし-

照明への反応​

インスペクターのラベルプロパティ形式範囲既定値役割
光源側の強調_FresnelRimLightDirectionInfluence実数0 ~ 10.80ではリム輝度を全周で均一にし、1では現在のメイン／Virtual Lightが当たる側だけを残します
視線基準_FresnelRimViewStrength実数0 ~ 10.8リム領域を置く基準軸です
ノーマルマップ影響_FresnelRimNormalInfluence実数0 ~ 110はメッシュ法線だけを使い、1は積層ノーマルマップを完全に使います
シーンライトの影響_FresnelRimSceneLightInfluence実数0 ~ 110ではシーンの明るさに関係なく一定の強さで出て、1では照明が暗くなるほどリムも暗くなります
影内の表示量_FresnelRimShadowVisibility実数0 ~ 100は影でリムを隠し、1は影でも完全に表示します

カメラ安定化​

インスペクターのラベルプロパティ形式範囲既定値役割
距離補正_FresnelRimDistanceCompensation実数0 ~ 110は従来の生の幅を使い、1はカメラ距離が変わってもフレネルリム幅を安定させます
投影 / FOV補正_FresnelRimProjectionCompensation実数0 ~ 110はFOVや正投影で生の幅が変わり、1はFOVや正投影でも幅を安定させます

縁の光 (エッジリム)​

インスペクターのラベルプロパティ形式範囲既定値役割
エッジリムを使用_EdgeRimEnabledオン/オフ-オンライトに追従するエッジリムを描き、メインライトが表面の後ろにあるときは逆光ブーストでシルエットを強めます

エッジリム基本​

インスペクターのラベルプロパティ形式範囲既定値役割
エッジリム色_EdgeRimColor色-2, 2, 2, 1HDRエッジリム色で、既定値は(2, 2, 2)です
エッジリムの合成モード_EdgeRimBlendMode選択Normal / Multiply / Add / Screen / Color / OverlayAddNormal・Multiply・Add・Screen・Color・Overlayからエッジリムの合成方法を選びます
ブレンド不透明度_EdgeRimBlendOpacity実数0 ~ 11エッジリムが最終色へ混ざる割合です
色純度_EdgeRimColorPurity実数0 ~ 101ベース色とエッジリムティントを合成した後の彩度です
マスク強度_EdgeRimMaskStrength実数0 ~ 11フレネルリムのマスクマップをエッジリム・影内部反射・バックライト・透過が共有します
ベースカラー影響_EdgeRimBaseColorInfluence実数0 ~ 10.50はエッジリム色をそのまま使い、1はベースマップ色を完全に掛けます
強度_EdgeRimStrength実数0 ~ 102エッジリムと逆光ブーストの明るさ倍率で、0では色や境界を変えても見えません

形状と範囲​

インスペクターのラベルプロパティ形式範囲既定値役割
輪郭の幅（ピクセル）_EdgeRimWidthPixels実数0 ~ 320既定値は0（オフ）です
範囲_EdgeRimBorder実数0 ~ 10.50では領域なし、1では領域全体を使います
輪郭の固定_EdgeRimContourTightness実数0 ~ 10上の境界は1-|N·V|のしきい値なので
反転_EdgeRimAreaInvertオン/オフ-オフエッジリムの適用領域の内外を入れ替えます
柔らかさ_EdgeRimSoftness実数0 ~ 10.30は硬い境界、1は選択した幅の内側の柔らかなグラデーションです

照明への反応​

インスペクターのラベルプロパティ形式範囲既定値役割
指向性_EdgeRimDirectivity実数0 ~ 10ライト方向への追従度で、0は広く、1は背面条件に敏感になります
光源方向の反応_EdgeRimLightDirectionInfluence実数0 ~ 10リムがどこに乗るかを光源方向が決めます
視線強度_EdgeRimViewStrength実数0 ~ 10視線方向がエッジリム形状へ与える影響で、0は視点変化が少なく、1はカメラで縁の反応が大きく変わります
ノーマル影響度_EdgeRimNormalInfluence実数0 ~ 110はメッシュノーマル、1は積層ノーマルをエッジリム境界に使います
シーンライトの影響_EdgeRimSceneLightInfluence実数0 ~ 11シーン照明の明るさでエッジリムが暗くなる度合いで、0は一定の演出光、1はシーン輝度に従います
影内の表示量_EdgeRimShadowVisibility実数0 ~ 10.5影の中でエッジリムをどれだけ残すかで、0は隠し、1は影に関係なく表示します
逆光の強度ブースト_EdgeRimBacklightIntensityBoost実数0 ~ 40デプスリムの逆光ブーストと同じ位置です
逆光の幅ブースト_EdgeRimBacklightWidthBoost実数0 ~ 40明るさだけを上げると白飛びに見えるため

正面の光 (フロントライト)​

インスペクターのラベルプロパティ形式範囲既定値役割
フロントライトを使用_FrontLightEnabledオン/オフ-オン現在のライトと視線を使って正面向きの面に独立したアクセントを加えます

フロントライト基本​

インスペクターのラベルプロパティ形式範囲既定値役割
フロントライト色_FrontLightColor色-白HDR正面アクセントの色で、既定値は(1, 1, 1)です
フロントライトの合成モード_FrontLightBlendMode選択Normal / Multiply / Add / Screen / Color / OverlayOverlayNormal・Multiply・Add・Screen・Color・Overlayからフロントライトの合成方法を選びます
ブレンド不透明度_FrontLightBlendOpacity実数0 ~ 10.1フロントライトが最終色へ混ざる割合です
色純度_FrontLightColorPurity実数0 ~ 101ベース色とフロントライトティントを合成した後の彩度です
ベースカラー影響_FrontLightBaseColorInfluence実数0 ~ 100はアクセント色をそのまま使い、1はベースマップ色を完全に掛けます
強度_FrontLightStrength実数0 ~ 100.3正面アクセントの明るさ倍率で、0では領域や色の設定も画面に寄与しません
ハイライト中心強度_FrontLightCoreIntensity実数0 ~ 21中心部へ追加する明るさです

形状と範囲​

インスペクターのラベルプロパティ形式範囲既定値役割
領域サイズ_FrontLightSize実数0 ~ 10.50で消え、1で正面全体がアクセントの使用可能領域になります
ハイライト中心サイズ_FrontLightCoreSize実数0 ~ 11外側領域の中で、より明るく強調する中心部の相対サイズです
柔らかさ_FrontLightSoftness実数0 ~ 10.50は硬い外周、1は選択領域の内側全体で滑らかに減衰します

照明への反応​

インスペクターのラベルプロパティ形式範囲既定値役割
光源方向の影響_FrontLightLightDirectionInfluence実数0 ~ 11キャップ軸へ加える主光源方向の重みです
視線方向の影響_FrontLightViewDirectionInfluence実数0 ~ 10キャップ軸へ加えるカメラ視線方向の重みです
ノーマル影響度_FrontLightNormalInfluence実数0 ~ 110はメッシュノーマル、1は積層ノーマルを使います
