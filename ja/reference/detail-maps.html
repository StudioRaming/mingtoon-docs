ディテールマップ

ベースの上に積むレイヤーと質感です。レイヤー系はレイヤー数から上げる必要があります。

このページは値を探すための表です。オンにする順序が必要な場合は ディテールマップガイド を見てください。

見出しと目次は、インスペクターのセクション名と表示順をそのまま踏襲しています。

マップとマスクのスロット内の項目は、すべてのスロットで共通です。 チャンネル・リマップ・フェザー・マスクUVは テクスチャスロット共通UI に一度だけ記載しています。

追加テクスチャ（最大10枚）​

サーフェスレイヤーは最大10枚です。レイヤーを増やすと、下の項目が1枚ごとに同じ形で繰り返されます。

インスペクターのラベル形式範囲既定値役割
サーフェススタックを使用オン/オフ-オフ複数のテクスチャを順番に表面色へ合成します
サーフェススタックレイヤー数整数0 ~ 100数を超えたスロットは評価されず、増やすほどテクスチャ・マスク・合成の負荷が累積します
合成モード選択Normal / Multiply / Add / Screen / Color / OverlayMultiplyこのスタックレイヤーを下の結果とどう混ぜるかです
不透明度実数0 ~ 11このレイヤーの適用量です

ノーマルマップ（最大5枚）​

ノーマルレイヤーは最大5枚です。レイヤーを増やすと、下の項目が1枚ごとに同じ形で繰り返されます。

インスペクターのラベル形式範囲既定値役割
ノーマルレイヤーを使用オン/オフ-オフ積層ノーマルマップを照明・リムなどで使います
ノーマルレイヤー数整数0 ~ 50この数のスロットだけを評価し、数を超えたスロットはサンプリングしません

MatCap（最大5枚）​

マットキャップレイヤーは最大5枚です。レイヤーを増やすと、下の項目が1枚ごとに同じ形で繰り返されます。

インスペクターのラベル形式範囲既定値役割
MatCapレイヤーを使用オン/オフ-オフ視線基準のMatCapレイヤーを表面へ合成します
MatCapレイヤー数整数0 ~ 50数を超えたスロットは評価されず、アクティブなレイヤーごとにマップ・マスク・合成の負荷が増えます
金属領域のみオン/オフ-オフPBRの金属度で全MatCapレイヤーを制限します
反射の彩度を下げる実数0 ~ 10MatCapの色を灰色へ寄せてベース色を保ち、1では色相をほぼすべて除きます
MatCap ノーマルマップテクスチャ-なしMatCap ノーマルマップ
MatCapマップテクスチャ-なし球体に描かれた照明・質感の画像です
合成モード選択Normal / Multiply / Add / Screen / Color / OverlayScreenMatCapを表面色とどう混ぜるかを決めます
強度実数0 ~ 200.74このレイヤーの適用量です
MatCap 発光への寄与実数0 ~ 10このレイヤーが実際にピクセルへ加えた明るさのうち、この割合を照明に依存しない発光としてもう一度加えます
ベースカラー影響実数0 ~ 100ではベースカラーに依存せず、1では暗いベースほど効果が弱くなります
ノーマルマップ影響実数0 ~ 110ではメッシュ法線、1では積層ノーマル結果をすべて反映します
MatCap ノーマルマップ強度実数0 ~ 10このレイヤーがMatCapノーマルマップにどれだけ従うかです
フォーム・AO影内の表示量実数0 ~ 10.280ではフォームシャドウとアンビエントオクルージョン内でMatCapを隠し、1ではそのまま表示します
キャスト・デプス影内の表示量実数0 ~ 10.280ではキャストシャドウとデプスシャドウ内でMatCapを隠し、1ではそのまま表示します
ライト明度連動実数0 ~ 110では現在の明るさを維持し、1ではメインライトが暗いほどMatCapの寄与を下げます
MatCap / メッシュUV投影実数0 ~ 100では視線基準のMatCap投影、1ではメッシュUVに固定されます
MatCap 回転実数-180 ~ 1800MatCapの球をその中心を軸に回します

パックマスクを使用オン/オフ-オフメタリック・オクルージョン・スムースネスを1枚のテクスチャからチャンネル別に読み取ります
PBRパックマスクテクスチャ-なし既定の配置はR=メタリック、G=オクルージョン、A=スムースネスです
メタリックチャンネル選択R / G / B / ARパックマスクのどのチャンネルからメタリックを読むかです
メタリック反転オン/オフ-オフ読み取ったメタリック値を反転します
オクルージョンチャンネル選択R / G / B / AGパックマスクのどのチャンネルから反射オクルージョンを読むかです
オクルージョン反転オン/オフ-オフ読み取った反射オクルージョン値を反転します
反射オクルージョン実数0 ~ 10パックマスクのオクルージョンチャンネルで環境反射を抑える量で、0ではチャンネル・反転設定があっても結果に現れません
スムースネスチャンネル選択R / G / B / AAパックマスクのどのチャンネルからスムースネスを読むかです
ラフネス / 反転オン/オフ-オフスムースネスではなくラフネスのマップを入れた場合にオンにします
スペキュラーカラーマップ (RGB) を使用オン/オフ-オフ反射色をテクスチャで指定します
スペキュラーカラーマップを反転オン/オフ-オフスペキュラーカラーマップのRGBを反転します
直接ハイライト強度実数0 ~ 41光源から直接来るハイライトの強さで、0ではハイライト計算自体を飛ばすためスムースネスを上げても輝きは出ません
影内で表示実数0 ~ 10影の中でPBRハイライトをどれだけ残すかを決め、0では影の中で完全に消え、1では影に関係なくそのまま見えます
ノーマルマップ影響実数0 ~ 110ではメッシュノーマルのみ、1では積み重ねたノーマルマップをそのまま反映します
ハイライトのトゥーン化実数0 ~ 100では物理そのままのGGXローブ、つまり柔らかく滲んだ塊です
ハイライトの境界実数0 ~ 10.5ローブのどこを切ってハイライトの形にするか

キューブマップの照明影響実数0 ~ 11素材キューブマップに解決済みメインライトの色と強度をどれだけ反映するかです
フレネル指数実数1 ~ 85斜めから見たときの明るさの減衰です
