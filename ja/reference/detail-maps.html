ディテールマップ

ベースの上に積むレイヤーと質感です。レイヤー系はレイヤー数から上げる必要があります。

このページは値を探すための表です。オンにする順序が必要な場合は ディテールマップガイド を見てください。

見出しと目次は、インスペクターのセクション名と表示順をそのまま踏襲しています。

マップとマスクのスロット内の項目は、すべてのスロットで共通です。 チャンネル・リマップ・フェザー・マスクUVは テクスチャスロット共通UI に一度だけ記載しています。

ノーマルマップ（最大5枚）​

ノーマルマップの影はこのノーマルマップ設定内で有効にします。突出部を明るくは光基準方式でのみ表示され、レイヤーの2つの影響項目はノーマルマップの影がオンの場合に表示されます。

ノーマルレイヤーは最大5枚です。レイヤーを増やすと、下の項目が1枚ごとに同じ形で繰り返されます。

インスペクターのラベルプロパティ形式範囲既定値役割
ノーマルレイヤーを使用_NormalEnabledオン/オフ-オフ積層ノーマルマップを照明・リムなどで使います
ノーマルレイヤー数_NormalLayerCount整数0 ~ 50この数のスロットだけを評価し、数を超えたスロットはサンプリングしません
ノーマルマップの影を使用_NormalMapShadowEnabledオン/オフ-オフノーマルレイヤーがオンのときだけ動作します
陰影方式_NormalMapShadowMode選択光基準 / 光に無関係（くぼみ）光基準光基準：光に背を向けた側の凹凸を暗くします（既定）
陰影色を指定_NormalMapShadowUseCustomColorオン/オフ-オフオフでは第1シャドウ色（統合シャドウがオンなら統合シャドウの色）に従います
陰影色_NormalMapShadowColor色-0.7, 0.7, 0.75, 1凹凸の陰影に乗算する色です
陰影の強さ_NormalMapShadowStrength実数0 ~ 10.7高いほど陰影が濃くなり、小さな凹凸にも広く適用されます
ぼかし_NormalMapShadowSoftness実数0 ~ 111では凹凸に応じてなめらかに濃くなり、0ではトゥーン調の硬い境界になります
突出部を明るく_NormalMapShadowHighlightオン/オフ-オフ明るい領域と影の中の両方で、光の方へ盛り上がった凹凸を明るい色へ持ち上げます
ノーマルマップ_BumpMapテクスチャ-なし表面の凹凸を擬似的に表現するノーマルマップです
ノーマル強度_BumpScale実数-2 ~ 21ノーマルマップの凹凸の強さです

反射​

インスペクターのラベルプロパティ形式範囲既定値役割
反射を使用_ReflectionEnabledオン/オフ-オフPBR表面とは別に、直接光・追加光・環境反射、反射カラーマップ、キューブマップを有効にします

反射基本​

インスペクターのラベルプロパティ形式範囲既定値役割
直接光スペキュラー_ReflectionApplySpecularオン/オフ-オンメインライトの直接光ハイライトに反射色とマスクを適用し、lilToonのApply Specularに対応します
追加光スペキュラー_ReflectionApplySpecularAdditionalオン/オフ-オンポイント・スポットなど追加光の直接ハイライトに反射を適用し、lilToonのApply Specular…
環境反射_ReflectionApplyEnvironmentオン/オフ-オンリフレクションプローブ・スカイボックス・素材キューブマップの反射を適用し、lilToonのApply…
環境反射のティント_PbrReflectionTint色-白HDR環境反射の色補正で、既定値は(1, 1, 1)です
反射カラーマップを使用_ReflectionColorTexEnabledオン/オフ-オフテクスチャを反射カラーマップとして使用します
反射カラーマップ／マスク_ReflectionColorTexテクスチャ-なし反射色に乗算されるマップです
反射色_ReflectionColor色-白lilToonの反射色と同じく、直接ハイライトと環境反射の両方に適用するHDR色です
反射合成モード_ReflectionBlendMode選択Normal / Multiply / Add / Screen / Color / OverlayAdd反射色を表面へ合成する方式です
キューブマップを使用_ReflectionCubeTexEnabledオン/オフ-オフ素材専用キューブマップを反射に使うかどうかです
反射キューブマップ_ReflectionCubeTexテクスチャ-なしリフレクションプローブが空、またはプローブ上書きがオンの時にサンプルする素材専用キューブマップです
キューブマップのティント_ReflectionCubeColor色-黒素材キューブマップに適用するHDR色です

反射オプション​

インスペクターのラベルプロパティ形式範囲既定値役割
反射のギザつき軽減 (GSAA)_ReflectionGsaaStrength実数0 ~ 10法線がピクセルごとにどれだけ速く変わるかを測り、その分だけ環境反射のスムースネスを下げます

トゥーンスペキュラー基本​

グリッター​

インスペクターのラベルプロパティ形式範囲既定値役割

グリッター基本​

インスペクターのラベルプロパティ形式範囲既定値役割
カラー_GlitterColor色-白HDRきらめきの色で、既定値は(1, 1, 1)です
形マップを使用_GlitterShapeEnabledオン/オフ-オフオンにすると粒子ひとつひとつの形をテクスチャに置き換えます(星、ハートなど)
形マップ_GlitterMapテクスチャ-なし粒子ひとつの形です
形チャンネル_GlitterShapeChannel選択R / G / B / A / LumaA既定値はAです
ベースカラー影響_GlitterBaseColorInfluence実数0 ~ 100はグリッター色をそのまま使い、1はベースマップ色を掛けます
強度_GlitterStrength実数0 ~ 168明るさ倍率で、0ではパターンを計算しても見えません

形状と範囲​

インスペクターのラベルプロパティ形式範囲既定値役割
スケール_GlitterDensity実数1 ~ 512379粒子セルの細かさを決めます
粒子サイズ_GlitterSize実数0 ~ 10.39粒子が画面で占める大きさで、高いと大きく、低いと小さな点になります
サイズランダム化_GlitterScaleRandomize実数0 ~ 11粒子サイズをランダム化し、0は均一、1は自然ですが不規則になります
粒子コントラスト_GlitterContrast実数0.25 ~ 12850粒子内のコントラストで、高いほど鮮明ですが段差やちらつきが増えることがあります
ポストコントラスト_GlitterPostContrast実数0.1 ~ 81粒子パターン後の全体コントラストで、1が中立、高いほど暗い点が消えやすくなります
速度_GlitterSpeed実数0 ~ 40.3視点依存のきらめきを動かします
回転ランダム_GlitterShapeRotation実数0 ~ 11粒子ごとに形をどれだけ違う角度に向けるかを決めます

視線パララックス_GlitterViewParallax実数0 ~ 10.52視点移動で粒子が滑る量で、高いほど奥行きが出ますがちらつくことがあります

光源方向の影響_GlitterLightDirection実数0 ~ 11きらめきが光源方向に従う強さで、低いと視点反応が中心になります
シーンライトの影響_GlitterSceneLightInfluence実数0 ~ 11シーン照明の明るさできらめきが暗くなる度合いです
