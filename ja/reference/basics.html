基本設定

マテリアルを作ったとき、最初に触る項目です。ベースカラー、サーフェスモード、透明度、ステンシルを扱います。

このページは値を探すための表です。オンにする順序が必要な場合は 基本設定ガイド を見てください。

見出しと目次は、インスペクターのセクション名と表示順をそのまま踏襲しています。

マップとマスクのスロット内の項目は、すべてのスロットで共通です。 チャンネル・リマップ・フェザー・マスクUVは テクスチャスロット共通UI に一度だけ記載しています。

通常パス・通過時選択Keep / Zero / Replace / IncrementSaturate / DecrementSaturate / Invert / IncrementWrap / DecrementWrapKeepステンシルと深度の両テストを通過したときにバッファへ行う動作です

通常パス・Z失敗時選択Keep / Zero / Replace / IncrementSaturate / DecrementSaturate / Invert / IncrementWrap / DecrementWrapKeepステンシルは通過したが深度テストに失敗したときに行う動作です
ノーマルアウトラインパス・参照値整数0 ~ 2550アウトラインパスが使うステンシル値です
ノーマルアウトラインパス・読み取りマスク整数0 ~ 255255ステンシルバッファを読むときに適用するビットマスクです
