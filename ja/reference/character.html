キャラクター表現

顔とキャラクター全体を対象にする項目です。

このページは値を探すための表です。オンにする順序が必要な場合は キャラクター表現ガイド を見てください。

見出しと目次は、インスペクターのセクション名と表示順をそのまま踏襲しています。

マップとマスクのスロット内の項目は、すべてのスロットで共通です。 チャンネル・リマップ・フェザー・マスクUVは テクスチャスロット共通UI に一度だけ記載しています。

インスペクターのラベル形式範囲既定値役割

顔の境界実数-1 ~ 10顔領域だけに適用されるフォームシャドウの境界です
顔の柔らかさ実数0.001 ~ 20.15顔領域のフォームシャドウ境界のぼかし幅です
頂点ペイントで顔領域を指定オン/オフ-オフ既定はオフです

顔領域マスクテクスチャ-なしベースUVで顔領域を指定します

プロキシ中心実数4つの値0, 0, 0, 1実際の球・円柱・カプセルプロキシメッシュのオブジェクト空間中心です
プロキシ半径実数0.001 ~ 20.12実際のプロキシメッシュの半径です
プロキシ境界のぼかし実数0 ~ 10.15選択したプロキシボリュームの境界で顔領域が半径の何割にわたって薄れるかを決めます
プロキシ軸（0 = 自動）実数4つの値0, 1, 0, 0Cylinder・Capsuleの長手方向です
プロキシ長さ実数0.001 ~ 40.3Cylinderでは円柱全体の高さです
