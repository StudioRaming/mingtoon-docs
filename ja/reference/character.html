キャラクター表現

顔とキャラクター全体を対象にする項目です。

このページは値を探すための表です。オンにする順序が必要な場合は キャラクター表現ガイド を見てください。

見出しと目次は、インスペクターのセクション名と表示順をそのまま踏襲しています。

マップとマスクのスロット内の項目は、すべてのスロットで共通です。 チャンネル・リマップ・フェザー・マスクUVは テクスチャスロット共通UI に一度だけ記載しています。

フェイス／ヘアシェーディング​

インスペクターのラベルプロパティ形式範囲既定値役割
フェイスシェーディングモジュール_FaceShadingEnabledオン/オフ-オフ顔・ヘアの陰影モジュールを有効にします

顔領域​

インスペクターのラベルプロパティ形式範囲既定値役割
顔領域マスクを使用_FaceAreaMaskEnabledオン/オフ-オフ頭と体が同じマテリアルに混在する場合に、どこまでが顔かをテクスチャで指定します
頂点ペイントで顔領域を指定_FaceAreaVertexMaskEnabledオン/オフ-オフ既定はオフです
プロキシボリュームを使用（領域＋ノーマル）_FaceAreaProxyMaskEnabledオン/オフ-オフ2つを同時に有効にします
顔領域マスク_FaceAreaMaskテクスチャ-なしテクスチャで顔領域を指定します
プロキシ形状_FaceProxyShape選択Sphere / Cylinder / Capsule / PlanePlane平面（3、既定）は解決した顔の前方向1つを顔全体にそのまま使います
プロキシ中心_FaceProxyCenterOS実数4つの値0, 0, 0, 1実際の球・円柱・カプセルプロキシメッシュのオブジェクト空間中心です
プロキシ半径_FaceProxyRadiusOS実数0.001 ~ 20.12実際のプロキシメッシュの半径です
プロキシスケール（メッシュXYZ）_FaceProxyScaleOS実数4つの値1, 1, 1, 0プロキシボリュームをメッシュローカルのX・Y・Z軸ごとに伸縮します
プロキシ軸（0 = 自動）_FaceProxyAxisOS実数4つの値0, 1, 0, 0Cylinder・Capsuleの長手方向です
プロキシ長さ_FaceProxyHeightOS実数0.001 ~ 40.3Cylinderでは円柱全体の高さです
プロキシ境界のぼかし_FaceProxyEdgeSoftness実数0 ~ 10.15選択したプロキシボリュームの境界で顔領域が半径の何割にわたって薄れるかを決めます

SDF陰影​

インスペクターのラベルプロパティ形式範囲既定値役割
顔SDF影を使用_FaceSdfEnabledオン/オフ-オフ既定はオフです
SDFマップ形式_FaceSdfMode選択Packed RGBA / Single Channel Mirrored UPacked RGBAPacked RGBA(0、既定)はR/G=左右、B/A=上下です
単一チャンネルSDFマップ（R/グレースケール、左右ミラー）_FaceSdfMapテクスチャ-なし4方向SDFマップ (RG左右 / BA上下)
SDF座標_FaceMapUvMode実数-1Base UV(0)は元のUV島、Baked Front UV7(1、既定)は連続正面投影です
SDF影の量_FaceSdfShadowAmount実数0 ~ 11SDF暗部の最終強度です
境界オフセット_FaceSdfThresholdOffset実数-1 ~ 10影開始のしきい値を移動します
境界の柔らかさ_FaceSdfSoftness実数0.001 ~ 0.50.04明暗の遷移幅です
左右の影響_FaceSdfHorizontalStrength実数0 ~ 11左右光への反応量です
上下の影響_FaceSdfVerticalStrength実数0 ~ 11上下光への反応量です
SDF適用マスクを使用_FaceSdfMaskEnabledオン/オフ-オフ既定はオフです
SDF適用領域_FaceSdfMaskテクスチャ-なしカードのUVソースで選んだUVで読み、白はSDF適用、黒は元の陰影を維持するため、耳や後頭部は黒く塗ります
SDFマスク強度_FaceSdfMaskStrength実数0 ~ 11マスク制限の強さです
共通横スケール_FaceMapScaleX実数0.1 ~ 40.5中心基準の横スケールです
共通縦スケール_FaceMapScaleY実数0.1 ~ 40.5中心基準の縦スケールです
共通横位置_FaceMapOffsetX実数-1 ~ 10拡縮後のSDFを横移動します
共通縦位置_FaceMapOffsetY実数-1 ~ 10拡縮後のSDFを縦移動します

形状と範囲​

インスペクターのラベルプロパティ形式範囲既定値役割
フォームシャドウ_FormShadowEnabledオン/オフ-オン光の向きに応じて落ちるフォームシャドウ（トゥーン陰影）のオン/オフです
顔の影を除去（SDF含む）_FaceFormShadowLift実数0 ~ 101にすると顔領域のフォームシャドウを完全に消します
顔の境界_FaceFormShadowMidPoint実数-1 ~ 10顔領域だけに適用されるフォームシャドウの境界です
顔の柔らかさ_FaceFormShadowSoftness実数0.001 ~ 20.15顔領域のフォームシャドウ境界のぼかし幅です

影方式​

インスペクターのラベルプロパティ形式範囲既定値役割
顔用デプスシャドウ補正_DepthShadowFaceAssistEnabledオン/オフ-オフ既定はオフです
顔自身のリアルタイム影_FaceShadowCasterEnabledオン/オフ-オンこのマテリアルの顔領域がリアルタイム影を落とすかを決めます
実シャドウキャスターオフセット_FaceShadowCasterOffset実数-0.05 ~ 0.050顔領域のシャドウキャスターを法線方向へ押し出し、リアルタイム影が顔自身に重なる度合いを調整します
深度オフ時はキャスターオフセット解除_FaceDepthOffProjectedShadowEnabledオン/オフ-オフオンにすると、深度エフェクトのマスターがオフの間や「深度の可用性」がForce…
顔の固定方向_DepthShadowFaceFixedDirection実数0 ~ 100は実ライト方向、1は顔のローカル上方向を使います

顔の整列・深度​

インスペクターのラベルプロパティ形式範囲既定値役割
顔の正面軸（通常 0, 0, 1）_FaceForwardDirectionOS実数4つの値0, 0, 1, 0顔が向いている方向をオブジェクト座標で指定します
プロキシノーマル強度_FaceNormalFlattenAmount実数0 ~ 10元のメッシュノーマルとプロキシノーマルを元のマテリアル上で一度だけリアルタイムに混ぜます
影のノーマルマップ影響_FaceShadowNormalMapInfluence実数0 ~ 10カスタム顔ノーマルが有効な領域の形状シャドウ境界へ、ノーマルマップをどれだけ戻すかを決めます
顔の受信面自動補正_FaceDepthAutoCorrectionオン/オフ-オン既定はオンです
顔の受信面オフセット_FaceDepthReceiverOffset実数0 ~ 0.20.002自動補正がオンの間、顔が影を受ける面をカメラからこの分だけ後ろへ押します
カメラ深度から顔を除外（実験的）_FaceDepthSourceExcludedオン/オフ-オフ既定はオフです
SDFテスト表示_FaceSdfTestModeオン/オフ-オフ既定はオフです
テスト表示チャンネル_FaceSdfTestChannel選択R / G / B / A / MaximumMaximumR=左、G=右、B=上、A=下です
受信面プッシュバック_DepthShadowReceiverPushback実数0 ~ 0.10デプスシャドウがオンのとき、このマテリアルのカメラ深度記録とデプス影の判定用受信面を一緒に奥へ押します
