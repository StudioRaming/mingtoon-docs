Using the Inspector

Select a MingToon material to open its inspector. Set the look in Simple, then refine features in Full.

Try it in 30 seconds​

  1. Select one converted material.
  2. Switch to Full.
  3. Type Blur into Search features and select 1st Shadow Blur from the suggestions.
  4. Check that Form Shadow is enabled, then lower the value to 0.05.

Typing and selecting a suggestion are separate actions. Selecting a suggestion switches to Full, opens its group and module, and clears the favorites and changed-value filters.

The three view modes​

ModePurpose
SimpleSet the look using key controls for look, basic settings, color, shadow, emission, material, rim, face and screen effects
FullAdjust every module and advanced render state
BulkWrite shared values to several materials found by scope and filters

Simple and Full edit the same material values. Switching modes preserves them. Search accepts Korean, English and Japanese labels and supported lilToon names.

The navigation bar and groups​

The header contains mode and collapse/expand controls, search and filters with a load estimate, and group jump tabs. Full places these nine groups below Quick Settings, in this order. A jump tab opens and moves to its group.

Enable and expand are separate​

A module checkbox enables or disables its effect; its arrow and name expand or collapse its settings. A collapsed row shows summary chips, a dot for values differing from defaults, and a ⋯ menu. Disabling preserves saved settings. Collapsing alone does not disable an effect. Basic modules without a checkbox contain shared material settings.

Turning Depth Effects off dims the Depth Rim Light, Depth Shadow, SSAO, Inner Outline and Skin Translucency rows below it. Check the parent switch and depth availability.

All Effects and Render Disabled​

All Effects and Render Disabled are in Advanced Rendering. All Effects off skips effect processing while keeping the base surface, alpha and silhouette handling. Render Disabled separately prevents this material from being displayed. The top warning reports either state when it prevents the intended look.

Quick Settings​

The first card in Full collects common look, color, shadow and outline values. It edits the same values as the original modules, so both update together. A material opened for the first time starts with Quick Settings open and the other groups collapsed.

The load display estimates cost from material settings. It is not GPU utilization or a measured FPS value.

Search, filters and presets​

Use Favorites Only and Changed Values Only to narrow the visible items. Changed values are compared with current factory defaults, including changes made by presets. Use the row's ⋯ menu for favorites, reset and related actions. Select a look preset and press Apply; save it through preset management. Changing the display language does not change material values.

Several materials at once​

Unity shows mixed values when selected materials differ. Editing a mixed value writes the same value to every selected material. Choose targets in the Manager's material-selection row, then open the material inspector. See Editing Multiple Materials for scope-based editing.

The material menu supports copying and pasting all data, values, textures, keywords or render queue. Pasting applies to the selected targets and can be undone.

Face proxies only within the same character

Select only one avatar's Face materials when editing a face proxy in the Scene view. Editing cannot start if materials from different avatars are mixed.

Common problems​

If a value does not change the look, check All Effects, Render Disabled, the module checkbox and its prerequisites. If a row is missing, check search and both filters, then switch to Full. Normal Map Shadow is inside normal-map settings; see Detail Maps.
