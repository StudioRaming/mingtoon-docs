Detail Maps

These are the layers and material qualities stacked on top of the base. For the layer families you have to raise the layer count first.

This page is a table for looking up values. If you want the order to turn things on in, see the Detail Maps guide.

The headings and order follow the inspector's section names and display order exactly.

The fields inside map and mask slots are the same in every slot.

Channel, remap, feather and mask UV are written once in the Shared Texture Slot UI.

Mask Packs​

The 27 layer, depth and rim mask slots are stored in up to nine RGB packs, without an alpha channel. Editable and baked shaders read the same packs; packs with no active input are not generated. Packs are saved as PNG and imported as BC7 with mipmaps.
