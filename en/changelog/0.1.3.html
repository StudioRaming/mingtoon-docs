0.1.3

Closed beta

Hotfix 1 · 2026-08-03​

  • Importing MingToon reimporting every texture in the project — the face SDF texture importer was a global AssetPostprocessor, which put every texture in the project on MingToon's dependency list. On a texture-heavy project the first import took hours.
  • The face SDF and halftone pattern textures blocking a VRChat upload — they shipped with Streaming Mip Maps off.

Check before you upgrade​

Do not delete MingToon components by hand

VRChat strips them on upload by itself. Deleting them manually also drops the cached renderer list, so the upload optimisation loses its scope and unoptimised materials ship as-is. → VRChat

Auto face detection no longer guesses from names

Auto now reads only the face flag the source material carries. Converting from Standard or URP Lit leaves every slot as Regular, so you have to mark the face slots as Face yourself. → MingToon Manager

The manager's step numbers changed

The order is now 1 · Convert → 2 · Setup → 3 · Advanced. Older notes will not match.

caution
Face Border no longer accepts negative values

Below 0 the face shadow terminator sat where the head's normals barely change, and the band followed triangle edges as a staircase. Materials on the old −0.3 default now read as 0, so faces pick up slightly more shadow. Re-tune the value on your face materials. → Docs

Unified Shadow now merges the cast shadow into one colour, always

A projected shadow crossing into the form shadow no longer deepens where they overlap. If you want that overlap back, raise 2D Shadow Overlap Depth. → Docs

New​

  • Depth Translucency — thin parts such as hair tips and hems now look like they are holding light. It measures how far light travelled through the character by reading depth twice along the light direction, so it works on its own regardless of Master Width. → Docs
  • Upload readiness check — walks the hierarchy and the manifest and reports anything blocking an upload as a diagnostic code. → Docs
  • Status panel — material composition, shading state, face-slot sync and optimisation scope are always visible at the top of the manager.
  • VRChat and Quest pre-checks — counts missing standard properties and disallowed components, and reports what a Quest variant would lose.
  • Skin role — a slot role that receives the bare-skin look values. Assign Skin Renderer Directly sets it in one go.
  • Tab presets — save and apply presets per section, with an option to include textures.
  • WARUDO Runtime Root — a self-contained runtime component that supplies camera depth and head direction to the shader in a Warudo mod. → Warudo
  • Master Adjust — the first section in the inspector. An Intensity and a Tint over each of Everything That Adds Light, Every Shadow and Final Output, so a character can be retuned for a new scene in one place.
  • Bound Added Light Too — applies the brightness ceiling after backlight, front light, fresnel rim, shadow interior reflection, 2D depth rim, depth translucency and glitter have all been added. The existing Final Lighting Maximum Multiplier runs before them, so raising a rim blew straight past it. Off by default. → Docs
  • 2D Shadow Overlap Depth — how much the 2D shadow deepens a form shadow it lands inside, in Unified Shadow mode. Zero is a single flat colour. → Docs
  • Paint the face area with vertex colours — mark the face region without a mask texture. It uses a different channel from the outline, so both can be painted on one mesh.
  • Shader variant prewarm — runs automatically at the end of a conversion, and on demand from Tools > Studio Raming > MingToon > Prewarm Shader Variants.

Changed​

  • Conversion is no longer lilToon-only — Standard, URP Lit and others convert too. In that case base colour, textures, normal, emission, occlusion and render state carry over, and everything else takes MingToon defaults.
  • Excluded material classes — particle/VFX, refraction/gem, fur/shell, audio-reactive, flipbook/scroll, and outline-only or auxiliary passes cannot be carried over, so their originals are left untouched. → Docs
  • Hull normal source now defaults to UV8TS — baking UV8 is the whole job; there is nothing to switch on the material afterwards. → Docs
  • Character Root is now called MingToon Manager.
  • lilToon Quick Convert is now called Shader Conversion.
  • What a preset carries — values and colours only. Textures, vectors, render queue, instancing and the RenderType tag are left alone.
  • The Face SDF Baker ships as a separate editor package. Without it installed, that button stays closed.
  • Normal strength accepts negative values. The relief inverts.
  • Enable Face SDF Shadow is now the master toggle at the top of the face SDF section. Everything else unfolds under it.
  • Normal map tiling now sits directly under its slot instead of inside a fold, where it was easy to mistake for the mask's tiling outside it. The two are deliberately kept separate.
  • Face Shading does not apply in this build. It is still in development, so the section is hidden and any material or preset carrying it enabled is read back as off. Face conversion and every other face feature work as normal.

Improved​

  • UV channel occupancy — shows whether UV4 · UV7 · UV8 are free or in use, and warns that UV7 is shared between the face normal bake and the face SDF projection, so only one can own it.
  • Conversion pair audit — verifies converted materials against their sources. It is slow, so it runs only when you press the button.
  • Face module sync — warns when a face slot's keyword disagrees with its material value and fixes them in one action. Baking in that state drops face shading.
  • Optimisation scope warning — tells you how many renderers would upload unoptimised when the cache is stale.
  • Editor runtime preview — preview look profiles and runtime face direction in the editor. None of it ships to a VRChat upload.
  • The material cost estimate moved next to the search box. One line, expandable for the breakdown.
  • Vertex painting — live overlay, X-axis symmetry, brush strength and opacity, and a movable window. It no longer stalls on every stroke.
  • Conversion tab — directly assigned renderers now show up in the slot summary, and skin is counted separately from face and regular. You can choose whether shadow colour and fresnel are overwritten, and re-apply a look preset to an already converted character.
  • Per-section and look preset lists are laid out by category instead of hidden behind a dropdown.

Fixed​

  • A second line drawn beside the face form shadow's edge — the border was built on the body terminator rather than the face one.
  • Projected shadows falling on slots marked as face.
  • Cast and 2D shadows not converging to one colour in Unified Shadow — the outline hull and the additional-light path never reached the brightness ceiling, so only those kept burning.
  • The master not reaching the fallback rim, the second of the two depth rims, which changed the result on cameras with no depth buffer.
  • The Scene view freezing for minutes — the post-processing bridge was rescanning every loaded object on each Scene view event.
  • Baked textures blocking a VRChat upload — the mask pack, surface flatten, and face SDF outputs were written with Streaming Mip Maps off.

Docs​

  • The documentation site is now available in 한국어 · English · 日本語. Switch at the top right.
  • New Internals section — shader pass structure, the performance cost formula, what the bake removes, how to read a conversion report, and the VRChat compatibility rules. → Docs
  • The control reference is generated from the MingToon source, so it always matches what the inspector displays.
  • Added full-text search.
