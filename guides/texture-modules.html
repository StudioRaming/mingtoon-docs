텍스처 슬롯 공통 UI

이 문서를 읽으면 MingToon의 모든 텍스처 슬롯에 공통으로 붙는 조정 항목을 한 번에 이해할 수 있습니다.

베이스 맵, 노멀, 마스크, 맷캡, 이미션, 레이어 — 이름은 달라도 아래 구조가 동일합니다. 한 번만 익히면 나머지 슬롯은 자동으로 읽힙니다.

텍스처 슬롯
├─ 텍스처 세부 설정      ← 채널 소스 · 반전 · HSVG · 틴트 순서
└─ 마스크 세부 설정      ← 마스크 맵 · 채널 · 반전 · 리맵 · 페더 · 그라데이션

텍스처 세부 설정​

채널 소스​

이 텍스처에서 어느 채널을 읽을지 정합니다.

값읽는 것
RGBA 전체컬러 그대로
R / G / B / A해당 채널 하나

여러 마스크를 한 장에 패킹했을 때 씁니다. 마스크 슬롯 쪽에는 RGBA 전체 (밝기) 옵션이 추가로 있어 RGB의 밝기를 씁니다.

소스 색 반전​

읽어 온 값의 흑백을 뒤집습니다. 지워야 할 곳이 흰색으로 그려진 마스크를 그대로 쓸 때 씁니다.

HSVG​

항목기본값
색조0
채도1
명도1
감마1

기본값에서 벗어난 값만 결과에 영향을 줍니다. 인스펙터가 각 항목의 기본값을 툴팁으로 알려 주고, 기본값은 색조 0, 채도 1, 명도 1, 감마 1입니다. 안내를 함께 보여 줍니다.

텍스처를 다시 굽는 대신

색을 조금 바꾸고 싶을 때는 텍스처를 편집하는 것보다 HSVG가 훨씬 빠르고, 원본과 비교하기도 쉽습니다.

HSVG 이후에 틴트 적용​

틴트 색을 HSVG 보정 전에 곱할지 후에 곱할지 정합니다. 같은 값이라도 순서에 따라 결과가 달라집니다.

마스크 세부 설정​

적용 범위를 제한합니다. 대부분의 모듈이 자기 전용 마스크를 가질 수 있습니다.

항목하는 일
마스크 맵흑백 이미지
마스크 채널R / G / B / A / RGBA 전체(밝기)
반전흑백 뒤집기
리맵 시작 · 리맵 끝마스크의 회색 구간을 다시 펼침
경계 부드러움경계 번짐 폭

리맵을 쓰는 법​

마스크가 흐릿하게 그려졌거나 너무 넓게 잡힐 때 씁니다.

  • 리맵 시작을 올리면 → 적용 범위가 좁아집니다
  • 리맵 끝을 낮추면 → 경계가 급격해집니다
  • 둘을 같게 두면 경계가 완전히 딱딱해집니다 (이진 마스크)

그라데이션​

마스크 이미지 없이 방향성 있는 페이드를 만듭니다.

항목하는 일
그라데이션 모드선형 / 방사형 등
각도방향
시작 · 끝페이드 구간
중심 (UV)방사형일 때 기준점

레이어 슬롯​

텍스처 레이어 · 노멀 레이어 · 맷캡 레이어에 공통입니다.

레이어 수​

표시의미
0 (사용 안 함)이 모듈이 아무것도 계산하지 않음
1 레이어
N 레이어
여기서 정한 개수보다 뒤에 있는 슬롯은 계산되지 않습니다

텍스처를 넣었는데 아무것도 안 보이면 거의 항상 레이어 수가 모자란 것입니다. 인스펙터 툴팁도 같은 말을 합니다.

순서 바꾸기​

각 레이어에 위로 / 아래로 버튼이 있습니다.

합성 순서가 바뀌면 결과가 달라집니다

단순한 정리 기능이 아닙니다. Multiply 위에 Normal을 올리는 것과 그 반대는 완전히 다른 그림입니다.

값 복사 / 붙여넣기​

항목을 우클릭하면 나옵니다.

메뉴범위
값 복사 / 값 붙여넣기항목 하나
레이어 값 복사 / 레이어 값 붙여넣기레이어 하나 전체
탭 값 복사 / 탭 값 붙여넣기섹션 전체
프로퍼티 이름 복사셰이더 프로퍼티 이름 (애니메이션 만들 때)

붙여넣기 결과가 로그로 나옵니다: 값 붙여넣기: 8개 적용, 2개 건너뜀.

건너뛰는 경우
  • 레이어 — 같은 모듈 종류의 레이어를 먼저 복사해 주세요. 맷캡 레이어를 노멀 레이어에 붙여넣을 수 없습니다.
  • 값 타입 — 붙여넣을 값의 타입이 호환되지 않습니다. 색을 슬라이더에 붙여넣을 수 없습니다.
  • 대상 없음 — 호환되는 대상 프로퍼티가 없어 붙여넣기를 건너뛰었습니다.

모든 붙여넣기는 하나의 Undo 단위입니다.
