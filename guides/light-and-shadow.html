조명과 그림자

이 문서를 읽으면 세 종류의 그림자를 구분하고, 어떤 순서로 잡아야 서로 싸우지 않는지 알게 됩니다.

인스펙터의 조명과 그림자 그룹 — 라이팅 · 그림자 색상 · 형태 그림자 · 그림자 투영 을 다룹니다. 전체 항목 목록은 조명과 그림자 레퍼런스에 있습니다.

먼저: 그림자가 세 종류입니다​

MingToon에서 "그림자"라고 부르는 것은 서로 다른 세 가지입니다. 이걸 구분하지 못하면 엉뚱한 슬라이더를 계속 만지게 됩니다.

종류인스펙터 섹션무엇이 만드나
형태 그림자형태 그림자표면 노멀과 광원 방향. 캐릭터 자신의 굴곡으로 생기는 명암. 툰 룩의 본체
캐스트 그림자그림자 투영Unity의 실시간 섀도우 맵. 다른 물체와 자기 자신이 드리우는 그림자
2D 그림자2D 그림자 (깊이 기반 효과)카메라 깊이 텍스처. 화면 공간에서 계산

작업 순서​

  1. 형태 그림자 경계 → 2. 그림자 색상 → 3. 2차 단계 → 4. 그림자 투영 → 5. 얼굴 예외 → 6. 경계 장식

겹친 그림자 확인하기​

먼저 형태 그림자와 캐스트 그림자를 맞춘 뒤, 2D 그림자와 SSAO를 하나씩 켜서 겹치는 부분을 확인하세요. 마지막으로 통합 그림자 색상과 경계 표현을 조정하면 각 효과의 영향을 구분하기 쉽습니다. 이 순서는 룩을 조정하는 순서이며, 셰이더 내부의 계산 순서를 나열한 것은 아닙니다. 2D 그림자와 SSAO에는 카메라 깊이가 필요합니다.

문제를 분리할 때는 추가한 효과를 하나씩 잠시 끄고 비교하세요. 접촉부가 과하게 어두우면 SSAO를 끈 결과와 비교하고, 투영된 실루엣을 따라 띠가 보이면 캐스트 그림자와 2D 그림자를 각각 꺼서 어느 효과에서 생기는지 확인하세요.

1. 형태 그림자 경계 — 가장 먼저​

1차 그림자 번짐이 MingToon에서 가장 자주 조정하는 값입니다. 여기서 룩의 성격이 정해집니다.

값결과
0.001 근처셀 애니메이션처럼 딱 떨어지는 경계
0.05 ~ 0.15살짝 부드러운 일러스트 느낌
0.3 이상부드러운 그라데이션

먼저 이 값 하나만 움직여 원하는 성격을 정한 다음 나머지로 넘어가세요. 빠른 설정의 1차 그림자 부드러움이 같은 값입니다.

2. 그림자 색상​

1차 그림자 밝기를 낮추면 어두워집니다. 다만:

주의
그림자 색상 섹션이 꺼져 있으면

1차 그림자 밝기가 반영되지 않습니다. 캐스트 그림자도 마찬가지로, 이 섹션이 꺼져 있으면 단순히 어두워지기만 하고 캐스트 그림자 밝기가 무시됩니다.

통합 그림자 — 겹칠 때 새까매지는 문제​

형태·캐스트·2D 그림자가 같은 자리에 겹치면 세 번 어두워져서 검게 뭉갭니다. 그림자 색상 안의 통합 그림자 사용 을 켜면 세 가지가 같은 색상과 톤으로 수렴해 이 문제가 없어집니다.

통합 모드에서 유지되는 것 / 무시되는 것
  • 유지 — 그림자 경계의 형태 설정, 그림자 패턴(스크린톤)
  • 무시 — 개별 그림자의 색·블렌드·밝기 컨트롤 (값 자체는 보존되므로 끄면 그대로 돌아옵니다)

통합 그림자 색상의 알파가 적용량입니다. 알파가 0이면 어떤 색을 골라도 그림자가 베이스 색 그대로 남습니다.

끌 때 룩이 한 번에 바뀔 수 있습니다

통합 그림자를 끄면 각 층에 저장돼 있던 색이 그대로 돌아옵니다. 통합으로 작업하는 동안 개별 색을 만진 적이 없다면, 끄는 순간 예전 값이 한꺼번에 나타납니다.

부위마다 다른 그림자 색 — 그림자 컬러맵​

통합 그림자는 색이 하나입니다. 머리카락은 붉게, 피부는 노랗게처럼 부위마다 다른 그림자 색이 필요하면 그림자 컬러맵을 켜세요. 통합 그림자 한 색을 UV 맵으로 분포시킵니다.

  • 흰색이 기준값입니다. 흰 부분은 통합 그림자 색상 그대로 나오고, 칠한 부분만 그 색으로 곱해집니다. 방금 켠 상태에서는 결과가 바뀌지 않습니다.
  • 컬러맵 적용량이 0이면 통합 색상 하나만, 1이면 텍스처 색을 그대로 곱합니다. 텍스처 HSVG로 색조·채도·명도·감마를 따로 조정할 수 있습니다.
통합 그림자 전용입니다

통합 그림자가 꺼져 있으면 셰이더가 이 텍스처를 아예 읽지 않습니다. 레이어별 그림자 모드는 층마다 색을 이미 가지고 있어 분포시킬 대상이 없기 때문이며, 샘플 비용도 들지 않습니다.

하이라이트 마스크가 남아 있다면

이 맵과 함께 매트캡이나 스페큘러 마스크로도 쓰는 것을 권합니다. 색 분포와 광택을 나눠서 잡을 수 있습니다.

3. 2차 그림자 — 3단 셀 음영​

2차 그림자 사용을 켜면 가장 어두운 쪽에 단계가 하나 더 생깁니다.

  • 2차 그림자 밝기는 1차보다 낮게 두어야 단계가 구분되어 보입니다.
  • 2차 그림자 번짐을 1차보다 좁게 두면 안쪽 단계가 또렷해집니다.

4. 그림자 투영 (캐스트 섀도우)​

실시간 그림자는 툰 룩에서 가장 자주 말썽을 부리는 부분입니다. 캐스트 섀도우 수신 그룹부터 봅니다.

수신 강도가 0이면 캐스트 그림자가 완전히 사라지고, 아래의 밝기·혼합·간접광 보정도 결과에 나타나지 않습니다.

그림자가 툰답지 않을 때​

PBR / 툰 혼합을 1로 올리면 Unity 기본의 부드러운 감쇠 대신 툰 밴드로 딱 잘립니다. 밴드 폭은 캐스트 툰 밴드 부드러움이 정합니다.

얼룩덜룩한 그림자​

옷 주름이나 몸에 지저분한 얼룩이 생기면:

  1. 셀프 캐스트 섀도우 억제를 켭니다.
  2. 셀프 섀도우 캐스터 바이어스를 0.01~0.03 사이에서 조정합니다.
바이어스를 너무 올리면

얼룩은 사라지지만 접지 그림자가 뜨고 얇은 부위의 그림자가 끊깁니다. 조금씩 올리세요.

얼굴의 스치는 그림자​

페이스 셰이딩의 그림자 방식에는 몸과 동일한 리얼 그림자, 2D 그림자 (얼굴 보정), Custom이 있습니다. 얼굴 그림자는 아래 순서로 조정하세요.

  1. 페이스 셰이딩의 그림자 방식에서 몸과 동일한 리얼 그림자 또는 2D 그림자 (얼굴 보정)을 선택합니다.
  2. 2D 보조를 쓰지 않을 때만 실제 그림자 캐스터 오프셋을 조정합니다. 보조가 꺼진 상태가 아니면 이 행은 비활성 표시됩니다.
  3. 얼굴 프록시 중심·노멀 정렬·Face SDF 전환을 먼저 맞춥니다.

그림자 경계가 계단처럼 각질 때​

투영 경계 페더 그룹의 투영 페더 사용을 켜고 투영 페더 반경·투영 페더 강도를 조정합니다. 반경 범위는 0~20px입니다. Light3Tap·Standard5Tap·High9Tap은 이 범위 전체에서 선택할 수 있고, 높은 품질일수록 경계 샘플이 늘어납니다. 캐스트 경계 페더 품질도 함께 확인하세요.

페더는 없는 정보를 복구하지 못합니다

낮은 해상도의 shadow map에 애초에 없던 디테일은 부드럽게 만든다고 돌아오지 않습니다. 먼저 광원의 shadow map 해상도와 bias/normal bias, cascade를 확인하세요.

씬마다 그림자가 너무 세거나 약할 때​

캐스트 간접광 보정을 올리면 환경광이 밝은 곳에서 캐스트 그림자가 옅어집니다. 실내·야외를 오가는 아바타에서 조명 차이를 자연스럽게 흡수합니다.

역광에서 몸에 캐릭터 모양 그림자가 겹칠 때​

역광 실루엣 억제를 켜면 광원을 등진 면에는 캐스트 그림자를 그리지 않습니다.

2D 그림자와 색이 따로 놀 때​

2D 그림자와 통합을 켜면 2D 그림자가 캐스트 그림자와 같은 색을 쓰고, 겹치는 자리에서 두 번 어두워지는 것도 막힙니다.

5. 얼굴은 따로 잡습니다​

→ 캐릭터 표현

6. 경계 장식 — 마지막에​

명암 경계에 색 띠를 얹는 연출입니다. 룩이 다 잡힌 뒤에 하세요.

  1. 그림자 경계 사용을 켭니다.
  2. 경계 폭을 올립니다. 0이면 아래 항목이 전부 무시됩니다.
  3. 경계 블러로 밝은 쪽에서 강한 밴드까지 차오르는 길이를 맞춥니다.
  4. 경계 강도로 불투명도를 맞춥니다.

캐스트 경계는 밝은 쪽에서 부드럽게 차오르고 그림자 코어 직전에 가장 강해진 뒤 코어에서 사라집니다. 형태·캐스트·2D 그림자·SSAO 합성이 끝난 뒤 마지막 그림자 레이어로 그려지므로 겹침부에서도 색이 묻히지 않습니다. 통합 그림자 내부를 가로지르는 오클루더 윤곽은 소거되어 빈 테두리처럼 떠다니지 않습니다.

피부와 머리카락이 한 머티리얼에 섞여 있다면

경계 베이스 맵 혼합을 올리세요. 0이면 단색 경계, 1이면 베이스 맵 색과 섞여 부위마다 다른 경계색이 나옵니다.

경계가 안 보이는 조건

그림자 색상 섹션이 켜져 있어야 하고, 형태 그림자나 투영 그림자 중 하나가 실제로 동작해야 합니다. 경계는 모든 그림자 합성의 마지막에 그려집니다.

라이팅 — 어두운 씬에서 검게 뭉칠 때​

VRChat 월드는 조명을 아바타 제작자가 통제할 수 없습니다. 라이팅 섹션의 아래 항목이 방어선입니다.

항목하는 일
베이스 색 유지
(간단 모드: 베이스 색상 보존)		완성된 베이스 색상에 씬 조명의 색조를 얼마나 섞을지. 0이면 조명 색조를 그대로 반영하고, 1이면 베이스 색상을 우선합니다. 조명의 밝기나 에너지 자체는 보존하지 않습니다
씬 조명 색 영향
(간단 모드: 조명 색상 반영)		0이면 어떤 색 조명에서도 흰 조명처럼 보임. 밝기가 아니라 색만 다룹니다
간접광 보정환경광 밝기만큼 형태 그림자를 들어 올림. 형태 그림자가 켜져 있을 때만 계산됩니다
VRC Light VolumesBuilt-in 전용 에디터 확인용 토글. VRChat 아바타 업로드 경로에서는 값과 관계없이 자동으로 켜져 월드의 볼륨을 읽고, 볼륨이 없으면 Unity 프로브로 폴백합니다. URP 재질에는 이 행이 표시되지 않음
최종 최소 밝기아무리 어두워도 이 아래로 내려가지 않음
최종 최대 밝기아무리 밝아도 이 위로 올라가지 않음. 과노출 월드 대비

밝은 면 밝기는 빛을 받는 면 전체의 배수입니다. 1이 기준이고, 올리면 밝은 면이 흰색으로 뭉개지기 쉽습니다.

추가 광원​

포인트/스폿 라이트에 대한 반응은 별도 항목입니다.

  • 추가 광원 받기 · 추가 광원 강도 (간단 모드)
  • 추가 광원 PBR / 툰 혼합 · 추가 광원 툰 경계 · 추가 광원 툰 부드러움 (전체 설정)
  • 추가 광원 최고 밝기 — 베이스 색 배수가 아니라 추가광 결과의 절대 HDR 피크 상한

림·추가광도 상한 적용을 켜면 이 상한값이 포인트·스폿 추가광뿐 아니라 주광(디렉셔널 라이트)을 받는 림·백라이트·프런트라이트·투과광·맷캡·이미시브·글리터의 씬 조명 인텐시티에도 적용됩니다. 1이면 인텐시티 1까지, 3이면 인텐시티 3까지 반영됩니다. 끄면 최종 가산광 상한과 효과 입력 cap이 모두 해제됩니다.

주광과 같은 톤을 유지하려면 추가 광원 쪽 툰 경계도 함께 맞추세요. 절대 상한은 어두운 재질의 스페큘러를 베이스 색에 눌러 없애지 않으면서 여러 라이트의 과노출을 제한합니다.

마스터 조정과 가장자리 림​

마스터 조정은 밝은 면·그림자·최종 출력의 색·밝기·채도를 한곳에서 보정합니다. 가장자리 림 마스터는 2D 림·프레넬 림·백라이트 등 실루엣 계열의 강도, 전용 색상과 HDR 상한을 함께 조정합니다. 개별 림 설정은 림을 참고하세요.

이 그룹의 마스터 강도·색상 행은 Ming Light Controller 저작 UI가 연결된 경우에만 표시됩니다. 성능 거리는 MLC 없이도 표시되는 MingToon 기본 설정입니다.
