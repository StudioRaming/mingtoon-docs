인스펙터 사용법

Manager로 처음 시작하기

컴포넌트 추가 → Face Mesh·Skin Mesh 지정 → 룩 프리셋 선택 → 색감 또는 기존값 선택 → 변환 → 빠른 설정.

Manager는 아바타 루트에 유지합니다. 재질 편집을 마친 뒤 VRC SDK 업로드 또는 WARUDO 모드 빌드를 실행하면 자동 최적화 베이크가 진행됩니다.

이 순서대로 따라 하기. MingToon으로 작업할 아바타 루트에 Manager를 항상 두세요. 의상만 편집할 때도 같습니다. Manager에서 업데이트도 확인합니다. VCC로 설치했다면 MingToon 업데이트는 VCC에서 진행합니다. Manager의 업데이트 안내를 이용할 때도 설치 경로를 먼저 확인하세요. 얼굴·맨살이 없는 의상은 해당 역할을 비워 두고 진행하세요.

Face SDF Studio는 아직 미발매인 제작 도구이며, 아래 온보딩에 필요하지 않습니다.

이 문서를 읽으면 MingToon 인스펙터의 보기 모드, 고정 툴바, 그룹 구조와 다중 재질 편집 규칙을 이해할 수 있습니다.

머티리얼 역할​

Face·Skin·Common 역할은 룩 프리셋이 어느 역할의 값을 적용할지 결정합니다. 일반 빌드에서도 재질 인스펙터 상단의 역할 선택에서 직접 지정할 수 있습니다. 이 행은 간단·전체 설정·일괄 설정 모드에서 공통으로 표시됩니다. 아바타를 처음 변환할 때는 MingToon Manager에서 렌더러·재질 슬롯별로 지정하고, 변환 후에는 재질 인스펙터에서도 수정할 수 있습니다.

여러 재질을 선택했을 때 역할이 다르면 혼합 상태로 표시됩니다. 역할을 바꾸면 선택한 재질 전체에 적용됩니다.

보기 모드​

모드보이는 것언제
간단표면, 조명, 핵심 맵, 그림자·림·얼굴·깊이의 대표 항목변환 직후 룩 잡기, 빠른 수정
전체 설정모든 사용자용 워크플로 그룹과 고급 렌더 상태본격 저작, 문제 해결
일괄 설정선택한 여러 재질에 공통 적용할 안전한 값아바타 전체 통일

간단은 기능 전체를 축약한 화면입니다. 필요한 항목이 없으면 전체 설정으로 바꾸세요. 진단 정보, 내부 기술 이름, 변형 덤프 같은 유지보수 기능은 정식 빌드에 표시되지 않으며 MINGTOON_DEV 개발 빌드에서만 보입니다.

고정 툴바​

인스펙터를 아래로 스크롤해도 상단 툴바가 남습니다.

도구하는 일
검색현재 언어뿐 아니라 한국어·영어·일본어 별칭으로 항목을 찾습니다
즐겨찾기만즐겨찾기한 섹션과 행만 표시합니다. 전체 설정 전용입니다
전부 접기 / 전부 펼치기워크플로 그룹과 섹션을 한 번에 정리합니다
변경값만셰이더 기본값과 다른 행만 남기고 해당 섹션을 자동으로 펼칩니다
복사 / 붙여넣기재질 설정을 다른 재질로 옮깁니다
언어한국어 / English / 日本語를 바꿉니다

변경값만은 내가 직접 바꿨거나 프리셋이 바꾼 후보를 찾는 진단 도구입니다. 텍스처의 기본 fallback과 실제 할당 상태도 구분합니다. 변경된 항목이 없으면 변경된 값 없음이 표시됩니다.

툴바 아래 색상 내비게이션 막대는 각 워크플로 그룹의 위치를 나타냅니다. 색상 구간을 누르면 해당 그룹으로 이동합니다.

전체 효과와 섹션 마스터​

전체 효과는 여러 부가 효과의 공통 스위치입니다. 꺼져 있을 때 영향을 받는 항목은 인스펙터에서 비활성 상태로 표시됩니다. 기본 표면이나 별도 게이트를 쓰는 모든 기능까지 같은 방식으로 꺼진다고 가정하지 마세요.

각 섹션에도 자체 마스터가 있습니다. 꺼진 섹션에는 (모듈 꺼짐)이 표시되고, 검색으로 하위 행을 찾았을 때는 이 모듈 켜기를 사용할 수 있습니다.

값이 반응하지 않을 때

전체 효과 → 해당 섹션 마스터 → 필요한 플랫폼 전제조건 순서로 확인하세요. 깊이 효과라면 깊이 가용성도 확인해야 합니다.

빠른 설정​

빠른 설정은 자주 조정하는 그림자 경계, 2D 림, 아웃라인, 이미션 같은 값을 한곳에 모읍니다. 실제 값의 복제 UI이므로 여기서 바꾸면 원래 섹션과 즉시 동기화됩니다.

모듈이 꺼져 있으면 (모듈 꺼짐), 선택 재질 값이 다르면 (혼합 상태)가 표시됩니다.

여러 재질 동시 편집​

값이 서로 다른 행은 혼합 값으로 표시됩니다. 그 행을 수정하면 선택한 모든 재질에 같은 값이 기록됩니다.

얼굴 프록시 SceneView 편집은 같은 캐릭터 루트의 호환되는 Face 재질끼리 사용하세요. 서로 다른 루트가 섞이면 잘못된 동기화를 막기 위해 편집을 시작하지 않습니다. 먼저 밍툰 매니저의 페이스 재질만 선택을 사용하면 안전합니다.

프리셋​

머티리얼 프리셋은 룩 값을 선택하고, 사용자가 적용을 눌렀을 때만 적용합니다. 미리보기나 선택만으로 자동 적용하지 않으며, 여러 재질을 선택하면 일괄 적용됩니다.

프리셋을 적용할 때는 다음과 같은 캐릭터별 항목의 보존 상태를 확인합니다.

  • 표면 모드(불투명·컷아웃·반투명·투명)와 렌더 큐
  • 알파 마스크와 컷오프
  • 얼굴 프록시 중심·반지름·모양·축·높이
  • 이미 할당된 캐릭터별 텍스처와 타일링/오프셋

역할별 Face / Skin / Common 값은 현재 재질에 기록된 역할에 따라 선택됩니다. Manager 또는 재질 인스펙터에서 역할을 확인하세요.

복사 / 붙여넣기​

복사 뒤 붙여넣기 메뉴에서 범위를 고릅니다.

  • 전체
  • 값만 (텍스처 제외)
  • 텍스처만
  • 키워드만
  • 렌더 큐만

붙여넣기는 선택한 모든 대상에 적용되고 Undo를 지원합니다.

재질 부하​

대표 숫자는 업로드되는 베이크 후 셰이더의 예상 비용입니다. 편집용 셰이더는 모든 저작 기능을 유지하므로 더 무겁습니다. 세부 표에서 현재 편집 상태와 베이크 후 상태를 나눠 확인할 수 있습니다.

편집 성능과 개발용 도구​

편집용 셰이더는 토글할 때마다 새 변형을 기다리지 않도록 저작 경로를 유지합니다. 사용하지 않는 기능 제거와 상수 접기는 빌드 시 자동 최적화에서 수행합니다.

정식 패키지에는 사용자 작업에 필요 없는 변형 덤프·레코드, 기술 진단 패널, Depth Debug Post Process 등록이 노출되지 않습니다. 제품 개발자가 MINGTOON_DEV를 정의한 빌드에서만 다시 나타납니다.
