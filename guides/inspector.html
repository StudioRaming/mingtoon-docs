인스펙터 사용법

MingToon 재질을 선택하면 전용 인스펙터가 열립니다. 간단 모드에서 룩을 잡고, 전체 설정에서 세부 기능을 조정하세요.

30초 만에 켜 보기​

  1. 변환한 재질 하나를 선택합니다.
  2. 보기 모드를 전체 설정으로 바꿉니다.
  3. 기능 검색에 흐리게를 입력하고 제안에서 1차 그림자 흐리게를 선택합니다.
  4. 열린 형태 그림자 모듈의 체크가 켜져 있는지 확인하고 값을 0.05로 내립니다.

검색어를 입력하는 것과 제안을 선택하는 것은 다릅니다. 제안을 선택하면 전체 설정으로 이동하고, 대상 그룹과 모듈을 펼치며 즐겨찾기·변경값 필터를 해제합니다.

보기 모드 세 가지​

모드용도
간단룩·기본 설정·색·그림자·발광·재질·림·얼굴·화면 효과의 대표값으로 외형을 잡습니다
전체 설정모든 모듈과 고급 렌더 상태를 조정합니다
일괄 설정범위와 필터로 찾은 여러 재질에 공통값을 씁니다

간단과 전체 설정은 같은 재질 값을 편집합니다. 모드를 바꿔도 값은 유지됩니다. 검색은 한국어·영어·일본어 표기와 지원되는 lilToon 이름으로 항목을 찾습니다.

이동 막대와 그룹​

상단에는 보기 모드와 접기·펴기, 검색과 필터·부하 표시, 그룹 이동 탭이 있습니다. 전체 설정은 빠른 설정 아래에 다음 9개 그룹을 순서대로 둡니다. 이동 탭으로 해당 그룹을 펼치고 이동합니다.

순서그룹관련 문서
1기본 설정기본 설정
2기본 색상과 투명도기본 설정
3그림자조명과 그림자
4발광과 특수 효과디테일 맵
5재질과 광택디테일 맵
6림과 보조광림
7얼굴과 외곽선캐릭터 표현 · 아웃라인
8화면 공간 효과깊이 기반 효과
9고급 렌더링기본 설정 레퍼런스

체크와 펼침은 따로입니다​

모듈 행의 체크는 기능을 켜고 끄며, 화살표와 이름은 설정을 펼치고 접습니다. 접힌 행에는 대표값 칩, 기본값과 다른 상태를 알리는 점, ⋯ 메뉴가 있습니다. 체크를 끄더라도 저장된 설정값은 남습니다. 설정을 접는 것만으로 기능이 꺼지지는 않습니다. 체크가 없는 기본 설정 모듈은 해당 재질의 공통 설정입니다.

깊이 효과를 끄면 그 아래 깊이 림라이트·깊이 그림자·SSAO·이너 아웃라인·피부 투과 행이 비활성으로 표시됩니다. 필요한 상위 체크와 깊이 가용성을 함께 확인하세요.

전체 효과와 렌더 비활성화​

전체 효과와 렌더 비활성화는 고급 렌더링 그룹에 있습니다. 전체 효과를 끄면 효과 계산을 건너뛰고 기본 표면·알파·실루엣 처리가 남습니다. 렌더 비활성화는 해당 재질의 표시를 막는 별도 기능입니다. 둘 중 하나가 외형을 막고 있으면 인스펙터 상단 경고에서 상태를 확인할 수 있습니다.

빠른 설정​

전체 설정의 첫 카드는 자주 쓰는 룩·색·그림자·외곽선 값을 모읍니다. 원래 모듈과 같은 값을 편집하므로 양쪽이 함께 바뀝니다. 처음 여는 재질은 빠른 설정을 펼치고 나머지 그룹은 접어 시작합니다.

부하 표시는 재질 설정을 기준으로 한 추정치입니다. GPU 사용률이나 실제 FPS 측정값이 아닙니다.

검색·필터·프리셋​

즐겨찾기만과 바뀐 값만으로 보이는 항목을 좁힐 수 있습니다. 변경값은 현재 공장 기본값과 비교한 결과로, 프리셋이 바꾼 값도 포함합니다. 행의 ⋯ 메뉴로 즐겨찾기와 초기화 등을 처리하세요. 룩 프리셋은 선택 뒤 적용을 눌러 적용하며, 저장은 프리셋 관리에서 합니다. 표시 언어를 바꾸어도 재질 값은 변하지 않습니다.

여러 재질을 한 번에​

선택한 재질마다 값이 다르면 Unity의 혼합 값 표시가 나타납니다. 그 값을 편집하면 선택한 재질 전체에 같은 값이 들어갑니다. Manager의 재질 선택 행에서 대상을 고른 뒤 재질 인스펙터로 이동하세요. 범위 기반 공통 편집은 여러 재질 한 번에를 참고하세요.

재질 메뉴의 복사·붙여넣기는 전체, 값, 텍스처, 키워드, 렌더 큐 중 필요한 범위를 골라 사용할 수 있습니다. 붙여넣기는 선택 대상에 적용되고 Undo로 되돌립니다.

얼굴 프록시는 같은 캐릭터끼리만

Scene 뷰에서 얼굴 프록시를 편집할 때는 한 아바타의 Face 재질만 선택하세요. 서로 다른 아바타가 섞이면 편집을 시작할 수 없습니다.

흔한 문제​

값을 바꿔도 외형이 그대로라면 전체 효과·렌더 비활성화·모듈 체크·상위 전제조건 순으로 확인하세요. 행이 보이지 않으면 검색과 두 필터를 확인하고 전체 설정으로 바꾸세요. 노멀맵 안의 노멀맵 그림자 설정은 디테일 맵에 있습니다.
