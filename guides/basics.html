기본 설정

이 문서를 읽으면 표면 모드를 올바르게 고르고, 베이스 색과 투명 처리를 잡을 수 있습니다.

인스펙터의 기본 설정 그룹 — 마스터 조정 · 표면 렌더링 · 라이팅을 중심으로 다룹니다. 맵 레이어는 디테일 맵, 전체 항목은 기본 설정 레퍼런스에 있습니다.

1. 표면 모드부터 정합니다​

베이스 맵을 넣기 전에 표면 모드를 먼저 정하세요. 나중에 바꾸면 렌더 큐가 움직이면서 깊이 기반 효과가 통째로 꺼지는 일이 생깁니다.

표면 모드쓰는 곳알아둘 것
불투명몸, 옷, 대부분의 파츠깊이가 완전히 기록되어 모든 효과가 동작합니다
컷아웃머리카락, 속눈썹, 잘라내는 파츠알파 컷오프 0.3~0.6이 무난. 0에 가까우면 반투명 가장자리가 지저분하게 남습니다
투명 · 아웃라인용 깊이 기록반투명이면서 깊이 효과도 써야 하는 파츠깊이를 기록하므로 2D 그림자·2D 림라이트·내부 2D 경계가 전부 동작합니다. 반투명이 필요하면 이쪽을 먼저
투명완전한 반투명깊이를 기록하지 않아 깊이 기반 모듈이 전부 꺼집니다
표면 모드가 바꾸는 것

렌더 상태 · 기본 렌더 큐 · 내부 아웃라인 버퍼 상태를 함께 맞춥니다. 알파 컷오프와 아웃라인 ON/OFF, 외형 값은 보존되므로 모드를 바꿔도 작업이 날아가지 않습니다.

렌더 비활성화​

렌더 비활성화 (이 재질을 그리지 않음)은 모든 패스를 빼서 드로우 콜 자체를 없앱니다. 베이스는 남기는 전체 효과 OFF와 다릅니다.

이 값은 Material의 패스 상태라 AnimationClip이나 VRC FX로 런타임 전환할 수 없습니다. 인게임 토글이 필요하면 Renderer나 GameObject를 켜고 끄세요. 켠 상태는 bake와 업로드본에도 유지됩니다.

깊이 모듈을 켰는데 투명 모드라면

인스펙터가 표면 모드 옆에 깊이 기록 모드가 필요합니다 라고 알려 줍니다. 투명 · 아웃라인용 깊이 기록으로 바꾸세요.

머리카락이 볼을 뚫고 보일 때​

표면 렌더링의 투명 깊이 선기록 을 켜세요. 색을 그리기 전에 표면 깊이를 먼저 기록해서, 뺨 뒤에 있는 머리카락 가닥이 뺨 위로 그려지는 것을 막습니다. 선기록 알파 기준으로 어느 알파부터 기록할지 정합니다.

표시할 면​

값결과
앞면만 표시 (일반)기본값
뒷면만 표시
OFF (양면)스커트, 천
Flip (양면 + 아웃라인 반전)양면이면서 아웃라인 방향을 뒤집어야 할 때

양면 재질에서 뒷면이 이상하게 어두우면 뒷면 라이팅 노멀 뒤집기를 켜 보세요.

2. 베이스 색​

  1. 베이스 맵에 캐릭터 텍스처를 넣습니다.
  2. 색 보정은 베이스맵 HSVG로 합니다. 텍스처를 다시 굽는 것보다 빠르고, 변환 결과를 원본과 비교하기도 쉽습니다.
  3. 베이스 색상으로 틴트를 얹을 때는 세 항목이 한 세트입니다.
항목역할
베이스 색상얹을 색
틴트 합성 모드Multiply는 맵의 명암을 남긴 채 색만 입힘 · Normal은 맵을 덮어 단색이 됨
틴트 불투명도0이면 위 두 항목이 통째로 무시됩니다
색을 바꿨는데 아무 변화가 없다면

틴트 불투명도가 0인지 먼저 확인하세요. MingToon에는 이런 "상위 값이 0이면 하위가 전부 무시"되는 구조가 여러 곳에 있습니다. 레퍼런스 표의 설명에 어떤 값이 상위인지 적혀 있습니다.

색조보정을 일부 부위에만​

베이스맵 HSVG는 기본적으로 재질 전체에 걸립니다. 눈만 색을 바꾸고 얼굴은 그대로 두는 식으로 부위를 한정하려면, 바로 아래에 있는 색조보정 범위 마스크 그룹을 씁니다.

  1. 범위 마스크 사용을 켭니다. 기본값은 꺼짐이고, 꺼져 있으면 보정이 지금까지처럼 전체에 걸립니다.
  2. 범위 마스크에 흑백 이미지를 넣습니다. 흰색이 보정 적용, 검은색이 원본 유지이며 회색은 그 비율만큼 섞입니다.
  3. 여러 마스크를 한 장에 패킹했다면 마스크 채널로 읽을 채널을 고릅니다.
  4. 보정할 곳이 검게 그려진 마스크라면 마스크 반전을 켭니다.

마스크는 베이스 맵과 같은 UV·타일링으로 읽힙니다. 베이스 맵을 타일링해 두었다면 마스크도 같이 따라갑니다.

lilToon에서 변환한 재질이라면

lilToon의 색조보정 마스크가 이 자리로 들어옵니다. 흑백 마스크라 채널은 R로 고정되며, 원본에 마스크가 없었으면 이 행은 꺼진 채로 나옵니다. → lilToon 재질 변환

3. 투명도를 텍스처로 따로 지정하기​

베이스 맵의 알파가 아니라 별도 이미지로 투명도를 주려면 알파 마스크를 씁니다.

  1. 알파 마스크 사용을 켭니다.
  2. 마스크 이미지에 흑백 이미지를 넣습니다.
  3. 마스크 채널에서 읽을 채널을 고릅니다. 여러 마스크를 한 장에 패킹했다면 R/G/B/A 중 하나, RGB 밝기를 쓰려면 Luma.
  4. 지워야 할 곳이 흰색으로 그려진 마스크라면 마스크 반전을 켭니다.

리맵 시작·리맵 끝·페더로 마스크의 회색 구간을 다시 펼칠 수 있고, 그라디언트 항목으로 방향성 있는 페이드를 만들 수 있습니다.

표면 모드가 불투명이면 켜도 보이지 않습니다

알파 마스크는 컷아웃 또는 투명 계열에서만 결과가 나옵니다.

4. 공통 맵​

간단 모드에도 노출되는 자주 쓰는 맵입니다.

  • 노멀맵 — 표면 요철. 노멀 강도 0이면 맵을 넣어도 평평하고, 1이 원본 세기입니다. 노멀 레이어 01에 해당하므로 노멀 레이어 모듈이 꺼져 있으면 반영되지 않습니다.
  • 오클루전 맵 — 간접광이 닿기 어려운 곳을 어둡게. 직접광에는 영향이 없어서 정면에서 강한 조명을 받으면 효과가 거의 안 보입니다. 오클루전 강도 0이면 맵을 넣어도 변화가 없습니다.

이미션·PBR·맷캡은 디테일 맵에서 다룹니다.
