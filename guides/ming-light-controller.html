  • Ming Light Controller 사용하기

모든 상업 라이선스에는 URP 버전이 포함됩니다. Personal Streaming·Personal Creator의 Early Access Founders Edition에는 MLC가 포함되며, 정식 출시 이후 구성은 변경될 수 있습니다. 현재 오픈 베타의 상업 이용은 금지됩니다. 라이선스 및 포함 구성을 확인하세요.

Ming Light Controller 사용하기

Ming Light Controller(MLC)는 MingToon 재질의 밝기·색·가상 조명·성능 설정을 VRChat 표현 메뉴로 조절하게 만드는 별도 애드온입니다. MingToon BRP 본체와 따로 설치합니다. MLC는 오픈베타 기간에만 Studio Raming 공식 BOOTH 페이지에서 무료 배포하고, 얼리 액세스 출시부터 유료 판매합니다. 무료 배포는 MingToon 상업 라이선스를 포함하지 않으며, 파일 공유·재배포를 허용하지 않습니다. 이 문서는 아바타 설정부터 메뉴 예산 확인, Play Mode와 업로드 확인까지의 순서를 설명합니다.

무료 배포와 지원 셰이더​

MLC는 오픈 베타 기간 한정 무료 배포이며, Early Access 출시부터 유료 판매할 예정입니다. 공식 BOOTH 상품 페이지에서 배포 안내와 패키지를 확인하세요. MingToon 셰이더는 별도 설치가 필요합니다.

셰이더현재 지원 상태
MingToon현재 버전에서 지원
lilToon향후 지원 예정. 현재 버전에서는 지원하지 않음
Poiyomi향후 지원 예정. 현재 버전에서는 지원하지 않음

예정된 지원의 시기와 세부 범위는 추후 안내합니다. MLC는 셰이더를 다른 셰이더로 변환하는 도구가 아닙니다. 무료 배포에는 MingToon 상업용 라이선스가 포함되지 않으며, 파일 공유·재배포는 금지됩니다.

원본 아바타에는 설정만 저장합니다

Edit Mode의 MLC 컴포넌트는 이 아바타의 설정을 보관합니다. 실제 메뉴·파라미터·FX와 필요한 재질 처리는 Play Mode 또는 업로드를 위해 만든 아바타 사본에서 수행합니다. 원본 FX, 메뉴, 파라미터, 재질을 직접 덮어쓰지 않습니다. 편집 중 Generated 폴더가 생기지 않는 것은 정상입니다.

먼저 구분하세요​

제품역할
MingToon BRP 본체재질의 렌더링, 인스펙터와 Manager, 빌드 최적화
Ming Light Controller아바타별 조절 설정과 인게임 표현 메뉴 생성
URP 애드온현재 BRP 오픈 베타에는 제외되며, 모든 상업 라이선스에 포함되는 URP 지원 패키지.
Mask Maker / Face SDF Studio별도 제작 도구. 자세한 경계는 별매 애드온을 확인하세요.

Ming Light Controller란​

셰이더 룩을 만드는 일은 MingToon에서, 착용자가 인게임에서 바꿀 항목을 고르는 일은 MLC에서 합니다. 메뉴에 포함할 기능, 동기화 여부, 초기값, 프리셋을 아바타마다 정할 수 있습니다.

준비할 것​

VRChat용으로 사용하려면 MingToon 재질이 있는 아바타, VRChat Avatars SDK, NDMF가 필요합니다. 기존 메뉴와 FX가 있는 아바타에는 Modular Avatar 또는 지원되는 VRCFury 연결 방식을 사용하세요. MLC는 이 의존성을 자동 설치하지 않습니다.

Direct Descriptor 방식은 기존 FX·표현 메뉴·파라미터가 비어 있는 아바타 사본에만 사용할 수 있습니다. Standalone은 아바타에 메뉴를 부착하지 않으므로 그것만 선택해서는 인게임 조절을 사용할 수 없습니다.

빠른 시작​

  1. 아바타 루트에 MLC 컴포넌트를 추가합니다. 또는 아바타 루트를 선택하고 GameObject → Studio Raming → Ming Light Controller → Add or Configure Component를 실행합니다.
  2. 빠른 시작에서 시작 프리셋을 고르고 프로필을 **자동(Auto)**으로 둡니다. 적용을 눌러 설정에 반영합니다.
  3. 메뉴 구성에서 사용할 항목을 켜고 메뉴 위치를 정합니다. 필요한 항목만 선택 항목 설정에서 조정합니다.
  4. 예산·검증에서 MLC 비용, 다른 기능의 비용, 합계와 생성 가능 여부를 확인합니다. 빨간 오류나 미확인 외부 비용을 먼저 해결합니다.
  5. Play Mode에서 생성된 메뉴와 조절 결과를 확인한 뒤 업로드합니다. Play Mode 미리보기 옵션이 꺼져 있으면 미리보기 사본에 MLC 메뉴를 만들지 않습니다.

프리셋은 편집의 출발점입니다. 적용 후에도 각 항목을 수정할 수 있고, 변경한 구성은 사용자 설정이 됩니다. 적용은 Undo로 되돌릴 수 있습니다. 프리셋을 선택하는 것과 적용을 누르는 것을 구분하세요.

설치하면 열리는 MingToon 기능​

MingToon에서 MLC에 연결된 마스터 조정·가상 조명 편집과 Manager의 MLC 설정 진입점을 사용할 수 있습니다. 버튼이 계속 잠겨 있다면 Console의 컴파일 오류와 애드온 설치 상태를 확인하세요.

MLC 없이도 되는 것​

MingToon의 조명·그림자·림·깊이 효과·아웃라인 렌더링은 MLC 없이도 동작합니다. MLC 전용 편집 UI가 잠겨 있어도 재질에 이미 저장된 값의 렌더링까지 제거되는 것은 아닙니다.

깊이 텍스처 확보와 플랫폼별 빌드 정책은 MingToon Manager에서 확인합니다. MLC의 성능 메뉴는 준비된 깊이 효과 등을 인게임에서 제어하는 역할입니다. 실제 깊이 효과 사용 조건은 깊이 기반 효과를 따릅니다.

프로필과 예산​

프로필선택 기준
Auto현재 설정과 아바타 예산을 보고 Smooth를 우선 검토하고, 필요한 경우 Compact로 전환합니다.
Smooth연속 조절의 정밀도를 우선합니다. 동기화 비트를 더 사용할 수 있습니다.
Compact동기화 비트를 줄이는 대신 조절값의 단계와 로컬 처리용 파라미터 수가 달라집니다.

동기화 비트와 파라미터 항목 수는 서로 다른 한도입니다. 비트가 적은 프로필이 항상 항목 수도 적은 것은 아닙니다. Compact를 고를 때는 절약량과 함께 UI에 표시되는 정밀도·단계 설명을 확인하세요.

비용은 활성 기능, Saved/Synced 설정, 선택 프로필과 아바타의 다른 컴포넌트에 따라 달라집니다. 문서의 고정 숫자보다 현재 Inspector의 계산값을 기준으로 판단하세요. Auto가 선택한 실제 프로필과 MLC 비용, 외부 비용을 포함한 합계를 함께 표시합니다.

미확인은 사용 가능 확정이 아닙니다

다른 컴포넌트가 만들 비용을 읽지 못하면 전체 예산을 보장할 수 없습니다. MLC 자체 추정치가 보이더라도 아바타 전체가 한도 안에 든다는 뜻은 아닙니다. 원인이 되는 통합 상태를 확인한 뒤 다시 검증하세요.

메뉴 구성​

추천 구성은 Reset, Final Output, Hue/Saturation, Photo Looks, Virtual Light, Master Adjust, Performance를 출발점으로 제공합니다. 사용자가 추가·제거한 기능과 하위 메뉴에 따라 최종 구성이 달라집니다. 각 메뉴의 슬롯 수는 메뉴 트리 표시에서 확인합니다.

  • 사용(Enabled): 이 기능을 메뉴와 생성 대상에 포함합니다.
  • 저장(Saved): 다음 사용 때 유지할 값인지 정합니다.
  • 동기화(Synced): 다른 사용자에게 동기화할 값인지 정합니다. 예산에 영향을 줍니다.
  • 연속값·토글의 세부 범위와 초기값은 선택한 항목에 맞춰 표시됩니다.

명령은 누를 때 실행합니다​

Reset이나 성능 프리셋 같은 명령(Command)은 버튼을 눌렀을 때 실행되는 이벤트입니다. 연속 조절 항목처럼 고정값·핀·복원값을 지정하지 않습니다. 따라서 명령 상세에는 해당 값 조작을 표시하지 않습니다.

이전 버전 설정에 잘못된 명령 고정값이 남아 있으면 경고와 명령 값 설정 복구 버튼이 나타납니다. 이 버튼은 Saved/Synced 선택을 유지하면서 명령 값 설정을 정리합니다. Undo로 되돌릴 수 있습니다. 경고를 해결한 뒤 다시 생성 가능 여부를 확인하세요.

템플릿과 재사용​

현재 구성을 템플릿 파일이나 복사·붙여넣기로 다른 아바타에 옮길 수 있습니다. 프리셋 적용과 템플릿 가져오기는 현재 설정을 바꾸는 동작이므로 반영할 대상을 먼저 확인하세요. 읽을 수 없는 파일이나 유효하지 않은 내용을 가져오면 오류를 표시하며 정상 적용으로 처리하지 않습니다.

Play Mode와 업로드에서 확인할 것​

생성은 NDMF가 만든 아바타 사본에서 수행합니다. 선택한 연결 방식이 메뉴·파라미터·FX를 사본에 붙이며, 원본 컴포넌트는 편집용 설정으로 남습니다. 필수 통합을 사용할 수 없으면 원본에 대신 설치하지 않고 진단을 표시합니다.

업로드 전에 메뉴 열기, 조절 방향과 초기값, Reset, 필요한 동기화와 저장 동작을 확인하세요. 에디터 테스트 통과만으로 실제 VRChat 클라이언트의 두 사용자 동기화까지 검증되는 것은 아닙니다. 현재 검증 범위는 제한 사항을 확인하세요.

예전 버전이 남긴 Generated 에셋이나 MLC 부착물이 있다면 표시된 전용 정리 동작을 사용하세요. 소유권을 확인할 수 없는 폴더를 일괄 삭제하지 않습니다.

Mask Maker​

Mask Maker는 마스크와 버텍스 페인트를 만드는 별도 도구입니다. MLC 표현 메뉴 생성에 반드시 필요한 제품은 아닙니다.

설치하면 열리는 MingToon 기능​

마스크 슬롯의 MM 버튼, 씬 뷰 아웃라인 두께 페인트, 얼굴 영역 페인트가 해당 도구의 연결 지점입니다. 별매 애드온에서 설치와 기능 범위를 확인하세요.

Mask Maker 없이도 되는 것​

다른 도구로 만든 마스크 텍스처를 슬롯에 넣거나 이미 준비된 버텍스 컬러를 사용할 수 있습니다. 얼굴 SDF 제작은 얼굴 SDF와 Face SDF Studio를 확인하세요.

설치 확인​

  • 메뉴가 나타나지 않으면 Play Mode 미리보기 옵션과 선택한 연결 방식, SDK·NDMF·연결 애드온의 컴파일 상태를 확인합니다.
  • Direct Descriptor가 기존 메뉴나 FX 때문에 중단되면 Modular Avatar 또는 지원되는 VRCFury 방식을 사용합니다.
  • 외부 비용이 미확인이면 합계가 확정된 것으로 판단하지 않습니다.
  • 명령 고정값 오류는 해당 명령의 복구 버튼으로 정리합니다.
  • 설정을 바꿔도 편집 중 원본에 FX·메뉴가 생기지 않는 것은 정상입니다. Play Mode/업로드 사본에서 확인합니다.
