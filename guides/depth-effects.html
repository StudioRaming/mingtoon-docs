깊이 기반 효과

이 문서를 읽으면 2D 림라이트·2D 그림자·내부 2D 경계가 왜 안 보이는지 진단하고, 각 플랫폼에서 깊이를 확보하는 방법을 알게 됩니다.

인스펙터의 깊이 기반 효과 그룹 — 깊이 · 2D 림라이트 · 2D 그림자 · 내부 2D 경계 를 다룹니다. 전체 항목 목록은 깊이 기반 효과 레퍼런스에 있습니다.

무엇이 깊이를 쓰나​

이 그룹의 네 섹션은 전부 카메라 깊이 텍스처를 읽습니다. 깊이가 없으면 값을 아무리 만져도 화면에 나타나지 않습니다.

값을 만지기 전에 깊이부터 확인하세요

인스펙터가 상태를 직접 알려 줍니다.

  • 깊이 효과가 꺼져 있어 이 모듈은 그려지지 않습니다. → 깊이 효과 켜기
  • 이 효과는 Depth가 켜진 카메라에서만 보입니다.
  • 2D 림라이트와 2D 그림자는 깊이를 기록하는 불투명 또는 컷아웃 재질이 필요합니다. 투명 큐에서는 깊이 효과가 비활성화됩니다.
  • 활성 Scene/Game 카메라의 깊이 텍스처가 준비되지 않았습니다.

이 메시지가 떠 있는 동안 폭이나 강도를 만지는 것은 의미가 없습니다.

내부 2D 경계가 여기 있는 이유

아웃라인처럼 보이지만 화면 깊이를 읽기 때문에 아웃라인 그룹이 아니라 이 그룹에 있습니다. 아웃라인에서 찾다가 못 찾는 일이 흔합니다.

플랫폼별 깊이 확보​

VRChat (주 대상)​

상황깊이
Photo Camera 활성 중✅ 공식 계약으로 호스트 깊이가 켜집니다
월드가 Screen Camera depth를 켠 경우✅
일반 플레이어 화면 (기본)❌ 아바타가 강제할 수 없습니다
미러 · 스트림 내부 경로⚠️ 보장되지 않습니다

Screen Camera 설정은 월드/Udon 측 권한입니다. 임의 Camera나 Light를 아바타에 추가하는 것은 지원되는 해결책이 아닙니다. 예외는 밍툰 매니저의 업로드 시 깊이 라이트 싣기입니다. 이 기본 꺼짐 옵트인은 업로드 복사본에 그림자를 켠 Directional Light를 추가하지만, 다른 사용자의 depth pass·아바타 랭크·월드 조명에 비용을 더합니다. → VRChat 깊이 라이트

업로드는 Depth Availability를 바꾸지 않습니다. Auto는 카메라마다 실제로 바인딩된 깊이를 판정하고, Force On은 작성자가 직접 고른 경우에만 유지됩니다. 자세한 내용은 VRChat을 보세요.

깊이가 없는 화면을 위한 대비

림의 림 라이트·림 셰이드와 아웃라인의 노멀 아웃라인은 깊이가 필요 없습니다. 깊이 기반 효과에만 의존하지 말고 이 둘로 실루엣의 바닥을 깔아 두세요.

일반 Unity (BRP)​

씬에 Studio Raming/MingToon/Depth Texture Provider 컴포넌트를 두면 됩니다. 활성 Game Camera가 렌더하기 직전에 필요한 depth flag와 카메라 행렬을 제공하고, 기존 카메라 플래그는 보존합니다.

URP 12​

  1. Tools > Studio Raming > MingToon > URP > Install Depth Effects Renderer Feature를 실행합니다.
  2. 아웃라인도 쓴다면 Tools > Studio Raming > MingToon > URP > Install Outline Renderer Feature도 실행합니다.
  3. 사용 중인 URP Renderer Data에서 Depth Texture를 활성화합니다.

Warudo​

Depth를 켠 Warudo 카메라가 필요합니다. 아바타 번들만으로는 호스트 카메라를 바꿀 수 없는 경우가 있습니다. → Warudo

깊이 가용성​

깊이 텍스처가 있는지 없는지를 어떻게 판정할지 정하는 값입니다. 네 가지 중에서 고릅니다.

값뜻
Auto (기본값)셰이더가 스스로 찾습니다. 이대로 두세요
Force On자동 판정이 닿지 않는 호스트에서 작성자가 깊이 버퍼를 보증합니다. 미러는 제외됩니다
Force Off깊이 효과를 완전히 차단합니다
Diagnostic판정 상태를 화면에 색으로 칠합니다. 버그 신고용
주의
Force On은 미러를 켜지 않습니다

미러 카메라는 자기 깊이 텍스처를 그리지 않는데, 플레이어 카메라의 깊이 버퍼는 그대로 바인드되어 있습니다. 그대로 읽으면 캐릭터가 남의 실루엣을 자기 그림자로 씁니다 — 고개를 돌릴 때마다 2D 그림자와 2D 림라이트가 몸을 따라오지 않고 미끄러지던 현상이 이것입니다.

그래서 Force On은 "호스트가 보고하지 못하는 경우까지 켠다, 단 미러는 제외"를 뜻합니다. 미러 안에서는 어떤 값을 골라도 깊이 모듈이 내려갑니다.

Diagnostic — 신고할 때만​

깊이 효과가 아바타 전체에 번지는 것처럼 보일 때, 셰이더가 실제로 어떤 깊이 텍스처를 보고 있었는지 단색으로 칠해 알려 줍니다. 룩이 통째로 바뀌므로 일반 작업에는 쓰지 마세요.

색뜻
검정깊이 텍스처가 아예 없음
빨강텍스처는 있으나 이 화면의 버퍼가 아님 (크기가 다르거나 미러)
노랑있고 크기도 맞음
파랑 채널이 섞임호스트가 깊이 가용을 직접 보고함

렌더링 자체는 바꾸지 않습니다. 진단 색 아래에서 도는 깊이 판정은 Auto와 완전히 같습니다.

VRChat에서 확인하려면 재업로드가 필요합니다

셰이더는 아바타 에셋번들에 동봉되므로, 이미 올라간 아바타는 예전 셰이더를 계속 씁니다. → VRChat

안 보일 때 진단 순서​

위에서부터 차례로 확인하세요.

  1. 전체 효과 — 마스터가 꺼져 있지 않은가 (인스펙터 사용법)
  2. 깊이 효과 섹션의 마스터 토글
  3. 표면 모드 — 투명(깊이 미기록)이면 전부 꺼집니다. 투명 · 아웃라인용 깊이 기록으로 바꾸세요
  4. 마스터 폭 — 0이면 각 모듈의 폭을 아무리 올려도 아무것도 나오지 않습니다
  5. 각 모듈의 강도 — 림 강도가 0이면 림 계산을 건너뜁니다
  6. 카메라 깊이 — 위의 플랫폼별 항목
  7. 계속되면 Tools > Studio Raming > MingToon > Validate Project

깊이 효과 마스터​

2D 림라이트와 2D 그림자가 공유하는 값이며, 마스터를 끄면 SSAO·2D 투과광·이너 아웃라인까지 깊이 그룹 전체가 꺼집니다. 여기를 먼저 잡고 각 모듈로 내려가세요.

항목하는 일
마스터 폭두 모듈의 화면 오프셋에 공통으로 곱해지는 배수. 0이면 전부 안 나옵니다
폭 모드Screen Pixels는 화면 픽셀 기준 · Distance Stable은 거리·FOV가 변해도 두께 일정
거리 스케일Distance Stable일 때 기준 거리. Screen Pixels면 무시됩니다
마스터 바이어스이 값을 넘는 깊이 차이만 경계로 인정. 낮추면 얕은 굴곡에도 선이 붙어 지저분해지고, 올리면 얇은 부위의 선이 사라집니다
마스터 부드러움낮으면 딱딱한 잉크선, 높으면 부드럽게 번진 경계
아바타에는 Distance Stable

카메라 거리가 계속 변하는 환경에서는 Distance Stable이 두께를 일정하게 유지합니다.

런타임 전환​

  • FX 애니메이터로 깊이 효과 전환 — VRChat FX 같은 애니메이터가 깊이 효과 마스터를 켜고 끌 수 있게 베이크 상수 접기를 보류합니다.
  • FX 메뉴로 그림자 투영 전환 — 밍툰 매니저의 VRC Quality 메뉴에 Shadow Projection을 추가합니다. 끄면 페더 샘플·캐스트 합성·관련 투과광 계산을 건너뜁니다.

두 옵션 모두 기본 꺼짐입니다. 런타임에서 실제로 전환할 재질에만 켜세요. 옵트인하면 해당 코드를 베이크에서 제거할 수 없으므로 High/ON 상태에도 소폭의 유지 비용이 있습니다.

2D 림라이트​

최종 두께 = 마스터 폭 × 림 폭 배수 입니다.

  • 림 강도 — 0이면 계산을 건너뜁니다. 색과 폭을 바꿔도 아무것도 안 보입니다.
  • 베이스 색 혼합 — 0이면 단색 림, 1이면 베이스 맵 색을 곱해 부위마다 다른 림 색.
  • 색 순도 — 범위 0~10, 기본값 1. 베이스 색과 림 색을 합친 뒤의 채도. 0은 무채색, 1은 기존 색, 1보다 크면 과채도입니다.
  • 360도 림 — 0이면 광원 방향 쪽에만, 1이면 실루엣 전체를 감쌉니다.
  • 2D 림 방향 — 림이 밀려나는 방향.
  • 림 샘플 품질 — Low 1탭 / Standard 2탭 / High 4탭. 폭은 같고 내부선 억제와 비용만 달라집니다. 1탭은 눈·코·옷 경계가 림으로 새거나 카메라 이동 때 한 텍셀 흔들릴 수 있고, 4탭은 좁은 내부선까지 더 잘 거릅니다.
조명이 없거나 방향이 자주 바뀌는 환경

360도 림을 올려 두면 안정적입니다.

실루엣 시작점과 실루엣 전환 부드러움은 같은 그룹의 외곽 실루엣 제한이 0이면 전혀 반영되지 않습니다.

빠른 설정의 2D 림 폭·2D 림 강도가 이 섹션의 값입니다.

2D 그림자​

캐릭터의 실루엣을 화면 공간에서 밀어 그림자를 만듭니다. 앞머리가 이마에 드리우는 그림자를 실시간 섀도우 없이 그릴 때 주로 씁니다.

항목하는 일

값결과

2D 그림자 조명 방향 추적을 켜면 씬 광원을 따라가고, 끄면 고정됩니다.

위·아래 오프셋과 앞·뒤 오프셋으로 그림자 위치를 미세 조정합니다.

눌어붙음과 감쇠​

항목하는 일

몸체 표면 가드를 먼저 올리세요. 그래도 남으면 마스터 바이어스나 추가 깊이 바이어스를 올립니다.

0.1.7은 수신자 거리와 표면 기울기에 따라 깊이 허용오차를 안정화하고, 화면 가장자리에서 화면 밖 탭을 감쇠합니다. 먼 거리에서는 소멸 구간과 함께 샘플 수가 줄어 군중 씬 비용도 낮아집니다.

SSAO (화면 공간 차폐)​

접히는 곳과 물체가 맞닿는 자리를 어둡게 합니다. 목·턱 아래, 겨드랑이, 옷 주름, 발이 바닥에 닿는 부분입니다.

그림자가 아니라 차폐입니다

형태 그림자를 꺼 둔 재질에도 그대로 들어갑니다. 툰 밴드와 스크린톤을 통과한 뒤에 합류하므로 그림자 경계를 계단지게 만들거나 망점으로 다시 찍히지 않습니다.

오클루전 맵과 어떻게 합쳐지나​

곱하지 않습니다. 둘을 각각 계산한 뒤 더 어두운 쪽을 취합니다. 맵으로 미리 칠해 둔 차폐가 이미 어두운 곳은 SSAO가 더 어둡게 만들지 않고, SSAO는 맵이 다루지 못하는 실제 자세와 주변 물체에 따른 차폐만 얹습니다.

값 잡는 순서​

항목하는 일
SSAO 반경차폐를 찾는 월드 거리입니다. 범위 0.001~0.01m, 기본 0.005m입니다
SSAO 강도세기. 0이면 끈 것과 같은 그림이지만 계산은 그대로 도므로, 안 쓸 때는 SSAO 사용을 끄세요
SSAO 대비어두워지는 곡선을 조입니다
SSAO 품질픽셀당 깊이 샘플 수(4/8/12/16). 키워드 변형이 아니라 균일 루프라 변형 수는 늘지 않습니다

0.1.7의 SSAO는 뷰 공간 접평면으로 기울어진 면의 자기 차폐를 줄이고, 이진 탭 게이트를 부드러운 램프로 바꿨습니다. 바이어스 0에서도 깊이 양자화 자국을 막는 작은 내부 바닥값이 적용됩니다.

캐릭터 크기 대상에서는 Standard 품질과 기본 반경 0.005m에서 시작하고, 넓은 얼룩을 만들기보다 필요한 접촉부만 남기세요.

거리와 화각이 바뀌어도 같게​

SSAO 거리 보정이 1(기본값)이면 카메라가 다가가거나 멀어져도, 화각을 바꿔도 같은 주름에 같은 두께의 음영이 들어갑니다. 화각은 별도 컨트롤 없이 저절로 상쇄됩니다. 0으로 내리면 카메라가 1m 안으로 들어왔을 때 반경이 짧아지는 예전 동작으로 돌아갑니다.

SSAO 소멸 거리는 효과가 완전히 사라지는 거리입니다. 페이드는 이 값의 75% 지점부터 시작하므로, 12로 두면 9m에서 옅어지기 시작해 12m에서 사라집니다. 0이면 사용하지 않습니다.

빛 방향·마스크·색​

  • SSAO 빛 방향 반응 — 차폐를 찾는 원을 주광원 쪽으로 기울입니다. 0이면 빛과 무관한 균일한 차폐이고, 올릴수록 빛이 닿지 않는 반대편에 차폐가 모입니다. 빛이 카메라 정면에 가까워질수록 기울기가 저절로 줄어듭니다.
  • SSAO 마스크 세기 — 전용 텍스처를 새로 만들지 않고 2D 그림자 마스크 (공용)를 그대로 빌립니다. 채널·반전·HSVG는 2D 그림자 마스크에 설정한 값을 함께 쓰며, 어느 쪽 화면에서 고쳐도 같은 텍스처 하나를 고치는 것입니다.
  • SSAO 틴트 · SSAO 명도 · SSAO 순도 — SSAO 전체 커버리지에 적용됩니다. 형태 그림자와 역광 안에서도 보이며 기본 흰색·명도 1에서는 결과가 같습니다.
깊이가 없으면 조용히 사라집니다

효과마다 필요한 깊이 샘플을 카메라 깊이 텍스처에서 읽습니다. 포스트 프로세스 패스나 별도 카메라는 쓰지 않지만, 일부 환경에서는 깊이를 확보하는 보조 광원이 필요할 수 있습니다. 설정은 MingToon Manager와 이 문서 위쪽의 플랫폼별 깊이 확보를 확인하세요. 이 페이지 위쪽의 플랫폼별 깊이 확보가 적용되며, 깊이가 없으면 차폐는 1(차폐 없음)으로 고정됩니다. VRChat 클라이언트 동작은 아직 검증 중입니다.

호환성 재검증 후보의 보조광은 Important(ForcePixel)입니다. 카메라 깊이 패스 외에 라이트별 그림자 맵·픽셀 라이트 슬롯 비용이 추가될 수 있으며, 영향을 받은 실제 VRChat 월드에서 재검증이 필요합니다. 설정 복원만으로 해결이 확인된 것은 아닙니다.

2D 투과광​

머리끝이나 옷자락처럼 얇은 부위가 빛을 머금은 것처럼 보이게 합니다.

이 모듈만 마스터 폭에 묶여 있지 않습니다

광원 방향으로 깊이를 두 번 읽어 빛이 캐릭터를 얼마나 통과했는지 직접 잽니다. 그래서 2D 림라이트·2D 그림자와 무관하게 단독으로 동작합니다. 마스터 폭이 0이어도 나옵니다.

1. 얇음을 어떻게 잴지​

항목하는 일
투과 강도전체 밝기 배수. 0이면 계산을 건너뜁니다
측정 폭광원 방향으로 얼마나 멀리 살펴볼지. 크게 잡으면 굵은 부위까지 얇다고 판정되고, 작게 잡으면 아주 얇은 끝부분만 빛납니다
깊이 범위이만큼(m) 뒤가 비어 있으면 완전히 뚫린 것으로 봅니다
껍데기 최소 두께아래 참고
머리카락 뒤의 옷이 배경으로 오인되어 밝아지면

깊이 범위를 올리세요. 조금만 뒤에 있는 표면이 "뚫린 것"으로 읽히고 있는 것입니다.

속이 빈 옷은 반드시 껍데기 최소 두께를 주세요

치마나 망토는 화면에서 폭이 넓어 두껍다고 측정되지만 실제 천은 아주 얇습니다.

  • 치마·망토 같은 껍데기 → 0.8 정도. 측정과 무관하게 항상 얇게 취급합니다
  • 피부·손처럼 속이 찬 부위 → 0. 측정에 맡깁니다

2. 빛이 퍼지는 성질​

항목하는 일
밀도클수록 아주 얇은 곳에만 빛이 남아 밀도 높은 재질처럼 보이고, 낮추면 넓게 퍼집니다
노출 부드러움응답 곡선만 바꿉니다. 경계 위치는 옮기지 않습니다
색 분리빨강이 파랑보다 깊이 스며드는 산란을 재현. 채널마다 감쇠가 달라져 틴트로는 만들 수 없는 피부·머리카락 특유의 번짐이 생깁니다. 0이면 세 채널이 동일

3. 어느 각도에서 빛날지​

항목하는 일
역광 감쇠클수록 정확한 역광에서만 좁게 강해집니다
정면광 바닥값정면광에서 남는 비율
노말 방향 휨빛 방향을 표면 노말 쪽으로 휘어, 정확한 역광이 아니어도 곡면을 따라 새어 나오게 합니다
시선 방향 휨빛 방향을 카메라 쪽으로 휩니다
씬 라이트 영향0이면 지정한 색만, 1이면 씬 조명 색을 그대로 받습니다
위험
정면광 바닥값을 0으로 두지 마세요

산란은 역광에서 강해질 뿐 정면광에서 사라지지 않습니다. 0으로 두면 피부가 피부처럼 보이지 않습니다.

머리카락 카드가 깜빡이면

평면 카드는 노말을 믿을 수 없어서 노말 방향 휨만으로는 빛이 켜졌다 꺼졌다 합니다. 시선 방향 휨이 그것을 막습니다.

4. 두 층으로 색을 만든다​

가장자리 층과 안쪽 층이 따로 있습니다. 한쪽 세기를 0으로 두면 나머지 한 층만 있는 단일 층과 완전히 같아집니다.

가장자리 층안쪽 층
밝히는 곳실루엣 바깥쪽실루엣 안쪽
세기가장자리 세기안쪽 세기
감쇠가장자리 감쇠안쪽 감쇠
색가장자리 색 보정 → 가장자리 틴트안쪽 색 보정 → 안쪽 틴트

두 층에는 색 순도도 각각 있습니다. HSVG 색 보정, 틴트와 두께별 채도차까지 합성한 뒤 0은 무채색, 1은 기존 합성색, 1보다 큰 값은 해당 층만 과채도로 만듭니다.

색 보정이 베이스 색에서 파생됩니다

절대 색이 아니라 베이스 맵 색에서 만들어 냅니다. 그래서 금발은 노랗게, 검은 머리는 어둡게 — 캐릭터 전체가 설정 하나로 맞습니다.

기본값은 안쪽 층의 색조를 붉은 쪽으로 돌리고 채도를 올려, 가장자리는 흰빛에 가깝고 안쪽은 따뜻하게 빛나는 머리카락 느낌을 만듭니다.

중립값 (0,1,1,1)이면 보정을 건너뜁니다.

이너 아웃라인​

화면 깊이 차이로 표면 안쪽 경계선을 그립니다. 추가 지오메트리가 없어서 노멀 아웃라인이 깨지는 메시에도 쓸 수 있습니다.

표면 모드가 투명이면 동작하지 않습니다

반투명이 필요하면 투명 · 아웃라인용 깊이 기록을 쓰세요.

조정 항목:

  • 깊이 바이어스 — 이 값보다 큰 깊이 차이만 경계로 인정합니다. 낮추면 완만한 굴곡에도 선이 붙어 노이즈가 되고, 올리면 얇은 부위의 선이 사라집니다.
  • 부드러움 — 0은 단단한 선, 1은 선 폭 전체가 경계에서 안쪽 끝까지 완전히 흐려집니다.
  • 카메라 거리·화각 안정화 — 카메라가 움직여도 선 두께가 일정하게 유지됩니다.
내부 2D 경계가 통째로 사라졌다면

Inner Edge 외곽선에 적용 토글을 확인하세요. 이 토글은 노멀 아웃라인 그룹 안에 있지만 노멀 아웃라인을 꺼도 내부 2D 경계에 계속 작용합니다. 버텍스 컬러가 검은 메시에서 켜져 있으면 내부 2D 경계가 전부 사라집니다.

반투명 표면과 깊이​

표면 모드가 두 갈래로 갈리고, 차이는 깊이를 기록하느냐입니다.

  • 투명 · 아웃라인용 깊이 기록 — 깊이 텍스처를 만드는 범위 안입니다. 2D 그림자·2D 림라이트·내부 2D 경계가 전부 동작합니다. 반투명이 필요하면 이쪽을 먼저 검토하세요.
  • 투명 — 그 범위 밖입니다. 깊이 기반 모듈은 꺼진 채로 둡니다. 켜면 캐릭터 뒤에 있는 것과 비교하게 됩니다.

불투명과 컷아웃은 영향을 받지 않고 항상 완전한 깊이를 갖습니다.
