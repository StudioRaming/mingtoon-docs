깊이 기반 효과

이 페이지는 깊이 효과를 처음 켜 보는 분을 위한 것입니다. 앞머리 그림자와 균일한 외곽선을 화면 깊이로 그립니다. 약 10분 걸립니다.

이게 뭔가요​

뎁스 텍스처는 카메라가 재는 무엇이 얼마나 앞에 있는지 정보입니다. 이 정보로 그리는 효과 다섯 가지가 화면 공간 효과 그룹에 있습니다.

인스펙터 섹션무엇을 그리나
뎁스 림라이트실루엣 전체에 굵기가 균일한 빛 선
뎁스 그림자앞머리가 이마에 드리우는 그림자
SSAO (화면 공간 차폐)접히는 곳과 맞닿는 자리의 접촉 음영
SSSSS (실험적)머리끝·옷자락이 빛을 머금은 듯한 투과광
이너 아웃라인Inner Depth Edge. 옷깃·턱처럼 실루엣 안쪽의 경계선

언제 쓰나요​

  • 앞머리 그림자가 조명이 바뀌어도 흔들리지 않기를 바랄 때.
  • 옷이 몸에 닿는 자리에 접촉 음영을 넣고 싶을 때.
값을 만지기 전에 깊이부터 확인하세요

깊이가 없으면 폭이나 강도를 올려도 화면에 아무것도 나오지 않습니다. 인스펙터가 그때 무엇이 없는지 직접 알려 줍니다.

먼저 깊이를 확보하세요​

환경해야 할 일
VRChatPhoto Camera를 켜거나 월드가 Screen Camera depth를 켭니다. 매니저의 빌드 시 깊이 라이트 제거하기 가 꺼져 있는지 확인하세요
일반 Unity (BRP)씬의 밍툰 매니저가 에디터에서 자동으로 공급합니다. 추가할 컴포넌트는 없습니다
URP 12StudioRaming > MingToon > URP > Install Depth Effects Renderer Feature를 실행합니다
WarudoDepth를 켠 Warudo 카메라가 필요합니다

URP에서는 사용 중인 Renderer Data에서 Depth Texture도 켜야 합니다. VRChat 일반 플레이어 화면은 아바타가 깊이를 강제할 수 없습니다. 그래서 림과 아웃라인으로 바닥을 깔아 두세요.

깊이 가용성​

깊이 가용성 은 깊이가 있는지 어떻게 판정할지 정합니다.

  • Auto 는 기본값입니다. 셰이더가 스스로 찾으므로 이대로 두세요.
  • Force On 은 자동 판정이 닿지 않는 호스트에서 작성자가 보증합니다.
  • Force Off 는 깊이 효과를 완전히 차단합니다.
  • Diagnostic 은 판정 상태를 색으로 칠합니다. 버그 신고용입니다.
Force On은 미러를 켜지 않습니다

미러 카메라는 자기 깊이를 그리지 않는데 남의 깊이 버퍼가 붙어 있습니다. 그대로 읽으면 캐릭터가 남의 실루엣을 자기 그림자로 씁니다.

Diagnostic — 신고할 때만​

셰이더가 어떤 깊이를 보고 있었는지 단색으로 칠해 줍니다. 룩이 통째로 바뀝니다. 검정은 깊이 없음, 빨강은 이 화면의 버퍼가 아님, 노랑은 정상입니다.

30초 만에 켜 보기​

  1. 변환한 얼굴 재질을 고릅니다.
  2. 깊이 효과 를 켭니다.
  3. 전체 폭 이 1인지 확인합니다.
  4. 뎁스 그림자 를 켭니다.

이마에 앞머리 그림자가 생기면 성공입니다. 아무 변화가 없으면 문제 해결로 가세요.

깊이 효과 마스터​

다섯 모듈을 한 번에 켜고 끄는 스위치와 공통 값이 모여 있습니다.

인스펙터 라벨뭘 바꾸는지추천 시작값올리면 / 내리면
깊이 효과다섯 모듈 전체의 마스터 스위치켜기끄면 다섯 모듈이 모두 꺼집니다
전체 폭뎁스 림라이트와 뎁스 그림자의 공통 배수기본값 그대로(1)0이면 각 모듈의 폭을 올려도 아무것도 안 나옵니다
전체 바이어스앞뒤 경계로 인정할 최소 깊이 차기본값 그대로(0.02)내리면 얕은 굴곡에도 선이 붙어 지저분해집니다
전체 부드러움깊이 경계 판정의 전환 폭기본값 그대로(0.08)내리면 딱딱한 잉크 선, 올리면 번진 경계가 됩니다
폭 모드두께의 기준기본값 그대로(Distance Stable)Screen Pixels는 멀어질수록 선이 두꺼워집니다

뎁스 림라이트​

실루엣 바깥에 굵기가 균일한 빛 선을 그립니다.

  1. 깊이 효과 가 켜져 있는지 확인합니다.
  2. 뎁스 림라이트 를 켭니다.
  3. 림 강도 를 1로 둡니다.
  4. 림 폭 배수 를 2로 둡니다.

실루엣을 따라 균일한 빛 선이 생기면 성공입니다.

인스펙터 라벨뭘 바꾸는지추천 시작값올리면 / 내리면
림 강도선의 밝기 배수기본값 그대로(1)0이면 색과 폭을 바꿔도 안 보입니다
림 폭 배수전체 폭에 곱하는 전용 배수기본값 그대로(2)전체 폭이 0이면 여기를 올려도 소용없습니다
360도 림실루엣 전체를 감쌀지10이면 광원 쪽에만 생기고, 1이면 전체를 감쌉니다
씬 조명 영향씬 밝기를 따라가는 정도0.30이면 어두운 월드에서도 선이 그대로 남습니다
림 샘플 품질픽셀당 읽는 깊이 샘플 수기본값 그대로(표준)낮음은 눈·코·입까지 림으로 잡힙니다

뎁스 그림자​

앞 물체의 실루엣을 조명 반대쪽으로 밀어 그림자 밴드를 그립니다.

  1. 얼굴 재질에서 뎁스 그림자 를 켭니다.
  2. 그림자 폭 을 3으로 둡니다.
  3. 그림자 강도 를 1로 둡니다.
  4. 뎁스 그림자 바이어스 를 0.03으로 둡니다.

이마에 앞머리 모양 그림자가 생기면 성공입니다.

인스펙터 라벨뭘 바꾸는지추천 시작값올리면 / 내리면
그림자 폭밀어 그린 밴드의 두께기본값 그대로(3)올리면 이마 아래로 길어지고, 내리면 메쉬에 붙습니다
그림자 강도그림자의 최종 적용량기본값 그대로(1)0이면 폭을 올려도 보이지 않습니다
뎁스 그림자 바이어스앞 물체와 수신면 사이 최소 간격기본값 그대로(0.03)0.03이 3mm입니다. 내리면 얼굴에 그림자가 붙습니다
깊이 늘림떠 있는 만큼 그림자를 넓히는 양기본값 그대로(0.75)0이면 폭만으로 그림자가 정해집니다
깊이 옅어짐뒤쪽 부위일수록 옅어지는 양기본값 그대로(0.5)1이면 가장 뒤쪽 그림자가 완전히 사라집니다
소프트니스경계가 완전한 그림자가 되는 폭기본값 그대로(0.05)내리면 딱 떨어지고, 올리면 얕은 접촉이 옅어집니다
깊이 커브폭·블러·옅어짐이 함께 쓰는 곡선기본값 그대로(0)0이면 깊이에 정비례하고, 올리면 뒤쪽만 크게 변합니다

눌어붙음과 감쇠​

그림자가 자기 얼굴에 눌어붙으면 뎁스 그림자 바이어스 를 올립니다. 그래도 남으면 얼굴 재질에서 수신면 밀기 를 올립니다. 바이어스 바로 아래에 있습니다. 얼굴·몸처럼 받는 재질에만 쓰고, 머리카락·의상은 0으로 둡니다.

수신면 밀기가 0보다 크면 투영 그림자를 못 받습니다

그 재질이 받는 투영 그림자가 자동으로 꺼집니다. 뎁스 그림자를 끄거나 값을 0으로 되돌리면 원래 설정으로 돌아옵니다.

SSSSS (실험적)​

얇은 부분이 빛을 머금은 것처럼 보이게 합니다. 아직 실험 단계입니다.

  1. 머리카락 재질에서 투과광 사용 을 켭니다.
  2. 투과 강도 를 1로 둡니다.
  3. 측정 폭 을 6으로 둡니다.
  4. 광원을 캐릭터 뒤로 옮깁니다.

머리끝이 붉게 비쳐 보이면 성공입니다.

인스펙터 라벨뭘 바꾸는지추천 시작값올리면 / 내리면
투과 강도투과광 전체의 밝기 배수기본값 그대로(1)0이면 계산을 건너뜁니다
측정 폭광원 방향으로 얼마나 멀리 볼지기본값 그대로(6)크게 잡으면 굵은 부위까지 얇다고 판정됩니다
껍데기 최소 두께속이 빈 옷을 얇게 취급하는 하한치마·망토는 0.80이면 측정값을 그대로 씁니다
정면광 바닥값정면광에서 남는 투과광 비율0.20으로 두면 피부가 피부처럼 보이지 않습니다

SSAO (화면 공간 차폐)​

접히는 곳과 맞닿는 자리를 부드럽게 어둡게 합니다.

  1. 몸 재질에서 SSAO 사용 을 켭니다.
  2. SSAO 강도 를 1로 둡니다.
  3. SSAO 반경 을 0.005로 둡니다.
  4. SSAO 대비 를 1로 둡니다.

옷이 몸에 닿는 자리가 어두워지면 성공입니다.

인스펙터 라벨뭘 바꾸는지추천 시작값올리면 / 내리면
SSAO 강도효과의 세기기본값 그대로(1)0이면 안 보이지만 계산은 그대로 돕니다
SSAO 반경차폐를 찾는 거리기본값 그대로(0.005)키우면 접촉 음영이 넓고 부드러워집니다
SSAO 대비차폐의 대비기본값 그대로(1)올리면 진하게 파인 곳만 남습니다
품질SSAO가 픽셀당 읽는 깊이 샘플 수기본값 그대로(Low)Low 4 · Standard 8 · High 16입니다
SSAO 틴트차폐 자리에만 곱하는 색흰색흰색이면 기존 그림자 색을 그대로 둡니다

Inner Depth Edge​

이너 아웃라인 섹션에 있습니다. 실루엣 안쪽의 깊이 단차에 선을 그립니다.

  1. 아웃라인 마스터 가 켜져 있는지 확인합니다.
  2. Inner Depth Edge 사용 을 켭니다.
  3. 폭 을 0.3으로 둡니다.
  4. 내부 경계 색 을 어둡게 잡습니다.

옷깃과 턱 아래에 선이 생기면 성공입니다.

인스펙터 라벨뭘 바꾸는지추천 시작값올리면 / 내리면
폭안쪽 경계선의 굵기기본값 그대로(0.3)노멀 아웃라인보다 가늘게 두는 것이 일반적입니다
깊이 바이어스경계로 인정할 최소 깊이 차기본값 그대로(0.02)내리면 완만한 굴곡에도 선이 붙어 지저분해집니다
내부 경계 색안쪽 경계선의 색베이스보다 어두운 색검정에 가까울수록 만화풍이 강해집니다
아웃라인 마스터노멀 아웃라인과 공용 게이트켜기꺼져 있으면 두 탭 모두 그려지지 않습니다

흔한 문제​

깊이 효과가 전혀 안 보여요​

  1. 전체 효과 마스터와 깊이 효과 가 켜져 있는지 봅니다.
  2. 전체 폭 이 0이 아닌지 봅니다.
  3. 각 모듈의 강도가 0이 아닌지 봅니다.
  4. 위의 먼저 깊이를 확보하세요를 다시 봅니다.

표면 모드를 투명으로 두니 다 꺼져요​

투명 (3000)은 깊이를 기록하지 않습니다. 기본 설정 가이드에서 표면 모드를 반투명 (2499) 로 바꾸세요. 반투명 (2499)는 알파 합성을 하면서 깊이도 기록합니다.

미러 안에서 그림자가 몸을 안 따라와요​

미러에서는 어떤 값을 골라도 깊이 모듈이 내려갑니다.
