아웃라인

이 문서를 읽으면 노멀 아웃라인을 세우고, 부위마다 굵기를 칠해 조절할 수 있습니다.

인스펙터의 아웃라인 그룹 — 노멀 아웃라인 을 다룹니다. 전체 항목 목록은 아웃라인 레퍼런스에 있습니다.

내부 2D 경계는 여기 없습니다

표면 안쪽 선을 그리는 내부 2D 경계는 화면 깊이를 읽기 때문에 깊이 기반 효과 그룹에 있습니다. → 깊이 기반 효과

노멀 아웃라인​

메시를 뒤집어 확장하는 방식입니다. Built-in에서는 추가 패스 한 번으로 그려져 카메라 깊이 텍스처를 읽지 않습니다. URP에서는 활성 Renderer Data에 MingToon Outline Renderer Feature를 설치해야 합니다. 따라서 VRChat 일반 화면처럼 깊이를 못 쓰는 곳에서도 선택할 수 있지만, 파이프라인 설정과 머티리얼 게이트가 갖춰져야 합니다.

URP Renderer Feature와 레거시 게이트

URP 프로젝트에서는 사용하는 모든 Renderer Data에 MingToon Outline Renderer Feature를 설치하고 켜 두세요: Tools > Studio Raming > MingToon > URP > Install Outline Renderer Feature. 기존 재질에 남은 _OutlineEnabled (Outline Master)도 호환성 게이트라서, 이 값이 꺼져 있으면 Classic Hull을 켜도 선이 그려지지 않습니다.

기본 설정​

  1. 클래식 헐 사용을 켭니다.
  2. 폭 모드를 고릅니다.
폭 모드동작권장
PixelStable화면 픽셀 기준. 거리와 무관하게 두께 일정아바타에는 이쪽
WorldSpace월드 크기 기준. 멀어지면 얇아짐고정 카메라 연출
  1. 아웃라인 폭과 아웃라인 색상을 조정합니다. (빠른 설정에도 있습니다)

이렇게 되면 정상입니다. 캐릭터 실루엣 바깥에 선이 그려집니다.

선 굵기를 부위마다 다르게​

압력 소스 고르기​

압력 소스로 굵기를 조절할 페인팅 채널을 고릅니다.

소스읽는 것
VertexRed버텍스 컬러 R
VertexAlpha버텍스 컬러 A
WidthMask폭 마스크 텍스처
OutlineNormalUV8UV8에 구운 외곽선 노멀. 긴 면은 두껍게, 꼭짓점은 얇게
선이 통째로 사라졌다면

버텍스 컬러가 검게 임포트된 메시에서 VertexRed를 고른 경우입니다. 압력이 0이면 폭도 0이 됩니다. 압력 소스를 바꾸거나 버텍스 컬러를 확인하세요.

헐 압력 대비는 굵기 차이를 키웁니다. 0이면 압력이 완전히 무시되고, 1이 원본, 높일수록 얇은 곳이 더 얇아집니다.

Hull 외곽선에 적용 / Inner Edge 외곽선에 적용으로 압력을 어느 쪽에 반영할지 정합니다.

주의
Inner Edge 외곽선에 적용은 노멀 아웃라인을 꺼도 작동합니다

이 토글은 노멀 아웃라인 그룹 안에 있지만 내부 2D 경계에 계속 작용합니다. 버텍스 컬러가 검은 메시에서 켜져 있으면 내부 2D 경계가 통째로 사라집니다.

씬 뷰에서 직접 칠하기​

굵기를 손으로 칠할 수 있습니다.

준비​

  1. 압력 소스를 Vertex Alpha 또는 Vertex Red로 둡니다. 아니면 인스펙터가 버텍스 페인팅으로 두께를 조절하려면 Pressure Source가 Vertex Alpha 또는 Vertex Red여야 합니다. 와 함께 Vertex Alpha로 전환 버튼을 보여 줍니다.
  2. 이 머티리얼을 쓰는 렌더러가 현재 선택 항목 아래에 있어야 합니다. 밍툰 매니저를 선택하면 됩니다.
  3. 머티리얼은 하나만 선택합니다.
채널 충돌 경고가 뜨면 그냥 진행하지 마세요

압력 소스가 Vertex Red이고 노멀 소스가 VertexColorTS이면 둘 다 같은 버텍스 컬러를 읽습니다. 이대로 칠하면 RGB에 저장된 아웃라인 방향이 덮어써지고, 깊이 효과 마스크도 레드 채널을 함께 읽습니다.

인스펙터가 이를 경고하고 그래도 칠하기 버튼을 줍니다. 진행 전에 둘 중 하나를 하세요.

  • 압력 소스를 Vertex Alpha로 바꾸기
  • 아웃라인 노멀을 UV8TS로 옮기기 → 메시 UV 베이크

칠하기​

씬 뷰에서 외곽선 두께 칠하기를 누르면 씬 뷰에 오버레이가 뜹니다.

조작동작
드래그칠하기
Shift + 드래그지우기
[ ]브러시 크기
Esc종료

오버레이에서 조정할 수 있는 값:

항목하는 일
반경브러시 크기
강도한 번에 칠해지는 양
감쇠브러시 가장자리의 부드러움
뒷면까지 칠하기화면에서 안 보이는 뒷면 정점까지 함께

현재 채널이 채널: Vertex Red (Shift = 지우기) 처럼 항상 표시되고, Vertex Red일 때는 레드 채널은 깊이 효과 마스크도 함께 읽습니다. 라고 함께 알려 줍니다.

마치면 외곽선 칠하기 종료 또는 Esc.

알아 둘 것​

버텍스 페인팅은 메시 에셋을 디스크에 직접 씁니다
  • Play 모드에서는 차단됩니다. Unity가 되돌려 주지 않기 때문입니다. Play를 끝내고 다시 시작하세요.
  • 같은 메시를 쓰는 다른 렌더러도 함께 바뀝니다. 인스펙터가 어떤 메시 에셋이 영향을 받는지 목록으로 경고합니다. 이 렌더러에만 적용하려면 먼저 메시를 복제해 이 렌더러에 할당한 뒤 칠하세요.
임포트된 메시는 사본이 자동 생성됩니다

원본 FBX는 건드리지 않고 편집 가능한 사본을 만들어 렌더러에 할당합니다.

칠하는 도중 Undo로 원본 메시가 복원되면 페인팅이 중단됩니다 (Undo로 '{메시}'의 원본 메시가 복원되어 칠하던 사본이 더 이상 사용되지 않습니다.). 다시 시작하면 됩니다.

칠할 수 없는 경우와 조치는 문제 해결에 정리되어 있습니다.

각진 부분에서 선이 끊길 때​

노멀 소스가 원인입니다.

소스조건
MeshNormal메시 노멀 그대로. 하드 엣지에서 선이 벌어집니다
VertexColorTS / UV8TS스무딩한 외곽선 노멀을 버텍스 컬러나 UV8에 구워 두었을 때만 유효합니다
위험
굽지 않은 메시에서 UV8TS를 고르면

오히려 각진 부분에서 선이 더 끊어집니다. 굽지 않았다면 MeshNormal을 쓰세요.

노트
VertexColorTS인데 버텍스 컬러가 없는 메시라면

메시 노멀로 내려가 동작합니다. 선이 대각선으로 통째로 밀려 나가지 않습니다.

헤어·스커트에서 선이 형태를 벗어날 때​

구나 원통에서 노멀을 옮겨 온 모델은 셰이딩용 노멀이 실제 형태와 다릅니다. 그대로 구우면 아웃라인이 메시가 아니라 옮겨 온 구를 따라갑니다.

UV8을 구울 때 노멀을 편집한 모델용으로 계산을 켜면 메시 면에서 방향을 다시 계산합니다. 셰이딩은 그대로 두고 외곽선만 메시를 따라갑니다. 기본값은 꺼짐입니다. → 메시 UV 베이크

방향을 텍스처로 직접 지정할 수도 있습니다. 지정 벡터 방향 사용을 켜고 벡터 UV와 벡터 스케일을 설정합니다. 스케일을 음수로 두면 방향이 뒤집힙니다. 끄면 이 두 항목은 무시되고 노멀 소스가 방향을 결정합니다.

선이 다른 파츠에 파묻힐 때​

깊이 바이어스로 헐 전체를 카메라 쪽으로 당깁니다. 너무 많이 당기면 선이 얼굴 앞으로 떠올라 보입니다.

몸 안쪽에 불필요한 선이 나오면 내부선 억제 오프셋으로 헐을 표면 쪽으로 가라앉힙니다.

아웃라인 색이 조명을 따라가게​

셰이딩 포함을 켜면 본체의 형태 그림자 색을 따르는 가벼운 명암 밴드가 아웃라인에 적용됩니다. 굵은 아웃라인에서 선이 조명을 따라 어두워지는 인상이 남습니다. 끄면 조명과 무관한 균일한 색을 유지합니다.

아웃라인은 본체 셰이딩을 복제하지 않습니다

아웃라인은 베이스 맵 색과 조명 응답만으로 그려집니다. 본체의 그림자 패턴·투영 그림자·깊이 효과를 선 위에 다시 그리지 않으므로 픽셀 비용이 낮습니다.

스크린톤을 선에도 찍고 싶다면 아웃라인 그림자 패턴을 따로 켜세요. → 그림자 패턴

다른 셰이더와 겹칠 때​

스텐실 설정은 다른 셰이더의 마스크와 연동할 때만 건드립니다. 기본값에서는 스텐실이 아웃라인에 영향을 주지 않습니다.

컬러 마스크가 0이면 아웃라인이 화면에 전혀 기록되지 않습니다. 기본값 15가 RGBA 전체입니다.
