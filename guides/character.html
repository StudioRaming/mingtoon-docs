캐릭터 표현

이 페이지는 페이스 셰이딩 모듈을 처음 켜 보는 분을 위한 것입니다. 코 그림자를 지우고 얼굴만 몸과 다른 음영 규칙으로 만듭니다. 약 8분 걸립니다.

이게 뭔가요​

얼굴에는 코와 눈두덩의 실제 굴곡이 있습니다. 몸과 같은 그림자 설정을 쓰면 거의 항상 지저분해집니다.

0.1.11의 페이스/헤어 셰이딩 탭은 얼굴 영역 → 얼굴 음영 → 그림자 방식 → 기준과 프록시 → 고급 순서입니다. 얼굴 프록시와 SDF는 헤어 재질에도 쓸 수 있고, 죽은 상태 표시 접힘은 제거됐습니다.

언제 쓰나요​

  • 정면 조명에서 코 그림자가 얼굴을 가를 때.
  • 앞머리 그림자를 조명과 무관하게 일정하게 유지하고 싶을 때.

30초 만에 켜 보기​

  1. 변환한 얼굴 재질을 고릅니다.
  2. 페이스 셰이딩 모듈 을 켭니다.
  3. 프록시 노멀 강도 를 1로 올립니다.
  4. 얼굴 경계 를 0.25로 올립니다. 기본값은 0입니다.

코와 눈두덩의 얼룩진 음영이 사라지면 성공입니다. 아무 변화가 없으면 문제 해결로 가세요.

페이스 셰이딩​

1단계: 얼굴 영역 지정​

마스크는 효과를 적용할 부분만 흰색으로 칠한 흑백 이미지입니다.

  1. 얼굴 영역 마스크 사용 을 켜고 얼굴 영역 마스크 에 텍스처를 넣습니다.
  2. 마스크 채널 (RGBA) 에 가중치를 넣습니다. G만 쓰려면 (0, 1, 0, 0).
  3. 얼굴이 검게 그려진 마스크라면 마스크 반전 을 켭니다.
  4. 리맵 시작 과 리맵 끝 으로 경계를 다듬습니다.

네 가지 지정 방법이 겹치면 위에서부터 하나만 쓰입니다.

순위방법켜는 항목
1텍스처 얼굴 마스크얼굴 영역 마스크 사용
2버텍스 페인트버텍스 페인트로 얼굴 영역 지정
3프록시 볼륨프록시 메시 노멀 사용
4재질 전체위 셋이 모두 꺼진 상태

마스크 강도 가 0이면 재질 전체를 얼굴로 처리합니다.

얼굴 영역을 SceneView에서 칠하기​

  1. 버텍스 페인트로 얼굴 영역 지정 을 켭니다.
  2. 얼굴 영역 페인트 시작 을 누릅니다.
  3. SceneView에서 얼굴을 칠하고, Shift를 누른 채 칠해 지웁니다.
  4. 경계는 Harden 또는 Smooth로 정리하고 저장합니다.
  5. 페인트를 쓸 때는 얼굴 영역 마스크 사용 을 끕니다.

2단계: 코 그림자 없애기​

프록시는 셰이딩 계산에만 쓰는 보이지 않는 기준 모양입니다.

  1. 프록시 메시 노멀 사용 을 켭니다.
  2. 프록시 모양 에서 평면 을 고릅니다. 목록의 첫 항목입니다.
  3. 프록시 노멀 강도 를 올립니다. 0은 원본 노멀, 1은 프록시 노멀입니다.
  4. SceneView의 얼굴 프록시 도구로 중심과 반지름을 맞춥니다.
  5. 프록시 경계 부드러움 으로 목과 헤어라인의 전환 폭을 맞춥니다.
나머지 세 모양은 실험적입니다

구 (실험적) · 원기둥 (실험적) · 캡슐 (실험적) 은 결과가 보장되지 않습니다.

3단계: 얼굴 전용 음영 경계​

  • 얼굴 경계 는 가장 자주 쓰는 조정입니다. 낮출수록 늦게 어두워집니다.
  • 기본 형태 그림자 제거 를 1로 두면 얼굴의 형태 그림자가 사라집니다.
  • 형태 그림자 섹션이 꺼져 있으면 얼굴 경계가 반영되지 않습니다.

4단계: 앞머리 그림자​

얼굴 그림자 방식 그룹의 그림자 방식 한 줄로 정합니다.

값결과쓰는 곳
몸과 동일한 리얼 그림자씬의 실시간 그림자를 그대로 받습니다얼굴을 따로 다루지 않을 때
뎁스 그림자 (얼굴 보정)얼굴에서 뎁스 그림자가 부드럽게 지도록 보조합니다애니메이션 룩
커스텀값을 직접 맞춰 둔 상태위 두 조합에서 벗어나면 자동 표시

뎁스 그림자 (얼굴 보정) 는 카메라 깊이가 있어야 보입니다. 깊이는 카메라가 재는 무엇이 얼마나 앞에 있는지 정보입니다. 확보 방법은 깊이 기반 효과에 있습니다. 실시간 그림자가 어긋나면 실제 그림자 캐스터 오프셋 으로 밀어 맞춥니다. 얼굴이 앞머리 그림자를 더 잘 받게 하려면 수신면 밀기 를 씁니다. 이 값은 뎁스 그림자 탭에 있습니다.

자주 만지는 값​

인스펙터 라벨뭘 바꾸는지추천 시작값올리면 / 내리면
프록시 노멀 강도얼굴 노멀을 프록시 곡률로 바꾸는 양10이면 원본 노멀, 1이면 코 그림자가 사라집니다
얼굴 경계얼굴에만 적용되는 음영 경계 위치0.25 (기본값 0)올리면 일찍 어두워지고, 내리면 늦게 어두워집니다
얼굴 부드러움얼굴 음영 경계의 번짐 폭기본값 그대로(0.15)올리면 부드러워지고, 내리면 또렷한 선이 됩니다
기본 형태 그림자 제거얼굴의 형태 그림자를 지우는 양01이면 코·볼 그림자가 완전히 사라집니다
프록시 경계 부드러움프록시 경계에서 얼굴 영역이 풀리는 폭기본값 그대로(0.15)올리면 목으로 이어지고, 0이면 딱 끊깁니다
아래쪽 색캐릭터 아래쪽에 물드는 색베이스보다 어두운 색흰색이면 변화 없음

캐릭터 높이 그라데이션​

캐릭터 루트 기준 높이로 아래쪽과 위쪽을 다른 색으로 물들입니다. 발밑을 어둡게 깔아 접지감을 만들 때 씁니다.

  1. 캐릭터 높이 그라데이션 을 켭니다.
  2. 아래쪽 색 을 베이스보다 조금 어둡게 잡습니다.
  3. 경계 높이 와 경계 부드러움 으로 섞이는 지점과 폭을 맞춥니다.
UV4 높이 베이크가 먼저입니다

캐릭터 전체 루트 기준 높이가 UV4에 있어야 위치가 맞습니다. 메시 단위가 아니라 캐릭터 단위입니다. → 메시 UV 베이크

흔한 문제​

마스크를 칠했는데 안 먹어요​

텍스처 마스크가 켜져 있으면 버텍스 페인트와 프록시가 무시됩니다.

프록시를 움직여도 반응이 없어요​

예전 버전에서 얼굴 노멀을 구운 재질일 수 있습니다. 밍툰 매니저의 구운 얼굴 노멀 해제 를 실행하세요.

목과 손까지 얼굴이 됐어요​

프록시 볼륨이 너무 큽니다. 반지름을 줄이거나 마스크로 지정하세요.
