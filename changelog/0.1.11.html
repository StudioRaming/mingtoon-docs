0.1.11

오픈 베타 · 2026년 9월 19일

한 줄 요약​

변환·빌드 캐시가 안정되고, Light Volume과 기본 룩·인스펙터가 정리됐습니다.

업데이트 전 확인
  • 백업: 프로젝트 전체를 백업한 뒤 설치하세요.
  • 재베이크: 구운 재질은 편집용으로 복원한 뒤 다시 구우세요.
  • 재업로드: VRChat 아바타는 다시 업로드해야 반영됩니다.
  • 룩 변화: 엣지 림, 볼륨 스페큘러, 조명 기준값, 뎁스 그림자 겹침을 확인하세요.
  • lilToon 변환 재질은 더 나은 보존을 위해 다시 변환하는 편이 안전합니다.

새 기능​

  • 엣지 림 — 윤곽을 감는 룩은 엣지 림으로 정리했습니다. 프리셋 탭의 기존 backlight 묶음은 edgerim으로 바뀌었고 에셋 GUID는 유지됩니다.
  • 프리뷰 버전 포함 — 업데이트 창에서 프리뷰 채널을 선택할 수 있습니다. 정식 버전에서 시험판을 미리 받을 때 씁니다.
  • 페이스/헤어 셰이딩 — 얼굴 영역 → 음영 → 그림자 방식 → 기준 → 고급 순서로 재배치하고 죽은 접힘을 정리했습니다.
  • 성능 부하 — 인스펙터 상단에서 업로드 기준 부하를 보고, 펼쳐 자세한 수치를 확인합니다.
  • 텍스처 카드와 레이어에서 추가·켜기·이동·삭제를 한곳에서 처리합니다. 텍스처 종류별 최대 해상도·압축 품질도 모아 적용합니다.
  • 프리셋 저장 및 관리 — 적용과 저장 버튼을 한곳에 모으고 마지막으로 적용한 프리셋을 기억합니다.

바뀐 기본값과 룩 변화​

  • 공장 룩은 엣지 림을 끈 상태로 시작합니다. 탭 프리셋에서 다시 켤 수 있습니다.
  • 볼륨 스페큘러 기본값이 Full에서 Off로 바뀌었습니다. 라이트 볼륨의 금속 같은 하이라이트가 줄어듭니다.
  • 조명 기준값을 다시 잡았습니다. 환경 색상 반영 1, 최종 최소 밝기 0.2, 엣지 림 최고 배율 0, 엣지 림 최저 배율 0.5입니다.
  • 어두워짐 반영이 0.8, 노멀 바이어스가 0.01, 화면 공간 그림자 겹침 심도가 0.5가 됐습니다. 씬 조명 영향 행은 모두 1입니다.
  • BRP 아웃라인은 볼륨 밝기를 정점에서 한 번만 읽습니다. 픽셀당 볼륨 샘플은 늘지 않습니다.

수정된 문제​

  • 텍스처를 임포트할 때 씬 전체 마스크 계획이 수동으로 돌던 문제가 고쳐졌습니다. 이제 선택된 입력만 준비합니다.
  • 마스크 입력 영수증은 수동 베이크와 업로드 전에 한 번 준비하고, 완료된 영수증을 반복 재검증하던 문제를 정리했습니다.
  • 빌드가 바꾸는 값 때문에 같은 아바타도 매번 새 셰이더 프로필을 만들던 문제가 고쳐졌습니다. 성공한 빌드 뒤 캐시를 재사용합니다.
  • lilToon 변환 순서를 변환 → 룩 프리셋 → 색감 프리셋으로 고정했습니다. 반사·백라이트·엣지 림·얼굴 데이터가 프리셋에 덮이지 않습니다.
  • 색감 프리셋이 그림자 컬러맵 UV와 베이스 알파까지 덮어쓰던 문제가 고쳐졌습니다.
  • 변환기와 색감 프리셋이 화면 공간 그림자 겹침 심도를 0으로 되돌리던 문제가 고쳐졌습니다.
  • DLL 설치 영수증이 이전 버전에 멈춰 업데이트 버튼이 잠기던 문제를 설치기가 남긴 검증 목록으로 복구합니다. bootstrap DLL은 바뀌지 않습니다.
  • VRC Light Volumes 3 월드가 공개하는 기존 v2 버퍼를 읽습니다. v3 네이티브 그림자·클러스터링·라이트별 셰이딩은 아직 쓰지 않습니다.

알려진 제한​

  • VRC Light Volume 캐스트 그림자 모양은 v2·v3 월드에서 0.1.10과 아직 다릅니다.
  • v3 버퍼 호환은 기본 간접광·포인트 데이터에만 해당합니다. v3 전용 기능은 월드가 제공해도 MingToon이 읽지 않습니다.
  • 첫 셰이더 컴파일과 첫 업로드는 캐시가 비어 더 오래 걸릴 수 있습니다.
