0.1.4

클로즈 베타 · 2026-08-05

업그레이드 시 확인할 것​

VRChat Expression Parameters 예산을 먼저 확인하세요

Modular Avatar로 비파괴 설치는 기본으로 켜져 있으며 가상 라이트와 Master Adjust에 21개 동기화 파라미터 · 154비트를 사용합니다. 기존 아바타와 합쳐 256비트를 넘으면 설치가 중단됩니다. → VRChat

0.1.3에서 숨겨졌던 페이스 셰이딩이 돌아왔습니다

페이스 셰이딩은 다시 표시되고 사용할 수 있습니다. 기존 얼굴 재질은 업데이트 후 마스크·경계·SDF 맵을 확인한 다음 직접 켜세요. → 캐릭터 표현

새 기능​

  • 하이브리드 PBR — 툰 확산광을 유지하면서 금속도·매끄러움·직접 하이라이트·환경 반사를 더하고, 툰 혼합으로 반사 모양을 정리합니다. → 문서
  • 툰 스페큘러 — PBR 전체를 켜지 않고 Isotropic 또는 머리카락용 Anisotropic 하이라이트를 추가합니다. → 문서
  • 영역 마스크 — RGBA 한 장을 네 영역으로 나눠 금속도·매끄러움·반사·툰 스페큘러를 파츠별로 보정합니다. → 문서
  • Face SDF Studio 동봉 — Base·Nose·Cheek·Lip·Eye Socket을 실시간 미리보기하고 한 장의 방향성 SDF로 굽습니다. → 문서
  • 단일 채널 얼굴 SDF — R 채널 한 장을 좌우 반전해 쓰는 Single Channel (Grayscale) 형식을 추가했습니다. → 문서
  • SceneView 버텍스·마스크 페인트 — Paint·Harden·Smooth·Hard Face, X 대칭, 연결 섬, 메시 격리와 명시적인 저장·버리기 흐름을 제공합니다. → 문서
  • MaskMaker 동봉과 MM 버튼 — 실제 마스크 슬롯에서 Selection·Gradient·Bridge Random·Brush Paint를 바로 열고 PNG를 슬롯에 적용합니다.
  • Virtual Light와 Master Adjust VRC 메뉴 — 가상광과 Highlight·Shadow·Final Output의 색상·밝기·강도를 VRC 메뉴에서 조절하고 Reset All로 기본값을 복원합니다. → 문서
  • MingToon 2D 투영 그림자 캐스터 — 안경·액세서리를 일반 렌더와 Unity 실시간 그림자는 유지한 채 MingToon 깊이 기반 효과에서 제외할 수 있습니다. → 문서

변경​

  • Face SDF Studio와 MaskMaker가 하나의 0.1.4 패키지에 포함되며 둘 다 Editor 전용이라 런타임 스크립트를 추가하지 않습니다.
  • Face SDF Studio 작업공간을 두 단계로 정리했습니다 — 준비 · 정면 UV7과 SDF 제작 · 미리보기 · 베이크만 따라가면 됩니다.
  • 아웃라인 폭 마스크를 폭 설정 가까이 이동했고 lilToon 변환 시 마스크의 Tiling/Offset도 함께 보존합니다.
  • Inspector 분류와 설명을 사용자 표시 이름으로 통일하고 별도 가이드 탭 대신 필요한 위치에 툴팁을 배치했습니다.

개선​

  • Inspector·프리셋·재질 비용 패널의 반복 계산을 줄여 여러 재질을 편집할 때의 불필요한 갱신을 줄였습니다.
  • Bake 경로의 Renderer·기능 분석과 Mask Pack readback을 재사용해 같은 데이터를 반복해서 읽지 않도록 했습니다.
  • Bake 취소·복원 안전성을 강화해 준비 중 취소, 최종 저장, 메시·블렌드셰이프·원본 재질 복원 경계를 명확히 했습니다.
  • VRC 메뉴 설치를 비파괴 방식으로 변경해 기존 Root Menu·Expression Parameters·FX를 유지하고 build clone에서만 합칩니다.

수정​

  • 페이스 셰이딩을 켜면 Base Pass가 사라지던 문제 — BRP ForwardBase와 URP UniversalForwardOnly를 복구하고 D3D11 리소스 한도를 넘기던 개발용 전체 고정 컴파일을 안전한 기본값으로 바꿨습니다.
  • 역광 얼굴에 흰 지그재그 선이 생기던 문제 — 형태 그림자 경계의 화면 미분 폭에 상한을 적용해 삼각형 경계가 셰이딩에 드러나지 않게 했습니다.
  • 얼굴 SDF 방향·좌표가 어긋나거나 전환이 한 번에 튀던 문제를 수정하고 맵 미할당 경고와 복구 경로를 추가했습니다.
  • lilToon 아웃라인 폭 마스크와 Tiling/Offset이 변환되지 않던 문제를 수정했습니다.
  • Manager 변환·저장·새로고침 후 EndLayoutGroup 오류가 나던 문제를 수정했습니다.
  • 이미션 맵이 없을 때 색상과 강도가 검게 곱해져 발광이 사라지던 문제를 수정했습니다.

문서​

  • 얼굴 SDF와 Face SDF Studio, 페이스 셰이딩, 하이브리드 PBR·툰 스페큘러·영역 마스크, VRChat Virtual Light 설치 문서를 0.1.4 기준으로 다시 작성했습니다.
