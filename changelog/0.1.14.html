0.1.14

정식 배포 · 2026년 10월 24일

이 글은 0.1.14 정식 버전의 변경 내역입니다. 이번 배포는 Built-in(BRP) 코어만 포함하며 URP 애드온은 들어 있지 않습니다.

한 줄 요약​

설치·업데이트 뒤 셰이더 준비가 에디터를 막지 않고, NDMF 업로드 막힘과 여러 렌더링 문제를 고쳤습니다.

업데이트 전 확인
  • 백업: 중요한 프로젝트는 먼저 백업하고, 별도 사본에서 업데이트하세요.
  • 재베이크: 셰이더 소스가 바뀌어 다음 베이크·업로드 때 베이크 셰이더를 새로 만듭니다. 업데이트 뒤 첫 업로드는 평소보다 오래 걸릴 수 있습니다.
  • 재업로드: 이미 올린 아바타는 다시 업로드해야 바뀐 셰이더로 그려집니다.
  • 메쉬 되돌리기: 0.1.13 변환이 체크하지 않은 메쉬를 구웠다면 Manager 맨 위 카드의 원래 메시로 되돌리기로 되돌릴 수 있습니다.

새 기능​

  • 문의용 환경 정보: Manager의 이 버튼이나 Tools/MingToon/Copy Support Info로 MingToon·Unity·파이프라인 버전, 같이 쓰는 도구 버전, 남은 복구 기록, 셰이더 준비 상태를 미리 보고 클립보드에 복사합니다. 경로·사용자 이름·프로젝트 이름은 넣지 않으며, 파일 저장이나 전송은 하지 않습니다. 마지막 변환 보고서도 같이 복사로 마지막 변환 보고서를 함께 복사할 수 있습니다.
  • 복구 기록 창: 복구 기록이 남아 VRChat 업로드나 Play가 막히면 열립니다. 재질마다 다시 복원을 누르고, 그래도 남으면 그 재질의 기록만 지울 수 있습니다. 지운 기록은 백업되며 마지막으로 지운 기록 되돌리기로 되살립니다.
  • 0.1.13 변환이 외곽선 노멀(UV8)만 구운 메쉬가 있으면 Manager 맨 위에 카드가 뜹니다. 메쉬를 골라 원래 메시로 되돌리기를 누르면 원래 메쉬로 돌아가고, 그 재질의 노멀 소스는 MeshNormal로 돌아갑니다. 구운 .asset 파일은 지우지 않습니다.
  • 업데이트 창(StudioRaming/MingToon/Update)에 프리뷰 버전 포함 체크박스가 다시 생겼습니다. 정식 버전에서 켜면 프리뷰 버전도 확인합니다.

바뀐 기본값과 룩 변화​

  • 설치와 업데이트 뒤의 셰이더 준비가 백그라운드에서 진행됩니다. 진행 상황과 취소는 Unity 창 아래쪽 상태 표시줄과 Manager 맨 위에 나옵니다. 준비가 끝나기 전에 처음 그리는 머티리얼은 컴파일되는 동안 잠시 하늘색으로 보입니다.
  • 글리터 입자 위치가 반 칸 옮겨집니다. 입자가 격자선에서 잘리던 문제를 고치면서 배치가 바뀌었고, 설정 값은 그대로입니다.
  • 실시간 디렉셔널 라이트가 없는 장면(베이크 전용 월드, 픽셀 라이트를 끈 미러)에서 외곽선 렌더 적용이 몸통과 같은 방향으로 명암을 받습니다.
  • SSSSS (실험적) 모듈을 삭제했습니다. 켜져 있던 재질은 업데이트 때 값이 자동으로 정리되며, 다른 모듈의 룩은 그대로입니다.
  • 팩토리 프리셋 Soft1(그림자 반사광)은 그림자 반사광 마스크 사용을 끄고, RealSkin1(노멀 맵)은 삭제했습니다. 이미 적용한 재질은 그대로입니다.
  • 변환은 이제 체크한 메쉬만 굽습니다. 모서리 노멀이 갈라진 메쉬는 Manager 알림의 버튼으로 직접 굽습니다.
  • 편집 중 미리 컴파일하는 폭을 표면 스택 2단, 노멀 맵 2장, 맷캡 2장까지로 줄였습니다. 그 이상 쓰는 재질은 처음 열 때 컴파일을 한 번 더 기다립니다. 업로드·빌드 결과는 같습니다.

수정된 문제​

VRChat 업로드와 빌드​

  • NDMF와 함께 쓸 때 업로드가 "Material recovery is incomplete before the VRChat build"로 계속 막히던 문제를 고쳤습니다. 이미 막힌 프로젝트는 업데이트 뒤 첫 업로드에서 경고 한 줄과 함께 풀립니다.
  • 빌드 시 깊이 라이트 제거하기를 끈 아바타가 MMD 월드에서 표정이 움직이지 않던 문제를 고쳤습니다.
  • 스크립트를 다시 컴파일할 때 VRCFury Test Copy가 쓰는 깊이 라이트 FX 컨트롤러가 지워지던 문제를 고쳤습니다.
  • 업로드 정리 뒤에 얼굴 노멀 베이크와 UV 라우터 키워드가 다시 켜지던 문제를 고쳤습니다.
  • 다른 최적화 도구와 함께 빌드할 때, 빌드가 지울 MingToon 임시 사본의 복원 경고가 뜨던 문제를 고쳤습니다.
  • 에셋 파일이 없는 MingToon 머티리얼이 있으면 텍스처 최적화를 켠 수동 베이크가 빈 오류로 멈추던 문제를 고쳤습니다. 이제 머티리얼 이름과 함께 .mat 에셋으로 저장하라는 안내를 보여 줍니다.
  • Ming Light Controller 0.1.5(별도 배포) 디버그 모드의 노말맵 그림자 토글이 수동 베이크한 머티리얼에서도 작동합니다.
  • 업로드용 셰이더의 변형 수와 명령 수를 줄였습니다. 수동 베이크 방식이 FastUpload일 때도 같이 적용되며, 룩은 같습니다.

변환​

  • 대상 셰이더를 쓸 수 없으면 Manager 변환, 설정 마법사, 오래된 재질 다시 변환이 아무것도 바꾸기 전에 멈추고 이유를 알립니다. 전에는 변환 뒤 아바타가 마젠타로 보였습니다.
  • lilToon 셰이더가 없는 프로젝트에서 아웃라인 폭 마스크 타일링과 림 광원측 강조가 빠지던 문제를 고쳤습니다. 굴절·퍼·보석 모드는 변환 보고서에 "지원 안 됨"으로 남깁니다.
  • 컷아웃 재질을 처음 변환할 때 쓰이지 않을 그림자 변형을 컴파일하지 않습니다.
  • 프리셋이 프로젝트에 없는 텍스처를 가리키면 프리셋 이름과 프로퍼티 이름이 든 경고를 남깁니다.

셰이더 준비(워밍업)​

  • 준비 중 셰이더가 컴파일 시간 초과로 분홍색이 되면 자동으로 다시 가져와 한 번 더 시도합니다.
  • 준비가 멈추거나 실패해도 남은 변형을 한꺼번에 컴파일하느라 에디터가 오래 멈추지 않습니다.
  • Unity 창이 다른 창 뒤에 있으면 첫 설치 준비가 시작되지 않던 문제를 고쳤습니다.
  • 첫 설치 준비 중에 Unity를 닫으면 MingToon 셰이더 준비 중 창이 뜹니다. 그래도 닫기는 남은 준비를 다음에 열 때 이어서 하고, 계속 준비는 닫기를 취소합니다.
  • Windows 에디터(D3D11)에서 편집용 셰이더를 최적화 단계 없이 컴파일해 컴파일 시간을 줄였습니다. 측정한 PC(Unity 2022.3)에서 가장 무거운 변형의 첫 그리기가 201초에서 40초로 줄었습니다. VRChat 업로드와 빌드용 셰이더는 지금처럼 최적화합니다.
  • 0.1.13에서 변환한 머티리얼이 있는 씬을 업데이트 뒤 처음 열 때, 준비가 끝난 뒤 셰이더를 따로 컴파일하던 문제를 고쳤습니다.

렌더링​

  • Shadowmask 혼합 조명 씬에서 일부 그림자 변형이 컴파일되지 않거나 실시간 그림자를 엉뚱한 위치에서 읽던 문제를 고쳤습니다.
  • 투영 그림자 경계 페더 사용이 베이크 그림자와 그림자 거리 페이드를 흐리게 만들던 문제를 고쳤습니다.
  • 경계 폭과 경계 번짐을 크게 올리면 캐스트 그림자 경계색이 밝은 면 전체를 덮던 문제를 고쳤습니다.
  • 카메라가 큰 면에 붙으면 깊이 그림자·SSAO 사용·깊이 림라이트가 잘린 가장자리에서 틀어지던 문제를 고쳤습니다.
  • 데칼 왼쪽에만 표시·오른쪽에만 표시에 각도나 회전을 주면 숨김 쪽에 띠가 보이던 문제를 고쳤습니다.
  • 머리를 크게 돌린 순간 재질이 바뀌면 얼굴 음영 방향이 90도 틀어지던 문제를 고쳤습니다.
  • 포인트·스폿 라이트에서 멀리 있을 뿐인 면을 그림자로 계산해 깊이 림라이트가 약해지고 그림자 반사광 안쪽에 띠가 생기던 문제를 고쳤습니다.
  • 내부 경계 마스크를 켠 재질에서 얇은 내부 경계선의 마스크가 흔들리거나 흐리게 읽히던 문제를 고쳤습니다.
  • 카메라 위치에 둔 스폿 라이트의 그림자에서 반투명 재질이 그림자를 드리우거나, 얼굴 자체 캐스트 사용을 꺼도 얼굴 그림자가 남던 문제를 고쳤습니다.

설치와 업데이트​

  • 새 설치에서 백신 등이 파일을 잠깐 잡고 있으면 "설치를 중단했습니다"가 뜨던 문제와, 설치 직후 잘못된 파일 교체 경고를 고쳤습니다.
  • 설치 기록 저장이 한 번 실패한 뒤 설치나 업데이트를 다시 시작할 수 없던 문제를 고쳤습니다.
  • 최신 설치기 받기 창의 다시 시도 버튼이 같은 오류로 계속 실패하던 문제를 고쳤습니다.
  • 컴파일 오류가 있는 프로젝트에서 설치기가 자동 설치 기회를 헛되이 쓰던 문제를 고쳤습니다. 이제 상태 오류를 보이고 기다립니다.

표시​

  • 영어 인스펙터에서 깊이 림·엣지 림의 역광 폭 부스트가 역광 강도 부스트와 같은 이름으로 보이던 문제를 고쳤습니다.
  • Apply Stack Distance Fade Defaults 메뉴 실행을 Ctrl+Z 한 번으로 되돌리고, 바뀐 재질만 저장합니다.
  • Manager와 얼굴 탭이 별도 제품인 Face SDF Maker를 찾아 바로 엽니다. 옛 Face SDF Studio만 있으면 예전처럼 그 창을 엽니다.

알려진 제한​

  • Light Volumes 월드에서 외곽선 렌더 적용의 명암 방향은 볼륨이 아니라 라이트 프로브의 주 방향을 따릅니다. 볼륨에서는 색과 밝기만 읽습니다. 성능 때문에 정한 동작입니다.
  • 이 수정 전에 남은 빈 설치 시도 폴더(Library/StudioRaming/MingToonVpmUpdates/ 아래 intent.json이 없는 폴더)는 자동으로 지워지지 않습니다.
  • 이번 배포에는 URP 애드온이 없습니다.
