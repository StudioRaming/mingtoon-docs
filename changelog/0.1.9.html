0.1.9

오픈 베타 · 2026년 9월 9일

0.1.9​

이번 업데이트는 변환할 룩과 색감 선택, Manager 작업 흐름, 베이크 안정성과 생성 텍스처 최적화에 중점을 두었습니다.

Manager와 룩·색감 선택​

  • 세 탭으로 작업 정리 — 시작하기, 룩·베이크, 최적화로 구성했습니다. 시작하기에서 변환 대상을 지정하고 변환하며, 룩·베이크에서 기존 MingToon 재질의 룩과 베이크를 조정합니다. 최적화에서는 자동 처리와 텍스처 해상도 상한을 설정합니다. 상단의 재질 선택과 대상 범위는 세 탭에서 공통으로 사용합니다.

  • 룩과 색감을 따로 선택 — 룩 프리셋 아래에 색감 프리셋을 추가했습니다. 기본값은 뉴트럴입니다. 먼저 룩을 적용한 뒤 선택한 색감을 적용하며, 기존의 그림자 색상 덮어쓰기 체크박스는 이 선택으로 대체했습니다.

  • 기존값 사용 — 원본에서 변환한 색상을 유지하려면 색감 프리셋에서 기존값 사용을 선택하세요. 이전 설정에서 그림자 색상 보존을 선택했다면 이 옵션으로 이어집니다. 별도 색감 프리셋을 선택하면 해당 색상은 선택한 프리셋의 값으로 바뀝니다.

  • 그림자 밴드 보존 — 변환할 때 원본에서 가져온 그림자 밴드의 강도·경계·너비·합성 설정이 룩 프리셋 적용으로 덮이지 않도록 했습니다. 색감 프리셋 선택과 밴드 설정 보존을 구분합니다.

  • 현재 MingToon 재질에 다시 적용 — 변환할 재질이 없고 편집용 MingToon 재질만 있으면, 시작하기에서 선택한 룩과 색감을 해당 캐릭터의 MingToon 재질 전체에 다시 적용할 수 있습니다. 적용 전 덮어쓰기 범위를 안내하며, 적용 결과는 Undo로 되돌릴 수 있습니다.

  • 메뉴와 컴포넌트 정리 — 제품 메뉴에서 개발용 진단 항목을 숨기고, 직접 추가하는 제품 컴포넌트를 MingToon Manager와 Ming Light Controller 중심으로 정리했습니다. 프로젝트 검증 메뉴는 유지합니다.

lilToon 변환​

  • 1·2차 그림자 색감과 강도 — 원본 그림자의 강도, 경계와 부드러움을 MingToon 설정에 반영합니다. 두 번째 그림자의 알파와 전체 그림자 강도를 함께 반영해, 강도가 0인데 두 번째 그림자가 남거나 중간 알파에서 지나치게 옅어지는 문제를 수정했습니다.
  • 보조 그림자 색상 — 그림자 색상 통합이 꺼져 있어도 다른 그림자 항목이 흰색으로 남지 않도록 원본 1차 그림자 색상을 전달합니다. 원본 2차 그림자의 알파가 0이면 2차 밴드를 켜지 않습니다.
  • 가능한 재질부터 변환 — 일부 재질의 변환이 실패해도 나머지 재질은 계속 처리합니다. 실패한 슬롯은 원본을 유지하고 성공한 변환 결과는 남깁니다. 선택한 룩이나 색감 등 후처리에서 발생한 문제도 결과에 표시해 완료·제외·실패를 구분할 수 있습니다.
  • 투명 재질 — 일반 투명 재질에서 보이는 표면의 컷오프와 깊이 처리용 컷오프를 구분하고, 원본의 애니메이션 컷오프를 유지하도록 보강했습니다. 굴절 재질은 기존의 별도 변환 경로를 사용합니다.

그림자 계산 방식이 서로 다르므로 모든 lilToon 룩이 픽셀 단위로 같아지는 것은 아닙니다. 변환 후 조명과 마스크를 포함한 실제 모습도 확인해 주세요.

베이크·변환 안정성​

  • VRChat SDK 빌드 후 편집용 재질에 임시 베이크 셰이더가 남을 수 있던 문제를 수정했습니다.
  • 메인 텍스처가 비어 있는 스트랩 등 일부 알파 마스크 재질에서, 베이크 후 컷아웃 경계가 달라지던 문제를 수정했습니다.
  • 베이크 후 재질이 하얗게 변하던 문제 — 꺼져 있던 이미션이 베이크 과정에서 활성화되어 재질 전체를 하얗게 덮을 수 있던 문제를 수정했습니다. 이미션의 강도나 색상을 애니메이션으로 제어하더라도 각 재질의 켜짐·꺼짐 상태를 유지합니다.
  • 이미션이 꺼지거나 상태가 달라지던 문제 — 이미션과 두 번째 이미션 레이어의 사용 상태가 베이크 결과에 올바르게 반영되도록 수정했습니다. 사용 중인 레이어는 유지하고, 꺼져 있는 레이어는 임의로 켜지지 않도록 했습니다.
  • Glitter가 다른 재질까지 적용되던 문제 — 일부 재질에 Glitter를 사용하는 아바타를 변환·베이크할 때, Glitter를 끈 재질까지 효과가 적용될 수 있던 문제를 수정했습니다. 각 재질의 Glitter 사용 상태를 따릅니다.
  • Glitter 마스킹 안정성 — 수동 베이크 후 마스크가 적용되지 않거나, 마스크를 나중에 켰을 때 영역 제한이 작동하지 않을 수 있던 문제를 수정했습니다. 마스크 반전과 컬러 마스크도 유지합니다.
  • 프리셋 선택 적용 — 변환 직후 또는 프리셋을 다시 적용할 때, 현재 사용 중인 모듈과 관련 설정을 프리셋의 꺼짐 값이 덮어쓰지 않도록 개선했습니다. 프리셋의 모든 값을 재질 전체에 일괄 덮어쓰지 않고, 유지해야 할 설정을 보존하며 룩을 적용합니다.

성능 및 기타 개선​

  • 재질별 고정 설정을 활용하는 베이크 최적화를 유지하고, 결과에 영향을 주지 않는 불필요한 셰이더 변형을 줄였습니다.
  • 셰이더 중복 계산 정리 — 조명 방향과 전체 색상 조정에서 반복되는 계산을 정리하고, 사용하지 않는 텍스처 레이어의 불필요한 처리를 줄였습니다. 기존 룩과 애니메이션 제어를 유지하면서 렌더링 부담을 낮추는 데 중점을 두었습니다.
  • 베이크·업로드 준비 처리 개선 — 재질과 키워드 상태를 확인하고 저장하는 과정의 중복 작업을 줄였습니다. 처리 시간의 개선 폭은 아바타 구성, 사용 기능과 셰이더 캐시 상태에 따라 달라집니다.
  • 원거리 MatCap 표시 유지 — 카메라에서 멀어졌을 때 MatCap으로 만든 색상이나 발광이 사라지던 문제를 수정했습니다.
  • 저장·복구 확인 보강 — 베이크 중 저장이 실패하거나 작업이 중단됐을 때, 재질 저장과 복구 상태를 더 정확하게 확인하도록 개선했습니다.

텍스처 최적화​

  • 합친 결과의 해상도 제한 — 텍스처 레이어와 노멀 레이어를 합치고 마스크를 묶은 뒤, 생성 결과에 해상도 상한을 적용합니다. 일반 마스크와 재질 편집 중 생성하는 마스크 팩 모두 마스크 해상도 설정을 따릅니다.
  • 원본 임포트 설정 보존 — 해상도 제한과 압축을 위해 원본 텍스처의 최대 크기나 압축 설정을 바꾸지 않습니다. 제한 없음은 합친 결과의 크기를 유지합니다.
  • 생성 결과의 압축과 저장 — PC용으로 합친 색상·노멀 텍스처에는 압축을 적용합니다. 생성 마스크는 채널 값을 보존하도록 무손실로 저장하고, 마스크 해상도 상한으로 크기를 줄입니다.
  • 캐시 재사용과 복구 — 같은 설정의 생성 결과를 다시 사용할 때 불필요한 재작성과 임포트를 줄였습니다. 설정이나 출력 크기가 바뀌면 기존 캐시를 그대로 사용하지 않습니다. 경로에 출처가 확인되지 않은 파일이 있으면 임의로 덮어쓰거나 삭제하지 않습니다.
  • 새 설치의 생성 폴더 — 패키지로 처음 설치해 Assets/StudioRaming 폴더가 없는 프로젝트에서도 마스크 생성 폴더를 만들 수 있도록 수정했습니다.

자동 빌드·업로드에서 텍스처를 다시 만들려면 최적화 탭의 빌드/업로드 시 자동 최적화와 업로드 시에도 텍스처 재작성 설정을 함께 확인하세요. 용량 감소율과 처리 시간은 실제 아바타 검증 후 확정하며, 이번 문서에 아직 수치로 제시하지 않습니다.

애니메이션 판정과 편집 안정성​

  • Animator 분석 중 예외 — 잘못되거나 특이한 Animator 상태를 읽는 중 예외가 발생하면 판정 실패를 알리고 보수적으로 처리하도록 보강했습니다. 분석이 불완전한 상태에서 애니메이션으로 바뀌는 값을 고정해 버리지 않도록 합니다.
  • Scene 뷰 깊이 표시 복구 — 현재 Scene 뷰에 필요한 깊이 표시를 다시 요청하도록 개선했습니다. Play Mode와 깊이 표시 억제 설정은 유지합니다.

Ming Light Controller 0.1.2​

  • 소수 Int 값과 최종 예산 게이트 — 설치된 SDK가 허용하는 경우 0.5와 같은 소수 Int 기본값을 보존하되, 정수 소비자가 값을 내림하거나 제한할 수 있음을 안내합니다. 최종 동기화 예산을 넘으면 초과 비트 수와 줄이는 방법을 명확히 안내하고 빌드를 막습니다.
  • VRCFury 경계 — 완전한 VRCFury 압축 협업과 압축 후 Inspector 미리보기는 다음 버전으로 미룹니다. 이 문서는 압축 전 예상치와 빌드에서 다시 확인해야 하는 경계를 구분합니다.

MLC는 별도 패키지입니다. MingToon 0.1.9와 함께 사용하려면 MLC도 0.1.2로 업데이트해 주세요. 지원 대상은 Unity 2021.3 및 2022.3이며, VRChat 업로드는 설치된 SDK가 요구하는 Unity 버전에서 진행해야 합니다.

업데이트 후 확인할 점​

  • 이미 만든 베이크 재질에 수정 사항을 반영하려면 편집용 재질로 복원한 뒤 다시 베이크하세요. VRChat에 업로드한 아바타에는 재업로드가 필요합니다.
  • 흰색 표시를 피하려고 이미션 강도를 임시로 0으로 바꿨다면, 업데이트 후 원하는 값으로 조정한 뒤 다시 베이크하세요.
  • 이전 버전의 프리셋 적용으로 이미 바뀐 값이 자동으로 복구되지는 않습니다. 필요한 설정을 다시 조정하거나 원본 재질에서 다시 변환한 뒤 결과를 확인하세요.
