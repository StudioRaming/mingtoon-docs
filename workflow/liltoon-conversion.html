lilToon 재질 변환

이 페이지는 lilToon 아바타를 MingToon으로 옮기는 분을 위한 것입니다. 변환이 무엇을 옮기고 무엇을 못 옮기는지, 옮긴 뒤 무엇을 보는지 다룹니다. 약 15분 걸립니다.

이게 뭔가요​

변환은 원본 재질을 읽어 편집용 MingToon 재질을 새로 만듭니다. 원본 재질 파일은 지워지지 않고 그대로 남습니다. Renderer의 슬롯만 새 재질로 바뀝니다.

변환이 옮기는 것:

  • 베이스 색과 텍스처, HSVG, 노멀, 이미션, 오클루전, PBR, 맷캡
  • 2nd·3rd 레이어와 마스크
  • 반사 설정, lilToon 역광, 엣지 림, 얼굴 전용 데이터
  • 스텐실, 렌더 큐, 표시할 면, 표면 모드 같은 렌더 상태

소스에 실제 데이터가 있으면 PBR·이미션·아웃라인·알파 마스크 모듈도 함께 켭니다. 옮길 수 없는 기능은 손실 보고서에 lossy 또는 unsupported로 남습니다.

룩이 똑같아지지는 않습니다

두 셰이더의 계산식과 기능의 뜻이 다릅니다. 변환은 출발점을 만드는 도구이고 복제 도구가 아닙니다.

언제 쓰나요​

  • lilToon으로 만든 아바타를 통째로 옮길 때
  • 셰이더 파일이 없어 분홍색이 된 아바타를 살릴 때
  • 일부 재질만 먼저 옮겨 결과를 비교해 볼 때

30초 만에 켜 보기​

  1. 아바타 루트의 MingToon Manager를 고릅니다.
  2. 시작하기 탭의 2. 룩 선택 → 변환을 찾습니다.
  3. 하위 재질을 MingToon으로 변환을 누릅니다.

결과 줄에 변환된 슬롯 개수가 뜨면 성공입니다. 0개라면 변환되지 않는 슬롯을 보세요.

켜는 법​

  1. Manager를 아바타 루트에 붙입니다. 의상만 옮길 때도 루트에 둡니다.
  2. 1. 얼굴 · 스킨 대상 지정에서 얼굴과 맨살 메시를 지정합니다.
  3. 2. 룩 선택 → 변환에서 변환 시 룩 프리셋을 고릅니다.
  4. 같은 자리에서 색감 프리셋을 고릅니다.
  5. 원본 색을 지키려면 색감에서 기존값 사용을 고릅니다.
  6. 같은 카드의 하위 재질을 MingToon으로 변환을 누릅니다.
  7. 결과의 성공·제외·실패·손실 항목을 읽습니다.

이미 MingToon 재질이 있다면 현재 MingToon 재질에 적용하기를 씁니다.

적용 순서는 변환 → 룩 → 색감입니다

먼저 원본을 변환하고, 룩 프리셋을 적용한 뒤, 색감 프리셋을 마지막에 씁니다. 원본 반사·백라이트·엣지 림·얼굴 데이터는 소스 재적용 단계에서 보존됩니다. 기존값 사용은 색감 프리셋을 적용하지 않고 원본 색을 유지합니다.

일부 재질이 실패해도 나머지는 계속 처리합니다. 성공한 재질이 있다는 것을 전체 성공으로 읽지 마세요. 실패한 슬롯은 원본 재질을 그대로 달고 남습니다.

Missing Shader 재질 복구 변환​

셰이더 파일이 없어 분홍색이 된 재질도 변환할 수 있습니다. 저장된 프로퍼티 이름과 값을 읽어 NiloToon·lilToon·Unity Standard 계열을 판별합니다. 판별 근거는 변환 미리보기에 표시됩니다.

이 경로에서는 원래 셰이더의 숨은 기본값과 키워드 뜻을 전부 살릴 수 없습니다. 변환 후 아래 네 가지를 직접 확인하세요.

  1. 표면 모드와 알파 컷오프
  2. 표시할 면과 렌더 큐, 스텐실
  3. 이미션·PBR·아웃라인 모듈이 켜졌는지
  4. 마스크 채널과 반전

변환 후 확인​

  • Renderer가 새 MingToon 재질을 쓰고 원본 에셋도 남아 있는가
  • 불투명·컷아웃·반투명·투명의 결과가 원본과 같은가
  • 렌더 큐, 표시할 면, 스텐실이 의도대로인가
  • 텍스처의 타일링·오프셋, 채널, 반전이 같은가
  • 필요한 재질에서 PBR·이미션·아웃라인·알파 마스크가 켜졌는가
  • 얼굴과 피부 역할, 얼굴 프록시가 맞는가

손실 보고서를 읽는 법은 변환 보고서 읽기에 있습니다.

자주 만지는 값​

인스펙터 라벨뭘 바꾸는지추천 시작값올리면 / 내리면
변환 시 룩 프리셋변환 직후 들어갈 룩 전체베이직툰 HighLow로 바꾸면 깊이 효과가 꺼진 가벼운 룩이 됩니다
색감 프리셋룩 위에 얹는 색조기존값 사용다른 프리셋을 고르면 원본 색 대신 그 톤이 들어갑니다
적용 안 함룩 프리셋 자체를 건너뛰기고르지 않기고르면 원본에서 읽은 값만 남아 밋밋해질 수 있습니다
아웃라인 스무스 노멀 (UV8)각진 부분의 외곽선 연결켜기끄면 모서리에서 선이 갈라집니다
이미 사용 중인 UV 채널 덮어쓰기이미 쓰는 UV 채널을 다시 쓸지끄기켜면 남의 데이터를 덮어써 룩이 깨질 수 있습니다

흔한 문제​

변환 버튼을 눌러도 아무 일이 없어요​

읽을 수 있는 슬롯이 전부 변환 제외 대상입니다. 목록은 변환되지 않는 슬롯에 있습니다.

얼굴이 몸과 똑같이 셰이딩돼요​

얼굴 슬롯이 Regular로 남아 있습니다. 지정 방법은 얼굴 · 피부 지정에 있습니다.

되돌렸더니 방금 고친 값도 사라졌어요​

**변환 되돌리기 (MingToon 이전 재질로)**는 한 Undo 단계입니다. 현재 슬롯만 원본으로 돌리며, 만들어진 변환 재질과 메시 베이크는 지우지 않습니다.
