MingToon Manager

아바타의 재질 선택, 룩, 메시 준비와 업로드 설정을 모아 둔 컴포넌트입니다. 변환 후에도 아바타 루트에 둡니다. 처음 변환은 설정 마법사에서 시작하세요.

30초 만에 켜 보기​

  1. Hierarchy에서 아바타 루트를 선택합니다.
  2. GameObject > MingToon > Add MingToon Manager를 누릅니다. 설정 마법사가 열립니다.
  3. 마법사의 안내에 따라 원본을 보관하고 MingToon 복사본을 만듭니다.
  4. 복사본 루트의 Manager에서 시작 탭과 슬롯 수를 확인합니다.

시작 탭과 상태​

탭은 시작 · 꾸미기 · 가볍게입니다. 탭 아래에는 모두 · 얼굴 · 피부 · 얼굴·피부 · 공통 · 얼굴 제외 재질 선택 버튼이 있습니다. 원하는 대상을 선택한 뒤 재질 인스펙터에서 함께 편집할 수 있습니다.

업데이트 행에는 알림 설정, 패치노트와 확인·업데이트 진입점이 있습니다. 시작 카드의 MingToon 슬롯 N · 바꿀 수 있는 슬롯 N은 현재 대상의 슬롯 수입니다. 바꿀 수 있는 슬롯은 변환 가능한 원본 슬롯이며, 모든 비MingToon 재질을 뜻하지 않습니다.

MingToon 슬롯이 있으면 현재 부하가 나타납니다. 재질 설정 기반 추정치이며 GPU 사용률·FPS 측정값이 아닙니다. 변경 후 재계산에는 잠시 시간이 걸릴 수 있습니다.

시작 카드 아래에는 게임 안에서 조명 바꾸기, 업로드 준비, 기존 대상 변환 · 복구 접힘이 있습니다. 이미 변환한 아바타에 새 의상·소품이 있으면 추가 대상 카드에서 해당 슬롯을 변환할 수 있습니다. 의상 구성이 바뀌면 하위 렌더러 다시 찾기로 범위를 갱신하세요.

시작 — 변환과 복구​

처음 작업은 복사본 만들기로 마법사를 열어 진행합니다. 기존 대상을 다룰 때는 기존 대상 변환 · 복구를 펼칩니다. 상세 절차와 변환 한계는 lilToon 재질 변환을 참고하세요.

변환되지 않는 슬롯​

파티클·VFX, 굴절·보석, 퍼·쉘, 오디오 반응이나 특수 보조 패스는 그대로 남을 수 있습니다. 변환 결과와 건너뛴 이유를 확인하세요. 바꿀 수 있는 슬롯이 0이어도 모든 재질이 MingToon이라는 뜻은 아닙니다.

얼굴 · 피부 지정​

페이스 렌더러와 스킨 렌더러를 지정하고 역할 표시를 적용합니다. 씬 선택으로 추가로 선택한 Renderer를 목록에 넣을 수 있습니다. 슬롯별 역할은 Auto · Face · Skin · Regular입니다. 피부 Renderer에 옷이나 머리카락 슬롯이 섞였다면 그 슬롯은 Regular로 지정하세요.

Auto는 이름으로 얼굴을 추측하지 않습니다. 원본 재질의 얼굴 플래그가 없는 경우 역할을 직접 지정하세요.

변환 시 룩 프리셋​

룩 프리셋 목록에서 공장 프리셋과 저장한 룩을 함께 고릅니다. Low 프리셋도 목록의 별도 항목입니다. 원하는 항목을 고르고 적용하세요. 색감은 룩 다음에 정합니다. 기존값 사용은 원본의 보호되는 색·그림자 값을 유지하면서 선택한 룩을 적용합니다. 원본과 픽셀 단위로 같아진다는 뜻은 아닙니다.

대상 · 도구​

활성 탭 아래의 대상 · 도구에서 대상 범위와 Renderer 목록, 역할 지정 등 공통 작업을 확인합니다. 비활성 자식 포함은 꺼 둔 의상도 범위에 넣습니다. 의상을 교체한 뒤에는 Renderer를 다시 찾고 슬롯과 역할을 확인하세요.

꾸미기 — 룩과 메시 준비​

룩 카드에서 프리셋을 적용하고 머티리얼 세부 설정에서 재질별로 조정합니다. 윤곽선 · 얼굴 · 높이 준비를 펼치면 메시 채널 준비·다시 굽기를 진행할 수 있습니다. 사용 중인 UV 채널은 이미 사용 중인 UV 채널 덮어쓰기를 켜지 않으면 보호됩니다.

얼굴 노멀은 편집 중 프록시로 조절하고 업로드용 복사본에서 굽습니다. 예전 베이크 때문에 프록시가 반영되지 않으면 구운 얼굴 노멀 해제를 확인하세요. 채널과 충돌 규칙은 메시 UV 베이크에 있습니다.

**변환 되돌리기 (MingToon 이전 재질로)**와 변환 복구는 기록된 대상에만 적용합니다. 되돌리기 전에 현재 슬롯과 마지막 변환 결과를 확인하세요.

가볍게 — 최적화와 업로드​

업로드 자동 처리와 텍스처·애니메이션 보존 설정을 확인하는 탭입니다. 동작 범위와 복구는 빌드 시 자동 최적화를 참고하세요. 텍스처 해상도 상한은 이 Unity 에디터의 프로젝트들에 공유되는 설정이므로 적용 범위를 확인하세요. Quest(Android)는 현재 지원하지 않습니다.

VRChat 업로드 준비​

Manager는 표현 메뉴·파라미터·FX를 직접 설치하지 않습니다. 게임 안 조절은 별도 Ming Light Controller 연동에서 준비합니다.

  1. 하위 렌더러 다시 찾기로 현재 Renderer 범위를 확인합니다.
  2. 슬롯 역할과 마지막 변환 결과·건너뛴 재질을 확인합니다.
  3. 프로젝트 검증과 SDK Builder의 경고를 확인하고 업로드합니다.
  4. 클라이언트에서 본인 화면·미러·Photo Camera를 각각 확인합니다.

내보내기 · 검증​

업로드 준비 점검​

StudioRaming > MingToon > Validate Project로 프로젝트 조건을 확인합니다. 검증 코드는 프로젝트 점검이며 아바타 외형·애니메이션·실제 클라이언트 수용을 대신하지 않습니다. 슬롯 수, 변환 결과와 build clone의 컴포넌트 정리도 각각 확인하세요.

흔한 문제​

얼굴이 몸과 같은 음영으로 보이면 Face 역할과 얼굴 재질 설정을 확인하세요. 새 옷이 범위에서 빠졌다면 Renderer 목록을 갱신하고 추가 대상 카드를 확인하세요. Manager를 제거하면 캐시된 Renderer 범위가 사라지므로 업로드 전 범위를 다시 준비해야 합니다.
