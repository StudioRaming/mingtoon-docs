문제 해결

증상으로 찾으세요. 대부분은 "상위 값이 0이거나 꺼져 있으면 하위가 전부 무시된다" 는 구조 때문에 생깁니다.

아무 값도 안 먹힌다​

위에서부터 확인하세요.

  1. 전체 효과 — 인스펙터 맨 위의 마스터 스위치. 꺼져 있으면 아래 섹션 전체가 비활성이고 이 섹션은 전체 효과가 꺼져 있어 비활성 상태입니다. 가 표시됩니다.
  2. 섹션 마스터 토글 — 각 섹션에도 자체 토글이 있습니다. 꺼져 있으면 빠른 설정에 (모듈 꺼짐)이 붙습니다.
  3. 상위 값 — 아래 표.

2022.3.22f1은 정상 지원 버전이라 아무 지적도 나오지 않습니다. → Validator 코드 전체

내부 2D 경계만 사라졌다​

원인조치
Inner Edge 외곽선에 적용이 켜져 있고 버텍스 컬러가 검음토글을 끄거나 압력 소스를 바꿈
표면 모드가 투명깊이 기록 모드로 변경
카메라 깊이 없음위 항목 참고

노멀 아웃라인은 카메라 깊이 없이도 동작합니다. 노멀 아웃라인은 보이는데 내부 2D 경계만 없다면 깊이 문제입니다.

아웃라인을 찾을 수 없다​

내부 2D 경계는 아웃라인 그룹이 아니라 깊이 기반 효과 그룹에 있습니다. 화면 깊이를 읽기 때문입니다.

노멀 아웃라인이 통째로 사라졌다​

원인조치
버텍스 컬러가 검게 임포트된 메시에서 압력 소스가 VertexRed압력 소스를 바꾸거나 버텍스 컬러 확인
헐 압력 대비가 0압력이 완전히 무시됨
컬러 마스크가 015(RGBA 전체)로

아웃라인이 각진 부분에서 끊긴다​

노멀 소스가 VertexColorTS 또는 UV8TS인데 스무딩한 외곽선 노멀을 굽지 않은 메시입니다. MeshNormal로 바꾸세요.

씬 뷰에서 아웃라인 두께를 칠할 수 없다​

인스펙터가 말하는 것조치
Pressure Source가 Vertex Alpha 또는 Vertex Red여야 합니다.Vertex Alpha로 전환 버튼 사용
현재 선택 항목 아래에 이 머티리얼을 사용하는 렌더러가 없습니다.밍툰 매니저(또는 그 아래 오브젝트)를 선택
버텍스 페인팅은 머티리얼을 하나만 선택했을 때 사용할 수 있습니다.하나만 선택
버텍스 페인팅은 ... Play 모드를 끝내도 Unity가 되돌려 주지 않습니다.Play 모드 종료 후 다시 시작
칠할 수 있는 메시가 없습니다.렌더러에 메시가 있는지, 그 메시가 이 머티리얼이 그리는 서브메시를 포함하는지 확인
렌더러에 메시가 없습니다.Mesh Filter 또는 Skinned Mesh Renderer의 Mesh 슬롯에 메시 할당
렌더러에 Mesh Filter가 없어...같은 오브젝트에 Mesh Filter 추가, 또는 Skinned Mesh Renderer가 있는 오브젝트 선택
메시 '{...}'에서 정점을 읽지 못해...모델을 다시 임포트
메시 '{...}'은(는) 런타임에 생성되어...메시 에셋으로 저장한 뒤 그 에셋을 렌더러에 할당
...다시 임포트한 뒤에도 읽을 수 없어 복사하지 못했습니다.모델 파일이 읽기 전용인지 확인
편집용 메시 사본을 '{...}'에 기록하지 못했습니다.폴더 쓰기 권한과 디스크 여유 공간 확인
편집용 메시 사본을 저장할 '{...}' 폴더를 만들지 못했습니다.프로젝트 폴더 쓰기 권한 확인
'{...}'의 모델 임포터를 열 수 없어...모델 파일이 프로젝트 안에 있고 임포트에 성공했는지 확인

칠했더니 아웃라인 방향이 망가졌다​

압력 소스가 Vertex Red이고 노멀 소스가 VertexColorTS여서 같은 버텍스 컬러를 덮어쓴 경우입니다. 인스펙터가 칠하기 전에 경고합니다.

조치: 압력 소스를 Vertex Alpha로 바꾸거나, 아웃라인 노멀을 UV8로 옮기세요.

다른 오브젝트의 아웃라인까지 같이 바뀌었다​

여러 렌더러가 같은 메시 에셋을 공유하고 있습니다. 버텍스 페인팅은 메시 에셋을 직접 수정합니다.

조치: 메시를 복제해 해당 렌더러에만 할당한 뒤 다시 칠하세요.

렌더 파이프라인을 바꿨더니 재질이 전부 깨졌다​

파이프라인이 바뀌면 MingToon 렌더 파이프라인 불일치 다이얼로그가 뜨고, 프로젝트의 MingToon 재질을 맞는 백엔드로 일괄 전환할지 물어봅니다. 열려 있는 씬의 재질도 함께 검사합니다.

로드되지 않은 씬과 AssetBundle은 검사할 수 없습니다

그쪽 재질은 따로 열어서 전환해야 합니다.

다이얼로그를 놓쳤어도 재질 인스펙터에 남는 경고에서 언제든 다시 실행할 수 있습니다.

전환이 차단되는 경우:

사유조치
머티리얼이 다른 에셋에 포함되어 있습니다.서브에셋에서 추출
머티리얼이 읽기 전용 패키지 안에 있습니다.패키지 밖으로 복사
머티리얼이 읽기 전용이거나 체크아웃되어 있지 않습니다.읽기 전용 속성 해제 또는 버전 관리에서 체크아웃

변환/베이크가 실패한다​

메시지조치
이 루트 아래에서 변환할 재질 슬롯을 찾지 못했습니다.밍툰 매니저를 맞게 붙였는지, 하위 렌더러 다시 찾기를 눌렀는지 확인
MingToon 원본 셰이더 '{...}'을(를) 찾지 못해 베이크할 수 없습니다.설치가 불완전합니다. 패키지를 다시 임포트
생성한 MingToon 셰이더 '{...}'을(를) 임포트하지 못했습니다.프로젝트 폴더 쓰기 권한 확인 후 재시도
생성한 MingToon 셰이더 '{...}'에 컴파일 오류가 있습니다.MingToon 인클루드 폴더가 원래 경로에 있는지 확인. 이 결과는 캐시되지 않으므로 경로를 바로잡고 다시 베이크하면 재생성됩니다

캐스트 그림자가 얼룩덜룩하다​

위치조치
옷 주름·몸 전반셀프 캐스트 섀도우 억제 켜고 셀프 섀도우 캐스터 바이어스 0.01~0.03
얼굴앞머리·헤어 캐스터의 그림자 방식과 실제 그림자 캐스터 오프셋, Face SDF, 얼굴 2D 그림자 어시스트를 조정. 작동하지 않던 얼굴 캐스트 안정화 옵션은 0.1.7에서 제거됨
위아래 방향상하 보정 강도·상하 도달 임계값 (낮을수록 넓게)
경계가 계단처럼 각짐투영 페더 사용 + 투영 페더 반경·강도
전반적으로 지글거림광원 shadow map 해상도 · bias/normal bias · cascade 순으로 확인
페더는 없는 정보를 복구하지 못합니다

낮은 해상도의 shadow map에 애초에 없던 디테일은 부드럽게 만든다고 돌아오지 않습니다.

그림자가 겹치는 곳만 새까맣다​

통합 그림자를 켰더니 개별 그림자 색이 안 먹힌다​

정상입니다. 통합 모드에서는 개별 그림자의 색·블렌드·밝기가 결과에 반영되지 않습니다. 값은 보존되므로 끄면 돌아옵니다. 개별 값을 통합 값에 맞추려면 통합 값을 개별 그림자에 복사를 쓰세요.
