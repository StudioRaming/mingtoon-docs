설치​

재질이 분홍색(마젠타)으로 보여요​

원인조치
렌더 파이프라인 불일치맞는 백엔드 셰이더로 교체합니다
셰이더 모델 4.5 미달StudioRaming > MingToon > Validate Project 실행. PC만 지원합니다
URP 버전이 범위 밖Unity 2021.3 + URP 12.x로 맞춥니다
이 경우에는 오류 메시지가 하나도 안 나옵니다

SubShader가 통째로 탈락하므로 로그가 조용합니다. 분홍색이 유일한 신호입니다.

Validate Project가 Unity 버전을 지적해요​

코드언제 뜨나뜻
MING-ENV-UNITY-VERSION (오류)에디터가 2021.3도 2022.3도 아닐 때지원하지 않는 스트림입니다
MING-VRC-UNITY-VERSION (경고)VRC SDK가 있는데 2022.3이 아닐 때이 프로젝트에는 아바타 업로드 지원이 없습니다
MING-ENV-BUILD-TARGET (오류)빌드 타깃이 셰이더 모델 4.5를 못 맞출 때Android·Quest·iOS·WebGL입니다. Windows로 되돌리세요

2022.3.22f1은 정상 지원 버전이라 아무 지적도 나오지 않습니다. → Validate Project 코드

렌더 파이프라인을 바꿨더니 재질이 다 깨졌어요​

전환 다이얼로그에서 프로젝트의 MingToon 재질을 맞는 백엔드로 일괄 전환합니다. 다이얼로그를 놓쳐도 재질 인스펙터의 경고에서 다시 실행할 수 있습니다.

전환이 막히는 사유조치
머티리얼이 다른 에셋에 포함되어 있음서브에셋에서 추출
머티리얼이 읽기 전용 패키지 안에 있음패키지 밖으로 복사
머티리얼이 읽기 전용이거나 체크아웃 안 됨읽기 전용 해제 또는 체크아웃

닫혀 있는 씬과 AssetBundle의 재질은 검사할 수 없습니다. 따로 열어서 전환하세요.

그림자​

그림자가 겹치는 곳만 새까매요​

그림자 색상 섹션의 통합 그림자 사용 을 켜세요. 형태·캐스트·뎁스 그림자가 한 색으로 모입니다. → 조명과 그림자

켠 뒤 개별 그림자 색이 안 먹히는 것은 정상입니다. 값은 남아 있으므로 끄면 돌아옵니다.

캐스트 그림자가 얼룩덜룩해요​

위치조치
옷 주름과 몸 전반셀프 캐스트 섀도우 억제 를 켜고 셀프 섀도우 캐스터 바이어스 를 0.01에서 0.03 사이로
경계가 계단처럼 각짐투영 페더 사용 을 켜고 투영 페더 반경·투영 페더 강도 조절
전반적으로 지글거림광원의 shadow map 해상도, bias, cascade 순으로 확인
역광에서 몸 위에 캐릭터 모양이 겹침역광 실루엣 억제 를 켭니다
페더는 없는 정보를 되살리지 못합니다

해상도가 낮은 shadow map에 애초에 없던 디테일은 부드럽게 해도 돌아오지 않습니다.

그림자 패턴이 전혀 안 찍혀요​

원인조치
패턴 모양 타일 사용 은 켰는데 타일 슬롯이 빔빈 슬롯은 흰색으로 읽히고 흰색은 어떤 농도도 넘지 못합니다. 기본 제공 타일을 쓰세요
패턴 강도 가 0올립니다
적용 대상이 안 맞음패턴 적용 대상 확인
점이 톤에 반응하지 않고 크기가 일정함이진화된 점 그림을 넣었습니다. 타일은 임계값 맵이어야 합니다

어두운 월드에서 캐릭터가 검게 뭉개져요​

베이스 색 유지, 최종 최소 밝기, 간접광 보정, 캐스트 간접광 보정 을 차례로 올리세요. 밝은 월드에서 하얗게 날아가면 최종 최대 밝기 를 낮춥니다.

뎁스 효과​

뎁스 림라이트나 뎁스 그림자가 안 보여요​

원인조치
전체 효과 또는 깊이 효과 가 꺼짐인스펙터가 켜기 버튼을 보여 줍니다
전체 폭 이 0올립니다
각 모듈의 강도가 0올립니다
표면 모드가 투명 (3000)반투명 (2499) 로 바꿉니다
카메라 깊이 기록 이 꺼짐켭니다
VRChat 일반 화면아바타가 강제할 수 없습니다 → VRChat
URPRenderer Feature 설치와 Depth Texture 활성화
WARUDODepth Bridge 설치 → Warudo

인스펙터에 깊이 텍스처가 준비되지 않았다는 안내가 뜨면 그 안내대로 진행하세요. SSAO 반경 을 올려도 안 넓어진다면 상한에 닿은 것입니다. 범위는 0.001에서 0.05m입니다.

이너 아웃라인만 사라졌어요​

Inner Depth Edge 사용 은 이너 아웃라인 섹션에 있습니다. 이 섹션은 화면 공간 효과 그룹 안에 있습니다.

원인조치
이너 아웃라인에 적용 이 켜졌고 버텍스 컬러가 검음토글을 끄거나 압력 소스 를 바꿉니다
표면 모드가 투명 (3000)반투명 (2499) 로 바꿉니다
카메라 깊이 없음위 항목 참고

노멀 아웃라인은 깊이 없이도 그려집니다. 노멀 아웃라인만 보인다면 깊이 문제입니다.

머리카락이 뺨을 뚫고 보여요​

표면 모드를 반투명 (2499) 로 바꾸세요. 이 모드는 알파 합성을 쓰면서 깊이도 기록합니다.

투명 깊이 선기록 은 투명 (3000) 전용입니다. 반투명 (2499)에서 켜도 아무 변화가 없습니다.

아웃라인​

노멀 아웃라인이 통째로 사라졌어요​

원인조치
버텍스 컬러가 검은데 압력 소스 가 VertexRed압력 소스를 바꾸거나 버텍스 컬러를 확인
압력 대비 가 0압력이 완전히 무시됩니다. 올리세요
컬러 마스크 가 015로 되돌립니다
아웃라인 마스터 가 꺼짐켭니다. 이너 아웃라인도 이 게이트를 씁니다

아웃라인이 각진 부분에서 끊겨요​

노멀 소스 가 VertexColorTS 또는 UV8TS인데 스무딩한 외곽선 노멀을 굽지 않은 메시입니다. MeshNormal로 바꾸세요. → 아웃라인 스무스 노멀 UV8

씬 뷰에서 아웃라인 두께를 칠할 수 없어요​

인스펙터가 이유를 문장으로 알려 줍니다. 메시지별 조치는 씬 뷰에서 직접 칠하기에 있습니다.

칠했더니 결과가 이상해졌어요​

압력 소스 가 Vertex Red이고 노멀 소스 가 VertexColorTS면 같은 채널을 덮어씁니다. 압력 소스를 Vertex Alpha로 바꾸거나 아웃라인 노멀을 UV8로 옮기세요.

다른 오브젝트까지 같이 바뀌었다면 여러 렌더러가 같은 메시 에셋을 공유하는 것입니다. 메시를 복제해 그 렌더러에만 할당한 뒤 다시 칠하세요.

얼굴​

얼굴 마스크를 칠했는데 안 먹혀요​

마스크 강도 가 0이면 마스크를 무시하고 재질 전체를 얼굴로 봅니다. 0보다 크게 올리세요. 마스크는 텍스처, 버텍스 페인트, 프록시, 재질 전체 순으로 우선합니다. → 페이스 셰이딩

얼굴에 그림자가 하나도 안 져요​

깊이 가용성 이 Force Off면 뎁스 그림자가 절대 그려지지 않습니다. 얼굴용 자동 보정은 얼굴에서 투영 그림자를 빼 둡니다. Face 재질의 깊이 꺼짐 시 투영 그림자 를 켜면 깊이가 없을 때 투영 그림자로 돌아옵니다.

VRChat​

업로드했는데 최적화가 안 걸린 것 같아요​

  1. Unity 버전이 2022.3.22f1인지 확인합니다. 2021.3에서는 VRChat 훅이 컴파일되지 않습니다.
  2. Console에 [MingToon] VRChat build hook compiled and registered. 가 있는지 봅니다.
  3. 밍툰 매니저 최적화 탭에서 빌드/업로드 시 자동 최적화 (전체 공통) 이 켜져 있는지 봅니다.
  4. 프로젝트 폴더 옆 StudioRaming/MingToonOptimizeReport.txt를 엽니다.

→ 제대로 걸렸는지 확인하기

내 화면에서는 보이는데 남들한테는 뎁스 효과가 안 보여요​

기본값이 그렇습니다. 깊이 효과는 본인과 친구에게만 보입니다. 매니저 시작하기 탭의 비친구에게도 깊이 효과 보이기 를 켜면 모두에게 보입니다. 대신 상대방의 부하가 커집니다.

미러에서 안 나오는 것도 의도한 동작입니다. 미러가 남의 실루엣을 그림자로 쓰지 않도록 차단합니다. → 깊이 효과가 어디까지 보장되나

WARUDO​

WARUDO에서 뎁스 효과가 전부 비어 있어요​

Depth Bridge가 설치되지 않았습니다. Playground 경로와 .cs 확장자, installed 로그를 확인하세요. → WARUDO Depth Bridge

메인 화면만 정상이고 Spout·NDI 출력이 다르면 그 카메라의 depth enabled for camera= 로그를 확인하세요. 로그가 없으면 처리되지 않은 카메라입니다.

성능​

작업 중 인스펙터가 무거워요​

정상입니다. 편집용 셰이더는 모든 기능과 최대 레이어 수를 한 번에 컴파일해 유지합니다. 덕분에 기능을 켤 때마다 컴파일을 기다리지 않습니다. 대신 Unity 에디터 안에서는 같은 재질이 빌드 결과물보다 GPU를 약 2배 더 씁니다(실측 기준). 에디터 화면의 프레임이나 프로파일러 수치로 아바타 무게를 판단하지 마세요. 경량화는 빌드할 때만 적용됩니다.

아바타가 너무 무겁다고 해요​

깊이 효과를 전부 끄면 깊이 라이트도 빌드에서 자동으로 빠집니다. 이것이 가장 가벼운 경로입니다. → VRChat 깊이 라이트

베이크와 복원​

baked 재질의 복원 버튼이 비활성이에요​

베이크 뒤에 켰던 기능이 동작하지 않아요​
