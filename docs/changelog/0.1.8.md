*오픈 베타 · 2026-09-08*

## 0.1.8 {#v018}

[고정 링크: 0.1.8 패치노트](/changelog/0.1.8#v018)

### 주요 수정·개선

- **변환 안정성** — lilToon 변환에서 SSAO 색상 순도가 바뀌거나 발광 마스크가 꺼지고, 마스크 데이터가 압축으로 달라지는 문제를 수정했습니다.
- **Manager 조작** — 업데이트 상태와 현재·최신 버전을 두 줄에 모아 패널 높이를 기존의 약 1/3로 줄였고, `확인`·`업데이트`·`패치노트`를 한곳에서 사용할 수 있습니다.
- **설치·업데이트 경로** — DLL 방식은 unitypackage 안의 DLL을 최초 설치한 뒤 자체 서버에서 승인된 패키지를 `Packages`에 설치합니다. 이후 `자동 업데이트`를 켜면 Unity 시작 시 다음 승인 버전을 확인하고, 재생·컴파일·빌드 중에는 기다렸다가 재로드 후 확인합니다. VCC에서 설치한 사용자는 계속 VCC에서 수동으로 업데이트합니다.
- **기존 에셋 보존** — 0.1.7 설치와 기존 인벤토리를 인식하고, 패키지가 관리하는 파일만 갱신하며 기존 재질·씬·프리팹과 Unity가 만든 `package.json.meta`를 보존합니다.

### 새 기능

- **색상 프리셋** — `색상 프리셋`에서 그림자·림·깊이·틴트·HSVG를 한 번에 적용하고, 팩토리 팔레트를 선택한 재질에 적용할 수 있습니다. 텍스처·렌더 상태·키워드는 유지되며 Undo로 되돌릴 수 있습니다.
- **밴드와 림 색상 조정** — 빠른 설정에서 전체 채도·전체 발광 강도를 조정하고 `림 셰이드 색상`과 그림자 밴드 색상을 직접 설정할 수 있습니다.
- **레이어별 UV 선택** — 노멀 레이어와 마스크가 사용할 UV 채널을 레이어마다 선택할 수 있습니다.

### 변경

- **언어 표시** — 설치·업데이트 안내는 시스템 언어에 따라 한국어·일본어·영어(그 외 언어)로 표시되고, Manager 라벨은 인스펙터의 언어 선택을 따릅니다.
- **변환 결과** — 발광 마스크의 RGBA 정보와 표면 알파 혼합을 반영하고, 노멀·마스크에 작성된 UV 선택을 유지합니다.

### 개선

- **셰이더 베이크** — 같은 요청을 묶어 처리해 반복 베이크의 중복 작업을 줄이고, 기존 생성 결과와 상태를 유지합니다.
- **생성 결과 복구** — 베이크가 중단되어도 부분 생성 파일이 다음 작업의 캐시를 오염시키지 않도록 복구 처리를 강화했습니다.

### 문서

- Manager의 `패치노트`가 최신 문서로 연결되며, 현재 버전과 최신 버전을 한눈에 확인할 수 있습니다.
