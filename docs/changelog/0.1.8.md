*오픈 베타 · 2026년 9월 8일*

## 한 줄 요약 {#v018}

업로드가 빨라지고, 베이크 후 아바타가 하얗게 보이던 문제를 고쳤습니다.

:::warning[업데이트 전 확인]
- 백업: 프로젝트를 백업한 뒤 설치하세요.
- 재베이크: 이미 구운 재질은 다시 구워야 이번 수정이 반영됩니다.
- 재업로드: VRChat 아바타는 다시 업로드하세요.
- 구 설치본에서 옮길 때만: `Assets/StudioRaming/MingToon` 안에 직접 저장한 파일을 먼저 빼내세요.
- `MingLightController`나 `StudioRaming` 전체 폴더는 지우지 마세요.
:::

## 새 기능

- **색상 프리셋** — 그림자 색상 탭 전체와 림·깊이 틴트, HSVG를 저장하고 적용합니다.
- 기본 팔레트는 `Neutral`·`Warm Tone 1`·`Warm Tone 2`·`Cool Tone 1`·`Cool Tone 2`·`High Saturation`·`Low Saturation` 7종입니다.
- **전체 채도** — 최종 출력 전체에 적용됩니다. 0은 흑백, 1은 기준값입니다.
- **SSAO 색상** · **림 셰이드 색상** — 빠른 설정에서 밴드 색상과 함께 직접 정합니다.
- **UV Source** · **Mask UV Source** — 노멀 레이어와 마스크의 UV를 UV0~UV3에서 따로 고릅니다.
- BOOTH에서 받은 DLL을 임포트하면 필요한 패키지가 자동으로 설치됩니다.
- Unity를 켤 때 새 버전을 확인하고 안내창을 띄웁니다. `업데이트`를 눌러야 설치합니다.
- Manager의 업데이트 패널이 두 줄로 줄고 `확인`·`업데이트`·`패치노트`가 한곳에 모였습니다.

## 바뀐 기본값과 룩 변화

- **림 셰이드 색상** 의 블렌드 불투명도가 0이면 예전처럼 `1차 그림자 색상`을 그대로 씁니다.
- 기본 텍스처 베이크 정책 `LosslessOnly`는 원본 픽셀을 다시 쓰지 않습니다.
- `업로드 시에도 텍스처 재작성 (옵트인)` 과 `빌드/업로드 시 자동 최적화 (전체 공통)` 를 둘 다 켜야 동작합니다.
- 켜면 업로드 직전에 텍스처 레이어와 노멀 레이어를 각각 한 장으로 합칩니다.
- 낱개 마스크는 RGBA 팩으로 묶이며 `아웃라인` 탭의 `폭 마스크`도 들어갑니다.
- 색공간·밉·압축 때문에 픽셀이 달라질 수 있습니다. 베이크 전후를 직접 비교하세요.
- 노멀 레이어의 UV가 둘 다 기본값 UV0이면 UV 라우터를 컴파일하지 않습니다.
- 설치·업데이트 안내는 시스템 언어를 따르고, Manager 라벨은 인스펙터 언어를 따릅니다.

## 수정된 문제

- 업로드가 지나치게 오래 걸리던 문제를 고쳤습니다. 첫 업로드 기준 3~50% 빨라졌습니다.
- 베이크 후 업로드한 캐릭터가 하얗게 보이던 문제를 대부분 해결했습니다.
- BRP 전용 프로젝트에서 없는 URP를 검사해 업로드가 막히던 MLC 문제가 고쳐졌습니다.
- lilToon 변환에서 SSAO 색 순도가 바뀌던 문제가 고쳐졌습니다.
- 변환에서 발광 마스크가 꺼지고 마스크 데이터가 압축으로 달라지던 문제가 고쳐졌습니다.
- 모델 크기에 따라 외곽선 노멀의 보정이 달라지던 문제가 고쳐졌습니다.
- 베이크가 중단되면 부분 생성 파일이 다음 작업을 오염시키던 문제가 고쳐졌습니다.
- Manager의 `패치노트` 버튼이 최신 문서로 연결됩니다.

## 알려진 제한

- 빨라지는 정도는 아바타와 환경에 따라 다릅니다.
- 폴백 발광을 검정으로 만드는 수정은 0.1.7 핫픽스 1에 들어 있습니다.
- 0.1.7 핫픽스 1 이전에 구운 재질은 다시 굽고 재업로드해야 합니다.
- 구 설치본 정리는 한 번만 필요합니다. 이후 업데이트마다 반복하지 않습니다.
- VCC로 설치한 사용자는 계속 VCC에서 직접 업데이트합니다.
