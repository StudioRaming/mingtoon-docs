## 0.1.8 {#v018}

[고정 링크: 0.1.8 패치노트](/changelog/0.1.8#v018)

### 주요 수정·개선

- **첫 업로드 처리 시간** — 업로드가 과도하게 오래 걸리는 문제를 개선했습니다. 사용자 측정에서는 첫 업로드 기준 3~50% 빨라졌으며 환경에 따라 달라질 수 있습니다.
- **VRC 베이크 후 흰색 표시** — VRC 베이크 경로에서 발광 레이어가 기존 조명 결과를 덮어쓰지 않고 현재 결과에 순차적으로 합성되도록 수정해, 베이크 후 업로드한 캐릭터가 하얗게 보이던 문제를 대부분 해결했습니다. 발광 마스크·그림자 가시성·`Normal`/`Multiply` 블렌드와 맵의 RGB·알파, 표면 알파를 유지합니다. 기존 baked 재질에 반영하려면 다시 베이크하고 재업로드하세요.
- **Fallback 경로 구분** — fallback 발광 alias(`_EmissionColor`)를 항상 검정으로 만드는 변경은 0.1.7 HotFix1에 포함된 별도 수정입니다. 이번 0.1.8 수정은 일반 MingToon 베이크·렌더 경로의 발광 합성을 다룹니다. 0.1.7 HotFix1 이전에 만든 baked 재질은 다시 베이크하고 재업로드하세요.
- **Ming Light Controller 0.1.1** — URP 셰이더가 없는 BRP 전용 프로젝트에서 존재하지 않는 URP를 검사해 VRChat 업로드가 중단되던 문제를 수정했습니다. 설치된 MingToon backend만 검증하고, 두 backend가 모두 없을 때만 오류를 냅니다. NDMF 빌드 클론용 승인된 임시 ID는 메모리에만 두며 원본 아바타나 프로젝트 파일을 다시 쓰지 않습니다. 메뉴의 채도는 MingToon의 `Output Master Saturation`에 연결됩니다. MLC는 별도 패키지이므로 MingToon 설치 후 함께 업데이트해 주세요.
- **기존 Assets 설치본과 충돌할 때 복구** — 기존 Assets 방식 설치본과 새 설치기가 충돌해 설치가 실패한 경우에만, `Assets/StudioRaming/MingToon` 안에 직접 저장한 `.mat`·텍스처·프리셋을 먼저 다른 폴더로 옮긴 뒤 해당 MingToon 폴더만 삭제하고 다시 임포트하세요. `MingLightController`나 `StudioRaming` 전체 폴더는 삭제하지 마세요. 이 정리는 구 Assets 설치본에서 전환할 때 한 번만 필요하며 이후 VPM 업데이트마다 반복하지 않습니다.
- **변환 안정성** — lilToon 변환에서 SSAO 색상 순도가 바뀌거나 발광 마스크가 꺼지고, 마스크 데이터가 압축으로 달라지는 문제를 수정했습니다.
- **업로드 시 텍스처 재작성 (옵트인)** — 기본 텍스처 Bake 정책인 `LosslessOnly`는 원본 texel을 다시 쓰지 않습니다. `최적화` 탭에서 `업로드 시에도 텍스처 재작성 (옵트인)`을 켜고 같은 그룹의 `빌드/업로드 시 자동 최적화 (전체 공통)`도 켠 경우에만 업로드 직전에 `텍스처 레이어`와 `노멀 레이어`를 각각 한 장으로 합치고 낱개 마스크를 RGBA 팩으로 묶습니다. 색공간·밉 재생성·플랫폼 압축으로 픽셀이 달라질 수 있으므로 목표 플랫폼의 베이크 전후 캡처로 직접 비교하세요. 넓어진 팩에는 `아웃라인` 탭의 `폭 마스크`도 포함됩니다.
- **Manager 조작** — 업데이트 상태와 현재·최신 버전을 두 줄에 모아 패널 높이를 기존의 약 1/3로 줄였고, `확인`·`업데이트`·`패치노트`를 한곳에서 사용할 수 있습니다.
- **설치·업데이트 경로** — BOOTH에서 받은 DLL unitypackage를 최초 임포트하면 추가 설치 버튼 없이 필요한 MingToon 패키지를 자동 설치합니다. 이번 버전에서 도입한 VCC·VPM 기반 경로이며, 이후 Unity 시작 시 새 버전을 자동으로 확인하고 아직 설치하지 않았고 건너뛰지 않은 버전의 안내창을 표시합니다. 안내창에서 사용자가 `업데이트` 버튼을 눌러야 설치하며, 재생·컴파일·빌드 중에는 기다렸다가 재로드 후 다시 확인합니다. Unity를 재시작해도 자동 설치하지 않으며, `건너뛰기`는 해당 버전에만 적용되어 다음 새 버전에서 다시 알립니다. VCC에서 설치한 사용자는 계속 VCC에서 수동으로 유지·업데이트합니다.
- **기존 에셋 보존** — 0.1.7 설치와 기존 인벤토리를 인식하고, 패키지가 관리하는 파일만 갱신하며 기존 재질·씬·프리팹과 Unity가 만든 `package.json.meta`를 보존합니다.

### 새 기능

- **색상 프리셋** — `색상 프리셋` 패널에서 그림자 색상 탭 전체(밴드·색 순도·명도·컬러맵), 림·깊이 틴트와 HSVG를 저장하고 선택한 재질에 적용할 수 있습니다. 기본 팔레트는 `Neutral`, `Warm Tone 1`, `Warm Tone 2`, `Cool Tone 1`, `Cool Tone 2`, `High Saturation`, `Low Saturation` 7종입니다. 프리셋 대상 이외의 텍스처·렌더 상태·키워드는 유지되며 여러 선택 재질에 적용하고 Undo로 되돌릴 수 있습니다.
- **밴드와 림 색상 조정** — 빠른 설정에서 전체 채도와 전체 발광 강도를 조정하고, `SSAO 색상`·`림 셰이드 색상`과 그림자 밴드 색상을 직접 설정할 수 있습니다. `림 셰이드 색상`의 블렌드 불투명도를 0으로 두면 기존처럼 `1차 그림자 색상`을 유지합니다.
- **최종 출력 채도** — `전체 채도`(`Output Master Saturation`)는 최종 출력 전체에 적용됩니다. 0은 흑백, 1은 기준값이며 1보다 크게 올리면 밝기를 유지한 채 색을 강화합니다.
- **레이어별 UV 선택** — 각 노멀 레이어의 `UV Source`와 해당 마스크의 `Mask UV Source`를 UV0~UV3으로 따로 선택할 수 있습니다. 둘 다 기본값인 UV0이면 UV 라우터 variant를 컴파일하지 않습니다.

### 변경

- **언어 표시** — 설치·업데이트 안내는 시스템 언어에 따라 한국어·일본어·영어(그 외 언어)로 표시되고, Manager 라벨은 인스펙터의 언어 선택을 따릅니다.
- **변환 결과** — 발광 맵의 RGB·알파와 발광 마스크의 RGBA 정보를 보존하고, 투명 재질의 표면 알파 혼합을 반영합니다. 노멀 레이어의 `UV Source`와 각 마스크의 `Mask UV Source`(UV0~UV3) 선택도 유지합니다.

### 개선

- **셰이더 베이크** — 같은 요청을 묶어 처리해 반복 베이크의 중복 작업을 줄이고, 기존 생성 결과와 상태를 유지합니다.
- **생성 결과 복구** — 베이크가 중단되어도 부분 생성 파일이 다음 작업의 캐시를 오염시키지 않도록 복구 처리를 강화했습니다.
- **외곽선 노멀 안정성** — 모델 크기에 따라 외곽선 노멀의 기하 보정이 달라지던 계산을 유한값 기반의 스케일 독립 처리로 바꾸고, 퇴화했거나 유한하지 않은 geometry에는 작성된 방향을 사용하는 fallback을 추가했습니다.

### 문서

- Manager의 `패치노트`가 최신 문서로 연결되며, 현재 버전과 최신 버전을 한눈에 확인할 수 있습니다.

### 이전 버전에서 업데이트하기

프로젝트를 백업한 뒤, 기존 `Assets/StudioRaming/MingToon` 안에 직접 저장한 재질·텍스처·프리셋을 다른 폴더로 옮기세요. 이전 Assets 방식 설치본은 해당 MingToon 폴더만 삭제한 후 새 설치기를 임포트합니다. `MingLightController`나 `StudioRaming` 전체 폴더를 삭제하지 마세요. 이 폴더 정리는 이전 설치 방식에서 옮길 때만 필요하며, 이후 VPM 업데이트마다 반복하지 않습니다.
