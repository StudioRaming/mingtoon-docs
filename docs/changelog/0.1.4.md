*클로즈 베타 · 2026년 8월 5일*

## 한 줄 요약

금속과 광택을 표현하는 하이브리드 PBR과 툰 스페큘러가 생겼습니다.

:::warning[업데이트 전 확인]
- 파라미터 예산: VRChat Expression Parameters 잔여량을 먼저 확인하세요.
- `Modular Avatar로 비파괴 설치`가 21개 동기화 파라미터와 154비트를 씁니다.
- 기존 아바타와 합쳐 256비트를 넘으면 설치가 중단됩니다.
- 룩이 바뀌는 항목: 0.1.3에서 숨겨졌던 `페이스 셰이딩`이 다시 표시됩니다.
- 기존 얼굴 재질은 마스크·경계·SDF 맵을 확인한 다음 직접 켜세요.
:::

## 새 기능

- **PBR 표면 사용** — 툰 확산광을 유지하면서 금속도·매끄러움·반사를 더합니다. → [문서](/guides/detail-maps#pbr-표면)
- **툰 스페큘러** — PBR 전체를 켜지 않고 하이라이트만 추가합니다. 머리카락용 이방성도 있습니다.
- Isotropic과 Anisotropic 중에서 고릅니다. → [문서](/guides/detail-maps#툰-스페큘러)
- **영역 마스크** — RGBA 한 장을 네 영역으로 나눠 파츠별로 보정합니다. → [문서](/guides/detail-maps#영역-마스크)
- **Single Channel (Grayscale)** — 얼굴 SDF 형식에 추가됐습니다. R 채널 한 장을 좌우 반전해 씁니다.
- 얼굴 영역을 SceneView에서 직접 칠합니다. Paint·Harden·Smooth·Hard Face와 X 대칭을 지원합니다.
- 연결 섬, 메시 격리, 저장·버리기 흐름을 제공합니다. → [문서](/guides/character#얼굴-영역을-sceneview에서-칠하기)
- **MingToon 2D 투영 그림자 캐스터** — 안경·액세서리를 깊이 기반 효과에서만 제외합니다.
- 일반 렌더와 Unity 실시간 그림자는 그대로 유지됩니다.
- Face SDF Studio를 동봉했습니다. Base·Nose·Cheek·Lip·Eye Socket을 한 장으로 굽습니다.
- MaskMaker와 `MM` 버튼을 동봉했습니다. 마스크 슬롯에서 바로 열고 PNG를 적용합니다.
- 가상광과 Highlight·Shadow·Final Output을 VRC 메뉴에서 조절합니다. `Reset All`로 복원합니다.

## 바뀐 기본값과 룩 변화

- Face SDF Studio와 MaskMaker가 0.1.4 패키지에 함께 들어갑니다. 둘 다 Editor 전용입니다.
- 런타임 스크립트를 추가하지 않습니다.
- Face SDF Studio 작업공간이 `준비 · 정면 UV7`과 `SDF 제작 · 미리보기 · 베이크` 두 단계가 됐습니다.
- 아웃라인 폭 마스크가 폭 설정 가까이로 옮겨졌습니다.
- lilToon 변환에서 폭 마스크의 Tiling/Offset도 함께 보존합니다.
- Inspector 분류와 설명을 사용자 표시 이름으로 통일했습니다. 가이드 탭 대신 툴팁을 씁니다.
- VRC 메뉴 설치가 비파괴 방식이 됐습니다. 기존 Root Menu와 FX를 유지하고 빌드 사본에서만 합칩니다.

:::note[지금은]
Face SDF Studio와 Mask Maker는 0.1.7부터 동봉되지 않습니다. 별매 제품입니다.
설치하면 인스펙터의 같은 자리에서 그대로 연동됩니다. → [별매 애드온](/guides/add-ons)
:::

:::note[지금은]
VRChat 메뉴 제작은 0.1.7에서 별매 애드온 Ming Light Controller로 옮겨졌습니다.
MingToon 본체는 메뉴·파라미터·FX를 만들지 않습니다. → [Ming Light Controller](/guides/ming-light-controller)
:::

## 수정된 문제

- `페이스 셰이딩`을 켜면 Base Pass가 사라지던 문제가 고쳐졌습니다.
- BRP `ForwardBase`와 URP `UniversalForwardOnly`를 복구했습니다.
- 역광 얼굴에 흰 지그재그 선이 생기던 문제가 고쳐졌습니다.
- 형태 그림자 경계의 화면 미분 폭에 상한을 걸어 삼각형 경계가 드러나지 않게 했습니다.
- 얼굴 SDF 방향·좌표가 어긋나거나 전환이 한 번에 튀던 문제가 고쳐졌습니다.
- 맵을 연결하지 않았을 때의 경고와 복구 경로를 추가했습니다.
- lilToon 아웃라인 폭 마스크와 Tiling/Offset이 변환되지 않던 문제가 고쳐졌습니다.
- Manager 변환·저장·새로고침 후 `EndLayoutGroup` 오류가 나던 문제가 고쳐졌습니다.
- 이미션 맵이 없을 때 색상과 강도가 검게 곱해져 발광이 사라지던 문제가 고쳐졌습니다.
- 여러 재질을 편집할 때 인스펙터·프리셋·비용 패널이 반복 갱신되던 것을 줄였습니다.
- Bake 취소와 복원의 경계를 명확히 했습니다. 준비 중 취소와 최종 저장을 구분합니다.

## 알려진 제한

- 이 버전의 Face SDF Studio와 MaskMaker는 Editor 전용입니다. 빌드에 실리지 않습니다.
- 파라미터 예산을 넘으면 설치가 중단됩니다. 기존 아바타의 잔여량을 먼저 비우세요.
