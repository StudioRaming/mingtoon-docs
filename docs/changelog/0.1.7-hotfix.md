## 핫픽스 1 — 2026-09-07 (1차)

**업데이트 후 해야 할 것**

- VRChat 빌드가 `Material recovery is incomplete`로 막혀 있던 프로젝트는 덮어쓴 뒤 에디터를 한 번 재시작하면 자동으로 정리됩니다.
- 스텐실(눈 오버레이·숨김 마스크)을 쓰는 lilToon 변환 재질은 다시 변환하거나 스텐실 값을 직접 되돌려 주세요.
- 재업로드는 필요 없습니다.

### NDMF 생성 클론의 레코드가 남아 VRChat 빌드가 계속 막히던 문제

- 증상 — NDMF를 쓰는 아바타를 한 번 빌드한 뒤부터 모든 VRChat 빌드가 `Material recovery is incomplete`로 실패했습니다.
- 조치 — NDMF가 빌드 후 지우는 `Packages/nadena.dev.ndmf/__Generated/` 클론 머티리얼의 복구 레코드가 저널에 남던 것이 원인입니다. 머티리얼 소실 판정을 GUID 매핑이 아니라 실제 파일 존재로 바꿨고, 그런 레코드는 다음 복원 시점에 경고 한 줄과 함께 정리됩니다.

### 룩 프리셋이 스텐실 값을 덮어쓰던 문제

- 증상 — lilToon 변환은 원본의 스텐실 값(Ref·Comp·Pass 등)을 그대로 가져오는데, 변환 직후 적용되는 팩토리 룩 프리셋이 셰이더 기본값(Ref 0·Always·Keep)을 들고 있어 눈 오버레이·숨김 마스크용 스텐실이 전부 0으로 되돌아갔습니다. 룩 프리셋을 다시 적용할 때도 같았습니다.
- 조치 — 스텐실 두 단위(표면·아웃라인, 14개 항목)는 이제 프리셋에 캡처되지도 적용되지도 않습니다.
