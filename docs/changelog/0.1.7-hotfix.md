## 한 줄 요약

얼굴 프록시·스텐실·폴백 발광·빌드 차단을 고친 0.1.7 재배포입니다.

:::warning[업데이트 전 확인]
- 받는 법: 같은 0.1.7 패키지를 다시 받아 덮어쓰면 됩니다.
- 재업로드: `이미션 사용`이 켜진 재질을 쓰는 아바타만 다시 업로드하세요.
- 그 재질은 다시 변환하거나 Manager의 `폴백 프로퍼티 동기화`를 한 번 누르세요.
- 재변환: 스텐실을 쓰는 lilToon 변환 재질은 다시 변환하거나 스텐실 값을 직접 되돌리세요.
- 얼굴 프록시는 덮어쓰기만 하면 됩니다. 씬을 열면 바로 반영됩니다.
:::

:::info[핫픽스 읽는 법]
버전 번호를 올리지 않고 같은 패키지를 다시 올린 수정입니다.
몇 차까지 들어 있는지는 패키지 안 `Docs/PATCH_NOTES_0.1.7.md`로 확인합니다.
:::

## 수정된 문제

- 얼굴 프록시를 조정해 두면 씬 저장·플레이·리로드 때마다 원본 노멀로 돌아가던 문제.
- 이제 편집 재질에서 셰이더가 프록시 노멀을 직접 계산합니다. 실시간과 베이크가 같은 수식입니다.
- Root Bone이 있는 Skinned Mesh Renderer에서 `프록시 영역 마스크` 중심이 얼굴에서 어긋나던 문제.
- 아웃라인 없는 lilToon 재질을 변환하면 아웃라인만 스텐실 마스크를 무시하던 문제.
- 앞머리 사이로 비치게 만든 눈이 표면은 비치는데 선만 머리카락에 가려졌습니다.
- 이제 원본에 아웃라인이 없으면 아웃라인이 표면 스텐실 값을 물려받습니다.
- 폴백 셰이더로 떨어진 아바타가 아웃라인만 남기고 하얗게 나오던 문제.
- 폴백용 발광 색은 이제 항상 검정입니다. MingToon 셰이더 자체의 이미션은 그대로입니다.
- NDMF 아바타를 한 번 빌드한 뒤 모든 VRChat 빌드가 `Material recovery is incomplete`로 막히던 문제.
- 이제 재질 소실을 실제 파일 존재로 판정하고, 남은 기록은 다음 복원 때 정리합니다.
- 변환 직후 적용되는 팩토리 룩 프리셋이 원본의 스텐실 값을 0으로 되돌리던 문제.
- 스텐실 두 단위(표면·아웃라인, 14개 항목)는 이제 프리셋에 저장되지도 적용되지도 않습니다.

## 알려진 제한

- 빌드가 막혀 있던 프로젝트는 덮어쓴 뒤 에디터를 한 번 재시작해야 정리됩니다.
- 새 차수가 나오면 이 페이지 맨 위에 붙습니다.
