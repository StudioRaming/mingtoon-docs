*클로즈 베타 · 2026년 8월 7일*

## 한 줄 요약

맞닿는 자리를 어둡게 하는 SSAO와 부위별 그림자 색이 생겼습니다.

:::warning[업데이트 전 확인]
- 룩이 바뀌는 항목: 새 재질의 `베이스맵 HSVG` 색조 기본값이 0.02에서 0으로 바뀝니다.
- 0.1.4까지 만든 재질은 저장된 0.02를 그대로 유지합니다.
- 색이 약 7도 돌아 보였다면 색조를 0으로 되돌리세요.
- 프리셋 목록: `SoftCartoon` 한 벌이 빠지고 세 룩과 각각의 `- Low` 경량판이 들어옵니다.
- 이미 적용해 둔 재질의 값은 그대로 남고, 고를 수 있는 목록만 달라집니다.
- 재변환: 업데이트 후 첫 변환은 메시를 한 번 다시 굽습니다. 그다음부터는 구운 메시를 씁니다.
:::

## 새 기능

- **SSAO (화면 공간 차폐)** — 목·겨드랑이·옷 주름·발이 바닥에 닿는 자리를 어둡게 합니다.
- 새 광원도 포스트 프로세스도 아닙니다. 깊이가 없는 곳에서는 조용히 사라집니다. → [문서](/guides/depth-effects#ssao-화면-공간-차폐)
- **그림자 컬러맵** — 통합 그림자의 한 색을 UV 맵으로 분포시켜 부위마다 다른 색을 냅니다.
- 흰색이 기준값이라 켜는 것만으로는 결과가 바뀌지 않습니다. → [문서](/guides/light-and-shadow#그림자-컬러맵)
- **Screen** — 스크린톤 `패턴 기준`에 추가됐습니다. 격자를 화면에 고정해 캐릭터가 그 아래로 지나갑니다.
- 화각이나 각도를 바꿔도 휘거나 점멸하지 않습니다. → [문서](/guides/shadow-pattern#패턴-기준)
- **모양 맵 사용** — 글리터 입자 하나하나의 실루엣을 텍스처로 바꿉니다.
- Star · Bloom · Sparkle · Heart · Hex · Flower 6종을 `Textures/Glitter/`에 동봉했습니다.
- **회전 랜덤** — 입자마다 모양을 다른 각도로 세웁니다. 방향이 있는 모양은 0으로 내리세요.
- **색상도 같이 사용** — 마스크 알파를 영역, RGB를 입자 색으로 함께 씁니다.
- 텍스처를 한 번 더 읽지 않습니다.
- **프레넬 림 시점 영향** — 림의 위치를 시점과 광원 중 무엇이 정할지 고릅니다.
- 0이면 카메라를 돌려도 림이 그 자리에 남습니다. → [문서](/guides/rim#림이-카메라를-따라다니는-게-싫다면)
- 프리팹을 우클릭해 셰이딩을 끝낸 캐릭터에서 Common · Face · Skin 프리셋 한 벌을 뽑습니다.
- `VRChat Preview`로 에디터 화면을 업로드 후 상태로 바꿔 봅니다. 깊이 없음과 있음 두 가지입니다.

## 바뀐 기본값과 룩 변화

- `그림자 패턴 (스크린톤)`이 독립 탭이 됐습니다. 자체 마스터 토글과 프리셋 행을 갖습니다.
- `그림자 패턴 사용`을 float 애니메이션과 VRChat 표현 메뉴로 토글할 수 있습니다.
- `림·추가광 최고 배율` 기본값이 2에서 3으로 올라갔습니다. 팩토리 룩도 같은 값입니다.
- 조명 밝기 제한 그룹의 나머지 값은 그대로입니다. → [문서](/guides/light-and-shadow#라이팅--어두운-씬에서-검게-뭉칠-때)
- `MingToon 2D 투영 그림자 캐스터`가 `MingToon 2D 투영 그림자 드리우기`가 됐습니다. 동작은 같습니다.
- 룩 프리셋이 성능 설정을 몰래 올리지 못하게 막았습니다. `- Low`가 모듈을 끄는 동작은 그대로입니다.

## 수정된 문제

- `MingToon 2D 투영 그림자 드리우기`를 끈 재질이 통째로 어두워지던 문제가 고쳐졌습니다.
- 끈 재질의 깊이 모듈이 자기 몸 뒤를 읽어 안경 전체에 선을 깔고 있었습니다.
- 스크린톤 `패턴 경계 부드러움`을 올리면 밝은 면에도 마크가 찍히던 문제가 고쳐졌습니다.
- 스크린톤 `Overlay`가 `Recolor`와 구분되지 않던 문제가 고쳐졌습니다.
- 잉크가 그림자 영역 밖까지 번지고 있었습니다. 이제 그림자 안쪽에만 놓입니다.
- 툰 스페큘러의 `Screen`·`Overlay`에서 반사면이 검게 나오던 문제가 고쳐졌습니다.
- 같은 결함이 있던 `Hue`·`Color`도 함께 고쳤습니다. → [문서](/guides/detail-maps#툰-스페큘러)
- 뎁스 그림자 (이전 이름: 2D 그림자)를 끈 재질에서도 얼굴 보조 밀기가 동작하던 문제.
- `MingToon 2D 투영 그림자 드리우기` 툴팁이 실제 동작과 반대로 설명하던 것을 고쳤습니다.
- 모듈을 토글할 때 파란색으로 멈춰 있는 시간이 줄었습니다. 룩 모듈 8종을 미리 담아 둡니다.
- 조명 변형을 설치 직후 한 번에 컴파일합니다. 라이트를 껐다 켜거나 새로 추가해도 멈추지 않습니다.
- lilToon 변환이 이미 구운 메시를 다시 쓰도록 고쳤습니다. → [문서](/workflow/liltoon-conversion)

## 알려진 제한

- 체감 차이는 환경마다 다릅니다.
- 통합 그림자를 끄면 각 층에 저장된 색이 돌아와 룩이 한 번에 바뀔 수 있습니다.
- SSAO의 소멸 거리 페이드는 그 값의 75% 지점에서 시작합니다.
- SSAO는 오클루전 맵과 곱하지 않고, 툰 밴드·스크린톤 뒤에 더 어두운 쪽을 취합니다.
- SSAO는 픽셀별 노이즈를 뿌리지 않습니다.

:::note[지금은]
`VRChat Preview` 메뉴는 0.1.7에서 제거됐습니다. 깊이 확인은 `깊이 가용성`을 `Diagnostic`으로 두세요. → [문서](/guides/depth-effects#diagnostic)
팩토리 룩 프리셋 목록은 이후 Basic · Hard · Soft Toon으로 다시 바뀌었습니다. → [0.1.10 패치노트](/changelog/0.1.10#v0110)
`프레넬 림 시점 영향`의 현재 라벨은 `시점 기준`입니다. → [림](/guides/rim)
:::
