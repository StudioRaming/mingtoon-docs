*클로즈 베타 · 2026-08-07*

## 업그레이드 시 확인할 것

:::caution[새 재질의 `Base HSVG` 색조 기본값이 0.02에서 0으로 바뀝니다]
0.1.4까지 만든 재질은 저장된 0.02를 그대로 유지합니다. 손대지 않은 베이스 맵 색이 약 7도 돌아 보였다면, 색조를 0으로 되돌리거나 프로퍼티 우클릭 → 기본값 복원을 쓰세요.
:::

:::caution[팩토리 룩 프리셋이 교체되었습니다]
`SoftCartoon` 한 벌이 빠지고 `Soft Toon` · `Hard Toon` · `Rim Shadow` 세 룩과 각각의 `- Low` 경량판으로 바뀝니다. 이미 적용해 둔 재질의 값은 그대로 남고, 고를 수 있는 목록만 달라집니다.
:::

:::caution[lilToon 변환의 메시 주소 규칙이 바뀌었습니다]
업데이트 후 첫 변환은 메시를 한 번 다시 굽습니다. 그 다음부터는 같은 아바타를 씬에 몇 번 다시 꺼내도 이미 구운 메시를 그대로 씁니다. → [문서](/workflow/liltoon-conversion)
:::

## 새 기능

- **`SSAO (화면 공간 차폐)`** — 카메라 깊이를 픽셀마다 다시 읽어 목·겨드랑이·옷 주름·발이 바닥에 닿는 자리를 어둡게 합니다. 새 광원도 포스트 프로세스도 아니라, 깊이가 없는 곳에서는 조용히 사라집니다. → [문서](/guides/depth-effects#ssao-화면-공간-차폐)
- **`그림자 컬러맵`** — 통합 그림자의 한 색을 UV 맵으로 분포시켜 머리카락·피부처럼 부위마다 다른 그림자 색을 냅니다. 흰색이 기준값이라 켜는 것만으로는 결과가 바뀌지 않습니다. → [문서](/guides/light-and-shadow#그림자-컬러맵)
- **스크린톤 `패턴 기준`에 `Screen` 추가** — 격자를 화면에 고정해 캐릭터가 그 아래로 지나갑니다. 인쇄물에 겹쳐 찍은 스크린톤·팝아트 형태이며, 화각이나 각도를 바꿔도 휘거나 점멸하지 않습니다. → [문서](/guides/shadow-pattern#패턴-기준)
- **글리터 `모양 맵 사용`** — 입자 하나하나의 실루엣을 텍스처로 바꿉니다. Star · Bloom · Sparkle · Heart · Hex · Flower 6종을 `Textures/Glitter/`에 동봉했습니다. → [문서](/guides/detail-maps#입자-모양-바꾸기)
- **글리터 `회전 랜덤`** — 입자마다 모양을 다른 각도로 세웁니다. 하트처럼 방향이 있는 모양을 똑바로 세우려면 0으로 내리세요.
- **글리터 `색상도 같이 사용`** — 마스크 한 장의 알파를 영역, RGB를 입자 색으로 함께 씁니다. 텍스처를 한 번 더 읽지 않습니다.
- **`프레넬 림 시점 영향`** — 림의 위치를 시점과 광원 중 무엇이 정할지 고릅니다. 0이면 카메라를 돌려도 림이 그 자리에 남습니다. → [문서](/guides/rim#림이-카메라를-따라다니는-게-싫다면)
- **프리팹에서 룩 프리셋 만들기** — 프로젝트 창에서 프리팹 우클릭 → `Studio Raming / MingToon / Create Look Preset From Prefab`. 셰이딩을 끝낸 캐릭터에서 Common · Face · Skin 한 벌을 한 번에 뽑습니다.
- **VRChat 프리뷰** — `Tools / Studio Raming / MingToon / VRChat Preview`로 에디터 화면을 업로드 후 상태로 바꿔 봅니다. 카메라 깊이 없음 / 있음 두 가지이며, 켜져 있는 동안 씬 뷰에 배너가 뜹니다. → [문서](/platforms/vrchat#깊이-효과가-어디까지-보장되나)

## 변경

- **`그림자 패턴 (스크린톤)`이 독립 탭이 되었습니다.** Shadow Color 안의 한 그룹이 아니라 자체 마스터 토글·프리셋 행·복사 붙여넣기를 갖습니다. → [문서](/guides/shadow-pattern)
- **스크린톤을 인게임에서 켜고 끌 수 있습니다.** 편집용 셰이더에서 모듈이 컴파일에서 빠지지 않으므로, `그림자 패턴 사용`을 일반 float 애니메이션과 VRChat 표현 메뉴로 토글할 수 있습니다.
- **`림·추가광 최고 배율` 기본값이 2에서 3으로 올라갔습니다.** 팩토리 룩 프리셋도 같은 값으로 맞췄고, 조명 밝기 제한 그룹의 나머지 값은 그대로입니다. → [문서](/guides/light-and-shadow#라이팅--어두운-씬에서-검게-뭉칠-때)
- **`MingToon 2D 투영 그림자 드리우기`로 이름을 바꿨습니다** — 0.1.4까지의 `…캐스터`입니다. 동작은 같습니다.
- **룩 프리셋은 재질을 싸게 만들 수는 있어도 조용히 비싸게 만들지는 않습니다.** `- Low` 프리셋이 무거운 모듈을 끄는 동작은 그대로 두고, 룩이 성능 설정을 몰래 올리는 방향만 막았습니다.

## 개선

- **모듈을 토글할 때 파란색으로 멈춰 있는 시간을 줄였습니다.** 자주 켜고 끄는 룩 모듈 8종(맷캡 · 프레넬 림 · 툰 스페큘러 · 백라이트 · 프런트 라이트 · 림 셰이드 · 이미션 · 오클루전)을 편집용 셰이더에 미리 담아 두어, 그 뒤로는 토글해도 재컴파일이 없습니다. 베이크 산출물의 비용은 그대로입니다.
- **조명 변형을 설치 직후 한 번에 컴파일합니다.** 방향광·점광·스팟·버텍스 라이트처럼 작업 중 실제로 만드는 조합을 미리 구워, 라이트를 껐다 켜거나 새로 추가할 때 멈추지 않습니다. `Tools / Studio Raming / MingToon / Warm up shader variants`로 다시 실행할 수 있습니다.
- **lilToon 변환이 이미 구운 메시를 다시 쓰도록** 했습니다. 유니티가 사본에 붙이는 `(1)` 접미사 하나 때문에 같은 아바타가 매번 새 주소를 받아 전부 다시 굽고 있었습니다. → [문서](/workflow/liltoon-conversion)
- **깊이 마스크를 프래그먼트당 한 번만 읽습니다.** SSAO와 2D 그림자가 같은 텍스처를 같은 UV로 두 번 읽고 있었습니다.
- **`그림자 내부 반사`의 마스크에 키워드를 붙였습니다.** 마스크를 쓰지 않는 재질에서 명령어와 텍스처 샘플이 각각 줄어듭니다. → [문서](/guides/rim#그림자-내부-반사)

## 수정

- **`MingToon 2D 투영 그림자 드리우기`를 끈 재질이 통째로 어두워지던 문제** — 투명 재질의 깊이 프리패스가 같은 스위치에 묶여 있었고, 끈 재질의 깊이 모듈이 자기 몸 뒤를 읽어 안경 전체에 림과 내부 선을 깔고 있었습니다. → [문서](/guides/light-and-shadow#역광에서-몸에-캐릭터-모양-그림자가-겹칠-때)
- **스크린톤 `패턴 경계 부드러움`을 올리면 그림자가 없는 밝은 면에도 마크가 찍히던 문제** — 흐림 폭이 마크 크기를 넘지 못하도록 묶었습니다. 부드러움이 0이면 결과가 이전과 같습니다. → [문서](/guides/shadow-pattern)
- **스크린톤 `Overlay`가 `Recolor`와 구분되지 않던 문제** — 잉크가 그림자 영역 밖까지 번지고 있었습니다. 이제 그림자 안쪽에만 놓입니다.
- **툰 스페큘러의 합성 모드 `Screen`·`Overlay`에서 반사면이 검게 나오던 문제** — `[HDR]` 색이나 1을 넘는 강도가 들어오면 공식이 음수로 뒤집혔습니다. 같은 결함이 있던 `Hue`·`Color`도 함께 고쳤습니다. → [문서](/guides/detail-maps#툰-스페큘러)
- **2D 그림자를 끈 재질에서도 얼굴 보조 밀기가 동작하던 문제** — 프리셋에서 값만 따라온 재질이 얼굴에서 투영 그림자를 잃고 대신 받는 것도 없었습니다. → [문서](/guides/depth-effects#2d-그림자)
- **인스펙터 안내 정정** — `MingToon 2D 투영 그림자 드리우기` 툴팁이 실제 동작과 반대로 설명하던 것을 고치고, 통합 그림자를 끄면 각 층에 저장된 색이 돌아와 룩이 한 번에 바뀔 수 있다는 경고를 넣었습니다. 이 재질이 카메라 깊이에서 빠져 있을 때 깊이 모듈 화면에 그 사실을 알립니다.

## 문서

- 매뉴얼에 `조명 밝기 제한`과 `통합 그림자` 절을 3개국어로 새로 넣었습니다. 통합 그림자는 기본으로 켜져 있어 신규 재질에서 개별 그림자 색상이 숨는데, 그 이유가 어디에도 없었습니다.
- SSAO 설명 세 곳을 실제 동작에 맞게 고쳤습니다 — 오클루전 맵과 곱하는 것이 아니라 툰 밴드·스크린톤 뒤에 더 어두운 쪽을 취하고, 픽셀별 노이즈를 뿌리지 않으며, 소멸 거리 페이드는 그 값의 75% 지점에서 시작합니다.
- VRChat 호환성 문서의 얼굴 좌표계 서술을 실제 출하 경로에 맞게 고쳤습니다. → [문서](/platforms/vrchat#깊이-효과가-어디까지-보장되나)
