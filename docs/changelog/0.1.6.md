*클로즈 베타 · 2026-08-18*

## 업그레이드 시 확인할 것

:::danger[스키마 마이그레이션을 한 번 실행하세요]
`Tools > Studio Raming > MingToon > Advanced > Migrate Project To Current Schema`

머티리얼 스키마가 10에서 11로 올라갔습니다. 새로 생긴 `림라이트 마스크 사용`·`림 그림자 마스크 사용` 토글이 이전 재질에서는 꺼진 것으로 읽히므로, **돌리기 전까지 그 재질의 림 마스크가 적용되지 않습니다.** 마이그레이션이 흰색 기본값이 아닌 마스크를 찾아 토글을 켜 줍니다. → [설치](/getting-started/installation#이전-버전에서-올라왔다면)
:::

:::caution[베이크 캐시가 다시 생성되고, VRChat 아바타는 재업로드해야 합니다]
생성 셰이더 캐시 버전이 28에서 29로 올라가 기존 베이크 산출물이 무효가 됩니다. 다음 빌드에서 자동으로 다시 구워지므로 손댈 것은 없지만 그 한 번은 시간이 더 걸립니다. 셰이더는 아바타 에셋번들에 동봉되므로 **이미 올라간 아바타는 재업로드해야 이번 수정을 받습니다.**
:::

:::caution[`깊이 가용성`의 `Force On`이 미러를 제외합니다]
`Force On`은 이제 "호스트가 보고하지 못하는 경우까지 켠다, 단 미러는 제외"를 뜻합니다. 미러 안에서는 어떤 값을 골라도 깊이 모듈이 내려갑니다. → [문서](/guides/depth-effects#깊이-가용성)
:::

:::caution[Missing Depth Fallback(프레넬 폴백)이 제거되었습니다]
깊이가 없을 때 `2D 뎁스 림`이 프레넬 림으로 대체되던 기능이 없어졌습니다. 대체 모드를 Fresnel로 지정해 두었던 재질은 **그 림을 잃습니다.** 이제 깊이가 없으면 깊이 모듈은 조용히 내려갑니다.
:::

:::caution[아웃라인의 `셰이딩 포함` 동작이 바뀝니다]
아웃라인은 이제 베이스 맵 색과 조명 응답만으로 그려지고, 본체의 그림자 패턴·투영 그림자·깊이 효과를 선 위에 다시 그리지 않습니다. `셰이딩 포함`을 켜면 본체 셰이딩 전체를 복제하는 대신 형태 그림자 색을 따르는 가벼운 명암 밴드가 적용됩니다. → [문서](/guides/outline#아웃라인-색이-조명을-따라가게)
:::

:::caution[`Compile All Modules While Authoring`이 기본 켜짐이 되었습니다]
작업 중 토글이 셰이더 재컴파일을 기다리지 않게 하기 위한 변경입니다. 처음 켜질 때 콘솔에 한 줄 안내가 나오며, 일괄 편집 패널에서 끌 수 있습니다. 켜 둔 채 빌드해도 불필요한 키워드는 자동으로 정리되어 나갑니다.
:::

## 새 기능

- **`색조보정 범위 마스크`** — `베이스맵 HSVG` 보정을 마스크가 흰 곳에만 겁니다. 얼굴은 그대로 두고 눈만 색을 바꾸는 식의 부위 한정 보정에 씁니다. lilToon의 색조보정 마스크가 변환에서 이 자리로 들어옵니다. → [문서](/guides/basics#색조보정-범위-마스크)
- **`툰 스페큘러 색 방식`에 `Mask Texture Color` 추가** — 마스크에 칠해 둔 RGB가 하이라이트 색이 되어, 머리카락 하이라이트를 가닥마다 다른 색으로 나눌 수 있습니다. 텍스처를 한 번 더 읽지 않습니다. → [문서](/guides/detail-maps#하이라이트-색을-부위마다-다르게)
- **`얼굴 그림자 방식` 셀렉터** — 앞머리·소품 그림자를 리얼 그림자로 받을지 부드러운 2D 그림자로 그릴지 한 줄에서 고릅니다. 두 탭에 흩어져 있던 값이 함께 설정됩니다. → [문서](/guides/character#4단계-앞머리-그림자)
- **아웃라인 UV8 베이크의 `노멀을 편집한 모델용으로 계산`** — 구·원통에서 노멀을 옮겨온 헤어·스커트에서 외곽선 방향을 메시 면에서 다시 계산합니다. 기본은 꺼짐이라 이미 구운 캐릭터의 선은 달라지지 않습니다. → [문서](/guides/mesh-bakes#노멀을-편집한-모델용으로-계산)
- **`업로드 시 깊이 라이트 싣기` (기본 꺼짐)** — VRChat 업로드본에만 라이트를 하나 실어 카메라가 깊이를 그리게 합니다. 비용을 보는 사람이 내므로 인스펙터가 네 가지 비용을 먼저 보여 줍니다. → [문서](/platforms/vrchat#vrchat-깊이-라이트)
- **`림라이트 마스크 사용` · `림 그림자 마스크 사용`** — 두 림 마스크가 `그림자 내부 반사 마스크`와 같은 구조가 되어, 마스크를 쓰지 않는 재질은 마스크 텍스처를 아예 읽지 않습니다. 마스크를 쓰려면 토글을 먼저 켜세요. → [문서](/guides/rim#림-마스크)
- **`깊이 가용성`에 `Diagnostic` 추가** — 셰이더가 실제로 어떤 깊이 텍스처를 보고 있었는지 단색으로 칠해 알려 줍니다. 버그 신고 전용입니다. → [문서](/guides/depth-effects#diagnostic)
- **`VRC 라이트 볼륨` (기본 꺼짐)** — VRC Light Volumes를 쓰는 월드에서 `간접광 보정`과 그림자 색조가 유니티 프로브 대신 방의 볼륨을 따릅니다. Built-in 전용이며, 볼륨이 없는 환경에서는 프로브로 되돌아갑니다.
- **`Heal Material Keywords (Project)` 메뉴** — 프로젝트의 모든 MingToon 재질의 저장된 키워드와 패스 상태를 인스펙터 값과 일치시킵니다. 실행 전 확인 후 백업하며, 결과는 콘솔에 한 줄로 남습니다.
- **아웃라인 UV8이 필요하면 매니저가 먼저 알려 줍니다** — `노멀 소스`가 `UV8TS`인데 메시에 UV8이 없으면 밍툰 매니저 최상단에 경고와 베이크 버튼이 나타납니다. 버튼 위에 어디에 새 메시를 만들고 몇 개 렌더러를 처리할지 미리 표시합니다. → [문서](/guides/mesh-bakes#아웃라인-스무스-노멀-uv8)
- **일괄 편집 패널에 `그림자 컬러맵 사용`·`컬러맵 적용량` 추가** — 여러 재질을 선택해 한 번에 설정할 수 있습니다. → [문서](/guides/bulk-editing)

## 변경

- **Missing Depth Fallback(프레넬 폴백) 기능을 제거했습니다.** 깊이가 없으면 깊이 모듈이 그냥 내려갑니다.
- **아웃라인(클래식 헐)의 픽셀 비용이 약 1/3로 줄었습니다.** 아웃라인이 본체 셰이딩을 복제하지 않습니다. → [문서](/guides/outline#아웃라인-색이-조명을-따라가게)
- **`깊이 가용성`의 `Force On`이 미러를 제외합니다.** → [문서](/guides/depth-effects#깊이-가용성)
- **`Compile All Modules While Authoring`이 기본 켜짐이 되었습니다.**
- **`Prewarm Shader Variants` 메뉴가 없어졌습니다.** 같은 일을 하는 `Warm up shader variants`가 남습니다.

## 개선

- **인스펙터 토글이 더 이상 셰이더 컴파일을 기다리지 않습니다.** `글리터 마스크 사용`·`마스크 사용`(그림자 반사)·`2D 그림자 마스크`·`깊이 림 마스크`·`내부 경계 마스크`·`영역 마스크 사용`·`2차 그림자 사용` 7개 토글과 레이어 드롭다운, `Base Tint After HSVG`, `Face Shading Module`에서 토글당 2~6초의 재컴파일이 사라졌습니다. 그려지는 그림과 기본값은 그대로입니다.
- **셰이더 컴파일이 패키지 설치 시 한 번에 끝납니다.** 임포트 직후 취소 가능한 진행바와 함께 병렬로 굽고, 이후 변환·머티리얼 선택·편집 중에 컴파일 대기 구간이 없습니다. 취소한 지점부터 다음 실행이 이어받습니다.
- **변환 진행 상황이 단계별로 표시됩니다.** 머티리얼 변환 → 룩 프리셋 → 메시 베이크 진행바가 나오고, 완료 시 단계별 소요 시간이 콘솔에 한 줄로 남습니다. → [문서](/workflow/liltoon-conversion)
- **레이어 마스크가 통합 텍스처로 자동 합성됩니다.** 서페이스 스택·노멀·맷캡 마스크를 하나로 묶어 GPU가 읽는 텍스처 수를 줄입니다. 사용법과 조절값은 그대로이며, 합성본은 `MingToonGenerated/MaskPacks`에 자동 생성·공유됩니다.
- **아웃라인 패널이 메시에 UV8·버텍스 컬러가 있는지 보고합니다.** → [문서](/guides/outline#선-굵기를-부위마다-다르게)
- **아웃라인 UV8 베이크가 이미 구운 캐릭터를 거절하지 않습니다.** MingToon이 구운 UV8은 건너뛰고, 사용자 모델의 원래 UV8만 거절하며 어느 메시인지 이름으로 알려 줍니다.
- **인스펙터 툴바·섹션 헤더의 글자 잘림과 폭 조절 시 헤더 깜빡임을 고쳤고, 안내·경고 박스 글자를 본문 크기로 키웠습니다.**

## 수정

- **업로드 최적화(베이크)가 꺼놓은 모듈을 강제로 켜던 결함** — 거울이나 포스트 없는 카메라에서 아바타가 새하얗게 빛나던 신고의 근본 원인입니다. `이미션 사용`을 껐는데 기본 흰 맵으로 전면 발광하거나, 꺼진 `2D 그림자 마스크`가 동작하던 현상이 사라집니다.
- **VRChat 거울 안에서 `2D 그림자`와 `깊이 림`이 몸을 따라오지 않고 미끄러지던 문제** — 셰이더가 플레이어 카메라의 깊이 버퍼를 읽어 남의 실루엣을 쓰고 있었습니다. 이제 거울 안에서는 깊이 모듈이 자동으로 내려갑니다. → [문서](/guides/depth-effects#깊이-가용성)
- **리얼타임 디렉셔널 라이트가 없는 월드와 Disable Pixel Lights 거울에서 명암이 무너지고 창백해지던 문제** — 앰비언트 프로브에서 키 라이트를 합성해 어디서나 정상 셰이딩을 유지합니다. 디렉셔널 라이트가 있는 월드는 변화가 없습니다. → [문서](/guides/light-and-shadow#라이팅--어두운-씬에서-검게-뭉칠-때)
- **lilToon 변환이 값만 옮기고 모듈은 꺼진 채로 내보내던 문제** — `PBR 표면 사용`·`이미션 사용`·`표면 스택 사용`·`아웃라인 마스터`·`클래식 헐 사용` 토글이 이제 함께 켜집니다. 스택 2·3단 레이어와 아웃라인 방향·두께도 정확히 받습니다. → [문서](/workflow/liltoon-conversion)
- **`노멀 소스`가 `VertexColorTS`인데 버텍스 컬러가 없는 메시에서 아웃라인이 대각선으로 밀려 나가던 문제** — 메시 노멀로 내려갑니다. → [문서](/guides/outline#각진-부분에서-선이-끊길-때)
- **탄젠트나 노멀이 없는 파츠 하나가 아웃라인·얼굴·높이 베이크를 한꺼번에 죽이던 문제** — 그 렌더러만 건너뛰고 어느 메시인지 콘솔에 알려 줍니다.
- **같은 메시를 여러 렌더러가 공유할 때 베이크가 사본을 렌더러 수만큼 만들던 문제** — 소스 메시마다 에셋 하나를 만들고 모두 그것을 공유합니다.
- **변환이 사용자 모델의 UV8을 `이미 사용 중인 UV 채널 덮어쓰기`와 무관하게 지우던 문제** — 옵션이 꺼져 있으면 건너뛰고 보고합니다.
- **`Unified Shadow Color Map`을 꺼도 광역 컴파일 모드에서는 동작하지 않던 문제** — 이제 어떤 컴파일 모드에서도 확실히 꺼집니다. → [문서](/guides/light-and-shadow#통합-그림자--겹칠-때-새까매지는-문제)
- **아바타 SDK가 없는 VRChat 월드 프로젝트에서 `VRCExpressionsMenu` 컴파일 에러(CS0246)로 프로젝트가 깨지던 문제** — 표현식 메뉴 설치기가 월드 프로젝트에서는 자동으로 컴파일에서 제외됩니다.
- **Unity 2022 프로젝트에서 머티리얼을 선택하거나 편집하는 순간 베이스가 사라지고 아웃라인만 남던 현상** — 근본 원인을 찾아 고쳤습니다. 컴파일을 기다려도 재발하던 환경에서도 나타나지 않습니다. → [문제 해결](/troubleshooting#작업-중-인스펙터가-무겁다)
- **변환할 때 골라 둔 룩 프리셋 대신 목록 맨 위 프리셋이 적용되던 문제** — 스크립트 리로드나 오브젝트 재선택 뒤에도 선택이 유지됩니다. → [문서](/workflow/character-manager#변환-시-룩-프리셋)
- **룩 프리셋이 변환으로 옮겨온 맷캡·노멀 레이어·서페이스 스택을 끄거나 합성 모드를 전부 `Add`로 바꾸던 문제** — 룩 프리셋은 그림자·림 같은 "룩"만 다루고 레이어 콘텐츠는 그대로 둡니다.
- **`[MingToon] VRChat build hook compiled and registered.` 확인 로그가 표시되지 않던 문제** — 에디터 세션당 한 번 콘솔에 나옵니다. → [VRChat](/platforms/vrchat)
- **툰 스페큘러 마스크를 쓰지 않는 재질까지 마스크 텍스처를 읽던 것** — 두 림 마스크와 함께 사용 토글로 분리했습니다.
