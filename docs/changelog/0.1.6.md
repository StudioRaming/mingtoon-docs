*클로즈 베타 · 2026년 8월 18일*

## 한 줄 요약

아바타가 새하얗게 빛나던 문제를 고치고, 미러 안 깊이 효과를 정상화했습니다.

:::warning[업데이트 전 확인]
- 마이그레이션: `Migrate Project To Current Schema`를 한 번 실행하세요.
- 돌리기 전까지 기존 재질의 `림 라이트 마스크 사용`·`림 그림자 마스크 사용`이 꺼진 것으로 읽힙니다.
- 재베이크: 베이크 캐시가 무효가 되어 다음 빌드에서 자동으로 다시 구워집니다.
- 재업로드: 이미 올린 아바타는 다시 올려야 이번 수정을 받습니다.
- 룩이 바뀌는 항목: 아웃라인의 `셰이딩 포함`, 미러 안 깊이 효과, 어두운 씬의 명암.
- 깊이가 없을 때 뎁스 림라이트를 프레넬 림으로 대체하던 기능이 없어졌습니다.
:::

:::note[지금은 마이그레이션 메뉴가 보이지 않습니다]
위 `Migrate Project To Current Schema`는 현재 공개 빌드에 포함되지 않습니다(내부 도구 전용).
구버전 재질은 인스펙터 경고의 안내를 따르세요.
MingToon 메뉴는 0.1.7에서 최상위 `StudioRaming > MingToon`으로 옮겨졌습니다.
→ [0.1.7 패치노트](/changelog/0.1.7)
:::

## 새 기능

- **색조보정 범위 마스크** — `베이스맵 HSVG` 보정을 마스크가 흰 곳에만 겁니다. → [문서](/guides/basics#색조보정-범위-마스크)
- **Mask Texture Color** — `툰 스페큘러 색 방식`에 추가됐습니다. 마스크의 RGB가 하이라이트 색이 됩니다.
- **얼굴 그림자 방식** — 앞머리 그림자를 리얼 그림자로 받을지 뎁스 그림자로 그릴지 한 줄에서 고릅니다.
- **노멀을 편집한 모델용으로 계산** — 아웃라인 UV8 베이크에서 외곽선 방향을 메시 면에서 다시 계산합니다.
- **업로드 시 깊이 라이트 싣기** — VRChat 업로드본에만 라이트를 실어 카메라가 깊이를 그리게 합니다.
- **림 라이트 마스크 사용** · **림 그림자 마스크 사용** — 마스크를 쓰지 않는 재질은 텍스처를 읽지 않습니다.
- **Diagnostic** — `깊이 가용성`에 추가됐습니다. 셰이더가 본 깊이 텍스처를 단색으로 알려 줍니다.
- **VRC 라이트 볼륨 (테스트용)** — 볼륨을 쓰는 월드에서 간접광과 그림자 색조가 볼륨을 따릅니다.
- **Heal Material Keywords (Project)** — 저장된 키워드와 패스 상태를 인스펙터 값과 맞춥니다.
- `노멀 소스`가 `UV8TS`인데 메시에 UV8이 없으면 Manager 맨 위에 경고와 베이크 버튼이 뜹니다.
- 일괄 편집 패널에 `그림자 컬러맵 사용`·`컬러맵 적용량`이 추가됐습니다.

## 바뀐 기본값과 룩 변화

- 뎁스 그림자 (이전 이름: 2D 그림자)와 뎁스 림라이트는 깊이가 없으면 조용히 내려갑니다.
- `깊이 가용성`의 `Force On`이 미러를 제외합니다. 미러 안에서는 어떤 값이든 깊이 모듈이 꺼집니다.
- 아웃라인이 베이스 맵 색과 조명 응답만으로 그려집니다. 본체 셰이딩을 복제하지 않습니다.
- `셰이딩 포함`을 켜면 형태 그림자 색을 따르는 가벼운 명암 밴드만 적용됩니다.
- 아웃라인의 픽셀 비용이 약 1/3로 줄었습니다.
- `Compile All Modules While Authoring`이 기본 켜짐이 됐습니다. 일괄 편집 패널에서 끌 수 있습니다.
- `Prewarm Shader Variants` 메뉴가 없어지고 `Warm up shader variants`만 남습니다.
- `노멀을 편집한 모델용으로 계산`은 기본 꺼짐이라 이미 구운 캐릭터의 선은 달라지지 않습니다.
- 레이어 마스크가 하나로 합성되어 GPU가 읽는 텍스처 수가 줄어듭니다. 조절값은 그대로입니다.

## 수정된 문제

- 거울이나 포스트 없는 카메라에서 아바타가 새하얗게 빛나던 문제가 고쳐졌습니다.
- 업로드 최적화가 꺼 둔 모듈을 강제로 켜던 것이 원인입니다.
- VRChat 거울 안에서 뎁스 그림자와 뎁스 림라이트가 몸을 따라오지 않고 미끄러지던 문제.
- 디렉셔널 라이트가 없는 월드와 Disable Pixel Lights 거울에서 명암이 창백해지던 문제.
- lilToon 변환이 값만 옮기고 모듈은 꺼진 채로 내보내던 문제가 고쳐졌습니다.
- 버텍스 컬러가 없는 메시에서 아웃라인이 대각선으로 밀려 나가던 문제가 고쳐졌습니다.
- 탄젠트나 노멀이 없는 파츠 하나가 베이크를 한꺼번에 죽이던 문제가 고쳐졌습니다.
- 같은 메시를 여러 렌더러가 공유할 때 베이크가 사본을 렌더러 수만큼 만들던 문제.
- 변환이 사용자 모델의 UV8을 옵션과 무관하게 지우던 문제가 고쳐졌습니다.
- `Unified Shadow Color Map`을 꺼도 광역 컴파일 모드에서는 켜져 있던 문제가 고쳐졌습니다.
- 아바타 SDK가 없는 월드 프로젝트에서 CS0246 컴파일 에러로 프로젝트가 깨지던 문제.
- Unity 2022에서 재질을 고르면 베이스가 사라지고 아웃라인만 남던 문제가 고쳐졌습니다.
- 변환할 때 골라 둔 룩 프리셋 대신 목록 맨 위 프리셋이 적용되던 문제가 고쳐졌습니다.
- 룩 프리셋이 변환으로 옮겨온 레이어를 끄거나 합성 모드를 전부 `Add`로 바꾸던 문제.
- `[MingToon] VRChat build hook compiled and registered.` 확인 로그가 안 뜨던 문제.
- 인스펙터 툴바·섹션 헤더의 글자 잘림과 폭 조절 시 헤더 깜빡임이 고쳐졌습니다.
- 인스펙터 토글 7종에서 토글당 2~6초의 재컴파일이 사라졌습니다. 그림과 기본값은 그대로입니다.

## 알려진 제한

- 대체 모드를 Fresnel로 지정해 두었던 재질은 그 림을 잃습니다.
- 첫 베이크는 캐시를 다시 만들기 때문에 한 번은 시간이 더 걸립니다.
- 셰이더 컴파일은 패키지 설치 때 한 번에 끝납니다. 취소하면 다음 실행이 이어받습니다.
- `VRC 라이트 볼륨 (테스트용)`은 Built-in 전용입니다.
