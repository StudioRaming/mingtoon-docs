*클로즈 베타 · 2026년 8월 3일*

## 한 줄 요약

얇은 부위가 빛을 머금는 투과광과 마스터 조정이 생겼습니다.

:::warning[업데이트 전 확인]
- 컴포넌트: MingToon 컴포넌트를 손으로 지우지 마세요. 캐시된 렌더러 목록이 함께 사라집니다.
- 얼굴 지정: `Auto`가 이름 추측을 하지 않습니다. 원본 재질의 얼굴 플래그만 읽습니다.
- Standard나 URP Lit에서 변환하면 모든 슬롯이 `Regular`로 남습니다. 직접 `Face`로 지정하세요.
- 룩이 바뀌는 항목: `얼굴 경계`가 음수를 받지 않습니다. 기존 −0.3은 0으로 읽힙니다.
- 얼굴에 그림자가 조금 더 집니다. 얼굴 재질에서 이 값을 다시 잡으세요.
- 통합 그림자에서 투영 그림자가 형태 그림자 위에서 더 진해지던 동작이 사라졌습니다.
- 매니저 단계 번호가 `1 · 변환` → `2 · 설정` → `3 · 세부 설정`으로 바뀌었습니다.
:::

:::note[지금은]
MingToon 컴포넌트의 자동 삭제는 보장되지 않습니다. 위 안내는 0.1.3 당시 기준입니다.
→ [VRChat](/platforms/vrchat)
:::

## 새 기능

- **SSSSS (실험적)** (이전 이름: 깊이 투과광) — 머리끝이나 옷자락이 빛을 머금습니다.
- 광원 방향으로 깊이를 두 번 읽어 직접 잽니다. `마스터 폭`과 무관하게 동작합니다. → [문서](/guides/depth-effects#깊이-투과광)
- **마스터 조정** — 인스펙터 첫 번째 섹션입니다. 씬이 바뀔 때 한 번에 다시 맞춥니다.
- `빛을 더하는 것 전부`·`그림자 전부`·`최종 출력` 세 묶음에 `밝기 배수`와 `틴트`를 겁니다.
- **화면 공간 그림자 겹침 심도** (이전 이름: 2D 그림자 겹침 심도) — 겹친 부분을 더 진하게 만듭니다.
- 0이면 완전히 한 색입니다. → [문서](/guides/light-and-shadow#통합-그림자--겹칠-때-새까매지는-문제)
- **림·추가광도 상한 적용** — 림 계열이 전부 더해진 뒤에 밝기 상한을 겁니다. 기본은 꺼짐입니다.
- 기존 `최종 조명 최고 배율`은 더해지기 전에 걸려서 림을 올리면 그대로 탔습니다.
- **Skin** — 맨살 전용 룩 값을 받는 슬롯 역할입니다. `피부 렌더러 직접 지정`으로 한 번에 지정합니다.
- **업로드 준비 점검** — 계층과 Manifest를 훑어 업로드를 막는 문제를 진단 코드로 보고합니다.
- **상태 패널** — 재질 구성·셰이딩 상태·얼굴 슬롯 동기화·최적화 범위를 매니저 상단에 표시합니다.
- 얼굴 범위를 마스크 텍스처 없이 버텍스 페인트로 직접 칠합니다. 아웃라인 채널과 분리돼 있습니다.
- 섹션 단위로 프리셋을 저장하고 적용합니다. 텍스처 포함 여부를 고를 수 있습니다.
- WARUDO Runtime Root가 카메라 깊이와 머리 방향을 셰이더에 공급합니다.

:::note[지금은]
별도 Runtime Root를 프리팹에 붙이지 않습니다. 위 안내는 0.1.3 당시 기준입니다.
→ [밍툰 매니저](/workflow/character-manager)
:::

## 바뀐 기본값과 룩 변화

- lilToon 외에 Standard, URP Lit 등에서도 변환할 수 있습니다.
- 이 경우 베이스 색·텍스처·노멀·이미션·오클루전과 렌더 상태만 옮겨집니다.
- 파티클/VFX, 굴절/보석, 퍼/쉘, 오디오 반응, 플립북은 옮길 수 없어 원본을 그대로 둡니다.
- 헐 노멀 소스 기본값이 `UV8TS`가 됐습니다. UV8을 굽기만 하면 됩니다.
- `캐릭터 루트`가 `밍툰 매니저`로, `lilToon 빠른 변환`이 `셰이더 변환`으로 이름이 바뀌었습니다.
- 프리셋은 수치와 색만 적용합니다. 텍스처·렌더 큐·RenderType 태그는 건드리지 않습니다.
- 얼굴 SDF Baker가 별도 에디터 패키지로 분리됐습니다. 없으면 해당 버튼이 열리지 않습니다.
- 노멀 강도에 음수를 넣을 수 있습니다. 요철이 반대로 뒤집힙니다.
- `SDF 얼굴 그림자 사용`이 얼굴 SDF 섹션의 맨 위 마스터 토글이 됐습니다.
- 노멀맵 타일링이 슬롯 바로 아래로 나왔습니다. 바깥의 마스크 타일링과 일부러 따로 둡니다.
- `얼굴 셰이딩`은 이번 버전에서 적용되지 않습니다. 켜져 있던 재질도 꺼진 상태로 읽힙니다.

## 수정된 문제

- MingToon을 처음 넣으면 프로젝트의 모든 텍스처가 다시 임포트되던 문제가 고쳐졌습니다.
- 얼굴 SDF와 하프톤 패턴 텍스처가 VRChat 업로드를 막던 문제가 고쳐졌습니다.
- 얼굴 형태 그림자 경계에 선이 하나 더 그려지던 문제가 고쳐졌습니다.
- 얼굴로 지정한 영역에도 투영 그림자가 지던 문제가 고쳐졌습니다.
- 통합 그림자에서 캐스트와 뎁스 그림자 (이전 이름: 2D 그림자)가 한 색으로 모이지 않던 문제.
- 뎁스 림라이트 (이전 이름: 2D 뎁스 림)의 폴백 쪽에만 마스터가 걸리지 않던 문제.
- 씬 뷰가 몇 분씩 멈추던 문제가 고쳐졌습니다. 씬 뷰 이벤트마다 전체 오브젝트를 훑고 있었습니다.
- 구워서 만든 텍스처가 VRChat 업로드를 막던 문제가 고쳐졌습니다.
- 버텍스 페인트로 칠할 때마다 멈추던 문제가 고쳐졌습니다.

## 알려진 제한

- 범용 셰이더 변환은 대응하지 않는 값을 기본값으로 둡니다.
- 변환 짝 검사는 시간이 걸려 버튼을 눌렀을 때만 실행됩니다.
- 에디터 런타임 미리보기는 VRChat 업로드에 실리지 않습니다.
- UV7은 얼굴 노멀 베이크와 얼굴 SDF가 함께 쓰므로 둘 중 하나만 소유할 수 있습니다.
