*클로즈 베타*

## 핫픽스 1 · 2026-08-03

- **MingToon을 처음 넣으면 프로젝트의 모든 텍스처가 다시 임포트되던 문제** — 얼굴 SDF 텍스처 임포터가 전역 `AssetPostprocessor`여서 프로젝트의 텍스처 전부가 MingToon에 의존하고 있었습니다. 텍스처가 많은 프로젝트에서는 첫 임포트가 몇 시간씩 걸렸습니다.
- **얼굴 SDF와 하프톤 패턴 텍스처가 VRChat 업로드를 막던 문제** — `Streaming Mip Maps`가 꺼진 채로 들어 있었습니다.

## 업그레이드 시 확인할 것

:::danger[MingToon 컴포넌트를 직접 지우지 마세요]
VRChat 업로드에서 **자동으로 제거**됩니다. 손으로 지우면 캐시된 렌더러 목록이 함께 사라져 **업로드 최적화가 범위를 잃고**, 최적화되지 않은 재질이 그대로 올라갑니다. → [VRChat](/platforms/vrchat)
:::

:::caution[얼굴 Auto 판정이 이름 추측을 하지 않습니다]
`Auto`는 이제 **원본 재질이 가진 얼굴 플래그만** 읽습니다. Standard나 URP Lit에서 변환하면 **모든 슬롯이 `Regular`로 남으므로**, 얼굴로 쓸 슬롯을 직접 `Face`로 지정해야 합니다. → [밍툰 매니저](/workflow/character-manager#얼굴--피부-지정--가장-중요한-단계)
:::

:::caution[밍툰 매니저 단계 번호가 바뀌었습니다]
`1 · 변환` → `2 · 설정` → `3 · 세부 설정` 순서입니다. 기존 메모의 단계 번호와 다릅니다.
:::

:::caution[`얼굴 경계`가 음수를 받지 않습니다]
0 미만은 얼굴 그림자 경계를 머리 뒤쪽 면이 큰 구간에 놓아 계단처럼 각지게 만들었습니다. 이전 기본값 −0.3을 쓰던 재질은 **0으로 읽혀 얼굴에 그림자가 조금 더 집니다.** 얼굴 재질에서 이 값을 다시 잡아 주세요. → [문서](/guides/light-and-shadow#1-형태-그림자-경계--가장-먼저)
:::

:::caution[통합 그림자에서 캐스트 섀도우가 항상 한 색으로 합쳐집니다]
투영 그림자가 형태 그림자 위에 겹칠 때 더 진해지던 동작이 사라졌습니다. 겹친 부분을 다시 진하게 만들고 싶으면 **`2D 그림자 겹침 심도`** 를 올리세요. → [문서](/guides/light-and-shadow#통합-그림자--겹칠-때-새까매지는-문제)
:::

## 새 기능

- **깊이 투과광** — 머리끝이나 옷자락처럼 얇은 부위가 빛을 머금은 것처럼 보입니다. 광원 방향으로 깊이를 두 번 읽어 직접 재므로 `마스터 폭`과 무관하게 단독으로 동작합니다. → [문서](/guides/depth-effects#깊이-투과광)
- **업로드 준비 점검** — 계층과 Manifest를 훑어 업로드를 막는 문제를 진단 코드로 보고합니다. → [문서](/workflow/character-manager#업로드-준비-점검)
- **상태 패널** — 재질 구성, 셰이딩 상태, 얼굴 슬롯 동기화, 최적화 범위를 매니저 상단에 상시 표시합니다.
- **VRChat 사전 점검 · Quest 점검** — 없는 표준 프로퍼티와 허용되지 않는 컴포넌트를 세고, Quest에서 잃는 항목을 개수로 보여 줍니다.
- **`Skin` 역할** — 맨살 전용 룩 값을 받는 슬롯 역할이 추가됐습니다. `피부 렌더러 직접 지정`으로 한 번에 지정할 수 있습니다.
- **탭 프리셋** — 섹션 단위로 프리셋을 저장·적용합니다. 텍스처 포함 여부를 고를 수 있습니다.
- **WARUDO Runtime Root** — Warudo 모드에서 카메라 깊이와 머리 방향을 셰이더에 공급하는 독립 런타임 컴포넌트입니다. → [Warudo](/platforms/warudo#내보내기-전-필수--warudo-runtime-root)
- **`마스터 조정`** — 인스펙터 첫 번째 섹션입니다. `빛을 더하는 것 전부` · `그림자 전부` · `최종 출력` 세 묶음에 각각 `밝기 배수`와 `틴트`를 걸어 씬이 바뀔 때 한 번에 다시 맞춥니다.
- **`림·추가광도 상한 적용`** — 백라이트 · 프런트라이트 · 프레넬 림 · 그림자 내부반사 · 2D 뎁스 림 · 깊이 투과광 · 글리터가 전부 더해진 뒤에 밝기 상한을 겁니다. 기존 `최종 조명 최고 배율`은 이것들이 더해지기 전에 걸려서 림을 올리면 그대로 탔습니다. 기본은 꺼져 있습니다. → [문서](/guides/light-and-shadow#라이팅--어두운-씬에서-검게-뭉칠-때)
- **`2D 그림자 겹침 심도`** — 통합 그림자 모드에서 2D 그림자가 형태 그림자 안에 들어갔을 때 얼마나 더 진해질지 정합니다. 0이면 완전히 한 색입니다. → [문서](/guides/light-and-shadow#통합-그림자--겹칠-때-새까매지는-문제)
- **얼굴 영역을 버텍스 페인트로 지정** — 마스크 텍스처 없이 얼굴 범위를 직접 칠합니다. 아웃라인이 쓰는 채널과 분리되어 있어 둘을 같이 쓸 수 있습니다.
- **셰이더 변형 미리 컴파일** — 변환이 끝날 때 자동으로 실행되고, `Tools > Studio Raming > MingToon > Prewarm Shader Variants` 로도 부를 수 있습니다.

## 변경

- **범용 셰이더 변환** — lilToon 외에 Standard, URP Lit 등에서도 변환할 수 있습니다. 이 경우 베이스 색·텍스처·노멀·이미션·오클루전과 렌더 상태가 옮겨지고 나머지는 기본값이 됩니다.
- **변환 제외 계열** — 파티클/VFX, 굴절/보석, 퍼/쉘, 오디오 반응, 플립북/스크롤, 외곽선 전용·보조 패스는 옮길 수 없어 원본을 그대로 둡니다. → [문서](/workflow/character-manager#변환되지-않는-슬롯)
- **헐 노멀 소스 기본값이 `UV8TS`** — UV8을 굽기만 하면 됩니다. 재질에서 따로 바꿀 것이 없습니다. → [문서](/guides/mesh-bakes#아웃라인-스무스-노멀-uv8)
- **`캐릭터 루트` → `밍툰 매니저`** 로 이름이 바뀌었습니다.
- **`lilToon 빠른 변환` → `셰이더 변환`** 으로 이름이 바뀌었습니다.
- **프리셋이 담는 범위** — 수치와 색만 적용합니다. 텍스처·벡터·렌더 큐·인스턴싱·RenderType 태그는 건드리지 않습니다.
- **얼굴 SDF Baker가 별도 에디터 패키지로 분리**됐습니다. 설치하지 않으면 해당 버튼이 열리지 않습니다.
- **노멀 강도에 음수를 넣을 수 있습니다.** 요철이 반대로 뒤집힙니다.
- **`SDF 얼굴 그림자 사용`이 얼굴 SDF 섹션의 맨 위 마스터 토글**이 됐습니다. 켜야 나머지가 펼쳐집니다.
- **노멀맵 타일링이 슬롯 바로 아래**로 나왔습니다. 접힌 안쪽에 있어 바깥의 마스크 타일링과 헷갈리던 문제를 없앴습니다. 두 값은 일부러 따로 둡니다.
- **`얼굴 셰이딩`은 이번 버전에서 적용되지 않습니다.** 개발 중이라 섹션이 숨겨져 있고, 켜져 있던 재질과 프리셋도 꺼진 상태로 읽힙니다. 얼굴 변환과 나머지 얼굴 기능은 그대로 동작합니다.

## 개선

- **UV 채널 사용 현황** — `UV4 · UV7 · UV8`이 각각 비었는지 사용 중인지 표시합니다. UV7은 얼굴 노멀 베이크와 얼굴 SDF가 함께 쓰므로 둘 중 하나만 소유할 수 있다는 안내가 함께 나옵니다.
- **변환 짝 검사** — 변환 재질과 원본의 짝을 확인합니다. 시간이 걸려 버튼을 눌렀을 때만 실행됩니다.
- **얼굴 모듈 동기화** — 얼굴 슬롯의 키워드가 재질 값과 어긋나면 경고하고 한 번에 맞춥니다. 어긋난 채로 베이크하면 얼굴 셰이딩이 빠집니다.
- **최적화 범위 경고** — 렌더러 캐시가 낡으면 몇 개가 최적화 없이 업로드되는지 알려 줍니다.
- **에디터 런타임 미리보기** — 룩 프로필과 런타임 얼굴 방향을 에디터에서 미리 볼 수 있습니다. VRChat 업로드에는 실리지 않습니다.
- **재질 부하 예상치가 검색창 옆으로** 올라왔습니다. 한 줄로 나오고 펼치면 자세히 보입니다.
- **버텍스 페인트** — 실시간 오버레이, X축 대칭, 브러시 세기·불투명도, 창 이동을 지원합니다. 칠할 때마다 멈추던 문제도 없앴습니다.
- **변환 탭** — 직접 지정한 렌더러가 슬롯 요약에 반영되고, 스킨을 얼굴·일반과 따로 셉니다. 그림자 색상·프레넬 덮어쓰기 여부를 고를 수 있고, 이미 변환된 캐릭터에 룩 프리셋만 다시 씌울 수 있습니다.
- **항목별 프리셋 · 룩 프리셋 목록**이 분류별로 펼쳐져 보입니다.

## 수정

- **얼굴 형태 그림자 경계에 선이 하나 더 그려지던 문제** — 테두리가 얼굴이 아니라 몸통 종단자 위치에 그려지고 있었습니다.
- **얼굴로 지정한 영역에도 투영 그림자가 지던 문제.**
- **통합 그림자에서 캐스트와 2D가 한 색으로 수렴하지 않던 문제** — 아웃라인 헐과 추가 광원 경로가 밝기 상한을 타지 않아 그쪽만 계속 탔습니다.
- **깊이 림 두 종류 중 폴백 림에만 마스터가 걸리지 않던 문제** — 뎁스가 없는 카메라에서 결과가 달라졌습니다.
- **씬 뷰가 몇 분씩 멈추던 문제** — 포스트 프로세싱 연결이 씬 뷰 이벤트마다 전체 오브젝트를 다시 훑고 있었습니다.
- **굽기로 만든 텍스처가 VRChat 업로드를 막던 문제** — 마스크 팩·표면 병합·얼굴 SDF 결과물에 `Streaming Mip Maps`가 꺼져 있었습니다.
