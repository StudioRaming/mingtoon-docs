*클로즈 베타 · 2026-08-22*

0.1.7은 0.1.6 이후의 누적 업데이트입니다. 얼굴 저작 흐름, 그림자와 SSAO, VRChat 런타임 제어, 변환·베이크 안정성, 인스펙터와 밍툰 매니저를 함께 정리했습니다.

## 업그레이드 시 확인할 것

:::caution[생성 셰이더와 메시 베이크 캐시가 다시 만들어집니다]
Generator와 베이크 입력 계약이 바뀌었습니다. 다음 빌드에서 자동 재생성되지만 첫 빌드는 평소보다 오래 걸릴 수 있습니다. 셰이더는 아바타 에셋번들에 포함되므로 **이미 업로드한 VRChat 아바타는 다시 업로드해야 0.1.7 수정과 최적화를 받습니다.**
:::

:::caution[이전에 얼굴 노멀 UV7을 구웠다면 Live로 되돌리세요]
0.1.7부터 얼굴 노멀 누름은 편집 중 셰이더가 실시간 계산하고, VRChat 업로드 복사본에만 자동 베이크합니다. 밍툰 매니저의 `얼굴 노멀 실시간으로 되돌리기`를 한 번 실행하세요. 예전 tangent-normal UV7을 가진 재질이 Face SDF UV7을 선택한 경우에는 좌표 오독을 막기 위해 `얼굴 맵 좌표`도 Base UV로 되돌립니다. 이 작업은 Undo할 수 있습니다.
:::

:::caution[그림자와 SSAO 모양이 달라질 수 있습니다]

- `2D 그림자 소멸 거리` 기본값은 12m입니다. 9m부터 옅어지고 12m에서 사라집니다. 이전처럼 무한 거리로 쓰려면 0으로 두세요.
- `투영 페더 반경`의 실제 범위는 0~48px입니다. 48을 넘던 저장값은 슬라이더를 다시 만질 때 48로 제한됩니다.
- SSAO 반경 기본값은 0.005, 상한은 0.01로 바뀌었습니다. 가장자리와 자기면 자국은 더 부드럽게 처리됩니다.
- 그림자 경계의 캐스트 밴드 위치와 합성 순서가 바뀌었습니다. 경계를 쓰던 재질은 코어 쪽에 더 또렷하게 보일 수 있습니다.
:::

:::caution[제거된 얼굴 캐스트 항목이 있습니다]
`얼굴 균일 캐스트`와 `얼굴 캐스트 안정화`는 실제 효과가 성립하지 않아 제거했습니다. 해당 값을 쓰던 재질은 기본 캐스트 수신 동작으로 돌아갑니다.
:::

:::caution[VRChat Expressions를 다시 설치하세요]
0.1.7은 기본 **전체 메뉴 28개: 동기화 21개·77비트 + 로컬 7개·0비트**와 **가벼운 메뉴 12개: 동기화 10개·31비트 + 로컬 2개·0비트**를 제공합니다. 밍툰 매니저의 전체 조정 메뉴 사용을 고른 뒤 기존 설치를 갱신하고 Gesture Manager에서 확인하세요.
:::

:::caution[조명 기본값은 새 재질과 팩토리 프리셋에만 적용됩니다]
`씬 조명 색상 영향`·`간접광 보정`·`추가 광원 PBR / 툰 혼합` 등 9개 기본값을 실사용 세팅에 맞췄고 `2D 투과광`은 기본 꺼짐이 됐습니다. 이미 저장된 재질 값은 바뀌지 않습니다. 팩토리 프리셋을 다시 적용하거나 기본값 복원을 실행할 때만 새 값이 들어갑니다.
:::

:::caution[Face SDF Studio와 Mask Maker는 별도 제품입니다]
두 도구는 MingToon 패키지에 동봉되지 않습니다. 설치돼 있으면 인스펙터와 밍툰 매니저에서 연동되고, 없으면 설치 안내만 표시됩니다. MingToon 셰이더와 기본 저작 기능은 그대로 동작합니다.
:::

## 새 기능

### 얼굴 저작과 깊이

- **실시간 얼굴 노멀 누름** — 프록시 중심·반지름·모양·높이·노멀 방식·강도를 바꾸면 SceneView와 GameView에 바로 반영됩니다. 업로드 시에는 업로드 복사본만 자동 베이크하고 씬 원본은 건드리지 않습니다.
- **구·원통·캡슐 얼굴 프록시** — 노멀 방향과 얼굴 영역을 같은 프록시로 맞출 수 있습니다. 캡슐 높이와 축도 씬 도구에서 편집합니다.
- **깊이가 없는 화면의 얼굴 투영 그림자 폴백** — 명시적으로 옵트인한 재질은 깊이 텍스처가 없어도 얼굴 그림자 텍스처 경로를 유지할 수 있습니다.
- **Avatar Interior Shield** — 카메라가 닫힌 몸·얼굴 표면을 실제로 통과한 뒤에만 원하는 색으로 내부를 덮습니다. Fast/Balanced/Robust 품질, 관통 경계 안정화, 색상·불투명도, 폐곡면 진단을 제공합니다.

### 그림자·SSAO·림

- **2D 림 샘플 품질 1 / 2 / 4탭** — 품질과 비용을 재질별 또는 VRC 품질 티어로 조절합니다.
- **2D 그림자 소멸 거리** — 기본 12m이며 먼 거리에서는 탭 수도 함께 줄어듭니다. 화면 가장자리 오검출과 가까운 별도 메시 사이의 끊김도 완화했습니다.
- **깊이 효과 런타임 전환 옵트인** — VRC FX에서 깊이 효과 전체를 실제로 끄고 관련 샘플 비용을 건너뜁니다.
- **Shadow Projection 런타임 전환 옵트인** — VRC 품질 메뉴에서 투영 그림자만 따로 켜고 끕니다.
- **가장자리 림 그룹 마스터·색상·강도·상한** — 2D 림, 프레넬 림, 백라이트 같은 실루엣 계열을 한 번에 조정하고 별도 HDR 피크를 제한합니다.
- **림 종류별 색 순도** — 백라이트·프런트 라이트·프레넬 림·그림자 내부 반사·2D 림·투과광 가장자리/안쪽의 채도를 각각 0~10으로 조정합니다. 베이스 색, 개별 틴트와 색 보정을 모두 합성한 뒤 적용되며 1은 기존 결과입니다.
- **내부 반사·SSAO의 `그림자 안 표시`** — 기존 그림자 안에서 각 효과가 얼마나 남을지 따로 정합니다. WARUDO Built-in의 포인트·스폿 추가광 반사에는 이 게이트가 적용되지 않습니다.
- **글리터 맷캡 제한** — 맷캡 텍스처로 시선 방향의 글리터 영역을 거릅니다.

### 디테일과 출력

- **발광 레이어 2** — 서로 다른 맵·색·강도를 더해서 부위별 발광을 만듭니다.
- **발광 맵 알파 세기 마스크** — 두 발광 레이어 모두 맵 알파를 픽셀별 강도로 사용합니다. 추가 텍스처 샘플은 없습니다.
- **발광 시간 애니메이션** — 레이어별 스크롤, 깜빡임, 어두울수록 발광을 설정합니다.
- **맷캡 5슬롯 확장** — 슬롯별 회전·원형 마스크·발광 기여와 공용 맷캡 노멀맵 강도를 지원합니다.
- **렌더 비활성화** — 특정 재질의 모든 패스를 빼 드로우 콜 자체를 없앱니다. Material 패스 상태이므로 런타임 토글은 Renderer나 GameObject로 처리합니다.

### 인스펙터와 밍툰 매니저

- **재질 설정 복사·붙여넣기** — `전체`·`값만`·`텍스처만`·`키워드만`·`렌더 큐만` 다섯 방식과 Undo를 지원합니다.
- **고정 툴바와 섹션 내비게이션** — 스크롤해도 상단 도구가 남고, 색상 막대로 그룹 위치를 바로 이동합니다.
- **전부 접기 / 전부 펼치기 / 변경값만** — `변경값만`은 셰이더 기본값과 다른 행만 남기고 관련 섹션을 자동으로 펼칩니다.
- **빠른 설정과 재질 부하 요약** — 자주 쓰는 값과 베이크 후 예상 비용을 인스펙터 상단에서 확인합니다.
- **재질 역할 지정 흐름 정리** — 밍툰 매니저 1단계에서 Face / Skin / Common을 렌더러와 슬롯별로 지정하고 변환 룩의 적용 대상을 바로 확인합니다.
- **밍툰 매니저 4단계 흐름** — `1 · 변환` → `2 · 설정` → `3 · 세부 설정` → `4 · 출하` 순서로 정리하고, 현재 단계에서 해야 할 일과 보류 이유를 표시합니다.
- **페이스 재질만 선택** — 얼굴 프록시 편집과 얼굴 일괄 조정 전에 Face 재질만 고릅니다.
- **업로드 시 텍스처 해상도 상한** — 베이스·노멀·마스크 등 슬롯 종류별 최대 해상도를 정해 업로드 복사본만 줄입니다. 원본 텍스처는 바꾸지 않습니다.

### 변환·VRChat

- **분홍색 Missing Shader 재질 변환** — 저장된 프로퍼티를 읽어 NiloToon·lilToon·Standard 계열을 복구 변환합니다.
- **렌더 상태 전체 보존** — 스텐실, 렌더 큐, Cull, Cutout·Fade·Premultiply 등 투명 모드를 변환 결과에 이어받습니다.
- **VRC 품질 티어 Low / Mid / High** — High는 저작값을 유지하고, Mid는 샘플 수를 제한하며, Low는 샘플 수를 더 낮추고 깊이 효과 마스터와 투영 그림자 페더를 끕니다.
- **8색 × 4채도 압축 팔레트** — Warm·Gold·Mint·Cyan·Blue·Violet·Rose·Red와 Neutral·Soft·Medium·Full을 Int 한 개에 담습니다. Highlight·Shadow·Final Output은 같은 팔레트를 공유하면서 Tint 영향량과 강도를 각각 따로 고릅니다.
- **Photo Looks 8종** — 어두운 월드 보정, Flat Studio, Unlit 기준, 따뜻한·차가운 인물, 발광/백라이트 제거를 한 버튼으로 전환합니다. 자기 아바타 결과를 동기화하며 월드/Udon이 필요한 타 아바타 일괄 제어는 포함하지 않습니다.
- **VRC 전체/가벼운 메뉴 선택** — 전체 메뉴는 28개 중 동기화 21개가 77비트, 가벼운 메뉴는 12개 중 동기화 10개가 31비트를 씁니다. 가벼운 메뉴도 Virtual Light 핵심, High/Mid/Low, Shadow Projection, Reset을 유지합니다.
- **프로필 전환 정리** — 전체 조정 메뉴 사용을 바꿔 재설치하면 현재 프로필에 없는 MingToon 파라미터·FX 레이어·생성 메뉴를 제거합니다.
- **VRC Light Volumes 확장** — 간접광뿐 아니라 볼륨 스페큘러, 포인트 라이트 그림자, 노멀 바이어스와 강도를 지원합니다. 아바타 업로드에서는 필요한 변형을 자동 활성화하고, 월드 빌드에서는 씬에 Light Volumes가 있을 때만 켭니다.
- **Expressions 루트 직접 배치** — 전체는 Virtual Light·Master Adjust·Reset, 가벼운 메뉴는 Virtual Light·Quality·Reset을 루트에 둘 수 있습니다. 세 칸이 없으면 폴더 방식으로 돌아갑니다.

## 변경

- **인스펙터 정보 구조 재편** — `라이팅`은 기본 설정으로, `그림자`는 독립 그룹으로 이동했습니다. PBR 표면·툰 스페큘러·영역 마스크는 `PBR` 그룹이 됐고, 깊이 섹션은 결과 중심 이름으로 정리했습니다.
- **간단 모드 재정의** — 실제 첫 설정에 필요한 항목만 남기고 고급 진단과 내부 기술 정보는 정식 빌드에서 숨겼습니다. 변형 덤프·레코드, Depth Debug Post Process도 `MINGTOON_DEV` 빌드에서만 보입니다.
- **추가 광원 상한 의미 변경** — 베이스 색 배수가 아니라 HDR 피크를 직접 제한합니다. 어두운 재질의 스페큘러를 지우지 않으면서 다중 광원의 폭주를 막고, `림·추가광도 상한 적용`이 켜져 있으면 주광을 포함한 효과 입력 인텐시티도 1·3 같은 상한값까지 제한합니다.
- **그림자 경계 재설계** — 캐스트 밴드는 밝은 쪽에서 차오르고 그림자 코어 직전에 정점을 찍습니다. 모든 그림자·SSAO 위, 가산광 앞에서 마지막으로 합성되며 통합 그림자 안의 떠다니는 윤곽은 제거됩니다.
- **SSAO 합성 방식 변경** — SSAO 색은 기존 그림자의 증분이 아니라 전체 SSAO 커버리지에 적용됩니다. 폼 그림자와 역광에서도 색·밝기 설정이 보입니다.
- **`전체 효과`·`깊이 효과 마스터` 범위 정리** — 깊이 마스터를 끄면 SSAO까지 함께 꺼집니다.
- **투영 페더 범위 0~48px** — 품질 티어가 실제 사용할 수 있는 상한과 UI 범위를 맞췄습니다.
- **통합 그림자 색 순도 상한 10** — 강한 색 연출을 위해 기존 2보다 넓혔습니다.
- **`얼굴 균일 캐스트`·`얼굴 캐스트 안정화` 삭제** — 작동하지 않던 프로퍼티와 프리셋 시드를 제거했습니다.

## 개선

- **맷캡 업로드 최적화** — Built-in에서 맷캡 2~5 슬롯의 고정값도 상수로 접습니다. 5슬롯 측정에서 프래그먼트 명령어가 1,286에서 117로 줄었고 URP와 비용 차이도 거의 사라졌습니다.
- **베이크 캐시 정합성** — 프록시 모양·축·높이·영역 마스크·UV 소유권과 업로드 전용 경로를 캐시 키에 포함했습니다. 다른 캐릭터나 편집용 베이크 산출물을 덮어쓰지 않습니다.
- **업로드 복원 안정성** — 렌더러·재질 복원을 항목별로 격리하고 변경한 에셋만 저장합니다. 한 항목 실패가 나머지 복원을 막거나 관련 없는 작업물을 저장하지 않습니다.
- **프리셋 보존 범위** — Surface Mode, Cutout, 렌더 큐, 얼굴 프록시처럼 재질 정체성과 캐릭터별 배치를 보존합니다.
- **Mask Maker 연동** — 페인트 중 적용 영역을 표시하고, 모드 전환과 Undo가 편집 상태를 잃지 않습니다.
- **셰이더 워밍·키워드 복구** — 현재 백엔드와 실제 패스 키워드만 데우고 중단 지점부터 이어갑니다. 유지보수용 상세 진단은 개발 빌드에만 남습니다.

## 수정

- 얼굴 SDF 조명이 정중앙을 지날 때 좌우 선택이 딱딱하게 튀던 문제.
- 얼굴 영역 버텍스 마스크가 ShadowCaster·Depth 패스에서 무시돼 몸까지 얼굴 오프셋을 받던 문제.
- 텍스처 얼굴 영역 마스크를 업로드 베이크가 전체 얼굴로 오해하던 문제. 이 경우는 동일한 결과를 위해 Live 경로를 유지합니다.
- 한 렌더러의 여러 Face 슬롯이 서로 다른 프록시·런타임 프레임을 쓰는데 첫 슬롯 값으로 모두 베이크하던 문제. 이제 불일치하면 안전하게 Live 경로를 유지합니다.
- 프록시 씬 도구가 부모·렌더러 스케일을 무시해 클릭 위치가 어긋나던 문제.
- AlphaToCoverage Cutout의 ForwardAdd가 추가광에서 밝은 외곽 프린지를 만들 수 있던 문제.
- VRChat 미러가 다른 카메라의 깊이를 읽거나 깊이 라이트가 실제로 켜지지 않던 문제.
- 2D 그림자가 가까운 별도 메시에서 끊기고 화면 가장자리에서 오검출되던 문제.
- SSAO가 기울어진 면을 자기 차폐하고, 바이어스 0에서 사각 자국과 계단 경계를 만들던 문제.
- lilToon 변환이 PBR·이미션·레이어·아웃라인·알파 마스크 토글을 켜지 않던 문제.
- Missing Shader 변환과 일반 변환이 Surface 상태 일부를 잃던 문제.
- 룩 프리셋이 알파 모드와 얼굴 프록시 값을 되돌리던 문제.
- 공유 Mesh 베이크, UV 채널 충돌, 탄젠트 없는 파츠 실패, 재베이크·복원 중단 문제.
- 버텍스 페인트 대상 FBX를 Read/Write 재임포트한 뒤 실패 롤백에서 오래된 Mesh 참조를 복원하던 문제.
- 다중 루트 얼굴 프록시 편집, 보류 편집 정리, 다중 선택 상태 키가 서로 충돌하던 문제.
- 인스펙터 좁은 폭의 잘림·깜빡임, 스티키 툴바 DPI 좌표, 프리셋 토글 줄바꿈, 누락된 일괄 편집 항목.
