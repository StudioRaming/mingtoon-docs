*오픈 베타 · 2026년 9월 9일*

## 한 줄 요약 {#v019}

변환할 때 룩과 색감을 따로 고르고, 베이크 후 하얗게 변하던 문제를 고쳤습니다.

:::warning[업데이트 전 확인]
- 재베이크: 이미 구운 재질은 편집용으로 복원한 뒤 다시 구우세요.
- 재업로드: VRChat 아바타는 다시 업로드해야 이번 수정이 반영됩니다.
- 이미션 강도를 0으로 낮춰 흰색을 피했다면 원하는 값으로 되돌린 뒤 다시 구우세요.
- 이전 버전의 프리셋이 덮어쓴 값은 자동으로 돌아오지 않습니다.
:::

## 새 기능

- **색감 프리셋** — 룩 프리셋 아래에 생겼습니다. 룩을 먼저 적용한 뒤 색감을 적용합니다.
- **기존값 사용** — 색감 프리셋에서 고르면 원본에서 변환한 색을 그대로 유지합니다.
- **시작하기** · **룩·베이크** · **최적화** — Manager가 세 탭으로 나뉘었습니다.
- 시작하기에서 변환 대상을 정하고, 룩·베이크에서 기존 재질의 룩을 조정합니다.
- 최적화에서 자동 처리와 텍스처 해상도 상한을 설정합니다.
- 변환할 재질이 없으면 선택한 룩과 색감을 기존 MingToon 재질에 다시 적용할 수 있습니다.
- 제품 메뉴에서 개발용 진단 항목을 숨겼습니다. 프로젝트 검증 메뉴는 그대로입니다.

## 바뀐 기본값과 룩 변화

- 색감 프리셋의 기본값은 `뉴트럴`입니다. 기존의 그림자 색상 덮어쓰기 체크박스를 대신합니다.
- 변환할 때 원본에서 가져온 그림자 밴드 설정이 룩 프리셋에 덮이지 않습니다.
- 원본 2차 그림자의 알파가 0이면 2차 밴드를 켜지 않습니다.
- 합친 텍스처와 노멀에 해상도 상한이 적용됩니다. `제한 없음`은 크기를 유지합니다.
- 해상도 제한을 위해 원본 텍스처의 임포트 설정을 바꾸지 않습니다.
- 생성 마스크는 채널 값을 지키도록 무손실로 저장합니다.

## 수정된 문제

- 베이크 후 재질이 하얗게 변하던 문제가 고쳐졌습니다. 꺼 둔 이미션이 켜지던 것이 원인입니다.
- 이미션과 두 번째 레이어의 켜짐·꺼짐 상태가 베이크에서 달라지던 문제가 고쳐졌습니다.
- Glitter를 끈 재질에까지 효과가 적용되던 문제가 고쳐졌습니다.
- 수동 베이크 뒤 Glitter 마스크가 듣지 않던 문제가 고쳐졌습니다.
- 카메라에서 멀어지면 맷캡의 색이나 발광이 사라지던 문제가 고쳐졌습니다.
- VRChat SDK 빌드 후 편집용 재질에 임시 베이크 셰이더가 남던 문제가 고쳐졌습니다.
- 메인 텍스처가 빈 알파 마스크 재질에서 베이크 후 컷아웃 경계가 달라지던 문제가 고쳐졌습니다.
- 프리셋의 꺼짐 값이 사용 중인 모듈을 덮어쓰던 문제가 고쳐졌습니다.
- 그림자 강도가 0인데 두 번째 그림자가 남던 lilToon 변환 문제가 고쳐졌습니다.
- 일부 재질의 변환이 실패하면 나머지까지 멈추던 문제가 고쳐졌습니다.
- `Assets/StudioRaming` 폴더가 없는 프로젝트에서 마스크 생성 폴더를 못 만들던 문제가 고쳐졌습니다.
- Scene 뷰에서 깊이 표시가 사라지던 문제가 고쳐졌습니다.

## 알려진 제한

- 모든 lilToon 룩이 픽셀 단위로 같아지지는 않습니다. 변환 후 실제 모습을 확인하세요.
- 용량이 줄어드는 정도와 처리 시간은 환경마다 달라 아직 수치로 제시하지 않습니다.
- Ming Light Controller는 별도 패키지입니다. 함께 0.1.2로 업데이트하세요.
- MLC의 VRCFury 압축 협업과 압축 후 미리보기는 다음 버전으로 미뤘습니다.
