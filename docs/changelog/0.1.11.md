*오픈 베타 · 2026년 9월 19일*

## 한 줄 요약 {#v0111}

변환·빌드·업데이트가 안정되고, 뎁스 그림자와 기본 룩·인스펙터가 크게 바뀌었습니다.

:::warning[업데이트 전 확인]
- 백업: 프로젝트 전체를 백업한 뒤 설치하세요.
- 재베이크: 구운 재질은 편집용으로 복원한 뒤 다시 구우세요.
- 재업로드: VRChat 아바타는 다시 업로드해야 반영됩니다.
- 룩 변화: 엣지 림, 볼륨 스페큘러, 조명 기준값, 뎁스 그림자, 어두운 베이스 그림자를 확인하세요.
- 기존 재질: 저장된 기본값은 자동 변경되지 않습니다. 새 기준값은 다시 만들거나 프리셋을 적용해야 반영됩니다.
- lilToon 변환 재질: 반사·백라이트·프레넬 림·뎁스 그림자가 달라지므로 다시 변환해 비교하세요.
- 애니메이션: `2D` 계열 속성 이름 8개가 자동 이전됩니다. 직접 바인딩한 클립·FX는 다시 연결하세요.
- 프로젝트 JSON: 스키마 24 문서는 거절됩니다. 현재 재질에서 다시 내보내세요.
:::

## 새 기능

- **엣지 림** — 윤곽을 따라가는 별도 림 모듈입니다. **광원 방향 반응**, **가장자리 폭 (픽셀)**, **가장자리 고정**, **역광 강도·폭 부스트**가 추가됐습니다.
- **백라이트** — lilToon의 역광을 별도 모듈로 옮겼습니다. 색상 맵, 시점 감쌈, 역광 집중도, 뒷면 마스크를 지원합니다.
- **반사** — lilToon의 반사 토글·큐브맵·반사 색상 맵을 실제로 켭니다. PBR 노멀과 반사 노멀도 따로 옮깁니다.
- **스택 거리 페이드** — 추가 텍스처 레이어마다 lilToon식 시작 거리·끝 거리·강도를 적용합니다.
- **환경광 반영 배수** — 월드가 주는 환경 색·간접광·Light Volume·그림자 색 레이어를 한 줄로 조절합니다.
- **페이스/헤어 셰이딩** — 얼굴 영역 → 음영 → 그림자 방식 → 기준 → 고급 순서로 재배치하고 죽은 접힘을 제거했습니다.
- **평면 얼굴 프록시** — 얼굴 정면 기준을 평면으로 맞추는 모드가 추가됐습니다.
- **색감 프리셋 편집창** — 그림자·마스터 보정값을 한 창에서 보고 저장·편집합니다.
- **프리셋 저장 및 관리** — 적용과 저장을 분리하고 마지막으로 적용한 프리셋을 기억합니다.
- **성능 부하** — 업로드 기준 부하를 한 줄로 보여 주고 세부 추정치를 펼쳐 봅니다.
- 텍스처 카드에 미리보기·정렬·할당 필터가 생겼고, 레이어는 카드에서 추가·켜기·이동·삭제합니다.
- **원본 텍스처 임포트 설정** — 원본 텍스처의 **최대 해상도**·**압축 품질**·형식을 종류별로 모아 적용합니다.
- **생성 캐시 정리** — 사용하지 않는 MingToon 생성 셰이더·패킹 텍스처를 참조 검사 뒤 휴지통으로 보냅니다.
- **프리뷰 버전 포함** — 업데이트 창에서 프리뷰 채널을 선택합니다. 해제하면 시험판보다 번호가 낮아도 정식 채널의 최신 버전을 안내합니다.

## 바뀐 기본값과 룩 변화

- 공장 룩은 **엣지 림**을 끈 상태로 시작합니다. 기존 `backlight` 프리셋 탭은 `edgerim`으로 이름을 바꾸고 GUID를 유지합니다.
- **볼륨 스페큘러** 기본값이 Full에서 Off로 바뀌었습니다. 라이트 볼륨의 금속 같은 하이라이트가 줄어듭니다.
- 조명 기준값을 재조정했습니다. **환경 색상 반영** 1, **베이스 색 유지** 0.1, **최종 최소 밝기** 0.2, **엣지 림 최고 배율** 0, **엣지 림 최저 배율** 0.5입니다.
- **어두워짐 반영** 0.8, **노멀 바이어스** 0.01, **화면 공간 그림자 겹침 심도** 0.5, **어두운 베이스 그림자 강화** 0.8이 기본입니다. 씬 조명 영향 행은 모두 1입니다.
- 공장 룩 18개를 MAYO 기준 재질과 새 조명 기준으로 다시 맞췄습니다. 다시 적용하면 값이 덮어써집니다.
- BRP 아웃라인은 Light Volume 밝기를 정점에서 한 번만 읽고, 그 밝기와 색을 선에 반영합니다. 픽셀당 볼륨 샘플은 늘지 않습니다.
- 그림자 색도 Light Volume 밝기·색을 베이스 표면과 같은 완료 조명 경로로 받습니다.

### 뎁스 그림자 (이전 2D 그림자) {#depth-shadow-changes}

- 기능명 `2D 그림자`는 `뎁스 그림자`로, `2D 림라이트`는 `뎁스 림라이트`로, `2D 투과광`은 `SSSSS (실험적)`로 바뀌었습니다.
- 저장된 셰이더 속성 8개도 `2D`에서 `Depth`로 자동 이전됩니다. 직접 바인딩한 애니메이션 클립·FX만 다시 연결해야 합니다.
- **각도 폭 바닥**과 **각도 길이 바닥** 기본값이 0.02에서 0.35로 올라갔습니다. 카메라와 광원이 나란한 각도에서 그림자가 사라지던 문제를 막습니다.
- **깊이 커브** 기본값은 0.5에서 0으로 바뀌었습니다. 새 재질의 깊이 늘림은 떠 있는 거리에 정비례합니다.
- 위 세 값은 새 재질에만 적용됩니다. 기존 재질에서 아래에서 올려다볼 때 그림자가 사라지면 각도 바닥 두 값을 0.35로 직접 올리세요.
- 변환기와 색감 프리셋이 **화면 공간 그림자 겹침 심도**를 0으로 되돌리던 문제가 고쳐졌습니다. 기본값과 프리셋 값은 0.5입니다.
- 뎁스 그림자의 길이 축을 캐릭터 자체 축으로 계산해, 캐릭터가 회전해도 그림자 방향이 화면 기준으로 흔들리지 않습니다.
- 그림자 패턴의 `Depth2D` 항목은 `Depth`로 바뀌었습니다. 저장값은 그대로입니다.
- 뎁스 그림자·뎁스 림라이트·SSSSS·내부 뎁스 경계의 표시명과 검색명을 새 이름으로 통일했습니다.

## 개선

- 베이크 셰이더가 노멀·탠젠트·씬 조명 계산을 공유합니다. 중립 감마와 사용하지 않는 언릿 버텍스 조명은 건너뜁니다.
- 얼굴·레거시 투명 샘플러 프로필을 합치고 자동 뎁스 앵커를 상수에서 제외해 반복 빌드의 셰이더 생성과 warm build가 안정됐습니다.
- 같은 패스·표면 모드끼리만 프로필을 합치도록 제한해 다른 렌더 상태가 섞이지 않습니다.
- 생성 텍스처 서명·최종 마스크 압축·안전한 마스크 소스 정리로 같은 결과의 파일이 반복 생성되는 일을 줄였습니다.
- 아웃라인 조명을 단순화하고 **베이스맵 따라가기**·**알파 따라가기**를 분리했으며, DOF 보호 깊이 패스를 추가했습니다.
- URP 양면 투명 뒷면 패스와 CBUFFER·얇은 PBR 스페큘러 정리를 추가했습니다. 토글이 꺼진 URP 베이크본에서는 뒷면 패스를 제거합니다.
- 레이어 이동·삭제 시 애니메이션 바인딩을 원자적으로 옮기고, 임포터 초안과 Unity 2021 메타데이터를 보존합니다.
- Warudo 프리팹 전용 빌드는 참조된 재질과 메타데이터를 보존하고, 개발 메뉴는 출시 패키지에서 제거합니다.
- Inspector의 좁은 폭 헤더·성능 표시·텍스처 목록·프리셋 레이아웃을 정리하고 죽은 관리자 화면을 제거했습니다.
- 첫 설치 직후에는 최초 화면에 필요한 조명 상태만 미리 컴파일해 초기 대기를 줄입니다.

## 수정된 문제

- 텍스처를 임포트할 때 씬 전체 마스크 계획이 돌던 문제가 고쳐졌습니다. 이제 선택된 입력만 준비합니다.
- 마스크 입력 영수증을 수동 베이크·업로드 전에 한 번 준비하고, 완료된 영수증을 반복 검증하던 문제를 정리했습니다.
- 빌드 전용 값 때문에 같은 아바타도 매번 새 셰이더 프로필을 만들던 문제가 고쳐졌습니다. 성공한 빌드는 생성 프로필과 소스 캐시를 재사용합니다.
- lilToon 변환 순서를 `변환 → 룩 프리셋 → 색감 프리셋`으로 고정했습니다. 원본 반사·백라이트·얼굴 데이터는 보존하고, 엣지 림은 룩 프리셋이 소유합니다.
- Manager에서 프레넬 림을 켤 수 있게 했고, 변환된 아웃라인 폭을 원본의 폭 단위로 정규화합니다.
- 팩토리 룩 적용이 소스 값을 암묵적으로 보존하지 않도록 정리했습니다.
- 색감 프리셋이 그림자 컬러맵 UV와 베이스 알파까지 덮어쓰던 문제가 고쳐졌습니다.
- 마스크 팩 채널 순서와 그림자 경계 게이트를 통일해 마스크 결과가 어긋나던 문제가 고쳐졌습니다.
- `Hue` 혼합 연산자를 제거하고, 빛이 0인 그림자 왕복에서 값이 손상되지 않게 했습니다.
- lilToon 반사 모듈이 켜지지 않아 큐브맵 오버라이드와 반사 색상 맵이 무시되던 문제가 고쳐졌습니다.
- lilToon 금속의 큐브맵 반사가 그림자 쪽에서 사라지던 문제와 프레넬 림 밴드가 면 전체를 덮던 문제가 고쳐졌습니다.
- 기본 얼굴 룩이 이미션을 강제로 켜던 문제와 아웃라인 헐 색 감마가 빠지던 문제가 고쳐졌습니다.
- 텍스처 임포터 초안이 더 새로운 설정을 덮어쓰던 문제와 레이어 이동·삭제 시 애니메이션 바인딩이 어긋나던 문제가 고쳐졌습니다.
- URP에서 SSAO·뎁스 그림자 마스크 조합이 컴파일되지 않던 문제와 URP CBUFFER·얇은 PBR 스페큘러 문제가 고쳐졌습니다.
- Warudo 프리팹 전용 모드 빌드가 참조 재질을 빠뜨리던 문제와 Unity 2021.3 컴파일 오류가 고쳐졌습니다.
- 업데이트 알림 창이 상세 창을 강제로 덮던 문제와, 알림에서 상세 내용을 열 수 없던 문제가 고쳐졌습니다.
- DLL 설치 영수증이 이전 버전에 멈춰 업데이트 버튼이 잠기던 문제를 설치기가 남긴 검증 목록으로 복구합니다. bootstrap DLL은 바뀌지 않습니다.
- 툴팁이 잘못 적어 둔 기본값 31종을 실제 셰이더 기본값과 맞췄습니다. `Depth2D` 표기 오타도 `Depth`로 고쳤습니다.

## 알려진 제한

- VRC Light Volume 캐스트 그림자 모양은 v2·v3 월드에서 0.1.10과 아직 다릅니다.
- VRC Light Volumes 3 월드는 기존 v2 버퍼만 읽습니다. v3 네이티브 그림자·클러스터링·라이트별 셰이딩은 지원하지 않습니다.
- 첫 셰이더 컴파일과 첫 업로드는 캐시가 비어 더 오래 걸릴 수 있습니다.
