# Manager로 처음 시작하기

**MingToon으로 작업할 아바타의 루트에는 MingToon Manager가 항상 있어야 합니다.** Manager에서 대상 메시, 변환, 룩과 업데이트를 관리합니다. 이 가이드는 설치 직후 Manager를 추가하고 재질을 변환한 뒤 빠른 설정으로 룩을 다듬는 순서입니다. [설치](/getting-started/installation)를 마친 상태에서 시작하세요. Face SDF Studio는 아직 미발매이며 이 과정에 필요하지 않습니다.

## 1. 아바타 루트에 Manager 추가 — 가장 먼저

Hierarchy에서 **MingToon으로 작업할 아바타의 루트 오브젝트**를 선택합니다. 아바타의 의상만 작업하더라도 Manager는 아바타 루트에 둡니다. Add Component에서 **MingToon Manager**를 찾아 추가합니다. 대상 아래에 변환할 메시가 들어 있는지 확인하고, Manager 하나를 선택한 상태에서 진행하세요. 변환 후에도 컴포넌트를 유지하세요. Manager에서 업데이트와 작업 상태를 확인합니다.

**VCC로 설치했다면 MingToon 업데이트는 VCC에서 진행합니다.** Manager의 업데이트 안내를 이용할 때도 설치 경로를 먼저 확인하세요.

## 2. Face Mesh와 Skin Mesh 지정

Manager의 Setup에서 얼굴 메시를 **Face**, 맨살 메시를 **Skin**으로 지정합니다. UI의 얼굴·피부 렌더러 지정 영역을 사용하고, 슬롯별 역할 미리보기로 적용 범위를 확인하세요. 눈·속눈썹·옷·머리카락까지 모두 얼굴이나 피부로 지정하지 않습니다.

얼굴과 몸이 없는 의상만 변환한다면 Face와 Skin을 비워 두어도 됩니다. 한 Renderer에 맨살과 옷이 섞여 있으면 슬롯별로 구분하고 옷은 **Regular**로 둡니다. 역할은 프리셋의 얼굴용·피부용·공용 값이 적용될 대상을 정합니다.

→ [역할 지정 상세](/workflow/character-manager#얼굴--피부-지정--가장-중요한-단계)

## 3. 원하는 룩 프리셋 선택

**변환 시 룩 프리셋**에서 시작할 룩을 고릅니다. 처음에는 원하는 분위기에 가까운 프리셋 하나로 시작하고, 변환 후 수치를 다듬으세요. 원본에서 읽은 설정을 출발점으로 삼고 룩 프리셋을 적용하지 않으려면 **적용 안 함**을 선택합니다.

## 4. 색감 톤 또는 기존 재질값 선택

| 원하는 출발점 | 선택 |
|---|---|
| 프리셋 색감으로 새 분위기를 만들기 | **색감 프리셋**에서 원하는 톤 선택 |
| 원래 재질의 색감을 바탕으로 시작하기 | **기존값 사용** 선택 |

**기존값 사용**은 **변환된 원본 색상과 그림자 밴드·합성 설정을 유지**합니다. 룩 프리셋 전체를 끄는 **적용 안 함**과는 별개의 선택입니다. 색감 프리셋은 룩 적용 후 적용되며, 선택만으로 재질이 바뀌지는 않습니다.

## 5. 변환 버튼 누르기

대상 메시, 역할, 룩, 색감 선택을 확인한 뒤 **변환**을 누릅니다. 완료되면 대상에 편집용 MingToon 재질이 적용됐는지 확인하세요. 변환 결과에 제외·실패 슬롯이 있으면 해당 재질과 이유를 먼저 확인합니다. 모든 재질이 변환됐다고 가정하고 다음 단계로 넘어가지 마세요.

## 6. 빠른 설정에서 룩 조정

변환된 재질을 선택해 Inspector의 **빠른 설정**을 엽니다. Manager의 재질 선택 기능을 이용하면 얼굴이나 피부 등 필요한 재질만 골라 편집할 수 있습니다. 처음에는 얼굴·피부·옷을 나눠 조정하고, 전체에 같은 값을 줄 때 여러 재질을 함께 선택하세요.

**색과 밝기 → 그림자 경계 → 아웃라인 → 림·광택·이미션** 순으로 하나씩 움직이며 모델의 변화를 확인합니다. 빠른 설정에 없는 항목은 검색 또는 전체 설정에서 찾습니다. 아래 항목 전부를 한 번에 켤 필요는 없습니다.

## 자주 만지는 파라미터

| 바꾸고 싶은 인상 | 먼저 찾을 항목 | 조정할 때 볼 것 |
|---|---|---|
| 전체 색감 | 베이스맵 HSVG | 색상·채도·명도·감마를 조금씩 조정해 피부와 옷의 색 확인 |
| 어두운 곳의 밝기 | 간접광 보정 · 최종 최소 밝기 | 어두운 면의 밝기와 명암 확인. 조명 색조는 베이스 색 유지에서 별도 조정 |
| 그림자 경계 | 1차 그림자 부드러움 | 낮추면 또렷하게, 높이면 부드럽게 전환 |
| 그림자의 색 | 그림자 색상 | 피부·머리카락·옷에 각각 어울리는 색으로 조정 |
| 외곽선 | 아웃라인 폭 · 아웃라인 색상 | 가까운 거리와 전신 거리에서 선의 두께 확인 |
| 가장자리 빛 | 림 라이트 · 2D 림 | 실루엣 강조량 확인. 2D 림은 카메라 깊이 조건도 확인 |
| 표면 광택 | Matcap · 툰 스페큘러 | 머리카락·의상의 광택이 과하지 않은지 확인 |
| 스스로 빛나는 부분 | 이미션 | 필요한 영역에만 적용하고 색과 세기를 확인 |

값을 바꿔도 반응이 없으면 **전체 효과 → 해당 모듈 켜짐 → 효과에 필요한 조건** 순서로 확인합니다. 2D 림·2D 그림자처럼 깊이를 사용하는 기능은 [깊이 기반 효과](/guides/depth-effects)의 준비가 필요합니다.

## 7. 편집을 마치면 평소처럼 업로드·빌드

원하는 재질로 편집을 마치고 **VRC SDK의 아바타 업로드** 또는 **WARUDO 모드 빌드**를 실행하면 자동 최적화 베이크가 진행됩니다. 처음부터 수동 Bake를 별도로 누르는 순서가 아닙니다. **아바타 루트의 MingToon Manager를 유지**하고 Manager에서 빌드/업로드 시 자동 최적화 상태를 확인하세요.

자세한 조건은 [빌드 시 자동 최적화](/workflow/build-optimization)와 대상 플랫폼 가이드를 확인하세요. 현재 베타의 검증 범위는 [현재 제한](/limitations)에 안내되어 있습니다.
