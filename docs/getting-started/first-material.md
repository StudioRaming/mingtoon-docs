# 첫 재질 만들기

**이 문서를 마치면** MingToon 재질 하나를 만들어 모델에 적용하고, 툰 셰이딩이 실제로 켜져 있음을 눈으로 확인하게 됩니다. 약 5분.

이 문서는 **재질 하나**를 다룹니다. 아바타 전체를 한 번에 옮기려면 [lilToon 변환](/workflow/liltoon-conversion)으로 가세요.

## 1. 재질 만들기

1. Project 창에서 우클릭 → `Create > Material`.
2. 만들어진 재질을 선택하고 Inspector 상단의 셰이더 드롭다운을 엽니다.
3. `StudioRaming > MingToon > BRP`를 선택합니다.

**이렇게 되면 정상입니다.** Inspector가 일반 Standard 셰이더 UI가 아니라 MingToon 전용 인스펙터로 바뀝니다.

{/* SCREENSHOT: 셰이더 선택 드롭다운 */}

:::tip 재질이 분홍색이라면
셰이더가 컴파일되지 않은 것입니다. 대부분 렌더 파이프라인이 안 맞거나, 빌드 타깃이 셰이더 모델 4.5를 만족하지 않는 경우입니다. → [문제 해결](/troubleshooting)
:::

## 2. 표면 모드 정하기

베이스 맵을 넣기 **전에** 표면 모드부터 정합니다. 나중에 바꾸면 렌더 큐가 움직여 깊이 기반 효과가 통째로 꺼지는 일이 생깁니다.

| 파츠 | 표면 모드 |
|---|---|
| 몸, 옷 | **불투명** |
| 머리카락, 속눈썹 | **컷아웃** (`알파 컷오프` 0.3~0.6) |
| 반투명이면서 깊이 효과도 필요 | **투명 · 아웃라인용 깊이 기록** |

자세한 내용은 [기본 설정](/guides/basics#1-표면-모드부터-정합니다)에 있습니다.

## 3. 베이스 텍스처 넣기

1. 인스펙터 보기 모드가 **간단**인지 확인합니다.
2. **베이스 맵** 슬롯에 캐릭터 텍스처를 넣습니다.
3. 재질을 모델의 Renderer에 드래그해 적용합니다.

**이렇게 되면 정상입니다.** 씬에 캐릭터가 텍스처 색으로 보이고, 광원 방향에 따라 **경계가 뚜렷한 그림자**가 생깁니다. 이 뚜렷한 경계가 툰 셰이딩이 켜져 있다는 신호입니다. 부드러운 그라데이션만 보인다면 셰이더가 Standard로 남아 있는 것입니다.

{/* SCREENSHOT: 베이스 맵 적용 후 씬 뷰 */}

## 4. 그림자와 밝기 잡기

간단 모드에서 아래만 만져도 인상이 크게 바뀝니다.

| 항목 | 하는 일 | 처음 잡을 때 |
|---|---|---|
| **베이스맵 HSVG** | 베이스 색의 색상/채도/명도/감마 보정 | 원본 텍스처를 안 고치고 톤만 조정 |
| **1차 그림자 부드러움** (빠른 설정) | 명암 경계의 번짐 폭 | **가장 먼저 잡을 값.** 0.001이면 셀, 0.3 이상이면 그라데이션 |
| **베이스 색상 보존** | 조명이 어두워도 원화 색을 얼마나 남길지 | VRChat 월드 대비. 높게 |
| **최종 최소 밝기** | 아무리 어두워도 이 아래로 안 내려감 | 어두운 월드에서 검게 뭉개지지 않게 |

:::tip VRChat에서 특히 중요합니다
월드 조명은 아바타 제작자가 통제할 수 없습니다. `베이스 색상 보존`과 `최종 최소 밝기`를 올려 두면 어떤 월드에 들어가도 캐릭터가 사라지지 않습니다. → [조명과 그림자](/guides/light-and-shadow#라이팅--어두운-씬에서-검게-뭉칠-때)
:::

## 5. 아웃라인 켜기

1. 보기 모드를 **전체 설정**으로 바꿉니다.
2. **아웃라인** 그룹의 `노멀 아웃라인` 섹션에서 `클래식 헐 사용`을 켭니다.
3. `아웃라인 폭`과 `아웃라인 색상`을 조정합니다. (`빠른 설정`에도 있습니다)

**이렇게 되면 정상입니다.** 캐릭터 실루엣 바깥에 선이 그려집니다.

{/* SCREENSHOT: 노멀 아웃라인 켠 상태 */}

노멀 아웃라인은 카메라 깊이가 필요 **없어서** 어떤 환경에서도 동작합니다. 반면 옷 주름 같은 안쪽 선을 그리는 **내부 2D 경계**는 카메라 깊이를 읽기 때문에 [별도 준비](/guides/depth-effects)가 필요합니다.
