# 그림자

툰 룩의 인상을 가장 크게 좌우하는 부분입니다. 형태 그림자(빛의 방향으로 생기는 명암)와 캐스트 그림자(실시간으로 드리우는 그림자)는 서로 다른 항목이니 구분해서 보세요.

:::note
이 페이지의 항목 이름과 설명은 MingToon 인스펙터가 실제로 표시하는 문구를 소스에서 그대로 가져온 것입니다.
:::

## 형태 그림자

형태 기반 명암 경계와 부드러움을 설정합니다.

| 항목 | 설명 | 셰이더 프로퍼티 |
|---|---|---|
| **1차 그림자 번짐** | 명암 경계의 번짐 폭입니다. 0.001에 가까우면 셀 애니메이션처럼 딱 떨어지는 경계, 0.3 이상이면 부드러운 그라데이션이 됩니다. 이 제품에서 가장 자주 조정하는 값입니다. | `_FormShadowSoftness` |
| **1차 그림자 밝기** | 1차 형태 그림자 색의 밝기 배수입니다. 낮출수록 어두워지며, 그림자 색상 모듈이 꺼져 있으면 반영되지 않습니다. | `_FormShadowBrightness` |
| **2차 그림자 밝기** | 2차 형태 그림자 색의 밝기 배수입니다. 1차보다 낮게 두어야 단계가 구분되어 보입니다. 2차 그림자 사용이 꺼져 있으면 반영되지 않습니다. | `_FormShadow2ndBrightness` |
| **2차 그림자 사용** | 가장 어두운 쪽에 두 번째 그림자 단계를 추가해 3단 셀 음영을 만듭니다. 끄면 2차 밝기와 번짐이 모두 무시됩니다. | `_FormShadow2ndEnabled` |
| **2차 그림자 번짐** | 2차 그림자 경계의 번짐 폭입니다. 1차보다 좁게 두면 안쪽 단계가 또렷해집니다. 2차 그림자 사용이 꺼져 있으면 반영되지 않습니다. | `_FormShadow2ndSoftness` |
| **그림자 경계 사용** | 명부와 그림자 사이의 색 경계 효과 전체를 켜거나 끕니다. 끄면 관련 경계 연산도 건너뜁니다. | `_MingShadowBorderEnabled` |
| **경계선 배치** | 경계 색 띠를 명암 경계 양쪽에 걸칠지, 그림자 쪽 안에만 남길지 정합니다. 켜면 밝은 면까지 걸쳐 두꺼운 색 경계 연출이 되고, 끄면 그림자 안쪽에만 남아 단정해집니다. | `_MingShadowBorderOverlay` |
| **경계 폭** | 명암 경계에 얹히는 색 띠의 폭입니다. 0이면 띠 자체가 그려지지 않아 경계 색·번짐·강도가 모두 무시됩니다. 그림자 색상 모듈이 켜져 있어야 하고, 형태 그림자나 캐스트 그림자 중 하나는 동작 중이어야 합니다. | `_ShadowBorderWidth` |
| **경계 번짐** | 경계 색 띠 가장자리의 번짐 폭입니다. 경계 폭이 0이면 반영되지 않습니다. | `_ShadowBorderBlur` |
| **경계 강도** | 경계 색 띠의 불투명도입니다. 0이면 폭을 아무리 올려도 띠가 보이지 않습니다. | `_ShadowBorderStrength` |
| **경계 베이스 맵 혼합** | 0이면 지정한 경계 색이 단색으로 나오고, 1이면 베이스 맵 색과 섞여 부위마다 다른 경계색이 됩니다. 피부와 머리카락이 한 머티리얼에 섞여 있을 때 올려 두면 자연스럽습니다. | `_ShadowBorderBaseColorMix` |

## 그림자 색상

툰 그림자 단계별 색상과 혼합을 설정합니다.

| 항목 | 설명 | 셰이더 프로퍼티 |
|---|---|---|
| **통합 그림자 사용** | 형태·캐스트·2D 그림자를 하나의 최종 색으로 모아 겹칠 때 과도하게 어두워지는 것을 막습니다. 켜져 있는 동안 개별 그림자 색·블렌드·밝기 컨트롤은 결과에 반영되지 않습니다(값은 그대로 보존됩니다). | `_MingUnifiedShadowEnabled` |
| **통합 그림자 색상** | 모든 그림자가 수렴할 색입니다. RGB는 베이스 색에 곱해지고 알파가 적용량이므로, 알파가 0이면 어떤 색을 골라도 그림자가 베이스 색 그대로 남습니다. 통합 그림자가 꺼져 있으면 사용되지 않습니다. | `_MingUnifiedShadowColor` |

## 그림자 투영

이 재질 위에 투영되는 캐스트 그림자와 경계 페더를 설정합니다.

| 항목 | 설명 | 셰이더 프로퍼티 |
|---|---|---|
| **수신 강도** | 다른 물체와 자기 자신이 드리우는 실시간 그림자를 얼마나 받을지 정합니다. 0이면 캐스트 그림자가 완전히 사라지고 아래의 밝기·혼합·간접광 보정도 결과에 나타나지 않습니다. | `_CastShadowReceiveStrength` |
| **PBR / 툰 혼합** | 0이면 유니티 기본 그림자처럼 부드럽게 감쇠하고, 1이면 툰 밴드로 딱 잘립니다. 밴드의 폭은 캐스트 툰 밴드 부드러움이 정합니다. | `_CastShadowToonBlend` |
| **2D 그림자와 통합** | 2D 그림자가 캐스트 그림자와 같은 색을 쓰도록 묶어 두 그림자가 겹치는 자리에서 두 번 어두워지는 것을 막습니다. 켜면 2D 그림자 색상 대신 캐스트 그림자 색상이 사용됩니다. | `_LinkDepthShadowToCastShadow` |
| **셀프 캐스트 섀도우 억제** | 메시가 자기 자신에게 드리우는 실시간 그림자를 줄입니다. 얼굴이나 옷 주름에 얼룩덜룩한 그림자가 생길 때 켭니다. 끄면 아래 바이어스 값이 무시됩니다. | `_SelfShadowCasterBiasEnabled` |
| **셀프 섀도우 캐스터 바이어스** | 그림자 캐스터를 표면에서 얼마나 밀어낼지 정합니다. 크게 올리면 얼룩은 사라지지만 접지 그림자가 뜨고 얇은 부위의 그림자가 끊깁니다. 0.01~0.03이 무난합니다. 셀프 캐스트 섀도우 억제가 꺼져 있으면 반영되지 않습니다. | `_SelfShadowCasterBias` |
| **캐스트 간접광 보정** | 환경광이 밝은 곳에서 캐스트 그림자를 옅게 만들어 실내·야외 조명 차이를 자연스럽게 흡수합니다. 1에 가까우면 밝은 씬에서 캐스트 그림자가 거의 사라집니다. | `_CastShadowIndirectLift` |
| **역광 실루엣 억제** | 광원을 등진 면에는 캐스트 그림자를 그리지 않습니다. 역광에서 캐릭터 모양의 그림자가 몸 위에 한 번 더 겹쳐 보이는 현상을 막습니다. | `_CastShadowBackfaceSuppression` |
| **캐스트 그림자 밝기** | 캐스트 그림자 색의 밝기 배수입니다. 그림자 색상 모듈이 꺼져 있으면 캐스트 그림자는 단순히 어두워지기만 하므로 이 값이 무시됩니다. | `_CastShadowBrightness` |
| **얼굴 캐스트 안정화** | 얼굴처럼 완만한 면에 실시간 그림자가 스치듯 들어올 때 생기는 얼룩을 정리합니다. 끄면 아래의 강도와 스침 임계값이 무시되고, 캐스트 그림자 자체가 꺼져 있으면 켜도 아무 변화가 없습니다. | `_MingFaceCastStabilizationEnabled` |
| **안정화 강도** | 얼굴 캐스트 안정화를 얼마나 강하게 적용할지 정합니다. 너무 올리면 앞머리 그림자 같은 의도된 그림자까지 옅어집니다. 얼굴 캐스트 안정화가 꺼져 있으면 반영되지 않습니다. | `_MingFaceCastStabilizationStrength` |
| **스침 각도 임계값** | 빛이 얼굴 정면 방향과 얼마나 어긋나야 스침으로 볼지 정합니다. 올릴수록 더 넓은 각도 범위에서 보정이 걸리고, 0에 가까우면 거의 정확한 측광에서만 걸립니다. 얼굴 캐스트 안정화가 꺼져 있으면 반영되지 않습니다. | `_MingFaceCastGrazingThreshold` |

## 그림자 패턴 (스크린톤)

| 항목 | 설명 | 셰이더 프로퍼티 |
|---|---|---|
| **그림자 패턴 사용** | 폼 그림자와 2D 그림자에 스크린톤(망점)을 적용합니다. 적용 대상은 아래 패턴 적용 대상에서 선택합니다. 패턴은 메쉬/레스트 포즈 좌표에 고정되어 거리와 화각이 바뀌어도 같은 부위의 점 개수가 유지됩니다. | `_ShadowPatternEnabled` |
| **패턴 적용 대상** | 폼 그림자만, 2D 그림자만, 또는 둘 다에 같은 패턴을 적용합니다. 실시간 캐스트 섀도우 자체는 이 선택에 포함되지 않습니다. | `_ShadowPatternTarget` |
| **패턴 밀도** | 메쉬 투영 한 단위를 채우는 셀 개수입니다. 셀 한 칸이 타일 한 번 반복이라 모양 타일을 켜도 표면 밀도는 그대로입니다. | `_ShadowPatternScale` |
| **거리 보정** | 1이면 패턴 셀 수가 메쉬에 완전히 고정됩니다. 낮추면 화면상 점 크기를 고정하던 이전 방식에 가까워지지만, 패턴 위치는 계속 메쉬를 따라갑니다. | `_ShadowPatternDistanceCompensation` |
| **화각 / 투영 보정** | 1이면 원근 화각과 직교 카메라 크기가 바뀌어도 같은 메쉬 부위의 패턴 밀도를 유지합니다. 0이면 카메라 투영 변화가 패턴 밀도에 반영됩니다. | `_ShadowPatternProjectionCompensation` |
| **패턴 회전** | 패턴 격자의 각도입니다. 45도 부근이 인쇄 망점처럼 자연스럽고, 0도는 화면 픽셀 격자와 겹쳐 모아레가 생기기 쉽습니다. | `_ShadowPatternRotation` |
| **패턴 경계 부드러움** | 점 가장자리의 번짐 폭입니다. 실제 번짐 폭은 이 값과 픽셀 발자국 중 큰 쪽이라, 멀어져도 가장자리가 계단으로 갈라지지 않습니다. 0에 가까우면 가까이에서 계단이 보일 수 있고 0.02~0.1 정도가 무난합니다. | `_ShadowPatternSoftness` |
| **패턴 강도** | 원래의 부드러운 그림자와 패턴 처리된 그림자를 섞는 비율입니다. 0이면 패턴이 전혀 보이지 않습니다. | `_ShadowPatternStrength` |
| **가장 어두운 곳 채움 사용** | 가장 어두운 부분에서도 패턴이 완전히 메워지지 않게 합니다. 끄면 아래의 채움 정도가 무시되고 깊은 그림자는 단색으로 채워집니다. | `_ShadowPatternFullShadowEnabled` |
| **가장 어두운 곳 채움 정도** | 1에 가까울수록 단색에 가깝고, 낮출수록 가장 어두운 곳에서도 패턴이 뚜렷하게 남습니다. 가장 어두운 곳 채움 사용이 꺼져 있으면 반영되지 않습니다. | `_ShadowPatternFullShadowLevel` |
| **패턴 모양 타일 사용** | 점의 모양을 타일 이미지로 바꿉니다. 꺼 두면 계산으로 그리는 원형 망점이 그대로 쓰이고 텍스처를 한 번도 읽지 않으므로 비용이 늘지 않습니다. | `_ShadowPatternTileEnabled` |
| **패턴 모양 타일** | 기본 제공 타일 5종(망점, 고운 망점, 선, 교차선, 점묘)은 Assets/StudioRaming/MingToon/Textures/Patterns 폴더에 있습니다. 타일은 무늬 그림이 아니라 임계값 맵이라 각 텍셀이 잉크로 바뀌는 농도를 담고 있고, 그래서 한 장으로 첫 점부터 완전히 채워질 때까지 전부 표현합니다. 직접 만들 때는 sRGB를 끄고 모든 밝기 단계가 같은 텍셀 수를 차지하게 하세요. 격자 한 칸이 타일 한 번 반복이라 Tiling/Offset은 없습니다. | `_ShadowPatternTile` |
