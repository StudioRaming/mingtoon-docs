# 아웃라인

메시를 확장해 그리는 외곽선 항목입니다. 카메라 깊이를 쓰지 않습니다.

이 페이지는 값을 찾는 표입니다. 켜는 순서가 필요하면 [아웃라인 가이드](/guides/outline)를 보세요.

제목과 차례는 인스펙터의 섹션 이름과 표시 순서를 그대로 따릅니다.

맵과 마스크 슬롯 안의 항목은 모든 슬롯이 같습니다.
채널·리맵·페더·마스크 UV는 [텍스처 슬롯 공통 UI](/guides/texture-modules)에 한 번만 적었습니다.

## 노멀 아웃라인 {#노멀-아웃라인}

| 인스펙터 라벨 | 형식 | 범위 | 기본값 | 하는 일 |
|---|---|---|---|---|
| **노멀 아웃라인 사용** | 켜기/끄기 | - | 켜짐 | 메시를 노멀 방향으로 확장해 선을 그립니다 |
| **아웃라인 색상** | 색상 | - | 0.75, 0.6, 0.6, 1 | 노멀 아웃라인 선의 색입니다 |
| **아웃라인 색 혼합** | 선택 | Normal / Multiply | Multiply | 아웃라인 기본색에 색상을 섞는 방식입니다 |
| **아웃라인 색 혼합 세기** | 실수 | 0 ~ 1 | 1 | 선택한 혼합 방식이 아웃라인 기본색에 적용되는 세기입니다 |
| **베이스맵 따라가기** | 켜기/끄기 | - | 꺼짐 | 베이스맵과 모든 텍스처 레이어를 합성한 RGB를 아웃라인 기본색으로 사용합니다 |
| **알파 따라가기** | 켜기/끄기 | - | 켜짐 | 켜면 원본 표면 알파를 외곽선 출력에 반영합니다 |
| **아웃라인 폭** | 실수 | 0 ~ 10 | 1 | 아웃라인의 굵기입니다 |
| **버텍스 컬러 알파(VertexAlpha)로 전환** | 선택 | Constant / VertexAlpha / VertexRed / WidthMask / OutlineNormalUV8 | Constant | 선 굵기를 조절할 페인팅 채널을 고릅니다 |
| **노멀 아웃라인에 적용** | 켜기/끄기 | - | 켜짐 | 페인팅한 압력을 노멀 아웃라인 굵기에 반영합니다 |
| **이너 아웃라인에 적용** | 켜기/끄기 | - | 꺼짐 | 페인팅한 압력을 Inner Depth Edge 굵기에도 반영합니다 |
| **압력 대비** | 실수 | -4 ~ 4 | 2 | 압력 값을 지수로 눌러 선 굵기 차이를 키웁니다 |
| **내부선 억제 오프셋** | 실수 | 0 ~ 1 | 0.004 | 값이 클수록 화면 위치와 폭은 유지한 채 아웃라인의 래스터 깊이 기준만 뒤로 이동해, 본체와 깊이 차가 작은… |
| **DOF에서 아웃라인 보호** | 켜기/끄기 | - | 켜짐 | 아웃라인이 깊이를 기록해 피사계 심도(DOF) 블러가 선을 지우지 못하게 보호합니다 |
| **원거리 최소 픽셀** | 실수 | 0 ~ 4 | 0.95 | 멀리 있어도 아웃라인이 이 화면 픽셀 수보다 가늘어지지 않게 유지합니다 |
| **폭 모드** | 선택 | PixelStable / WorldSpace | WorldSpace | PixelStable은 화면 픽셀 기준이라 거리와 무관하게 선 두께가 일정하고, WorldSpace는 월드… |
| **노멀 소스** | 선택 | MeshNormal / VertexColorTS / UV8TS | MeshNormal | 외곽선을 어느 방향으로 밀어낼지 정합니다 |
| **사용자 벡터 방향** | 켜기/끄기 | - | 꺼짐 | 외곽선을 밀어낼 방향을 텍스처로 직접 지정합니다 |
| **벡터 스케일** | 실수 | -10 ~ 10 | 1 | 지정한 방향 벡터의 세기입니다 |
| **깊이 바이어스** | 실수 | -0.1 ~ 0.1 | 0 | 노멀 아웃라인 전체를 카메라 쪽으로 당기거나 뒤로 밀어 다른 파츠에 파묻힌 외곽선을 꺼냅니다 |
| **렌더 적용** | 켜기/끄기 | - | 켜짐 | 형태 그림자·림·전면광을 외곽선에 적용합니다 |
| **전면광 색상** | 색상 | - | 흰색 | 렌더 적용이 켜져 있을 때 전면광에 섞을 색입니다 |
| **전면광 세기** | 실수 | 0 ~ 1 | 0 | 표면 법선과 주광 방향의 내적을 0~1로 제한한 값으로 전면광 색을 섞는 양입니다 |
