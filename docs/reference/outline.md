# 아웃라인

노멀 아웃라인은 메시를 확장해 그리므로 카메라 깊이 없이 어디서나 동작합니다. 화면 깊이를 읽어 표면 안쪽 선까지 그리는 내부 2D 경계는 [깊이 기반 효과](/reference/depth-effects) 그룹에 있습니다.

:::note
이 페이지의 항목 이름과 설명은 MingToon 인스펙터가 실제로 표시하는 문구를 소스에서 그대로 가져온 것입니다.
:::

## 노멀 아웃라인

메시 노멀을 따라 확장되는 외곽선의 폭, 색상과 거리 보정을 설정합니다.

| 항목 | 설명 | 셰이더 프로퍼티 |
|---|---|---|
| **클래식 헐 사용** | 메시를 뒤집어 확장하는 방식의 외곽선입니다. 추가 패스 한 번으로 그려지고 깊이 텍스처 없이 동작합니다. | `_OutlineHullEnabled` |
| **폭** | 아웃라인의 굵기입니다. 캐릭터 전체를 보면서 실루엣이 뭉개지지 않는 선에서 조절하세요. 부위별 굵기 차이는 폭 마스크로 만듭니다. | `_OutlineHullWidth` |
| **헐 색** | 노멀 아웃라인 선의 색입니다. 베이스를 어둡게 만든 근접색을 쓰면 자연스럽고, 검정에 가까울수록 만화풍이 강해집니다. | `_OutlineHullColor` |
| **DOF에서 헐 보호** | 아웃라인이 깊이를 기록해 피사계 심도(DOF) 블러가 선을 지우지 못하게 보호합니다. 아웃라인이 다른 깊이 기반 포스트 효과에 잘못 반응하면 꺼 보세요. | `_OutlineHullDofProtection` |
| **원거리 최소 픽셀** | 멀리 있어도 아웃라인이 이 화면 픽셀 수보다 가늘어지지 않게 유지합니다. 원거리에서 선이 끊겨 보이면 올리고, 멀리서 선이 너무 도드라지면 낮추세요. | `_OutlineDistanceMinPixels` |
| **폭 모드** | PixelStable은 화면 픽셀 기준이라 거리와 무관하게 선 두께가 일정하고, WorldSpace는 월드 크기 기준이라 멀어질수록 얇아집니다. 아바타에는 PixelStable이 안전합니다. | `_OutlineHullWidthMode` |
| **헐 압력 대비** | 압력 값을 지수로 눌러 선 굵기 차이를 키웁니다. 0이면 압력이 완전히 무시되고, 1이 원본, 높일수록 얇은 곳이 더 얇아집니다. Pressure Source가 OutlineNormalUV8이면 긴 면은 두껍게 꼭짓점은 얇게 나옵니다. | `_OutlineHullPressureContrast` |
| **노멀 소스** | 헐을 어느 방향으로 밀어낼지 정합니다. MeshNormal은 메시 노멀을 그대로 쓰고, VertexColorTS와 UV8TS는 스무딩한 외곽선 노멀을 버텍스 컬러나 UV8에 구워 두었을 때만 유효합니다. 굽지 않은 메시에서 고르면 각진 부분에서 선이 끊어집니다. | `_OutlineHullNormalSource` |
| **지정 벡터 방향 사용** | 외곽선을 밀어낼 방향을 텍스처로 직접 지정합니다. 끄면 아래의 벡터 UV와 벡터 스케일이 무시되고 노멀 소스가 방향을 결정합니다. | `_OutlineVectorEnabled` |
| **벡터 UV** | 외곽선 방향 텍스처를 읽을 UV 채널입니다. 지정 벡터 방향 사용이 꺼져 있으면 무시됩니다. | `_OutlineVectorUVMode` |
| **벡터 스케일** | 지정한 방향 벡터의 세기입니다. 음수로 두면 방향이 반대로 뒤집힙니다. 지정 벡터 방향 사용이 꺼져 있으면 무시됩니다. | `_OutlineVectorScale` |
| **깊이 바이어스** | 헐 전체를 카메라 쪽으로 당기거나 뒤로 밀어 다른 파츠에 파묻힌 외곽선을 꺼냅니다. 너무 많이 당기면 선이 얼굴 앞으로 떠올라 보입니다. | `_OutlineHullZBias` |
| **셰이딩 포함** | 형태·캐스트·2D 그림자와 2D 림을 최종 외곽선 색상에 함께 반영합니다. 끄면 외곽선은 조명과 무관한 균일한 색상을 유지합니다. | `_OutlineIncludeFormShadow` |
| **아웃라인 그림자 패턴** | 그림자 패턴(스크린톤) 무늬를 아웃라인에도 적용합니다. 그림자 패턴 탭의 설정을 그대로 따릅니다. | `_OutlinePatternEnabled` |
| **Hull 외곽선에 적용** | 페인팅한 압력을 Hull 외곽선 굵기에 반영합니다. 압력 소스가 Constant면 켜도 변화가 없습니다. | `_OutlineHullPressureApply` |
| **블렌드 불투명도** | 아웃라인 색이 섞이는 비율입니다. 0이면 선이 보이지 않습니다. | `_OutlineHullColorBlendOpacity` |

## 아웃라인

외곽선 폭, 색상, 마스크, 거리 보정을 설정합니다.

| 항목 | 설명 | 셰이더 프로퍼티 |
|---|---|---|
| **아웃라인 마스터** | 노멀 아웃라인과 내부 2D 경계가 함께 쓰는 공통 게이트입니다. 꺼져 있으면 두 탭 모두 렌더링되지 않습니다. 구버전 머티리얼 호환용 스위치입니다. | `_OutlineEnabled` |

## 스텐실 설정

일반 패스와 노멀 아웃라인 패스의 스텐실 상태를 각각 설정합니다.

| 항목 | 설명 | 셰이더 프로퍼티 |
|---|---|---|
| **스텐실 참조값** | 외곽선 패스가 사용하는 스텐실 값입니다. 다른 셰이더의 마스크와 맞출 때만 건드리세요. 기본값에서는 스텐실이 결과에 영향을 주지 않습니다. | `_OutlineStencilRef` |
| **스텐실 읽기 마스크** | 스텐실 버퍼를 읽을 때 적용할 비트 마스크입니다. 다른 셰이더의 스텐실 마스크와 연동할 때만 사용합니다. | `_OutlineStencilReadMask` |
| **스텐실 쓰기 마스크** | 스텐실 버퍼에 기록할 때 적용할 비트 마스크입니다. 다른 셰이더의 스텐실 마스크와 연동할 때만 사용합니다. | `_OutlineStencilWriteMask` |
| **스텐실 비교** | 스텐실 값을 어떻게 비교해 픽셀을 통과시킬지 정합니다. Always면 스텐실이 외곽선을 가리지 않습니다. 다른 셰이더로 외곽선을 잘라낼 때만 바꾸세요. | `_OutlineStencilComp` |
| **스텐실 통과 동작** | 스텐실과 깊이 테스트를 모두 통과했을 때 스텐실 버퍼에 할 동작입니다. 기본 Keep은 버퍼를 바꾸지 않습니다. | `_OutlineStencilPass` |
| **스텐실 실패 동작** | 스텐실 테스트에 실패했을 때 스텐실 버퍼에 할 동작입니다. 기본 Keep은 버퍼를 바꾸지 않습니다. | `_OutlineStencilFail` |
| **깊이 실패 동작** | 스텐실은 통과했지만 깊이 테스트에 실패했을 때의 동작입니다. 기본 Keep은 버퍼를 바꾸지 않습니다. | `_OutlineStencilZFail` |
