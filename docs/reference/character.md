# 캐릭터 표현

얼굴과 캐릭터 전체를 대상으로 하는 항목입니다. 얼굴은 코와 눈두덩이 만드는 그림자 때문에 몸과 같은 설정으로는 거의 항상 지저분해지므로 따로 다룹니다.

:::note
이 페이지의 항목 이름과 설명은 MingToon 인스펙터가 실제로 표시하는 문구를 소스에서 그대로 가져온 것입니다.
:::

## 페이스 셰이딩

캐릭터 얼굴 전용 마스크와 명암 방향을 설정합니다.

| 항목 | 설명 | 셰이더 프로퍼티 |
|---|---|---|
| **기본 형태 그림자 제거** | 1이면 얼굴 영역의 형태 그림자를 완전히 지웁니다. 코·볼 그림자를 없애고 2D 그림자나 그림자 텍스처로만 얼굴 음영을 만들 때 사용합니다. | `_FaceFormShadowLift` |
| **얼굴 경계** | 얼굴 영역에만 적용되는 형태 그림자 경계입니다. 몸통보다 낮게(마이너스 쪽으로) 두면 얼굴이 늦게 어두워져 일러스트처럼 깨끗하게 유지됩니다. 형태 그림자가 꺼져 있으면 반영되지 않습니다. | `_FaceFormShadowMidPoint` |
| **얼굴 부드러움** | 얼굴 영역 형태 그림자 경계의 번짐 폭입니다. 형태 그림자가 꺼져 있으면 반영되지 않습니다. | `_FaceFormShadowSoftness` |
| **프록시 구를 얼굴 영역으로 사용** | 얼굴 마스크 텍스처 없이 프록시 구 안쪽을 얼굴로 간주합니다. 얼굴 영역 마스크 사용이 켜져 있으면 마스크가 우선하므로 이 옵션은 무시됩니다. | `_FaceAreaProxyMaskEnabled` |
| **얼굴 영역 마스크 사용** | 머리와 몸이 한 머티리얼에 섞여 있을 때 어디까지가 얼굴인지 텍스처로 지정합니다. 끄면 아래의 채널·강도·반전·리맵이 모두 무시됩니다. | `_FaceAreaMaskEnabled` |
| **프록시 구 중심** | 머리를 대신하는 가상 구의 중심입니다. 씬 뷰의 얼굴 프록시 도구로 맞추는 편이 정확합니다. 노멀 누름 정도가 0이면 사용되지 않습니다. | `_FaceProxyCenterOS` |
| **프록시 구 반지름** | 가상 구의 반지름입니다. 얼굴 영역 마스크 대신 프록시 구를 쓰면 이 구 안쪽이 얼굴로 인식되므로, 너무 크면 목이나 손까지 얼굴로 처리됩니다. | `_FaceProxyRadiusOS` |
| **마스크 채널 (RGBA)** | 마스크 텍스처에서 읽을 채널의 가중치입니다. G 채널만 쓰려면 (0, 1, 0, 0)처럼 입력합니다. | `_FaceAreaMaskChannel` |
| **마스크 강도** | 0이면 마스크 텍스처를 무시하고 머티리얼 전체를 얼굴로 취급합니다. 1이면 마스크를 그대로 사용합니다. | `_FaceAreaMaskStrength` |
| **마스크 반전** | 얼굴 영역 마스크의 흑백을 뒤집습니다. 얼굴이 검게 그려진 마스크를 그대로 쓸 때 사용합니다. | `_FaceAreaMaskInvert` |
| **리맵 시작** | 마스크의 회색 구간을 다시 펼치는 시작점입니다. 올리면 얼굴로 인정되는 범위가 좁아집니다. 리맵 시작과 끝이 같으면 경계가 완전히 딱딱해집니다. | `_FaceAreaMaskRemapStart` |
| **리맵 끝** | 마스크의 회색 구간을 다시 펼치는 끝점입니다. 낮추면 얼굴 경계가 급격해집니다. 리맵 시작과 끝이 같으면 경계가 완전히 딱딱해집니다. | `_FaceAreaMaskRemapEnd` |
| **얼굴 자체 캐스트 사용** | 얼굴 메시가 실시간 그림자를 드리울지 정합니다. 끄면 앞머리가 얼굴에 실제 그림자를 만들지 않으므로, 이마 그림자를 2D 그림자로만 그릴 때 유용합니다. | `_FaceShadowCasterEnabled` |
| **실제 그림자 캐스터 오프셋** | 얼굴의 그림자 캐스터를 앞뒤로 밀어 앞머리 그림자가 떨어지는 위치를 미세 조정합니다. 얼굴 자체 캐스트 사용이 꺼져 있으면 반영되지 않습니다. | `_FaceShadowCasterOffset` |
| **노멀 방식** | 0이면 얼굴 노멀을 정면 방향으로 완전히 눌러 코 그림자가 사라지고, 1이면 프록시 구를 따라 완만한 곡면이 됩니다. 노멀 누름 정도가 0이면 이 값은 반영되지 않습니다. | `_FaceNormalMode` |
| **노멀 누름 정도** | 얼굴 노멀 보정을 얼마나 적용할지 정합니다. 0이면 노멀 방식·프록시 구 중심·프록시 구 반지름이 모두 무시되고 원래 메시 노멀이 그대로 쓰입니다. | `_FaceNormalFlattenAmount` |
