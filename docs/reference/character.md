# 캐릭터 표현

얼굴과 캐릭터 전체를 대상으로 하는 항목입니다. 얼굴은 코와 눈두덩이 만드는 그림자 때문에 몸과 같은 설정으로는 거의 항상 지저분해지므로 따로 다룹니다.

:::note
이 페이지의 항목 이름과 설명은 MingToon 인스펙터가 실제로 표시하는 문구를 소스에서 그대로 가져온 것입니다.
:::

## 페이스/헤어 셰이딩

얼굴 마스크와 명암 방향을 설정합니다. 프록시 볼륨과 SDF는 헤어에도 쓸 수 있습니다.

| 항목 | 설명 | 셰이더 프로퍼티 |
|---|---|---|
| **페이스 셰이딩 모듈** | 얼굴 전용 음영 모듈을 켭니다. 얼굴 머티리얼에서만 사용하세요. 몸 머티리얼에 켜면 몸의 음영이 얼굴 규칙을 따라가 어색해집니다. | `_MingFaceShadingEnabled` |
| **얼굴 영역 마스크 사용** | 머리와 몸이 한 머티리얼에 섞여 있을 때 어디까지가 얼굴인지 텍스처로 지정합니다. 끄면 아래의 채널·강도·반전·리맵이 모두 무시됩니다. | `_FaceAreaMaskEnabled` |
| **버텍스 페인트 얼굴 영역** | 기본값은 꺼짐입니다. 얼굴 페인트 도구의 버텍스 값을 얼굴 영역으로 사용합니다. 텍스처 얼굴 마스크가 켜져 있으면 텍스처가 우선합니다. | `_FaceAreaVertexMaskEnabled` |
| **프록시 구를 얼굴 영역으로 사용** | 얼굴 마스크 텍스처 없이 프록시 구 안쪽을 얼굴로 간주합니다. 얼굴 영역 마스크 사용이 켜져 있으면 마스크가 우선하므로 이 옵션은 무시됩니다. | `_FaceAreaProxyMaskEnabled` |
| **얼굴 경계** | 얼굴 영역에만 적용되는 형태 그림자 경계입니다. 범위 0~1, 기본값 0.25입니다. 0에 가까울수록 얼굴이 늦게 어두워지고, 1에 가까울수록 일찍 어두워집니다. 형태 그림자가 꺼져 있으면 반영되지 않습니다. | `_FaceFormShadowMidPoint` |
| **얼굴 부드러움** | 얼굴 영역 형태 그림자 경계의 번짐 폭입니다. 형태 그림자가 꺼져 있으면 반영되지 않습니다. | `_FaceFormShadowSoftness` |
| **프록시 구 중심** | 머리를 대신하는 가상 구의 중심입니다. 씬 뷰의 얼굴 프록시 도구로 맞추는 편이 정확합니다. 노멀 누름 정도가 0이면 사용되지 않습니다. | `_FaceProxyCenterOS` |
| **프록시 구 반지름** | 가상 구의 반지름입니다. 얼굴 영역 마스크 대신 프록시 구를 쓰면 이 구 안쪽이 얼굴로 인식되므로, 너무 크면 목이나 손까지 얼굴로 처리됩니다. | `_FaceProxyRadiusOS` |
| **프록시 경계 부드러움** | 프록시 구 경계에서 얼굴 영역이 몇 %의 반지름에 걸쳐 서서히 사라질지 정합니다. 얼굴 영역은 형태 그림자 경계·번짐을 얼굴 값으로 바꾸고 노멀도 함께 누르므로, 값이 작으면 귀나 턱선 주변에 셰이딩이 뚝 끊기는 띠가 생깁니다. 반지름 위치는 바뀌지 않고 전환 폭만 넓어집니다. | `_FaceProxyEdgeSoftness` |
| **프록시 모양** | Sphere(0, 기본값)는 둥근 머리, Cylinder(1)는 축 방향으로 무한한 통, Capsule(2)는 길이가 정해진 통입니다. 축은 Cylinder·Capsule, 높이는 Capsule에서만 적용됩니다. | `_FaceProxyShape` |
| **프록시 축** | 오브젝트 공간의 길이 방향입니다. 기본값 (0,1,0)은 머리 위쪽입니다. Cylinder·Capsule에서만 쓰며 0 벡터는 피하세요. | `_FaceProxyAxisOS` |
| **캡슐 높이** | Capsule의 축 선분 길이입니다. 범위 0.001~4, 기본값 0.3입니다. 0에 가까우면 Sphere와 같아지고, 너무 크면 목·머리카락까지 얼굴로 분류될 수 있습니다. | `_FaceProxyHeightOS` |
| **얼굴 프록시 뎁스 (실험적)** | 깊이 버퍼와 그림자 맵에 얼굴 메시 대신 프록시 볼륨을 기록합니다. 색상 패스는 그대로이므로 앞머리 그림자는 실제 얼굴 굴곡을 따라 선명하게 드리웁니다. 프록시를 배치하지 않은 재질에서는 아무 일도 일어나지 않습니다. | `_MingFaceProxyDepthEnabled` |
| **프록시 뎁스 적용량** | 원본 얼굴 위치와 프록시 표면 사이의 블렌드입니다. 1이면 완전히 프록시로 치환하고, 0이면 원본 그대로입니다. 코나 눈두덩이 얼마나 남을지를 이 값으로 조절합니다. | `_MingFaceProxyDepthAmount` |
| **프록시 뎁스 적용 범위** | CameraDepthOnly(0, 기본값)는 카메라 깊이 렌더에만 적용해 월드 AO와 깊이 모듈이 보는 얼굴만 매끈하게 만듭니다. CameraDepthAndShadow(1)는 실시간 그림자 캐스터까지 축소된 프록시로 바꿔 얼굴 셀프섀도를 없앱니다. 얼굴이 남에게 던지는 그림자가 돔 실루엣이 되므로 단계적으로 켜세요. | `_MingFaceProxyDepthMode` |
| **섀도우 캐스터 축소 (m)** | 그림자 캐스터로 쓰는 프록시를 반지름 방향으로 몇 미터 줄일지 정합니다. 줄어든 만큼 실제 표면이 캐스터 바깥에 놓이므로 얼굴이 자기 그림자에 잠기지 않습니다. 너무 작으면 눈두덩처럼 오목한 곳이 돔 안쪽에 남아 다시 그림자가 생기고, 너무 크면 턱이 목에 던지는 그림자가 얇아집니다. 적용 범위가 CameraDepthAndShadow일 때만 쓰입니다. | `_MingFaceProxyDepthShadowShrink` |
| **SDF 얼굴 그림자 사용** | 기본값은 꺼짐입니다. 방향성 SDF로 얼굴 형태 그림자를 만듭니다. 텍스처 샘플과 연산이 추가되므로 필요한 얼굴 재질에만 켜세요. | `_FaceSdfEnabled` |
| **SDF 좌표** | Base Texture UV(0)는 기존 UV 섬, Baked Front UV7(1, 기본값)은 정면 연속 좌표입니다. SDF가 UV7을 쓰면 베이크 얼굴 노멀은 지오메트리 노멀로 안전하게 폴백합니다. | `_FaceMapUvMode` |
| **베이크 얼굴 노멀 상태** | Manager가 관리하는 숨김 출력입니다. 1이면 UV7 베이크 노멀을 사용하며 데이터가 없거나 SDF가 UV7을 쓰면 지오메트리 노멀로 폴백합니다. 직접 수정하지 마세요. | `_FaceNormalBaked` |
| **기본 형태 그림자 제거** | 1이면 얼굴 영역의 형태 그림자를 완전히 지웁니다. 코·볼 그림자를 없애고 2D 그림자나 그림자 텍스처로만 얼굴 음영을 만들 때 사용합니다. | `_FaceFormShadowLift` |
| **얼굴 영역 마스크** | 기본 UV 텍스처로 얼굴 범위를 정합니다. 흰색은 얼굴, 검은색은 비얼굴이며 사용 토글이 꺼져 있으면 읽지 않습니다. 기본 흰 텍스처는 재질 전체를 얼굴로 만듭니다. | `_FaceAreaMask` |
| **얼굴 자체 캐스트 사용** | 이 머티리얼의 얼굴 영역이 실시간 그림자를 드리울지 정합니다. 끄면 얼굴이 목·옷 등 다른 표면에 만드는 그림자만 사라집니다. 앞머리 그림자는 헤어 머티리얼이 드리우므로 이 토글로는 사라지지 않습니다. 카메라 깊이 기록은 유지되어 2D 그림자·깊이 림은 그대로 동작합니다. | `_FaceShadowCasterEnabled` |
| **깊이 꺼짐 시 투영 그림자** | '얼굴용 자동 보정'은 2D 그림자에게 얼굴을 넘기려고 얼굴에서 투영 그림자를 빼 둡니다. 이 항목을 켜면, 깊이 효과 마스터가 꺼져 있거나 '깊이 가용성'이 Force Off인 동안에는 그 투영 그림자를 얼굴에 도로 돌려줍니다. 깊이가 켜져 있는 동안에는 아무것도 달라지지 않습니다. | `_FaceDepthOffProjectedShadowEnabled` |
| **실제 그림자 캐스터 오프셋** | 얼굴 영역의 그림자 캐스터를 노멀 방향으로 밀어, 실시간 그림자가 얼굴 자신과 겹치는 정도를 조정합니다. '얼굴 2D 그림자 어시스트'가 켜져 있을 때만 적용됩니다. 앞머리 그림자의 위치는 바꾸지 않습니다 — 그 그림자는 헤어 머티리얼이 드리웁니다. | `_FaceShadowCasterOffset` |
| **마스크 채널 (RGBA)** | 마스크 텍스처에서 읽을 채널의 가중치입니다. G 채널만 쓰려면 (0, 1, 0, 0)처럼 입력합니다. | `_FaceAreaMaskChannel` |
| **마스크 강도** | 0이면 마스크 텍스처를 무시하고 머티리얼 전체를 얼굴로 취급합니다. 1이면 마스크를 그대로 사용합니다. | `_FaceAreaMaskStrength` |
| **마스크 반전** | 얼굴 영역 마스크의 흑백을 뒤집습니다. 얼굴이 검게 그려진 마스크를 그대로 쓸 때 사용합니다. | `_FaceAreaMaskInvert` |
| **리맵 시작** | 마스크의 회색 구간을 다시 펼치는 시작점입니다. 올리면 얼굴로 인정되는 범위가 좁아집니다. 리맵 시작과 끝이 같으면 경계가 완전히 딱딱해집니다. | `_FaceAreaMaskRemapStart` |
| **리맵 끝** | 마스크의 회색 구간을 다시 펼치는 끝점입니다. 낮추면 얼굴 경계가 급격해집니다. 리맵 시작과 끝이 같으면 경계가 완전히 딱딱해집니다. | `_FaceAreaMaskRemapEnd` |
| **노멀 누름 정도** | 얼굴 노멀 보정을 얼마나 적용할지 정합니다. 0이면 노멀 방식·프록시 구 중심·프록시 구 반지름이 모두 무시되고 원래 메시 노멀이 그대로 쓰입니다. 베이크된 재질에서도 이 값이 라이브로 적용량을 정합니다. 0이면 원본 노멀입니다. | `_FaceNormalFlattenAmount` |
| **노멀 방식** | 0이면 얼굴 노멀을 정면 방향으로 완전히 눌러 코 그림자가 사라지고, 1이면 프록시 구를 따라 완만한 곡면이 됩니다. 노멀 누름 정도가 0이면 이 값은 반영되지 않습니다. | `_FaceNormalMode` |
| **공용 가로 스케일** | 텍스처 중심 기준 가로 스케일입니다. 범위 0.1~4, 기본값 0.5입니다. 슬롯 Tiling에 추가로 곱해지므로 정렬할 때는 한쪽씩 조절하세요. | `_FaceMapScaleX` |
| **공용 세로 스케일** | 텍스처 중심 기준 세로 스케일입니다. 범위 0.1~4, 기본값 0.5입니다. 슬롯 Tiling과 함께 적용되고 바깥 픽셀은 반복하지 않습니다. | `_FaceMapScaleY` |
| **공용 가로 위치** | 스케일 후 SDF를 가로 이동합니다. 범위 -1~1, 기본값 0입니다. 눈과 코의 좌우 중심을 작은 값부터 맞추세요. | `_FaceMapOffsetX` |
| **공용 세로 위치** | 스케일 후 SDF를 세로 이동합니다. 범위 -1~1, 기본값 0입니다. 타일링처럼 보이면 텍스처 Wrap Mode가 Clamp인지 확인하세요. | `_FaceMapOffsetY` |
| **SDF 테스트 표시** | 기본값은 꺼짐입니다. 조명을 무시하고 원본 SDF를 그레이스케일로 표시해 정렬·채널을 진단합니다. 베이크 셰이더에서는 자동 제거됩니다. | `_FaceSdfTestMode` |
| **테스트 표시 채널** | R=좌, G=우, B=위, A=아래입니다. Maximum(4, 기본값)은 네 채널 중 최댓값으로 전체 정렬을 빠르게 확인합니다. | `_FaceSdfTestChannel` |
| **SDF 맵 형식** | Packed RGBA(0, 기본값)는 R/G=좌우, B/A=상하입니다. Single Channel Mirrored U(1)는 R grayscale를 반대쪽에서 U 반전해 재사용하며 상하 영향은 무시합니다. | `_FaceSdfMode` |
| **얼굴 SDF 맵** | 경계 순서 텍스처이며 기본값은 회색입니다. Packed는 RG 좌우·BA 상하, 단일 채널은 R을 읽습니다. Clamp와 Bilinear를 권장하며 텍스처 샘플 비용이 추가됩니다. | `_FaceSdfMap` |
| **좌우 영향** | 좌우 조명 반응량입니다. 범위 0~1, 기본값 1입니다. 0이면 좌우 변화가 사라지고 1이면 맵을 전부 사용합니다. | `_FaceSdfHorizontalStrength` |
| **상하 영향** | 상하 조명 반응량입니다. 범위 0~1, 기본값 1입니다. Packed RGBA의 B/A에만 적용되고 단일 grayscale 모드에서는 무시됩니다. | `_FaceSdfVerticalStrength` |
| **SDF 그림자 양** | SDF 어두운 영역의 최종 강도입니다. 범위 0~1, 기본값 1입니다. 0은 숨기고 1은 계산 결과를 그대로 씁니다. | `_FaceSdfShadowAmount` |
| **경계 이동** | 그림자가 시작되는 시점을 이동합니다. 범위 -1~1, 기본값 0입니다. 맵 위치가 아니라 명암 경계이므로 작은 값부터 조절하세요. | `_FaceSdfThresholdOffset` |
| **경계 부드러움** | 밝음과 그림자 전환 폭입니다. 범위 0.001~0.5, 기본값 0.04입니다. 너무 작으면 텍스처 해상도·압축 노이즈가 드러납니다. | `_FaceSdfSoftness` |
| **SDF 적용 마스크 사용** | 기본값은 꺼짐입니다. 귀·뒤통수처럼 SDF를 받지 않을 부분을 기본-UV 마스크로 제외합니다. 얼굴 영역 마스크와는 별개입니다. | `_FaceSdfMaskEnabled` |
| **SDF 적용 마스크** | 기본 UV로 읽습니다. 흰색은 SDF 적용, 검은색은 원래 음영 유지입니다. 사용 토글이 꺼져 있으면 샘플하지 않습니다. | `_FaceSdfMask` |
| **SDF 마스크 강도** | 마스크 제한 강도입니다. 범위 0~1, 기본값 1입니다. 0이면 마스크를 무시하고 1이면 그린 값을 그대로 씁니다. | `_FaceSdfMaskStrength` |

## 캐릭터 높이 그라데이션

캐릭터 루트 기준 UV4 높이로 하단 색 그레이딩을 적용합니다.

| 항목 | 설명 | 셰이더 프로퍼티 |
