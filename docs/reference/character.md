# 캐릭터 표현

얼굴과 캐릭터 전체를 대상으로 하는 항목입니다.

이 페이지는 값을 찾는 표입니다. 켜는 순서가 필요하면 [캐릭터 표현 가이드](/guides/character)를 보세요.

제목과 차례는 인스펙터의 섹션 이름과 표시 순서를 그대로 따릅니다.

맵과 마스크 슬롯 안의 항목은 모든 슬롯이 같습니다.
채널·리맵·페더·마스크 UV는 [텍스처 슬롯 공통 UI](/guides/texture-modules)에 한 번만 적었습니다.

## 페이스/헤어 셰이딩 {#페이스헤어-셰이딩}

| 인스펙터 라벨 | 형식 | 범위 | 기본값 | 하는 일 |
|---|---|---|---|---|
| **페이스 셰이딩 모듈** | 켜기/끄기 | - | 꺼짐 | 얼굴 전용 음영 모듈을 켭니다 |
| **정면 방향 (오브젝트 공간)** | 실수 | 네 값 | 0, 0, 1, 0 | 얼굴이 바라보는 방향을 오브젝트 좌표로 지정합니다 |
| **기본 형태 그림자 제거** | 실수 | 0 ~ 1 | 0 | 1이면 얼굴 영역의 형태 그림자를 완전히 지웁니다 |
| **얼굴 경계** | 실수 | -1 ~ 1 | 0 | 얼굴 영역에만 적용되는 형태 그림자 경계입니다 |
| **얼굴 부드러움** | 실수 | 0.001 ~ 2 | 0.15 | 얼굴 영역 형태 그림자 경계의 번짐 폭입니다 |
| **버텍스 페인트로 얼굴 영역 지정** | 켜기/끄기 | - | 꺼짐 | 얼굴 페인트 도구의 버텍스 값을 얼굴 영역으로 사용합니다 |
| **얼굴 영역 마스크 사용** | 켜기/끄기 | - | 꺼짐 | 머리와 몸이 한 머티리얼에 섞여 있을 때 어디까지가 얼굴인지 텍스처로 지정합니다 |
| **얼굴 영역 마스크** | 텍스처 | - | 없음 | 기본 UV 텍스처로 얼굴 범위를 정합니다 |
| **얼굴용 자동 보정** | 켜기/끄기 | - | 꺼짐 | 얼굴 영역을 지정한 뒤 켜면 그 영역에서 MingToon 카메라 깊이 기반 투영 그림자의 자기 겹침을… |
| **얼굴 자체 캐스트 사용** | 켜기/끄기 | - | 켜짐 | 이 머티리얼의 얼굴 영역이 실시간 그림자를 드리울지 정합니다 |
| **SDF 얼굴 그림자 사용** | 켜기/끄기 | - | 꺼짐 | 방향성 SDF로 얼굴 형태 그림자를 만듭니다 |
| **SDF 좌표** | 실수 | - | 1 | Base Texture UV(0)는 기존 UV 섬, Baked Front UV7(1, 기본값)은 정면 연속… |
| **공용 가로 스케일** | 실수 | 0.1 ~ 4 | 0.5 | 텍스처 중심 기준 가로 스케일입니다 |
| **공용 세로 스케일** | 실수 | 0.1 ~ 4 | 0.5 | 텍스처 중심 기준 세로 스케일입니다 |
| **공용 가로 위치** | 실수 | -1 ~ 1 | 0 | 스케일 후 SDF를 가로 이동합니다 |
| **공용 세로 위치** | 실수 | -1 ~ 1 | 0 | 스케일 후 SDF를 세로 이동합니다 |
| **SDF 테스트 표시** | 켜기/끄기 | - | 꺼짐 | 조명을 무시하고 원본 SDF를 그레이스케일로 표시해 정렬·채널을 진단합니다 |
| **표시 채널** | 선택 | R / G / B / A / Maximum | Maximum | R=좌, G=우, B=위, A=아래입니다 |
| **맵 형식** | 선택 | Packed RGBA / Single Channel Mirrored U | Packed RGBA | Packed RGBA(0, 기본값)는 R/G=좌우, B/A=상하입니다 |
| **단일 채널 SDF 맵 (R/그레이스케일, 좌우 미러)** | 텍스처 | - | 없음 | 4방향 SDF 맵 (RG 좌우 / BA 상하) |
| **좌우 영향** | 실수 | 0 ~ 1 | 1 | 좌우 조명 반응량입니다 |
| **상하 영향** | 실수 | 0 ~ 1 | 1 | 상하 조명 반응량입니다 |
| **SDF 그림자 양** | 실수 | 0 ~ 1 | 1 | SDF 어두운 영역의 최종 강도입니다 |
| **경계 이동** | 실수 | -1 ~ 1 | 0 | 그림자가 시작되는 시점을 이동합니다 |
| **경계 부드러움** | 실수 | 0.001 ~ 0.5 | 0.04 | 밝음과 그림자 전환 폭입니다 |
| **SDF 적용 마스크 사용** | 켜기/끄기 | - | 꺼짐 | 귀·뒤통수처럼 SDF를 받지 않을 부분을 기본-UV 마스크로 제외합니다 |
| **SDF 적용 마스크 (귀/뒤통수 제외)** | 텍스처 | - | 없음 | 기본 UV로 읽습니다 |
| **맵과 강도 · 마스크 강도** | 실수 | 0 ~ 1 | 1 | 마스크 제한 강도입니다 |
| **프록시 모양** | 선택 | Sphere / Cylinder / Capsule / Plane | Plane | Sphere(0, 기본값)는 닫힌 구, Cylinder(1)는 길이가 정해진 닫힌 원통… |
| **프록시 메시 노멀 사용** | 켜기/끄기 | - | 꺼짐 | 실제 프록시 메시의 스무스 노멀을 얼굴 정점에 전송합니다 |
| **프록시 중심** | 실수 | 네 값 | 0, 0, 0, 1 | 실제 구·원기둥·캡슐 프록시 메시의 오브젝트 공간 중심입니다 |
| **프록시 반지름** | 실수 | 0.001 ~ 2 | 0.12 | 실제 프록시 메시의 반지름입니다 |
| **프록시 경계 부드러움** | 실수 | 0 ~ 1 | 0.15 | 선택한 프록시 볼륨 경계에서 얼굴 영역이 몇 %의 반지름에 걸쳐 서서히 사라질지 정합니다 |
| **프록시 축 (0 = 자동)** | 실수 | 네 값 | 0, 1, 0, 0 | Cylinder·Capsule의 길이 방향입니다 |
| **프록시 길이** | 실수 | 0.001 ~ 4 | 0.3 | Cylinder에서는 원통의 전체 높이입니다 |
| **마스크 채널 (RGBA)** | 실수 | 네 값 | 0, 1, 0, 0 | 마스크 텍스처에서 읽을 채널의 가중치입니다 |
| **마스크 매핑 · 마스크 강도** | 실수 | 0 ~ 1 | 1 | 0이면 마스크 텍스처를 무시하고 머티리얼 전체를 얼굴로 취급합니다 |
| **마스크 반전** | 켜기/끄기 | - | 꺼짐 | 얼굴 영역 마스크의 흑백을 뒤집습니다 |
| **리맵 시작** | 실수 | 0 ~ 1 | 0 | 마스크의 회색 구간을 다시 펼치는 시작점입니다 |
| **리맵 끝** | 실수 | 0 ~ 1 | 1 | 마스크의 회색 구간을 다시 펼치는 끝점입니다 |
| **실제 그림자 캐스터 오프셋** | 실수 | -0.05 ~ 0.05 | 0 | 얼굴 영역의 그림자 캐스터를 노멀 방향으로 밀어, 실시간 그림자가 얼굴 자신과 겹치는 정도를 조정합니다 |

|---|---|---|---|---|
| **캐릭터 높이 그라데이션** | 켜기/끄기 | - | 꺼짐 | 캐릭터 높이에 따라 아래쪽과 위쪽을 다른 색으로 물들이는 그라데이션을 켭니다 |
