# 기본 설정

베이스 색, 표면 모드, 자주 쓰는 맵. 재질을 만들면 가장 먼저 만지는 항목들입니다.

:::note
이 페이지의 항목 이름과 설명은 MingToon 인스펙터가 실제로 표시하는 문구를 소스에서 그대로 가져온 것입니다.
:::

## 기본 표면

기본 텍스처, 색상, UV 변형을 설정합니다.

| 항목 | 설명 | 셰이더 프로퍼티 |
|---|---|---|
| **베이스 맵** | 캐릭터의 기본 색 텍스처입니다. 알파 채널은 표면 모드가 Cutout 또는 Transparent일 때만 사용됩니다. | `_MainTex` |
| **베이스 색상** | 베이스 맵 위에 덧입히는 색입니다. 섞는 방식은 틴트 합성 모드, 세기는 틴트 불투명도가 정하므로 불투명도가 0이면 색을 바꿔도 아무 변화가 없습니다. | `_Color` |
| **알파 컷오프** | 표면 모드가 Cutout일 때만 동작합니다. 알파가 이 값보다 낮은 픽셀을 잘라냅니다. 머리카락·속눈썹은 0.3~0.6이 무난하고, 0에 가까우면 반투명 가장자리가 지저분하게 남습니다. | `_Cutoff` |
| **틴트 합성 모드** | 베이스 색상을 베이스 맵과 어떻게 섞을지 정합니다. 기본값 Multiply는 맵의 명암을 남긴 채 색만 입히고, Normal은 맵을 완전히 덮어 단색이 됩니다. | `_ColorBlendMode` |
| **틴트 불투명도** | 베이스 색상이 적용되는 세기입니다. 0이면 베이스 색상과 합성 모드가 모두 무시됩니다. | `_ColorBlendOpacity` |
| **마스크 채널** | 범위 마스크에서 읽을 채널입니다. 여러 마스크를 한 장에 패킹했을 때 채널을 나눠 씁니다. | `_MingBaseAdjustMaskChannel` |
| **마스크 반전** | 범위 마스크의 흑백을 뒤집어 색조보정이 적용되는 부위를 반대로 만듭니다. | `_MingBaseAdjustMaskInvert` |

## 표면 렌더링

표면 타입, 컬링, 알파 처리 방식을 설정합니다.

| 항목 | 설명 | 셰이더 프로퍼티 |
|---|---|---|
| **알파 마스크 사용** | 베이스 맵의 알파 대신 별도 이미지로 투명도를 지정합니다. 끄면 아래의 마스크 이미지·채널·반전이 모두 무시되고, 표면 모드가 Opaque면 켜도 결과가 보이지 않습니다. | `_AlphaMaskEnabled` |
| **마스크 이미지** | 투명도로 사용할 흑백 이미지입니다. 알파 마스크 사용이 꺼져 있으면 반영되지 않습니다. | `_AlphaMask` |
| **마스크 채널** | 마스크 이미지에서 읽어올 채널입니다. 여러 마스크를 한 장에 패킹했을 때 R/G/B/A를 골라 쓰고, Luma는 RGB 밝기를 사용합니다. | `_AlphaMaskChannel` |
| **마스크 반전** | 마스크의 흑백을 뒤집습니다. 지워야 할 곳이 흰색으로 그려진 마스크를 그대로 쓸 때 사용합니다. | `_AlphaMaskInvert` |
| **부드러운 컷아웃** | 컷아웃의 계단진 가장자리를 화면의 안티에일리어싱으로 다듬습니다. 머리카락 카드나 레이스처럼 잘라내는 면이 많은 메시에서 차이가 큽니다. 표면 모드가 Cutout일 때만 쓸 수 있고, 다른 모드로 바꾸면 자동으로 꺼집니다. | `_MingAlphaToCoverage` |
| **가장자리 선명도** | 다듬는 폭입니다. 1이 화면 한 픽셀 폭이고, 올리면 좁아져 또렷해지며 내리면 넓어져 뿌옇게 번집니다. 머리카락 끝이 너무 흐려 보이면 올리세요. | `_MingAlphaToCoverageSharpness` |
| **컬러 마스크** | 외곽선 패스가 기록할 컬러 채널입니다. 15가 RGBA 전체이고, 0이면 외곽선이 화면에 전혀 기록되지 않습니다. | `_OutlineColorMask` |

## 알파 페이드

| 항목 | 설명 | 셰이더 프로퍼티 |
|---|---|---|
| **거리 페이드 사용** | 카메라와의 거리에 따라 표면을 사라지게 합니다. 1인칭에서 자기 머리나 액세서리가 시야를 막지 않게 하거나, 멀어질수록 사라지게 할 때 씁니다. 켠 직후에는 기본값이 아무 것도 가리지 않으므로 아래 거리를 직접 지정해야 합니다. 표면 모드가 Opaque면 결과가 보이지 않습니다. | `_MingAlphaDistanceFadeEnabled` |
| **각도 페이드 사용** | 표면이 카메라를 향한 정도에 따라 투명도를 바꿉니다. 가장자리만 비치게 하거나 반대로 가장자리만 남기는 표현에 씁니다. 노멀맵이 아니라 메시 자체의 방향을 보므로 실루엣을 따라갑니다. 표면 모드가 Opaque면 결과가 보이지 않습니다. | `_MingAlphaFresnelEnabled` |
| **가까운 쪽 · 완전히 사라지는 거리** | 카메라가 이 거리보다 가까우면 완전히 사라집니다. 단위는 미터입니다. 0이면 가까운 쪽 페이드를 쓰지 않습니다. | `_MingAlphaFadeNearStart` |
| **가까운 쪽 · 완전히 보이는 거리** | 카메라가 이 거리보다 멀면 원래대로 보입니다. 사라지는 거리와의 사이가 서서히 옅어지는 구간입니다. 두 값이 같으면 그 지점에서 딱 끊깁니다. | `_MingAlphaFadeNearEnd` |
| **먼 쪽 · 옅어지기 시작하는 거리** | 카메라가 이 거리보다 멀어지면 옅어지기 시작합니다. 단위는 미터입니다. 최대값이면 먼 쪽 페이드를 쓰지 않습니다. | `_MingAlphaFadeFarStart` |
| **먼 쪽 · 완전히 사라지는 거리** | 카메라가 이 거리보다 멀면 완전히 사라집니다. 시작 거리와 같게 두면 그 지점에서 딱 끊깁니다. | `_MingAlphaFadeFarEnd` |
| **정면 불투명도** | 카메라를 똑바로 마주 본 면의 불투명도입니다. 1이 원래대로, 0이 완전히 투명합니다. | `_MingAlphaFresnelFacing` |
| **가장자리 불투명도** | 실루엣 가장자리의 불투명도입니다. 정면 값보다 낮으면 가장자리가 비치고, 높으면 가장자리만 남습니다. 두 값이 방향을 정하므로 별도의 모드 선택이 없습니다. | `_MingAlphaFresnelEdge` |
| **가장자리 폭** | 정면에서 가장자리로 넘어가는 속도입니다. 값을 올리면 아주 얕은 각도에만 가장자리 값이 적용되어 띠가 좁아지고, 내리면 넓게 퍼집니다. | `_MingAlphaFresnelPower` |

## 스텐실 설정

일반 패스와 노멀 아웃라인 패스의 스텐실 상태를 각각 설정합니다.

| 항목 | 설명 | 셰이더 프로퍼티 |
|---|---|---|
| **기준값** | 일반 패스가 스텐실 버퍼와 비교·기록하는 기준값(0-255)입니다. 앞머리 너머로 눈썹을 비치게 하는 식의 셰이더 조합을 만들 때만 바꾸고, 그 외에는 0으로 두세요. | `_StencilRef` |
| **읽기 마스크** | 스텐실을 비교할 때 참조하는 비트 마스크입니다. 여러 효과가 스텐실 비트를 나눠 쓸 때만 바꿉니다. | `_StencilReadMask` |
| **쓰기 마스크** | 스텐실에 기록할 때 쓰는 비트 마스크입니다. 여러 효과가 스텐실 비트를 나눠 쓸 때만 바꿉니다. | `_StencilWriteMask` |
| **비교** | 스텐실 비교 함수입니다. Always면 스텐실 검사 없이 항상 그립니다. 다른 머티리얼이 남긴 값에 반응해야 할 때만 바꾸세요. | `_StencilComp` |
| **통과 동작** | 스텐실·깊이 검사를 모두 통과했을 때 버퍼에 수행할 동작입니다. 다른 머티리얼에게 표시를 남기려면 Replace를 씁니다. | `_StencilPass` |
| **실패 동작** | 스텐실 검사에 실패했을 때 버퍼에 수행할 동작입니다. 보통 Keep으로 둡니다. | `_StencilFail` |
| **깊이 실패 동작** | 스텐실은 통과했지만 깊이 검사에 실패했을 때 수행할 동작입니다. 보통 Keep으로 둡니다. | `_StencilZFail` |

## 공통 맵

자주 쓰는 노멀, 이미션, 오클루전, 맷캡을 빠르게 설정합니다.

| 항목 | 설명 | 셰이더 프로퍼티 |
|---|---|---|
| **노멀맵** | 표면의 요철을 흉내 내는 노멀맵입니다. 노멀 레이어 01에 해당하며, 노멀 모듈이 꺼져 있으면 반영되지 않습니다. | `_BumpMap` |
| **노멀 강도** | 노멀맵 요철의 세기입니다. 0이면 맵을 넣어도 평평하게 보이고, 1이 원본 세기, 그 이상은 과장됩니다. | `_BumpScale` |
| **오클루전 맵** | 간접광이 닿기 어려운 부분을 어둡게 만드는 흑백 맵입니다. 직접광에는 영향을 주지 않으므로 정면에서 강한 조명을 받으면 효과가 잘 보이지 않습니다. | `_OcclusionMap` |
| **오클루전 강도** | 오클루전 맵의 적용량입니다. 0이면 맵을 넣어도 아무 변화가 없습니다. | `_OcclusionStrength` |
