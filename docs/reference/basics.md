# 기본 설정

재질을 만들면 가장 먼저 만지는 항목입니다. 베이스 색, 표면 모드, 투명도, 스텐실을 담습니다.

이 페이지는 값을 찾는 표입니다. 켜는 순서가 필요하면 [기본 설정 가이드](/guides/basics)를 보세요.

제목과 차례는 인스펙터의 섹션 이름과 표시 순서를 그대로 따릅니다.

맵과 마스크 슬롯 안의 채널·리맵·페더·마스크 UV 항목은 모든 슬롯이 같으므로 [텍스처 슬롯 공통 UI](/guides/texture-modules)에 한 번만 적었습니다.

| **그라데이션 LUT 사용** | 켜기/끄기 | - | 꺼짐 | 베이스 맵의 색을 R·G·B 채널별 램프로 다시 매핑합니다 |

## 스텐실 설정 {#스텐실-설정}
