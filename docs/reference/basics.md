# 기본 설정

베이스 색, 표면 모드, 자주 쓰는 맵. 재질을 만들면 가장 먼저 만지는 항목들입니다.

:::note
이 페이지의 항목 이름과 설명은 MingToon 인스펙터가 실제로 표시하는 문구를 소스에서 그대로 가져온 것입니다.
:::

## 기본 표면

기본 텍스처, 색상, UV 변형을 설정합니다.

| 항목 | 설명 | 셰이더 프로퍼티 |
|---|---|---|
| **베이스 맵** | 캐릭터의 기본 색 텍스처입니다. 알파 채널은 표면 모드가 Cutout 또는 Transparent일 때만 사용됩니다. | `_MainTex` |
| **베이스 색상** | 베이스 맵 위에 덧입히는 색입니다. 섞는 방식은 틴트 합성 모드, 세기는 틴트 불투명도가 정하므로 불투명도가 0이면 색을 바꿔도 아무 변화가 없습니다. | `_Color` |
| **알파 컷오프** | 표면 모드가 Cutout일 때만 동작합니다. 알파가 이 값보다 낮은 픽셀을 잘라냅니다. 머리카락·속눈썹은 0.3~0.6이 무난하고, 0에 가까우면 반투명 가장자리가 지저분하게 남습니다. | `_Cutoff` |
| **틴트 합성 모드** | 베이스 색상을 베이스 맵과 어떻게 섞을지 정합니다. 기본값 Multiply는 맵의 명암을 남긴 채 색만 입히고, Normal은 맵을 완전히 덮어 단색이 됩니다. | `_ColorBlendMode` |
| **틴트 불투명도** | 베이스 색상이 적용되는 세기입니다. 0이면 베이스 색상과 합성 모드가 모두 무시됩니다. | `_ColorBlendOpacity` |

## 표면 렌더링

표면 타입, 컬링, 알파 처리 방식을 설정합니다.

| 항목 | 설명 | 셰이더 프로퍼티 |
|---|---|---|
| **알파 마스크 사용** | 베이스 맵의 알파 대신 별도 이미지로 투명도를 지정합니다. 끄면 아래의 마스크 이미지·채널·반전이 모두 무시되고, 표면 모드가 Opaque면 켜도 결과가 보이지 않습니다. | `_AlphaMaskEnabled` |
| **마스크 이미지** | 투명도로 사용할 흑백 이미지입니다. 알파 마스크 사용이 꺼져 있으면 반영되지 않습니다. | `_AlphaMask` |
| **마스크 채널** | 마스크 이미지에서 읽어올 채널입니다. 여러 마스크를 한 장에 패킹했을 때 R/G/B/A를 골라 쓰고, Luma는 RGB 밝기를 사용합니다. | `_AlphaMaskChannel` |
| **마스크 반전** | 마스크의 흑백을 뒤집습니다. 지워야 할 곳이 흰색으로 그려진 마스크를 그대로 쓸 때 사용합니다. | `_AlphaMaskInvert` |
| **컬러 마스크** | 외곽선 패스가 기록할 컬러 채널입니다. 15가 RGBA 전체이고, 0이면 외곽선이 화면에 전혀 기록되지 않습니다. | `_OutlineColorMask` |

## 공통 맵

자주 쓰는 노멀, 이미션, 오클루전, 맷캡을 빠르게 설정합니다.

| 항목 | 설명 | 셰이더 프로퍼티 |
|---|---|---|
| **노멀맵** | 표면의 요철을 흉내 내는 노멀맵입니다. 노멀 레이어 01에 해당하며, 노멀 모듈이 꺼져 있으면 반영되지 않습니다. | `_BumpMap` |
| **노멀 강도** | 노멀맵 요철의 세기입니다. 0이면 맵을 넣어도 평평하게 보이고, 1이 원본 세기, 그 이상은 과장됩니다. | `_BumpScale` |
| **오클루전 맵** | 간접광이 닿기 어려운 부분을 어둡게 만드는 흑백 맵입니다. 직접광에는 영향을 주지 않으므로 정면에서 강한 조명을 받으면 효과가 잘 보이지 않습니다. | `_OcclusionMap` |
| **오클루전 강도** | 오클루전 맵의 적용량입니다. 0이면 맵을 넣어도 아무 변화가 없습니다. | `_OcclusionStrength` |
