# 조명과 그림자

툰 룩의 인상을 가장 크게 좌우하는 그룹입니다. 형태 그림자(빛의 방향으로 생기는 명암)와 그림자 투영(실시간으로 드리우는 그림자)은 서로 다른 섹션이니 구분해서 보세요.

:::note
이 페이지의 항목 이름과 설명은 MingToon 인스펙터가 실제로 표시하는 문구를 소스에서 그대로 가져온 것입니다.
:::

## 마스터 조정

빛을 더하는 것 전부 · 그림자 전부 · 최종 출력을 각각 한 번에 곱하고 틴트합니다.

| 항목 | 설명 | 셰이더 프로퍼티 |
|---|---|---|
| **밝기 배수** | 빛을 더하는 레이어 전부(백라이트·프런트라이트·프레넬 림·그림자 내부반사·2D 림라이트·깊이 투과광)의 밝기를 한 번에 조절합니다. 새 씬에서 림 계열이 전부 과하거나 약하면 모듈을 하나씩 고치는 대신 이 값을 움직이세요. 1이 기준입니다. | `_MingRimMasterIntensity` |
| **기본 색** | 빛을 더하는 레이어 전부에 곱해지는 색입니다. 각 모듈의 색은 그대로 두고 전체 색조만 씬 분위기에 맞출 때 사용합니다. 흰색이 기준입니다. | `_MingRimMasterTint` |
| **색상 패드 X** | 기본 색 위에 얹는 색상환 좌표입니다. X·Y가 모두 0이면 색이 바뀌지 않고, 중심에서 멀수록 그 방향의 색으로 진하게 물듭니다. | `_MingRimMasterColorX` |
| **색상 패드 Y** | 색상 패드 X와 한 쌍으로 색상환 위의 위치를 정합니다. 둘 다 0이면 색이 바뀌지 않습니다. | `_MingRimMasterColorY` |
| **밝기** | 색상 패드로 만든 색의 밝기입니다. 1이 기준이고, 낮추면 패드가 중앙에 있어도 대상 레이어 전체가 어두워집니다. | `_MingRimMasterColorValue` |
| **밝기 배수** | 형태·AO·림 셰이드·캐스트·2D 그림자가 전부 합쳐진 뒤 그늘진 부분만 한 번 더 조절합니다. 그림자가 전체적으로 너무 무겁거나 얕을 때 사용하세요. 밝은 면은 변하지 않습니다. | `_MingShadowMasterIntensity` |
| **기본 색** | 그림자 영역 전체에 곱해지는 색입니다. 각 그림자 레이어의 색은 유지한 채 전체 그림자를 차갑게·따뜻하게 기울일 때 사용합니다. 그늘진 만큼만 적용됩니다. | `_MingShadowMasterTint` |
| **색상 패드 X** | 그림자용 기본 색 위에 얹는 색상환 좌표입니다. X·Y가 모두 0이면 색이 바뀌지 않고, 중심에서 멀수록 그 방향의 색으로 물듭니다. | `_MingShadowMasterColorX` |
| **색상 패드 Y** | 색상 패드 X와 한 쌍으로 색상환 위의 위치를 정합니다. 둘 다 0이면 색이 바뀌지 않습니다. | `_MingShadowMasterColorY` |
| **밝기** | 색상 패드로 만든 색의 밝기입니다. 낮추면 그늘진 부분만 더 어두워집니다. 1이 기준입니다. | `_MingShadowMasterColorValue` |
| **전체 밝기 배수** | 모든 효과가 끝난 최종 캐릭터 전체의 밝기 배수입니다. 화면에서 캐릭터가 통째로 어둡거나 밝을 때 쓰는 마지막 손잡이입니다. 안개보다 앞에 적용되어 거리와 무관합니다. | `_MingOutputMasterIntensity` |
| **전체 색 보정** | 최종 출력 전체에 곱해지는 색입니다. 캐릭터 전체 색감을 씬에 맞춰 마지막으로 기울일 때 사용합니다. 흰색이 기준입니다. | `_MingOutputMasterTint` |
| **색상 패드 X** | 최종 출력의 기본 색 위에 얹는 색상환 좌표입니다. X·Y가 모두 0이면 색이 바뀌지 않고, 중심에서 멀수록 그 방향의 색으로 물듭니다. | `_MingOutputMasterColorX` |
| **색상 패드 Y** | 색상 패드 X와 한 쌍으로 색상환 위의 위치를 정합니다. 둘 다 0이면 색이 바뀌지 않습니다. | `_MingOutputMasterColorY` |
| **밝기** | 색상 패드로 만든 색의 밝기입니다. 낮추면 최종 출력 전체가 어두워집니다. 1이 기준입니다. | `_MingOutputMasterColorValue` |
| **가장자리 림 배수** | 2D 림라이트 · 프레넬 림 · 백라이트 · 깊이 투과광의 가장자리 층, 네 가지에만 추가로 곱해집니다. 위의 배수보다 한 단계 아래라, 이 값을 내려도 프런트라이트 · 그림자 내부반사 · 투과광 안쪽은 그대로 있습니다. 1이 기준입니다. | `_MingEdgeRimMasterIntensity` |
| **가장자리 림 최고 배율** | 위 네 가지를 모두 더한 뒤의 상한입니다. 각 효과의 설정은 그대로 두고 합계만 눌러 주므로, 넷을 동시에 최대로 올려도 외곽선이 하얗게 타지 않습니다. 0이면 상한 없음이고, 그게 기본값입니다. | `_MingEdgeRimBrightnessMaximum` |
| **최종 최소 밝기** | 아무리 어두운 씬에서도 캐릭터가 이보다 어두워지지 않게 막는 바닥값입니다. 어두운 월드에서 캐릭터가 새까맣게 묻히면 올리세요. 완성된 베이스 색 기준 배율입니다. | `_MingLightBrightnessMinimum` |
| **최종 최대 밝기** | 밝은 씬에서 캐릭터가 이보다 밝게 타지 않게 막는 상한입니다. 1이면 광원 색감은 유지하면서 원화보다 밝아지지 않습니다. 강한 조명에서 흰색으로 날아가면 낮추세요. | `_MingLightBrightnessMaximum` |

## 라이팅

직접광과 간접광의 반응 및 제한을 설정합니다.

| 항목 | 설명 | 셰이더 프로퍼티 |
|---|---|---|
| **베이스 색 유지** | 씬 조명이 어두워도 베이스 맵 색을 얼마나 원본에 가깝게 유지할지 정합니다. 1이면 조명 세기와 무관하게 원화 색이 남고, 0이면 조명 밝기를 그대로 따라갑니다. 조명을 예측할 수 없는 VRChat 월드에서는 높게 두는 편이 안전합니다. | `_BaseColorPreservation` |
| **씬 조명 색상 영향** | 씬 광원의 색을 캐릭터에 얼마나 반영할지 정합니다. 0이면 어떤 색 조명에서도 흰 조명처럼 보이고, 1이면 붉은 조명에서 캐릭터도 붉어집니다. 밝기가 아니라 색만 다룹니다. | `_LightColorInfluence` |
| **추가 광원 받기** | 포인트·스포트라이트 같은 추가 광원을 받는 양입니다. 월드의 잡광에 캐릭터가 번쩍이면 낮추세요. 0이면 추가 광원을 완전히 무시합니다. | `_MingAdditionalLightReceive` |
| **추가 광원 강도** | 받아들인 추가 광원의 밝기 배율입니다. 받을지 말지는 추가 광원 받기로 정하고, 받은 빛이 너무 세거나 약할 때 이 값을 조절하세요. 광원의 색은 바뀌지 않습니다. | `_MingAdditionalLightIntensity` |
| **추가 광원 베이스 색상 보존** | 1 = 원본 베이스 색상 최대 보존, 0 = 추가 광원색 완전 반영 | `_MingAdditionalLightBasePreservation` |
| **좌우 각도** | 가상 광원의 좌우 각도입니다. 얼굴에 지는 음영 방향을 보면서 잡으세요. 인게임 메뉴로 돌릴 값은 좌우 오프셋에 따로 있습니다. | `_MingVirtualLightYaw` |
| **상하 각도** | 가상 광원의 상하 각도입니다. 위에서 비추면 자연스럽고, 아래에서 비추면 공포 조명이 됩니다. 인게임 메뉴로 돌릴 값은 상하 오프셋에 따로 있습니다. | `_MingVirtualLightPitch` |
| **광원 색** | 가상 광원의 색입니다. 월드 광원 대신, 또는 그 위에 얹혀 캐릭터를 비추는 색이므로 흰색에서 시작해 씬 분위기에 맞춰 살짝만 기울이는 것이 안전합니다. | `_MingVirtualLightColor` |
| **색상 패드 X** | 광원 색 위에 얹는 색상환 좌표입니다. X·Y가 모두 0이면 색이 바뀌지 않고, 중심에서 멀수록 그 방향의 색으로 물듭니다. | `_MingVirtualLightColorX` |
| **색상 패드 Y** | 색상 패드 X와 한 쌍으로 색상환 위의 위치를 정합니다. 둘 다 0이면 색이 바뀌지 않습니다. | `_MingVirtualLightColorY` |
| **밝기** | 색상 패드로 만든 색의 밝기입니다. 광원 밝기와 곱해지므로 보통 1로 두고 광원 밝기 쪽을 조절합니다. | `_MingVirtualLightColorValue` |
| **광원 밝기** | 가상 광원의 밝기입니다. 대체 모드에서는 이 값이 곧 키 라이트 밝기이고, 추가 모드에서는 월드 광원 위에 얹는 양입니다. | `_MingVirtualLightIntensity` |
| **밝은 면 밝기** | 빛을 받는 면 전체의 밝기 배수입니다. 1이 기준이고, 올리면 밝은 면이 흰색으로 뭉개지기 쉽습니다. | `_LitBrightness` |
| **간접광 보정** | 환경광(라이트 프로브·앰비언트) 밝기만큼 형태 그림자를 들어 올려 어두운 씬에서 검게 뭉치는 것을 막습니다. 형태 그림자가 켜져 있을 때만 계산되고, 캐스트 그림자에는 별도의 캐스트 간접광 보정이 있습니다. | `_IndirectStrength` |
| **VRC 라이트 볼륨 (테스트용)** | 에디터 확인용 토글입니다. VRC 업로드 시에는 값과 상관없이 자동으로 켜져서, 월드가 배치한 VRC Light Volumes를 라이트 프로브 대신 읽습니다. 볼륨이 없는 월드에서는 프로브로 되돌아가 그림이 그대로입니다. 에디터에서 켜면 변형이 하나 더 컴파일되고 Texture3D를 한 번 더 읽으므로, 볼륨 월드에서의 룩을 미리 보고 싶을 때만 켜 보세요. Built-in 전용이라 URP 머티리얼에서는 이 줄이 보이지 않습니다. | `_MingLightVolumesEnabled` |
| **볼륨 강도** | 월드가 놓은 볼륨에서 읽어 온 간접광 전체에 곱해집니다. 1이 월드가 구운 그대로이고, 올리면 그 방 전체의 환경광이 세지는 것처럼 보입니다. 볼륨이 없는 월드에서는 프로브로 되돌아가므로 이 값이 무엇이든 그림이 바뀌지 않습니다. | `_MingLightVolumesIntensity` |
| **노멀 바이어스** | 볼륨을 읽는 지점을 표면 노멀 방향으로 밀어냅니다. 벽이나 바닥에 바싹 붙은 면이 어두운 격자 칸을 물어 얼룩질 때 올리세요. 너무 올리면 음영이 표면에서 떠 보이므로 얼룩이 사라지는 최소값에서 멈추는 것이 좋습니다. | `_MingLightVolumesNormalBias` |
| **포인트 라이트 그림자** | 월드가 구워 둔 차폐 정보를 볼륨 포인트 라이트가 얼마나 따를지 정합니다. 1이 기본 동작이고, 0이면 포인트 라이트가 그림자 없이 그대로 들어옵니다. 차폐를 굽지 않은 월드에서는 값과 무관하게 차이가 없습니다. | `_MingLightVolumesPointShadows` |
| **볼륨 스페큘러** | 볼륨의 방향 성분으로 환경 하이라이트를 만듭니다. PBR 표면이 켜져 있어야 나타나며, 반사 강도와는 별개로 동작하므로 반사를 0으로 둔 툰 머티리얼에서도 쓸 수 있습니다. Dominant는 방향 하나만 쓰는 저비용 단계이고 Full은 색 축 세 개를 각각 계산합니다. 툰 밴딩을 거치지 않는 부드러운 하이라이트입니다. | `_MingLightVolumesSpecularMode` |
| **볼륨 스페큘러 강도** | 볼륨 스페큘러의 세기입니다. 볼륨 스페큘러가 꺼져 있으면 아무 영향도 없습니다. | `_MingLightVolumesSpecularStrength` |

## 형태 그림자

형태 기반 명암 경계와 부드러움을 설정합니다.

| 항목 | 설명 | 셰이더 프로퍼티 |
|---|---|---|
| **형태 그림자** | 빛 방향에 따라 지는 형태 그림자(툰 음영)를 켜고 끕니다. 끄면 캐릭터에서 명암 단이 사라지고 캐스트·2D 그림자만 남습니다. | `_FormShadowEnabled` |
| **1차 그림자 경계** | 1차 그림자가 시작되는 경계 위치입니다. 올리면 그림자가 밝은 쪽으로 넓어지고, 내리면 빛 반대쪽으로 물러납니다. 그림자 면적이 마음에 안 들 때 가장 먼저 만지는 값입니다. | `_FormShadowMidPoint` |
| **1차 그림자 번짐** | 명암 경계의 번짐 폭입니다. 0.001에 가까우면 셀 애니메이션처럼 딱 떨어지는 경계, 0.3 이상이면 부드러운 그라데이션이 됩니다. 이 제품에서 가장 자주 조정하는 값입니다. | `_FormShadowSoftness` |
| **1차 그림자 색** | 1차 형태 그림자의 색입니다. 완전한 검정 대신 베이스보다 약간 어두운 차분한 색을 쓰면 인상이 부드러워집니다. 통합 그림자 모드가 켜져 있으면 이 색 대신 통합 색이 쓰입니다. | `_FormShadowColor` |
| **1차 그림자 밝기** | 1차 형태 그림자 색의 밝기 배수입니다. 낮출수록 어두워지며, 그림자 색상 모듈이 꺼져 있으면 반영되지 않습니다. | `_FormShadowBrightness` |
| **2차 그림자 색** | 2차(더 깊은) 형태 그림자의 색입니다. 1차보다 더 어둡게 잡는 것이 일반적입니다. 2차 그림자를 켰을 때만 보입니다. | `_FormShadow2ndColor` |
| **2차 그림자 밝기** | 2차 형태 그림자 색의 밝기 배수입니다. 1차보다 낮게 두어야 단계가 구분되어 보입니다. 2차 그림자 사용이 꺼져 있으면 반영되지 않습니다. | `_FormShadow2ndBrightness` |
| **블렌드 불투명도** | 1차 그림자 색이 결과에 섞이는 비율입니다. 그림자 색이 너무 진하게 덮으면 낮추세요. 0이면 색이 전혀 적용되지 않습니다. | `_FormShadowColorBlendOpacity` |
| **2차 그림자 사용** | 가장 어두운 쪽에 두 번째 그림자 단계를 추가해 3단 셀 음영을 만듭니다. 끄면 2차 밝기와 번짐이 모두 무시됩니다. | `_FormShadow2ndEnabled` |
| **2차 그림자 경계** | 2차 그림자의 경계 위치입니다. 1차 경계보다 어두운 쪽에 두어야 두 단이 자연스럽게 나뉩니다. | `_FormShadow2ndMidPoint` |

## 그림자 색상

툰 그림자 단계별 색상과 혼합을 설정합니다.

| 항목 | 설명 | 셰이더 프로퍼티 |
|---|---|---|
| **그림자 색상** | 그림자에 색을 입히는 처리 전체를 켜고 끕니다. 끄면 형태·캐스트·2D 그림자용으로 지정한 색과 경계색이 적용되지 않습니다. | `_ShadowColorEnabled` |
| **통합 그림자 색상** | 모든 그림자가 수렴할 색입니다. RGB는 베이스 색에 곱해지고 알파가 적용량이므로, 알파가 0이면 어떤 색을 골라도 그림자가 베이스 색 그대로 남습니다. 통합 그림자가 꺼져 있으면 사용되지 않습니다. | `_MingUnifiedShadowColor` |
| **통합 그림자 사용** | 형태·캐스트·2D 그림자를 하나의 최종 색으로 모아 겹칠 때 과도하게 어두워지는 것을 막습니다. 켜져 있는 동안 개별 그림자 색·블렌드·밝기 컨트롤은 결과에 반영되지 않습니다(값은 그대로 보존됩니다). | `_MingUnifiedShadowEnabled` |
| **그림자 주변광 영향** | 그림자를 주변광(환경광)의 색조로 물들이는 정도입니다. 노을 진 월드에서 그림자만 따로 놀면 올리세요. 밝기가 아니라 색만 가져오고, 그늘진 만큼만 적용됩니다. | `_MingShadowAmbientInfluence` |

## 그림자 투영

이 재질 위에 투영되는 캐스트 그림자와 경계 페더를 설정합니다.

| 항목 | 설명 | 셰이더 프로퍼티 |
|---|---|---|
| **그림자 투영** | 다른 물체나 자기 자신이 드리우는 투영 그림자(캐스트 섀도우)를 받을지 정합니다. 끄면 씬의 그림자가 캐릭터 위에 지지 않습니다. | `_CastShadowEnabled` |
| **수신 강도** | 다른 물체와 자기 자신이 드리우는 실시간 그림자를 얼마나 받을지 정합니다. 0이면 캐스트 그림자가 완전히 사라지고 아래의 밝기·혼합·간접광 보정도 결과에 나타나지 않습니다. | `_CastShadowReceiveStrength` |
| **PBR / 툰 혼합** | 0이면 유니티 기본 그림자처럼 부드럽게 감쇠하고, 1이면 툰 밴드로 딱 잘립니다. 밴드의 폭은 캐스트 툰 밴드 부드러움이 정합니다. | `_CastShadowToonBlend` |
| **2D 그림자와 통합** | 2D 그림자가 캐스트 그림자와 같은 색을 쓰도록 묶어 두 그림자가 겹치는 자리에서 두 번 어두워지는 것을 막습니다. 켜면 2D 그림자 색상 대신 캐스트 그림자 색상이 사용됩니다. | `_LinkDepthShadowToCastShadow` |
| **셀프 캐스트 섀도우 억제** | 메시가 자기 자신에게 드리우는 실시간 그림자를 줄입니다. 얼굴이나 옷 주름에 얼룩덜룩한 그림자가 생길 때 켭니다. 끄면 아래 바이어스 값이 무시됩니다. | `_SelfShadowCasterBiasEnabled` |
| **셀프 섀도우 캐스터 바이어스** | 그림자 캐스터를 표면에서 얼마나 밀어낼지 정합니다. 크게 올리면 얼룩은 사라지지만 접지 그림자가 뜨고 얇은 부위의 그림자가 끊깁니다. 0.01~0.03이 무난합니다. 셀프 캐스트 섀도우 억제가 꺼져 있으면 반영되지 않습니다. | `_SelfShadowCasterBias` |
| **캐스트 간접광 보정** | 환경광이 밝은 곳에서 캐스트 그림자를 옅게 만들어 실내·야외 조명 차이를 자연스럽게 흡수합니다. 1에 가까우면 밝은 씬에서 캐스트 그림자가 거의 사라집니다. | `_CastShadowIndirectLift` |
