# 조명과 그림자

툰 룩의 인상을 가장 크게 좌우하는 항목입니다. 형태 그림자와 그림자 투영은 서로 다른 섹션입니다.

이 페이지는 값을 찾는 표입니다. 켜는 순서가 필요하면 [조명과 그림자 가이드](/guides/light-and-shadow)를 보세요.

제목과 차례는 인스펙터의 섹션 이름과 표시 순서를 그대로 따릅니다.

맵과 마스크 슬롯 안의 항목은 모든 슬롯이 같습니다.
채널·리맵·페더·마스크 UV는 [텍스처 슬롯 공통 UI](/guides/texture-modules)에 한 번만 적었습니다.
