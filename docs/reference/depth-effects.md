# 깊이 기반 효과

카메라 깊이 텍스처를 읽어 화면 공간에서 그리는 효과입니다. 깊이가 없는 환경에서는 통째로 보이지 않으므로, 값을 만지기 전에 깊이부터 확인하세요. 내부 2D 경계도 이 그룹에 들어 있습니다.

:::note
이 페이지의 항목 이름과 설명은 MingToon 인스펙터가 실제로 표시하는 문구를 소스에서 그대로 가져온 것입니다.
:::

## 깊이 효과 마스터

깊이 기반 효과에 사용할 범위와 마스크를 설정합니다.

| 항목 | 설명 | 셰이더 프로퍼티 |
|---|---|---|
| **깊이 효과** | 2D 뎁스 림·깊이 투과광·2D 그림자 등 깊이 효과 전체의 마스터 스위치입니다. 끄면 세 모듈이 모두 꺼집니다. 이 효과들은 카메라 깊이 텍스처가 있어야 동작합니다. | `_DepthEffectsEnabled` |
| **깊이 가용성** | 깊이 텍스처가 있는지 판정하는 방식입니다. 기본 Auto를 유지하세요. Force On은 자동 판정이 못 보는 호스트에서 작성자가 깊이 버퍼를 보증할 때만, Force Off는 깊이 효과를 완전히 차단할 때, Diagnostic은 판정 상태를 화면에 표시합니다. | `_MingDepthAvailabilityMode` |
| **마스터 폭** | 2D 림과 2D 그림자의 화면 오프셋에 공통으로 곱해지는 배수입니다. 여기서 0으로 두면 각 모듈의 폭을 아무리 올려도 아무것도 나오지 않습니다. | `_DepthWidth` |
| **폭 모드** | Screen Pixels는 화면 픽셀 기준이라 멀어질수록 선이 상대적으로 두꺼워지고, Distance Stable은 거리와 FOV가 변해도 두께가 일정하게 보입니다. Screen Pixels를 고르면 거리 스케일이 동작하지 않습니다. | `_DepthWidthMode` |
| **거리 스케일** | 폭 모드가 Distance Stable일 때 두께의 기준 거리를 정합니다. 폭 모드가 Screen Pixels면 반영되지 않습니다. | `_DepthDistanceScale` |
| **마스터 바이어스** | 화면 깊이 차이가 이 값을 넘어야 앞뒤 경계로 인정합니다. 낮추면 얕은 굴곡에도 선이 붙어 지저분해지고, 올리면 얇은 부위의 선이 사라집니다. | `_DepthBias` |
| **마스터 부드러움** | 깊이 경계 판정의 전환 폭입니다. 낮으면 딱딱한 잉크 선, 높으면 부드럽게 번진 경계가 됩니다. | `_DepthSoftness` |
| **FX 애니메이터로 깊이 효과 전환** | 깊이 효과 마스터를 애니메이터(VRChat FX 등)로 켜고 끌 수 있게 합니다. 깊이 텍스처가 없는 월드에서 평소에는 꺼 두고, 카메라를 들 때만 켜는 용도입니다. 이 옵션을 끄면 베이크가 마스터를 상수로 접어 애니메이션이 아무 반응도 하지 않습니다. | `_MingDepthEffectsRuntimeToggle` |
| **MingToon 2D 투영 그림자 드리우기** | 이 재질을 MingToon 카메라 깊이 필드에 포함할지 정합니다. 안경·액세서리에서 끄면 Opaque·Cutout·Transparent 모두 2D 투영 그림자 캐스터에서 빠집니다. 일반 색상 렌더링, 투명 재질의 깊이 프리패스, Unity 실시간 ShadowCaster 그림자는 그대로 유지되므로 자체 정렬과 아웃라인은 켰을 때와 같습니다. 끈 재질은 자기 자신이 깊이에 없으므로 그 재질의 Depth Rim·Inner 2D Edge·2D 그림자·깊이 투과광은 자기 뒤를 보지 못합니다. 안경 자체에 림이 필요하면 깊이를 쓰지 않는 Fresnel Rim을 쓰세요. | `_Ming2DShadowCasterEnabled` |
| **2D 그림자 소멸 거리** | 2D 그림자가 완전히 사라지는 거리(미터)입니다. 페이드는 이 값의 75% 지점에서 시작하므로 12로 두면 9m부터 옅어져 12m에서 0이 됩니다. 같은 구간에서 픽셀당 깊이 읽기 횟수도 함께 줄어들어 이 거리 밖의 캐릭터는 계산 비용이 0이 되므로, 군중 씬에서는 이 값을 줄이는 것이 가장 확실한 최적화입니다. 0이면 거리 페이드를 쓰지 않습니다(비용 절감도 없습니다). | `_MingDepthShadowFarDistance` |

## 런타임 전환

| 항목 | 설명 | 셰이더 프로퍼티 |
|---|---|---|
| **VRC 품질 메뉴 사용** | VRChat EX 메뉴의 Quality(Low/Mid/High)가 이 재질에 적용되도록 합니다. 티어는 상한으로만 작동합니다 — High는 여기서 설정한 값 그대로이고, Mid는 샘플 수 계열을 낮추며, Low는 깊이 효과와 투영 그림자 부드럽게를 끕니다. 이 옵션을 끄면 베이크가 티어를 High로 상수화해서 메뉴가 이 재질에 아무 영향도 주지 않습니다. | `_MingVrcQualityMenuEnabled` |
| **FX 메뉴로 그림자 투영 전환** | 「그림자 투영」을 VRChat EX 메뉴에서 켜고 끌 수 있게 합니다. 그림자를 켠 채로 업로드하고, 사람이 많은 인스턴스에서 메뉴로 끄는 용도입니다. 런타임에 끄면 투영 그림자의 페더 샘플, 캐스트 합성, 투과광 캐스트 계산이 픽셀마다 건너뛰어집니다. 이 옵션을 끄면 베이크가 「그림자 투영」을 상수로 접어 메뉴가 아무 반응도 하지 않습니다. | `_MingCastShadowRuntimeToggle` |
| **품질 티어 미리보기** | 인게임 메뉴가 이 값을 바꿉니다. 여기서 직접 바꾸면 Low/Mid가 어떻게 보이는지 에디터에서 미리 확인할 수 있습니다. 저장할 때는 High로 되돌려 두세요 — 이 값이 재질의 기본 상태가 됩니다. | `_MingVrcQualityTier` |

## 2D 림라이트

화면 깊이 차이로 생성되는 림 효과를 설정합니다.

| 항목 | 설명 | 셰이더 프로퍼티 |
|---|---|---|
| **2D 뎁스 림** | 실루엣의 깊이 차이로 그리는 2D 림 라이트를 켜고 끕니다. 노멀 기반 프레넬 림과 달리 외곽에 균일한 굵기의 선이 생깁니다. 카메라 깊이 텍스처가 필요합니다. | `_DepthRimEnabled` |
| **깊이 림 마스크** | 2D 림을 특정 부위로 제한하는 마스크를 켭니다. 금속 장식에만 림을 남기는 식의 부위 한정에 씁니다. | `_DepthRimMaskEnabled` |
| **채널** | 림 마스크에서 읽을 채널입니다. 여러 마스크를 한 장에 패킹했을 때 채널을 나눠 씁니다. | `_DepthRimMaskChannel` |
| **반전** | 림 마스크의 흑백을 뒤집어 적용 부위를 반대로 만듭니다. | `_DepthRimMaskInvert` |
| **영향도** | 마스크가 림을 깎는 정도입니다. 1이면 마스크의 검은 곳에서 림이 완전히 사라지고, 낮추면 부분적으로 남습니다. | `_DepthRimMaskStrength` |
| **림 색상** | 2D 림의 색입니다. HDR 색이므로 강도를 올려 블룸과 함께 빛나게 할 수도 있습니다. | `_DepthRimColor` |
| **림 폭 배수** | 마스터 폭에 곱해지는 2D 림 전용 배수입니다. 최종 두께는 마스터 폭 × 이 값이므로, 마스터 폭이 0이면 여기를 올려도 소용이 없습니다. | `_DepthRimWidth` |
| **림 강도** | 2D 림의 밝기 배수입니다. 0이면 림 계산을 건너뛰므로 색과 폭을 바꿔도 아무것도 보이지 않습니다. | `_DepthRimIntensity` |
| **베이스 색 혼합** | 0이면 지정한 림 색이 단색으로 나오고, 1이면 베이스 맵 색을 곱해 부위마다 다른 림 색이 됩니다. | `_DepthRimBaseColorMix` |
| **360도 림** | 0이면 광원 방향 쪽에만 림이 생기고, 1이면 실루엣 전체를 감쌉니다. 조명이 없거나 방향이 자주 바뀌는 환경에서는 올려 두면 안정적입니다. | `_DepthRim360` |
| **림 샘플 품질** | 2D 림이 픽셀당 읽는 깊이 샘플 수를 고릅니다. 표준(2탭)이 기본이고, 낮음(1탭)은 내부선 억제가 사라져 눈·코·입 선이나 옷 경계가 림으로 새어 나오며 카메라가 움직일 때 림 안쪽 경계가 텍셀 단위로 흔들립니다. 높음(4탭)은 같은 검사 범위를 더 촘촘히 훑어 좁은 내부선까지 걸러 내는 대신 깊이 샘플을 두 개 더 씁니다. 어느 티어에서도 림 폭은 달라지지 않습니다. | `_DepthRimSampleQuality` |
| **실루엣 시작점** | 표면이 카메라에서 얼마나 꺾여야 실루엣으로 볼지 정합니다. 이 값과 아래의 전환 부드러움은 같은 그룹의 외곽 실루엣 제한이 0이면 전혀 반영되지 않습니다. | `_DepthRimSilhouetteThreshold` |
| **실루엣 전환 부드러움** | 실루엣 판정의 전환 폭입니다. 같은 그룹의 외곽 실루엣 제한이 0이면 반영되지 않습니다. | `_DepthRimSilhouetteSoftness` |
| **블렌드 불투명도** | 림 색이 결과에 섞이는 비율입니다. 림이 과하면 세기보다 먼저 이 값을 낮춰 보세요. 0이면 림이 보이지 않습니다. | `_DepthRimColorBlendOpacity` |

## 2D 그림자

앞 물체의 화면 깊이 실루엣을 이용한 가벼운 캐릭터 그림자를 설정합니다.

| 항목 | 설명 | 셰이더 프로퍼티 |
|---|---|---|
| **2D 그림자** | 깊이 차이로 만드는 2D 그림자를 켜고 끕니다. 머리카락이 얼굴에 지는 앞머리 그림자가 대표적인 용도입니다. 카메라 깊이 텍스처가 필요합니다. | `_DepthShadowEnabled` |
| **2D 그림자 마스크** | 2D 그림자를 특정 부위로 제한하는 마스크를 켭니다. 원치 않는 곳에 지는 2D 그림자를 지울 때 씁니다. | `_DepthShadowMaskEnabled` |
| **채널** | 2D 그림자 마스크에서 읽을 채널입니다. 여러 마스크를 한 장에 패킹했을 때 채널을 나눠 씁니다. | `_DepthShadowMaskChannel` |
| **반전** | 2D 그림자 마스크의 흑백을 뒤집어 적용 부위를 반대로 만듭니다. | `_DepthShadowMaskInvert` |
| **2D 그림자 색** | 2D 그림자의 색입니다. 머리카락이 얼굴에 드리우는 깊이 기반 그림자가 이 색으로 칠해집니다. 다른 그림자 색과 톤을 맞추세요. | `_DepthShadowColor` |
| **블렌드 불투명도** | 2D 그림자 색이 결과에 섞이는 비율입니다. 통합 그림자 모드에서는 겹침 심도로 쓰입니다 — 0이면 형태 그림자와 완전히 한 색이 되고, 올릴수록 2D 그림자가 그 안에서 더 진하게 남습니다. | `_DepthShadowColorBlendOpacity` |
| **그림자 밝기** | 2D 그림자 색의 밝기 배수입니다. 낮출수록 어두워집니다. 2D 그림자와 캐스트 그림자를 통합해 두면 이 값이 통합된 층의 밝기로 쓰입니다. | `_DepthShadowBrightness` |
| **얼굴 2D 그림자 어시스트** | 기본값은 꺼짐입니다. 얼굴 영역을 지정한 뒤 켜면 그 영역에서 MingToon 카메라 깊이 기반 투영 그림자의 자기 겹침을 억제합니다. 깊이 림·내부 경계처럼 같은 카메라 깊이를 쓰는 효과도 달라질 수 있습니다. | `_DepthShadowFaceAssistEnabled` |
| **영향도** | 마스크가 2D 그림자를 깎는 정도입니다. 1이면 마스크의 검은 곳에서 그림자가 완전히 사라지고, 낮추면 부분적으로 남습니다. | `_DepthShadowMaskStrength` |

## SSAO (화면 공간 차폐)

카메라 깊이 텍스처를 픽셀마다 다시 읽어 접히는 곳과 맞닿는 자리를 어둡게 합니다. 오클루전 맵과 곱해지는 것이 아니라, 툰 밴드와 스크린톤을 통과한 뒤 더 어두운 쪽을 택하는 방식으로 합류합니다. 깊이 텍스처가 없는 환경에서는 조용히 사라집니다.

| 항목 | 설명 | 셰이더 프로퍼티 |
|---|---|---|
| **SSAO 사용** | 카메라 깊이 텍스처를 픽셀마다 다시 읽어 접히는 곳과 맞닿는 자리를 어둡게 합니다. 결과는 오클루전 맵과 같은 자리에 합쳐지므로 그림자의 일부로 읽히고, 끄면 계산이 컴파일에서 빠져 비용이 0입니다. | `_MingSsaoEnabled` |
| **SSAO 강도** | 효과의 세기입니다. 0이면 끈 것과 같은 그림이 나오지만 계산은 그대로 돌므로, 쓰지 않을 때는 SSAO 사용을 끄세요. | `_MingSsaoIntensity` |
| **SSAO 대비** | 차폐의 대비입니다. 올리면 진하게 파인 곳만 남고 옅은 차폐가 지워집니다. | `_MingSsaoPower` |
| **SSAO 반경** | 차폐를 찾는 반경이며 단위는 미터입니다(0.001~0.25 = 1mm~25cm). 화면 픽셀이 아니라 월드 크기 기준이라 카메라가 멀어지거나 화각이 바뀌어도 두께가 유지됩니다 — 단 이 성질은 `SSAO 거리 보정`이 1일 때(기본값) 성립하며, 내리면 1미터 안쪽에서 반경이 줄어듭니다. 카메라를 아주 가까이 붙이면 화면상 크기에 내부 상한이 걸려 그 이상 커지지 않습니다(프레임타임 보호용이며 조절 항목이 아닙니다). `SSAO 페이드 범위`는 이 값의 배수로 동작하므로 반경을 바꾸면 도달 거리도 같은 비율로 따라옵니다. | `_MingSsaoRadius` |
| **SSAO 품질** | 픽셀당 깊이 샘플 수입니다. Low 4 · Medium 8 · High 12 · Ultra 16이며, 이 비용은 재질당 한 번이 아니라 화면에 보이는 프래그먼트마다 냅니다. 캐릭터 크기에서는 품질을 낮추고 반경을 키우는 쪽이 대체로 더 나은 그림을 냅니다. | `_MingSsaoQuality` |
| **SSAO 바이어스** | 깊이 버퍼의 반올림 오차가 차폐로 새는 것을 막는 여유값입니다. 카메라에서 멀어질수록 자동으로 함께 커지므로, 거리와 무관하게 한 번만 맞추면 됩니다. 평평한 면에 얼룩이 남으면 조금 올리고, 얕은 주름이 지워지면 내립니다. 기울어진 면의 자기 차폐는 이제 계산 자체가 없애므로 예전보다 훨씬 작은 값이면 충분합니다. | `_MingSsaoBias` |
| **SSAO 페이드 범위** | 앞을 가로막은 것이 얼마나 가까워야 차폐로 인정할지를 `SSAO 반경`의 배수로 지정합니다. 1이면 반경 한 칸, 2면 두 칸까지 인정하고 그 너머는 가중치가 0으로 떨어지므로, 멀리 있는 벽이 실루엣 전체를 어둡게 칠하지 않습니다. 미터가 아니라 배수라서 반경을 바꿔도 비율이 그대로 따라갑니다. | `_MingSsaoFadeRange` |
| **SSAO 소멸 거리** | 효과가 완전히 사라지는 거리(미터)입니다. 페이드는 이 값의 75% 지점에서 시작하므로 12로 두면 9m부터 옅어져 12m에서 0이 됩니다. 같은 구간에서 픽셀당 샘플 수도 함께 줄어들어 이 거리 밖의 캐릭터는 계산 비용이 0이 되므로, 군중 씬에서는 이 값을 줄이는 것이 가장 확실한 최적화입니다. 0이면 거리 페이드를 쓰지 않습니다(비용 절감도 없습니다). | `_MingSsaoFarDistance` |
| **SSAO 거리 보정** | 1이면 반경이 실제 월드 크기로 고정되어, 카메라가 다가가거나 화각이 바뀌어도 같은 자리에 같은 모양의 음영이 들어갑니다. 0이면 1미터 안쪽에서 반경이 줄어드는 예전 근접 보정으로 돌아갑니다. | `_MingSsaoDistanceCompensation` |
| **SSAO 빛 방향 반응** | 0이면 빛과 무관한 균일한 차폐입니다. 올리면 탐색 범위가 빛 쪽으로 기울어, 빛이 닿지 않는 반대편에 차폐가 모입니다. 빛이 카메라 정면에서 올수록 기울기가 저절로 줄어들어, 정면광에서 음영이 한쪽으로 쏠리지 않습니다. | `_MingSsaoLightDirectionInfluence` |
| **SSAO 마스크 세기** | 2D 그림자 마스크를 그대로 빌려 SSAO가 들어갈 범위를 제한합니다. 0이면 마스크를 쓰지 않고, 올릴수록 마스크가 가린 곳에서 차폐가 빠집니다. 채널·반전·HSVG는 2D 그림자 마스크에 설정한 값을 함께 씁니다. | `_MingSsaoMaskStrength` |
| **SSAO 틴트** | 차폐가 들어간 자리에만 곱해지는 색입니다. 흰색이면 아무 색도 입히지 않고, 기존 그림자 색을 그대로 둡니다. | `_MingSsaoColor` |
| **SSAO 명도** | 차폐 부분을 얼마나 더 어둡게 할지입니다. 1이면 추가로 어둡게 하지 않고, 내릴수록 그 자리만 짙어집니다. | `_MingSsaoBrightness` |
| **SSAO 순도** | 차폐 부분의 채도입니다. 1이면 그대로, 0이면 회색으로 빠지고, 1을 넘기면 그 자리만 색이 진해집니다. | `_MingSsaoSaturation` |
| **캐스트 섀도우 안 표시량** | 0 = 투영 그림자 안에서 SSAO를 숨김, 1 = 그대로 표시(기본값). 그림자가 이미 진 자리에 차폐가 겹쳐 더 어두워지는 것을 막을 때 내립니다. | `_MingSsaoCastShadowVisibility` |
| **2D 섀도우 안 표시량** | 0 = 2D 그림자 안에서 SSAO를 숨김, 1 = 그대로 표시(기본값). 그려 넣은 2D 그림자 위에 차폐가 겹쳐 보일 때 내립니다. | `_MingSsao2DShadowVisibility` |

## 2D 투과광

빛이 캐릭터를 얼마나 통과했는지 광원 방향으로 재어, 얇은 부위가 빛을 머금은 것처럼 보이게 합니다.

| 항목 | 설명 | 셰이더 프로퍼티 |
|---|---|---|
| **투과광 사용** | 머리끝이나 옷자락처럼 얇은 부분이 빛을 머금은 것처럼 보이게 합니다. 광원 방향으로 깊이를 두 번 읽어 빛이 캐릭터를 얼마나 통과했는지 직접 재므로, 2D 깊이 림과 무관하게 단독으로 동작합니다. | `_TranslucencyEnabled` |
| **측정 폭** | 빛이 지나온 거리를 재기 위해 광원 방향으로 얼마나 멀리 살펴볼지 정합니다. 크게 잡으면 굵은 부위까지 얇다고 판정되고, 작게 잡으면 아주 얇은 끝부분만 빛납니다. | `_TranslucencyWidth` |
| **깊이 범위** | 이만큼(미터) 뒤가 비어 있으면 완전히 뚫린 것으로 봅니다. 머리카락 뒤에 있는 옷처럼 조금만 뒤에 있는 표면이 배경으로 오인되어 밝아지면 이 값을 올리세요. | `_TranslucencyDepthRange` |
| **껍데기 최소 두께** | 치마나 망토처럼 속이 빈 옷은 화면에서 폭이 넓어 두껍다고 측정되지만 실제 천은 아주 얇습니다. 그런 재질에 0.8 정도를 주면 측정과 무관하게 항상 얇게 취급합니다. 피부나 손처럼 속이 찬 부위는 0으로 두고 측정에 맡기세요. | `_TranslucencyShellFloor` |
| **투과 강도** | 투과광 전체의 밝기 배수입니다. 0이면 계산을 건너뜁니다. | `_TranslucencyStrength` |
| **가장자리 세기** | 실루엣 바깥쪽만 밝히는 층의 세기입니다. 0으로 두면 안쪽 층만 있는 단일 층과 완전히 같아집니다. | `_TranslucencyEdgeIntensity` |
| **가장자리 감쇠** | 가장자리 층이 실루엣에서 얼마나 좁게 모이는지 정합니다. 값이 클수록 가장자리에 얇게 붙습니다. | `_TranslucencyEdgePower` |
| **가장자리 굵기** | 실루엣 가장자리를 따라 도는 투과광 띠의 폭입니다. 가장자리 글로우가 안쪽까지 너무 넓게 번지면 낮추세요. | `_TranslucencyEdgeWidth` |
| **가장자리 부드러움** | 가장자리 띠가 사라지는 경계의 완만함입니다. 올리면 부드럽게 번지고, 내리면 선명한 띠가 됩니다. | `_TranslucencyEdgeSoftness` |
| **가장자리 색 보정** | 가장자리 층의 색을 베이스 색에서 만들어 냅니다. 절대 색이 아니라 베이스에서 파생되므로, 금발은 노랗게 검은 머리는 어둡게 캐릭터 전체가 한 설정으로 맞습니다. 중립값(0,1,1,1)이면 보정을 건너뜁니다. | `_TranslucencyEdgeHSVG` |
| **가장자리 틴트** | 색 보정을 마친 가장자리 색에 마지막으로 곱하는 색입니다. 흰색이면 아무것도 바꾸지 않습니다. | `_TranslucencyEdgeTint` |
| **안쪽 세기** | 실루엣 안쪽을 밝히는 층의 세기입니다. 0으로 두면 가장자리 층만 있는 단일 층과 완전히 같아집니다. | `_TranslucencyCenterIntensity` |
| **안쪽 감쇠** | 안쪽 층이 정면을 향한 면에 얼마나 좁게 모이는지 정합니다. | `_TranslucencyCenterPower` |
| **안쪽 굵기** | 정면을 향한 안쪽 투과광 띠의 폭입니다. 귀나 손끝처럼 얇은 부위의 중앙이 비쳐 보이는 범위를 조절합니다. | `_TranslucencyCenterWidth` |
| **안쪽 부드러움** | 안쪽 띠가 사라지는 경계의 완만함입니다. 올리면 부드럽게 번지고, 내리면 선명해집니다. | `_TranslucencyCenterSoftness` |
| **안쪽 색 보정** | 안쪽 층의 색을 베이스 색에서 만들어 냅니다. 기본값은 색조를 붉은 쪽으로 돌리고 채도를 올려, 가장자리는 흰빛에 가깝고 안쪽은 따뜻하게 빛나는 머리카락 느낌을 만듭니다. | `_TranslucencyCenterHSVG` |
| **안쪽 틴트** | 색 보정을 마친 안쪽 색에 마지막으로 곱하는 색입니다. 흰색이면 아무것도 바꾸지 않습니다. | `_TranslucencyCenterTint` |
| **역광 감쇠** | 카메라와 광원이 얼마나 정확히 마주봐야 빛이 가장 강해지는지 정합니다. 값이 클수록 정확한 역광에서만 좁게 강해지며, 정면광에서 남는 양은 정면광 바닥값이 정합니다. | `_TranslucencyLightPower` |
| **정면광 바닥값** | 정면에서 빛을 받을 때 남는 투과광의 비율입니다. 산란은 역광에서 강해질 뿐 정면광에서 사라지지 않으므로, 0으로 두면 피부가 피부처럼 보이지 않습니다. | `_TranslucencyAmbient` |
| **노멀 방향 휨** | 빛 방향을 표면 노멀 쪽으로 휘게 해, 정확한 역광이 아니어도 곡면을 따라 빛이 새어 나오게 합니다. 0이면 순수한 역광 반응만 남습니다. | `_TranslucencyDistortion` |
| **시선 방향 휨** | 빛 방향을 카메라 쪽으로 휘게 합니다. 머리카락 카드처럼 노멀을 믿을 수 없는 평면에서 노멀 방향 휨만으로는 빛이 켜졌다 꺼졌다 하는데, 이 값이 그것을 막습니다. | `_TranslucencyViewBend` |
| **노멀맵 영향** | 투과광의 모양에 노멀맵을 반영하는 정도입니다. 0이면 메시 노멀만 사용합니다. 강한 노멀맵이 투과광을 표면 노이즈처럼 쪼개면 낮추세요. | `_TranslucencyNormalInfluence` |
| **씬 조명 영향** | 0이면 씬의 조명 색을 무시하고 지정한 색만 쓰고, 1이면 조명 색을 그대로 받습니다. 월드마다 조명이 크게 다르므로 양쪽 다 필요합니다. | `_TranslucencySceneLightInfluence` |
| **노출 부드러움** | 깊이 범위로 정규화한 값의 시작과 끝 무릎을 부드럽게 만듭니다. 0이면 정확히 직선 램프이고, 이 값은 응답 곡선만 바꿀 뿐 경계 위치는 옮기지 않습니다. | `_TranslucencySoftness` |
| **밀도** | 얇음이 밝기로 바뀌는 감쇠 정도입니다. 값이 클수록 아주 얇은 곳에만 빛이 남아 밀도가 높은 재질처럼 보이고, 낮추면 넓게 퍼집니다. | `_TranslucencyDensity` |
| **색 분리** | 빨강이 파랑보다 더 깊이 스며드는 산란 특성을 재현합니다. 채널마다 감쇠 자체가 달라져 빛이 닿는 범위의 크기가 달라지므로, 틴트로는 만들 수 없는 피부·머리카락 특유의 번짐이 생깁니다. 0이면 세 채널이 완전히 같습니다. | `_TranslucencyChannelSpread` |

## 이너 아웃라인

화면 깊이로 표면 안쪽에 그리는 2D 경계를 설정합니다.

| 항목 | 설명 | 셰이더 프로퍼티 |
|---|---|---|
| **Inner 2D Edge 사용** | 화면 깊이 차이로 표면 안쪽 경계선을 그립니다. 추가 지오메트리가 없어 Hull이 깨지는 메시에도 쓸 수 있지만, 카메라 깊이 텍스처가 필요하고 표면 모드가 Transparent면 동작하지 않습니다. | `_OutlineInnerEdgeEnabled` |
| **압력 소스** | 선 굵기를 조절할 페인팅 채널을 고릅니다. VertexRed는 버텍스 컬러 R, VertexAlpha는 A, WidthMask는 폭 마스크 텍스처를 씁니다. 버텍스 컬러가 검게 임포트된 메시에서 VertexRed를 고르면 선이 통째로 사라집니다. | `_OutlineHullPressureSource` |
| **내부 경계 마스크** | 내부 경계를 특정 부위로 제한하는 마스크를 켭니다. 얼굴 등에서 원치 않는 선이 생기는 부위를 지울 때 씁니다. | `_OutlineInnerEdgeMaskEnabled` |
| **채널** | 내부 경계 마스크에서 읽을 채널입니다. 여러 마스크를 한 장에 패킹했을 때 채널을 나눠 씁니다. | `_OutlineInnerEdgeMaskChannel` |
| **반전** | 내부 경계 마스크의 흑백을 뒤집어 적용 부위를 반대로 만듭니다. | `_OutlineInnerEdgeMaskInvert` |
| **영향도** | 마스크가 내부 경계선을 깎는 정도입니다. 1이면 마스크의 검은 곳에서 선이 완전히 사라지고, 낮추면 부분적으로 남습니다. | `_OutlineInnerEdgeMaskStrength` |
| **내부 경계 색** | 내부 2D 경계선의 색입니다. 옷깃·턱·주름처럼 실루엣 안쪽의 깊이 단차에 그려지는 선이 이 색이 됩니다. | `_OutlineInnerEdgeColor` |
| **폭** | 내부 2D 경계선의 굵기입니다. 노멀 아웃라인보다 가늘게 두는 것이 일반적입니다. | `_OutlineInnerEdgeWidth` |
| **이너 아웃라인에 적용** | 페인팅한 압력을 Inner 2D Edge 굵기에도 반영합니다. 이 토글과 압력 소스는 Classic Hull 그룹 안에 있지만, 이 값은 Hull을 꺼도 Inner Edge에 계속 작용합니다. 버텍스 컬러가 검은 메시에서 켜져 있으면 Inner Edge가 통째로 사라집니다. | `_OutlineInnerEdgePressureApply` |
| **깊이 바이어스** | 이 값보다 큰 깊이 차이만 경계로 인정합니다. 낮추면 완만한 굴곡에도 선이 붙어 노이즈가 되고, 올리면 얇은 부위의 선이 사라집니다. | `_OutlineInnerEdgeBias` |
| **부드러움** | 안쪽 경계선의 공간 그라데이션 폭입니다. 0은 단단한 선, 1은 선 폭 전체가 경계에서 안쪽 끝까지 완전히 흐려집니다. | `_OutlineInnerEdgeSoftness` |
| **블렌드 불투명도** | 내부 경계 색이 섞이는 비율입니다. 0이면 내부 경계선이 보이지 않습니다. | `_OutlineInnerEdgeColorBlendOpacity` |
