# 깊이 기반 효과

카메라 깊이 텍스처를 읽어 화면 공간에서 그리는 항목입니다. 깊이가 없으면 통째로 보이지 않습니다.

이 페이지는 값을 찾는 표입니다. 켜는 순서가 필요하면 [깊이 기반 효과 가이드](/guides/depth-effects)를 보세요.

제목과 차례는 인스펙터의 섹션 이름과 표시 순서를 그대로 따릅니다.

맵과 마스크 슬롯 안의 항목은 모든 슬롯이 같습니다.
채널·리맵·페더·마스크 UV는 [텍스처 슬롯 공통 UI](/guides/texture-modules)에 한 번만 적었습니다.

| **깊이 가용성** | 선택 | Auto / Force On / Force Off / Diagnostic | Auto | 깊이 텍스처가 있는지 판정하는 방식입니다 |
