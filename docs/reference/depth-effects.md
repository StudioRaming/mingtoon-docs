# 깊이 기반 효과

카메라 깊이 텍스처를 읽어 화면 공간에서 그리는 효과입니다. 깊이가 없는 환경에서는 통째로 보이지 않으므로, 값을 만지기 전에 깊이부터 확인하세요. 내부 2D 경계도 이 그룹에 들어 있습니다.

:::note
이 페이지의 항목 이름과 설명은 MingToon 인스펙터가 실제로 표시하는 문구를 소스에서 그대로 가져온 것입니다.
:::

## 깊이 효과 마스터

깊이 기반 효과에 사용할 범위와 마스크를 설정합니다.

| 항목 | 설명 | 셰이더 프로퍼티 |
|---|---|---|
| **깊이 효과** | 2D 림라이트·깊이 투과광·2D 그림자 등 깊이 효과 전체의 마스터 스위치입니다. 끄면 세 모듈이 모두 꺼집니다. 이 효과들은 카메라 깊이 텍스처가 있어야 동작합니다. | `_DepthEffectsEnabled` |
| **마스터 폭** | 2D 림라이트와 2D 그림자의 화면 오프셋에 공통으로 곱해지는 배수입니다. 여기서 0으로 두면 각 모듈의 폭을 아무리 올려도 아무것도 나오지 않습니다. | `_DepthWidth` |
| **폭 모드** | Screen Pixels는 화면 픽셀 기준이라 멀어질수록 선이 상대적으로 두꺼워지고, Distance Stable은 거리와 FOV가 변해도 두께가 일정하게 보입니다. Screen Pixels를 고르면 거리 스케일이 동작하지 않습니다. | `_DepthWidthMode` |
| **거리 스케일** | 폭 모드가 Distance Stable일 때 두께의 기준 거리를 정합니다. 폭 모드가 Screen Pixels면 반영되지 않습니다. | `_DepthDistanceScale` |
| **마스터 바이어스** | 화면 깊이 차이가 이 값을 넘어야 앞뒤 경계로 인정합니다. 낮추면 얕은 굴곡에도 선이 붙어 지저분해지고, 올리면 얇은 부위의 선이 사라집니다. | `_DepthBias` |
| **마스터 부드러움** | 깊이 경계 판정의 전환 폭입니다. 낮으면 딱딱한 잉크 선, 높으면 부드럽게 번진 경계가 됩니다. | `_DepthSoftness` |
| **FX 애니메이터로 깊이 효과 전환** | 깊이 효과 마스터를 애니메이터(VRChat FX 등)로 켜고 끌 수 있게 합니다. 깊이 텍스처가 없는 월드에서 평소에는 꺼 두고, 카메라를 들 때만 켜는 용도입니다. 이 옵션을 끄면 베이크가 마스터를 상수로 접어 애니메이션이 아무 반응도 하지 않습니다. | `_MingDepthEffectsRuntimeToggle` |

## 런타임 전환

| 항목 | 설명 | 셰이더 프로퍼티 |
|---|---|---|
| **VRC 런타임 제어 사용** | VRChat EX 메뉴의 가상 라이트·팔레트·마스터 조정·사진 룩·품질 제어가 이 재질에 적용되도록 합니다. 그림자 투영은 별도 FX 스위치도 필요합니다. 끄면 베이크가 관련 값을 상수로 접어 메뉴 조작이 이 재질에 적용되지 않습니다. | `_MingVrcQualityMenuEnabled` |
| **FX 메뉴로 그림자 투영 전환** | 「그림자 투영」을 VRChat EX 메뉴에서 켜고 끌 수 있게 합니다. 그림자를 켠 채로 업로드하고, 사람이 많은 인스턴스에서 메뉴로 끄는 용도입니다. 런타임에 끄면 투영 그림자의 페더 샘플, 캐스트 합성, 투과광 캐스트 계산이 픽셀마다 건너뛰어집니다. 이 옵션을 끄면 베이크가 「그림자 투영」을 상수로 접어 메뉴가 아무 반응도 하지 않습니다. | `_MingCastShadowRuntimeToggle` |
| **품질 티어 미리보기** | 인게임 메뉴가 이 값을 바꿉니다. 여기서 직접 바꾸면 Low/Mid가 어떻게 보이는지 에디터에서 미리 확인할 수 있습니다. 저장할 때는 High로 되돌려 두세요 — 이 값이 재질의 기본 상태가 됩니다. | `_MingVrcQualityTier` |

## 2D 림라이트

화면 깊이 차이로 생성되는 림 효과를 설정합니다.

| 항목 | 설명 | 셰이더 프로퍼티 |
|---|---|---|
| **2D 림라이트** | 실루엣의 깊이 차이로 그리는 2D 림라이트를 켜고 끕니다. 노멀 기반 프레넬 림과 달리 외곽에 균일한 굵기의 선이 생깁니다. 카메라 깊이 텍스처가 필요합니다. | `_DepthRimEnabled` |
| **가장자리 림 최저 배율** | 조명을 따라가는 림, 즉 백라이트·프레넬 림·2D 림라이트가 어두운 곳에서도 유지하는 최소 조명 배율입니다. 위의 최고 배율이 상한이라면 이 값은 그 짝이 되는 하한입니다. 0이면 지금까지와 완전히 같고, 올리면 어두운 라이트 볼륨 안에서도 실루엣이 완전히 사라지지 않습니다. | `_EdgeRimLightResponseFloor` |
| **2D 림라이트 마스크** | 2D 림을 특정 부위로 제한하는 마스크를 켭니다. 금속 장식에만 림을 남기는 식의 부위 한정에 씁니다. | `_DepthRimMaskEnabled` |
| **채널** | 림 마스크에서 읽을 채널입니다. 여러 마스크를 한 장에 패킹했을 때 채널을 나눠 씁니다. | `_DepthRimMaskChannel` |
| **반전** | 림 마스크의 흑백을 뒤집어 적용 부위를 반대로 만듭니다. | `_DepthRimMaskInvert` |
| **영향도** | 마스크가 림을 깎는 정도입니다. 1이면 마스크의 검은 곳에서 림이 완전히 사라지고, 낮추면 부분적으로 남습니다. | `_DepthRimMaskStrength` |
| **림 색상** | 2D 림의 색입니다. HDR 색이므로 강도를 올려 블룸과 함께 빛나게 할 수도 있습니다. | `_DepthRimColor` |
| **색 순도** | 베이스 색과 2D 림 틴트가 합쳐진 뒤의 색 순도입니다. 범위 0~10, 기본값 1입니다. 0은 무채색, 1은 기존 합성색, 1을 넘으면 과채도입니다. | `_DepthRimColorPurity` |
| **씬 조명 영향** | 2D 림이 씬 조명을 얼마나 따라갈지 정합니다. 1이면 백라이트와 같은 방식으로 씬 조명 응답을 받아, 어두운 라이트 볼륨 안에서는 림도 함께 어두워집니다. 0이면 조명의 색만 받고 밝기는 작성한 값 그대로 남아, 몸이 어두워져도 림만 밝게 떠오릅니다. | `_DepthRimSceneLightInfluence` |
| **림 폭 배수** | 마스터 폭에 곱해지는 2D 림 전용 배수입니다. 최종 두께는 마스터 폭 × 이 값이므로, 마스터 폭이 0이면 여기를 올려도 소용이 없습니다. | `_DepthRimWidth` |
| **림 강도** | 2D 림의 밝기 배수입니다. 0이면 림 계산을 건너뛰므로 색과 폭을 바꿔도 아무것도 보이지 않습니다. | `_DepthRimIntensity` |
| **프레넬 적용** | 2D 림으로 찾은 영역에 프레넬 영역을 곱해 안쪽 경계를 점차 풀어 줍니다. 끄면 기존 2D 림 모양을 그대로 사용합니다. | `_DepthRimFresnelEnabled` |
| **폭** | 범위 0-1, 기본값 1입니다. 0이면 프레넬 영역이 없고 1이면 전체 영역을 사용합니다. 부드러움을 바꿔도 이 폭 바깥으로 퍼지지 않습니다. | `_DepthRimFresnelWidth` |
| **부드러움** | 범위 0-1, 기본값 1입니다. 0은 딱딱한 경계, 1은 선택한 폭 안을 모두 쓰는 부드러운 그라데이션입니다. 폭은 변하지 않습니다. | `_DepthRimFresnelSoftness` |
| **영역 반전** | 선택한 폭을 유지한 채 프레넬 영역을 반대쪽으로 옮깁니다. 가장자리 쪽 영역은 안쪽·가운데 방향으로 바뀝니다. | `_DepthRimFresnelAreaInvert` |
| **베이스 색 혼합** | 0이면 지정한 림 색이 단색으로 나오고, 1이면 베이스 맵 색을 곱해 부위마다 다른 림 색이 됩니다. | `_DepthRimBaseColorMix` |
| **360도 림** | 0이면 광원 방향 쪽에만 림이 생기고, 1이면 실루엣 전체를 감쌉니다. 조명이 없거나 방향이 자주 바뀌는 환경에서는 올려 두면 안정적입니다. | `_DepthRim360` |
| **림 샘플 품질** | 2D 림이 픽셀당 읽는 깊이 샘플 수를 고릅니다. 표준(2탭)이 기본이고, 낮음(1탭)은 내부선 억제가 사라져 눈·코·입 선이나 옷 경계가 림으로 새어 나오며 카메라가 움직일 때 림 안쪽 경계가 텍셀 단위로 흔들립니다. 높음(4탭)은 같은 검사 범위를 더 촘촘히 훑어 좁은 내부선까지 걸러 내는 대신 깊이 샘플을 두 개 더 씁니다. 어느 티어에서도 림 폭은 달라지지 않습니다. | `_DepthRimSampleQuality` |
| **실루엣 시작점** | 표면이 카메라에서 얼마나 꺾여야 실루엣으로 볼지 정합니다. 이 값과 아래의 전환 부드러움은 같은 그룹의 외곽 실루엣 제한이 0이면 전혀 반영되지 않습니다. | `_DepthRimSilhouetteThreshold` |
| **실루엣 전환 부드러움** | 실루엣 판정의 전환 폭입니다. 같은 그룹의 외곽 실루엣 제한이 0이면 반영되지 않습니다. | `_DepthRimSilhouetteSoftness` |
| **블렌드 불투명도** | 림 색이 결과에 섞이는 비율입니다. 림이 과하면 세기보다 먼저 이 값을 낮춰 보세요. 0이면 림이 보이지 않습니다. | `_DepthRimColorBlendOpacity` |

## 2D 그림자

앞 물체의 화면 깊이 실루엣을 조명 반대 방향으로 밀어 그리는 가벼운 캐릭터 그림자입니다. 깊이 늘림을 켜면 수신면에서 떠 있는 물체일수록 그림자가 더 길어지고, 깊이 옅어짐을 켜면 그만큼 점진적으로 옅어져 뒤에 있는 것처럼 보입니다. 샘플 수·소멸 거리는 Depth Common 탭의 공용 설정을 따릅니다.

| 항목 | 설명 | 셰이더 프로퍼티 |
|---|---|---|
| **2D 그림자** | 깊이 차이로 만드는 2D 그림자를 켜고 끕니다. 머리카락이 얼굴에 지는 앞머리 그림자가 대표적인 용도입니다. 카메라 깊이 텍스처가 필요합니다. 2D 그림자는 멀리 있는 차폐물도 투영 그림자처럼 떨어뜨리는 단단한 한 장이 정체성이고, 접촉부의 부드러운 음영은 SSAO가 담당합니다 — 겹쳐 쓰면 SSAO가 접촉부를 덧그립니다. | `_DepthShadowEnabled` |
| **MingToon 2D 투영 그림자 드리우기** | 이 재질을 MingToon 카메라 깊이 필드에 포함할지 정합니다. 안경·액세서리에서 끄면 Opaque·Cutout·Transparent 모두 2D 투영 그림자 캐스터에서 빠집니다. 일반 색상 렌더링, 투명 재질의 깊이 프리패스, Unity 실시간 ShadowCaster 그림자는 그대로 유지되므로 자체 정렬과 아웃라인은 켰을 때와 같습니다. 끈 재질은 자기 자신이 깊이에 없으므로 그 재질의 2D 림라이트·Inner 2D Edge·2D 그림자·깊이 투과광은 자기 뒤를 보지 못합니다. 안경 자체에 림이 필요하면 깊이를 쓰지 않는 Fresnel Rim을 쓰세요. | `_2DShadowCasterEnabled` |
| **2D 그림자 마스크** | 2D 그림자를 특정 부위로 제한하는 마스크를 켭니다. 원치 않는 곳에 지는 2D 그림자를 지울 때 씁니다. | `_DepthShadowMaskEnabled` |
| **채널** | 2D 그림자 마스크에서 읽을 채널입니다. 여러 마스크를 한 장에 패킹했을 때 채널을 나눠 씁니다. | `_DepthShadowMaskChannel` |
| **반전** | 2D 그림자 마스크의 흑백을 뒤집어 적용 부위를 반대로 만듭니다. | `_DepthShadowMaskInvert` |
| **2D 그림자 색** | 2D 그림자의 색입니다. 머리카락이 얼굴에 드리우는 깊이 기반 그림자가 이 색으로 칠해집니다. 다른 그림자 색과 톤을 맞추세요. | `_DepthShadowColor` |
| **화면 공간 그림자 겹침 심도** | 2D 그림자와 SSAO가 다른 그림자와 겹친 부분만 추가로 진하게 하는 양입니다. 0이면 기존 그림자 안에서 같은 통합 그림자색으로 합쳐지고, 올릴수록 겹친 부분이 곱해져 형태가 남습니다. | `_DepthShadowColorBlendOpacity` |
| **그림자 밝기** | 2D 그림자 색의 밝기 배수입니다. 낮출수록 어두워집니다. 2D 그림자와 캐스트 그림자를 통합해 두면 이 값이 통합된 층의 밝기로 쓰입니다. | `_DepthShadowBrightness` |
| **깊이 가용성** | 깊이 텍스처가 있는지 판정하는 방식입니다. 기본 Auto를 유지하세요. Force On은 자동 판정이 못 보는 호스트에서 작성자가 깊이 버퍼를 보증할 때만, Force Off는 깊이 효과를 완전히 차단할 때, Diagnostic은 판정 상태를 화면에 표시합니다. | `_DepthAvailabilityMode` |
| **공용 품질** | 2D 그림자 꼬리와 SSAO가 함께 쓰는 깊이 샘플 단계입니다. Low 4, Standard 8, High 16. 두 효과는 각자 이 수만큼 읽습니다. | `_ScreenSpaceShadowQuality` |
| **공용 소멸 거리** | 2D 그림자와 SSAO가 함께 사라지는 카메라 거리입니다. 마지막 25% 구간에서 부드럽게 사라지며 0은 거리 제한 없음입니다. | `_ScreenSpaceShadowFadeDistance` |
| **얼굴 2D 그림자 어시스트** | 기본값은 꺼짐입니다. 얼굴 영역을 지정한 뒤 켜면 그 영역에서 MingToon 카메라 깊이 기반 투영 그림자의 자기 겹침을 억제합니다. 2D 림라이트·내부 경계처럼 같은 카메라 깊이를 쓰는 효과도 달라질 수 있습니다. | `_DepthShadowFaceAssistEnabled` |
| **영향도** | 마스크가 2D 그림자를 깎는 정도입니다. 1이면 마스크의 검은 곳에서 그림자가 완전히 사라지고, 낮추면 부분적으로 남습니다. | `_DepthShadowMaskStrength` |
| **깊이 커브** | 깊이 늘림이 거리에 따라 늘어나는 모양입니다. 0이면 떠 있는 거리에 정비례해 밀립니다. 올릴수록 가까이 떠 있는 물체는 거의 밀리지 않고 멀리 떠 있는 물체만 점점 더 멀리 밀려, 붙은 것은 그대로 두고 먼 것만 뒤로 보냅니다. | `_DepthShadowDepthCurve` |
| **블러** | 다 그려진 그림자의 가장자리를 이 반경(m)만큼 사방으로 부드럽게 번지게 합니다. 반경은 이 값(m)만으로 정해집니다. 그림자를 먼저 완성한 뒤 마지막에 적용되어 원래 크기 바깥까지 퍼지며, 픽셀마다 위상이 달라지는 노이즈(중심 1회 + 회전 디스크 4회)로 부드러워집니다. 공용 품질 단계와는 무관합니다. 그림자 경계 색 띠는 이렇게 실루엣이 부드러워진 자리에만 얹히므로, 이 값을 올리면 경계 연출이 함께 넓어집니다. 0이면 추가 깊이 샘플 비용이 없습니다. | `_DepthShadowBlur` |
| **2D 그림자 바이어스** | 앞 물체가 수신면보다 최소 이만큼 앞에 있어야 그림자로 인정합니다. 1이 10cm이고 0.03이 3mm입니다. 0이면 깊이 정밀도 여유만 남습니다. 이 값은 모든 차폐물에서 똑같이 빼기 때문에, 올릴수록 얕게 맞닿는 그림자가 먼저 사라집니다 - 코가 솟은 높이는 이마에 닿은 앞머리와의 간격보다 크므로, 코 얼룩이 지워질 값에서는 그 앞머리 그림자도 이미 지워져 있습니다. 얼굴 자체의 굴곡만 걷어내려면 이 값이 아니라 수신면 밀기를 쓰세요 - 그쪽은 값을 넣은 머티리얼만 뒤로 밀기 때문에, 밀지 않은 머리카락이 만드는 간격은 그대로 남습니다. | `_DepthShadowSelfReject` |

## SSAO (화면 공간 차폐)

카메라 깊이 텍스처를 픽셀마다 다시 읽어 접히는 곳과 맞닿는 자리를 어둡게 합니다. 폼·투영·2D 그림자가 전부 칠해진 다음 그 위에 곱으로 덧그려지는 오버레이라서, 이미 그림자가 진 자리도 맞닿은 곳은 한층 더 깊어집니다. 반경·바이어스가 월드 크기 기준이라 카메라 거리와 화각이 바뀌어도 같은 모양으로 유지됩니다. 샘플 수·소멸 거리는 Depth Common 탭의 공용 설정을, 수신면 밀기(카메라)는 2D 그림자 탭의 값을 함께 씁니다. 깊이 텍스처가 없는 환경에서는 조용히 사라집니다.

| 항목 | 설명 | 셰이더 프로퍼티 |
|---|---|---|
| **SSAO 사용** | 카메라 깊이 텍스처를 방사형으로 읽어 접히는 곳과 맞닿는 자리를 부드럽게 어둡게 합니다. 폼·투영·2D 그림자 위에도 접촉 음영이 유지됩니다. 끄면 계산이 컴파일에서 빠져 비용이 0입니다. | `_SsaoEnabled` |
| **SSAO 강도** | 효과의 세기입니다. 0이면 끈 것과 같은 그림이 나오지만 계산은 그대로 돌므로, 쓰지 않을 때는 SSAO 사용을 끄세요. | `_SsaoIntensity` |
| **SSAO 대비** | 차폐의 대비입니다. 올리면 진하게 파인 곳만 남고 옅은 차폐가 지워집니다. | `_SsaoPower` |
| **SSAO 반경** | 차폐를 찾는 월드 반경입니다(0.001~0.05m). 가장 직접적인 블러 폭이며, 키우면 접촉 음영이 넓고 부드러워집니다. | `_SsaoRadius` |
| **SSAO 바이어스** | 자기면을 차폐로 오인하지 않게 하는 여유값을 SSAO 반경의 비율로 지정합니다(0.4 = 반경의 40%). 반경 비율이라 카메라 거리·반경이 바뀌어도 룩이 그대로입니다. 깊이 텍셀 크기에 맞춘 최소 여유는 자동으로 깔리므로 0에서도 평평한 면이 얼룩지지 않습니다. 얕은 주름이 지워지면 내리고, 곡면에 얼룩이 남으면 올립니다. | `_SsaoBias` |
| **접촉 감쇠** | 앞을 가로막은 것이 얼마나 가까워야 차폐로 인정할지를 `SSAO 반경`의 배수로 지정합니다. 1이면 반경 한 칸, 2면 두 칸까지 인정하고 그 너머는 가중치가 0으로 떨어지므로, 멀리 있는 벽이 실루엣 전체를 어둡게 칠하지 않습니다. 미터가 아니라 배수라서 반경을 바꿔도 비율이 그대로 따라갑니다. | `_SsaoFadeRange` |
| **SSAO 마스크 세기** | 2D 그림자 마스크를 그대로 빌려 SSAO가 들어갈 범위를 제한합니다. 0이면 마스크를 쓰지 않고, 올릴수록 마스크가 가린 곳에서 차폐가 빠집니다. 채널·반전·HSVG는 2D 그림자 마스크에 설정한 값을 함께 씁니다. | `_SsaoMaskStrength` |
| **SSAO 틴트** | 차폐가 들어간 자리에만 곱해지는 색입니다. 흰색이면 아무 색도 입히지 않고, 기존 그림자 색을 그대로 둡니다. | `_SsaoColor` |
| **색 순도** | SSAO가 상속한 그림자 색에 틴트를 곱한 뒤의 색 순도입니다. 범위 0~10, 기본값 1입니다. 0은 무채색, 1은 곱해진 색 그대로, 1을 넘으면 과채도입니다. 순도 → 밝기 → 감마 순서로 적용되며 그중 가장 먼저 들어갑니다. | `_SsaoColorPurity` |
| **색상 밝기** | 순도를 적용한 뒤의 SSAO 색 밝기 배수입니다. 범위 0~4, 기본값 1은 기존 룩을 그대로 보존합니다. 감마보다 먼저 적용됩니다. | `_SsaoColorBrightness` |
| **색상 감마** | 순도와 밝기 뒤에 적용하는 SSAO 색의 감마입니다. 밝기 축만 구부리고 색조와 순도는 유지합니다. 범위 0.1~3, 기본값 1은 중립입니다. | `_SsaoColorGamma` |

## 2D 투과광

빛이 캐릭터를 얼마나 통과했는지 광원 방향으로 재어, 얇은 부위가 빛을 머금은 것처럼 보이게 합니다.

| 항목 | 설명 | 셰이더 프로퍼티 |
|---|---|---|
| **투과광 사용** | 머리끝이나 옷자락처럼 얇은 부분이 빛을 머금은 것처럼 보이게 합니다. 광원 방향으로 깊이를 두 번 읽어 빛이 캐릭터를 얼마나 통과했는지 직접 재므로, 2D 림라이트와 무관하게 단독으로 동작합니다. | `_TranslucencyEnabled` |
| **측정 폭** | 빛이 지나온 거리를 재기 위해 광원 방향으로 얼마나 멀리 살펴볼지 정합니다. 크게 잡으면 굵은 부위까지 얇다고 판정되고, 작게 잡으면 아주 얇은 끝부분만 빛납니다. | `_TranslucencyWidth` |
| **깊이 범위** | 이만큼(미터) 뒤가 비어 있으면 완전히 뚫린 것으로 봅니다. 머리카락 뒤에 있는 옷처럼 조금만 뒤에 있는 표면이 배경으로 오인되어 밝아지면 이 값을 올리세요. | `_TranslucencyDepthRange` |

| **내부 경계 마스크** | 내부 경계를 특정 부위로 제한하는 마스크를 켭니다. 얼굴 등에서 원치 않는 선이 생기는 부위를 지울 때 씁니다. | `_OutlineInnerEdgeMaskEnabled` |
| **채널** | 내부 경계 마스크에서 읽을 채널입니다. 여러 마스크를 한 장에 패킹했을 때 채널을 나눠 씁니다. | `_OutlineInnerEdgeMaskChannel` |
| **반전** | 내부 경계 마스크의 흑백을 뒤집어 적용 부위를 반대로 만듭니다. | `_OutlineInnerEdgeMaskInvert` |
| **영향도** | 마스크가 내부 경계선을 깎는 정도입니다. 1이면 마스크의 검은 곳에서 선이 완전히 사라지고, 낮추면 부분적으로 남습니다. | `_OutlineInnerEdgeMaskStrength` |
| **내부 경계 색** | 내부 2D 경계선의 색입니다. 옷깃·턱·주름처럼 실루엣 안쪽의 깊이 단차에 그려지는 선이 이 색이 됩니다. | `_OutlineInnerEdgeColor` |
| **색상 감마** | 이너 아웃라인 색의 밝기 축에 감마를 적용합니다. 색조와 순도는 유지되며, 1은 변화 없고 알파·불투명도·폭에는 영향을 주지 않습니다. | `_OutlineInnerEdgeColorGamma` |
| **폭** | 내부 2D 경계선의 굵기입니다. 노멀 아웃라인보다 가늘게 두는 것이 일반적입니다. | `_OutlineInnerEdgeWidth` |
| **이너 아웃라인에 적용** | 페인팅한 압력을 Inner 2D Edge 굵기에도 반영합니다. 이 토글과 압력 소스는 노멀 아웃라인 그룹 안에 있지만, 이 값은 노멀 아웃라인을 꺼도 Inner Edge에 계속 작용합니다. 버텍스 컬러가 검은 메시에서 켜져 있으면 Inner Edge가 통째로 사라집니다. | `_OutlineInnerEdgePressureApply` |
| **깊이 바이어스** | 이 값보다 큰 깊이 차이만 경계로 인정합니다. 낮추면 완만한 굴곡에도 선이 붙어 노이즈가 되고, 올리면 얇은 부위의 선이 사라집니다. | `_OutlineInnerEdgeBias` |
| **부드러움** | 안쪽 경계선의 공간 그라데이션 폭입니다. 0은 단단한 선, 1은 선 폭 전체가 경계에서 안쪽 끝까지 완전히 흐려집니다. | `_OutlineInnerEdgeSoftness` |
| **블렌드 불투명도** | 내부 경계 색이 섞이는 비율입니다. 0이면 내부 경계선이 보이지 않습니다. | `_OutlineInnerEdgeColorBlendOpacity` |
