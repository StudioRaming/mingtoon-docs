# 깊이 기반 효과

카메라 깊이 텍스처를 읽어 화면 공간에서 그리는 효과입니다. 깊이가 없는 환경에서는 통째로 보이지 않으므로, 값을 만지기 전에 깊이부터 확인하세요. 내부 2D 경계도 이 그룹에 들어 있습니다.

:::note
이 페이지의 항목 이름과 설명은 MingToon 인스펙터가 실제로 표시하는 문구를 소스에서 그대로 가져온 것입니다.
:::

## 깊이

깊이 기반 효과에 사용할 범위와 마스크를 설정합니다.

| 항목 | 설명 | 셰이더 프로퍼티 |
|---|---|---|
| **마스터 폭** | 2D 림과 2D 그림자의 화면 오프셋에 공통으로 곱해지는 배수입니다. 여기서 0으로 두면 각 모듈의 폭을 아무리 올려도 아무것도 나오지 않습니다. | `_DepthWidth` |
| **폭 모드** | Screen Pixels는 화면 픽셀 기준이라 멀어질수록 선이 상대적으로 두꺼워지고, Distance Stable은 거리와 FOV가 변해도 두께가 일정하게 보입니다. Screen Pixels를 고르면 거리 스케일이 동작하지 않습니다. | `_DepthWidthMode` |
| **거리 스케일** | 폭 모드가 Distance Stable일 때 두께의 기준 거리를 정합니다. 폭 모드가 Screen Pixels면 반영되지 않습니다. | `_DepthDistanceScale` |
| **마스터 바이어스** | 화면 깊이 차이가 이 값을 넘어야 앞뒤 경계로 인정합니다. 낮추면 얕은 굴곡에도 선이 붙어 지저분해지고, 올리면 얇은 부위의 선이 사라집니다. | `_DepthBias` |
| **마스터 부드러움** | 깊이 경계 판정의 전환 폭입니다. 낮으면 딱딱한 잉크 선, 높으면 부드럽게 번진 경계가 됩니다. | `_DepthSoftness` |

## 깊이 림

화면 깊이 차이로 생성되는 림 효과를 설정합니다.

| 항목 | 설명 | 셰이더 프로퍼티 |
|---|---|---|
| **림 폭 배수** | 마스터 폭에 곱해지는 2D 림 전용 배수입니다. 최종 두께는 마스터 폭 × 이 값이므로, 마스터 폭이 0이면 여기를 올려도 소용이 없습니다. | `_DepthRimWidth` |
| **림 강도** | 2D 림의 밝기 배수입니다. 0이면 림 계산을 건너뛰므로 색과 폭을 바꿔도 아무것도 보이지 않습니다. | `_DepthRimIntensity` |
| **베이스 색 혼합** | 0이면 지정한 림 색이 단색으로 나오고, 1이면 베이스 맵 색을 곱해 부위마다 다른 림 색이 됩니다. | `_DepthRimBaseColorMix` |
| **360도 림** | 0이면 광원 방향 쪽에만 림이 생기고, 1이면 실루엣 전체를 감쌉니다. 조명이 없거나 방향이 자주 바뀌는 환경에서는 올려 두면 안정적입니다. | `_DepthRim360` |
| **실루엣 시작점** | 표면이 카메라에서 얼마나 꺾여야 실루엣으로 볼지 정합니다. 이 값과 아래의 전환 부드러움은 같은 그룹의 외곽 실루엣 제한이 0이면 전혀 반영되지 않습니다. | `_DepthRimSilhouetteThreshold` |
| **실루엣 전환 부드러움** | 실루엣 판정의 전환 폭입니다. 같은 그룹의 외곽 실루엣 제한이 0이면 반영되지 않습니다. | `_DepthRimSilhouetteSoftness` |

## 2D 그림자

앞 물체의 화면 깊이 실루엣을 이용한 가벼운 캐릭터 그림자를 설정합니다.

| 항목 | 설명 | 셰이더 프로퍼티 |
|---|---|---|
| **그림자 밝기** | 2D 그림자 색의 밝기 배수입니다. 낮출수록 어두워집니다. 2D 그림자와 캐스트 그림자를 통합해 두면 이 값이 통합된 층의 밝기로 쓰입니다. | `_DepthShadowBrightness` |

## 내부 2D 경계

화면 깊이로 표면 안쪽에 그리는 2D 경계를 설정합니다.

| 항목 | 설명 | 셰이더 프로퍼티 |
|---|---|---|
| **Inner 2D Edge 사용** | 화면 깊이 차이로 표면 안쪽 경계선을 그립니다. 추가 지오메트리가 없어 헐이 깨지는 메시에도 쓸 수 있지만, 카메라 깊이 텍스처가 필요하고 표면 모드가 Transparent면 동작하지 않습니다. | `_OutlineInnerEdgeEnabled` |
| **압력 소스** | 선 굵기를 조절할 페인팅 채널을 고릅니다. VertexRed는 버텍스 컬러 R, VertexAlpha는 A, WidthMask는 폭 마스크 텍스처를 씁니다. 버텍스 컬러가 검게 임포트된 메시에서 VertexRed를 고르면 선이 통째로 사라집니다. | `_OutlineHullPressureSource` |
| **Inner Edge 외곽선에 적용** | 페인팅한 압력을 Inner 2D Edge 굵기에도 반영합니다. 이 토글과 압력 소스는 Classic Hull 그룹 안에 있지만, 이 값은 Hull을 꺼도 Inner Edge에 계속 작용합니다. 버텍스 컬러가 검은 메시에서 켜져 있으면 Inner Edge가 통째로 사라집니다. | `_OutlineInnerEdgePressureApply` |
| **깊이 바이어스** | 이 값보다 큰 깊이 차이만 경계로 인정합니다. 낮추면 완만한 굴곡에도 선이 붙어 노이즈가 되고, 올리면 얇은 부위의 선이 사라집니다. | `_OutlineInnerEdgeBias` |
| **부드러움** | 안쪽 경계선의 공간 그라데이션 폭입니다. 0은 단단한 선, 1은 선 폭 전체가 경계에서 안쪽 끝까지 완전히 흐려집니다. | `_OutlineInnerEdgeSoftness` |
