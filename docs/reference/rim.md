# 림

실루엣을 살리고 캐릭터를 배경에서 떼어 놓는 항목입니다. 겹쳐 켜면 금세 과해집니다.

이 페이지는 값을 찾는 표입니다. 켜는 순서가 필요하면 [림 가이드](/guides/rim)를 보세요.

제목과 차례는 인스펙터의 섹션 이름과 표시 순서를 그대로 따릅니다.

맵과 마스크 슬롯 안의 항목은 모든 슬롯이 같습니다.
채널·리맵·페더·마스크 UV는 [텍스처 슬롯 공통 UI](/guides/texture-modules)에 한 번만 적었습니다.

## 림 셰이드 {#림-셰이드}

| 인스펙터 라벨 | 형식 | 범위 | 기본값 | 하는 일 |
|---|---|---|---|---|
| **림 셰이드 사용** | 켜기/끄기 | - | 꺼짐 | 실루엣 안쪽 음영 띠를 형태 그림자 마스크에 더합니다 |
| **그림자 기여 강도** | 실수 | 0 ~ 1 | 1 | 실루엣 안쪽 음영 띠의 세기 |
| **폭** | 실수 | 0 ~ 1 | 0.2 | 0이면 영역이 없고 1이면 전체 영역을 사용합니다 |
| **부드러움** | 실수 | 0 ~ 1 | 0.4 | 0은 딱딱한 경계, 1은 선택한 폭 안의 부드러운 그라데이션 |
| **노멀맵 영향** | 실수 | 0 ~ 1 | 1 | 0 = 메쉬 노멀, 1 = 스택된 노멀맵 전체 적용 |
| **림 그림자 마스크 사용** | 켜기/끄기 | - | 꺼짐 | - |
