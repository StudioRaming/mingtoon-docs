# 림

실루엣을 살리고 캐릭터를 배경에서 떼어 놓는 항목입니다. 겹쳐 켜면 금세 과해집니다.

이 페이지는 값을 찾는 표입니다. 켜는 순서가 필요하면 [림 가이드](/guides/rim)를 보세요.

제목과 차례는 인스펙터의 섹션 이름과 표시 순서를 그대로 따릅니다.

맵과 마스크 슬롯 안의 항목은 모든 슬롯이 같습니다.
채널·리맵·페더·마스크 UV는 [텍스처 슬롯 공통 UI](/guides/texture-modules)에 한 번만 적었습니다.

| **뎁스 그림자 안 표시량** | 실수 | 0 ~ 1 | 0 | 0 = 뎁스 그림자 안에서 내부 반사를 숨김(기본값), 1 = 그대로 표시 |
| **마스크 사용** | 켜기/끄기 | - | 꺼짐 | 끄면 마스크 텍스처를 읽지 않아 픽셀당 텍스처 fetch를 절약합니다 |
