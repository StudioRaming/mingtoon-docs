# 림

실루엣을 살리고 캐릭터를 배경에서 떼어 놓는 그룹입니다. 여러 종류를 겹쳐 켜면 금세 과해지므로 하나씩 확인하며 올리세요.

:::note
이 페이지의 항목 이름과 설명은 MingToon 인스펙터가 실제로 표시하는 문구를 소스에서 그대로 가져온 것입니다.
:::

## 림 셰이드

윤곽 안쪽의 음영 띠를 설정합니다.

| 항목 | 설명 | 셰이더 프로퍼티 |
|---|---|---|
| **림 셰이드 사용** | 기본값은 꺼짐입니다. 실루엣 안쪽 음영 띠를 형태 그림자 마스크에 더합니다. 색을 더하는 효과가 아니며, 끄면 관련 계산을 건너뜁니다. | `_MingRimShadeEnabled` |
| **그림자 기여 강도** | 범위 0-1, 기본값 1입니다. 실루엣 안쪽 음영 띠의 세기입니다. 0이면 림 셰이드 계산 자체를 건너뛰므로 폭·감쇠·부드러움을 바꿔도 아무 변화가 없습니다. | `_MingRimShadeIntensity` |
| **림 감쇠** | 범위 0.01-32, 기본값 0.3입니다. 값이 클수록 음영 띠가 실루엣 가장자리에 얇게 붙습니다. | `_MingRimShadePower` |
| **림 그림자 폭** | 범위 0-1, 기본값 0.2입니다. 음영 띠가 시작되는 지점이며 0이면 띠가 나타나지 않습니다. | `_MingRimShadeWidth` |
| **경계 부드러움** | 범위 0.001-2, 기본값 0.4입니다. 음영 띠 경계의 번짐 폭이며 낮추면 잉크로 그은 선처럼 단단해집니다. | `_MingRimShadeSoftness` |
| **림 셰이드 노멀 영향** | 범위 0-1, 기본값 1입니다. 0은 메시 노멀, 1은 쌓인 노멀맵을 림 음영 모양에 사용합니다. 노멀 레이어가 꺼져 있으면 메시 노멀만 사용합니다. | `_MingRimShadeNormalInfluence` |

## 림 라이트

시선 각도에 반응하는 림 라이트를 설정합니다.

| 항목 | 설명 | 셰이더 프로퍼티 |
|---|---|---|
| **프레넬 림 사용** | 기본값은 켜짐입니다. 비스듬히 보이는 실루엣 가장자리에 림광을 합성합니다. 끄면 값은 보존되지만 이 패스의 계산을 건너뜁니다. | `_MingFresnelRimEnabled` |
| **프레넬 림 색상** | HDR 림광 색입니다. 기본값은 (26.17, 26.17, 26.17)이며 합성 불투명도와 함께 적용됩니다. 너무 높으면 블룸이 없을 때 흰색으로 포화될 수 있습니다. | `_MingFresnelRimColor` |
| **프레넬 림 합성 모드** | Normal·Multiply·Add·Hue·Screen·Color·Overlay 중 림광을 표면에 섞는 방식을 고릅니다. 기본값 Add(2)는 밝기를 더하므로 HDR 색·불투명도가 높으면 클리핑이나 블룸이 생길 수 있습니다. | `_MingFresnelRimBlendMode` |
| **블렌드 불투명도** | 프레넬 림이 결과에 섞이는 비율입니다. 림의 색과 세기는 그대로 두고 존재감만 줄일 때 사용하세요. 0이면 림이 완전히 꺼집니다. | `_MingFresnelRimBlendOpacity` |
| **강도** | 범위 0-20, 기본값 0.52입니다. 프레넬 림의 밝기 배수이며 0이면 림 색과 폭을 바꿔도 화면에 나타나지 않습니다. | `_MingFresnelRimIntensity` |
| **폭** | 범위 0-1, 기본값 0입니다. 림이 시작되는 지점이며 0이면 림이 전혀 나타나지 않고, 1에 가까우면 표면 전체가 밝아집니다. | `_MingFresnelRimWidth` |
| **부드러움** | 범위 0.001-2, 기본값 0.64입니다. 림 경계의 번짐 폭이며 낮추면 셀 룩의 단단한 띠, 올리면 부드러운 그라데이션이 됩니다. | `_MingFresnelRimSoftness` |
| **프레넬 감쇠** | 범위 0.01-32, 기본값 0.54입니다. 값이 클수록 림이 실루엣 가장자리로 얇게 몰립니다. 폭과 함께 작동하며, 낮출수록 부드럽게 퍼집니다. 보통 2~8 사이에서 씁니다. | `_MingFresnelRimPower` |
| **광원 방향 영향** | 0이면 카메라 기준으로 실루엣 전체에 림이 돌고, 1이면 광원이 있는 쪽에만 남습니다. 씬에 방향광이 없으면 차이가 없습니다. | `_MingFresnelRimLightDirectionInfluence` |
| **프레넬 림 시점 영향** | 림이 어디에 앉을지를 시점과 광원 중 무엇이 정할지입니다. 1이면 지금까지처럼 카메라가 보는 실루엣을 따라 돌아 카메라를 움직이면 림도 같이 움직입니다. 0이면 광원 방향만 따라가 카메라를 돌려도 림이 그 자리에 그대로 있습니다. | `_MingFresnelRimViewStrength` |
| **프레넬 림 그림자 표시** | 범위 0-1, 기본값 0. 0은 그림자에서 숨기고 1은 그림자에서도 완전히 표시합니다. | `_MingFresnelRimShadowVisibility` |
| **베이스 색 영향** | 0이면 림 색만 그대로 쓰고, 1이면 베이스 맵 색을 곱해 재질별로 다른 림 색이 나옵니다. | `_MingFresnelRimBaseColorInfluence` |
| **씬 조명 영향** | 0이면 씬 밝기와 무관하게 항상 같은 세기로 나오고, 1이면 조명이 어두워질수록 림도 함께 어두워집니다. | `_MingFresnelRimSceneLightInfluence` |
| **프레넬 림 노멀맵 영향** | 범위 0-1, 기본값 1. 0은 메시 노멀만 사용하고 1은 누적 노멀 맵을 완전히 사용합니다. | `_MingFresnelRimNormalInfluence` |
| **프레넬 림 거리 보정** | 범위 0-1, 기본값 1. 0은 기존의 원시 폭을 사용하고 1은 카메라 거리 변화에도 프레넬 림 폭을 안정화합니다. | `_MingFresnelRimDistanceCompensation` |
| **프레넬 림 투영 보정** | 범위 0-1, 기본값 1. 0은 FOV와 직교 투영 변화에 따라 원시 폭이 변하고 1은 FOV와 직교 투영에서도 폭을 안정화합니다. | `_MingFresnelRimProjectionCompensation` |

## 백라이트

표면 뒤쪽의 주광이 만드는 독립적인 역광 띠를 설정합니다.

| 항목 | 설명 | 셰이더 프로퍼티 |
|---|---|---|
| **백라이트 사용** | 기본값은 켜짐입니다. 주광이 표면 뒤에 있을 때 역광 강조를 더합니다. 끄면 값은 보존되지만 색 기여와 픽셀 계산을 건너뜁니다. | `_MingBacklightEnabled` |
| **백라이트 색상** | HDR 역광 색입니다. 기본값은 (2, 2, 2)이며 강도와 합성되어 적용됩니다. 너무 높으면 블룸이 없을 때 흰색으로 포화될 수 있습니다. | `_MingBacklightColor` |
| **백라이트 강도** | 범위 0-10, 기본값 0.29입니다. 역광 밝기 배수이며 0이면 색·경계 설정을 바꿔도 보이지 않습니다. | `_MingBacklightStrength` |
| **백라이트 경계** | 범위 0-1, 기본값 0.66입니다. 역광이 시작되는 경계입니다. 높이면 더 넓은 면에, 낮추면 실루엣 가까이에만 나타납니다. | `_MingBacklightBorder` |
| **백라이트 부드러움** | 범위 0.001-1, 기본값 0.5입니다. 경계 전환 폭입니다. 낮추면 단단한 셀 띠가 되고 높이면 그라데이션이 넓어집니다. | `_MingBacklightSoftness` |
| **백라이트 지향성** | 범위 0-1, 기본값 0.5입니다. 광원 방향을 얼마나 엄격히 따를지 정합니다. 0은 넓게 퍼지고 1은 광원 반대쪽 조건에 더 민감합니다. | `_MingBacklightDirectivity` |
| **백라이트 시점 영향** | 범위 0-1, 기본값 1입니다. 시선 방향을 역광 형태에 반영하는 세기입니다. 0은 시점 변화가 적고 1은 카메라에 따라 경계가 크게 달라집니다. | `_MingBacklightViewStrength` |
| **백라이트 노멀 영향** | 범위 0-1, 기본값 1입니다. 0은 메시 노멀, 1은 쌓인 노멀맵을 역광 경계에 사용합니다. 노멀 레이어가 꺼져 있으면 1이어도 차이가 없습니다. | `_MingBacklightNormalInfluence` |
| **백라이트 그림자 가시성** | 범위 0-1, 기본값 0.5입니다. 그림자 안에서 역광을 얼마나 남길지 정합니다. 0은 그림자에서 숨기고 1은 조명 그림자와 무관하게 보입니다. | `_MingBacklightShadowVisibility` |
| **백라이트 베이스 색 영향** | 범위 0-1, 기본값 0.5입니다. 0은 역광 색을 그대로 쓰고 1은 베이스 맵 색을 완전히 곱합니다. | `_MingBacklightBaseColorInfluence` |
| **백라이트 씬 조명 영향** | 범위 0-1, 기본값 1입니다. 씬 조명 밝기에 역광이 함께 어두워지는 정도입니다. 0은 일정한 스타일 광, 1은 물리적인 밝기 변화를 따릅니다. | `_MingBacklightSceneLightInfluence` |

## 그림자 내부 반사

그림자 안쪽에서만 보이는 프레넬 반사 띠를 설정합니다.

| 항목 | 설명 | 셰이더 프로퍼티 |
|---|---|---|
| **그림자 내부 반사 사용** | 기본값은 켜짐입니다. 조명·캐스트·2D 그림자로 어두워진 영역 안에만 반사 띠를 더합니다. 끄면 그림자 판정까지 포함해 효과를 건너뜁니다. | `_MingShadowReflectionEnabled` |
| **그림자 내부 반사 색상** | HDR 그림자 내부 반사 색입니다. 기본값은 (3.81, 3.81, 3.81)이며 합성 불투명도·강도와 함께 적용됩니다. 너무 높으면 블룸이 없을 때 흰색으로 포화됩니다. | `_MingShadowReflectionColor` |
| **그림자 내부 반사 합성 모드** | Normal·Multiply·Add·Hue·Screen·Color·Overlay 중 그림자 내부 반사를 섞는 방식입니다. 기본값 Add(2)는 반사 밝기를 더하며, 실제 적용 범위는 그림자 게이트와 불투명도가 함께 결정합니다. | `_MingShadowReflectionBlendMode` |
| **블렌드 불투명도** | 그림자 내부반사 레이어가 결과에 섞이는 비율입니다. 그림자 속 반사광이 과하면 낮추세요. 0이면 꺼집니다. | `_MingShadowReflectionBlendOpacity` |
| **그림자 내부 반사 강도** | 범위 0-20, 기본값 0.5입니다. shadow 영역 안 반사 밝기 배수이며 0이면 그림자 형태를 설정해도 색을 더하지 않습니다. | `_MingShadowReflectionIntensity` |
| **그림자 내부 반사 감쇠** | 범위 0.01-32, 기본값 3.9입니다. 값이 높을수록 반사 띠가 실루엣 가장자리에 얇게 모입니다. | `_MingShadowReflectionPower` |
| **그림자 내부 반사 폭** | 범위 0-1, 기본값 0.9입니다. 그림자 안에서 반사 띠가 차지하는 폭입니다. 0이면 띠가 사라지고 1에 가까우면 넓게 덮습니다. | `_MingShadowReflectionWidth` |
| **그림자 내부 반사 부드러움** | 범위 0.001-1, 기본값 0.5입니다. 반사 띠 가장자리 전환 폭입니다. 낮추면 단단한 띠, 높이면 부드러운 그라데이션입니다. | `_MingShadowReflectionSoftness` |
| **그림자 내부 반사 노멀 영향** | 범위 0-1, 기본값 1입니다. 0은 메시 노멀, 1은 쌓인 노멀맵을 반사 모양에 사용합니다. 노멀 레이어가 꺼져 있으면 메시 노멀만 사용합니다. | `_MingShadowReflectionNormalInfluence` |
| **그림자 내부 반사 시작점** | 범위 0-1, 기본값 0.8입니다. 이 값보다 어두운 shadow 영역에서 반사가 시작됩니다. 높이면 더 깊은 그림자에만 나타납니다. | `_MingShadowReflectionShadowThreshold` |
| **그림자 내부 반사 그림자 부드러움** | 범위 0.001-1, 기본값 0.5입니다. 밝은 면과 그림자 내부 반사 사이 전환 폭입니다. 높이면 경계가 넓게 섞입니다. | `_MingShadowReflectionShadowSoftness` |
| **그림자 내부 반사 베이스 색 영향** | 범위 0-1, 기본값 0.7입니다. 0은 반사 색만 쓰고 1은 베이스 맵 색을 완전히 곱합니다. | `_MingShadowReflectionBaseColorInfluence` |
| **그림자 내부 반사 씬 조명 영향** | 범위 0-1, 기본값 1입니다. 씬 조명 밝기에 반사도 함께 어두워지는 정도입니다. 0은 일정한 스타일 광으로 유지합니다. | `_MingShadowReflectionSceneLightInfluence` |
| **그림자 내부 반사 조명 방향 영향** | 범위 0-1, 기본값 1. 0은 광원 방향을 무시해 반사 림을 전체 실루엣에 두고, 1은 메인·추가 광원 방향을 따라 밝은 면에 배치합니다. | `_MingShadowReflectionLightDirectionInfluence` |
| **그림자 내부 반사 환경광 영향** | 범위 0-1, 기본값 1. 0은 라이트 프로브와 환경 SH 색을 무시하고, 1은 환경 색을 그림자 내부 반사에 완전히 더합니다. | `_MingShadowReflectionAmbientInfluence` |
| **그림자 내부 반사 추가 광원 영향** | 범위 0-1, 기본값 1. 0은 점광원·스포트라이트의 영향을 무시하고, 1은 각 광원의 방향·색·그림자·감쇠를 반사에 완전히 적용합니다. | `_MingShadowReflectionAdditionalLightInfluence` |
| **캐스트 섀도우 안 표시량** | 0 = 투영 그림자 안에서 내부 반사를 숨김, 1 = 그대로 표시(기본값). 투영 그림자 속에서 반사 하이라이트가 빛나는 게 싫을 때 내립니다. WARUDO(빌트인)에서는 포인트·스폿 추가광이 만드는 반사에는 적용되지 않습니다. | `_MingShadowReflectionCastShadowVisibility` |

## 프런트 라이트

카메라를 향한 면에 더하는 독립적인 정면 강조광을 설정합니다.

| 항목 | 설명 | 셰이더 프로퍼티 |
|---|---|---|
| **프런트 라이트 사용** | 기본값은 켜짐입니다. 현재 광원과 시선이 향한 정면에 독립 강조광을 더합니다. 끄면 이 효과의 픽셀 계산을 건너뜁니다. | `_MingFrontLightEnabled` |
