# 림

실루엣을 살리고 캐릭터를 배경에서 떼어 놓는 그룹입니다. 여러 종류를 겹쳐 켜면 금세 과해지므로 하나씩 확인하며 올리세요.

:::note
이 페이지의 항목 이름과 설명은 MingToon 인스펙터가 실제로 표시하는 문구를 소스에서 그대로 가져온 것입니다.
:::

## 림 셰이드

윤곽 안쪽의 음영 띠를 설정합니다.

| 항목 | 설명 | 셰이더 프로퍼티 |
|---|---|---|
| **림 셰이드 사용** | 기본값은 꺼짐입니다. 실루엣 안쪽 음영 띠를 형태 그림자 마스크에 더합니다. 색을 더하는 효과가 아니며, 끄면 관련 계산을 건너뜁니다. | `_RimShadeEnabled` |
| **그림자 기여 강도** | 범위 0-1, 기본값 1입니다. 실루엣 안쪽 음영 띠의 세기입니다. 0이면 림 셰이드 계산 자체를 건너뛰므로 폭과 부드러움을 바꿔도 아무 변화가 없습니다. | `_RimShadeIntensity` |
| **폭** | 범위 0-1, 기본값 0.2입니다. 0이면 영역이 없고 1이면 전체 영역을 사용합니다. 부드러움을 바꿔도 이 폭 바깥으로 퍼지지 않습니다. | `_RimShadeWidth` |
| **부드러움** | 범위 0-1, 기본값 0.4입니다. 0은 딱딱한 경계, 1은 선택한 폭 안의 부드러운 그라데이션입니다. 폭은 변하지 않습니다. | `_RimShadeSoftness` |
| **림 셰이드 노멀 영향** | 범위 0-1, 기본값 1입니다. 0은 메시 노멀, 1은 쌓인 노멀맵을 림 음영 모양에 사용합니다. 노멀 레이어가 꺼져 있으면 메시 노멀만 사용합니다. | `_RimShadeNormalInfluence` |

## 림 라이트

시선 각도에 반응하는 림 라이트를 설정합니다.

| 항목 | 설명 | 셰이더 프로퍼티 |
|---|---|---|
| **프레넬 림 사용** | 기본값은 켜짐입니다. 비스듬히 보이는 실루엣 가장자리에 림광을 합성합니다. 끄면 값은 보존되지만 이 패스의 계산을 건너뜁니다. | `_FresnelRimEnabled` |
| **프레넬 림 색상** | HDR 림광 색입니다. 기본값은 (26.17, 26.17, 26.17)이며 합성 불투명도와 함께 적용됩니다. 너무 높으면 블룸이 없을 때 흰색으로 포화될 수 있습니다. | `_FresnelRimColor` |
| **프레넬 림 합성 모드** | Normal·Multiply·Add·Hue·Screen·Color·Overlay 중 림광을 표면에 섞는 방식을 고릅니다. 기본값 Add(2)는 밝기를 더하므로 HDR 색·불투명도가 높으면 클리핑이나 블룸이 생길 수 있습니다. | `_FresnelRimBlendMode` |
| **블렌드 불투명도** | 프레넬 림이 결과에 섞이는 비율입니다. 림의 색과 세기는 그대로 두고 존재감만 줄일 때 사용하세요. 0이면 림이 완전히 꺼집니다. | `_FresnelRimBlendOpacity` |
| **색 순도** | 베이스 색과 Fresnel 림 틴트가 합쳐진 뒤의 색 순도입니다. 범위 0~10, 기본값 1입니다. 0은 무채색, 1은 기존 합성색, 1을 넘으면 과채도입니다. | `_FresnelRimColorPurity` |
| **강도** | 범위 0-20, 기본값 0.52입니다. 프레넬 림의 밝기 배수이며 0이면 림 색과 폭을 바꿔도 화면에 나타나지 않습니다. | `_FresnelRimIntensity` |
| **폭** | 범위 0-1, 기본값 0입니다. 0이면 영역이 없고 1이면 전체 프레넬 영역을 사용합니다. 부드러움을 바꿔도 이 폭 바깥으로 퍼지지 않습니다. | `_FresnelRimWidth` |
| **부드러움** | 범위 0-1, 기본값 0.64입니다. 0은 딱딱한 경계, 1은 선택한 폭 안을 모두 쓰는 부드러운 그라데이션입니다. 폭은 변하지 않습니다. | `_FresnelRimSoftness` |
| **광원측 강조** | 0이면 림 밝기가 둘레에 균일하고, 1이면 현재 메인·가상 광원이 닿는 쪽만 남깁니다. 반대쪽을 완전히 낮춰 광원을 돌릴 때 변화가 바로 보입니다. 영역 위치는 아래 시점 기준이 정합니다. | `_FresnelRimLightDirectionInfluence` |
| **시점 기준** | 림 영역의 기준 축입니다. 1은 카메라 실루엣을 따라가는 일반 프레넬, 0은 현재 메인·가상 광원 축에 고정된 띠입니다. | `_FresnelRimViewStrength` |
| **프레넬 림 그림자 표시** | 범위 0-1, 기본값 0. 0은 그림자에서 숨기고 1은 그림자에서도 완전히 표시합니다. | `_FresnelRimShadowVisibility` |
| **베이스 색 영향** | 0이면 림 색만 그대로 쓰고, 1이면 베이스 맵 색을 곱해 재질별로 다른 림 색이 나옵니다. | `_FresnelRimBaseColorInfluence` |
| **씬 조명 영향** | 0이면 씬 밝기와 무관하게 항상 같은 세기로 나오고, 1이면 조명이 어두워질수록 림도 함께 어두워집니다. | `_FresnelRimSceneLightInfluence` |
| **프레넬 림 노멀맵 영향** | 범위 0-1, 기본값 1. 0은 메시 노멀만 사용하고 1은 누적 노멀 맵을 완전히 사용합니다. | `_FresnelRimNormalInfluence` |
| **프레넬 림 거리 보정** | 범위 0-1, 기본값 1. 0은 기존의 원시 폭을 사용하고 1은 카메라 거리 변화에도 프레넬 림 폭을 안정화합니다. | `_FresnelRimDistanceCompensation` |
| **프레넬 림 투영 보정** | 범위 0-1, 기본값 1. 0은 FOV와 직교 투영 변화에 따라 원시 폭이 변하고 1은 FOV와 직교 투영에서도 폭을 안정화합니다. | `_FresnelRimProjectionCompensation` |

## 백라이트

표면 뒤쪽의 주광이 만드는 독립적인 역광 띠를 설정합니다.

| 항목 | 설명 | 셰이더 프로퍼티 |
|---|---|---|
| **백라이트 사용** | 기본값은 켜짐입니다. 주광이 표면 뒤에 있을 때 역광 강조를 더합니다. 끄면 값은 보존되지만 색 기여와 픽셀 계산을 건너뜁니다. | `_BacklightEnabled` |
| **백라이트 색상** | HDR 역광 색입니다. 기본값은 (2, 2, 2)이며 강도와 합성되어 적용됩니다. 너무 높으면 블룸이 없을 때 흰색으로 포화될 수 있습니다. | `_BacklightColor` |
| **백라이트 합성 모드** | Normal·Multiply·Add·Hue·Screen·Color·Overlay 중 백라이트를 표면에 섞는 방식을 고릅니다. 기본값 Add는 기존 밝기 가산 결과를 그대로 유지합니다. | `_BacklightBlendMode` |
| **블렌드 불투명도** | 백라이트가 최종 색에 섞이는 비율입니다. 색과 강도는 유지한 채 존재감만 줄이며, 0이면 완전히 꺼집니다. | `_BacklightBlendOpacity` |
| **색 순도** | 베이스 색과 백라이트 틴트가 합쳐진 뒤의 색 순도입니다. 범위 0~10, 기본값 1입니다. 0은 무채색, 1은 기존 합성색, 1을 넘으면 과채도입니다. | `_BacklightColorPurity` |
| **백라이트 강도** | 범위 0-10, 기본값 0.29입니다. 역광 밝기 배수이며 0이면 색·경계 설정을 바꿔도 보이지 않습니다. | `_BacklightStrength` |
| **폭** | 범위 0-1, 기본값 0.34입니다. 0이면 영역이 없고 1이면 전체 영역을 사용합니다. 부드러움을 바꿔도 이 폭 바깥으로 퍼지지 않습니다. | `_BacklightBorder` |
| **부드러움** | 범위 0-1, 기본값 0.5입니다. 0은 딱딱한 경계, 1은 선택한 폭 안의 부드러운 그라데이션입니다. 폭은 변하지 않습니다. | `_BacklightSoftness` |
| **백라이트 지향성** | 범위 0-1, 기본값 0.5입니다. 광원 방향을 얼마나 엄격히 따를지 정합니다. 0은 넓게 퍼지고 1은 광원 반대쪽 조건에 더 민감합니다. | `_BacklightDirectivity` |
| **백라이트 시점 영향** | 범위 0-1, 기본값 1입니다. 시선 방향을 역광 형태에 반영하는 세기입니다. 0은 시점 변화가 적고 1은 카메라에 따라 경계가 크게 달라집니다. | `_BacklightViewStrength` |
| **백라이트 노멀 영향** | 범위 0-1, 기본값 1입니다. 0은 메시 노멀, 1은 쌓인 노멀맵을 역광 경계에 사용합니다. 노멀 레이어가 꺼져 있으면 1이어도 차이가 없습니다. | `_BacklightNormalInfluence` |
| **백라이트 그림자 가시성** | 범위 0-1, 기본값 0.5입니다. 그림자 안에서 역광을 얼마나 남길지 정합니다. 0은 그림자에서 숨기고 1은 조명 그림자와 무관하게 보입니다. | `_BacklightShadowVisibility` |
| **백라이트 베이스 색 영향** | 범위 0-1, 기본값 0.5입니다. 0은 역광 색을 그대로 쓰고 1은 베이스 맵 색을 완전히 곱합니다. | `_BacklightBaseColorInfluence` |
| **백라이트 씬 조명 영향** | 범위 0-1, 기본값 1입니다. 씬 조명 밝기에 역광이 함께 어두워지는 정도입니다. 0은 일정한 스타일 광, 1은 물리적인 밝기 변화를 따릅니다. | `_BacklightSceneLightInfluence` |

## 그림자 내부 반사

그림자 안쪽에서만 보이는 프레넬 반사 띠를 설정합니다.

|---|---|---|

| **그림자 내부 반사 색상** | HDR 그림자 내부 반사 색입니다. 기본값은 (3.81, 3.81, 3.81)이며 합성 불투명도·강도와 함께 적용됩니다. 너무 높으면 블룸이 없을 때 흰색으로 포화됩니다. | `_ShadowReflectionColor` |
| **그림자 내부 반사 합성 모드** | Normal·Multiply·Add·Hue·Screen·Color·Overlay 중 그림자 내부 반사를 섞는 방식입니다. 기본값 Add(2)는 반사 밝기를 더하며, 실제 적용 범위는 그림자 게이트와 불투명도가 함께 결정합니다. | `_ShadowReflectionBlendMode` |
| **블렌드 불투명도** | 그림자 내부반사 레이어가 결과에 섞이는 비율입니다. 그림자 속 반사광이 과하면 낮추세요. 0이면 꺼집니다. | `_ShadowReflectionBlendOpacity` |
| **색 순도** | 베이스 색과 그림자 내부 반사 틴트가 합쳐진 뒤의 색 순도입니다. 범위 0~10, 기본값 1입니다. 0은 무채색, 1은 기존 합성색, 1을 넘으면 과채도입니다. | `_ShadowReflectionColorPurity` |
| **그림자 내부 반사 강도** | 범위 0-20, 기본값 0.5입니다. shadow 영역 안 반사 밝기 배수이며 0이면 그림자 형태를 설정해도 색을 더하지 않습니다. | `_ShadowReflectionIntensity` |
| **폭** | 범위 0-1, 기본값 0.9입니다. 0이면 영역이 없고 1이면 전체 영역을 사용합니다. 부드러움을 바꿔도 이 폭 바깥으로 퍼지지 않습니다. | `_ShadowReflectionWidth` |
| **부드러움** | 범위 0-1, 기본값 0.5입니다. 0은 딱딱한 경계, 1은 선택한 폭 안의 부드러운 그라데이션입니다. 폭은 변하지 않습니다. | `_ShadowReflectionSoftness` |
| **그림자 내부 반사 노멀 영향** | 범위 0-1, 기본값 1입니다. 0은 메시 노멀, 1은 쌓인 노멀맵을 반사 모양에 사용합니다. 노멀 레이어가 꺼져 있으면 메시 노멀만 사용합니다. | `_ShadowReflectionNormalInfluence` |
| **그림자 내부 반사 시작점** | 범위 0-1, 기본값 0.8입니다. 이 값보다 어두운 shadow 영역에서 반사가 시작됩니다. 높이면 더 깊은 그림자에만 나타납니다. | `_ShadowReflectionShadowThreshold` |
| **그림자 내부 반사 그림자 부드러움** | 범위 0.001-1, 기본값 0.5입니다. 밝은 면과 그림자 내부 반사 사이 전환 폭입니다. 높이면 경계가 넓게 섞입니다. | `_ShadowReflectionShadowSoftness` |
| **그림자 내부 반사 베이스 색 영향** | 범위 0-1, 기본값 0.7입니다. 0은 반사 색만 쓰고 1은 베이스 맵 색을 완전히 곱합니다. | `_ShadowReflectionBaseColorInfluence` |
| **그림자 내부 반사 씬 조명 영향** | 범위 0-1, 기본값 1입니다. 씬 조명 밝기에 반사도 함께 어두워지는 정도입니다. 0은 일정한 스타일 광으로 유지합니다. | `_ShadowReflectionSceneLightInfluence` |
| **그림자 반사 광원측 강조** | 범위 0-1, 기본값 1. 0은 반사 밝기를 둘레에 균일하게 두고, 1은 메인·추가 광원이 닿는 쪽만 남깁니다. 영역 위치가 아니라 밝은 쪽 선택을 조절합니다. | `_ShadowReflectionLightDirectionInfluence` |
| **그림자 내부 반사 환경광 영향** | 범위 0-1, 기본값 1. 0은 라이트 프로브와 환경 SH 색을 무시하고, 1은 환경 색을 그림자 내부 반사에 완전히 더합니다. | `_ShadowReflectionAmbientInfluence` |
| **그림자 내부 반사 추가 광원 영향** | 범위 0-1, 기본값 1. 0은 점광원·스포트라이트의 영향을 무시하고, 1은 각 광원의 방향·색·그림자·감쇠를 반사에 완전히 적용합니다. | `_ShadowReflectionAdditionalLightInfluence` |
| **캐스트 섀도우 안 표시량** | 0 = 투영 그림자 안에서 내부 반사를 숨김, 1 = 그대로 표시(기본값). 투영 그림자 속에서 반사 하이라이트가 빛나는 게 싫을 때 내립니다. WARUDO(빌트인)의 포인트·스폿 추가광이 만드는 반사에도 적용됩니다. 2D 그림자와 SSAO는 추가광 패스에서 다시 계산하지 않습니다. | `_ShadowReflectionCastShadowVisibility` |

## 프런트 라이트

카메라를 향한 면에 더하는 독립적인 정면 강조광을 설정합니다.

| 항목 | 설명 | 셰이더 프로퍼티 |
|---|---|---|
| **프런트 라이트 사용** | 기본값은 켜짐입니다. 현재 광원과 시선이 향한 정면에 독립 강조광을 더합니다. 끄면 이 효과의 픽셀 계산을 건너뜁니다. | `_FrontLightEnabled` |

| **하이라이트 중심 강도** | 범위 0-2, 기본값 0.25입니다. 중심부에 추가하는 밝기입니다. 0이면 영역 모양은 유지한 채 중심 강조만 사라집니다. | `_FrontLightCoreIntensity` |
