# 디테일 맵

베이스 위에 쌓는 레이어와 재질감입니다. 레이어 계열은 모두 같은 함정을 공유합니다 — 레이어 수보다 뒤에 있는 슬롯은 계산 자체를 건너뜁니다.

:::note
이 페이지의 항목 이름과 설명은 MingToon 인스펙터가 실제로 표시하는 문구를 소스에서 그대로 가져온 것입니다.
:::

## 텍스처 레이어

추가 표면 텍스처 레이어를 합성합니다.

| 항목 | 설명 | 셰이더 프로퍼티 |
|---|---|---|
| **표면 스택 사용** | 기본값은 꺼짐입니다. 여러 텍스처를 순서대로 표면 색에 합성합니다. 활성 레이어마다 샘플·마스크·합성 비용이 추가됩니다. | `_StackEnabled` |
| **표면 스택 레이어 수** | 범위 0-10, 기본값 0입니다. 설정한 수를 넘는 슬롯은 평가되지 않으며, 늘릴수록 텍스처·마스크·합성 비용이 누적됩니다. | `_StackLayerCount` |

## 노멀 레이어

여러 노멀 맵 레이어와 혼합 강도를 설정합니다.

| 항목 | 설명 | 셰이더 프로퍼티 |
|---|---|---|
| **노멀 레이어 사용** | 기본값은 꺼짐입니다. 쌓인 노멀맵을 조명·림·다른 모듈에 사용합니다. 활성 레이어마다 텍스처·합성 비용이 늘고, 레이어 수가 0이면 결과가 없습니다. | `_NormalEnabled` |
| **노멀 레이어 수** | 범위 0-5, 기본값 0입니다. 이 수만 평가하고 설정한 수를 넘는 슬롯은 샘플링하지 않습니다. 레이어마다 텍스처·마스크·합성 비용이 추가됩니다. | `_NormalLayerCount` |

## 맷캡 레이어

맷캡 텍스처, 합성 방식, 투영 특성을 설정합니다.

| 항목 | 설명 | 셰이더 프로퍼티 |
|---|---|---|
| **맷캡 레이어 사용** | 기본값은 꺼짐입니다. 시점 기준 MatCap 레이어를 표면에 합성합니다. 활성 레이어마다 텍스처·합성 비용이 생기고, 레이어 수가 0이면 변화가 없습니다. | `_MatcapEnabled` |
| **맷캡 레이어 수** | 범위 0-5, 기본값 0입니다. 설정한 수를 넘는 슬롯은 평가되지 않으며 활성 레이어마다 맵·마스크·합성 비용을 추가합니다. | `_MatcapLayerCount` |
| **금속 영역만 맷캡** | 기본값은 꺼짐입니다. PBR 금속도 값이 높은 영역에만 모든 맷캡 레이어를 제한합니다. PBR이 꺼져 있거나 금속 마스크가 없으면 제한할 기준이 없어 효과가 약합니다. | `_MatcapMetallicOnly` |
| **맷캡 반사 탈채도** | 범위 0-1, 기본값 0.25입니다. 맷캡 색을 회색에 가깝게 만들어 베이스 색이 튀지 않게 합니다. 1이면 색 정보를 거의 모두 제거합니다. | `_MatcapDesaturation` |
| **MatCap 노멀맵** | 맷캡 다섯 슬롯이 함께 쓰는 노멀맵입니다. 맷캡을 투영할 때 쓰는 노멀만 흔들기 때문에 표면 음영은 그대로 두고 하이라이트만 일그러집니다. 슬롯마다 `MatCap 노멀맵 강도`로 따라가는 정도를 정하며, 모든 슬롯의 강도가 0이면 텍스처를 넣어도 읽지 않습니다. 슬롯별로 나누지 않은 이유는 텍스처 바인딩 예산이며, 다섯 장이면 한 장으로 될 일에 다섯 칸을 씁니다. | `_MatcapNormalMap` |

## PBR 표면

금속도, 매끄러움과 직접광 스페큘러를 설정합니다.

| 항목 | 설명 | 셰이더 프로퍼티 |
|---|---|---|
| **PBR 표면 사용** | 기본값은 꺼짐입니다. 금속도·매끄러움·반사 기반 표면 경로를 켭니다. 툰 조명 결과가 달라지고 노멀·환경 반사 계산 비용이 추가될 수 있습니다. | `_PbrEnabled` |
| **워크플로** | Metallic은 금속도에서 반사색을 만들고, Specular는 스페큘러 컬러를 직접 지정합니다. Specular를 고르면 금속도 슬라이더는 결과에 반영되지 않습니다. | `_WorkflowMode` |
| **패킹 마스크 사용** | 금속도·오클루전·매끄러움을 한 장의 텍스처에서 채널별로 읽습니다. 끄면 아래 채널·반전 설정이 모두 무시되고 금속도·매끄러움 슬라이더 값만 사용됩니다. | `_PbrMaskMapEnabled` |
| **PBR 패킹 마스크** | 기본 배치는 R=금속도, G=오클루전, A=매끄러움입니다. 텍스처의 채널 배치가 다르면 아래 채널 설정으로 맞출 수 있습니다. | `_MaskMap` |
| **금속도** | 0은 비금속, 1은 금속입니다. 패킹 마스크를 쓰면 마스크 값과 곱해지므로 마스크가 검은 곳은 금속이 되지 않습니다. | `_Metallic` |
| **매끄러움** | 높을수록 반사가 작고 선명해집니다. 툰 룩에서는 0.3~0.6이 무난하며, 1에 가까우면 하이라이트가 점처럼 작아집니다. | `_Smoothness` |
| **반사광 강도** | 범위 0-2, 기본값 1입니다. 스페큘러 반사의 세기이며 0으로 두면 직접 하이라이트와 환경 반사가 함께 사라지므로, 매끄러움과 반사 강도를 올려도 아무 변화가 없습니다. | `_PbrSpecularStrength` |
| **영역 마스크 사용** | 기본값은 꺼짐입니다. 한 장의 RGBA 텍스처를 네 개의 영역 마스크로 나눠 재질 값을 보정합니다. 마스크 샘플·연산이 늘고 UV가 맞지 않으면 경계가 어긋납니다. | `_RegionMaskEnabled` |
| **영역별 금속도 보정** | 범위 -1-1, 기본값 0인 R/G/B/A 영역별 금속도 가산값입니다. 머티리얼 기본값에 더해지므로 1에 가까운 큰 값은 금속으로 급격히 바뀔 수 있습니다. | `_RegionMetallic` |
| **영역별 환경반사 보정** | 범위 -4-4, 기본값 0인 영역별 환경반사 가산값입니다. 피부·천은 음수로 반사를 줄이고, 단단한 재질은 양수로 강조합니다. | `_RegionReflection` |
| **영역별 툰 스페큘러 강도 보정** | 범위 -8-8, 기본값 0인 영역별 툰 스페큘러 강도 가산값입니다. 값이 크면 하이라이트가 과하게 밝아져 클리핑될 수 있습니다. | `_RegionSpecularStrength` |
| **영역별 툰 스페큘러 매끄러움 보정** | 범위 -1-1, 기본값 0인 영역별 툰 스페큘러 매끄러움 가산값입니다. 양수는 더 날카롭게, 음수는 더 넓게 보이게 합니다. | `_RegionSpecularSmoothness` |
| **금속도 채널** | 패킹 마스크에서 금속도를 읽을 채널입니다. 패킹 마스크 사용이 꺼져 있으면 무시됩니다. | `_PbrMetallicChannel` |
| **금속도 반전** | 읽어온 금속도 값을 뒤집습니다. 비금속을 흰색으로 칠한 마스크를 그대로 쓸 때 사용합니다. | `_PbrMetallicInvert` |
| **PBR 오클루전 채널** | 패킹 마스크에서 반사 차폐를 읽을 채널입니다. 반사 오클루전이 0이면 이 설정은 결과에 전혀 반영되지 않습니다. | `_PbrOcclusionChannel` |
| **PBR 오클루전 반전** | 읽어온 반사 차폐 값을 뒤집습니다. 반사 오클루전이 0이면 무시됩니다. | `_PbrOcclusionInvert` |
| **반사 오클루전** | 범위 0-1, 기본값 0입니다. 패킹 마스크의 오클루전 채널로 환경 반사를 억제하는 양이며 0이면 채널·반전 설정이 있어도 결과에 나타나지 않습니다. | `_PbrOcclusionStrength` |
| **매끄러움 채널** | 패킹 마스크에서 매끄러움을 읽을 채널입니다. 패킹 마스크 사용이 꺼져 있으면 무시됩니다. | `_PbrSmoothnessChannel` |
| **러프니스로 사용 (반전)** | 매끄러움 대신 거칠기(러프니스) 맵을 넣었을 때 켭니다. 채널 값을 1에서 빼서 사용합니다. | `_PbrSmoothnessInvert` |
| **스페큘러 컬러 맵 (RGB) 사용** | 반사색을 텍스처로 지정합니다. 끄면 스페큘러 컬러 맵과 반전 설정이 무시됩니다. 워크플로가 Metallic이면 반사색은 금속도에서 만들어지므로 영향이 제한적입니다. | `_PbrSpecularMapEnabled` |
| **스페큘러 컬러 맵 반전** | 스페큘러 컬러 맵의 RGB를 반전합니다. 스페큘러 컬러 맵 사용이 꺼져 있으면 무시됩니다. | `_PbrSpecularInvert` |
| **직접 하이라이트 강도** | 범위 0-4, 기본값 1입니다. 광원에서 직접 오는 하이라이트의 세기이며 0이면 하이라이트 계산 자체를 건너뛰므로 매끄러움을 올려도 반짝임이 생기지 않습니다. | `_PbrDirectStrength` |
| **그림자 안 표시량** | 범위 0-1, 기본값 0입니다. 그림자에 들어간 부분에서 PBR 하이라이트를 얼마나 남길지 정하며, 0이면 그림자 안에서 완전히 사라지고 1이면 그림자와 무관하게 그대로 보입니다. | `_PbrShadowVisibility` |
| **노멀맵 영향** | 범위 0-1, 기본값 1입니다. 0이면 메시 노멀만 쓰고 1이면 쌓인 노멀맵을 그대로 반영합니다. 노멀맵이 없으면 값과 무관하게 결과가 같습니다. | `_PbrNormalInfluence` |
| **하이라이트 툰화** | 범위 0-1, 기본값 0입니다. GGX 하이라이트 감쇠를 툰 단계로 바꾸는 양입니다. 0이면 물리 로브 그대로이고 높이면 경계가 생깁니다. 켜면 임계값도 함께 작동합니다. | `_PbrDirectToonAmount` |
| **하이라이트 툰 경계** | 범위 0-1, 기본값 0.5입니다. 로브에서 하이라이트로 남길 경계를 정합니다. 낮추면 넓어지고 높이면 좁아지며, 툰화가 0이면 무시됩니다. | `_PbrDirectToonThreshold` |
| **환경 반사 강도** | 범위 0-4, 기본값 0입니다. 리플렉션 프로브나 스카이박스가 비치는 양이며 씬에 프로브가 없으면 값을 올려도 거의 변화가 없습니다. | `_PbrReflectionStrength` |
| **환경반사 흐림 보정** | 범위 -1-1, 기본값 0입니다. 실제 매끄러움보다 환경반사를 흐리거나 선명하게 합니다. 음수는 선명하게 하며 눈·젖은 표면에 유용합니다. | `_PbrReflectionSmoothnessBias` |
| **환경반사 탈채도** | 범위 0-1, 기본값 0입니다. 환경반사의 색을 얼마나 회색에 가깝게 만들지 정합니다. 1이면 밝기만 남아 고유 색을 보존하기 쉽습니다. | `_PbrReflectionDesaturation` |
| **환경반사 틴트** | HDR 환경반사 색 보정입니다. 기본값은 (1, 1, 1)이며 탈채도와 함께 적용됩니다. 너무 높이면 반사만 흰색으로 포화될 수 있습니다. | `_PbrReflectionTint` |
| **PBR 프레넬 지수** | 범위 1-8, 기본값 5입니다. 스치는 각도에서 반사가 밝아지는 감쇠입니다. 낮추면 가장자리 밝기가 안쪽까지 넓어지고 높이면 얇아집니다. | `_PbrFresnelPower` |

## 반사

PBR 표면과 별개로 직접광·추가광·환경반사, 색상 마스크와 큐브맵을 설정합니다.

| 항목 | 설명 | 셰이더 프로퍼티 |
|---|---|---|
| **반사 사용** | PBR 표면과 별개로 직접광·추가광·환경반사, 반사 색상 맵과 큐브맵을 켭니다. 끄면 이 모듈의 반사 계산과 텍스처 샘플을 건너뜁니다. | `_ReflectionEnabled` |
| **직접광 반사** | 주광원의 직접광 하이라이트에 반사 색상과 마스크를 적용합니다. lilToon의 Apply Specular에 대응합니다. PBR 표면도 함께 켜져 있으면 PBR 탭의 공통 로브가 우선되어 이 스위치는 사용되지 않습니다. | `_ReflectionApplySpecular` |
| **추가광 반사** | 포인트·스폿 등 추가광의 직접 하이라이트에 반사를 적용합니다. lilToon의 Apply Specular FA에 대응합니다. PBR 표면도 함께 켜져 있으면 PBR 탭의 공통 로브가 우선되어 이 스위치는 사용되지 않습니다. | `_ReflectionApplySpecularAdditional` |
| **환경 반사** | 리플렉션 프로브·스카이박스·재질 큐브맵의 반사를 적용합니다. lilToon의 Apply Reflection에 대응합니다. PBR 표면도 함께 켜져 있으면 PBR 탭의 공통 환경 로브가 우선되어 이 스위치는 사용되지 않습니다. | `_ReflectionApplyEnvironment` |
| **기본 반사율** | 범위 0-1, 기본값 0.04입니다. 비금속 표면의 기본 반사율(F0)이며 반사 전용 모드와 Metallic 워크플로의 비금속 부분에 사용됩니다. 금속도 1에 가까운 부분은 표면 색으로 전환됩니다. | `_ReflectionReflectance` |
| **반사 색상 맵 사용** | 반사 색상에 텍스처의 RGB와 알파를 추가로 곱합니다. 끄면 텍스처 샘플과 Tiling/Offset은 사용하지 않습니다. | `_ReflectionColorTexEnabled` |
| **반사 색상 맵** | 릴툰 Reflection Color Tex에 대응하는 RGB 색상·A 마스크입니다. Tiling/Offset은 이 맵에만 적용되며 다른 표면 맵과 공유하지 않습니다. | `_ReflectionColorTex` |
| **반사 색상** | 릴툰의 반사 색상처럼 직접 하이라이트와 환경반사에 함께 곱해지는 HDR 색입니다. 알파는 두 반사 로브의 적용량이며 기본값은 흰색·불투명(1)입니다. | `_ReflectionColor` |
| **투명도 반사 적용** | 켜면 표면 알파를 반사 색상 알파에 곱합니다. 기존 MingToon 재질의 외형을 보존하기 위해 기본값은 꺼짐이며, 릴툰 변환기가 원본 설정을 명시적으로 옮깁니다. | `_ReflectionApplyTransparency` |
| **반사 합성 모드** | 반사 색상을 표면에 합성하는 방식입니다. Add는 기존 PBR 반사처럼 더하고, Multiply·Screen 등은 릴툰 변환 결과의 레이어 합성에 사용합니다. | `_ReflectionBlendMode` |
