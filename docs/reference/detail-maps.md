# 디테일 맵

베이스 위에 쌓는 레이어와 재질감입니다. 레이어 계열은 레이어 수부터 올려야 합니다.

이 페이지는 값을 찾는 표입니다. 켜는 순서가 필요하면 [디테일 맵 가이드](/guides/detail-maps)를 보세요.

제목과 차례는 인스펙터의 섹션 이름과 표시 순서를 그대로 따릅니다.

맵과 마스크 슬롯 안의 항목은 모든 슬롯이 같습니다.
채널·리맵·페더·마스크 UV는 [텍스처 슬롯 공통 UI](/guides/texture-modules)에 한 번만 적었습니다.

## 추가 텍스처 (최대 10장) {#추가-텍스처-최대-10장}

표면 레이어는 최대 10장입니다. 레이어를 늘리면 아래 항목이 장마다 같은 모양으로 반복됩니다.

| 인스펙터 라벨 | 형식 | 범위 | 기본값 | 하는 일 |
|---|---|---|---|---|
| **표면 스택 사용** | 켜기/끄기 | - | 꺼짐 | 여러 텍스처를 순서대로 표면 색에 합성합니다 |
| **표면 스택 레이어 수** | 정수 | 0 ~ 10 | 0 | 설정한 수를 넘는 슬롯은 평가되지 않으며, 늘릴수록 텍스처·마스크·합성 비용이 누적됩니다 |
| **합성 모드** | 선택 | Normal / Multiply / Add / Screen / Color / Overlay | Multiply | 이 스택 레이어를 아래 결과와 섞는 방식입니다 |
| **불투명도** | 실수 | 0 ~ 1 | 1 | 이 레이어의 적용량입니다 |

노멀 레이어는 최대 5장입니다. 레이어를 늘리면 아래 항목이 장마다 같은 모양으로 반복됩니다.

| 인스펙터 라벨 | 형식 | 범위 | 기본값 | 하는 일 |
|---|---|---|---|---|
| **노멀 레이어 사용** | 켜기/끄기 | - | 꺼짐 | 쌓인 노멀맵을 조명·림·다른 모듈에 사용합니다 |
| **노멀 레이어 수** | 정수 | 0 ~ 5 | 0 | 이 수만 평가하고 설정한 수를 넘는 슬롯은 샘플링하지 않습니다 |
