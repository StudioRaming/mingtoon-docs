# 디테일 맵

베이스 위에 쌓는 레이어와 재질감입니다. 레이어 계열은 모두 같은 함정을 공유합니다 — 레이어 수보다 뒤에 있는 슬롯은 계산 자체를 건너뜁니다.

:::note
이 페이지의 항목 이름과 설명은 MingToon 인스펙터가 실제로 표시하는 문구를 소스에서 그대로 가져온 것입니다.
:::

## 텍스처 레이어

추가 표면 텍스처 레이어를 합성합니다.

| 항목 | 설명 | 셰이더 프로퍼티 |
|---|---|---|
| **합성 모드** | 이 스택 레이어를 아래 결과와 섞는 방식입니다. Normal은 완전히 덮고, Multiply는 아래 명암을 유지한 채 색만 얹습니다. | `_MingStackBlendMode` |
| **불투명도** | 이 레이어의 적용량입니다. 0이면 레이어 계산을 건너뛰므로 텍스처를 넣어도 보이지 않고, 레이어 수보다 뒤에 있는 슬롯도 계산되지 않습니다. | `_MingStackOpacity` |

## 노멀 레이어

여러 노멀 맵 레이어와 혼합 강도를 설정합니다.

| 항목 | 설명 | 셰이더 프로퍼티 |
|---|---|---|
| **노멀맵** | 이 레이어의 노멀맵입니다. 레이어 수보다 뒤에 있는 슬롯은 계산되지 않으므로, 맵을 넣어도 보이지 않으면 먼저 레이어 수를 확인하세요. | `_MingNormalMap` |
| **노멀 강도** | 이 레이어가 최종 노멀에 섞이는 세기입니다. 0이면 텍스처를 넣어도 아무 영향이 없습니다. | `_MingNormalStrength` |

## 맷캡 레이어

맷캡 텍스처, 합성 방식, 투영 특성을 설정합니다.

| 항목 | 설명 | 셰이더 프로퍼티 |
|---|---|---|
| **맷캡 맵** | 구체에 그려진 조명·재질 이미지입니다. 시선 기준으로 투영되므로 카메라가 돌면 하이라이트도 따라 돕니다. | `_MingMatcapMap` |
| **합성 모드** | 맷캡을 표면 색과 어떻게 섞을지 정합니다. Add와 Screen은 밝은 광택, Multiply는 어두운 재질감에 적합합니다. | `_MingMatcapBlendMode` |
| **대비** | 맷캡 이미지의 명암 대비입니다. 1이 원본이고, 올리면 하이라이트와 어두운 부분이 갈라져 셀 느낌이 강해집니다. | `_MingMatcapContrast` |
| **강도** | 이 레이어의 적용량입니다. 0이면 레이어 계산을 건너뛰므로 맵과 합성 모드를 바꿔도 아무 변화가 없습니다. 레이어 수보다 뒤에 있는 슬롯도 계산되지 않습니다. | `_MingMatcapStrength` |
| **MatCap / 메시 UV 투영** | 0이면 시선 기준 맷캡 투영, 1이면 메시 UV에 고정됩니다. 1로 두면 카메라를 돌려도 무늬가 표면에 붙어 있어 문신이나 페인팅 표현에 적합합니다. | `_MingMatcapProjectionBlend` |

## PBR 표면

금속도, 매끄러움, 스페큘러와 환경 반사를 설정합니다.

| 항목 | 설명 | 셰이더 프로퍼티 |
|---|---|---|
| **워크플로** | Metallic은 금속도에서 반사색을 만들고, Specular는 스페큘러 컬러를 직접 지정합니다. Specular를 고르면 금속도 슬라이더는 결과에 반영되지 않습니다. | `_WorkflowMode` |
| **패킹 마스크 사용** | 금속도·오클루전·매끄러움을 한 장의 텍스처에서 채널별로 읽습니다. 끄면 아래 채널·반전 설정이 모두 무시되고 금속도·매끄러움 슬라이더 값만 사용됩니다. | `_MingPbrMaskMapEnabled` |
| **PBR 패킹 마스크** | 기본 배치는 R=금속도, G=오클루전, A=매끄러움입니다. 텍스처의 채널 배치가 다르면 아래 채널 설정으로 맞출 수 있습니다. | `_MaskMap` |
| **금속도** | 0은 비금속, 1은 금속입니다. 패킹 마스크를 쓰면 마스크 값과 곱해지므로 마스크가 검은 곳은 금속이 되지 않습니다. | `_Metallic` |
| **매끄러움** | 높을수록 반사가 작고 선명해집니다. 툰 룩에서는 0.3~0.6이 무난하며, 1에 가까우면 하이라이트가 점처럼 작아집니다. | `_Smoothness` |
| **반사광 강도** | 스페큘러 반사의 세기입니다. 0으로 두면 직접 하이라이트와 환경 반사가 함께 사라지므로, 매끄러움과 반사 강도를 올려도 아무 변화가 없습니다. | `_MingPbrSpecularStrength` |
| **금속도 채널** | 패킹 마스크에서 금속도를 읽을 채널입니다. 패킹 마스크 사용이 꺼져 있으면 무시됩니다. | `_MingPbrMetallicChannel` |
| **금속도 반전** | 읽어온 금속도 값을 뒤집습니다. 비금속을 흰색으로 칠한 마스크를 그대로 쓸 때 사용합니다. | `_MingPbrMetallicInvert` |
| **PBR 오클루전 채널** | 패킹 마스크에서 반사 차폐를 읽을 채널입니다. 반사 오클루전이 0이면 이 설정은 결과에 전혀 반영되지 않습니다. | `_MingPbrOcclusionChannel` |
| **PBR 오클루전 반전** | 읽어온 반사 차폐 값을 뒤집습니다. 반사 오클루전이 0이면 무시됩니다. | `_MingPbrOcclusionInvert` |
| **반사 오클루전** | 패킹 마스크의 오클루전 채널로 환경 반사를 억제하는 양입니다. 0이면 채널·반전 설정이 있어도 결과에 나타나지 않습니다. | `_MingPbrOcclusionStrength` |
| **매끄러움 채널** | 패킹 마스크에서 매끄러움을 읽을 채널입니다. 패킹 마스크 사용이 꺼져 있으면 무시됩니다. | `_MingPbrSmoothnessChannel` |
| **러프니스로 사용 (반전)** | 매끄러움 대신 거칠기(러프니스) 맵을 넣었을 때 켭니다. 채널 값을 1에서 빼서 사용합니다. | `_MingPbrSmoothnessInvert` |
| **스페큘러 컬러 맵 (RGB) 사용** | 반사색을 텍스처로 지정합니다. 끄면 스페큘러 컬러 맵과 반전 설정이 무시됩니다. 워크플로가 Metallic이면 반사색은 금속도에서 만들어지므로 영향이 제한적입니다. | `_MingPbrSpecularMapEnabled` |
| **스페큘러 컬러 맵 반전** | 스페큘러 컬러 맵의 RGB를 반전합니다. 스페큘러 컬러 맵 사용이 꺼져 있으면 무시됩니다. | `_MingPbrSpecularInvert` |
| **직접 하이라이트 강도** | 광원에서 직접 오는 하이라이트의 세기입니다. 0이면 하이라이트 계산 자체를 건너뛰므로 매끄러움을 올려도 반짝임이 생기지 않습니다. | `_MingPbrDirectStrength` |
| **환경 반사 강도** | 리플렉션 프로브나 스카이박스가 비치는 양입니다. 씬에 프로브가 없으면 값을 올려도 거의 변화가 없습니다. | `_MingPbrReflectionStrength` |
| **그림자 안 표시량** | 그림자에 들어간 부분에서 PBR 하이라이트를 얼마나 남길지 정합니다. 0이면 그림자 안에서 완전히 사라지고, 1이면 그림자와 무관하게 그대로 보입니다. | `_MingPbrShadowVisibility` |
| **노멀맵 영향** | 0이면 메시 노멀만 쓰고, 1이면 쌓인 노멀맵을 그대로 반영합니다. 노멀맵이 없으면 값과 무관하게 결과가 같습니다. | `_MingPbrNormalInfluence` |

## 이미션

자체 발광 색상, 텍스처, 강도를 설정합니다.

| 항목 | 설명 | 셰이더 프로퍼티 |
|---|---|---|
| **이미션 강도** | 발광 밝기의 배수입니다. 씬에 블룸 후처리가 없으면 값을 올려도 번지지 않고 흰색으로만 포화됩니다. | `_EmissionIntensity` |
| **이미션 맵** | 스스로 빛나는 영역을 지정하는 텍스처입니다. 이미션 색상과 곱해지므로 색상이 검정이면 텍스처가 있어도 빛나지 않습니다. | `_EmissionMap` |
| **이미션 색상** | 발광 색입니다. HDR이므로 1을 넘겨 블룸을 유도할 수 있고, 검정으로 두면 이미션을 끈 것과 같습니다. | `_MingEmissionTint` |
