# 캐릭터 표현

**이 문서를 읽으면** 코 그림자와 앞머리 그림자를 통제하고, 얼굴만 몸과 다른 음영 규칙으로 만들 수 있습니다.

인스펙터의 **캐릭터 표현** 그룹 — `페이스 셰이딩` · `캐릭터 높이 그라데이션` 을 다룹니다. 전체 항목 목록은 [캐릭터 표현 레퍼런스](/reference/character)에 있습니다.

---

# 페이스 셰이딩

## 왜 얼굴만 따로 다루나

얼굴은 코와 눈두덩이 실제 굴곡을 갖고 있어서, 몸과 같은 형태 그림자 설정을 쓰면 **거의 항상 지저분해집니다.** 애니메이션 룩에서 얼굴이 깨끗해 보이는 이유는 얼굴의 음영 규칙이 몸과 다르기 때문입니다.

MingToon은 이걸 두 단계로 처리합니다.

1. **어디까지가 얼굴인가** — 얼굴 영역을 지정
2. **얼굴에 무엇을 다르게 할 것인가** — 노멀 누름, 경계 조정, 그림자 제거

## 1단계: 얼굴 영역 지정

머리와 몸이 한 머티리얼에 섞여 있으면 어디까지가 얼굴인지 알려 줘야 합니다.

### 방법 A — 얼굴 영역 마스크 (권장)

1. `얼굴 영역 마스크 사용`을 켭니다.
2. 마스크 텍스처를 넣습니다.
3. `마스크 채널 (RGBA)`에 가중치를 넣습니다. G 채널만 쓰려면 `(0, 1, 0, 0)`.
4. 얼굴이 검게 그려진 마스크라면 `마스크 반전`을 켭니다.

경계를 다듬는 항목:

- `마스크 강도` — **0이면 마스크를 무시하고 머티리얼 전체를 얼굴로 취급합니다.** 1이 마스크 그대로.
- `리맵 시작` / `리맵 끝` — 마스크의 회색 구간을 다시 펼칩니다. 시작을 올리면 얼굴 범위가 좁아지고, 끝을 낮추면 경계가 급격해집니다. **둘이 같으면 경계가 완전히 딱딱해집니다.**

### 방법 B — 프록시 구

마스크 텍스처 없이 가상의 구 안쪽을 얼굴로 봅니다.

1. `프록시 구를 얼굴 영역으로 사용`을 켭니다.
2. 씬 뷰의 **얼굴 프록시 도구**로 `프록시 구 중심`과 `프록시 구 반지름`을 맞춥니다. 숫자를 직접 입력하는 것보다 정확합니다.

:::caution 구가 너무 크면
목이나 손까지 얼굴로 처리됩니다. 화면에서 확인하며 줄이세요.
:::

:::note 둘 다 켰다면
`얼굴 영역 마스크 사용`이 우선하고 프록시 구 옵션은 무시됩니다.
:::

## 2단계: 코 그림자 없애기

얼굴 노멀을 눌러서 굴곡이 만드는 음영을 지웁니다.

1. `노멀 누름 정도`를 올립니다. **0이면 아래 항목이 전부 무시되고** 원래 메시 노멀이 그대로 쓰입니다.
2. `노멀 방식`을 고릅니다.

| 값 | 결과 |
|---|---|
| 0 | 얼굴 노멀을 **정면 방향으로 완전히 눌러** 코 그림자가 사라짐 |
| 1 | 프록시 구를 따라 완만한 곡면 |

`노멀 방식`을 1 쪽으로 쓰려면 프록시 구 중심·반지름이 맞아 있어야 합니다.

`얼굴 고정 방향`으로 얼굴이 기준으로 삼을 방향을 조정할 수 있습니다.

## 3단계: 얼굴 전용 음영 경계

- `얼굴 경계` — **몸통보다 낮게(마이너스 쪽으로) 두면 얼굴이 늦게 어두워져** 일러스트처럼 깨끗하게 유지됩니다. 가장 자주 쓰는 조정입니다.
- `얼굴 부드러움` — 얼굴 영역 경계의 번짐 폭.
- `기본 형태 그림자 제거` — 1이면 얼굴 영역의 형태 그림자를 **완전히 지웁니다.** 코·볼 그림자를 없애고 2D 그림자나 그림자 텍스처로만 얼굴 음영을 만들 때 씁니다.

:::caution 형태 그림자 섹션이 꺼져 있으면
`얼굴 경계`와 `얼굴 부드러움`이 반영되지 않습니다.
:::

## 4단계: 앞머리 그림자

두 방향 중 하나를 고르세요.

### 실제 그림자를 쓴다

기본 상태입니다. 위치가 어긋나면 `실제 그림자 캐스터 오프셋`으로 얼굴의 그림자 캐스터를 앞뒤로 밀어 미세 조정합니다.

### 2D 그림자로만 그린다

1. `얼굴 자체 캐스트 사용`을 **끕니다.** 얼굴 메시가 실시간 그림자를 드리우지 않게 됩니다.
2. 이마 그림자를 [2D 그림자](/guides/depth-effects)나 그림자 텍스처로 그립니다.

이쪽이 애니메이션 룩에 가깝고, 조명이 바뀌어도 앞머리 그림자 모양이 흔들리지 않습니다.

## 얼굴에 실시간 그림자 얼룩이 생길 때

`그림자 투영` 섹션의 `얼굴 캐스트 안정화`에서 다룹니다. → [조명과 그림자](/guides/light-and-shadow#얼굴의-스치는-그림자)

# 캐릭터 높이 그라데이션

캐릭터 **루트를 기준으로 한 높이를 UV4에 구워 두고**, 그 높이로 색을 물들입니다. 발밑을 어둡게 깔거나 옷자락에 색을 올릴 때 씁니다.

:::danger UV4.x에 높이가 구워져 있어야 합니다
캐릭터 **전체** 루트 기준 높이가 UV4.x에 있어야 동작합니다. 메시 단위가 아니라 캐릭터 단위입니다. 굽는 도구가 함께 제공됩니다.
:::

| 항목 | 하는 일 |
|---|---|
| `아래쪽 색` / `위쪽 색` | 두 색 |
| `그라데이션 방향` | 위→아래로 바꾸면 두 색의 위치가 서로 뒤바뀝니다 |
| `경계 높이` | 두 색이 절반씩 섞이는 높이 |
| `경계 부드러움` | 경계를 기준으로 퍼지는 폭. **0이면 딱 끊깁니다** |
| `곡선 지수` | 전환 곡선 |
| `영향도` | 전체 적용량 |

:::tip 흔한 쓰임
`위쪽 색`을 흰색(변화 없음)으로 두고 `아래쪽 색`만 어둡게 하면, 발밑으로 갈수록 자연스럽게 가라앉는 접지감이 생깁니다.
:::
