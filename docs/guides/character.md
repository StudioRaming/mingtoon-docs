# 캐릭터 표현

**이 문서를 읽으면** 코 그림자와 앞머리 그림자를 통제하고, 얼굴만 몸과 다른 음영 규칙으로 만들 수 있습니다.

인스펙터의 **캐릭터 표현** 그룹 — `페이스 셰이딩` · `캐릭터 높이 그라데이션` 을 다룹니다. 전체 항목 목록은 [캐릭터 표현 레퍼런스](/reference/character)에 있습니다.

---

## 페이스 셰이딩 {#페이스-셰이딩}

### 왜 얼굴만 따로 다루나

얼굴은 코와 눈두덩이 실제 굴곡을 갖고 있어서, 몸과 같은 형태 그림자 설정을 쓰면 **거의 항상 지저분해집니다.** 애니메이션 룩에서 얼굴이 깨끗해 보이는 이유는 얼굴의 음영 규칙이 몸과 다르기 때문입니다.

MingToon은 이걸 두 단계로 처리합니다.

1. **어디까지가 얼굴인가** — 얼굴 영역을 지정
2. **얼굴에 무엇을 다르게 할 것인가** — 프록시 노멀, 경계 조정, 그림자 제거

<!-- SCREENSHOT: 페이스 셰이딩 적용 전 / 후 비교 -->

### 1단계: 얼굴 영역 지정

머리와 몸이 한 머티리얼에 섞여 있으면 어디까지가 얼굴인지 알려 줘야 합니다.

#### 방법 A — 얼굴 영역 마스크 (권장) {#방법-a--얼굴-영역-마스크-권장}

1. `얼굴 영역 마스크 사용`을 켭니다.
2. 마스크 텍스처를 넣습니다.
3. `마스크 채널 (RGBA)`에 가중치를 넣습니다. G 채널만 쓰려면 `(0, 1, 0, 0)`.
4. 얼굴이 검게 그려진 마스크라면 `마스크 반전`을 켭니다.

경계를 다듬는 항목:

- `마스크 강도` — **0이면 마스크를 무시하고 머티리얼 전체를 얼굴로 취급합니다.** 1이 마스크 그대로.
- `리맵 시작` / `리맵 끝` — 마스크의 회색 구간을 다시 펼칩니다. 시작을 올리면 얼굴 범위가 좁아지고, 끝을 낮추면 경계가 급격해집니다. **둘이 같으면 경계가 완전히 딱딱해집니다.**

### 얼굴 영역을 SceneView에서 칠하기 {#얼굴-영역을-sceneview에서-칠하기}

마스크 텍스처를 만들지 않고 Mesh의 버텍스 값으로 얼굴 영역을 지정할 수 있습니다.

1. `버텍스 페인트로 얼굴 영역 지정`을 켭니다.
2. `얼굴 영역 페인트 시작`을 누릅니다.
3. SceneView에서 Paint로 얼굴을 칠하고 Shift를 누른 채 칠해 지웁니다.
4. 경계는 Harden 또는 Smooth로 정리하고, 한 삼각형을 즉시 채우려면 Hard Face를 사용합니다.
5. `편집 메쉬만 보기`로 대상 Renderer만 격리하고 X 대칭이나 `L`/`Shift+L` 연결 섬 채우기를 필요에 따라 사용합니다.
6. 종료할 때 `저장`·`버리기`·`취소` 중 하나를 고릅니다.

:::caution[텍스처 얼굴 마스크가 우선합니다]
`얼굴 영역 마스크 사용`이 켜져 있으면 버텍스 페인트가 무시됩니다. 페인트를 사용할 때는 텍스처 마스크 토글을 끄세요. 마스크가 켜진 채 텍스처까지 비어 있으면 재질 전체가 얼굴로 처리됩니다.
:::

칠한 채널은 아웃라인 압력 채널과 분리할 수 있어 한 Mesh에서 두 기능을 함께 사용할 수 있습니다.

#### 방법 B — 프록시 볼륨 {#방법-b--프록시-구}

마스크 텍스처 없이 구·원통·캡슐 안쪽을 얼굴로 봅니다.

1. `프록시를 얼굴 영역으로 사용`을 켭니다.
2. `프록시 모양`에서 Sphere / Cylinder / Capsule을 고릅니다.
3. SceneView의 얼굴 프록시 도구로 중심·반지름·축을 맞추고, Capsule은 높이도 조정합니다.
4. `프록시 경계 부드러움`으로 목과 헤어라인의 전환 폭을 맞춥니다.

:::caution[볼륨이 너무 크면]
목이나 손까지 얼굴로 처리됩니다. 여러 Face 슬롯이 한 Renderer를 공유한다면 프록시 모양·강도·런타임 얼굴 프레임을 서로 같게 맞추세요. 서로 다르면 업로드 베이크는 안전하게 Live 경로를 유지합니다.
:::

:::note[마스크 우선순위]
텍스처 얼굴 마스크 → 버텍스 페인트 → 프록시 볼륨 → 재질 전체 순서입니다. 텍스처 마스크 강도가 0이면 하위 마스크로 내려가지 않고 재질 전체를 얼굴로 처리합니다.
:::

### 2단계: 코 그림자 없애기 {#2단계-코-그림자-없애기}

얼굴 노멀을 프록시 곡률로 바꿔 코·눈두덩의 지저분한 음영을 정리합니다.

1. `프록시 노멀 강도`를 올립니다. 0이면 원래 메시 노멀, 1이면 프록시 목표 노멀입니다.
2. Sphere / Cylinder / Capsule을 고르고 중심·축·높이를 맞춥니다.
3. 반지름으로 곡률을 정합니다. 작을수록 더 둥글고, 클수록 더 완만합니다.
4. `얼굴 노멀 정렬`과 고정 방향으로 정면·위쪽 축을 맞춥니다.
5. 노멀맵 때문에 큰 명암 경계가 씬의 노멀 선과 다르면 `그림자 노멀맵 영향`을 낮춥니다.

0.1.7에서는 이 계산이 **편집 중 실시간**입니다. 프록시나 강도를 바꾸면 별도 메시 베이크 없이 바로 보입니다. SceneView 왼쪽 위 패널에서 노멀 선과 프록시 볼륨을 각각 켜고 끌 수 있고, 선 길이·밀도는 표시만 바꾸며 실제 조명에는 영향을 주지 않습니다. VRChat 업로드 때는 업로드 복사본에만 UV7 payload를 자동으로 만들고, 씬의 원본 Mesh와 재질은 Live 상태로 복원합니다.

텍스처 얼굴 영역 마스크를 쓰는 경우 SceneView 노멀 선도 UV0, Tiling/Offset, HSVG, 채널, 반전과 리맵을 반영합니다. GPU 샘플이나 UV를 읽을 수 없으면 실제 영역과 다른 선을 대신 그리지 않고 노멀 선을 숨긴 뒤 패널에 이유를 표시합니다.

:::caution[프록시를 움직여도 반응이 없다면]
예전 버전에서 얼굴 노멀 UV7을 구운 재질일 수 있습니다. 밍툰 매니저의 `얼굴 노멀 실시간으로 되돌리기`를 실행하세요. 텍스처 얼굴 영역 마스크는 픽셀 샘플이 필요하므로 업로드에서도 Live 경로를 유지합니다.
:::

### 3단계: 얼굴 전용 음영 경계 {#3단계-얼굴-전용-음영-경계}

- `얼굴 경계` — 범위 0~1, 기본값 0.25입니다. **0에 가까울수록 얼굴이 늦게 어두워지고**, 1에 가까울수록 일찍 어두워집니다. 가장 자주 쓰는 조정입니다.
- `얼굴 부드러움` — 얼굴 영역 경계의 번짐 폭.
- `기본 형태 그림자 제거` — 1이면 얼굴 영역의 형태 그림자를 **완전히 지웁니다.** 코·볼 그림자를 없애고 2D 그림자나 그림자 텍스처로만 얼굴 음영을 만들 때 씁니다.

:::caution[형태 그림자 섹션이 꺼져 있으면]
`얼굴 경계`와 `얼굴 부드러움`이 반영되지 않습니다.
:::

### 4단계: 앞머리 그림자 {#4단계-앞머리-그림자}

앞머리와 소품이 얼굴에 만드는 그림자를 **어떤 방식으로 그릴지** 고르는 단계입니다. 페이스 셰이딩 맨 위의 `얼굴 그림자 방식` 그룹에 `그림자 방식` 한 줄로 들어 있습니다.

| 값 | 결과 | 쓰는 곳 |
|---|---|---|
| **몸과 동일한 리얼 그림자** | 씬의 실시간 그림자를 그대로 받습니다 | 얼굴만 따로 다루고 싶지 않을 때 |
| **부드러운 2D 그림자 (얼굴 보정)** | 얼굴에서 [2D 그림자](/guides/depth-effects#2d-그림자)가 부드럽게 지도록 보조 밀기를 함께 켭니다 | 애니메이션 룩. 조명이 바뀌어도 앞머리 그림자 모양이 흔들리지 않습니다 |
| **커스텀** | 관련 값을 손으로 맞춰 둔 상태 | 위 두 조합에서 벗어나면 자동으로 여기로 표시됩니다 |

:::note[한 줄이 여러 값을 함께 씁니다]
이 결정에 필요한 값은 원래 두 탭에 흩어져 있었습니다. 모드를 고르면 `얼굴 자체 캐스트 사용`과 깊이 탭의 얼굴 보조 밀기가 **한 번에 함께** 설정됩니다. 되돌리기 한 단위이며, 선택한 재질 전부에 적용됩니다.

값을 직접 만지면 셀렉터 표시가 `커스텀`으로 바뀝니다. 잘못된 상태라는 뜻이 아니라, 프리셋 조합이 아니라는 표시입니다.
:::

`부드러운 2D 그림자 (얼굴 보정)`는 [카메라 깊이](/guides/depth-effects#플랫폼별-깊이-확보)가 있어야 보입니다. 깊이가 없는 화면에서는 얼굴에 아무 그림자도 남지 않으므로, VRChat 일반 화면을 기준으로 잡는다면 그림자 텍스처를 함께 준비해 두세요.

실시간 그림자의 위치가 얼굴과 어긋나면 `실제 그림자 캐스터 오프셋`으로 얼굴 영역의 그림자 캐스터를 노멀 방향으로 밀어 미세 조정합니다.

### 얼굴 캐스트 조정

0.1.7에서 작동하지 않던 `얼굴 균일 캐스트`와 `얼굴 캐스트 안정화`는 제거됐습니다. 앞머리 그림자는 `그림자 방식`, `실제 그림자 캐스터 오프셋`, 2D 그림자 얼굴 보조와 Face SDF로 조정하세요. → [조명과 그림자](/guides/light-and-shadow#얼굴의-스치는-그림자)

### 얼굴 SDF — 스크립트 없이 쓰기

별도 제품인 Face SDF Studio가 설치돼 있으면 Packed RGBA 4방향 또는 Single Channel 얼굴 SDF를 만들 수 있습니다. Base UV만으로도 사용할 수 있고, `Baked Front UV7`을 선택하면 정면 투영 좌표를 고정할 수 있습니다. → [얼굴 SDF와 Face SDF Studio](/guides/face-sdf)

:::tip[페이스 셰이딩부터 맞추세요]
SDF는 그림자가 덮이는 순서를 바꾸는 기능입니다. 얼굴 영역, 프록시 노멀과 `얼굴 경계`가 어긋난 상태를 대신 고쳐 주지는 않습니다.
:::

## 캐릭터 높이 그라데이션 {#캐릭터-높이-그라데이션}

캐릭터 **루트를 기준으로 한 높이를 UV4에 구워 두고**, 그 높이로 색을 물들입니다. 발밑을 어둡게 깔거나 옷자락에 색을 올릴 때 씁니다.

:::danger[먼저 UV4를 구워야 동작합니다]
캐릭터 **전체** 루트 기준 높이가 UV4.x에 있어야 합니다. 메시 단위가 아니라 캐릭터 단위입니다. → [메시 UV 베이크 — 캐릭터 높이 (UV4)](/guides/mesh-bakes#캐릭터-높이-uv4)
:::

| 항목 | 하는 일 |
|---|---|
| `아래쪽 색` / `위쪽 색` | 두 색 |
| `그라데이션 방향` | 위→아래로 바꾸면 두 색의 위치가 서로 뒤바뀝니다 |
| `경계 높이` | 두 색이 절반씩 섞이는 높이 |
| `경계 부드러움` | 경계를 기준으로 퍼지는 폭. **0이면 딱 끊깁니다** |
| `곡선 지수` | 전환 곡선 |
| `영향도` | 전체 적용량 |

:::tip[흔한 쓰임]
`위쪽 색`을 흰색(변화 없음)으로 두고 `아래쪽 색`만 어둡게 하면, 발밑으로 갈수록 자연스럽게 가라앉는 접지감이 생깁니다.
:::
