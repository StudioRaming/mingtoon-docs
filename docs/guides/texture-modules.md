# 텍스처 슬롯 공통 UI

> 이 페이지는 찾아보는 문서입니다. 읽는 순서는 정해져 있지 않습니다.
> MingToon의 모든 텍스처 슬롯이 같은 모양을 씁니다. 여기서 한 번만 익히면 됩니다.

한 슬롯은 위에서 아래로 네 덩어리입니다.

1. 맵 행 — 텍스처, 색상, 타일링과 오프셋
2. **텍스처 세부 설정** — 채널과 색 보정
3. **UV·움직임** — 어느 UV를 읽고 어떻게 움직일지
4. 마스크 행과 **마스크 세부 설정**

## 맵 행

| 인스펙터 라벨 | 형식 | 하는 일 |
|---|---|---|
| **색상** | 색상 | 이 맵에 곱하는 색 |
| **미할당** | — | 맵이 비어 있다는 표시 |
| **텍스처 비우기** | — | 이 슬롯의 맵을 지웁니다 |
| **UV · 타일링 · 오프셋** | — | 이 맵만의 UV 변환을 펼칩니다 |

:::caution[맵의 타일링과 마스크의 타일링은 따로입니다]
둘은 자동으로 같이 바뀌지 않습니다.
표면 맵을 30번 반복하면서 마스크는 한 번만 놓을 수 있습니다.
:::

## 텍스처 세부 설정

### 채널 소스 {#채널-소스}

| 인스펙터 라벨 | 형식 | 값 | 하는 일 |
|---|---|---|---|
| **채널 소스** | 선택 | R / G / B / A | 여러 정보를 한 장에 넣었을 때 하나만 읽습니다 |
| **소스 색 반전** | 켜기/끄기 | — | 읽어온 색을 뒤집습니다 |
| **HSVG 이후에 틴트 적용** | 켜기/끄기 | — | 색상을 색 보정 앞뒤 어디서 곱할지 정합니다 |
| **그레이스케일로 사용** | 켜기/끄기 | — | 이 맷캡에서 채도 조정을 쓰지 않습니다 |

### HSVG {#hsvg}

| 인스펙터 라벨 | 형식 | 기본값 | 하는 일 |
|---|---|---:|---|
| **색조** | 실수 | 0 | 색상환에서 색을 돌립니다 |
| **채도** | 실수 | 1 | 0이면 흑백, 1보다 크면 과채도입니다 |
| **명도** | 실수 | 1 | 전체 밝기입니다 |
| **감마** | 실수 | 1 | 중간 톤의 밝기를 조정합니다 |

네 값이 기본값이면 원본 색이 그대로 나옵니다.
결과가 이상하면 0 · 1 · 1 · 1로 되돌려 원본과 비교하세요.

## UV·움직임 {#uv-router}

| 인스펙터 라벨 | 형식 | 값 또는 기본값 | 하는 일 |
|---|---|---|---|
| **UV 채널** | 선택 | UV0 (기본) / UV1 / UV2 / UV3 | 메시의 어느 UV 세트를 읽을지 |
| **스크롤 속도 (X/Y)** | 실수 | 0, 0 | 초당 몇 타일씩 흐를지 |
| **기본 회전 (°)** | 실수 | 0 | UV 중심을 기준으로 돌립니다 |
| **회전 속도 (°/초)** | 실수 | 0 | 초당 회전 각도입니다 |

`UV1`~`UV3`은 제작자가 추가 UV를 넣었다고 안내한 경우에만 고르세요.

**스프라이트 시트·아틀라스** 를 펼치면 격자 텍스처를 재생할 수 있습니다.
**가로·세로 칸 수** · **프레임·재생 수** · **재생 속도 (FPS)** 를 정합니다.
**프레임·재생 수** 가 0이면 아틀라스를 쓰지 않습니다.

**데칼·좌우 복사** 를 펼치면 로고를 한 자리에 붙일 수 있습니다.
먼저 **데칼로 사용** 을 켜야 나머지 항목이 살아납니다.
**복사본 좌우 뒤집기** 는 **반대쪽에도 복사** 를 먼저 켜야 동작합니다.

## 마스크 세부 설정 {#마스크-세부-설정}

| 인스펙터 라벨 | 형식 | 값 또는 기본값 | 하는 일 |
|---|---|---|---|
| **마스크 맵** | 텍스처 | 비어 있음 | 비우면 재질 전체에 적용됩니다 |
| **마스크 채널** | 선택 | R / G / B / A / 휘도 | 마스크에서 읽을 채널 |
| **반전** | 켜기/끄기 | 꺼짐 | 적용 범위를 반대로 만듭니다 |
| **경계 부드러움** | 실수 | 0 | 마스크 경계를 번지게 합니다 |

### 리맵을 쓰는 법 {#리맵을-쓰는-법}

**리맵 시작** 이하의 값은 0이 됩니다. 올리면 적용 범위가 좁아집니다.
**리맵 끝** 이상의 값은 1이 됩니다. 내리면 경계가 급해집니다.
두 값을 같게 두면 경계가 완전히 딱딱해집니다.

**그라데이션 모드** 를 켜면 텍스처 없이 방향 그라데이션을 씁니다.
꺼져 있는 동안 **각도** · **시작** · **끝** · **중심 (UV)** 은 무시됩니다.

## 레이어 슬롯 {#레이어-수}

| 모듈 | 셰이더 상한 |
|---|---:|
| 추가 텍스처 | 10 |
| 노말맵 | 5 |
| 매트캡 | 5 |

레이어 수 목록은 처음에 0~2까지만 보입니다.
더 쓰려면 **레이어 더 쓰기 (최대 N)** 버튼을 누르세요.
N은 모듈마다 다릅니다. 표면 스택 10, 노멀 5, 맷캡 5입니다.
이 표시 제한은 셰이더의 실제 상한을 줄이지 않습니다.

:::caution[레이어 순서는 결과를 바꿉니다]
합성은 아래에서 위로 차례대로 쌓입니다.
순서를 바꾼 뒤에는 각 슬롯의 세기를 다시 확인하세요.
:::

## 값 복사 / 붙여넣기 {#값-복사--붙여넣기}

프로퍼티나 레이어 머리글을 우클릭하면 복사 메뉴가 나옵니다.
값 하나, 레이어 하나, 탭 하나 단위로 복사할 수 있습니다.

붙여넣기는 호환되는 항목만 적용하고 한 번의 Undo로 기록됩니다.
맷캡 값을 노멀 레이어에 붙이는 것처럼 맞지 않는 항목은 건너뜁니다.
적용한 수와 건너뛴 수는 Console 로그에 나옵니다.

## 보이지 않을 때 확인

1. 맵 칸이 비어 있지 않은지 봅니다.
2. 그 모듈의 레이어 수와 세기가 0이 아닌지 봅니다.
3. 맵과 마스크의 타일링이 의도한 UV와 맞는지 봅니다.
4. **데칼로 사용** 같은 상위 스위치가 켜져 있는지 봅니다.
5. HSVG를 기본값으로 되돌려 비교합니다.
