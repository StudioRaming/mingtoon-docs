# 텍스처 슬롯 공통 UI

**용도:** MingToon의 베이스 맵, 마스크, 노멀, 맷캡, 이미션 슬롯에서 반복되는 조정 순서를 익힙니다. 처음에는 재질을 선택하고 슬롯의 맵과 **타일링/오프셋**부터 확인한 다음, 필요한 경우 **UV Router**와 세부 설정을 펼치세요.

텍스처 슬롯은 다음 순서로 읽습니다.

- 맵 행: 텍스처, 틴트(지원 슬롯), **Tiling / Offset**
- 선택 사항: **UV Router**
- 세부 설정: 채널, 반전, HSVG, 틴트 적용 순서
- 선택 사항: 마스크 맵의 Tiling / Offset, UV Router, 채널·리맵·페더·그라데이션

## 텍스처 세부 설정

### 채널 소스 {#채널-소스}

맵에서 읽을 채널을 고릅니다.

| 값 | 결과 |
|---|---|
| **Full RGBA** | 색상 전체를 읽습니다 |
| **R / G / B / A** | 해당 채널 하나만 읽습니다 |

여러 값을 한 텍스처에 패킹할 때 채널을 바꿉니다. 마스크 슬롯에는 **Luminance**가 추가되어 RGB의 밝기를 마스크 값으로 만듭니다.

### 소스 색 반전

읽은 값을 반전합니다. 검은 곳에서 효과가 필요하거나, 지울 영역을 흰색으로 그린 마스크를 재사용할 때 켭니다.

### HSVG {#hsvg}

| 항목 | 범위 | 중립값 | 조정 결과 |
|---|---:|---:|---|
| **Hue** | -1 ~ 1 | 0 | 색상환을 회전합니다 |
| **Saturation** | 0 ~ 2 | 1 | 색의 선명도를 줄이거나 높입니다 |
| **Value** | 0 ~ 2 | 1 | 밝기를 줄이거나 높입니다 |
| **Gamma** | 0.1 ~ 3 | 1 | 중간 톤의 대비를 바꿉니다 |

중립값이면 원본 색이 유지됩니다. 예를 들어 눈 텍스처의 **Hue**만 조금 바꾸면 파일을 다시 굽지 않고 색조를 바꿀 수 있습니다. 강도나 색이 예상과 다르면 HSVG 값을 0/1/1/1로 되돌려 원본과 비교하세요.

틴트가 있는 슬롯의 **Apply Tint After HSVG**는 틴트를 HSVG 전후 어느 단계에서 곱할지 정합니다. 같은 틴트라도 순서가 다르면 결과가 달라집니다.

## 타일링, 오프셋, UV Router {#uv-router}

맵 행 아래의 **Tiling / Offset**은 그 맵 자체의 UV 변환입니다. 마스크에도 별도의 Tiling / Offset이 있으므로 둘은 자동으로 같이 바뀌지 않습니다. 표면 맵을 30배 반복하면서 마스크는 UV 전체에 한 번만 놓는 구성이 가능합니다.

**UV Router**가 있는 슬롯에서는 다음을 펼칠 수 있습니다.

- **UV Source:** UV0, UV1, UV2, UV3
- **Scroll:** X/Y 이동량
- **Rotation / Rotation Speed:** UI는 도 단위로 표시됩니다
- **Atlas:** 그리드 최소 1, 프레임 수 최소 0, FPS와 프레임 스케일·중심 블렌드
- **Decal:** 먼저 **Is Decal**을 켜야 좌우·복사·미러 옵션이 활성화됩니다. **Should Copy**가 꺼져 있으면 Flip Copy가 비활성화됩니다.

이 항목이 안 보이면 해당 셰이더 슬롯에 UV Router 프로퍼티가 없는 것입니다. 일반 UV0 슬롯에서 고급 행을 찾느라 맵이 사라진 것으로 판단하지 마세요.

## 마스크 세부 설정 {#마스크-세부-설정}

### 리맵을 쓰는 법 {#리맵을-쓰는-법}

마스크는 효과가 적용되는 범위를 제한합니다. 마스크 행에서도 맵 자체의 Tiling / Offset과 UV Router를 먼저 정합니다. 세부 설정에는 다음이 있습니다.

| 항목 | 효과 |
|---|---|
| **Mask Channel** | R/G/B/A 또는 **Luminance**로 읽을 채널을 바꿉니다 |
| **Invert** | 마스크의 흑백을 뒤집습니다 |
| **Remap Start / End** | 회색 입력 범위를 다시 펼쳐 적용 범위를 조정합니다 |
| **Boundary Blur** | 경계 전이를 부드럽게 합니다 |
| **Gradient Mode** | 그라데이션을 켭니다. 켜야 Angle, Start, End, Center(UV)가 표시됩니다 |
| **Alpha Scale / Offset / Blend Mode** | 지원되는 알파 마스크에서 최종 마스크 값을 조합합니다 |

리맵은 먼저 **Start**를 올려 좁아지는지, **End**를 내려 경계가 선명해지는지 확인하세요. 두 값을 같게 하면 하드 컷에 가까워집니다. 그라데이션 모드가 꺼져 있으면 방향·중심 항목이 보이지 않는 것이 정상입니다. 알파 블렌드 모드는 **Multiply, Replace, Add, Subtract** 중에서 고릅니다.

## 레이어 슬롯 {#레이어-수}

텍스처 스택은 최대 10개, 노멀 레이어는 최대 5개, 맷캡 레이어는 최대 5개입니다. **Active Layers**가 0이면 해당 모듈은 계산하지 않습니다. 맵을 넣었는데 보이지 않으면 먼저 Active Layers가 그 슬롯 번호 이상인지 확인하세요. 레이어 헤더는 첫 슬롯이 기본으로 열리고, **Up / Down**으로 순서를 바꿉니다.

인스펙터 팝업은 처음에 최대 2개 레이어만 보여 줄 수 있습니다. 실제 재질이 3개 이상을 이미 사용하거나 **Show up to N layers** 버튼을 누르면 각 모듈의 실제 최대치까지 선택할 수 있습니다. 이 UI 표시 제한은 셰이더의 하드 최대치를 바꾸지 않습니다.

:::caution[레이어 순서는 결과를 바꿉니다]
Multiply 위에 Normal을 두는 것과 Normal 위에 Multiply를 두는 것은 다른 합성입니다. 순서를 바꾼 뒤에는 각 슬롯의 맵과 불투명도·강도를 다시 확인하세요.
:::

## 값 복사 / 붙여넣기 {#값-복사--붙여넣기}

속성이나 레이어 헤더를 우클릭하면 값, 레이어, 탭 단위의 복사 메뉴가 나옵니다. 붙여넣기는 호환되는 프로퍼티만 적용하고, 한 번의 Undo 단위로 기록됩니다. 맷캡 레이어 값을 노멀 레이어에 붙이거나 색을 숫자 슬라이더에 붙이는 것처럼 타입·모듈이 맞지 않는 항목은 건너뜁니다.

붙여넣기 결과의 적용/건너뜀 수를 Console 로그에서 확인할 수 있습니다. 메뉴가 없거나 기대한 항목이 안 보이면 현재 행이 검색으로 숨겨졌는지, 해당 슬롯에 프로퍼티가 있는지, 그리고 선택한 레이어 종류가 같은지 확인하세요.

## 보이지 않을 때 확인

1. 맵 오브젝트 필드가 비어 있지 않은지 확인합니다.
2. 해당 슬롯의 Active Layers, 강도 또는 불투명도가 0인지 확인합니다.
3. 맵과 마스크의 Tiling / Offset이 의도한 UV와 맞는지 확인합니다.
4. UV Router·Atlas·Decal 옵션의 게이트가 열려 있는지 확인합니다.
5. HSVG를 중립값으로, 마스크 채널을 실제로 칠한 채널로 되돌려 비교합니다.
