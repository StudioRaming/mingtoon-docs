# 여러 재질 한 번에

**용도:** 아바타의 여러 MingToon 재질에 같은 값을 적용하거나, 룩 프리셋을 저장·재사용합니다. 첫 조작은 인스펙터 **일괄 설정**에서 범위와 필터를 고르고 **미리보기 머티리얼 수**를 확인하는 것입니다.

수단은 세 가지입니다.

| 수단 | 적합한 작업 |
|---|---|
| **일괄 설정 패널** | 선택·매니저·씬 범위의 공통 값 일괄 변경 |
| **머티리얼 프리셋** | 값 중심의 룩 저장·재사용 |
| **복사 / 붙여넣기** | 한 속성·레이어·탭을 호환 대상에 이동 |

## 일괄 설정 패널 {#일괄-설정-패널}

인스펙터의 **보기**를 **일괄 설정**으로 바꾸면 패널이 열립니다. 현재 선택한 범위에서 중복을 제거한 MingToon 머티리얼을 먼저 찾고, 공통 프로퍼티만 표시합니다.

### 범위와 필터

| 항목 | 선택지와 의미 |
|---|---|
| **범위** | 선택한 오브젝트, 밍툰 매니저, 활성 씬, 불러온 모든 씬 |
| **비활성 오브젝트 포함** | 꺼진 의상·오브젝트도 검색합니다. 기본값은 켜짐입니다 |
| **머티리얼 종류** | 전체, 일반, 얼굴 |
| **표면 종류** | 전체, 불투명, 컷아웃, 투명 |

**밍툰 매니저** 범위에서는 **캐릭터 루트**에 지정한 Manager 아래의 렌더러를 검색합니다. 아바타나 의상을 편집할 때는 항상 아바타 루트의 Manager를 선택하세요. 얼굴 필터는 머티리얼 태그 **MingToonSurfaceKind=Face**, 일반 필터는 그 태그가 아닌 재질을 기준으로 합니다. 표면 필터는 _MingSurfaceMode 0=Opaque, 1=Cutout, 2 이상=Transparent로 분류합니다.

### 미리보기와 적용 {#적용}

1. 범위, 비활성 포함, 두 필터를 정합니다.
2. **미리보기 머티리얼 수**를 확인합니다.
3. 의상·씬을 바꿨다면 **새로고침**을 누릅니다.
4. 필요하면 **선택**으로 검색 결과를 Unity 선택 상태에 넣습니다.
5. **공통 외형**의 그룹을 열고 값을 바꿉니다.

대상은 MingToon 머티리얼만 남고 중복은 한 번만 들어갑니다. 여러 재질에 적용한 값은 한 번의 Undo 단위입니다. 각 행은 선택 항목 중 해당 프로퍼티를 가진 재질에만 기록하므로, 같은 행이 일부 재질에만 적용될 수 있습니다.

### 공통 외형 그룹

현재 패널에는 **베이스 조명**, **그림자**, **스타일 효과**, **아웃라인 이미션** 그룹이 있습니다. 예를 들어 베이스 조명에는 전체 효과, 베이스 색, **Base Map Opacity**, 출력 강도·틴트·채도, 색 보존, 조명 색상 영향, 밝기 범위, 노멀 강도, 매끄러움이 포함될 수 있습니다. 그림자·스타일·아웃라인·이미션 항목도 대상 셰이더가 프로퍼티를 선언한 경우에만 표시됩니다.

**프로퍼티 검색**은 프로퍼티 이름, 표시 라벨, 등록된 별칭을 검색합니다. 검색 중에는 해당 그룹이 자동으로 펼쳐집니다. 결과가 없으면 검색어를 지우거나 선택 범위를 확인하세요.

## 머티리얼 프리셋 {#머티리얼-프리셋}

프리셋 패널의 **사용자 프리셋 저장**은 현재 MingToon 재질의 룩 값을 에셋으로 저장합니다. 프리셋을 적용할 때는 먼저 드롭다운에서 **Factory** 또는 **User** 프리셋을 고르고 **Apply**를 누르세요. 선택한 대상이 여러 개면 덮어쓰기 전에 대상 수와 적용 범위를 확인합니다.

기본 캡처·적용은 값 중심입니다. 부동 소수점, 색상, 현재 셰이더가 룩으로 분류한 벡터가 저장되며 재질의 렌더 큐·재질 식별자 같은 상태는 룩 프리셋이 쓰지 않습니다. 기본 UI의 프리셋은 대상 텍스처를 유지합니다. 맵을 포함하도록 명시한 캡처 경로만 비어 있지 않은 텍스처와 그 Tiling / Offset을 저장·적용합니다.

패널의 **캡처 범위**를 펼치면 전체 재질 또는 선택한 탭만 저장할 수 있습니다. 탭 범위를 비우면 전체 재질 범위입니다. **Shadow Color**, **Fresnel** 체크박스는 적용 시 해당 값을 포함할지 결정합니다. 프리셋을 고르는 것과 Apply를 누르는 것은 별도 동작이며, 적용은 Undo로 되돌릴 수 있습니다.

## 복사 / 붙여넣기

프로퍼티·레이어 헤더를 우클릭하면 값, 레이어, 탭 단위 메뉴가 나옵니다. 호환되는 프로퍼티만 적용하며 다른 모듈의 레이어나 맞지 않는 값 타입은 건너뜁니다. 적용·건너뜀 수는 Console 로그에서 확인하세요. 자세한 메뉴 목록은 [텍스처 슬롯 공통 UI](/guides/texture-modules#값-복사--붙여넣기)를 참고하세요.

## 보이지 않거나 대상이 없을 때

- 미리보기 수가 0이면 범위, 아바타 루트 Manager, 비활성 포함, 얼굴·표면 필터를 순서대로 확인합니다.
- 행이 보이지 않으면 선택한 재질 중 하나라도 해당 프로퍼티를 선언하는지 확인합니다.
- 변경이 보이지 않으면 행의 혼합 값 표시, 해당 모듈의 사용 토글, 레이어 수와 강도를 확인합니다.
- 프리셋이 적용되지 않으면 선택한 프리셋과 대상 수, 스키마 오류 대화상자를 확인합니다.
