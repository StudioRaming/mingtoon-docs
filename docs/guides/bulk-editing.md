# 여러 재질 한 번에

**이 문서를 읽으면** 아바타 전체의 룩을 한 번의 조작으로 맞추고, 실수로 값을 뭉개는 사고를 피할 수 있습니다.

수단이 셋입니다.

| 수단 | 쓰는 곳 |
|---|---|
| **일괄 설정 패널** | 아바타 전체의 공통 값을 한 번에. 되돌리기도 한 번 |
| **머티리얼 프리셋** | 룩 전체를 저장·재사용 |
| **복사 / 붙여넣기** | 섹션·레이어·값 단위로 옮기기 |

---

## 일괄 설정 패널 {#일괄-설정-패널}

인스펙터 **보기**를 `일괄 설정`으로 바꾸면 나옵니다.

> 중복을 제거한 MingToon 머티리얼을 미리 확인하고, 프리셋과 공통 외형 값을 **한 번의 실행 취소 단위**로 적용합니다.

<!-- SCREENSHOT: 일괄 설정 패널 -->

### 1. 범위 정하기

| 범위 | 대상 |
|---|---|
| `선택한 오브젝트` | 지금 선택한 것 아래 |
| `밍툰 매니저` | 밍툰 매니저가 관리하는 범위 |
| `활성 씬` | 현재 씬 전체 |
| `불러온 모든 씬` | 열려 있는 모든 씬 |

`비활성 오브젝트 포함`을 켜면 꺼져 있는 의상 파츠도 포함합니다. **의상 토글이 있는 아바타에서는 켜세요.** 안 그러면 지금 꺼져 있는 옷만 룩이 다르게 남습니다.

### 2. 필터

| 필터 | 값 |
|---|---|
| `머티리얼 종류` | 전체 / 일반 / **얼굴** |
| `표면 종류` | 전체 / 불투명 / 컷아웃 / 투명 |

:::tip[얼굴만 따로 조정]
`머티리얼 종류`를 `얼굴`로 두면 얼굴 재질만 잡힙니다. 얼굴은 몸과 다른 값을 써야 하므로 이 필터가 자주 필요합니다.
:::

### 3. 미리보기 확인

`미리보기 머티리얼 수`로 몇 개가 잡혔는지 보고, `미리보기 머티리얼 선택`으로 실제로 무엇이 잡혔는지 Project 창에서 확인합니다.

의상을 바꿨으면 `미리보기 새로고침`을 먼저 누르세요.

`현재 범위와 필터에 맞는 MingToon 머티리얼이 없습니다.` 가 나오면 범위나 필터를 넓히세요.

### 4. 공통 외형 적용

`공통 외형`에는 여러 재질에 **안전하게** 같은 값을 넣을 수 있는 항목만 노출됩니다. 네 그룹으로 묶여 있습니다.

| 그룹 | 항목 |
|---|---|
| **베이스 · 조명** | 전체 효과 · 베이스 색상 · 베이스 색 보존 · 조명 색상 영향 · 최소 밝기 · 최대 밝기 |
| **그림자** | 그림자 경계 · 그림자 부드러움 · 그림자 강도 · 통합 그림자 사용 · 통합 그림자 색상 · 통합 그림자 HSVG · 그림자 경계 사용 · 경계선 폭 / 블러 / 강도 · 캐스트 섀도우 수신량 |
| **스타일 효과** | 2D 림 폭 · 2D 림 강도 · 2D 그림자 폭 / 강도 · 2D 그림자 캐스트 도달 거리 · 얼굴 2D 그림자 보조 · 2D 그림자 조명 방향 추적 · 얼굴 고정 방향 · 얼굴 자기면 억제 · 2D 그림자 위·아래 / 앞·뒤 오프셋 · 거리 감쇠 범위 · 페이스 셰이딩 |
| **아웃라인 · 이미션** | 아웃라인 색상 · 아웃라인 폭 · 이미션 강도 |

`프로퍼티 검색`으로 필터할 수 있고, 결과가 없으면 `검색어와 선택한 머티리얼에 맞는 안전한 일괄 프로퍼티가 없습니다.` 가 나옵니다.

:::tip[아바타 전체 톤을 맞추는 가장 빠른 길]
1. 범위 = `밍툰 매니저`, `비활성 오브젝트 포함` 켜기
2. `머티리얼 종류` = `일반`
3. `그림자 부드러움`·`베이스 색 보존`·`최소 밝기`를 맞춤
4. `머티리얼 종류` = `얼굴`로 바꿔 얼굴만 따로 조정
:::

## 여러 재질을 그냥 선택했을 때 {#여러-재질을-그냥-선택했을-때}

일괄 패널을 안 쓰고 Project 창에서 재질을 여러 개 선택해도 편집할 수 있습니다. 이때 인스펙터 위에 안내가 뜹니다.

- `N개 머티리얼을 함께 편집 중입니다. 변경은 호환되는 프로퍼티에 모두 적용됩니다.`
- `N개 MingToon 머티리얼의 서로 다른 셰이더를 함께 편집 중입니다. 공통 프로퍼티만 표시됩니다.` — BRP와 URP 재질을 섞었거나, 일부가 baked 재질일 때

값이 서로 다른 항목은 **`혼합 값`** 으로 표시됩니다.

:::danger[혼합 값을 건드리면 되돌릴 수 없습니다]
그 필드를 만지는 순간 **선택한 모든 재질에 같은 값이 덮어써지고**, 원래 달랐던 값은 사라집니다. Undo로만 되돌아갑니다. 쓰기 전에 무엇이 혼합 상태인지 반드시 확인하세요.
:::

`빠른 설정`에서는 값이 갈리는 항목에 `(혼합 상태)`가 붙습니다.

## 머티리얼 프리셋 {#머티리얼-프리셋}

룩 전체를 저장하고 다시 씌웁니다. 선택 상태에 따라 이름이 바뀝니다 — `머티리얼 프리셋` / `캐릭터 머티리얼 프리셋` / `머티리얼 일괄 프리셋`.

### 적용 {#적용}

1. `프리셋` 드롭다운에서 고릅니다. `팩토리 프리셋`은 동봉된 것, `사용자 프리셋`은 직접 저장한 것입니다.
2. `선택 프리셋 적용 (N개 머티리얼)`.

:::note[프리셋이 바꾸는 것 / 지키는 것]
- **적용** — 모든 수치 · 색 · 벡터 · 렌더 상태
- **보존** — 대상 재질의 텍스처가 셰이더 기본값과 다르면 **그 텍스처와 타일링/오프셋은 그대로 둡니다**

그래서 캐릭터마다 다른 텍스처를 유지한 채 룩만 통일할 수 있습니다.
:::

### 저장 {#저장}

`사용자 프리셋 저장`으로 현재 재질의 값을 에셋으로 굽습니다. 저장 원본이 무엇인지 `저장 원본: {재질}` 로 표시됩니다.

`고급 / 직접 지정`을 고르면 `프리셋 에셋` 슬롯에 에셋을 직접 넣을 수 있습니다.

## 복사 / 붙여넣기

항목 우클릭 메뉴입니다. 자세한 내용은 [텍스처 슬롯 공통 UI](/guides/texture-modules#값-복사--붙여넣기)에 있습니다.

| 메뉴 | 범위 |
|---|---|
| `값 복사` / `값 붙여넣기` | 항목 하나 |
| `레이어 값 복사` / `레이어 값 붙여넣기` | 레이어 하나 전체 |
| `탭 값 복사` / `탭 값 붙여넣기` | 섹션 전체 |
| `프로퍼티 이름 복사` | 셰이더 프로퍼티 이름 |

## 씬 전체 재질 찾기

`씬의 모든 MingToon 머티리얼 선택`으로 현재 씬의 MingToon 재질을 한 번에 선택할 수 있습니다. 밍툰 매니저가 없는 씬에서 유용합니다.
