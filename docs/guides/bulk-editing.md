# 여러 재질 한 번에

> 이 페이지는 **일괄 설정**을 처음 써 보는 분을 위한 것입니다.
> 아바타의 여러 재질에 같은 값을 한 번에 넣습니다. 약 5분 걸립니다.

## 이게 뭔가요

아바타 하나에 재질이 스무 개 넘게 붙는 일은 흔합니다.
아웃라인 색을 바꾸려고 스무 번 같은 슬라이더를 만질 필요는 없습니다.
일괄 설정은 조건에 맞는 재질을 모아 한 번에 값을 씁니다.

## 언제 쓰나요

- 아바타 전체의 아웃라인 색을 한 톤으로 맞출 때
- 의상 전부의 그림자 경계를 같이 옮길 때

## 30초 만에 켜 보기

1. 밍툰 매니저를 선택합니다.
2. 인스펙터의 보기를 **일괄 설정** 으로 바꿉니다.
3. **범위** 를 `밍툰 매니저` 로 둡니다.
4. **미리보기 머티리얼 수** 가 1보다 큰지 확인합니다.

숫자가 보이면 성공입니다.
0이면 아래 [흔한 문제](#흔한-문제)를 보세요.

## 켜는 법

1. **범위** 와 두 필터를 정합니다.
2. **미리보기 머티리얼 수** 를 확인합니다.
3. 의상이나 씬을 바꿨다면 **미리보기 새로고침** 을 누릅니다.
4. 필요하면 **미리보기 머티리얼 선택** 으로 결과를 선택 상태에 넣습니다.
5. **공통 외형** 의 그룹을 열고 값을 바꿉니다.

대상에는 MingToon 재질만 남고 같은 재질은 한 번만 들어갑니다.
여러 재질에 적용한 값은 한 번의 Undo로 되돌릴 수 있습니다.

## 범위와 필터

| 인스펙터 라벨 | 고를 수 있는 값 |
|---|---|
| **범위** | 선택한 오브젝트 / 밍툰 매니저 / 활성 씬 / 불러온 모든 씬 |
| **비활성 오브젝트 포함** | 꺼진 의상까지 함께 찾습니다 |
| **머티리얼 종류** | 전체 / 일반 / 얼굴 |
| **표면 종류** | 전체 / 불투명 / 컷아웃 / 투명 |

**범위** 를 `밍툰 매니저` 로 두면 그 매니저 아래만 찾습니다.
아바타나 의상을 편집할 때는 아바타 맨 위의 매니저를 고르세요.

## 자주 만지는 값

**공통 외형** 은 네 그룹으로 나뉩니다.
각 행은 그 프로퍼티를 가진 재질에만 기록됩니다.

| 인스펙터 라벨 | 뭘 바꾸는지 | 추천 시작값 | 올리면 / 내리면 |
|---|---|---|---|
| **전체 밝기 배수** | 캐릭터 전체의 최종 밝기 | 기본값 그대로(1) | 올리면 통째로 밝아지고, 내리면 어두워집니다 |
| **베이스 색상** | 베이스 맵 위에 덧입히는 색 | 흰색 | 색을 넣으면 선택한 재질 전부가 그 색으로 물듭니다 |
| **그림자 경계** | 밝은 면과 그늘의 경계 위치 | 기본값 그대로(0) | 올리면 그늘이 넓어지고, 내리면 좁아집니다 |
| **그림자 부드러움** | 경계가 번지는 폭 | 기본값 그대로(0.3) | 올리면 부드럽게 번지고, 내리면 또렷한 선이 됩니다 |
| **아웃라인 색상** | 선의 색 | 베이스보다 어두운 색 | 검정에 가까울수록 만화풍이 강해집니다 |
| **아웃라인 폭** | 선의 굵기 | 기본값 그대로(1) | 올리면 두꺼워지고, 0이면 사라집니다 |
| **전체 이미션 강도** | 발광 전체의 세기 | 기본값 그대로(1) | 0이면 발광이 사라집니다 |

행이 너무 많으면 **프로퍼티 검색** 에 이름 일부를 넣으세요.
검색 중에는 해당 그룹이 자동으로 펼쳐집니다.

## 머티리얼 프리셋 {#머티리얼-프리셋}

값 묶음을 에셋으로 저장했다가 다른 아바타에 다시 씁니다.

1. **프리셋 저장 및 관리** 를 펼칩니다.
2. **사용자 프리셋 저장** 으로 지금 재질의 값을 저장합니다.
3. 다른 재질에서 **프리셋** 목록에서 고릅니다.
4. **적용** 을 누릅니다.

:::caution[프리셋이 덮어쓰지 않는 값이 있습니다]
표면 렌더링과 레이어 내용은 재질 자신의 것이라 그대로 남습니다.
텍스처와 타일링·오프셋도 건드리지 않습니다.
:::

프리셋은 수치와 색만 담습니다.
렌더 큐와 RenderType 태그는 그대로 둡니다.
적용은 Undo로 되돌릴 수 있습니다.

## 복사 / 붙여넣기

값 하나나 탭 하나만 옮기고 싶을 때 씁니다.
프로퍼티나 레이어 머리글을 우클릭하면 메뉴가 나옵니다.
자세한 규칙은 [값 복사 / 붙여넣기](/guides/texture-modules#값-복사--붙여넣기)에 있습니다.

## 흔한 문제 {#흔한-문제}

| 증상 | 원인 | 조치 |
|---|---|---|
| 미리보기 수가 0이다 | 범위가 매니저 밖을 가리킨다 | 아바타 맨 위의 매니저를 고릅니다 |
| 원하는 행이 안 보인다 | 선택한 재질에 그 프로퍼티가 없다 | 필터를 전체로 넓혀 다시 찾습니다 |
| 값이 일부에만 들어갔다 | 그 프로퍼티가 없는 재질은 건너뛴다 | 종류 필터로 나눠 두 번 적용합니다 |

의상이나 씬을 바꾼 뒤에는 **미리보기 새로고침** 을 먼저 누르세요.
