# 표면과 텍스처

**이 문서를 읽으면** 베이스 색을 잡고, 투명 처리를 고르고, 그 위에 레이어를 쌓는 순서를 알게 됩니다.

전체 항목 목록은 [표면과 텍스처 레퍼런스](/reference/surface)에 있습니다. 여기서는 **어떤 순서로 만지는지**를 다룹니다.

## 인스펙터 모드

|---|---|---|
| **간단** | 베이스 맵, HSVG, 노멀·이미션·오클루전·PBR·맷캡의 핵심만, 그림자, 밝기 한계 | 톤 잡기, 변환 결과 확인 |
| **전체** | 레이어, 마스크, 합성, 아웃라인, 림, 고급 조명 | 본격 채색 |
| **일괄** | 여러 재질에 공통으로 쓰는 값만 | 아바타 전체를 한 번에 |

## 1. 표면 모드부터 정합니다

베이스 맵을 넣기 전에 **표면 모드**를 먼저 정하세요. 나중에 바꾸면 렌더 큐가 움직이면서 2D 효과가 통째로 꺼지는 일이 생깁니다.

| 모드 | 쓰는 곳 | 알아둘 것 |
|---|---|---|
| **Opaque** | 몸, 옷, 대부분의 파츠 | 깊이가 완전히 기록되어 모든 효과가 동작합니다 |
| **Cutout** | 머리카락, 속눈썹, 잘라내는 파츠 | `알파 컷오프` 0.3~0.6이 무난. 0에 가까우면 반투명 가장자리가 지저분하게 남습니다 |
| **Transparent, depth-recorded** (큐 2499) | 반투명이면서 2D 효과도 써야 하는 파츠 | 깊이가 기록되는 구간 안이라 2D 그림자·깊이 림·Inner Edge가 전부 동작합니다. **반투명이 필요하면 이쪽을 우선 고려하세요** |
| **Transparent** (큐 3000) | 완전한 반투명 | 깊이 구간 밖이라 **깊이 기반 모듈이 전부 꺼집니다** |

:::tip 머리카락이 볼을 뚫고 보인다면
`Transparent Depth Prepass`를 켜세요. 색을 그리기 전에 표면 깊이를 먼저 기록해서, 뺨 뒤에 있는 머리카락 가닥이 뺨 위로 그려지는 것을 막습니다.
:::

## 2. 베이스 색

1. **베이스 맵**에 캐릭터 텍스처를 넣습니다.
2. 색을 조정할 일이 있으면 **베이스 맵 HSVG**로 합니다. 텍스처를 다시 굽는 것보다 빠르고, 변환 결과를 원본과 비교하기도 쉽습니다.
3. **베이스 색상**으로 틴트를 얹을 때는 세 항목이 한 세트입니다.

| 항목 | 역할 |
|---|---|
| 베이스 색상 | 얹을 색 |
| 틴트 합성 모드 | `Multiply`는 맵의 명암을 남긴 채 색만 입힘 · `Normal`은 맵을 덮어 단색이 됨 |
| 틴트 불투명도 | **0이면 위 두 항목이 통째로 무시됩니다** |

:::note 색을 바꿨는데 아무 변화가 없다면
틴트 불투명도가 0인지 먼저 확인하세요. MingToon에는 이런 "상위 값이 0이면 하위가 전부 무시"되는 구조가 여러 곳에 있습니다. 레퍼런스 표의 설명에 어떤 값이 상위인지 적혀 있습니다.
:::

## 3. 투명도를 텍스처로 따로 지정하기

베이스 맵의 알파가 아니라 별도 이미지로 투명도를 주려면 **알파 마스크**를 씁니다.

1. `알파 마스크 사용`을 켭니다.
2. `마스크 이미지`에 흑백 이미지를 넣습니다.
3. `마스크 채널`에서 읽을 채널을 고릅니다. 여러 마스크를 한 장에 패킹했다면 R/G/B/A 중 하나, RGB 밝기를 쓰려면 `Luma`.
4. 지워야 할 곳이 흰색으로 그려진 마스크라면 `마스크 반전`을 켭니다.

:::caution 표면 모드가 Opaque면 켜도 보이지 않습니다
알파 마스크는 Cutout 또는 Transparent에서만 결과가 나옵니다.
:::

## 4. 공통 맵

간단 모드에 노출된 네 가지가 대부분의 작업을 커버합니다.

- **노멀맵** — 요철. 강도 0이면 맵을 넣어도 평평합니다. 1이 원본 세기.
- **오클루전 맵** — 간접광이 닿기 어려운 곳을 어둡게. **직접광에는 영향이 없어서** 정면에서 강한 조명을 받으면 효과가 거의 안 보입니다.
- **이미션** — 맵 × 색상 × 강도. 색상이 검정이면 맵이 있어도 빛나지 않습니다. 씬에 블룸이 없으면 강도를 올려도 번지지 않고 흰색으로 포화되기만 합니다.
- **PBR** — 아래 참고.

## 5. PBR을 쓸지 정하기

툰 룩에서 PBR은 "쓰거나 안 쓰거나"가 아니라 **어디에 얼마나 얹느냐**의 문제입니다. 금속 장식, 에나멜 구두, 젖은 입술 같은 데만 쓰는 것이 보통입니다.

만지는 순서:

1. **워크플로** — `Metallic`(금속도에서 반사색 생성) 또는 `Specular`(반사색 직접 지정). Specular를 고르면 금속도 슬라이더는 무시됩니다.
2. **반사광 강도** — 여기가 0이면 직접 하이라이트와 환경 반사가 **함께** 사라집니다. 매끄러움을 아무리 올려도 변화가 없다면 여기부터 보세요.
3. **매끄러움** — 툰 룩에서는 0.3~0.6이 무난합니다. 1에 가까우면 하이라이트가 점처럼 작아집니다.
4. **그림자 안 표시량** — 그림자에 들어간 부분에서 하이라이트를 얼마나 남길지. 0이면 그림자 안에서 완전히 사라집니다. 툰 룩에서는 낮게 두는 편이 깔끔합니다.
5. **환경 반사 강도** — 씬에 리플렉션 프로브가 없으면 올려도 거의 변화가 없습니다.

**패킹 마스크**를 쓰면 금속도·오클루전·매끄러움을 한 장에서 읽습니다. 기본 배치는 R=금속도, G=오클루전, A=매끄러움이고, 다르면 채널 설정으로 맞춥니다. 러프니스 맵을 넣었다면 `러프니스로 사용 (반전)`을 켜세요.

:::caution 패킹 마스크를 끄면
아래의 채널·반전 설정이 **전부 무시되고** 금속도·매끄러움 슬라이더 값만 쓰입니다.
:::

## 6. 레이어 쌓기

**텍스처 레이어**는 베이스 위에 추가 텍스처를 합성합니다. **노멀 레이어**는 노멀맵을 여러 장 겹칩니다. **맷캡 레이어**는 시선 기준 반사 이미지를 얹습니다.

세 가지 모두 같은 함정이 있습니다.

:::danger 레이어 수를 먼저 올리세요
`레이어 수`보다 뒤에 있는 슬롯은 **계산 자체를 건너뜁니다.** 텍스처를 넣었는데 아무것도 안 보인다면 십중팔구 레이어 수가 모자란 것입니다. 각 레이어의 `불투명도`(맷캡은 `강도`)가 0일 때도 같은 결과가 됩니다.
:::

**맷캡 팁 하나** — `MatCap / 메시 UV 투영`을 1로 두면 무늬가 시선이 아니라 메시 UV에 고정됩니다. 카메라를 돌려도 표면에 붙어 있어서 **문신이나 페이스 페인팅**에 씁니다.
