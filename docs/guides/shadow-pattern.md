# 그림자 패턴 (스크린톤)

**이 문서를 읽으면** 그림자를 만화 스크린톤처럼 하프톤 망점으로 바꾸고, 원하는 모양의 타일을 직접 만들 수 있습니다.

`조명과 그림자` 그룹 안의 `그림자 패턴 (스크린톤)`을 다룹니다. 전체 항목 목록은 [조명과 그림자 레퍼런스](/reference/light-and-shadow)에 있습니다.

## 어떻게 동작하나

형태 그림자와 2D 그림자를 하프톤 망점으로 표현합니다. 그림자가 깊어질수록 점이 커집니다.

격자는 계산으로 그리는 원형 망점이 기본이며, 선택적으로 모양 타일을 한 번 읽습니다. `패턴 기준`이 `Mesh`면 레스트 포즈 좌표에 붙고, `Screen`이면 화면에 고정됩니다.

Skinned Mesh에서 Mesh 기준을 쓰려면 레스트 포즈 앵커가 있어야 애니메이션 중 패턴이 피부 위를 미끄러지지 않습니다.

:::note[통합 그림자와 함께 써도 됩니다]
[통합 그림자](/guides/light-and-shadow#통합-그림자--겹칠-때-새까매지는-문제)를 켠 상태에서도 그림자 패턴은 그대로 유지됩니다.
:::

## 런타임 값 {#런타임-값}

| 항목 | 하는 일 |
|---|---|
| **패턴 적용 대상** | 형태 그림자, 2D 그림자, 또는 둘 다 |
| **패턴 방식** | `Recolor` — 그림자 커버리지 자체를 다시 그림. 점이 그림자 색을 그대로 씀<br />`Overlay` — 그림자를 그대로 두고 `잉크 색`으로 위에 올림 |
| **패턴 밀도** | 화면 한 폭을 채우는 셀 개수. 화면 **높이** 기준이라 해상도가 바뀌어도 같은 크기로 보임 |
| **패턴 회전** | 격자 각도 |
| **패턴 경계 부드러움** | 점 가장자리의 부드러움 |
| **패턴 강도** | 패턴이 적용되는 세기. **0이면 아무것도 안 보입니다** |
| **거리 보정** | 멀어질 때 점 크기 보정 |
| **화각 / 투영 보정** | FOV가 바뀔 때 보정 |
| **가장 어두운 곳에도 패턴 유지** | 최암부까지 망점을 남길지. `가장 어두운 곳 채움 정도`로 양을 정합니다 |

:::caution[2D 그림자에서는 `Overlay`가 `Recolor`로 내려갑니다]
`패턴 방식`이 `Overlay`이고 `패턴 적용 대상`이 `Depth2D`이면 패턴은 그대로 찍히지만 `잉크 색` 대신 그림자 색을 씁니다. `Overlay`는 완성된 음영 위에 선을 얹는 방식이라 합성 지점이 형태 그림자 경로에만 있기 때문입니다. 예전부터 이렇게 동작했고, 이제 인스펙터가 그 조합에서 안내를 띄웁니다.

`Overlay`를 그대로 쓰려면 `패턴 적용 대상`을 `Form` 또는 `Both`로 두세요.
:::

:::tip[회전 각도]
**45도 부근**이 인쇄 망점처럼 자연스럽습니다. **0도**는 화면 픽셀 격자와 겹쳐 모아레가 생기기 쉽습니다.
:::

## 패턴 기준 — 표면에 붙일까, 화면에 고정할까 {#패턴-기준}

`패턴 기준` — **기본값 `Mesh`**

| 값 | 격자가 어디에 있나 |
|---|---|
| `Mesh` | 표면에 붙어 캐릭터와 **함께 움직입니다.** 팔을 들면 팔의 망점도 따라옵니다 |
| `Screen` | 화면에 고정되고 **캐릭터가 그 아래로 지나갑니다.** 인쇄물에 겹쳐 찍은 스크린톤 / 팝아트 |

모양 타일과 밀도·회전은 두 기준에서 같은 것을 씁니다. 바뀌는 것은 격자가 무엇에 붙어 있는지뿐입니다.

:::caution[Skinned Mesh의 Mesh 기준에는 Rest Pose Anchor가 필요합니다]
앵커가 없으면 인스펙터가 누락된 Skinned Renderer 수를 경고하고 `레스트 포즈 앵커 굽기` 버튼을 표시합니다. 먼저 MingToon Manager를 선택한 뒤 버튼을 누르거나 `Tools > Studio Raming > MingToon > Advanced > Bake Rest Pose Anchor`를 실행하세요.

베이커는 UV2 또는 UV4의 사용 가능한 payload에 레스트 포즈를 저장한 복제 Mesh를 만들고 관련 재질의 앵커 사용을 켭니다. 기존 채널과 충돌해 거부된 Renderer는 Console에 따로 표시됩니다.
:::

`Screen`에서는 별도 앵커가 필요 없습니다. 화각을 바꾸거나 고개를 돌려도 패턴이 휘거나 점멸하지 않고, 화면 종횡비가 달라도 셀을 정사각으로 유지합니다.

### 두 기준에서 보정 슬라이더의 의미가 뒤집힙니다

`거리 보정`과 `화각 / 투영 보정`은 **양쪽에서 다 동작합니다.** 다만 방향이 반대입니다.

- `Mesh`에서는 **카메라 안정성을 빼는** 값입니다. 0이면 표면에 완전히 고정되고, 1이면 카메라 움직임을 따라 크기를 보정합니다.
- `Screen`에서는 **카메라 안정성을 더하는** 값입니다. 1(기본값)이면 가까이서 잡아 둔 마크 크기와 밀도가 멀리서 봐도, 화각을 바꿔도 유지됩니다. 0으로 내리면 격자가 픽셀에 완전히 고정되어 카메라가 무엇을 하든 한 톨도 움직이지 않습니다.

:::tip[가까이서 작업하고 멀리서 확인하세요]
`Screen` + `거리 보정` 1이 바로 그 조합입니다. 0.1.5 이전에는 이 두 슬라이더가 `Screen`에서 잠겨 있어 쓸 수 없었습니다.
:::

## 패턴 모양 타일 {#패턴-모양-타일}

`패턴 모양 타일 사용` — **기본값 꺼짐**

- **꺼 두면** 계산으로 그리는 원형 망점이 쓰이고 텍스처를 한 번도 읽지 않습니다.
- **켜면** 셀 안에 그려지는 **모양만** 타일 이미지로 바뀝니다. 격자·밀도·톤 반응은 그대로입니다.

### 동봉 타일

`Assets/StudioRaming/MingToon/Textures/Patterns` 폴더에 5종이 있고, 인스펙터의 버튼으로 바로 넣을 수 있습니다.

| 버튼 | 모양 |
|---|---|
| **망점** | 표준 하프톤 |
| **고운 망점** | 가는 망점 |
| **선** | 평행선 |
| **교차선** | 크로스해칭 |
| **점묘** | 스티플 |

<!-- SCREENSHOT: 5종 타일 각각의 결과 -->

:::danger[타일 슬롯이 비어 있으면 패턴이 전혀 안 찍힙니다]
빈 슬롯은 **흰색**으로 읽히고, 흰색은 어떤 농도로도 넘어설 수 없는 임계값입니다. 인스펙터가 이를 경고하고 기본 제공 타일 버튼을 함께 보여 줍니다.
:::

### 타일은 그림이 아니라 임계값 맵입니다 {#타일은-그림이-아니라-임계값-맵입니다}

이 부분을 오해하면 타일을 직접 만들 때 반드시 실패합니다.

타일의 각 텍셀은 **그 텍셀이 잉크로 바뀌는 농도**를 담고 있습니다. "패턴을 그린 그림"이 아닙니다. 그래서 타일 한 장으로 **첫 점부터 완전히 채워질 때까지 전부** 표현됩니다.

:::danger[이미 이진화된 점 패턴을 넣으면]
그림자 깊이와 무관하게 **같은 크기의 점만** 나옵니다. 톤에 반응하지 않습니다.
:::

### 직접 만들 때 임포트 설정

| 설정 | 값 | 이유 |
|---|---|---|
| `sRGB (Color Texture)` | **끄기** | sRGB 변환이 톤 곡선을 왜곡합니다 |
| 압축 (Compression) | **끄기** | 블록 압축이 그라디언트를 뭉개 패턴에 얼룩을 만듭니다 |

모든 밝기 단계가 **같은 텍셀 수**를 차지해야 합니다. 그래야 점이 샘플링 한계보다 작아졌을 때 원래 농도로 수렴합니다.

### Tiling / Offset이 없는 이유

셀 한 칸이 정확히 타일 한 번의 반복입니다. 따라서 밀도는 `패턴 밀도`가, 방향은 `패턴 회전`이 그대로 정합니다. 슬롯에 Tiling/Offset이 없는 것은 이 때문입니다.
