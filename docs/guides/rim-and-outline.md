# 림과 외곽선

**이 문서를 읽으면** 캐릭터를 배경에서 떼어 놓는 네 가지 수단을 구분하고, 어느 것부터 켜야 하는지 알게 됩니다.

전체 항목 목록은 [림과 강조광](/reference/rim-and-highlights) · [외곽선](/reference/outline) 레퍼런스에 있습니다.

## 무엇을 켤지 먼저 고릅니다

| 수단 | 어디에 생기나 | 깊이 필요 | 쓰는 곳 |
|---|---|---|---|
| **Hull 외곽선** | 실루엣 바깥 | ❌ | 기본 외곽선. 어디서나 동작 |
| **Inner Edge** | 표면 안쪽 경계 | ✅ | 옷 주름, 파츠 경계선 |
| **림 라이트** (프레넬) | 실루엣 안쪽, 밝게 | ❌ | 역광 느낌, 캐릭터 분리 |
| **림 셰이드** | 실루엣 안쪽, 어둡게 | ❌ | 부피감, 일러스트의 가장자리 음영 |

:::caution 겹쳐 켜면 금세 과해집니다
하나씩 켜고 확인하면서 올리세요. 특히 림 라이트와 백라이트를 같이 올리면 실루엣이 하얗게 날아갑니다.
:::

## Hull 외곽선

메시를 뒤집어 확장하는 방식입니다. 추가 패스 한 번으로 그려지고 **깊이 텍스처 없이 동작**하므로 어떤 환경에서도 안전합니다.

### 기본 설정

1. `클래식 헐 사용`을 켭니다.
2. `폭 모드`를 고릅니다.

| 폭 모드 | 동작 | 권장 |
|---|---|---|
| `PixelStable` | 화면 픽셀 기준. 거리와 무관하게 두께 일정 | **아바타에는 이쪽** |
| `WorldSpace` | 월드 크기 기준. 멀어지면 얇아짐 | 고정 카메라 연출 |

3. 폭과 색을 조정합니다.

**이렇게 되면 정상입니다.** 캐릭터 실루엣 바깥에 선이 그려집니다.

### 선 굵기를 부위마다 다르게

`압력 소스`로 굵기를 조절할 페인팅 채널을 고릅니다.

| 소스 | 읽는 것 |
|---|---|
| `VertexRed` | 버텍스 컬러 R |
| `VertexAlpha` | 버텍스 컬러 A |
| `WidthMask` | 폭 마스크 텍스처 |
| `OutlineNormalUV8` | UV8에 구운 외곽선 노멀. 긴 면은 두껍게, 꼭짓점은 얇게 |

:::danger 선이 통째로 사라졌다면
**버텍스 컬러가 검게 임포트된 메시**에서 `VertexRed`를 고른 경우입니다. 압력이 0이면 폭도 0이 됩니다. 압력 소스를 바꾸거나 버텍스 컬러를 확인하세요.
:::

`헐 압력 대비`는 굵기 차이를 키웁니다. **0이면 압력이 완전히 무시**되고, 1이 원본, 높일수록 얇은 곳이 더 얇아집니다.

### 각진 부분에서 선이 끊길 때

`노멀 소스`가 원인입니다.

- `MeshNormal` — 메시 노멀 그대로. 하드 엣지에서 선이 벌어집니다.
- `VertexColorTS` / `UV8TS` — **스무딩한 외곽선 노멀을 버텍스 컬러나 UV8에 구워 두었을 때만** 유효합니다. 굽지 않은 메시에서 고르면 오히려 각진 부분에서 선이 끊어집니다.

굽지 않은 메시라면 `MeshNormal`을 쓰고, 문제가 되는 부위만 모델링 쪽에서 정리하는 편이 빠릅니다.

### 선이 다른 파츠에 파묻힐 때

`깊이 바이어스`로 헐 전체를 카메라 쪽으로 당깁니다. **너무 많이 당기면 선이 얼굴 앞으로 떠올라 보입니다.**

### 외곽선 색이 조명을 따라가게

`셰이딩 포함`을 켜면 형태·캐스트·2D 그림자와 2D 림이 외곽선 색에도 반영됩니다. 끄면 조명과 무관한 균일한 색을 유지합니다.

## Inner Edge

화면 깊이 차이로 **표면 안쪽** 경계선을 그립니다. 추가 지오메트리가 없어서 Hull이 깨지는 메시에도 쓸 수 있습니다.

:::danger 동작 조건
- 카메라 깊이 텍스처가 필요합니다 → [Camera Depth](/guides/camera-depth)
- **표면 모드가 Transparent(큐 3000)면 동작하지 않습니다.** 반투명이 필요하면 `Transparent, depth-recorded`(큐 2499)를 쓰세요.
:::

조정 항목은 둘입니다.

- `깊이 바이어스` — 이 값보다 큰 깊이 차이만 경계로 인정합니다. **낮추면** 완만한 굴곡에도 선이 붙어 노이즈가 되고, **올리면** 얇은 부위의 선이 사라집니다.
- `부드러움` — 0은 단단한 잉크선, 1은 선 폭 전체가 흐려집니다.

:::caution Inner Edge가 통째로 사라졌다면
`Inner Edge 외곽선에 적용` 토글을 확인하세요. 이 토글은 Classic Hull 그룹 안에 있지만 **Hull을 꺼도 Inner Edge에 계속 작용합니다.** 버텍스 컬러가 검은 메시에서 켜져 있으면 Inner Edge가 전부 사라집니다.
:::

## 림 라이트 (프레넬)

시선 각도에 반응하는 밝은 테두리광입니다. 깊이가 필요 없습니다.

만지는 순서:

1. `강도` — **0이면 색과 폭을 바꿔도 화면에 나타나지 않습니다.** 여기부터 올리세요.
2. `폭` — 림이 시작되는 지점. 0이면 안 나오고, 1에 가까우면 표면 전체가 밝아집니다.
3. `프레넬 감쇠` — 클수록 실루엣 가장자리로 얇게 몰립니다.
4. `부드러움` — 낮추면 셀 룩의 단단한 띠, 올리면 그라데이션.

환경에 맞추는 항목:

| 항목 | 0 | 1 |
|---|---|---|
| `광원 방향 영향` | 카메라 기준으로 실루엣 전체에 림 | 광원 쪽에만 남음 |
| `베이스 색 영향` | 지정한 림 색 그대로 | 베이스 맵 색을 곱해 재질별로 다른 림 색 |
| `씬 조명 영향` | 씬 밝기와 무관하게 항상 같은 세기 | 조명이 어두워지면 림도 어두워짐 |

:::tip 조명을 통제할 수 없는 환경이라면
`광원 방향 영향`을 낮추고 `씬 조명 영향`도 낮게 두세요. 어떤 월드에 들어가도 림이 일정하게 남습니다.
:::

## 림 셰이드

실루엣 **안쪽에 어두운 띠**를 넣어 부피감을 만듭니다. 일러스트에서 가장자리에 넣는 음영과 같은 역할입니다.

- `그림자 기여 강도` — **0이면 계산 자체를 건너뛰므로** 폭·감쇠·부드러움을 바꿔도 변화가 없습니다.
- `림 그림자 폭` — 띠가 시작되는 지점. 0이면 안 나옵니다.
- `림 감쇠` — 클수록 가장자리에 얇게 붙습니다.
- `경계 부드러움` — 낮추면 잉크로 그은 선처럼 단단해집니다.

## 백라이트 · 프런트 라이트 · 글리터

각각 켜기 토글 + 색 + 강도, 세 항목뿐인 가벼운 모듈입니다.

| 모듈 | 하는 일 |
|---|---|
| **백라이트** | 표면 뒤쪽의 주광이 만드는 독립적인 역광 띠 |
| **프런트 라이트** | 카메라를 향한 면에 더하는 정면 강조광 |
| **글리터** | 보로노이 입자 반짝임 |
