# Mask Maker 연동

> 이 페이지는 `MM` 버튼이나 페인트 버튼을 눌러 여기로 온 분을 위한 것입니다.
> 없이 하는 방법을 먼저 알려 드립니다.

## 30초 만에 켜 보기

Mask Maker를 이미 설치했다면 아래 순서로 한 장을 만들어 보세요.

1. 변환한 재질 하나만 고릅니다.
2. **마스크 이미지** 슬롯 오른쪽의 `MM` 버튼을 누릅니다.
3. 씬 뷰에서 적용할 부분을 칠합니다.
4. 저장하면 그 슬롯에 마스크 텍스처가 들어갑니다.

슬롯에 방금 칠한 텍스처가 들어가면 성공입니다.
`MM` 버튼이 안 보이면 [마스크 슬롯의 MM 버튼](#mm-버튼)을 보세요.

## Mask Maker 없이 하는 법

마스크와 버텍스 컬러는 전부 다른 경로로도 넣을 수 있습니다.

| 하고 싶은 것 | Mask Maker 없이 |
|---|---|
| 마스크 텍스처 | 외부 도구에서 만들어 해당 슬롯에 직접 넣습니다 |
| 외곽선 두께 조절 | **압력 소스** 를 `WidthMask`로 두고 **폭 마스크** 텍스처를 씁니다 |
| 얼굴 영역 지정 | **얼굴 영역 마스크** 텍스처를 씁니다 |
| 이미 칠해진 버텍스 컬러 | 그대로 읽습니다. 외부 DCC에서 칠한 값도 유효합니다 |

### 버텍스 컬러 채널 정리

| 용도 | 채널 |
|---|---|
| 외곽선 두께(압력) | 빨강(R) 또는 알파(A) |
| 얼굴 영역 | 초록(G) |

어느 채널을 읽을지는 **압력 소스** 가 정합니다.

## Mask Maker가 여는 기능

Mask Maker는 별도로 판매되는 에디터 도구입니다. MingToon 오픈 베타 패키지에 동봉되지 않습니다.

| 위치 | 버튼 | 하는 일 |
|---|---|---|
| 마스크 텍스처 슬롯 | `MM` | 그 슬롯의 마스크를 씬 뷰에서 직접 그립니다 |
| `노멀 아웃라인` | **씬 뷰에서 외곽선 두께 칠하기** | 선 굵기를 조절할 버텍스 컬러를 칠합니다 |
| `페이스/헤어 셰이딩` | **얼굴 영역 페인트 시작** | 얼굴로 취급할 범위를 버텍스 컬러로 칠합니다 |

### 마스크 슬롯의 MM 버튼 {#mm-버튼}

`MM`은 마스크 계열 텍스처 슬롯에만 붙습니다.

**마스크 이미지**, **PBR 패킹 마스크**, **얼굴 영역 마스크**, **SDF 적용 마스크** 가 대표적입니다.

슬롯 옆에 `MM`이 보이면 지원 슬롯입니다. 보이지 않으면 그 슬롯은 대상이 아닙니다.

:::tip[재질 하나만 선택한 상태에서 씁니다]
`MM`은 한 재질의 한 슬롯을 편집합니다. 여러 재질을 함께 고르면 눌리지 않습니다.
:::

### 외곽선 두께 칠하기

`노멀 아웃라인` 탭에서 시작합니다. 칠한 값은 버텍스 컬러의 빨강(R) 또는 알파(A)에 들어갑니다.

**압력 소스** 가 아직 버텍스 채널이 아니면 인스펙터가 먼저 안내합니다. **버텍스 컬러 알파(VertexAlpha)로 전환** 버튼을 보여 줍니다.

→ [아웃라인](/guides/outline#씬-뷰에서-직접-칠하기)

### 얼굴 영역 페인트

`페이스/헤어 셰이딩` 탭에서 시작합니다. 칠한 값은 버텍스 컬러의 초록(G)에 들어갑니다.

얼굴 범위를 몸과 다르게 처리하려면 이 정보가 필요합니다.
→ [페이스 셰이딩](/guides/character#페이스-셰이딩)

:::caution[버텍스 페인팅은 메시 에셋을 직접 고칩니다]
같은 메시를 공유하는 다른 렌더러의 결과도 함께 바뀝니다.
따로 칠하려면 메시를 먼저 복제하세요.
:::
