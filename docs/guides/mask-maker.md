# Mask Maker 연동

**이 문서를 읽으면** Mask Maker가 MingToon 안에서 어떤 버튼을 열어 주는지, 설치하지 않았을 때 같은 목적을 어떻게 달성하는지, 제품을 어디서 구하는지 알 수 있습니다.

## 방금 누른 버튼은 별매 제품이 필요합니다

Mask Maker는 별도로 판매되는 Editor 도구입니다. MingToon 0.1.7 오픈베타 패키지에는 동봉되지 않습니다.

MingToon 자체는 Mask Maker가 없어도 설치되고, 컴파일되고, 동작합니다. 마스크를 **읽는** 쪽은 MingToon 셰이더이고, Mask Maker는 그 마스크를 **만드는** 쪽만 담당합니다.

**구매:** <https://raming.booth.pm/items/8606444> (BOOTH · `[Unity] MaskMaker`)

:::note[MingToon은 애드온을 어셈블리로 참조하지 않습니다]
MingToon은 Mask Maker, Face SDF Studio, Ming Light Controller를 어셈블리 참조가 아니라 리플렉션으로만 찾습니다. 그래서 셋이 전부 없어도 MingToon은 정상적으로 설치·컴파일·동작합니다.

설치하면 해당 버튼이 그 자리에서 살아납니다. 설치하지 않았다면 버튼은 그대로 보이고, 누르면 이 문서로 옵니다.
:::

## Mask Maker가 여는 MingToon 기능

| 위치 | 버튼 | 하는 일 |
|---|---|---|
| 인스펙터 · 마스크 텍스처 슬롯 | `MM` | 그 슬롯의 마스크를 씬 뷰에서 직접 그립니다 |
| 인스펙터 · `노멀 아웃라인` | `씬 뷰에서 외곽선 두께 칠하기` | 선 굵기를 조절할 버텍스 컬러를 칠합니다 |
| 인스펙터 · `페이스/헤어 셰이딩` | `얼굴 영역 페인트 시작` | 얼굴로 취급할 범위를 버텍스 컬러로 칠합니다 |

### 마스크 슬롯의 `MM` 버튼 {#mm-버튼}

마스크 계열 텍스처 슬롯 옆에만 붙습니다. 예를 들어 `마스크 이미지`, `PBR 패킹 마스크`, `얼굴 영역 마스크`, `SDF 적용 마스크` 같은 슬롯입니다. 슬롯 옆에 `MM`이 보이면 지원 슬롯이고, 보이지 않으면 그 슬롯은 대상이 아닙니다.

:::tip[재질 하나만 선택한 상태에서 씁니다]
`MM`은 씬 뷰에서 한 재질의 한 슬롯을 편집합니다. 여러 재질을 함께 선택한 상태에서는 눌리지 않습니다.
:::

### `노멀 아웃라인` — 외곽선 두께 칠하기

`노멀 아웃라인` 탭에서 시작합니다. 칠한 값은 버텍스 컬러의 **빨강(R) 또는 알파(A)** 채널로 들어가고, 어느 채널을 읽을지는 같은 탭의 `압력 소스`가 정합니다.

`압력 소스`가 아직 버텍스 채널이 아니면 인스펙터가 안내 문구와 `버텍스 컬러 알파(VertexAlpha)로 전환` 버튼을 먼저 보여 줍니다.

### `페이스/헤어 셰이딩` — 얼굴 영역 페인트

`페이스/헤어 셰이딩` 탭에서 시작합니다. 칠한 값은 버텍스 컬러의 **초록(G)** 채널로 들어갑니다. 얼굴 범위를 몸과 다르게 처리하려면 이 범위 정보가 있어야 합니다. → [캐릭터 표현 — 페이스 셰이딩](/guides/character#페이스-셰이딩)

## Mask Maker 없이 하는 법

두 기능 모두 텍스처 마스크 경로가 따로 있습니다. Mask Maker는 그 데이터를 Unity 안에서 만들게 해 주는 도구일 뿐, 유일한 입력 경로가 아닙니다.

| 하고 싶은 것 | Mask Maker 없이 |
|---|---|
| 마스크 텍스처 | 외부 도구에서 만들어 인스펙터의 해당 슬롯에 직접 넣습니다 |
| 외곽선 두께 조절 | `압력 소스`를 `WidthMask`로 두고 폭 마스크 텍스처를 씁니다 |
| 얼굴 영역 지정 | `얼굴 영역 마스크` 텍스처를 씁니다 |
| 이미 칠해진 버텍스 컬러 | 그대로 읽습니다. 외부 DCC에서 칠해 임포트한 값도 유효합니다 |

### 버텍스 컬러 채널 정리

| 용도 | 채널 |
|---|---|
| 외곽선 두께(압력) | 빨강(R) 또는 알파(A) |
| 얼굴 영역 | 초록(G) |

## 함께 잠기는 다른 애드온

세 애드온의 전체 목록과 설치 확인 절차는 [별매 애드온](/guides/add-ons)에 있습니다.

### Face SDF Studio

광원 방향에 따른 얼굴 그림자 맵을 만드는 별매 도구입니다. 없어도 페이스 셰이딩은 동작하고, 이미 갖고 있는 SDF 텍스처는 슬롯에 직접 넣어 쓸 수 있습니다. → [얼굴 SDF와 Face SDF Studio](/guides/face-sdf)

### Ming Light Controller {#ming-light-controller}

MingToon 아바타 표현 메뉴(VRChat Expression Menu)를 만드는 Editor 전용 애드온입니다.

**출시 예정입니다.** 판매가 시작되면 이 자리에 구매 링크가 올라갑니다.

| 위치 | 잠긴 기능 |
|---|---|
| 인스펙터 · 최상단 | `마스터 조정` 섹션 |
| 인스펙터 · 조명 | `가상 광원` 오소링 행 |
| MingToon Manager | MLC 설치·부착 액션 |

파라미터 프로필은 아바타의 남은 VRChat 예산에 맞춰 고릅니다.

| 프로필 | 동기화 비트 | 항목 수 |
|---|---|---|
| Smooth | 84 | 22 |
| Compact | 41 | 51 |
| Auto | 남은 예산에 맞춰 위 둘 중 하나를 고름 | — |

루트 메뉴는 7칸입니다: `Reset`, `Final Output`, `Hue/Saturation`, `Photo Looks`, `Virtual Light`, `Master Adjust`, `Performance`.

#### MLC 없이도 되는 것

셰이더의 모든 룩 기능은 그대로 동작합니다. `마스터 조정`과 `가상 광원`은 재질에 값이 남아 있어도 인스펙터에서 편집 UI가 보이지 않을 뿐이며, 셰이더 동작 자체가 사라지는 것은 아닙니다.

VRChat·WARUDO의 Depth Light 빌드 정책은 MLC가 아니라 MingToon Manager가 계속 소유합니다. MLC를 제거해도 MingToon의 VRChat·WARUDO 빌드 동작은 바뀌지 않습니다.
