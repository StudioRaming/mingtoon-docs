# 깊이 기반 효과

**이 문서를 읽으면** 깊이 림·2D 그림자·내부 2D 경계가 왜 안 보이는지 진단하고, 각 플랫폼에서 깊이를 확보하는 방법을 알게 됩니다.

인스펙터의 **깊이 기반 효과** 그룹 — `깊이` · `깊이 림` · `2D 그림자` · `내부 2D 경계` 를 다룹니다. 전체 항목 목록은 [깊이 기반 효과 레퍼런스](/reference/depth-effects)에 있습니다.

## 무엇이 깊이를 쓰나

이 그룹의 네 섹션은 전부 **카메라 깊이 텍스처**를 읽습니다. 깊이가 없으면 값을 아무리 만져도 화면에 나타나지 않습니다.

:::danger 값을 만지기 전에 깊이부터 확인하세요
인스펙터가 상태를 직접 알려 줍니다.

- `깊이 효과가 꺼져 있어 이 모듈은 그려지지 않습니다.` → `깊이 효과 켜기`
- `이 효과는 Depth가 켜진 카메라에서만 보입니다.`
- `2D 뎁스 림과 2D 그림자는 깊이를 기록하는 불투명 또는 컷아웃 재질이 필요합니다. 투명 큐에서는 깊이 효과가 비활성화됩니다.`
- `활성 Scene/Game 카메라의 깊이 텍스처가 준비되지 않았습니다.`

이 메시지가 떠 있는 동안 폭이나 강도를 만지는 것은 의미가 없습니다.
:::

:::note 내부 2D 경계가 여기 있는 이유
아웃라인처럼 보이지만 화면 깊이를 읽기 때문에 **아웃라인 그룹이 아니라 이 그룹**에 있습니다. 아웃라인에서 찾다가 못 찾는 일이 흔합니다.
:::

## 플랫폼별 깊이 확보

### VRChat (주 대상)

| 상황 | 깊이 |
|---|---|
| **Photo Camera 활성 중** | ✅ 공식 계약으로 호스트 깊이가 켜집니다 |
| **월드가 Screen Camera depth를 켠 경우** | ✅ |
| **일반 플레이어 화면 (기본)** | ❌ 아바타가 강제할 수 없습니다 |
| **미러 · 스트림 내부 경로** | ⚠️ 보장되지 않습니다 |

Screen Camera 설정은 **월드/Udon 측 권한**입니다. 아바타에 Camera나 Light를 추가하는 것은 동등한 해결책이 아니며, 성능 비용을 올리거나 아바타 안전 설정에 의해 제거될 수 있습니다.

업로드 시 MingToon이 `Depth Availability`를 `Auto`에서 `Force On`으로 자동 승격합니다. 자세한 내용은 [VRChat](/platforms/vrchat)을 보세요.

:::tip 깊이가 없는 화면을 위한 대비
[림](/guides/rim)의 림 라이트·림 셰이드와 [아웃라인](/guides/outline)의 노멀 아웃라인은 **깊이가 필요 없습니다.** 깊이 기반 효과에만 의존하지 말고 이 둘로 실루엣의 바닥을 깔아 두세요.
:::

### 일반 Unity (BRP)

씬에 `Studio Raming/MingToon/Depth Texture Provider` 컴포넌트를 두면 됩니다. 활성 Game Camera가 렌더하기 직전에 필요한 depth flag와 카메라 행렬을 제공하고, 기존 카메라 플래그는 보존합니다.

### URP 12

1. `Tools > Studio Raming > MingToon > URP > Install Depth Effects Renderer Feature`를 실행합니다.
2. 아웃라인도 쓴다면 `Tools > Studio Raming > MingToon > URP > Install Outline Renderer Feature`도 실행합니다.
3. 사용 중인 URP Renderer Data에서 **Depth Texture**를 활성화합니다.

### Warudo

Depth를 켠 Warudo 카메라가 필요합니다. 아바타 번들만으로는 호스트 카메라를 바꿀 수 없는 경우가 있습니다. → [Warudo](/platforms/warudo)

## 안 보일 때 진단 순서

위에서부터 차례로 확인하세요.

1. **전체 효과** — 마스터가 꺼져 있지 않은가 ([인스펙터 사용법](/guides/inspector#전체-효과--가장-위의-마스터-스위치))
2. **깊이 효과** 섹션의 마스터 토글
3. **표면 모드** — 투명(깊이 미기록)이면 전부 꺼집니다. `투명 · 아웃라인용 깊이 기록`으로 바꾸세요
4. **마스터 폭** — 0이면 각 모듈의 폭을 아무리 올려도 아무것도 나오지 않습니다
5. **각 모듈의 강도** — `림 강도`가 0이면 림 계산을 건너뜁니다
6. **카메라 깊이** — 위의 플랫폼별 항목
7. 계속되면 `Tools > Studio Raming > MingToon > Validate Project`

## 깊이 — 공통 값

`깊이 림`과 `2D 그림자`가 **공유**하는 값입니다. 여기를 먼저 잡고 각 모듈로 내려가세요.

| 항목 | 하는 일 |
|---|---|
| `마스터 폭` | 두 모듈의 화면 오프셋에 공통으로 곱해지는 배수. **0이면 전부 안 나옵니다** |
| `폭 모드` | `Screen Pixels`는 화면 픽셀 기준 · `Distance Stable`은 거리·FOV가 변해도 두께 일정 |
| `거리 스케일` | `Distance Stable`일 때 기준 거리. `Screen Pixels`면 무시됩니다 |
| `마스터 바이어스` | 이 값을 넘는 깊이 차이만 경계로 인정. **낮추면** 얕은 굴곡에도 선이 붙어 지저분해지고, **올리면** 얇은 부위의 선이 사라집니다 |
| `마스터 부드러움` | 낮으면 딱딱한 잉크선, 높으면 부드럽게 번진 경계 |

:::tip 아바타에는 Distance Stable
카메라 거리가 계속 변하는 환경에서는 `Distance Stable`이 두께를 일정하게 유지합니다.
:::

## 깊이 림 (2D 림)

최종 두께 = `마스터 폭` × `림 폭 배수` 입니다.

- `림 강도` — **0이면 계산을 건너뜁니다.** 색과 폭을 바꿔도 아무것도 안 보입니다.
- `베이스 색 혼합` — 0이면 단색 림, 1이면 베이스 맵 색을 곱해 부위마다 다른 림 색.
- `360도 림` — 0이면 광원 방향 쪽에만, 1이면 실루엣 전체를 감쌉니다.
- `2D 림 방향` — 림이 밀려나는 방향.

:::tip 조명이 없거나 방향이 자주 바뀌는 환경
`360도 림`을 올려 두면 안정적입니다.
:::

`실루엣 시작점`과 `실루엣 전환 부드러움`은 **같은 그룹의 외곽 실루엣 제한이 0이면 전혀 반영되지 않습니다.**

`빠른 설정`의 `2D 림 폭`·`2D 림 강도`가 이 섹션의 값입니다.

## 2D 그림자

캐릭터의 실루엣을 화면 공간에서 밀어 그림자를 만듭니다. 앞머리가 이마에 드리우는 그림자를 실시간 섀도우 없이 그릴 때 주로 씁니다.

### 기본

| 항목 | 하는 일 |
|---|---|
| `그림자 밝기` | 낮출수록 어두워집니다. [캐스트 그림자와 통합](/guides/light-and-shadow#2d-그림자와-색이-따로-놀-때)해 두면 이 값이 통합된 층의 밝기로 쓰입니다 |
| `추가 깊이 바이어스` | 마스터 바이어스에 더해지는 이 모듈 전용 값 |

### 방향

`실루엣 이동 방향` — 실루엣을 어느 쪽으로 밀지 정합니다.

| 값 | 결과 |
|---|---|
| `조명 투영 방향` | 광원이 미는 방향 그대로. 물리적으로 자연스러움 |
| `조명 투영 반대` | 반대쪽. 연출 의도로 뒤집을 때 |

`2D 그림자 조명 방향 추적`을 켜면 씬 광원을 따라가고, 끄면 고정됩니다.

:::tip 조명이 예측 불가능한 월드라면
방향 추적을 끄고 고정하는 편이 안정적입니다. 월드마다 앞머리 그림자가 엉뚱한 쪽으로 붙는 것을 막습니다.
:::

`위·아래 오프셋`과 `앞·뒤 오프셋`으로 그림자 위치를 미세 조정합니다.

### 얼굴 전용 보조

얼굴은 별도 항목이 있습니다.

| 항목 | 하는 일 |
|---|---|
| `얼굴 2D 그림자 보조` | 얼굴 영역에서 2D 그림자를 보강 |
| `얼굴 고정 방향` | 얼굴이 기준으로 삼을 방향을 고정 |
| `얼굴 자기면 억제` | 얼굴 자체 면에 그림자가 눌어붙는 것을 억제 |

→ [캐릭터 표현](/guides/character#4단계-앞머리-그림자)

### 눌어붙음과 감쇠

| 항목 | 하는 일 |
|---|---|
| `몸체 표면 가드` | 몸 표면 자체에 그림자가 들러붙는 것을 막습니다 |
| `2D 그림자 캐스트 도달 거리` | 실루엣에서 얼마나 멀리까지 그림자가 뻗는지 |
| `거리 감쇠 범위` (`거리 감쇠와 경계` 그룹) | 멀어질수록 효과를 줄입니다 |

:::caution 그림자가 몸에 얼룩처럼 들러붙으면
`몸체 표면 가드`를 먼저 올리세요. 그래도 남으면 `마스터 바이어스`나 `추가 깊이 바이어스`를 올립니다.
:::

## 내부 2D 경계

화면 깊이 차이로 **표면 안쪽** 경계선을 그립니다. 추가 지오메트리가 없어서 노멀 아웃라인이 깨지는 메시에도 쓸 수 있습니다.

:::danger 표면 모드가 투명이면 동작하지 않습니다
반투명이 필요하면 `투명 · 아웃라인용 깊이 기록`을 쓰세요.
:::

조정 항목:

- `깊이 바이어스` — 이 값보다 큰 깊이 차이만 경계로 인정합니다. **낮추면** 완만한 굴곡에도 선이 붙어 노이즈가 되고, **올리면** 얇은 부위의 선이 사라집니다.
- `부드러움` — 0은 단단한 선, 1은 선 폭 전체가 경계에서 안쪽 끝까지 완전히 흐려집니다.
- `카메라 거리·화각 안정화` — 카메라가 움직여도 선 두께가 일정하게 유지됩니다.

:::caution 내부 2D 경계가 통째로 사라졌다면
`Inner Edge 외곽선에 적용` 토글을 확인하세요. 이 토글은 노멀 아웃라인 그룹 안에 있지만 **노멀 아웃라인을 꺼도 내부 2D 경계에 계속 작용합니다.** 버텍스 컬러가 검은 메시에서 켜져 있으면 내부 2D 경계가 전부 사라집니다.
:::

## 반투명 표면과 깊이

표면 모드가 두 갈래로 갈리고, 차이는 **깊이를 기록하느냐**입니다.

- **투명 · 아웃라인용 깊이 기록** — 깊이 텍스처를 만드는 범위 **안**입니다. 2D 그림자·깊이 림·내부 2D 경계가 전부 동작합니다. **반투명이 필요하면 이쪽을 먼저 검토하세요.**
- **투명** — 그 범위 **밖**입니다. 깊이 기반 모듈은 꺼진 채로 둡니다. 켜면 캐릭터 뒤에 있는 것과 비교하게 됩니다.

불투명과 컷아웃은 영향을 받지 않고 항상 완전한 깊이를 갖습니다.
