# 아웃라인

**이 문서를 읽으면** 노멀 아웃라인을 세우고, 부위마다 굵기를 칠해 조절할 수 있습니다.

인스펙터의 **아웃라인** 그룹 — `노멀 아웃라인` 을 다룹니다. 전체 항목 목록은 [아웃라인 레퍼런스](/reference/outline)에 있습니다.

:::note[내부 2D 경계는 여기 없습니다]
표면 안쪽 선을 그리는 `내부 2D 경계`는 화면 깊이를 읽기 때문에 **깊이 기반 효과** 그룹에 있습니다. → [깊이 기반 효과](/guides/depth-effects#내부-2d-경계)
:::

## 노멀 아웃라인 {#노멀-아웃라인}

메시를 뒤집어 확장하는 방식입니다. 추가 패스 한 번으로 그려지고 **깊이 텍스처 없이 동작**하므로 어떤 환경에서도 안전합니다. VRChat 일반 화면처럼 깊이를 못 쓰는 곳에서 실루엣을 잡는 유일한 수단입니다.

### 기본 설정 {#기본-설정}

1. `클래식 헐 사용`을 켭니다.
2. `폭 모드`를 고릅니다.

| 폭 모드 | 동작 | 권장 |
|---|---|---|
| `PixelStable` | 화면 픽셀 기준. 거리와 무관하게 두께 일정 | **아바타에는 이쪽** |
| `WorldSpace` | 월드 크기 기준. 멀어지면 얇아짐 | 고정 카메라 연출 |

3. `아웃라인 폭`과 `아웃라인 색상`을 조정합니다. (`빠른 설정`에도 있습니다)

**이렇게 되면 정상입니다.** 캐릭터 실루엣 바깥에 선이 그려집니다.

## 선 굵기를 부위마다 다르게 {#선-굵기를-부위마다-다르게}

### 압력 소스 고르기 {#압력-소스-고르기}

`압력 소스`로 굵기를 조절할 페인팅 채널을 고릅니다.

| 소스 | 읽는 것 |
|---|---|
| `VertexRed` | 버텍스 컬러 R |
| `VertexAlpha` | 버텍스 컬러 A |
| `WidthMask` | 폭 마스크 텍스처 |
| `OutlineNormalUV8` | UV8에 구운 외곽선 노멀. 긴 면은 두껍게, 꼭짓점은 얇게 |

:::danger[선이 통째로 사라졌다면]
**버텍스 컬러가 검게 임포트된 메시**에서 `VertexRed`를 고른 경우입니다. 압력이 0이면 폭도 0이 됩니다. 압력 소스를 바꾸거나 버텍스 컬러를 확인하세요.
:::

`헐 압력 대비`는 굵기 차이를 키웁니다. **0이면 압력이 완전히 무시**되고, 1이 원본, 높일수록 얇은 곳이 더 얇아집니다.

`Hull 외곽선에 적용` / `Inner Edge 외곽선에 적용`으로 압력을 어느 쪽에 반영할지 정합니다.

:::caution[`Inner Edge 외곽선에 적용`은 노멀 아웃라인을 꺼도 작동합니다]
이 토글은 노멀 아웃라인 그룹 안에 있지만 [내부 2D 경계](/guides/depth-effects#내부-2d-경계)에 계속 작용합니다. 버텍스 컬러가 검은 메시에서 켜져 있으면 내부 2D 경계가 통째로 사라집니다.
:::

### 씬 뷰에서 직접 칠하기 {#씬-뷰에서-직접-칠하기}

굵기를 손으로 칠할 수 있습니다.

#### 준비

1. `압력 소스`를 **Vertex Alpha** 또는 **Vertex Red**로 둡니다. 아니면 인스펙터가 `버텍스 페인팅으로 두께를 조절하려면 Pressure Source가 Vertex Alpha 또는 Vertex Red여야 합니다.` 와 함께 `Vertex Alpha로 전환` 버튼을 보여 줍니다.
2. 이 머티리얼을 쓰는 렌더러가 **현재 선택 항목 아래에** 있어야 합니다. 밍툰 매니저를 선택하면 됩니다.
3. 머티리얼은 **하나만** 선택합니다.

:::danger[채널 충돌 경고가 뜨면 그냥 진행하지 마세요]
`압력 소스`가 **Vertex Red**이고 `노멀 소스`가 **VertexColorTS**이면 둘 다 같은 버텍스 컬러를 읽습니다. 이대로 칠하면 **RGB에 저장된 아웃라인 방향이 덮어써지고**, 깊이 효과 마스크도 레드 채널을 함께 읽습니다.

인스펙터가 이를 경고하고 `그래도 칠하기` 버튼을 줍니다. 진행 전에 둘 중 하나를 하세요.
- `압력 소스`를 **Vertex Alpha**로 바꾸기
- 아웃라인 노멀을 **UV8TS**로 옮기기 → [메시 UV 베이크](/guides/mesh-bakes#아웃라인-스무스-노멀-uv8)
:::

#### 칠하기

`씬 뷰에서 외곽선 두께 칠하기`를 누르면 씬 뷰에 오버레이가 뜹니다.

| 조작 | 동작 |
|---|---|
| 드래그 | 칠하기 |
| **Shift** + 드래그 | 지우기 |
| `[` `]` | 브러시 크기 |
| Esc | 종료 |

오버레이에서 조정할 수 있는 값:

| 항목 | 하는 일 |
|---|---|
| `반경` | 브러시 크기 |
| `강도` | 한 번에 칠해지는 양 |
| `감쇠` | 브러시 가장자리의 부드러움 |
| `뒷면까지 칠하기` | 화면에서 안 보이는 뒷면 정점까지 함께 |

현재 채널이 `채널: Vertex Red (Shift = 지우기)` 처럼 항상 표시되고, Vertex Red일 때는 `레드 채널은 깊이 효과 마스크도 함께 읽습니다.` 라고 함께 알려 줍니다.

마치면 `외곽선 칠하기 종료` 또는 Esc.

<!-- SCREENSHOT: 씬 뷰 외곽선 두께 페인팅 오버레이 -->

#### 알아 둘 것

:::danger[버텍스 페인팅은 메시 에셋을 디스크에 직접 씁니다]
- **Play 모드에서는 차단됩니다.** Unity가 되돌려 주지 않기 때문입니다. Play를 끝내고 다시 시작하세요.
- **같은 메시를 쓰는 다른 렌더러도 함께 바뀝니다.** 인스펙터가 어떤 메시 에셋이 영향을 받는지 목록으로 경고합니다. 이 렌더러에만 적용하려면 **먼저 메시를 복제해 이 렌더러에 할당한 뒤** 칠하세요.
:::

:::note[임포트된 메시는 사본이 자동 생성됩니다]
원본 FBX는 건드리지 않고 편집 가능한 사본을 만들어 렌더러에 할당합니다.

칠하는 도중 Undo로 원본 메시가 복원되면 페인팅이 중단됩니다 (`Undo로 '{메시}'의 원본 메시가 복원되어 칠하던 사본이 더 이상 사용되지 않습니다.`). 다시 시작하면 됩니다.
:::

칠할 수 없는 경우와 조치는 [문제 해결](/troubleshooting#씬-뷰에서-아웃라인-두께를-칠할-수-없다)에 정리되어 있습니다.

## 각진 부분에서 선이 끊길 때 {#각진-부분에서-선이-끊길-때}

`노멀 소스`가 원인입니다.

| 소스 | 조건 |
|---|---|
| `MeshNormal` | 메시 노멀 그대로. 하드 엣지에서 선이 벌어집니다 |
| `VertexColorTS` / `UV8TS` | **스무딩한 외곽선 노멀을 버텍스 컬러나 UV8에 구워 두었을 때만** 유효합니다 |

:::danger[굽지 않은 메시에서 `VertexColorTS`/`UV8TS`를 고르면]
오히려 각진 부분에서 선이 **더** 끊어집니다. 굽지 않았다면 `MeshNormal`을 쓰세요.
:::

방향을 텍스처로 직접 지정할 수도 있습니다. `지정 벡터 방향 사용`을 켜고 `벡터 UV`와 `벡터 스케일`을 설정합니다. 스케일을 음수로 두면 방향이 뒤집힙니다. 끄면 이 두 항목은 무시되고 `노멀 소스`가 방향을 결정합니다.

## 선이 다른 파츠에 파묻힐 때

`깊이 바이어스`로 헐 전체를 카메라 쪽으로 당깁니다. **너무 많이 당기면 선이 얼굴 앞으로 떠올라 보입니다.**

몸 안쪽에 불필요한 선이 나오면 `내부선 억제 오프셋`으로 헐을 표면 쪽으로 가라앉힙니다.

## 아웃라인 색이 조명을 따라가게 {#아웃라인-색이-조명을-따라가게}

`셰이딩 포함`을 켜면 형태·캐스트·2D 그림자와 2D 림이 아웃라인 색상에 반영됩니다. 끄면 조명과 무관한 균일한 색을 유지합니다.

## 다른 셰이더와 겹칠 때

`스텐실 설정`은 다른 셰이더의 마스크와 연동할 때만 건드립니다. 기본값에서는 스텐실이 아웃라인에 영향을 주지 않습니다.

`컬러 마스크`가 0이면 아웃라인이 화면에 전혀 기록되지 않습니다. 기본값 15가 RGBA 전체입니다.
