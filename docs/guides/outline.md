# 아웃라인

**이 문서를 읽으면** 노멀 아웃라인을 세우고, 부위마다 굵기를 칠해 조절할 수 있습니다.

인스펙터의 **아웃라인** 그룹 — `노멀 아웃라인` 을 다룹니다. 전체 항목 목록은 [아웃라인 레퍼런스](/reference/outline)에 있습니다.

:::note 내부 2D 경계는 여기 없습니다
표면 안쪽 선을 그리는 `내부 2D 경계`는 화면 깊이를 읽기 때문에 **깊이 기반 효과** 그룹에 있습니다. → [깊이 기반 효과](/guides/depth-effects#내부-2d-경계)
:::

## 노멀 아웃라인

메시를 뒤집어 확장하는 방식입니다. 추가 패스 한 번으로 그려지고 **깊이 텍스처 없이 동작**하므로 어떤 환경에서도 안전합니다. VRChat 일반 화면처럼 깊이를 못 쓰는 곳에서 실루엣을 잡는 유일한 수단입니다.

### 기본 설정

1. `클래식 헐 사용`을 켭니다.
2. `폭 모드`를 고릅니다.

| 폭 모드 | 동작 | 권장 |
|---|---|---|
| `PixelStable` | 화면 픽셀 기준. 거리와 무관하게 두께 일정 | **아바타에는 이쪽** |
| `WorldSpace` | 월드 크기 기준. 멀어지면 얇아짐 | 고정 카메라 연출 |

3. `아웃라인 폭`과 `아웃라인 색상`을 조정합니다. (`빠른 설정`에도 있습니다)

**이렇게 되면 정상입니다.** 캐릭터 실루엣 바깥에 선이 그려집니다.

## 선 굵기를 부위마다 다르게

### 압력 소스 고르기

`압력 소스`로 굵기를 조절할 페인팅 채널을 고릅니다.

| 소스 | 읽는 것 |
|---|---|
| `VertexRed` | 버텍스 컬러 R |
| `VertexAlpha` | 버텍스 컬러 A |
| `WidthMask` | 폭 마스크 텍스처 |
| `OutlineNormalUV8` | UV8에 구운 외곽선 노멀. 긴 면은 두껍게, 꼭짓점은 얇게 |

:::danger 선이 통째로 사라졌다면
**버텍스 컬러가 검게 임포트된 메시**에서 `VertexRed`를 고른 경우입니다. 압력이 0이면 폭도 0이 됩니다. 압력 소스를 바꾸거나 버텍스 컬러를 확인하세요.
:::

`헐 압력 대비`는 굵기 차이를 키웁니다. **0이면 압력이 완전히 무시**되고, 1이 원본, 높일수록 얇은 곳이 더 얇아집니다.

`Hull 외곽선에 적용` / `Inner Edge 외곽선에 적용`으로 압력을 어느 쪽에 반영할지 정합니다.

:::caution `Inner Edge 외곽선에 적용`은 노멀 아웃라인을 꺼도 작동합니다
이 토글은 노멀 아웃라인 그룹 안에 있지만 [내부 2D 경계](/guides/depth-effects#내부-2d-경계)에 계속 작용합니다. 버텍스 컬러가 검은 메시에서 켜져 있으면 내부 2D 경계가 통째로 사라집니다.
:::

### 씬 뷰에서 직접 칠하기

굵기를 손으로 칠할 수 있습니다.

1. `압력 소스`를 **Vertex Alpha** 또는 **Vertex Red**로 둡니다. 아니면 `Vertex Alpha로 전환` 버튼이 표시됩니다.
2. 이 머티리얼을 쓰는 렌더러가 **현재 선택 항목 아래에** 있어야 합니다.
3. `씬 뷰에서 외곽선 두께 칠하기`를 누릅니다.
4. 씬 뷰에서 조작합니다.

| 조작 | 동작 |
|---|---|
| 드래그 | 칠하기 |
| Shift + 드래그 | 지우기 |
| `[` `]` | 브러시 크기 |
| Esc | 종료 |

5. `외곽선 칠하기 종료`로 마칩니다.

:::note 임포트된 메시도 칠할 수 있습니다
편집 가능한 사본이 자동 생성됩니다. 원본 FBX는 건드리지 않습니다.

단, 버텍스 페인팅은 **머티리얼을 하나만 선택했을 때만** 사용할 수 있습니다.
:::

## 각진 부분에서 선이 끊길 때

`노멀 소스`가 원인입니다.

| 소스 | 조건 |
|---|---|
| `MeshNormal` | 메시 노멀 그대로. 하드 엣지에서 선이 벌어집니다 |
| `VertexColorTS` / `UV8TS` | **스무딩한 외곽선 노멀을 버텍스 컬러나 UV8에 구워 두었을 때만** 유효합니다 |

:::danger 굽지 않은 메시에서 `VertexColorTS`/`UV8TS`를 고르면
오히려 각진 부분에서 선이 **더** 끊어집니다. 굽지 않았다면 `MeshNormal`을 쓰세요.
:::

방향을 텍스처로 직접 지정할 수도 있습니다. `지정 벡터 방향 사용`을 켜고 `벡터 UV`와 `벡터 스케일`을 설정합니다. 스케일을 음수로 두면 방향이 뒤집힙니다. 끄면 이 두 항목은 무시되고 `노멀 소스`가 방향을 결정합니다.

## 선이 다른 파츠에 파묻힐 때

`깊이 바이어스`로 헐 전체를 카메라 쪽으로 당깁니다. **너무 많이 당기면 선이 얼굴 앞으로 떠올라 보입니다.**

몸 안쪽에 불필요한 선이 나오면 `내부선 억제 오프셋`으로 헐을 표면 쪽으로 가라앉힙니다.

## 아웃라인 색이 조명을 따라가게

`셰이딩 포함`을 켜면 형태·캐스트·2D 그림자와 2D 림이 아웃라인 색상에 반영됩니다. 끄면 조명과 무관한 균일한 색을 유지합니다.

## 다른 셰이더와 겹칠 때

`스텐실 설정`은 다른 셰이더의 마스크와 연동할 때만 건드립니다. 기본값에서는 스텐실이 아웃라인에 영향을 주지 않습니다.

`컬러 마스크`가 0이면 아웃라인이 화면에 전혀 기록되지 않습니다. 기본값 15가 RGBA 전체입니다.
