# 아웃라인

> 이 페이지는 **노멀 아웃라인**을 처음 켜 보는 분을 위한 것입니다.
> 캐릭터 실루엣 바깥에 만화 같은 윤곽선을 그립니다. 약 3분 걸립니다.

## 이게 뭔가요

메시를 살짝 부풀린 껍데기를 한 겹 더 그려 실루엣에 선을 남깁니다.
뎁스 텍스처를 읽지 않으므로 VRChat 일반 화면에서도 그려집니다.

## 언제 쓰나요

- 아바타를 만화풍으로 또렷하게 만들고 싶을 때
- 밝은 배경에서 캐릭터 실루엣이 묻혀 보일 때

## 30초 만에 켜 보기

1. 변환한 재질을 하나 고릅니다.
2. **노멀 아웃라인 사용** 을 켭니다.
3. **아웃라인 폭** 을 1로 둡니다.
4. **아웃라인 색상** 을 베이스보다 어두운 색으로 바꿉니다.

실루엣 바깥에 선이 보이면 성공입니다.
아무 선도 없으면 [아웃라인 문제 해결](/troubleshooting#outline)로 가세요.

## 노멀 아웃라인 {#노멀-아웃라인}

### 기본 설정 {#기본-설정}

1. **노멀 아웃라인 사용** 을 켭니다.
2. **폭 모드** 를 고릅니다.
3. **아웃라인 폭** 과 **아웃라인 색상** 을 맞춥니다.

**폭 모드** 의 기본값은 `WorldSpace`이고, 멀어질수록 선이 얇아집니다.
`PixelStable`은 화면 픽셀 기준이라 거리가 멀어져도 굵기가 같습니다.
아바타에는 `PixelStable`이 안전합니다.

:::caution[URP에서는 Renderer Feature가 있어야 합니다]
URP 프로젝트는 활성 URP 에셋의 모든 렌더러에 기능이 필요합니다.
없으면 값은 전부 편집되지만 선이 한 픽셀도 그려지지 않습니다.
`StudioRaming > MingToon > URP > Install Outline Renderer Feature`
:::

**아웃라인 마스터** 는 노멀 아웃라인과 Inner Depth Edge의 공통 스위치입니다.
이 값이 꺼져 있으면 두 탭 모두 그려지지 않습니다.

## 자주 만지는 값

| 인스펙터 라벨 | 뭘 바꾸는지 | 추천 시작값 | 올리면 / 내리면 |
|---|---|---|---|
| **아웃라인 폭** | 선의 굵기 | 기본값 그대로(1) | 올리면 두꺼워지고, 0이면 사라집니다 |
| **아웃라인 색상** | 선의 색 | 베이스보다 어두운 색 | 검정에 가까울수록 만화풍이 강해집니다 |
| **아웃라인 색 혼합 세기** | 색 혼합 방식이 먹히는 양 | 기본값 그대로(1) | 0으로 내리면 혼합색 영향이 사라집니다 |
| **압력 대비** | 부위별 굵기 차이의 크기 | 기본값 그대로(2) | 올리면 얇은 곳이 더 얇아지고, 0이면 압력을 무시합니다 |
| **원거리 최소 픽셀** | 멀리서 선이 유지되는 최소 굵기 | 기본값 그대로(0.95) | 올리면 멀리서도 선이 남고, 0이면 끊겨 보입니다 |
| **깊이 바이어스** | 선 전체를 앞뒤로 미는 양 | 0 | 올리면 파묻힌 선이 드러나고, 너무 올리면 얼굴 앞에 뜹니다 |
| **DOF에서 아웃라인 보호** | 심도 흐림이 선을 지우지 않게 | 기본값 그대로(켜짐) | 끄면 심도 흐림이 켜진 월드에서 선이 번져 사라집니다 |

전체 항목과 범위는 [아웃라인 레퍼런스](/reference/outline)에 있습니다.

**DOF에서 아웃라인 보호** 는 BRP와 URP에서 같게 동작합니다.
백엔드가 갈리는 지점은 위의 Renderer Feature 설치 여부뿐입니다.

## 선 굵기를 부위마다 다르게 {#선-굵기를-부위마다-다르게}

### 압력 소스 고르기 {#압력-소스-고르기}

**압력 소스** 는 굵기를 조절할 채널을 정합니다. 기본값은 `Constant`입니다.

| 값 | 읽는 것 |
|---|---|
| `Constant` | 아무것도 읽지 않고 폭을 그대로 씁니다 |
| `VertexAlpha` | 버텍스 컬러 A |
| `VertexRed` | 버텍스 컬러 R |
| `WidthMask` | 폭 마스크 텍스처 |
| `OutlineNormalUV8` | UV8에 구운 값. 긴 면은 두껍게, 꼭짓점은 얇게 |

압력을 어느 선에 반영할지는 **노멀 아웃라인에 적용** 과
**이너 아웃라인에 적용** 이 각각 정합니다.

:::caution[이너 아웃라인에 적용은 노멀 아웃라인을 꺼도 작동합니다]
이 토글은 노멀 아웃라인 그룹에 있지만 Inner Depth Edge에 계속 작용합니다.
버텍스 컬러가 검은 메시에서 켜 두면 내부 선이 통째로 사라집니다.
:::

### 씬 뷰에서 직접 칠하기 {#씬-뷰에서-직접-칠하기}

1. **압력 소스** 를 `VertexAlpha` 또는 `VertexRed`로 둡니다.
2. 이 재질을 쓰는 렌더러를 선택 항목 아래에 둡니다. 밍툰 매니저를 고르면 됩니다.
3. 재질을 하나만 선택합니다.
4. **씬 뷰에서 외곽선 두께 칠하기** 를 누릅니다.

드래그로 칠하고, Shift와 함께 드래그하면 지웁니다.
`[` 와 `]` 로 브러시 크기를 바꾸고, Esc로 끝냅니다.
오버레이에서 **반경** · **강도** · **감쇠** · **뒷면까지 칠하기** 를 조절합니다.

![씬 뷰에 뜬 아웃라인 두께 페인팅 오버레이와 칠해진 메시](/img/placeholder.png)
<!-- CAPTURE: guides/outline-02-vertex-paint.png | 씬 뷰 아웃라인 두께 페인팅 오버레이 + 반경/강도/감쇠 행 + 칠한 자리의 굵기 차이 | 1200x700 -->

:::danger[버텍스 페인팅은 메시 에셋을 디스크에 직접 씁니다]
Play 모드에서는 차단됩니다. Unity가 되돌려 주지 않기 때문입니다.
같은 메시를 쓰는 다른 렌더러도 함께 바뀝니다.
:::

이 렌더러에만 적용하려면 메시를 복제해 할당한 뒤 칠하세요.
**압력 소스** 가 `VertexRed`이고 **노멀 소스** 가 `VertexColorTS`이면
둘이 같은 채널을 읽습니다. 압력 소스를 `VertexAlpha`로 바꾸세요.

## 각진 부분에서 선이 끊길 때 {#각진-부분에서-선이-끊길-때}

원인은 **노멀 소스** 입니다. 기본값은 `MeshNormal`입니다.
`VertexColorTS`와 `UV8TS`는 스무딩한 값을 미리 구워 두었을 때만 맞습니다.

굽지 않은 메시에서 `UV8TS`를 고르면 선이 오히려 더 끊어집니다.
UV8을 굽는 방법은 [메시 UV 베이크](/guides/mesh-bakes#아웃라인-스무스-노멀-uv8)에 있습니다.

### 헤어·스커트에서 선이 형태를 벗어날 때 {#헤어스커트에서-선이-형태를-벗어날-때}

구나 원통에서 노멀을 옮겨 온 모델은 셰이딩 노멀이 형태와 다릅니다.
UV8을 구울 때 **노멀을 편집한 모델용으로 계산** 을 켜세요.
→ [노멀을 편집한 모델](/guides/mesh-bakes#노멀을-편집한-모델용으로-계산)

방향을 텍스처로 직접 줄 수도 있습니다.
**지정 벡터 방향 사용** 을 켜고 **벡터 UV** 와 **벡터 스케일** 을 정합니다.
몸 안쪽에 군더더기 선이 나오면 **내부선 억제 오프셋** 을 올립니다.

## 아웃라인 색이 조명을 따라가게 {#아웃라인-색이-조명을-따라가게}

**렌더 적용** 을 켜면 형태 그림자·림·전면광이 선에도 적용됩니다.
굵은 선이 조명을 따라 어두워지는 인상이 남습니다.
끄면 조명과 무관한 균일한 색을 유지합니다.

**전면광 색상** 과 **전면광 세기** 로 밝은 쪽 색을 따로 줄 수 있습니다.
**전면광 세기** 가 0이면 전면광 색은 반영되지 않습니다.
스크린톤을 선에도 찍으려면 **아웃라인 그림자 패턴** 을 켜세요.

VRC Light Volumes 월드에서는 선의 밝기도 볼륨의 밝기를 따릅니다.
BRP는 볼륨을 정점마다 한 번만 읽고 밝기만 프래그먼트로 넘겨, 픽셀당 볼륨 샘플을 늘리지 않습니다.
