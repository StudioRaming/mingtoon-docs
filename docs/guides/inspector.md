# 인스펙터 사용법

**이 문서를 읽으면** MingToon 인스펙터의 구조를 파악하고, 원하는 항목을 빠르게 찾아 여러 재질에 안전하게 적용할 수 있습니다.

## 보기 모드

인스펙터 위쪽 **보기** 에서 세 가지 중 고릅니다.

| 모드 | 보이는 것 | 언제 |
|---|---|---|
| **간단** | 베이스맵 HSVG, 노멀·이미션·오클루전·PBR·맷캡의 핵심, 조명, 최종 최소/최대 밝기 | 톤 잡기, 변환 결과 확인 |
| **전체 설정** | 아래의 워크플로 그룹 전부 | 본격 작업 |
| **일괄 설정** | 여러 재질에 공통으로 쓰는 값만 | 아바타 전체를 한 번에 |

## 전체 설정의 워크플로 그룹

**전체 설정**은 아래 순서로 묶여 있습니다. 이 문서의 "룩 만들기" 항목도 같은 순서입니다.

| 그룹 | 안에 들어 있는 섹션 | 문서 |
|---|---|---|
| **기본 설정** | 기본 표면 · 표면 렌더링 · 공통 맵 | [기본 설정](/guides/basics) |
| **조명과 그림자** | 라이팅 · 그림자 색상 · 형태 그림자 · 그림자 투영 | [조명과 그림자](/guides/light-and-shadow) |
| **림** | 림 셰이드 · 림 라이트 · 백라이트 · 그림자 내부 반사 · 프런트 라이트 | [림](/guides/rim) |
| **깊이 기반 효과** | 깊이 · 깊이 림 · 2D 그림자 · 내부 2D 경계 | [깊이 기반 효과](/guides/depth-effects) |
| **디테일 맵** | 텍스처 레이어 · 노멀 레이어 · 맷캡 레이어 · 오클루전 · 이미션 · 글리터 · PBR 표면 | [디테일 맵](/guides/detail-maps) |
| **캐릭터 표현** | 페이스 셰이딩 · 캐릭터 높이 그라데이션 | [캐릭터 표현](/guides/character) |
| **아웃라인** | 노멀 아웃라인 | [아웃라인](/guides/outline) |
| **출력과 진단** | 고급 렌더링 · 스텐실 설정 · 기술 정보 | — |

:::note[내부 2D 경계는 아웃라인 그룹에 없습니다]
화면 깊이를 읽기 때문에 **깊이 기반 효과** 그룹에 들어 있습니다. 아웃라인 그룹에서 찾다가 못 찾는 일이 흔합니다.
:::

## 전체 효과 — 가장 위의 마스터 스위치

`전체 효과`가 꺼져 있으면 아래 섹션 전체가 비활성 상태가 되고, 그 상태에서는 **어떤 값을 바꿔도 화면이 변하지 않습니다.**

인스펙터가 `이 섹션은 전체 효과가 꺼져 있어 비활성 상태입니다.` 라고 알려 주고, `전체 효과 켜기` 버튼을 함께 표시합니다.

:::danger[아무것도 안 먹힐 때 여기부터]
값을 아무리 만져도 반응이 없다면 `전체 효과`부터 확인하세요. 각 섹션에도 자체 마스터 토글이 있고, 꺼진 섹션은 `(모듈 꺼짐)` 이라고 표시됩니다.
:::

## 빠른 설정

`빠른 설정`은 자주 조정하는 값만 한곳에 모아 둔 영역입니다.

- 1차 그림자 경계 · 1차 그림자 부드러움 · 1차 그림자 혼합량
- 2D 림 폭 · 2D 림 강도
- 아웃라인 폭 · 아웃라인 색상
- 이미션 강도

해당 모듈이 꺼져 있으면 항목 옆에 `(모듈 꺼짐)`이 붙고 `이 모듈 켜기` 버튼이 나옵니다. 여러 재질을 선택해 값이 서로 다르면 `(혼합 상태)`가 표시됩니다.

## 찾기

| 도구 | 하는 일 |
|---|---|
| **검색** | 항목 이름으로 필터. 한/영/일 별칭이 등록되어 있어 "외곽선", "outline", "윤곽선" 모두 아웃라인을 찾습니다 |
| **즐겨찾기만** | 자주 쓰는 항목만 남깁니다. 항목 옆 `즐겨찾기 추가`로 등록 |
| **언어** | 인스펙터 표기 언어. 한국어 / English / 日本語 |
| **진단 정보** | 현재 재질의 상태 정보 |

검색이나 즐겨찾기 필터로 결과가 하나도 없으면 `검색 결과 없음`이 표시됩니다.

## 여러 재질 동시 편집

값이 서로 다른 항목은 **`혼합 값`** 으로 표시됩니다.

:::caution[혼합 값을 먼저 확인하세요]
그 필드를 건드리면 **선택한 모든 재질에 같은 값이 덮어써져** 원래 달랐던 값이 사라집니다. 쓰기 전에 무엇이 혼합 상태인지 보세요.
:::

## 프리셋

`머티리얼 프리셋`으로 룩 전체를 저장하고 불러올 수 있습니다. 여러 재질을 선택한 상태면 `머티리얼 일괄 프리셋`이 됩니다.

프리셋은 모든 수치·색·벡터·렌더 상태를 적용합니다. **대상 재질의 텍스처가 셰이더 기본값과 다르면 그 텍스처와 타일링/오프셋은 보존**되므로, 캐릭터마다 다른 텍스처를 유지한 채 룩만 통일할 수 있습니다.

`팩토리 프리셋`은 동봉된 것, `사용자 프리셋`은 직접 저장한 것입니다.

## 복사 / 붙여넣기

`복사`와 `붙여넣기`로 섹션 단위 값을 다른 재질로 옮길 수 있습니다.

## 편집 성능에 대해

편집용 셰이더는 **모든 기능과 최대 레이어 수를 처음 한 번에 컴파일해 유지**합니다. 그래서 기능 토글을 켜고 끌 때 파란 자리표시 색이나 변형 컴파일 대기가 생기지 않습니다.

사용하지 않는 기능 제거와 경량화는 [빌드할 때](/workflow/build-optimization)만 적용됩니다. **작업 중에는 무거운 것이 정상입니다.**
