# 타일드 머티리얼 컴포저

**이 문서를 읽으면** 재질 슬롯 하나에 서로 다른 재질감 네 개를 넣어, 드로우콜을 늘리지 않고 옷의 천·가죽·금속·라벨을 구분할 수 있습니다.

`Tools > Studio Raming > MingToon > Tiled Material Composer`

## 해결하는 문제

옷 하나에 천과 가죽과 금속 장식이 섞여 있다고 합시다. 보통은 재질을 셋으로 나눕니다. 그러면 **드로우콜이 셋**이 되고, 아바타 성능 등급에도 영향을 줍니다.

컴포저는 대신 **RGBA 마스크 한 장으로 최대 네 개의 논리적 영역**을 한 슬롯 안에서 구분합니다.

```text
마스크 R 채널  →  영역 1 (예: 천)
마스크 G 채널  →  영역 2 (예: 가죽)
마스크 B 채널  →  영역 3 (예: 금속)
마스크 A 채널  →  영역 4 (예: 라벨)
```

기본 영역 이름도 `Cloth` · `Leather` · `Metal` · `Label` 입니다.

## 왜 텍스처 용량이 늘지 않나

여기가 이 도구의 핵심입니다.

> 마스크는 **저주파(low-frequency)** 이고, 표면 맵과 노멀 맵은 **작은 반복 텍스처로 남습니다.**

| | 해상도 | 이유 |
|---|---|---|
| **영역 마스크** | 낮아도 됨 | 어디가 천이고 어디가 가죽인지만 담습니다. 경계가 부드러워도 문제없습니다 |
| **표면·노멀 맵** | 작은 타일 | 천의 짜임, 가죽의 결처럼 **반복되는 패턴**이라 작은 이미지를 반복하면 됩니다 |

즉 옷 전체를 4K로 그리는 대신, **저해상도 마스크 + 작은 반복 텍스처들**로 같은 정보를 담습니다.

:::danger[이 텍스처들은 Reviewed High Quality 베이크에서도 평탄화되지 않습니다]
반복 타일을 UV 전체에 펼쳐 굽는 순간 용량 이점이 사라지고 해상도도 떨어집니다. 베이커가 이 점을 알고 건너뜁니다. → [베이크가 제거하는 것](/internals/bake-internals#텍스처-최적화)
:::

## 절차

1. `MingToon Material` 슬롯에 대상 재질을 넣습니다.
2. `Packed Region Mask`에 RGBA 마스크를 넣습니다.
3. 영역 네 개를 각각 설정합니다.
4. `Apply Four Logical Regions`를 누릅니다.

세 가지 중 하나라도 비어 있으면 `material, mask and region are required` 로 막힙니다.

### 영역별 항목

| 항목 | 하는 일 |
|---|---|
| `Mask Channel` | 이 영역이 읽을 채널 (R/G/B/A) |
| 표면 텍스처 · 틴트 | 텍스처 레이어로 들어감 |
| `Normal Strength` | 노멀 레이어로 들어감 |
| `MatCap Strength` | 맷캡 레이어로 들어감 |

### 무엇으로 변환되나

`Apply`를 누르면 컴포저가 재질의 레이어 모듈을 직접 구성합니다.

| 영역 설정 | 들어가는 곳 |
|---|---|
| 표면 텍스처 · 틴트 · 마스크 | **텍스처 레이어** (`_MingStack*`) |
| 노멀 맵 · 강도 · 마스크 | **노멀 레이어** (`_MingNormal*`) |
| 맷캡 · 강도 · 마스크 | **맷캡 레이어** (`_MingMatcap*`) |

해당 모듈의 `사용` 토글과 `레이어 수`도 함께 맞춥니다.

:::note[적용 후에는 평범한 레이어 재질입니다]
컴포저는 레이어를 **채워 넣는 도구**일 뿐, 별도의 런타임이나 특수 모드를 만들지 않습니다. 적용 뒤에는 [디테일 맵](/guides/detail-maps)과 [텍스처 슬롯 공통 UI](/guides/texture-modules)에서 평소처럼 손보면 됩니다.
:::

## 마스크 만들 때

| 권장 | 이유 |
|---|---|
| 채널을 **겹치지 않게** 칠하기 | 한 픽셀이 두 영역에 속하면 두 레이어가 겹쳐 합성됩니다 |
| 경계는 **약간 부드럽게** | 딱 끊으면 계단이 보입니다. 저주파 마스크의 장점을 살리세요 |
| **sRGB 끄기** | 마스크는 색이 아니라 가중치입니다 |
| 압축은 취향 | 마스크는 저주파라 압축 아티팩트가 잘 안 보입니다 |

:::tip[네 영역이 다 필요하지 않다면]
채널을 비워 두면 됩니다. 두 영역만 써도 드로우콜 절감 효과는 그대로입니다.
:::

## 언제 쓰고 언제 안 쓰나

| 상황 | 판단 |
|---|---|
| 옷 하나에 재질감이 여러 개 | ✅ 정확히 이 도구의 용도 |
| 아바타 성능 등급을 낮춰야 함 | ✅ 재질 수가 줄어듭니다 |
| 반복되지 않는 큰 그림(일러스트 텍스처) | ❌ 타일링이 성립하지 않습니다. 베이스 맵을 그대로 쓰세요 |
| 영역마다 표면 모드가 달라야 함 | ❌ 한 재질은 표면 모드가 하나입니다. 재질을 나눠야 합니다 |

:::caution[표면 모드는 나눌 수 없습니다]
불투명 천과 반투명 레이스를 한 슬롯에 넣을 수는 없습니다. 표면 모드·컬 모드·렌더 큐는 재질 단위 속성입니다. → [셰이더 구조와 패스](/internals/shader-structure#표면-모드가-실제로-바꾸는-값)
:::
