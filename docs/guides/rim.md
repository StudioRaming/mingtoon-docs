# 림

**이 문서를 읽으면** 실루엣을 살리는 다섯 가지 수단을 구분하고, 어느 것부터 켜야 하는지 알게 됩니다.

인스펙터의 **림** 그룹 — `림 셰이드` · `림 라이트` · `백라이트` · `그림자 내부 반사` · `프런트 라이트` 를 다룹니다. 전체 항목 목록은 [림 레퍼런스](/reference/rim)에 있습니다.

## 무엇을 켤지 먼저 고릅니다

| 섹션 | 어디에 생기나 | 쓰는 곳 |
|---|---|---|
| **림 셰이드** | 실루엣 안쪽, **어둡게** | 부피감. 일러스트에서 가장자리에 넣는 음영 |
| **림 라이트** | 실루엣 안쪽, **밝게** | 역광 느낌, 캐릭터를 배경에서 분리 |
| **백라이트** | 표면 뒤쪽 주광이 만드는 역광 띠 | 주광 방향을 살릴 때 |
| **프런트 라이트** | 카메라를 향한 면 | 정면 강조 |
| **그림자 내부 반사** | 그림자 안쪽에만 | 그림자가 죽지 않게 |

:::caution[겹쳐 켜면 금세 과해집니다]
하나씩 켜고 확인하면서 올리세요. 특히 림 라이트와 백라이트를 같이 올리면 실루엣이 하얗게 날아갑니다.
:::

이 다섯 가지는 모두 **카메라 깊이가 필요 없습니다.** 어떤 환경에서도 동작하므로, 깊이를 못 쓰는 VRChat 일반 화면에서 실루엣을 유지하는 수단으로 쓸 수 있습니다. 깊이를 읽는 `깊이 림`은 [깊이 기반 효과](/guides/depth-effects)에 있습니다.

## 림 라이트 {#림-라이트}

시선 각도에 반응하는 밝은 테두리광입니다. 만지는 순서:

1. `강도` — **0이면 색과 폭을 바꿔도 화면에 나타나지 않습니다.** 여기부터 올리세요.
2. `폭` — 림이 시작되는 지점. 0이면 안 나오고, 1에 가까우면 표면 전체가 밝아집니다.
3. `프레넬 감쇠` — 클수록 실루엣 가장자리로 얇게 몰립니다. 1에 가까울수록 가장 또렷합니다.
4. `부드러움` — 낮추면 셀 룩의 단단한 띠, 올리면 그라데이션.

환경에 맞추는 항목:

| 항목 | 0 | 1 |
|---|---|---|
| `광원 방향 영향` | 카메라 기준으로 실루엣 전체에 림 | 광원이 있는 쪽에만 남음 |
| `베이스 색 영향` | 지정한 림 색 그대로 | 베이스 맵 색을 곱해 재질별로 다른 림 색 |
| `씬 조명 영향` | 씬 밝기와 무관하게 항상 같은 세기 | 조명이 어두워지면 림도 어두워짐 |

:::tip[조명을 통제할 수 없는 환경이라면]
`광원 방향 영향`과 `씬 조명 영향`을 낮게 두세요. 어떤 월드에 들어가도 림이 일정하게 남습니다. 씬에 방향광이 없으면 `광원 방향 영향`은 어차피 차이가 없습니다.
:::

## 림 셰이드 {#림-셰이드}

실루엣 **안쪽에 어두운 띠**를 넣어 부피감을 만듭니다.

- `그림자 기여 강도` — **0이면 계산 자체를 건너뛰므로** 폭·감쇠·부드러움을 바꿔도 변화가 없습니다.
- `림 그림자 폭` — 띠가 시작되는 지점. 0이면 나타나지 않습니다.
- `림 감쇠` — 클수록 가장자리에 얇게 붙습니다.
- `경계 부드러움` — 낮추면 잉크로 그은 선처럼 단단해집니다.

:::tip[림 라이트보다 먼저 이쪽을 시도해 보세요]
밝게 더하는 것보다 어둡게 빼는 편이 조명이 예측 불가능한 환경에서 더 안정적입니다. 흰색으로 날아갈 위험이 없습니다.
:::

## 백라이트 · 프런트 라이트 · 글리터 {#백라이트--프런트-라이트--글리터}

각각 **켜기 토글 + 색 + 강도**, 세 항목뿐인 가벼운 모듈입니다.

| 모듈 | 하는 일 |
|---|---|
| **백라이트** | 표면 뒤쪽의 주광이 만드는 독립적인 역광 띠 |
| **프런트 라이트** | 카메라를 향한 면에 더하는 정면 강조광 |
| **글리터** | 보로노이 입자 반짝임. 거리 안정화·시점 민감도·광원 각도·크기와 색 랜덤화 ([디테일 맵](/guides/detail-maps) 그룹) |

백라이트는 씬의 주광 방향에 의존하므로, 방향광이 없는 월드에서는 나타나지 않습니다. 그런 환경에서 역광 느낌이 필요하면 림 라이트의 `광원 방향 영향`을 낮춰서 쓰세요.

## 그림자 내부 반사 {#그림자-내부-반사}

**그림자 안쪽에서만 보이는** 프레넬 반사 띠입니다(인스펙터 안내: `그림자 내부 전용 효과`). 그림자가 평평한 검은 덩어리로 죽는 것을 막습니다. 어두운 옷이나 대비가 강한 캐릭터에서 효과가 큽니다.

### 반사 표현

먼저 띠 자체를 만듭니다. 림 라이트와 같은 구조입니다.

| 항목 | 하는 일 |
|---|---|
| `반사 색` | 띠의 색 |
| `강도` | **0이면 아무것도 안 보입니다.** 여기부터 |
| `프레넬 감쇠` | 클수록 실루엣 가장자리로 얇게 몰림 |
| `폭` | 띠가 시작되는 지점 |
| `가장자리 부드러움` | 경계 번짐 |
| `노멀맵 영향` | 노멀맵을 얼마나 따를지 |

### 그림자 범위

**어디까지를 "그림자 안"으로 볼지** 정하는 부분입니다. 이 모듈에만 있는 항목입니다.

| 항목 | 하는 일 |
|---|---|
| `그림자 시작점` | 이 밝기보다 어두운 곳부터 반사가 나타납니다 |
| `그림자 부드러움` | 그 판정의 전환 폭 |

:::tip[반사가 밝은 면까지 번져 보이면]
`그림자 시작점`을 낮추세요. 반대로 깊은 그림자에만 넣고 싶으면 더 낮춥니다.
:::

### 환경 반응

조명이 통제되지 않는 환경에서 띠가 튀지 않게 하는 항목들입니다.

| 항목 | 0 | 1 |
|---|---|---|
| `베이스 색 영향` | 지정한 반사 색 그대로 | 베이스 맵 색을 곱함 |
| `씬 조명 영향` | 씬 밝기와 무관 | 조명을 따라감 |
| `조명 방향 영향` | 방향과 무관 | 광원 쪽에만 |
| `환경광 색 영향` | 환경광 색 무시 | 환경광 색을 반영 |
| `추가광원 영향` | 포인트/스폿 무시 | 반영 |

### 전용 마스크

`마스크 사용`을 켜면 이 효과만의 마스크를 지정할 수 있습니다. 마스크 항목 구성은 [텍스처 슬롯 공통 UI](/guides/texture-modules#마스크-세부-설정)와 같습니다.
