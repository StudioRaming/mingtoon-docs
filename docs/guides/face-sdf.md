# 얼굴 SDF 오소링

**이 문서를 읽으면** 광원이 얼굴 주위를 돌 때 그림자가 애니메이션처럼 **미끄러지듯 움직이는** 얼굴을 만들 수 있습니다.

## SDF가 해결하는 문제

얼굴 노멀을 눌러 코 그림자를 없애면([캐릭터 표현 2단계](/guides/character#2단계-코-그림자-없애기)) 얼굴은 깨끗해지지만 **완전히 평평**해집니다. 광원이 옆으로 가도 그림자 경계가 생기지 않습니다.

SDF는 다른 접근입니다. **얼굴 그림자가 어느 순서로 덮이는지를 텍스처에 미리 그려 두고**, 광원 각도에 따라 그 텍스처를 임계값으로 잘라 씁니다. 애니메이션에서 얼굴 그림자가 코를 따라 스윽 넘어가는 그 움직임이 이렇게 만들어집니다.

## 두 가지를 구분하세요

MingToon에는 얼굴 관련 베이크가 **둘** 있습니다. 헷갈리기 쉽습니다.

| | 얼굴 프론트뷰 노멀 (UV7) | 얼굴 SDF 텍스처 |
|---|---|---|
| **무엇** | 메시에 굽는 **정점 데이터** | 그려서 만드는 **텍스처** |
| **어디서** | `MingToon Manager` → 3 · 룩/얼굴 | 얼굴 SDF 오소링 창 |
| **역할** | 셰이더가 얼굴의 정면 방향을 알게 함 | 그림자가 덮이는 순서를 정의 |
| **문서** | [메시 UV 베이크](/guides/mesh-bakes#얼굴-프론트뷰-노멀-uv7) | 이 문서 |

:::tip[보통 둘 다 씁니다]
UV7이 있어야 **런타임 스크립트 없이** 4방향 SDF가 동작합니다. SDF 텍스처는 그림자 모양을 정의합니다. VRChat/Warudo에 올릴 아바타라면 UV7을 먼저 굽고 SDF 텍스처를 만드세요.
:::

## 레이어형 얼굴 SDF 편집

오소링 창은 **부위별로 따로 그리고 마지막에 합치는** 방식입니다.

> 기본 음영·코·볼·입술·아이홀을 각각 편집합니다. **미리보기와 최종 베이크는 RGBA 한 장만 사용합니다.**

### 레이어 다섯 개

| 레이어 | 담당 | 비고 |
|---|---|---|
| **기본 음영** | 얼굴 전체가 덮이는 큰 흐름 | **필수** — 없으면 베이크가 거부합니다 |
| **코 세부 표현** | 콧대·콧방울 그림자 | |
| **볼 세부 표현** | 광대 아래 음영 | **오른쪽만 그리면 왼쪽은 자동 미러** |
| **입술 표현** | 입술 주변 | |
| **아이홀 표현** | 눈두덩 그림자 | **오른쪽만 그리면 왼쪽은 자동 미러** |

:::note[미러는 "보는 사람 기준 오른쪽"입니다]
창에 이렇게 안내됩니다.

> 보는 사람 기준 오른쪽 아이홀을 배치하면 왼쪽은 **얼굴 중앙을 기준으로 자동 미러**됩니다.

절반만 그리면 되므로 작업량이 반으로 줄고, 좌우 대칭이 자동으로 보장됩니다.
:::

### 레이어별 조정 항목

| 항목 | 하는 일 |
|---|---|
| `텍스처` | 이 레이어에 쓸 이미지 |
| `크기` | 스케일 |
| `위치` | 배치 |
| `반전` | 흑백 뒤집기 |
| `흐림 정도` | 경계 부드러움 |
| `타이밍 강도` | **이 레이어가 그림자 진행 순서에서 얼마나 앞/뒤로 밀리는지** |

:::tip[`타이밍 강도`가 SDF의 핵심입니다]
SDF는 "얼마나 어둡나"가 아니라 **"언제 덮이나"** 를 담습니다. 타이밍을 조절하면 광원이 돌 때 코가 먼저 덮일지, 볼이 먼저 덮일지가 바뀝니다.

애니메이션 룩에서는 보통 **코 → 볼 → 눈두덩 → 얼굴 전체** 순서로 넘어갑니다.
:::

## 작업 순서

1. **기본 분리 레이어 불러오기** — 동봉된 기본 레이어 세트로 시작합니다.
2. `기본 음영` 텍스처를 넣습니다. **이게 없으면 베이크가 거부합니다** (`기본 음영 텍스처가 필요합니다.`).
3. 부위별 레이어를 배치하고 `크기`·`위치`를 맞춥니다.
4. `타이밍 강도`로 덮이는 순서를 조정합니다.
5. **라이브 미리보기**로 확인합니다.
6. `출력 크기`를 정하고 베이크합니다.

### 라이브 미리보기

`라이브 미리보기 즉시 갱신`으로 지금 상태를 바로 반영합니다. 갱신 중에는 `라이브 미리보기를 갱신하는 중입니다.` 가 표시됩니다.

:::tip[씬 뷰에서 광원을 돌리며 보세요]
정지 화면으로는 타이밍이 맞는지 알 수 없습니다. 방향광을 좌우로 돌리면서 그림자가 자연스럽게 미끄러지는지 확인하세요. 이게 SDF를 쓰는 유일한 이유입니다.
:::

### 편집 프로필

`레이어 편집 프로필 만들기`로 현재 레이어 구성을 저장합니다. 다른 캐릭터에 같은 구성을 재사용하거나, 나중에 다시 손볼 때 씁니다.

---

## 출력

| 항목 | 내용 |
|---|---|
| 최종 결과 | **RGBA 한 장** |
| 작업본 경로 | `.../FaceSDF/Packed/MingFaceSDF_Author_{GUID 앞 8자리}` |
| 미리보기 경로 | `.../FaceSDF/Preview/MingFaceSDF_Preview_{...}` |
| 재질 슬롯 | `_FaceSdfMap` |

오소링 설정은 `_FaceSdfAuthoringEncoding`에 인코딩되어 **재질에 함께 저장**됩니다. 나중에 창을 다시 열면 작업하던 레이어 구성이 복원됩니다.

:::caution[재질마다 GUID로 파일이 갈립니다]
재질을 복제하면 SDF 작업본도 새 GUID로 갈라집니다. 여러 캐릭터가 같은 SDF를 공유하려면 텍스처를 직접 `_FaceSdfMap`에 지정하세요.
:::

## SDF를 쓸지 판단

| 상황 | 판단 |
|---|---|
| 광원이 고정된 연출 | **불필요.** 노멀 누름 + 얼굴 경계로 충분합니다 |
| VRChat 월드를 돌아다니는 아바타 | **효과 큼.** 조명이 예측 불가능할수록 값어치가 있습니다 |
| Warudo 방송 | **효과 큼.** 조명을 바꿔가며 쓰는 경우 |
| 작업 시간이 없음 | 건너뛰어도 됩니다. 나머지 얼굴 처리만으로도 충분히 깨끗해집니다 |
