# 기본 설정

[Manager로 처음 시작하기](/getting-started/first-material)를 마치고 변환된 재질을 다듬는 단계입니다. **아바타 루트의 MingToon Manager는 유지**하고, 조정할 재질을 선택하세요. 이 문서는 현재 인스펙터의 표면·색·조명 설정을 설명합니다. 설치된 화면과 항목 이름이 다르면 버전을 확인하세요. **VCC 설치판의 업데이트는 VCC에서 진행합니다.**

## 먼저 어느 항목을 조정할까요?

| 원하는 변화 | 먼저 열 곳 | 핵심 항목 |
|---|---|---|
| 어둡거나 밝게 보이는 정도 | 라이팅 → 핵심 조명 반응 / 조명 밝기 제한 | 밝은 면 밝기 · 간접광 보정 · 최종 최소/최대 밝기 |
| 월드 조명의 색이 너무 강함 | 라이팅 → 핵심 조명 반응 | 환경 색상 반영 · 베이스 색 유지 |
| 텍스처 자체의 색감 | 디테일 맵 → 표면 맵 | 베이스맵 HSVG · 색조 회전 방식 · 베이스 색상 |
| 잘라내기·반투명 표현 | 표면 렌더링 / 알파 & 컷아웃 | 표면 모드 · 베이스맵 전체 불투명도 · 알파 컷오프 |
| 뒤집힌 면이나 겹친 옷의 표시 | 표면 렌더링 | 표시할 면 · 양면 듀얼패스 |
| 깊이 효과에서 가림 물체로 사용 | 표면 렌더링 | 카메라 깊이 기록 |

빠른 설정에서 전체 인상을 먼저 잡고, 필요한 항목만 검색하거나 **전체 설정**에서 여세요. 재질 상단의 **Face·Skin·Common 역할은 일반 빌드에서도 직접 바꿀 수 있습니다.** 여러 재질을 선택한 상태에서 역할이나 값을 바꾸면 선택 대상 전체에 적용됩니다.

## 밝기와 조명 색을 나누어 조정하기

라이팅의 **핵심 조명 반응**은 다음 네 항목부터 시작합니다.

| 항목 | 바뀌는 것 | 조정 기준 |
|---|---|---|
| 밝은 면 밝기 | 빛을 받는 면의 밝기 배수 | 1을 기준으로 조정. 올릴수록 밝은 부분이 하얗게 뭉치는지 확인 |
| 환경 색상 반영 | 라이트 프로브·앰비언트의 색조 | 환경색이 피부나 옷에 너무 강하게 섞이면 낮춤. 밝기 조절과 별개 |
| 간접광 보정 | 환경 간접광이 어두운 면을 들어 올리는 정도 | 0은 간접광 밝기 추가 없음, 1은 기준 강도 |
| 베이스 색 유지 | 완성된 베이스 색에 섞이는 조명 색조 | 높일수록 원래 베이스 색을 우선. **밝기를 보존하거나 올리는 기능은 아님** |

어두운 곳에서 너무 검게 보이면 **간접광 보정**과 **조명 밝기 제한 → 최종 최소 밝기**를 확인합니다. 밝은 곳에서 색이 날아가면 **밝은 면 밝기**와 **최종 최대 밝기**를 조정합니다. 베이스 색 유지만 올려 어두운 문제를 해결하려고 하지 마세요.

포인트·스폿 라이트의 영향은 **추가 광원 수신량**으로 조정합니다. 더 세밀한 조명 색·응답 곡선 설정은 고급 설정에 있습니다. → [조명과 그림자](/guides/light-and-shadow)

## 베이스 색과 텍스처 {#2-베이스-색}

**표면 맵**에서 베이스 맵과 색 보정을 다룹니다. 변환한 재질이라면 텍스처를 다시 넣기 전에 현재 할당과 변환 결과부터 확인하세요.

| 항목 | 역할 |
|---|---|
| 베이스 맵 | 표면의 원본 텍스처 |
| 베이스맵 HSVG | 색상·채도·명도·감마 보정 |
| 색조 회전 방식 | HSV 또는 OKLab 선택. 기존 HSV 룩을 유지하려면 방식을 그대로 유지 |
| 베이스 색상 · 틴트 합성 모드 | 텍스처에 색을 합성. Multiply는 맵의 명암을 남기고, Normal은 선택한 색으로 덮음 |
| 베이스맵 전체 불투명도 | 최종 베이스 알파에 곱하는 값. **틴트 합성 강도와 별개인 표면 불투명도** |

예전 설명의 ‘틴트 불투명도’와 현재의 **베이스맵 전체 불투명도**를 같은 조절로 보지 마세요. 틴트 합성 강도는 색 합성에 관한 고급 호환 설정이며, 최종 표면 알파를 조절하지 않습니다. 불투명도를 바꿔 투명하게 보이게 하려면 아래 표면 모드도 함께 확인해야 합니다.

### 그라데이션 LUT

**그라데이션 LUT 사용**을 켜고 가로 방향 램프 텍스처를 지정하면 베이스 맵 색을 채널별로 다시 매핑합니다. LUT는 sRGB로 임포트하고 **그라데이션 강도**로 적용량을 정합니다. 처음에는 HSVG와 베이스 색상만으로 조정한 뒤, 필요한 경우 추가하세요.

### 일부 영역만 색 보정하기 {#색조보정-범위-마스크}

**색조보정 범위 마스크 → 범위 마스크 사용**을 켜고 마스크를 넣습니다. 흰색은 보정 적용, 검은색은 원본 유지, 회색은 중간 비율입니다. 패킹한 텍스처라면 채널을 선택하고 필요하면 반전합니다.

범위 마스크에는 **자체 타일링·오프셋**이 있습니다. 베이스 맵을 조정했다고 마스크 위치도 자동으로 같아진다고 가정하지 말고, 눈·피부처럼 원하는 영역에 맞는지 확인하세요.

## 표면 모드 선택 {#1-표면-모드부터-정합니다}

이미 변환된 룩이 원하는 방식으로 보이면 모드를 먼저 바꿀 필요는 없습니다. 파츠에 필요한 불투명·잘라내기·겹침 방식에 맞춰 선택하세요. 모드는 **표면 렌더링**과 **알파 & 컷아웃** 양쪽에서 같은 값을 조정합니다.

| 현재 표시 | 사용 기준 | 깊이와 겹침 |
|---|---|---|
| 불투명 (2000) | 일반 피부·의상 | 알파 합성 없이 깊이 기록 |
| 컷아웃 (2450) | 머리카락·속눈썹 등 경계를 잘라냄 | 알파 컷오프보다 낮은 픽셀을 버리고 나머지는 깊이 기록 |
| 반투명 (2499) | 알파 합성을 쓰면서 가까운 표면이 우선해야 하는 파츠 | 깊이를 기록하며 카메라 깊이 대상이 되는 큐. 겹친 층을 모두 비쳐 보이게 하는 용도와 구분 |
| 투명 (3000) | 겹친 천·유리처럼 뒤쪽 층도 비쳐야 하는 파츠 | 기본 색상 패스는 깊이를 쓰지 않고 투명 순서로 합성. 카메라 깊이 기반 효과의 일반 대상이 아님 |

기존 문서의 ‘투명 · 아웃라인용 깊이 기록’은 현재 **반투명 (2499)**으로 표시됩니다. 두 투명 계열 모두 아웃라인을 유지할 수 있습니다. 모드 변경은 렌더 상태·기본 큐·내부 아웃라인 버퍼를 맞추며 알파 컷오프와 아웃라인의 켜짐·외형 값은 보존합니다.

**반투명으로 바꾸기만 하면 모든 깊이 효과가 보장되는 것은 아닙니다.** 카메라 깊이 준비, 카메라 깊이 기록, 효과 모듈과 실제 렌더 큐도 확인하세요. → [깊이 기반 효과](/guides/depth-effects)

### 카메라 깊이 기록

이 항목은 **다른 재질의 2D 그림자·SSAO·2D 림이 이 재질을 가림 물체로 읽을지** 결정합니다. 끄면 해당 기여를 제외합니다. 일반 색상 표시와 실제 라이트 그림자는 별도로 유지됩니다. 이 체크박스 자체가 카메라의 깊이 텍스처를 준비해 주는 것은 아닙니다.

### 표시할 면과 양면 처리 {#표시할-면}

**표시할 면**에서 앞면만·뒷면만·양면·양면과 아웃라인 반전 조합을 선택합니다. 천이나 치마처럼 양쪽이 보여야 하면 양면을 사용하고, 뒷면 조명이 이상할 때 **뒷면 라이팅 노멀 뒤집기**를 확인하세요.

**고급 컬러 버퍼 → 양면 듀얼패스**는 양면 표면의 뒷면을 먼저 별도로 그리는 선택입니다. 접힌 천의 앞·뒷면 겹침이 문제일 때 확인하며 추가 패스가 생기므로 필요한 재질에 적용합니다.

### 투명 파츠의 겹침이 이상할 때 {#머리카락이-볼을-뚫고-보일-때}

먼저 **반투명 (2499)**의 깊이 우선과 **투명 (3000)**의 층간 합성 중 원하는 결과를 선택합니다. 투명 (3000)의 **고급 컬러 버퍼**에는 **투명 깊이 선기록**이 있습니다. 이는 투명 정렬·아웃라인과 관련된 깊이 처리이며, 카메라 깊이 기록 스위치나 실시간 라이트 그림자와 같은 제어가 아닙니다. 모든 겹침 문제에 선기록을 무조건 켜는 방식으로 안내하지 않습니다.

## 알파 마스크와 컷아웃 {#3-투명도를-텍스처로-따로-지정하기}

**알파 & 컷아웃** 헤더의 모듈 스위치를 확인하고, 별도 투명 텍스처가 필요하면 **알파 마스크 사용**을 켭니다. 마스크·채널·반전·강도를 정한 뒤 **알파 컷오프**로 잘라낼 경계를 조정합니다. 불투명 모드에서는 알파를 낮춰도 반투명 합성으로 바뀌지 않습니다.

**Alpha To Coverage**는 MSAA 설정에 영향을 받습니다. MSAA가 꺼진 환경에서 가장자리 변화가 없다고 강도만 계속 올리지 마세요. 반투명·투명 모드에 표시되는 **카메라 깊이 알파 컷오프**는 색상 알파와 구분해 깊이 실루엣의 기준을 조정합니다.

거리·프레넬·방향에 따른 알파는 해당 접힌 그룹에서 필요할 때 설정합니다. 알파 마스크·표면 불투명도·컷오프를 먼저 맞춘 다음 확장하세요.

## 마스터 조정과 성능 거리

**마스터 조정**의 밝기·틴트 저작 행은 MLC가 설치된 경우 표시됩니다. MLC가 없는 화면에서 그 행을 찾을 필요는 없습니다. **성능 거리**는 별도 애드온 없이도 사용할 수 있으며, 카메라가 멀어질 때 샘플 상한과 일부 효과를 줄입니다. 멀리서 효과가 사라지면 거리·배율 설정도 확인하세요. → [Ming Light Controller](/guides/ming-light-controller)

## 공통 맵 {#4-공통-맵}

노멀맵은 표면 요철, 오클루전 맵은 간접광 차폐를 다룹니다. 텍스처 할당뿐 아니라 해당 모듈과 강도도 확인하세요. 추가 노멀 레이어·Matcap·이미션·PBR은 [디테일 맵](/guides/detail-maps)에서 이어서 조정합니다.

**렌더 비활성화**는 재질 자체를 그리지 않는 기능이고, **전체 효과**는 스타일 효과의 상위 스위치입니다. 재질이 사라진 경우와 개별 효과만 반응하지 않는 경우를 구분해 확인하세요.
