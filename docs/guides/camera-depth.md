# Camera Depth와 2D 효과

**이 문서를 읽으면** 2D 림·2D 그림자·Inner Edge가 왜 안 보이는지 진단하고, 각 플랫폼에서 깊이를 확보하는 방법을 알게 됩니다.

전체 항목 목록은 [2D 깊이 효과 레퍼런스](/reference/depth-effects)에 있습니다.

## 무엇이 깊이를 쓰나

아래 세 가지는 **카메라 깊이 텍스처**를 읽습니다. 깊이가 없으면 값을 아무리 만져도 화면에 나타나지 않습니다.

- 2D 깊이 림 (Depth Rim)
- 2D 깊이 그림자 (Depth Shadow)
- Inner Edge 외곽선

:::danger 값을 만지기 전에 깊이부터 확인하세요
이 페이지의 "안 보일 때" 순서를 먼저 밟고, 깊이가 확보된 뒤에 폭·강도를 조정하세요. 순서를 뒤집으면 되지도 않을 값을 계속 만지게 됩니다.
:::

## 플랫폼별 깊이 확보

### 일반 Unity (BRP)

씬에 `Studio Raming/MingToon/Depth Texture Provider` 컴포넌트를 두면 됩니다. 활성 Game Camera가 렌더하기 직전에 필요한 depth flag와 카메라 행렬을 제공하고, 기존 카메라 플래그는 보존합니다.

### URP 12

1. 사용 중인 URP Renderer Data에 **MingToon depth Renderer Feature**를 설치합니다.
2. Renderer Data에서 **Depth Texture**를 활성화합니다.

### Warudo

아바타 번들만으로는 호스트 카메라를 바꿀 수 없는 경우가 있습니다. 공개 호스트 플러그인/Playground bridge 또는 동등한 카메라 설정이 필요합니다. → [Warudo](/platforms/warudo)

### VRChat

여기가 가장 헷갈리는 부분입니다.

| 상황 | 깊이 |
|---|---|
| **Photo Camera 활성** | ✅ 공식 계약으로 호스트 깊이가 켜집니다 |
| **월드가 Screen Camera depth를 켠 경우** | ✅ |
| **일반 플레이어 화면 (기본)** | ❌ 아바타가 강제할 수 없습니다 |
| **미러 · 스트림 내부 경로** | ⚠️ 보장되지 않습니다 |

:::danger 아바타는 플레이어 메인 카메라의 깊이를 켤 수 없습니다
Screen Camera 설정은 **월드/Udon 측 권한**입니다. 아바타에 Camera나 Light를 추가하는 것은 동등한 해결책이 아니며, 성능 비용을 올리거나 아바타 안전 설정에 의해 제거될 수 있습니다.

본인 화면 · 미러 · 사진 카메라를 **각각** 확인하세요.
:::

**빌드 시 자동 처리** — VRChat 아바타 업로드에서는 MingToon이 `Depth Availability`를 `Auto`에서 `Force On`으로 자동 승격합니다. `Auto`는 "호스트가 깊이가 있다고 말하면 믿는다"는 뜻인데, 그렇게 말해 주는 `MingDepthTextureProvider`가 `IEditorOnly`라 업로드에서 제거되기 때문입니다. 자세한 내용은 [빌드 시 자동 최적화](/workflow/build-optimization)를 보세요.

## 안 보일 때 진단 순서

위에서부터 차례로 확인하세요.

1. **모듈 토글** — Depth Effects가 켜져 있나
2. **마스터 폭** — `마스터 폭`이 0이면 각 모듈의 폭을 아무리 올려도 아무것도 나오지 않습니다
3. **각 모듈의 강도** — `림 강도`가 0이면 림 계산을 건너뜁니다
4. **카메라 깊이** — 위의 플랫폼별 항목
5. **전역 depth available 값**
6. **표면 모드** — Transparent(큐 3000)면 깊이 기반 모듈이 전부 꺼집니다

## 공통 값 (마스터)

2D 림과 2D 그림자가 **공유**하는 값입니다. 여기를 먼저 잡고 각 모듈로 내려가세요.

| 항목 | 하는 일 |
|---|---|
| `마스터 폭` | 두 모듈의 화면 오프셋에 공통으로 곱해지는 배수. **0이면 전부 안 나옵니다** |
| `폭 모드` | `Screen Pixels`는 화면 픽셀 기준 · `Distance Stable`은 거리·FOV가 변해도 두께 일정 |
| `거리 스케일` | `Distance Stable`일 때 기준 거리. `Screen Pixels`면 무시됩니다 |
| `마스터 바이어스` | 이 값을 넘는 깊이 차이만 경계로 인정. **낮추면** 얕은 굴곡에도 선이 붙어 지저분해지고, **올리면** 얇은 부위의 선이 사라집니다 |
| `마스터 부드러움` | 낮으면 딱딱한 잉크선, 높으면 부드럽게 번진 경계 |

:::tip 아바타에는 Distance Stable
카메라 거리가 계속 변하는 환경에서는 `Distance Stable`이 두께를 일정하게 유지합니다.
:::

## 2D 깊이 림

최종 두께 = `마스터 폭` × `림 폭 배수` 입니다.

- `림 강도` — **0이면 계산을 건너뜁니다.** 색과 폭을 바꿔도 아무것도 안 보입니다.
- `베이스 색 혼합` — 0이면 단색 림, 1이면 베이스 맵 색을 곱해 부위마다 다른 림 색.
- `360도 림` — 0이면 광원 방향 쪽에만, 1이면 실루엣 전체를 감쌉니다.

:::tip 조명이 없거나 방향이 자주 바뀌는 환경
`360도 림`을 올려 두면 안정적입니다.
:::

`실루엣 시작점`과 `실루엣 전환 부드러움`은 **같은 그룹의 외곽 실루엣 제한이 0이면 전혀 반영되지 않습니다.**

## 반투명 표면과 깊이

표면 모드가 두 갈래로 갈리고, 차이는 **어느 렌더 큐에 들어가느냐**입니다.

- **Transparent, depth-recorded** (큐 2499, RenderType Opaque) — 두 파이프라인이 카메라 깊이 텍스처를 만드는 범위 **안**입니다. 2D 그림자·깊이 림·Inner Edge가 전부 동작합니다. `Transparent Depth Prepass`가 색 패스 전에 표면 깊이를 기록하므로, 뺨 뒤의 머리카락이 뺨 위로 그려지는 것도 막습니다. **반투명이 필요하면 이쪽을 먼저 검토하세요.**
- **Transparent** (큐 3000) — 그 범위 **밖**입니다. 파이프라인이 깊이를 요구하지 않으므로 깊이 기반 모듈은 꺼진 채로 둡니다. 켜면 캐릭터 뒤에 있는 것과 비교하게 됩니다. 해당 모듈이 켜져 있으면 인스펙터가 표면 모드 옆에 이를 알려 줍니다.

Opaque와 Cutout은 영향을 받지 않고 항상 완전한 깊이를 갖습니다.
