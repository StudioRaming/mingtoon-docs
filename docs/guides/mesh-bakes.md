# 메시 UV 베이크

**이 문서를 읽으면** 셰이더 값만으로는 해결되지 않는 세 가지 문제를 메시에 데이터를 구워서 해결할 수 있습니다.

MingToon은 세 개의 UV 채널을 씁니다. 전부 **선택 사항**이지만, 각각이 특정 문제의 유일한 해결책입니다.

| 채널 | 해결하는 문제 | 없으면 |
|---|---|---|
| **UV8** | 각진 부분에서 아웃라인이 끊김 | `노멀 소스`를 `MeshNormal`로만 쓸 수 있음 |
| **UV7** | 얼굴 SDF에 런타임 스크립트가 필요함 | 스크립트를 제거하는 배포에서 얼굴 셰이딩이 불안정 |
| **UV4** | 높이 기반 색 그라데이션 | 캐릭터 높이 그라데이션 자체가 동작 안 함 |

:::tip[변환할 때 한 번에 굽는 게 가장 편합니다]
`MingToon Manager`의 **2 · 변환** 단계에서 `함께 구울 메쉬 채널`을 체크하면 변환 직후 자동으로 굽습니다. 재질 변환이 끝난 뒤 실행되므로 **얼굴 노멀 베이커가 어떤 서브메시가 얼굴인지 알 수 있습니다.** → [MingToon Manager](/workflow/character-manager#함께-구울-메쉬-채널)
:::

:::caution[구운 UV는 렌더러마다 하나의 통합 메시 에셋에 함께 저장됩니다]
채널을 따로따로 여러 번 구워도 결국 같은 사본에 쌓입니다.
:::

## 아웃라인 스무스 노멀 (UV8)

**무엇을 하나** — 위치가 같은 버텍스의 노멀을 평균내 UV8에 굽습니다. 하드 엣지로 갈라진 노멀이 하나로 합쳐지므로, 헐을 밀어낼 때 선이 벌어지지 않습니다.

UV8.w에는 **선 굵기 대비용 값**이 함께 들어갑니다 — 긴 면은 두껍게, 꼭짓점은 얇게.

### 절차

1. `MingToon Manager`의 **1 · 설정** 근처에 있는 `아웃라인 스무스 노멀 UV8` 그룹을 엽니다.
2. 이미 UV8을 쓰는 메시가 있으면 `기존 UV8 덮어쓰기`를 켭니다.
3. `선택 캐릭터 전체 UV8 베이크`를 누릅니다.
4. **재질의 `노멀 소스`를 `UV8TS`로 바꿉니다.** 이걸 안 하면 구운 데이터가 쓰이지 않습니다.

완료 메시지: `아웃라인 스무스 노멀 베이크를 완료했습니다. 재질에서 헐 노멀 소스를 UV8TS로 바꾸세요.`

:::danger[탄젠트가 없는 메시는 거부합니다]
베이크가 실패하면 모델 임포터에서 탄젠트를 생성하도록 설정하고 다시 임포트하세요.
:::

:::note[UV8.w를 쓰려면]
`압력 소스`를 `OutlineNormalUV8`로 두면 구워진 굵기 대비값이 그대로 선 굵기에 반영됩니다. → [아웃라인](/guides/outline#선-굵기를-부위마다-다르게)
:::

## 얼굴 프론트뷰 노멀 (UV7)

**무엇을 하나** — 현재 씬의 **프론트뷰를 복제 메시의 TEXCOORD6 (Unity UV7)에 투영**합니다.

이걸 구워 두면 셰이더만으로 4방향 얼굴 SDF가 동작합니다. **런타임 노멀 공급자 컴포넌트가 필요 없어져서**, 스크립트를 제거해야 하는 VRChat 업로드와 Warudo 모드에서 얼굴 셰이딩이 안정적으로 남습니다.

### 절차

1. `MingToon Manager`의 **3 · 룩 / 얼굴** → `얼굴 SDF UV 준비 (WARUDO / VRC)`.
2. `프론트뷰 SDF TEXCOORD6 (Unity UV7) 베이커 열기`.
3. 씬 뷰 카메라로 **얼굴을 정면에서** 잡습니다. 이 시점이 그대로 구워집니다.
4. 굽습니다.

완료 로그: `MingToon 얼굴 조명 노멀을 구웠습니다: 렌더러 N개, 얼굴 정점 M개. 원본 형상 노멀은 그대로 유지됩니다.`

**원본 형상 노멀은 건드리지 않습니다.** 조명용 노멀만 별도 채널에 들어갑니다.

### 되돌리기

`원본 메시 복원`을 누릅니다. `MingToon 원본 메시를 복원했습니다: 렌더러 N개.`

:::danger[원본 모델을 옮기거나 다시 임포트하기 전에 먼저 복원하세요]
기록된 원본 메시를 못 찾으면 이런 경고가 나옵니다.

> `'{메시}'에 기록된 원본 메시를 찾지 못해, 렌더러 '{이름}'은(는) 현재 할당된 메시에서 굽습니다. 이 상태에서는 '원본 메시 복원'이 원래 모델까지 되돌리지 못합니다.`

이 상태로 진행하면 복원 경로가 끊깁니다.
:::

복원 실패 시 `렌더러 N개는 기록된 원본 메시가 프로젝트에 없어 복원하지 못했습니다.` 가 나오며, 원본 모델을 다시 임포트하거나 메시를 직접 할당해야 합니다.

## 캐릭터 높이 (UV4)

**무엇을 하나** — 캐릭터 **전체**의 루트 기준 높이를 모든 메시의 UV4.x에 굽습니다.

메시 단위가 아니라 **캐릭터 단위**라는 점이 중요합니다. 상의와 하의가 별개 메시여도 하나의 연속된 높이 축을 공유합니다.

### 절차 (캐릭터 루트에서)

1. `MingToon Manager`의 `캐릭터 높이 UV4` 그룹.
2. 상태를 확인합니다.
   - `모든 메시에 UV4 높이를 베이크할 준비가 됐습니다.` → 그대로 진행
   - `일부 메시의 UV4가 이미 사용 중입니다.` → `기존 UV4 덮어쓰기` 판단
3. `선택 캐릭터 전체 UV4 베이크`.
4. `하위 모든 MingToon 재질에 일괄 적용`으로 재질들의 높이 설정을 맞춥니다.

### 절차 (재질 인스펙터에서)

재질 쪽에도 같은 기능이 있습니다. `UV4 높이 베이크` 그룹의 `선택 재질의 캐릭터 UV4 베이크`.

선택한 재질을 쓰는 캐릭터를 씬에서 찾아 굽습니다. **재질을 전부 선택하고 눌러도 캐릭터당 한 번만 실행**됩니다.

:::caution[씬에 캐릭터가 없으면 실패합니다]
`선택한 재질을 쓰는 렌더러를 열려 있는 씬에서 찾지 못했습니다.` → 캐릭터가 있는 씬이나 프리팹을 연 뒤 다시 시도하세요.
:::

→ [캐릭터 높이 그라데이션 사용법](/guides/character#캐릭터-높이-그라데이션)

## 어떤 채널을 구울지 판단

| 상황 | 필요한 채널 |
|---|---|
| 아웃라인이 각진 부분에서 끊긴다 | **UV8** |
| VRChat / Warudo에 올릴 아바타의 얼굴을 안정적으로 | **UV7** |
| 발밑을 어둡게 깔거나 옷자락에 색을 넣고 싶다 | **UV4** |
| 위 셋 다 해당 없음 | 굽지 않아도 됩니다 |

굽지 않아도 MingToon은 정상 동작합니다. 각 채널은 **해당 기능을 쓸 때만** 필요합니다.
