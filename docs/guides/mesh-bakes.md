# 메시 UV 베이크

> 이 페이지는 **메시 UV 베이크**를 처음 해 보는 분을 위한 것입니다.
> 아웃라인이 각진 곳에서 끊기는 문제를 고칩니다. 약 5분 걸립니다.

## 이게 뭔가요

메시에는 색을 입힐 때 쓰는 좌표 칸이 여러 개 있습니다.
MingToon은 그중 세 칸에 셰이더가 읽을 값을 미리 적어 둡니다.
적어 두는 작업을 베이크라고 부릅니다. 굽고 나면 값을 못 바꿉니다.

## 어느 칸이 필요한가요

| 상황 | 필요한 칸 |
|---|---|
| 아웃라인이 하드 엣지에서 벌어진다 | UV8 |
| 캐릭터 높이 그라데이션을 쓴다 | UV4 |
| 얼굴 SDF가 정면 투영 좌표를 요구한다 | UV7 |
| 얼굴 프록시를 편집하며 확인만 한다 | 굽지 않습니다 |
| VRChat에 올릴 때 얼굴을 가볍게 하고 싶다 | 굽지 않습니다. 업로드가 알아서 합니다 |

대부분의 사용자는 UV8 하나만 구우면 됩니다.

:::danger[이미 쓰고 있는 칸을 덮어쓰지 마세요]
다른 셰이더나 모델 제작자가 이 칸에 값을 넣어 두었을 수 있습니다.
밍툰 매니저의 **UV 채널 사용 현황** 이 UV4·UV7·UV8을 보여 줍니다.
:::

## 30초 만에 켜 보기

1. 밍툰 매니저를 선택합니다.
2. **아웃라인 스무스 노멀 UV8** 을 펼칩니다.
3. **UV8만 따로 굽기 (개별 베이크)** 를 누릅니다.

각진 부분에서 끊기던 아웃라인이 이어지면 성공입니다.
아무 변화가 없으면 [베이크 문제 해결](/troubleshooting#bake)로 가세요.

## 자주 만지는 값

| 인스펙터 라벨 | 뭘 바꾸는지 | 추천 시작값 | 올리면 / 내리면 |
|---|---|---|---|
| **기존 UV8 덮어쓰기** | 값이 든 칸을 다시 쓸지 | 꺼짐 | 켜면 다시 구울 수 있고, 끄면 그 메시에서 단계가 실패합니다 |
| **노멀을 편집한 모델용으로 계산** | 아웃라인 방향을 면에서 다시 계산 | 기본값 그대로(꺼짐) | 켜면 선이 메시를 따라가고, 끄면 옮겨 온 노멀을 따릅니다 |
| **아웃라인 스무스 노멀 (UV8)** | 변환 때 UV8을 함께 구울지 | 켜짐 | 끄면 각진 곳에서 선이 갈라집니다 |
| **캐릭터 높이 그라데이션 (UV4)** | 변환 때 UV4를 함께 구울지 | 꺼짐 | 끄면 높이 그라데이션도 같이 꺼집니다 |
| **얼굴 프론트뷰 노멀 (UV7) — 보통은 끕니다** | 변환 때 얼굴을 미리 구울지 | 기본값 그대로(꺼짐) | 켜면 프록시를 만져도 화면이 안 바뀝니다 |
| **이미 사용 중인 UV 채널 덮어쓰기** | 변환 때 기존 칸을 덮을지 | 꺼짐 | 켜면 재변환이 통과하고, 그 칸을 쓰던 기능은 값을 잃습니다 |

## 아웃라인 스무스 노멀 (UV8) {#아웃라인-스무스-노멀-uv8}

같은 자리에 있는 꼭짓점들의 방향을 평균내 UV8에 적어 둡니다.
**노멀 소스** 의 기본값이 이미 `UV8TS`이므로 굽기만 하면 됩니다.
UV8의 네 번째 값에는 선 굵기 대비용 값이 함께 들어갑니다.

### 굽는 순서

1. 밍툰 매니저에서 **아웃라인 스무스 노멀 UV8** 을 엽니다.
2. 상태 패널에서 대상과 기존 UV8을 확인합니다.
3. 필요하면 **노멀을 편집한 모델용으로 계산** 을 켭니다.
4. 소유권을 확인한 경우에만 **기존 UV8 덮어쓰기** 를 켭니다.
5. **UV8만 따로 굽기 (개별 베이크)** 를 누릅니다.

**압력 소스** 를 `OutlineNormalUV8`로 두면 굵기 대비도 함께 쓰입니다.
→ [압력 소스 고르기](/guides/outline#압력-소스-고르기)

:::caution[탄젠트가 없는 메시는 건너뜁니다]
탄젠트(노멀맵 방향을 계산하는 메시 데이터. 모델 임포트 설정에서 켭니다)가 필요합니다.
없는 메시만 빠지고 다른 단계는 계속 진행됩니다. 켠 뒤 다시 실행하세요.
:::

### 노멀을 편집한 모델용으로 계산 {#노멀을-편집한-모델용으로-계산}

헤어나 치마는 구·원통에서 노멀을 옮겨 온 경우가 많습니다.
그대로 구우면 선이 메시가 아니라 옮겨 온 구를 따라갑니다.

이 항목을 켜면 메시의 면에서 방향을 다시 계산합니다.
셰이딩은 그대로 두고 외곽선만 메시를 따라갑니다.
기본값은 꺼짐이라 이미 구운 캐릭터의 선은 달라지지 않습니다.

## 얼굴 프론트뷰 노멀 (UV7) {#얼굴-프론트뷰-노멀-uv7}

얼굴 프록시 노멀은 편집 중에 셰이더가 실시간으로 계산합니다.
**프록시 모양** · 중심 · 반지름 · 축을 바꾸면 굽지 않아도 바로 보입니다.

**프록시 모양** 의 첫 항목이자 기본값은 `평면`입니다.
`구 (실험적)` · `원기둥 (실험적)` · `캡슐 (실험적)` 은 아직 실험 단계입니다.
먼저 `평면`으로 맞춰 보고, 부족할 때만 나머지를 시험하세요.

### VRChat에 올릴 때

업로드 중 MingToon은 임시 복사본에서만 얼굴 노멀을 처리합니다.
씬의 원본 메시와 재질은 그대로 둡니다.
UV7이 이미 차 있거나 얼굴 영역 마스크를 쓰는 렌더러는 건너뜁니다.

프록시를 움직여도 화면이 안 바뀌면 예전 베이크가 남은 것입니다.
밍툰 매니저의 **구운 얼굴 노멀 해제** 를 누르세요.
저장값 사용을 끄고 얼굴 맵 좌표를 되돌리며, 메시는 건드리지 않습니다.

## 캐릭터 높이 (UV4) {#캐릭터-높이-uv4}

캐릭터 루트를 기준으로 한 높이를 모든 메시의 UV4에 적어 둡니다.
상의와 하의가 다른 메시여도 하나의 연속된 축을 공유합니다.

1. 밍툰 매니저에서 **캐릭터 높이 그라데이션 (UV4)** 를 켭니다.
2. 기존 UV4와 대상 렌더러를 확인합니다.
3. 소유권을 확인한 경우에만 덮어쓰기를 켭니다.
4. 베이크를 실행합니다.

:::note[UV4를 굽지 않으면 그라데이션이 꺼집니다]
굽지 않은 UV4 위에서 켜 두면 켜진 것처럼 보이면서 아무 일도 안 합니다.
그래서 체크를 풀면 높이 그라데이션도 함께 꺼집니다.
:::

## 변환할 때 한 번에 굽기

밍툰 매니저 1단계의 **함께 구울 메쉬 채널** 에서 미리 고를 수 있습니다.
체크한 칸은 재질 변환이 끝난 직후에 자동으로 구워집니다.
**얼굴 프론트뷰 노멀 (UV7) — 보통은 끕니다** 는 이름 그대로 꺼 두세요.

이미 구운 캐릭터를 다시 변환한다면
**이미 사용 중인 UV 채널 덮어쓰기** 를 켜야 단계가 실패하지 않습니다.
