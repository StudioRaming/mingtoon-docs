# 메시 UV 베이크

**이 문서를 읽으면** UV4·UV7·UV8의 소유권과 0.1.7의 Live 얼굴 노멀·업로드 전용 bake를 구분할 수 있습니다.

| 채널 | 사용자용 데이터 |
|---|---|
| **UV8** | 아웃라인 스무스 노멀과 선택적인 압력 값 |
| **UV7** | Face SDF의 Baked Front 좌표. 얼굴 노멀 업로드 payload가 같은 채널을 임시로 사용할 수 있음 |
| **UV4** | 캐릭터 루트 기준 높이 |

:::danger[기존 채널을 확인하세요]
UV 채널에는 다른 셰이더·툴·모델 제작자가 넣은 데이터가 있을 수 있습니다. `덮어쓰기`는 소유권을 확인한 경우에만 켜세요. 밍툰 매니저의 `UV 채널 사용 현황`이 UV4·UV7·UV8을 표시합니다.
:::

## 아웃라인 스무스 노멀 (UV8) {#아웃라인-스무스-노멀-uv8}

같은 위치의 버텍스 노멀을 평균내 UV8에 저장합니다. 하드 엣지에서 헐 아웃라인이 벌어지는 문제를 줄입니다. UV8.w에는 선택적으로 선 굵기 대비 값도 들어갑니다.

### 절차

1. 밍툰 매니저의 `3 · 세부 설정`에서 `아웃라인 스무스 노멀 UV8`을 엽니다.
2. 상태 패널에서 대상·공유 Mesh·기존 UV8을 확인합니다.
3. 편집 노멀을 가진 헤어·스커트라면 `노멀을 편집한 모델용으로 계산`을 검토합니다.
4. 기존 UV8의 소유권을 확인한 경우에만 덮어쓰기를 켭니다.
5. 캐릭터 전체 UV8 bake를 실행합니다.

`노멀 소스 = UV8TS`가 기본이므로 bake 후 재질에서 따로 바꿀 것은 없습니다. `압력 소스 = OutlineNormalUV8`이면 UV8.w도 폭에 반영합니다.

탄젠트가 없는 파츠는 해당 UV8 단계를 건너뛰고 다른 UV4·얼굴 단계까지 함께 실패시키지 않습니다. 필요한 파츠는 Model Importer에서 tangent를 생성한 뒤 다시 실행하세요.

### 노멀을 편집한 모델이라면 {#노멀을-편집한-모델용으로-계산}

`노멀을 편집한 모델용으로 계산`을 켜면 구·원통에서 옮겨온 셰이딩 노멀 대신 Mesh 면에서 아웃라인 방향을 다시 계산합니다. 셰이딩 노멀은 바꾸지 않습니다.

## Live 얼굴 노멀과 UV7 {#얼굴-프론트뷰-노멀-uv7}

0.1.7부터 얼굴 노멀 누름은 편집 중 셰이더가 실시간 계산합니다. 프록시 중심·반지름·Sphere/Cylinder/Capsule 모양·축·높이·누름 값을 바꾸면 별도 Mesh bake 없이 바로 보입니다.

### VRChat 업로드 때

VRChat 업로드 훅은 업로드 복사본에만 얼굴 노멀 payload를 UV7로 만들 수 있습니다. 편집용 conversion과 다른 전용 출력 경로를 사용하고, 업로드가 끝나면 Renderer와 공유 재질을 Live 상태로 복원합니다.

다음 Renderer는 결과 보존을 위해 업로드 bake를 건너뛰고 Live 셰이더 경로를 유지합니다.

- Face SDF가 `Baked Front UV7`을 사용해 UV7을 소유함
- 텍스처 Face Area Mask가 활성이고 강도가 0보다 큼
- 한 Renderer의 여러 Face 슬롯이 프록시·노멀 방식·런타임 얼굴 프레임을 서로 다르게 사용함
- 소스 Mesh의 UV7이 MingToon이 아닌 다른 데이터로 이미 채워짐

### 예전 얼굴 노멀 bake 되돌리기

예전 버전에서 `_FaceNormalBaked`가 남아 프록시를 움직여도 화면이 바뀌지 않으면 밍툰 매니저의 `얼굴 노멀 실시간으로 되돌리기`를 실행하세요.

이 작업은:

- baked float와 keyword를 끔
- tangent-normal payload를 Face SDF 좌표로 오독하지 않도록 `얼굴 맵 좌표`를 Base UV로 되돌림
- Mesh 바이트 자체는 건드리지 않음
- 모든 재질을 하나의 Undo 단계로 기록하고 변경한 에셋만 저장

다음 일반 conversion은 원본 Mesh에서 다시 만들기 때문에 읽지 않는 예전 UV7 payload도 자연스럽게 빠집니다.

### Face SDF용 Baked Front UV7

Face SDF에서 UV7은 노멀이 아니라 **정면 투영 좌표**입니다. 별도 제품인 Face SDF Studio가 설치돼 있다면 SceneView 정면을 기준으로 복제 Mesh의 TEXCOORD6에 굽습니다.

1. 얼굴을 정면으로 맞춥니다.
2. Studio에서 `Baked Front UV7`을 선택합니다.
3. 복제 Mesh를 굽고 대상 Renderer에 적용합니다.
4. MingToon 재질의 `얼굴 맵 좌표`가 같은 모드인지 확인합니다.

Base UV로 만든 SDF는 UV7이 필요 없습니다. → [얼굴 SDF](/guides/face-sdf)

## 캐릭터 높이 (UV4) {#캐릭터-높이-uv4}

캐릭터 전체 루트 기준 높이를 모든 Mesh의 UV4.x에 저장합니다. 상의와 하의가 다른 Mesh여도 하나의 연속 축을 공유합니다.

### 절차 (밍툰 매니저에서)

1. `3 · 세부 설정`의 `캐릭터 높이 UV4`를 엽니다.
2. 기존 UV4와 대상 Renderer를 확인합니다.
3. 소유권을 확인한 경우에만 덮어쓰기를 켭니다.
4. 캐릭터 전체 UV4 bake를 실행합니다.
5. 하위 MingToon 재질에 높이 설정을 일괄 적용합니다.

재질 인스펙터에서도 선택 재질을 사용하는 열린 캐릭터를 찾아 실행할 수 있습니다. 여러 재질이 같은 캐릭터를 가리켜도 캐릭터당 한 번만 처리합니다.

## 어떤 채널을 구울지 판단

| 상황 | 선택 |
|---|---|
| 아웃라인이 하드 엣지에서 벌어짐 | UV8 |
| Face SDF가 정면 투영 좌표를 요구함 | UV7 |
| 높이 그라데이션을 사용함 | UV4 |
| 얼굴 노멀 프록시를 편집 중 확인 | bake하지 않음 — Live |
| VRChat 얼굴 노멀 최적화 | 직접 bake하지 않음 — 업로드 훅 |
