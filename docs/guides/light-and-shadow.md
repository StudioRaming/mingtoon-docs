# 조명과 그림자

**이 문서를 읽으면** 세 종류의 그림자를 구분하고, 어떤 순서로 잡아야 서로 싸우지 않는지 알게 됩니다.

인스펙터의 **조명과 그림자** 그룹 — `라이팅` · `그림자 색상` · `형태 그림자` · `그림자 투영` 을 다룹니다. 전체 항목 목록은 [조명과 그림자 레퍼런스](/reference/light-and-shadow)에 있습니다.

## 먼저: 그림자가 세 종류입니다

MingToon에서 "그림자"라고 부르는 것은 서로 다른 세 가지입니다. 이걸 구분하지 못하면 엉뚱한 슬라이더를 계속 만지게 됩니다.

| 종류 | 인스펙터 섹션 | 무엇이 만드나 |
|---|---|---|
| **형태 그림자** | 형태 그림자 | 표면 노멀과 광원 방향. 캐릭터 자신의 굴곡으로 생기는 명암. **툰 룩의 본체** |
| **캐스트 그림자** | 그림자 투영 | Unity의 실시간 섀도우 맵. 다른 물체와 자기 자신이 드리우는 그림자 |
| **2D 그림자** | 2D 그림자 ([깊이 기반 효과](/guides/depth-effects)) | 카메라 깊이 텍스처. 화면 공간에서 계산 |

## 1. 형태 그림자 경계 — 가장 먼저 {#1-형태-그림자-경계--가장-먼저}

**`1차 그림자 번짐`이 MingToon에서 가장 자주 조정하는 값입니다.** 여기서 룩의 성격이 정해집니다.

| 값 | 결과 |
|---|---|
| 0.001 근처 | 셀 애니메이션처럼 딱 떨어지는 경계 |
| 0.05 ~ 0.15 | 살짝 부드러운 일러스트 느낌 |
| 0.3 이상 | 부드러운 그라데이션 |

먼저 이 값 하나만 움직여 원하는 성격을 정한 다음 나머지로 넘어가세요. `빠른 설정`의 `1차 그림자 부드러움`이 같은 값입니다.

## 2. 그림자 색상 {#2-그림자-색상}

`1차 그림자 밝기`를 낮추면 어두워집니다. 다만:

:::caution[`그림자 색상` 섹션이 꺼져 있으면]
`1차 그림자 밝기`가 반영되지 않습니다. 캐스트 그림자도 마찬가지로, 이 섹션이 꺼져 있으면 단순히 어두워지기만 하고 `캐스트 그림자 밝기`가 무시됩니다.
:::

### 통합 그림자 — 겹칠 때 새까매지는 문제 {#통합-그림자--겹칠-때-새까매지는-문제}

형태·캐스트·2D 그림자가 같은 자리에 겹치면 세 번 어두워져서 검게 뭉갭니다. `그림자 색상` 안의 **`통합 그림자 사용`** 을 켜면 세 가지가 **같은 색상과 톤으로 수렴**해 이 문제가 없어집니다.

:::note[통합 모드에서 유지되는 것 / 무시되는 것]
- **유지** — 그림자 경계의 형태 설정, 그림자 패턴(스크린톤)
- **무시** — 개별 그림자의 색·블렌드·밝기 컨트롤 (값 자체는 보존되므로 끄면 그대로 돌아옵니다)

`통합 그림자 색상`의 **알파가 적용량**입니다. 알파가 0이면 어떤 색을 골라도 그림자가 베이스 색 그대로 남습니다.
:::

:::caution[끌 때 룩이 한 번에 바뀔 수 있습니다]
통합 그림자를 끄면 각 층에 **저장돼 있던 색이 그대로 돌아옵니다.** 통합으로 작업하는 동안 개별 색을 만진 적이 없다면, 끄는 순간 예전 값이 한꺼번에 나타납니다.
:::

### 부위마다 다른 그림자 색 — 그림자 컬러맵 {#그림자-컬러맵}

통합 그림자는 색이 하나입니다. 머리카락은 붉게, 피부는 노랗게처럼 **부위마다 다른 그림자 색**이 필요하면 `그림자 컬러맵`을 켜세요. 통합 그림자 한 색을 UV 맵으로 분포시킵니다.

- **흰색이 기준값입니다.** 흰 부분은 통합 그림자 색상 그대로 나오고, 칠한 부분만 그 색으로 곱해집니다. 방금 켠 상태에서는 결과가 바뀌지 않습니다.
- `컬러맵 적용량`이 0이면 통합 색상 하나만, 1이면 텍스처 색을 그대로 곱합니다. 텍스처 HSVG로 색조·채도·명도·감마를 따로 조정할 수 있습니다.

:::note[통합 그림자 전용입니다]
통합 그림자가 꺼져 있으면 셰이더가 이 텍스처를 **아예 읽지 않습니다.** 레이어별 그림자 모드는 층마다 색을 이미 가지고 있어 분포시킬 대상이 없기 때문이며, 샘플 비용도 들지 않습니다.
:::

:::tip[하이라이트 마스크가 남아 있다면]
이 맵과 함께 매트캡이나 스페큘러 마스크로도 쓰는 것을 권합니다. 색 분포와 광택을 나눠서 잡을 수 있습니다.
:::

## 3. 2차 그림자 — 3단 셀 음영 {#3-2차-그림자--3단-셀-음영}

`2차 그림자 사용`을 켜면 가장 어두운 쪽에 단계가 하나 더 생깁니다.

- `2차 그림자 밝기`는 **1차보다 낮게** 두어야 단계가 구분되어 보입니다.
- `2차 그림자 번짐`을 1차보다 **좁게** 두면 안쪽 단계가 또렷해집니다.

## 4. 그림자 투영 (캐스트 섀도우) {#4-그림자-투영-캐스트-섀도우}

실시간 그림자는 툰 룩에서 가장 자주 말썽을 부리는 부분입니다. `캐스트 섀도우 수신` 그룹부터 봅니다.

`수신 강도`가 **0이면 캐스트 그림자가 완전히 사라지고**, 아래의 밝기·혼합·간접광 보정도 결과에 나타나지 않습니다.

### 그림자가 툰답지 않을 때

`PBR / 툰 혼합`을 1로 올리면 Unity 기본의 부드러운 감쇠 대신 툰 밴드로 딱 잘립니다. 밴드 폭은 `캐스트 툰 밴드 부드러움`이 정합니다.

### 얼룩덜룩한 그림자 {#얼룩덜룩한-그림자}

옷 주름이나 몸에 지저분한 얼룩이 생기면:

1. `셀프 캐스트 섀도우 억제`를 켭니다.
2. `셀프 섀도우 캐스터 바이어스`를 **0.01~0.03** 사이에서 조정합니다.

:::danger[바이어스를 너무 올리면]
얼룩은 사라지지만 접지 그림자가 뜨고 얇은 부위의 그림자가 끊깁니다. 조금씩 올리세요.
:::

### 얼굴의 스치는 그림자 {#얼굴의-스치는-그림자}

빛이 얼굴처럼 완만한 면에 스치듯 들어오면 계단 모양 얼룩이 생깁니다. `캐스트 톤 / 얼굴 안정화` 그룹에서:

1. `얼굴 캐스트 안정화`를 켭니다.
2. `안정화 강도`를 올립니다. **너무 올리면 앞머리 그림자 같은 의도된 그림자까지 옅어집니다.**
3. `측면광 판정 범위`로 보정이 걸리는 각도 범위를 정합니다. 올릴수록 넓은 범위에 걸립니다.
4. 위아래 방향의 얼룩은 `상하 보정 강도`와 `상하 도달 임계값`으로 잡습니다. 임계값은 **낮을수록 넓게** 걸립니다.
5. 경계가 여전히 거칠면 `단단한 경계 정리`를 씁니다.

### 그림자 경계가 계단처럼 각질 때 {#그림자-경계가-계단처럼-각질-때}

`투영 경계 페더` 그룹의 `투영 페더 사용`을 켜고 `투영 페더 반경`·`투영 페더 강도`를 조정합니다. `캐스트 경계 페더 품질`로 샘플 수를 정합니다.

:::note[페더는 없는 정보를 복구하지 못합니다]
낮은 해상도의 shadow map에 애초에 없던 디테일은 부드럽게 만든다고 돌아오지 않습니다. 먼저 광원의 shadow map 해상도와 bias/normal bias, cascade를 확인하세요.
:::

### 씬마다 그림자가 너무 세거나 약할 때

`캐스트 간접광 보정`을 올리면 환경광이 밝은 곳에서 캐스트 그림자가 옅어집니다. 실내·야외를 오가는 아바타에서 조명 차이를 자연스럽게 흡수합니다.

### 역광에서 몸에 캐릭터 모양 그림자가 겹칠 때 {#역광에서-몸에-캐릭터-모양-그림자가-겹칠-때}

`역광 실루엣 억제`를 켜면 광원을 등진 면에는 캐스트 그림자를 그리지 않습니다.

### 2D 그림자와 색이 따로 놀 때 {#2d-그림자와-색이-따로-놀-때}

`2D 그림자와 통합`을 켜면 2D 그림자가 캐스트 그림자와 같은 색을 쓰고, 겹치는 자리에서 두 번 어두워지는 것도 막힙니다.

## 6. 경계 장식 — 마지막에 {#6-경계-장식--마지막에}

명암 경계에 색 띠를 얹는 연출입니다. 룩이 다 잡힌 뒤에 하세요.

1. `그림자 경계 사용`을 켭니다.
2. `경계 폭`을 올립니다. **0이면 아래 항목이 전부 무시됩니다.**
3. `경계 강도`가 불투명도입니다. 0이면 폭을 아무리 올려도 안 보입니다.
4. `경계선 배치` — 켜면 밝은 면까지 걸쳐 두꺼운 색 경계, 끄면 그림자 안쪽에만 남아 단정해집니다.

:::tip[피부와 머리카락이 한 머티리얼에 섞여 있다면]
`경계 베이스 맵 혼합`을 올리세요. 0이면 단색 경계, 1이면 베이스 맵 색과 섞여 부위마다 다른 경계색이 나옵니다.
:::

:::caution[경계가 안 보이는 조건]
`그림자 색상` 섹션이 켜져 있어야 하고, 형태 그림자나 캐스트 그림자 중 **하나는 실제로 동작 중**이어야 합니다.
:::

## 라이팅 — 어두운 씬에서 검게 뭉칠 때 {#라이팅--어두운-씬에서-검게-뭉칠-때}

VRChat 월드는 조명을 아바타 제작자가 통제할 수 없습니다. `라이팅` 섹션의 아래 항목이 방어선입니다.

| 항목 | 하는 일 |
|---|---|
| `베이스 색 유지` <br />(간단 모드: 베이스 색상 보존) | 조명이 어두워도 베이스 맵 색을 얼마나 원본에 가깝게 유지할지. **조명을 예측할 수 없는 환경에서는 높게** |
| `씬 조명 색 영향` <br />(간단 모드: 조명 색상 반영) | 0이면 어떤 색 조명에서도 흰 조명처럼 보임. 밝기가 아니라 **색만** 다룹니다 |
| `간접광 보정` | 환경광 밝기만큼 형태 그림자를 들어 올림. 형태 그림자가 켜져 있을 때만 계산됩니다 |
| `최종 최소 밝기` | 아무리 어두워도 이 아래로 내려가지 않음 |
| `최종 최대 밝기` | 아무리 밝아도 이 위로 올라가지 않음. 과노출 월드 대비 |

`밝은 면 밝기`는 빛을 받는 면 전체의 배수입니다. 1이 기준이고, 올리면 밝은 면이 흰색으로 뭉개지기 쉽습니다.

### 추가 광원 {#추가-광원}

포인트/스폿 라이트에 대한 반응은 별도 항목입니다.

- `추가 광원 받기` · `추가 광원 강도` (간단 모드)
- `추가 광원 PBR / 툰 혼합` · `추가 광원 툰 경계` · `추가 광원 툰 부드러움` (전체 설정)

주광과 같은 톤을 유지하려면 추가 광원 쪽 툰 경계도 함께 맞추세요.
