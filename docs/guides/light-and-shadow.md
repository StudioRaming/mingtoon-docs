# 조명과 그림자

> 이 페이지는 **형태 그림자**를 처음 잡아 보는 분을 위한 것입니다.
> 캐릭터의 명암 경계를 셀 애니메이션처럼 만듭니다. 약 5분 걸립니다.

## 이게 뭔가요

MingToon에서 그림자는 세 종류입니다.
셋은 각각 다른 슬라이더를 쓰므로 먼저 구분하세요.

| 종류 | 인스펙터 섹션 | 무엇이 만드나 |
|---|---|---|
| 형태 그림자 | **형태 그림자** | 캐릭터 자신의 굴곡. 툰 룩의 본체 |
| 투영 그림자 | **그림자 투영** | 다른 물체와 자기 자신이 드리우는 실시간 그림자 |
| 뎁스 그림자 | **뎁스 그림자** | 화면 깊이로 그리는 앞머리 그림자 |

## 언제 쓰나요

- 변환 직후 명암이 흐릿해서 경계를 또렷하게 만들고 싶을 때.
- 그림자가 겹친 자리가 새까맣게 뭉칠 때.
- 어두운 월드에서 캐릭터가 통째로 검게 가라앉을 때.

## 30초 만에 켜 보기

1. 변환한 몸 재질을 고릅니다.
2. **형태 그림자** 를 켭니다.
3. **1차 그림자 번짐** 을 0.01로 내립니다.
4. **1차 그림자 밝기** 를 0.7로 내립니다.

명암 경계가 한 줄로 딱 떨어지면 성공입니다.
아무 변화가 없으면 [문제 해결](/troubleshooting#shadow)로 가세요.

## 켜는 법

### 1. 형태 그림자 경계부터 {#1-형태-그림자-경계--가장-먼저}

**1차 그림자 번짐** 이 이 제품에서 가장 자주 만지는 값입니다.
0.001에 가까우면 셀 애니메이션, 0.3 이상이면 그라데이션입니다.
이 값 하나로 룩의 성격을 정한 뒤 다음으로 넘어가세요.

### 2. 그림자 색을 한 색으로 모으기 {#통합-그림자--겹칠-때-새까매지는-문제}

세 그림자가 같은 자리에 겹치면 세 번 어두워집니다.
**그림자 색상** 섹션의 **통합 그림자 사용** 을 켜면 한 색으로 수렴합니다.
**통합 그림자 색상** 의 알파가 적용량입니다. 알파가 0이면 변화가 없습니다.

:::note[통합을 켜면 유지되는 것과 무시되는 것]
그림자 경계의 모양과 [그림자 패턴](/guides/shadow-pattern)은 그대로 유지됩니다.
층별 색·블렌드·밝기 값은 화면에 반영되지 않고 보존만 됩니다.
:::

### 3. 부위마다 다른 그림자 색 {#그림자-컬러맵}

머리카락은 붉게, 피부는 노랗게 나누려면 **그림자 컬러맵** 을 켭니다.
흰색이 기준값이라 켠 직후에는 결과가 바뀌지 않습니다.
**컬러맵 적용량** 을 올려야 칠한 색이 나타납니다.

:::caution[통합 그림자가 꺼져 있으면 읽지 않습니다]
통합 그림자가 꺼진 상태에서는 셰이더가 이 텍스처를 아예 읽지 않습니다.
층마다 색을 이미 가지고 있어 분포시킬 대상이 없기 때문입니다.
:::

### 4. 투영 그림자 다듬기

**그림자 투영** 섹션의 **수신 강도** 가 0이면 아래 값이 전부 무시됩니다.
먼저 이 값을 1로 두세요.
그림자가 부드럽게 흐르면 **PBR / 툰 혼합** 을 1로 올려 툰 밴드로 자릅니다.

### 5. 어두운 월드 대비 {#라이팅--어두운-씬에서-검게-뭉칠-때}

VRChat 월드의 조명은 아바타 제작자가 통제할 수 없습니다.
**라이팅** 섹션의 **간접광 보정** 이 어두운 면을 들어 올립니다.
**씬 조명 색상 영향** 을 0으로 두면 색 조명에서도 흰 조명처럼 보입니다.

## 자주 만지는 값

| 인스펙터 라벨 | 뭘 바꾸는지 | 추천 시작값 | 올리면 / 내리면 |
|---|---|---|---|
| **1차 그림자 번짐** | 명암 경계의 번짐 폭 | 0.01 | 올리면 부드럽게 번지고, 내리면 잉크 선이 됩니다 |
| **1차 그림자 밝기** | 1차 그림자 색의 밝기 배수 | 0.7 | 내리면 어두워지고, 1이면 베이스 색 그대로입니다 |
| **통합 그림자 사용** | 세 그림자를 한 색으로 모음 | 켜기 | 켜면 겹쳐도 안 어두워지고, 끄면 층별 색이 돌아옵니다 |
| **수신 강도** | 투영 그림자를 받는 양 | 기본값 그대로(1) | 0이면 투영 그림자와 아래 값이 전부 사라집니다 |
| **셀프 섀도우 캐스터 바이어스** | 자기 그림자를 표면에서 밀어냄 | 0.02 | 올리면 얼룩이 사라지고, 너무 올리면 접지 그림자가 뜹니다 |
| **간접광 보정** | 환경광이 어두운 면을 들어 올리는 양 | 기본값 그대로(1) | 올리면 어두운 월드에서 덜 뭉치고, 0이면 검게 가라앉습니다 |
| **경계 폭** | 명암 경계에 얹는 색 띠의 폭 | 0.5 | 올리면 띠가 두꺼워지고, 0이면 띠가 아예 안 그려집니다 |

## 흔한 문제

### 역광에서 몸에 캐릭터 모양 그림자가 겹칠 때 {#역광에서-몸에-캐릭터-모양-그림자가-겹칠-때}

광원을 등진 면에 자기 실루엣이 한 번 더 겹쳐 보이는 증상입니다.
**그림자 투영** 의 **역광 실루엣 억제** 를 켜세요.
지우기 시작하는 지점은 **캐스트 억제 오프셋** 으로 맞춥니다.

### 뎁스 그림자와 색이 따로 놀 때 {#2d-그림자와-색이-따로-놀-때}

앞머리 그림자만 색이 튀어 보이는 증상입니다.
**그림자 투영** 의 **뎁스 그림자와 통합** 을 켜세요.
두 그림자가 같은 색을 쓰고 겹친 자리도 두 번 어두워지지 않습니다.

### 얼굴에 그림자가 스쳐 지나갈 때 {#얼굴의-스치는-그림자}

얼굴은 몸과 다른 규칙으로 잡아야 합니다.
[캐릭터 표현](/guides/character#4단계-앞머리-그림자)에서 **그림자 방식** 을 고르세요.
더 나빠지면 [문제 해결](/troubleshooting#face)을 보세요.
