# 문제 해결

증상으로 찾으세요. 대부분은 "상위 값이 0이면 하위가 전부 무시된다"는 구조 때문에 생깁니다.

## 재질이 분홍색(마젠타)으로 보인다

| 원인 | 확인 | 조치 |
|---|---|---|
| 렌더 파이프라인 불일치 | BRP 프로젝트에 URP 셰이더를 쓰거나 그 반대 | 맞는 백엔드의 셰이더로 교체 |
| URP 버전 범위 밖 | URP 12.x인지 | Unity 2021.3 + URP 12.x로 맞춤 |
| **셰이더 모델 4.5 미달** | `Tools > Studio Raming > MingToon > Validate Project` | 지원 대상은 PC(DX11+/Vulkan/Metal)뿐. Android·Quest·iOS·WebGL은 미지원 |

:::danger 이 경우 다른 오류 메시지가 나오지 않습니다
SubShader가 통째로 탈락하기 때문에 로그가 조용합니다. 분홍색이 유일한 신호입니다.
:::

## 값을 바꿨는데 아무 변화가 없다

MingToon에는 상위 값이 0이면 하위 항목 전체가 무시되는 구조가 많습니다. 아래 순서로 위에서부터 확인하세요.

| 안 보이는 것 | 먼저 확인할 상위 값 |
|---|---|
| 베이스 틴트 | `틴트 불투명도` |
| 2D 림 / 2D 그림자 | `마스터 폭` → 각 모듈의 `강도` |
| PBR 하이라이트·환경 반사 | `반사광 강도` |
| 텍스처/노멀/맷캡 레이어 | `레이어 수` → 각 레이어의 `불투명도`/`강도` |
| 림 라이트 | `강도` → `폭` |
| 림 셰이드 | `그림자 기여 강도` → `림 그림자 폭` |
| 그림자 경계 띠 | `경계 폭` → `경계 강도` |
| 그림자 패턴 | `패턴 강도` |
| 얼굴 노멀 보정 | `노멀 누름 정도` |
| PBR 패킹 마스크의 채널 설정 | `패킹 마스크 사용` |
| 알파 마스크 | 표면 모드가 Opaque면 켜도 안 보임 |

## 2D 림 / 2D 그림자 / Inner Edge가 안 보인다

| 원인 | 조치 |
|---|---|
| 모듈이 꺼져 있음 | Depth Effects 토글 확인 |
| `마스터 폭`이 0 | 올림 |
| 각 모듈의 강도가 0 | 올림 |
| **카메라 깊이가 없음** | [Camera Depth](/guides/camera-depth) 플랫폼별 설정 |
| 표면 모드가 Transparent(큐 3000) | `Transparent, depth-recorded`(큐 2499)로 변경 |
| VRChat 일반 화면 | 아바타가 강제할 수 없음. Photo Camera·미러에서 각각 확인 |
| URP | Renderer Feature 설치 + Depth Texture 활성화 |
| Warudo | 호스트 depth bridge 필요 |

## Inner Edge만 사라졌다

| 원인 | 조치 |
|---|---|
| `Inner Edge 외곽선에 적용`이 켜져 있고 버텍스 컬러가 검음 | 토글을 끄거나 압력 소스를 바꿈 |
| 표면 모드가 Transparent | 큐 2499 모드로 변경 |
| 카메라 깊이 없음 | 위 항목 참고 |

Hull 외곽선은 카메라 깊이 없이도 동작합니다. Hull은 보이는데 Inner Edge만 없다면 깊이 문제입니다.

## Hull 외곽선이 통째로 사라졌다

| 원인 | 조치 |
|---|---|
| **버텍스 컬러가 검게 임포트된 메시에서 `압력 소스`가 `VertexRed`** | 압력 소스를 바꾸거나 버텍스 컬러 확인 |
| `헐 압력 대비`가 0 | 압력이 완전히 무시됨 |
| `컬러 마스크`가 0 | 15(RGBA 전체)로 |

## 외곽선이 각진 부분에서 끊긴다

`노멀 소스`가 `VertexColorTS` 또는 `UV8TS`인데 **스무딩한 외곽선 노멀을 굽지 않은** 메시입니다. `MeshNormal`로 바꾸세요.

## 캐스트 그림자가 얼룩덜룩하다

| 위치 | 조치 |
|---|---|
| 옷 주름·몸 전반 | `셀프 캐스트 섀도우 억제` 켜고 `셀프 섀도우 캐스터 바이어스` 0.01~0.03 |
| 얼굴 | `얼굴 캐스트 안정화` 켜고 `안정화 강도` 조정 |
| 전반적으로 지글거림 | 광원 shadow map 해상도 · bias/normal bias · cascade 순으로 확인 |

:::note 페더는 없는 정보를 복구하지 못합니다
낮은 해상도의 shadow map에 애초에 없던 디테일은 부드럽게 만든다고 돌아오지 않습니다.
:::

## 그림자가 겹치는 곳만 새까맣다

`통합 그림자 사용`을 켜세요. 형태·캐스트·2D 그림자를 하나의 최종 색으로 모읍니다. → [그림자 잡기](/guides/shadow#통합-그림자--겹칠-때-새까매지는-문제)

## 역광에서 몸 위에 캐릭터 모양 그림자가 겹친다

`역광 실루엣 억제`를 켜세요.

## 어두운 월드에서 캐릭터가 검게 뭉갠다

| 항목 | 조치 |
|---|---|
| `베이스 색 유지` | 올림 |
| `최소 밝기` | 올림 |
| `간접광 보정` | 올림 |
| `캐스트 간접광 보정` | 올림 |

## 그림자 패턴이 전혀 안 찍힌다

| 원인 | 조치 |
|---|---|
| `패턴 모양 타일 사용`이 켜졌는데 타일 슬롯이 빔 | 빈 슬롯은 **흰색**으로 읽히고 흰색은 어떤 농도도 넘지 못하는 임계값입니다. 동봉 타일을 넣으세요 |
| `패턴 강도`가 0 | 올림 |
| 적용 대상이 안 맞음 | `패턴 적용 대상` 확인 |

## 패턴 점이 톤에 반응하지 않고 크기가 일정하다

**이미 이진화된 점 패턴**을 타일로 넣은 경우입니다. 타일은 그림이 아니라 임계값 맵이어야 합니다. → [그림자 패턴](/guides/shadow-pattern#타일은-그림이-아니라-임계값-맵입니다)

## 변환 후 룩이 원본과 다르다

변환 로그의 `lossy` / `unsupported` 항목을 먼저 읽고, 아래를 원본과 비교하세요.

- 마스크 채널 선택과 반전
- 텍스처 ST (Tiling / Offset)
- AO
- 표면 모드
- 얼굴 슬롯 판정

## baked 재질의 복원 버튼이 비활성이다

| 확인 |
|---|
| bake manifest가 남아 있는가 |
| 원본 편집 재질의 GUID가 살아 있는가 |
| Bake 이후 Renderer 계층 / 재질 슬롯이 바뀌지 않았는가 |

## 업로드했는데 최적화가 안 걸린 것 같다

1. Console에 `[MingToon] VRChat build hook compiled and registered.`가 있는지 — 없으면 훅 자체가 컴파일되지 않은 상태입니다.
2. `Tools > Studio Raming > MingToon > Optimize Shaders On Build`가 체크되어 있는지.
3. 프로젝트 폴더 옆 `StudioRaming/MingToonOptimizeReport.txt` 확인.

→ [빌드 시 자동 최적화](/workflow/build-optimization#제대로-걸렸는지-확인하기)

## 머리카락이 뺨을 뚫고 보인다

표면 모드를 `Transparent, depth-recorded`(큐 2499)로 두고 `Transparent Depth Prepass`를 켜세요.

## 그래도 해결되지 않으면

`studioraming@gmail.com`으로 아래를 함께 보내 주세요.

1. Unity 버전과 렌더 파이프라인
2. 대상 플랫폼
3. MingToon 버전
4. Console 로그 전문
5. 재현 순서
