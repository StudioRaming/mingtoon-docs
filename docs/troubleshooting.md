# 문제 해결

증상으로 찾으세요. 대부분은 **"상위 값이 0이거나 꺼져 있으면 하위가 전부 무시된다"** 는 구조 때문에 생깁니다.

## 아무 값도 안 먹힌다

위에서부터 확인하세요.

1. **전체 효과** — 인스펙터 맨 위의 마스터 스위치. 꺼져 있으면 아래 섹션 전체가 비활성이고 `이 섹션은 전체 효과가 꺼져 있어 비활성 상태입니다.` 가 표시됩니다.
2. **섹션 마스터 토글** — 각 섹션에도 자체 토글이 있습니다. 꺼져 있으면 `빠른 설정`에 `(모듈 꺼짐)`이 붙습니다.
3. **상위 값** — 아래 표.

| 안 보이는 것 | 먼저 확인할 상위 값 |
|---|---|
| 베이스 틴트 | `틴트 불투명도` |
| 깊이 림 / 2D 그림자 | `마스터 폭` → 각 모듈의 `강도` |
| PBR 하이라이트·환경 반사 | `반사광 강도` |
| 텍스처/노멀/맷캡 레이어 | `레이어 수` → 각 레이어의 `불투명도`/`강도` |
| 림 라이트 | `강도` → `폭` |
| 림 셰이드 | `그림자 기여 강도` → `림 그림자 폭` |
| 그림자 경계 띠 | `경계 폭` → `경계 강도` |
| 그림자 패턴 | `패턴 강도` |
| 얼굴 노멀 보정 | `노멀 누름 정도` |
| 얼굴 영역 마스크 | `마스크 강도` (0이면 전체를 얼굴로 취급) |
| PBR 패킹 마스크의 채널 설정 | `패킹 마스크 사용` |
| 캐스트 그림자 밝기·혼합 | `수신 강도` |
| 알파 마스크 | 표면 모드가 불투명이면 켜도 안 보임 |
| `1차 그림자 밝기`·`캐스트 그림자 밝기` | `그림자 색상` 섹션이 켜져 있는지 |

## 재질이 분홍색(마젠타)으로 보인다

| 원인 | 확인 | 조치 |
|---|---|---|
| 렌더 파이프라인 불일치 | BRP 프로젝트에 URP 셰이더를 쓰거나 그 반대 | 맞는 백엔드의 셰이더로 교체 |
| **셰이더 모델 4.5 미달** | `Tools > Studio Raming > MingToon > Validate Project` | 지원 대상은 PC(DX11+/Vulkan/Metal)뿐. Android·Quest·iOS·WebGL은 미지원 |
| URP 버전 범위 밖 | URP 12.x인지 | Unity 2021.3 + URP 12.x로 맞춤 |

:::danger 이 경우 다른 오류 메시지가 나오지 않습니다
SubShader가 통째로 탈락하기 때문에 로그가 조용합니다. 분홍색이 유일한 신호입니다.
:::

## Validate Project가 Unity 버전 오류를 낸다

VRChat용 **2022.3.22f1**에서 `MING-ENV-UNITY-VERSION` 오류가 나옵니다. 현재 빌드의 검증기가 2021.3.x 기준으로만 판정하기 때문입니다.

**VRChat 대상에서는 2022.3.22f1이 올바른 버전이므로 이 항목은 무시하세요.** 다른 검증 항목은 정상적으로 신뢰할 수 있습니다. 알려진 불일치이며 수정 예정입니다.

## 깊이 림 / 2D 그림자 / 내부 2D 경계가 안 보인다

| 원인 | 조치 |
|---|---|
| `전체 효과` 또는 `깊이 효과`가 꺼짐 | 인스펙터가 `깊이 효과 켜기` 버튼을 보여 줍니다 |
| `마스터 폭`이 0 | 올림 |
| 각 모듈의 강도가 0 | 올림 |
| 표면 모드가 **투명** | `투명 · 아웃라인용 깊이 기록`으로 변경. 인스펙터가 `깊이 기록 모드가 필요합니다`로 알려 줍니다 |
| **카메라 깊이가 없음** | [깊이 기반 효과](/guides/depth-effects) 플랫폼별 설정 |
| VRChat 일반 화면 | 아바타가 강제할 수 없음. Photo Camera·미러에서 각각 확인 |
| URP | Renderer Feature 설치 + Depth Texture 활성화 |
| Warudo | Depth를 켠 카메라 또는 host depth bridge 필요 |

인스펙터에 `활성 Scene/Game 카메라의 깊이 텍스처가 준비되지 않았습니다.` 가 뜨면 Scene 뷰를 다시 열고, 계속되면 `Validate Project`를 실행하세요.

## 내부 2D 경계만 사라졌다

| 원인 | 조치 |
|---|---|
| `Inner Edge 외곽선에 적용`이 켜져 있고 버텍스 컬러가 검음 | 토글을 끄거나 압력 소스를 바꿈 |
| 표면 모드가 투명 | 깊이 기록 모드로 변경 |
| 카메라 깊이 없음 | 위 항목 참고 |

노멀 아웃라인은 카메라 깊이 없이도 동작합니다. **노멀 아웃라인은 보이는데 내부 2D 경계만 없다면 깊이 문제입니다.**

## 아웃라인을 찾을 수 없다

`내부 2D 경계`는 **아웃라인 그룹이 아니라 깊이 기반 효과 그룹**에 있습니다. 화면 깊이를 읽기 때문입니다.

## 노멀 아웃라인이 통째로 사라졌다

| 원인 | 조치 |
|---|---|
| **버텍스 컬러가 검게 임포트된 메시에서 `압력 소스`가 `VertexRed`** | 압력 소스를 바꾸거나 버텍스 컬러 확인 |
| `헐 압력 대비`가 0 | 압력이 완전히 무시됨 |
| `컬러 마스크`가 0 | 15(RGBA 전체)로 |

## 아웃라인이 각진 부분에서 끊긴다

`노멀 소스`가 `VertexColorTS` 또는 `UV8TS`인데 **스무딩한 외곽선 노멀을 굽지 않은** 메시입니다. `MeshNormal`로 바꾸세요.

## 씬 뷰에서 아웃라인 두께를 칠할 수 없다

| 원인 | 조치 |
|---|---|
| `압력 소스`가 Vertex Alpha/Vertex Red가 아님 | `Vertex Alpha로 전환` 버튼 사용 |
| 렌더러가 선택 항목 아래에 없음 | 해당 렌더러를 포함해 선택 |
| 머티리얼을 여러 개 선택함 | 하나만 선택 |

## 캐스트 그림자가 얼룩덜룩하다

| 위치 | 조치 |
|---|---|
| 옷 주름·몸 전반 | `셀프 캐스트 섀도우 억제` 켜고 `셀프 섀도우 캐스터 바이어스` 0.01~0.03 |
| 얼굴 | `얼굴 캐스트 안정화` 켜고 `안정화 강도`·`측면광 판정 범위` 조정 |
| 위아래 방향 | `상하 보정 강도`·`상하 도달 임계값` (낮을수록 넓게) |
| 경계가 계단처럼 각짐 | `투영 페더 사용` + `투영 페더 반경`·`강도` |
| 전반적으로 지글거림 | 광원 shadow map 해상도 · bias/normal bias · cascade 순으로 확인 |

:::note 페더는 없는 정보를 복구하지 못합니다
낮은 해상도의 shadow map에 애초에 없던 디테일은 부드럽게 만든다고 돌아오지 않습니다.
:::

## 그림자가 겹치는 곳만 새까맣다

`그림자 색상` 섹션의 `통합 그림자 사용`을 켜세요. 형태·캐스트·2D 그림자가 같은 색상과 톤으로 수렴합니다. → [조명과 그림자](/guides/light-and-shadow#통합-그림자--겹칠-때-새까매지는-문제)

## 통합 그림자를 켰더니 개별 그림자 색이 안 먹힌다

정상입니다. 통합 모드에서는 개별 그림자의 색·블렌드·밝기가 결과에 반영되지 않습니다. 값은 보존되므로 끄면 돌아옵니다. 개별 값을 통합 값에 맞추려면 `통합 값을 개별 그림자에 복사`를 쓰세요.

## 역광에서 몸 위에 캐릭터 모양 그림자가 겹친다

`역광 실루엣 억제`를 켜세요.

## 어두운 월드에서 캐릭터가 검게 뭉갠다

| 항목 | 조치 |
|---|---|
| `베이스 색 유지` (간단 모드: 베이스 색상 보존) | 올림 |
| `최종 최소 밝기` | 올림 |
| `간접광 보정` | 올림 |
| `캐스트 간접광 보정` | 올림 |

밝은 월드에서 하얗게 날아가면 `최종 최대 밝기`를 낮추세요.

## 그림자 패턴이 전혀 안 찍힌다

| 원인 | 조치 |
|---|---|
| `패턴 모양 타일 사용`이 켜졌는데 타일 슬롯이 빔 | 빈 슬롯은 **흰색**으로 읽히고 흰색은 어떤 농도도 넘지 못하는 임계값입니다. 인스펙터의 기본 제공 타일 버튼을 쓰세요 |
| `패턴 강도`가 0 | 올림 |
| 적용 대상이 안 맞음 | `패턴 적용 대상` 확인 |

## 패턴 점이 톤에 반응하지 않고 크기가 일정하다

**이미 이진화된 점 패턴**을 타일로 넣은 경우입니다. 타일은 그림이 아니라 임계값 맵이어야 합니다. → [그림자 패턴](/guides/shadow-pattern#타일은-그림이-아니라-임계값-맵입니다)

## 머리카락이 뺨을 뚫고 보인다

표면 모드를 `투명 · 아웃라인용 깊이 기록`으로 두고 `투명 깊이 선기록`을 켜세요.

## 변환 후 룩이 원본과 다르다

변환 로그의 `lossy` / `unsupported` 항목을 먼저 읽고, 아래를 원본과 비교하세요.

- 마스크 채널 선택과 반전
- 텍스처 ST (Tiling / Offset)
- AO
- 표면 모드
- 얼굴 슬롯 판정

## baked 재질의 복원 버튼이 비활성이다

| 확인 |
|---|
| bake manifest가 남아 있는가 |
| 원본 편집 재질의 GUID가 살아 있는가 |
| Bake 이후 Renderer 계층 / 재질 슬롯이 바뀌지 않았는가 |

## 업로드했는데 최적화가 안 걸린 것 같다

1. Unity 버전이 **2022.3.22f1** 인지. 2021.3에서는 VRChat 훅이 컴파일되지 않습니다.
2. Console에 `[MingToon] VRChat build hook compiled and registered.` 가 있는지.
3. `Tools > Studio Raming > MingToon > Optimize Shaders On Build`가 체크되어 있는지.
4. 프로젝트 폴더 옆 `StudioRaming/MingToonOptimizeReport.txt` 확인.

→ [빌드 시 자동 최적화](/workflow/build-optimization#제대로-걸렸는지-확인하기)

## 작업 중 인스펙터가 무겁다

정상입니다. 편집용 셰이더는 모든 기능과 최대 레이어 수를 처음 한 번에 컴파일해 유지합니다. 덕분에 기능 토글 시 변형 컴파일 대기나 파란 자리표시 색이 생기지 않습니다. 경량화는 [빌드할 때](/workflow/build-optimization)만 적용됩니다.

## 그래도 해결되지 않으면

`studioraming@gmail.com`으로 아래를 함께 보내 주세요.

1. Unity 버전과 대상 플랫폼 (VRChat PC / Warudo / 일반 Unity)
2. 렌더 파이프라인 (BRP / URP 12.x)
3. MingToon 버전
4. Console 로그 전문
5. 재현 순서
