# いま MingToon がやらないこと

> このページは説明です。今すぐインストールするには[インストール](/getting-started/installation)をご覧ください。

## 一行でいうと

MingToon は公開オープンベータです。Built-in パイプライン(BRP)のみを配布します。

現在のバージョンは MingToon マネージャーの `更新設定` で確認してください。バージョンごとの変更は[パッチノート](/changelog)にあります。

## 配布前に知っておくこと

| 項目 | 現在の状態 |
|---|---|
| **性能の数値** | 検証済みの GPU ms・SetPass の改善数値はありません。性能に関する主張はしません |
| **VRChat PC** | 主な対象です。手動検証であり、リリース認証は完了していません |
| **VRChat Quest** | MingToon シェーダーを直接実行しません |
| **WARUDO** | 実機検証の待機状態です |
| **URP** | 今回の BRP オープンベータには含まれません |
| **深度エフェクト** | ホストがカメラ深度を提供するときだけ見えます |
| **lilToon 変換** | 相互運用のツールです。他のシェーダーの結果をそのまま複製するものではありません |

→ [対応環境](/platforms/compatibility) · [深度エフェクトがどこまで保証されるか](/platforms/vrchat#깊이-효과가-어디까지-보장되나)

## インストール経路は 2 つです

VCC でインストールする BRP コアはソースパッケージです。BOOTH のインストーラーは DLL 配布の経路です。

2 つの経路は同じ BRP コアのバージョンを指します。

## 配布前に自分で確認すること

作った成果物を他人に渡す前に、以下を確認してください。

1. Console に C#・シェーダーのエラーが 0 件です。
2. 実際のアバターの全身と顔をそれぞれキャプチャしてみました。
3. 対象プラットフォームのビルドが成功します。
4. 対象プラットフォームで直接見ました。VRChat なら自分の画面・ミラー・Photo Camera をそれぞれ見ます。

`StudioRaming > MingToon > Validate Project` が環境条件を先に振り分けてくれます。

:::note[ここまでが皆さんの担当です]
シェーダーのコンパイル回帰テストと EditMode テストは、私たちがリリースごとに回します。
皆さんに確認していただくのは、実際のアバターで見える結果です。
:::

## ベータのフィードバック

バグ報告は[公式 Discord サーバー](https://discord.gg/Zsj6pkWKKs)のバグ報告チャンネルをご利用ください。

1. Unity のバージョンと対象プラットフォーム (VRChat PC / WARUDO / 一般 Unity)
2. レンダーパイプライン (BRP / URP 12.x)

4. Console ログの全文
5. 再現手順
