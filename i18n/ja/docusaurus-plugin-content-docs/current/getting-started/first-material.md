# 最初のマテリアルを作成する

**このドキュメントを完了すると、** MingToonのマテリアル1つを作成してモデルに適用し、トゥーンシェーディングが実際にオンになっていることを目で確認します。約5分。

このドキュメントは**マテリアル1つ**を扱います。アバター全体を一度に移行する場合は、[lilToon変換](/workflow/liltoon-conversion)に移動してください。

## 1. マテリアルを作成

1. Projectウィンドウで右クリック → `Create > Material`
2. 作成されたマテリアルを選択して、Inspector上部のシェーダードロップダウンを開きます。
3. `StudioRaming > MingToon > BRP`を選択します。

**このようになれば正常です。** Inspectorが一般的な Standard シェーダーUIではなく、MingToon専用インスペクターに変わります。

<!-- SCREENSHOT: シェーダー選択ドロップダウン -->

:::tip[マテリアルがピンク色の場合]
シェーダーがコンパイルされていません。ほとんどの場合、レンダーパイプラインが一致していないか、ビルドターゲットがシェーダーモデル4.5を満たしていない場合です。 → [トラブルシューティング](/troubleshooting)
:::

## 2. サーフェスモードを決定

ベースマップを入れる**前に**、サーフェスモードを決定します。後で変更するとレンダーキューが移動し、深度ベースの効果が完全にオフになることがあります。

| パーツ | サーフェスモード |
|---|---|
| 身体、衣服 | **不透明** |
| 髪、まつげ | **カットアウト** (`アルファ カットオフ` 0.3~0.6) |
| 半透明かつ深度効果が必要な場合 | **透明・アウトライン用深度記録** |

詳細は[基本設定](/guides/basics#1-표면-모드부터-정합니다)に記載されています。

## 3. ベーステクスチャを追加

1. Inspectorビューモードが**Simple**であることを確認します。
2. **Base Map**スロットにキャラクタータクスチャを配置します。
3. マテリアルをモデルのRendererにドラッグして適用します。

**このようになれば正常です。** シーンにキャラクターがテクスチャ色で表示され、光源の方向に応じて**はっきりした影**が生成されます。このはっきりした境界がトゥーンシェーディングがオンになっていることの合図です。滑らかなグラデーションだけが見える場合、シェーダーはStandardのままです。

<!-- SCREENSHOT: ベースマップ適用後のシーンビュー -->

## 4. 影と明るさを調整

Simple モードでは、以下だけに触れても印象が大きく変わります。

| 項目 | 機能 | 初回調整時 |
|---|---|---|
| **ベースマップ HSVG** | ベース色の色相・彩度・明度・ガンマ補正 | 元のテクスチャを編集せず、トーンのみ調整 |
| **1次シャドウソフトネス** (クイック設定) | 明暗境界のぼかし幅 | **最初に調整する値。** 0.001ならセル、0.3以上ならグラデーション |
| **ベースカラー保持** | 照明が暗くても原画の色をどれだけ保つか | VRChatワールド対比。高く設定 |
| **最終最小明度** | どんなに暗くてもこれ以下に下がらない | 暗いワールドで黒くつぶれないように |

:::tip[VRChatで特に重要]
ワールドライティングはアバター製作者が制御できません。`ベースカラー保持`と`最終最小明度`を上げておくと、どのワールドに入ってもキャラクターが消えません。 → [ライティングと影](/guides/light-and-shadow#라이팅--어두운-씬에서-검게-뭉칠-때)
:::

## 5. アウトラインをオンにする

1. ビューモードを**フル設定**に変更します。
2. **アウトライン**グループの`法線アウトライン`セクションで`クラシックハル使用`をオンにします。
3. `アウトライン幅`と`アウトラインカラー`を調整します。(`クイック設定`にもあります)

**このようになれば正常です。** キャラクターのシルエット外側に線が描画されます。

<!-- SCREENSHOT: 法線アウトラインがオンの状態 -->

法線アウトラインはカメラ深度が**必要ない**ため、どんな環境でも機能します。一方、衣装の皺のような内側の線を描画する**内部2D境界**はカメラ深度を読み込むため、[別途準備](/guides/depth-effects)が必要です。
