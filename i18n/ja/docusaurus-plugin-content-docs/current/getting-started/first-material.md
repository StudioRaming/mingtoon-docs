# MingToon Manager から始める

**MingToon で作業するアバターのルートには、常に MingToon Manager を配置してください。** 対象メッシュ・変換・ルック・更新確認を Manager で管理します。このガイドではインストール直後の追加から変換、クイック設定による調整まで進めます。[インストール](/getting-started/installation)を済ませてから始めてください。Face SDF Studio はまだ未発売で、この手順には必要ありません。

## 1. 最初にアバタールートへ Manager を追加

Hierarchy で変換する**作業するアバターのルートオブジェクト**を選びます。Add Component で **MingToon Manager** を検索して追加してください。衣装だけを編集する場合も Manager はアバタールートに配置します。対象メッシュが配下にあることを確認し、Manager を1つ選択して進めます。変換後もコンポーネントを残し、更新と作業状態を確認してください。

**VCC からインストールした場合、MingToon の更新は VCC で行います。** Manager の更新案内を使う前に、インストール方法を確認してください。

## 2. Face Mesh と Skin Mesh を指定

Manager の Setup で、顔メッシュを **Face**、素肌メッシュを **Skin** に指定します。顔・肌レンダラーの指定欄を使い、スロットごとの役割プレビューで範囲を確認してください。目・まつ毛・衣装・髪まで一括で顔や肌に指定しないでください。

顔や素肌のない衣装だけを変換する場合は、指定を空欄にできます。1つの Renderer に素肌と衣装が混在する場合はスロットで分け、衣装を **Regular** にします。役割はプリセットの顔用・肌用・共通の値を適用する対象を決めます。

→ [役割指定の詳細](/workflow/character-manager)

## 3. ルックプリセットを選択

**変換時のルックプリセット**で出発点となるルックを選びます。まず希望の雰囲気に近いプリセットを選び、変換後に値を整えてください。元マテリアルから読み取った設定を出発点にし、ルックプリセットを適用しない場合は **適用しない** を選択します。

## 4. 色調または既存マテリアルの値を選択

| 出発点 | 選択 |
|---|---|
| プリセットの色で新しい雰囲気を作る | **色調プリセット**で好みのトーンを選択 |
| 元マテリアルの色を基準に始める | **既存の値を使用**を選択 |

**既存の値を使用**は、**変換した元の色・影バンド・合成設定を保持**します。ルックプリセット全体を無効にする **適用しない** とは別の選択です。色調プリセットはルックの後に適用され、選択だけではマテリアルを変更しません。

## 5. 変換ボタンを押す

対象メッシュ、役割、ルック、色調を確認して**変換**を押します。完了後は編集用 MingToon マテリアルが対象に適用されたことを確認してください。除外・失敗スロットがある場合は、該当マテリアルと理由を確認してから進めます。

## 6. クイック設定でルックを調整

変換済みマテリアルを選び、Inspector の**クイック設定**を開きます。Manager のマテリアル選択機能で、顔や肌など必要な対象だけを選べます。最初は顔・肌・衣装を分けて調整し、全体へ同じ値を設定したいときに複数選択します。

**色と明るさ → 影の境界 → アウトライン → リム・光沢・エミッション**の順に、1項目ずつ動かしてモデルの変化を見ます。クイック設定にない項目は検索や全設定で探してください。下記の機能をすべて有効にする必要はありません。

## よく調整するパラメーター

| 変えたい印象 | 最初に探す項目 | 確認すること |
|---|---|---|
| 全体の色味 | ベースマップ HSVG | 色相・彩度・明度・ガンマを少しずつ調整し、肌と衣装の色を確認 |
| 暗い場所の明るさ | 間接光の持ち上げ · 最終最小明るさ | 暗部の明るさと陰影を確認。照明の色味はベースカラー保持で別に調整 |
| 影の境界 | 1次シャドウの柔らかさ | 下げるとくっきり、上げると柔らかく変化 |
| 影の色 | シャドウカラー | 肌・髪・衣装を個別に調整 |
| 外側の線 | アウトライン幅 · アウトライン色 | 近距離と全身表示で線の太さを確認 |
| 輪郭の光 | リムライト · 2Dリム | シルエットの強調量を確認。2Dリムはカメラ深度も必要 |
| 表面の光沢 | Matcap · トゥーンスペキュラー | 髪・衣装のハイライトが強すぎないか確認 |
| 自発光部分 | エミッション | 必要な範囲に適用し、色と強さを確認 |

値が反応しない場合は**全体のエフェクト → 対象モジュール → 必要条件**の順に確認します。2Dリム・2Dシャドウなどには[深度ベースの効果](/guides/depth-effects)に記載した準備が必要です。

## 7. 編集後は通常どおりアップロード・ビルド

マテリアルの編集が終わったら、**VRC SDK でアバターをアップロード**、または **WARUDO のモッドをビルド**します。その工程で自動最適化ベイクが実行されます。最初から手動 Bake を別途押す手順ではありません。**アバタールートの MingToon Manager を残し**、ビルド／アップロード時の自動最適化状態を確認してください。

詳しい条件は[ビルド時の自動最適化](/workflow/build-optimization)と対象プラットフォームのガイドを確認してください。ベータ版の検証範囲は[現在の制限](/limitations)に記載しています。
