## ホットフィックス 1 — 2026-09-07（第 1 次）

**更新後にすること**

- 顔プロキシは上書きだけで済みます。シーンを開くと編集用マテリアルのプロキシノーマルがすぐにシェーダーで計算されます。再アップロードは不要です。
- アウトラインのない lilToon 元から変換したマテリアルでステンシルを使っている場合は、再変換するか `アウトライン` > `ステンシル設定` を表面の値に手動で合わせてください。
- `エミッションを使用` が有効なマテリアルは、再変換するか Manager の `フォールバックプロパティを同期` を一度押してから再アップロードすると VRChat フォールバックが黒になります。
- VRChat ビルドが `Material recovery is incomplete` で止まっていたプロジェクトは、上書き後にエディターを一度再起動すると自動的に整理されます。
- ステンシル（目のオーバーレイ・非表示マスク）を使う lilToon 変換マテリアルは、再変換するかステンシル値を手動で戻してください。
- 再アップロードは不要です。

### 顔プロキシノーマルがシーンで何度も外れていた問題

- 症状 — 調整したプロキシがシーン保存・再生モード・リロード・検証のたびに元のノーマルへ戻り、その間インスペクターはプレビュークローンを指していたため編集が元のマテリアルに残りませんでした。
- 対処 — 一時的な UV7 プレビューメッシュ・マテリアルへの差し替えをやめ、編集用マテリアルではシェーダーがプロキシノーマルを直接計算します。アップロード用コピーは従来どおりプロキシ設定でベイクされ、そのマテリアルではリアルタイム計算がコンパイルから外れます。リアルタイムとベイクは同じ式です。
- あわせて修正 — Root Bone を持つ Skinned Mesh Renderer で `プロキシ領域マスク` の中心が顔からずれていた問題。シェーダーの見るオブジェクト空間がルートボーン（通常 Hips）空間であるためで、エディターがレンダラーごとに補正値を渡します。

### アウトラインのない lilToon マテリアルを変換するとアウトラインがステンシルマスクを無視していた問題

- 症状 — 前髪越しに見せるようステンシルを設定した目が、表面は透けるのにアウトラインだけ髪に隠れていました。lilToon のアウトラインなし派生は未使用のアウトラインステンシル値を持っており、変換後に MingToon が描くアウトラインがその中立値を受け取っていました。
- 対処 — 元にアウトラインがない場合、アウトラインは表面のステンシルユニットを引き継ぎます。元がアウトラインを描くなら従来どおり自身の値を保ちます。

### VRChat フォールバックシェーダーでエミッションがアバター全体を白く塗りつぶしていた問題

- 症状 — シェーダーのブロックや読み込み失敗でフォールバックに落ちたアバターが、アウトラインだけを残して白く表示されていました。フォールバック用 `_EmissionColor` に `エミッションを使用` が有効なマテリアルのティント×強度が入り、VRChat のフォールバックシェーダーはエミッションマップがないとその色を表面全体に加算します。
- 対処 — フォールバック alias のエミッション色は常に黒になりました。MingToon シェーダー自体のエミッションは変わりません。

### NDMF 生成クローンのレコードが残り VRChat ビルドが塞がれ続けていた問題

- 症状 — NDMF を使うアバターを一度ビルドした後、以降の VRChat ビルドがすべて `Material recovery is incomplete` で失敗していました。
- 対処 — NDMF がビルド後に削除する `Packages/nadena.dev.ndmf/__Generated/` 配下のクローンマテリアルの復元レコードがジャーナルに残っていたのが原因です。マテリアル消失の判定を GUID マッピングではなく実ファイルの存在で行うようにし、該当レコードは次回の復元時に警告 1 行とともに整理されます。

### ルックプリセットがステンシル値を上書きしていた問題

- 症状 — lilToon 変換は元のステンシル値（Ref・Comp・Pass など）をそのまま引き継ぎますが、変換直後に適用されるファクトリールックプリセットがシェーダー既定値（Ref 0・Always・Keep）を保持していたため、目のオーバーレイや非表示マスク用のステンシルが 0 に戻っていました。ルックプリセットの再適用でも同じでした。
- 対処 — ステンシルの 2 ユニット（表面・アウトライン、14 項目）は、今後プリセットにキャプチャも適用もされません。
