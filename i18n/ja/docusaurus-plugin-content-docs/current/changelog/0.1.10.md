*オープンベータ · 2026年9月14日*

## 一行まとめ {#v0110}

顔プロキシに平面が加わり、テクスチャとレイヤーの編集がカードにまとまりました。

:::warning[アップデート前の確認]
- バックアップ: プロジェクト全体をバックアップしてからインストールしてください。新規プロジェクトにインストールしても構いません。
- 再ベイク: すでにベイクしたマテリアルは、編集用に復元してから焼き直してください。
- 再アップロード: VRChatアバターは再アップロードしないと反映されません。
- ルックが変わる項目: アウトラインの線の明るさと色、顔プロキシ、エミッション合成。
- 初回のアップデート時に、プロジェクト全体のテクスチャが一度再インポートされる場合があります。
:::

## 新機能

- **平面** — 顔プロキシの形状に追加されました。顔シェーディングを正面基準で平らに合わせます。
- **全体の彩度** · **全体のエミッション強度** — マスター調整でキャラクター全体を一度に調節します。
- **リムシェードカラー** — リムシェードの色を個別に指定します。ブレンドが0なら従来の影色を使います。
- **ベースマップに追従** · **アルファに追従** — アウトラインが表面の色と透明度をそれぞれ追従します。
- **インポート一括設定** — テクスチャの種類ごとに最大解像度と圧縮品質を選んで適用します。
- **マスク詳細設定** — コントラスト・ブラー・入力レベルと、色相・彩度・明度・ガンマを調節します。
- **マスクチャンネル** — `R / G / B / A / 輝度`をボタンで選びます。マットキャップのマスクには`RGB`もあります。
- テクスチャ・ノーマル・マットキャップの各レイヤーに、追加・移動・削除のボタンが付きました。
- レイヤーを削除せずに無効化できます。再度有効にすると、保存された設定をそのまま使います。
- テクスチャ一覧をセクション別・容量順・解像度順・名前順で並べ替えます。
- ベイク方式を`FastUpload`と`Legacy GPU 精密最適化`から選びます。
- インスペクターのカード・余白・セクションヘッダーを整理し、幅が狭くても読めるようにしました。

## 変わった既定値とルックの変化

- **受信面プッシュバック** が、デプスシャドウ（旧名: 2Dシャドウ）タブから顔シェーディングへ移動しました。
- デプスシャドウが有効で、プッシュバックが0より大きい場合、そのマテリアルは投影シャドウを受けません。
- プッシュバックを0に戻すか、デプスシャドウを無効にすると、投影シャドウが再び適用されます。
- アウトラインから複雑なライティング計算を取り除きました。既存のマテリアルは線の明るさと色を確認してください。
- 従来の球・円柱・カプセルのプロキシは、実験的な形状として区別されました。平面を推奨します。
- エミッション合成がlilToon基準になりました。従来のHue・Color・Overlayの値はAddとして扱われます。
- ファクトリープリセット6つを更新しました。再適用すると値が上書きされます。
  **ベーシックトゥーン High/Low** · **ハードトゥーン High/Low** · **ソフトトゥーン High/Low** です。

## 修正された問題

- 色調プリセットがシャドウカラーマップのUV設定まで上書きしていた問題が修正されました。
- カメラから離れるとマットキャップのマスクが外れ、テクスチャのバインドがずれていた問題が修正されました。
- マスクボックス下の行のラベルが2〜3文字で切れていた問題が修正されました。
- インスペクターの言語を変更しても、上への移動ボタンが以前の言語のまま残っていた問題が修正されました。

## 既知の制限

- 深度効果は、ワールド・カメラ・ミラーが与える深度情報によって変わります。
- この配布はBRPコアです。URPアドオンとMing Light Controllerは含まれていません。
- 初回のベイクと初回のコンパイルは、キャッシュが空のため時間がかかります。
