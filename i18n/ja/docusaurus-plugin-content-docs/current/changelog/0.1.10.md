*オープンベータ · 2026年9月14日*

## 0.1.10 {#v0110}

:::warning[インストール・アップデート前に必ずお読みください]

- **全テクスチャの再インポートについて：** 0.1.10への初回アップデート時は、インポート検証方式の変更により、**プロジェクト内のすべてのテクスチャが一度再インポートされる場合があります。** 毎回のアップデートで繰り返す仕組みではありません。完了後も繰り返し発生する場合はご報告ください。
- **制作中のプロジェクトを保護してください：** 既存の作業用プロジェクトでは、**プロジェクト全体をバックアップしてからインストール**するか、**新しいUnityプロジェクトにインストールして使用**することをおすすめします。
- **オープンベータ期間中の変更について：** アップデートにより、**見た目（色味・ライティングなど）やプリセットが変更**されたり、**機能が追加・削除**されたりする場合があります。更新前後で表現が変わる可能性があるため、既存の制作物に適用する前にご確認ください。

:::

**シェーダーとベイク処理、インスペクター、テクスチャ・レイヤー編集をまとめて改善しました。** 顔プロキシに平面モードを追加し、顔の影調整と lilToon 変換・ビルド処理を整理しました。ファクトリープリセットも更新しています。

今回の配布は **BRP コア**です。Unity 2021.3 / 2022.3 LTS に対応し、URP アドオンと Ming Light Controller は含まれません。従来のオープンベータ利用条件は変わりません。

### シェーダーとベイクの最適化

- **繰り返し計算を削減** — ベイク時に再利用できるライティング・ノーマル・タンジェント計算を共有し、使われない静的計算とシェーダー経路を減らしました。
- **アウトラインを軽量化** — 複雑なアウトライン照明と不要な分岐を整理しました。更新後は既存マテリアルの線の明るさと色を確認してください。
- **ベイク方式を分離** — ビルド・アップロードと手動ベイクで `FastUpload` または `Legacy GPU 精密最適化` をそれぞれ選べます。エディタープレビューとアップロード結果を比べるときは、両方で同じ方式を選んでください。
- **生成結果の再利用を改善** — マテリアル・テクスチャ・メッシュ・アニメーションの入力が同じ場合は生成結果を再利用し、入力が異なるときに古い結果を誤って使うことを減らしました。
- **復元の信頼性を向上** — ビルドやベイクの後に編集用マテリアル、キーワード、メッシュを戻す処理と、キャンセル・失敗時の復旧を強化しました。

改善の幅はマテリアル構成、描画条件、キャッシュ状態によって変わります。この変更をすべてのアバターに適用できる固定の FPS 向上率や GPU 改善率として示すものではありません。

### インスペクターとプリセット

- **画面構成を統一** — セクション見出し、上部の移動領域、カード、ボタン、余白を整理し、狭いインスペクターでの読みやすさを改善しました。
- **負荷表示を整理** — 上部とスティッキー領域の負荷表示を統一し、ゲージ・パーセント・詳細をより簡潔にしました。これは選択した機能の推定コストであり、実際の GPU 使用率ではありません。
- **プリセットと色調を整理** — すばやい適用と保存・管理領域の配置を統一しました。色調プリセットがシャドウカラーマップの UV 設定まで上書きしていた問題も修正しました。
- **全体調整** — `全体の彩度` と `全体のエミッション強度` で関連する表現をまとめて調整できます。
- **リムシェード色** — リムシェードの色を個別に調整できます。別色の混合が 0 のときは従来のシャドウ色を使います。
- **ファクトリープリセットを更新** — Basic・Hard・Soft Toon の Common・Face・Skin 系プリセットを更新し、High・Low の表示を整理しました。
- **ラベルとツールチップ** — 韓国語・英語・日本語の表示、長いラベル、重複した説明を整理しました。

### テクスチャとマスクのカード

- **テクスチャ一覧を整理** — セクションごとにまとめて表示したり、GPU 容量・解像度・名前の順で並べ替えたりできます。詳細を開くボタンはカードの右端に配置しました。
- **インポート設定を一括適用** — メイン・ノーマル・AO・MatCap・マスク・アルファマスクの種類ごとに、最大解像度、PC 形式、圧縮品質を選んで適用できます。元テクスチャのインポート設定を変更するため、同じテクスチャを使う他のマテリアルにも反映されます。
- **すばやい大きなプレビュー** — テクスチャの上に約 0.3 秒ポインターを置くと大きなプレビューが現れます。ポインターが外れると閉じます。
- **テクスチャ探索を改善** — フォルダー内にテクスチャがあるかを表示し、テクスチャを含むフォルダーを見つけやすい順に並べます。
- **X・Y 連動** — タイリング・オフセットに X/Y 接続ボタンを追加し、配置を操作するドラッグ領域を広げました。
- **カード内で編集** — プレビュー、色・合成、UV、チャンネル、補正項目をカード内にまとめ、重複表示を減らしました。
- **マスクカードを統一** — マスクのプレビュー・強度・UV・反転・チャンネル・詳細設定を一か所で調整できます。
- **マスク補正** — 対応するスロットでコントラスト・ブラー・入力レベルと、色相・彩度・明度・ガンマを調整できます。入力レベルはバーのハンドルと数値で調整します。
- **チャンネル選択** — `R / G / B / A / 輝度` をボタンで選び、MatCap マスクでは `RGB` も選べます。
- **カードの元に戻す** — カード見出しから、接続されているテクスチャ・色・合成設定をまとめて元に戻せます。
- **AO カードの整理** — テクスチャカードで `AO（Occlusion）` と強度を編集し、カードの詳細設定でコントラスト・ブラー・入力レベルを調整できます。結果は元のマップとマテリアル設定によって変わります。

### レイヤー編集

- **追加・移動・削除** — テクスチャ・ノーマル・MatCap レイヤーに追加ボタンと個別の移動・削除ボタンを用意しました。
- **値を保ったままオフ** — レイヤーを削除せずにオフ・オンできます。再びオンにすると保存されていたテクスチャ・色・合成設定を使います。
- **アニメーション連携** — レイヤーを移動・削除する前に接続されたアニメーションを確認し、見つかったカーブも一緒に処理します。マテリアルとカーブの変更は Undo でまとめて戻せます。接続を確認できない場合やレイヤー数自体をアニメーションで変える場合は案内を確認してください。
- **色だけのレイヤー** — テクスチャはなくても色とマスクで表現するレイヤーを変換経路で扱えるようにしました。

### 顔プロキシと影

- **平面プロキシを追加** — 顔プロキシの既定形状として `Plane` を追加しました。顔領域のシェーディングを正面基準の平面に揃えるときに使います。
- **実験的な形状を区別** — 従来の球・円柱・カプセルは実験的な形状として残しています。
- **関連設定を整理** — プロキシ形状、ノーマル強度、ノーマルマップの影響などを近くに配置しました。
- **受信面プッシュバックを移動** — 2D シャドウにあった `Receiver Depth Pushback` を Face Shading へ移しました。2D シャドウがオンのとき、記録した深度と受信面を一緒に後ろへ押し、顔自体による深度干渉を減らします。
- **投影シャドウの動作を明記** — 2D シャドウがオンでプッシュバックが正のとき、そのマテリアルの投影シャドウ受信をオフにします。2D シャドウをオフにするかプッシュバックを 0 に戻すと、元の投影シャドウ設定が再び適用されます。
- **実験的な深度調整** — 深度記録除外と受信面オフセットを実験機能として区別しました。通常の投影シャドウやワールドのポストプロセスにも影響する場合があるため、必要なときだけ確認して使ってください。

### アウトラインの色とアルファ

- **ベースマップに追従** — ベースマップとテクスチャレイヤーを合成した色をアウトラインに使えます。
- **アルファに追従** — 色への追従と表面アルファへの追従を別々に選択できます。アウトラインの色と透明度を個別に調整できます。

### lilToon 変換

- **オフになっている機能の数値を保持** — バックライト・リム・グリッター・アウトライン・反射・トゥーンスペキュラー・MatCap・エミッションで対応している数値をより広く移し、オン・オフの状態は区別して扱います。
- **エミッション合成** — Normal・Add・Screen・Multiply の4つの合成方式と既定値を lilToon に合わせました。既存の Hue・Color・Overlay の値は Add として処理します。
- **反射・リム・影を改善** — 反射モジュールの有効化、影の境界色、リムシェード色、フレネルリムの範囲、MatCap マスクと UV の処理を改善しました。
- **色だけの入力** — テクスチャがなく色だけで表現するサーフェス・エミッション・MatCap 入力も変換できます。
- **不足と損失の案内** — アニメーションからのみ参照されるマテリアルや、正確な対応先がない設定を変換レポートで確認できます。変換後はレポートと実際の見た目を確認してください。

### Depth Light と WARUDO

- **Depth Light 管理** — MingToon が所有する Depth Light の生成・再利用・削除と、ビルド中の一時処理を整理しました。
- **WARUDO UMod ビルド** — 書き出すプレハブの範囲を基準に最適化し、生成シェーダーとテクスチャをバンドルへ接続してから、作成したマテリアルを復元します。
- **不完全な結果を防止** — 生成物の登録やマテリアルの復元に失敗した場合はビルドエラーとして知らせます。

深度エフェクトはワールド・カメラ・ミラーが提供する深度情報によって変わります。この変更ですべてのワールドのポストプロセスやブルームの動作が保証されるわけではありません。

### 更新後に確認すること

1. 更新前にプロジェクトをバックアップしてください。VCC のインストール経路は VCC から、DLL のインストール経路は MingToon の更新ウィンドウから更新します。
2. すでにベイクしたマテリアルは、変更を反映するために **編集用マテリアルへ復元してから再度ベイク**する必要があります。VRChat にアップロード済みのアバターも再アップロードしてください。
3. ファクトリープリセットを再適用すると、選択した範囲の値が上書きされます。手動調整したマテリアルには必要なプリセットだけを適用してください。
4. ライティング・アウトライン・顔プロキシ・エミッション合成を使うマテリアルは、更新後の見た目を確認してください。プッシュバックを使う場合は投影シャドウ受信の条件も確認してください。
5. キャッシュと生成方式が変わったため、最初のベイクやコンパイルに時間がかかる場合があります。その後の所要時間もマテリアルとキャッシュ状態によって変わります。
