*クローズドベータ・2026-08-19*

## アップグレード時の確認事項

:::caution[ベイクキャッシュが再生成され、VRChat アバターは再アップロードが必要です]
生成シェーダーのキャッシュバージョンが上がり、既存のベイク成果物が無効になります。次のビルドで自動的に焼き直されるため手作業は不要ですが、その一回だけ時間がかかります。**今回のマットキャップ最適化は焼き直して初めて適用されます** — 以前のキャッシュは正常に見えますが、マットキャップを使うマテリアルでははるかにコストが高いままです。シェーダーはアバターのアセットバンドルに同梱されるため、**すでにアップロード済みのアバターは再アップロードするまで今回の修正が反映されません。**
:::

:::caution[顔の陰影と影の形が変わるマテリアルがあります]
どちらも従来の挙動がバグだったケースです。光が顔の中央を通るときに陰影が硬く飛んでいたのが滑らかに切り替わり、頂点ペイントで顔領域を指定した統合マテリアルで体全体に誤って適用されていた顔の深度オフセットがなくなります。
:::

:::caution[ライティング関連の既定値が変わりました — 新規作成するマテリアルとファクトリープリセットにのみ適用されます]
`ライトカラーの反映`・`間接光の強さ`・`追加ライトのトゥーン混合` を含むライティング項目9つの既定値を実運用のセットアップに合わせ、`透過光を使用` は既定でオフになりました。**すでに作成済みのマテリアルの値には手を加えません。** ファクトリープリセットを再適用すると新しい既定値になります。
:::

:::caution[Face SDF Studio と Mask Maker は今回の版から同梱されません]
2つのツールは別製品として分離されました。個別に購入してプロジェクトに入れれば、インスペクターの該当箇所で以前と同じように連携します。無い場合はそのボタンが案内に変わるだけで、他の機能には影響しません。
:::

## 新機能

- **`発光レイヤー2を使用`** — 2枚目の発光マップが追加され、部位ごとに異なる色で発光させられます。2つのレイヤーは加算されるため、各部位の色はそのまま残ります。既定はオフです。 → [ドキュメント](/guides/detail-maps)
- **`マップのアルファを強度マスクに`** — 発光マップのアルファチャンネルをピクセル単位の強度マスクとして使います。アルファは色と一緒にすでに読み込まれているため、**テクスチャの読み取りは増えません。** 2つの発光レイヤーのどちらにもあります。 → [ドキュメント](/guides/detail-maps)
- **マテリアル設定のコピー＆ペースト** — インスペクター上部のバーにコピー・ペーストのボタンが追加されました。ペーストは `すべて`・`値のみ (テクスチャを除く)`・`テクスチャのみ`・`キーワードのみ`・`レンダーキューのみ` の5種類に分かれており、テクスチャはマテリアルごとに残したまま設定だけを移せます。元に戻す (Ctrl+Z) が効きます。
- **`クイック設定` カード** — マテリアル全体にすぐ効く項目をインスペクター最上部の一か所にまとめました。`統合シャドウカラー` を含みます。

## 変更

- **PBR 関連の3つのセクションが独立した `PBR` グループに分かれました。** `PBRサーフェス`・`トゥーンスペキュラー`・`領域マスク` がキャラクターグループに混ざっていたものを、独立したグループに分離しました。位置は `キャラクター表現` の次、`深度エフェクト` の前です。値と既定値はそのままです。
- **`パターン方式` を `Overlay` にしたまま `パターン適用対象` を `Depth2D` に変えると案内が出ます。** `Overlay` は仕上がった陰影の上に線を重ねる方式のためフォームシャドウでのみ動作し、2D では `Recolor` に下がります。以前からの挙動ですが、何の表示もありませんでした。
- **インスペクターのセクション順と名称を整理しました。** ライティング項目は `基本設定` 内の `シャドウ` セクションに移り `フォームシャドウ`→`キャストシャドウ`→`シャドウカラー`→`シャドウパターン` の順になり、リム系は `リムライト`→`リムシェード`→`フロントライト`→`バックライト`→`シャドウバウンスライト`、深度系は `深度エフェクトマスター`→`2Dリムライト`→`2D透過光`→`2Dシャドウ`→`インナーアウトライン` の順です。値と既定値はそのままです。
- **`マテリアル負荷` メーターがベイク後の値を既定で表示します。** 実際にアップロードされるのはベイクされたシェーダーなので、その値が代表の数字になるのが正しいためです。編集中のマテリアルの値は詳細項目で確認できます。

## 改善

- **マットキャップを使うマテリアルのアップロード最適化が、はるかによく効くようになりました。** マットキャップレイヤー2〜5が最適化で定数に畳み込まれていませんでした。マットキャップを多く使うマテリアルほど効果が大きくなります。マットキャップを使わないマテリアルに変化はありません。
- **同じマテリアルが Built-in と URP で異なるコストになっていたのが揃いました。** 上記の最適化は URP では元から効いており、Built-in でのみ抜けていました。これで2つのバックエンドが同じコストになります。
- **アップロード最適化が値を1つでも取りこぼすと、表面化するようになりました。** 以前の検査は「1つでも適用されていれば通過」だったため、値を100個取りこぼしても静かなままでした。上記の欠陥が長く見つからなかった理由です。

## 修正

- **光が顔の中央を通るときに陰影が硬く飛んでいた問題** — SDF 顔の persistent チャンネルが threshold チャンネルとは異なる方式で切り替わっていました。
- **頂点ペイントで顔を指定した統合マテリアルで、顔の深度オフセットが体全体に適用されていた問題** — 影を落とすパスが顔領域の指定を読んでいませんでした。
- **同じセッションでベイクしたあと、生成物を削除して再ベイクすると失敗していた問題** — 削除したパスが占有されたままと判定され、名前を作成できませんでした。
- **2つ目の発光スロットの `チャンネルソース`・`ソース色を反転` の行が、インスペクターにまったく無かった問題** — シェーダーはその値を読んでいるのに、調整する場所がありませんでした。
- **プリセット適用範囲のトグル2つが韓国語・日本語で見切れていた問題** — `シャドウカラーも上書き` と `フレネル設定も上書き` を2行に分けました。
- **インスペクターの幅を狭めると中ほどのスライダーと数値欄が見切れていた問題** — 狭い幅で名前の欄が値の欄を押し出していました。
- **元に戻すボタンが項目のボックスの外に離れて見え、右の余白が広すぎた問題** — ボタンがボックスと同じ余白を使うようにしました。
- **Face SDF Studio を先に開くとツール全体が韓国語で固定されていた問題** — 言語を選んだことがない場合に韓国語を強制的に保存していました。今はシステム言語に従います。
