*クローズドベータ · 2026-08-22*

0.1.7は0.1.6以降の累積アップデートです。顔のオーサリングフロー、シャドウとSSAO、VRChatランタイム制御、変換・ベイクの安定性、InspectorとMingToon Managerをまとめて整理しました。

## アップグレード時の確認事項

:::caution[生成シェーダーとメッシュベイクキャッシュが再生成されます]
Generatorとベイク入力の契約が変更されました。次回ビルド時に自動再生成されますが、最初のビルドは通常より時間がかかる場合があります。シェーダーはアバターAssetBundleに含まれるため、**アップロード済みのVRChatアバターは再アップロードしないと0.1.7の修正と最適化が反映されません。**
:::

:::caution[以前に顔ノーマルをUV7へベイクした場合はLiveへ戻してください]
0.1.7から、顔プロキシノーマルのリアルタイム合成は編集中にシェーダーでリアルタイム計算し、VRChatアップロード用コピーにのみ自動ベイクします。MingToon Managerで一度`顔ノーマルをリアルタイムへ戻す`を実行してください。古いtangent-normal UV7を持つマテリアルでFace SDFのUV7を選んでいる場合は、座標の誤読を防ぐため`顔マップ座標`もBase UVへ戻します。この操作はUndoできます。
:::

:::caution[シャドウとSSAOの見た目が変わる場合があります]

- `2Dシャドウ消失距離`のデフォルトは12mです。9mから薄くなり、12mで消えます。以前のように距離制限なしで使う場合は0にしてください。
- `投影フェザー半径`の実範囲は0～48pxです。48を超えて保存されていた値は、スライダーを再操作したとき48に制限されます。
- SSAO半径のデフォルトは0.005、上限は0.01に変更されました。エッジと自己面の跡をより柔らかく処理します。
- シャドウ境界のキャストバンド位置と合成順序が変わりました。境界を使っていたマテリアルでは、コア寄りにより明瞭に見える場合があります。
:::

:::caution[削除された顔キャスト項目があります]
`顔均一キャスト`と`顔キャスト安定化`は実際の効果が成立しなかったため削除しました。これらの値を使っていたマテリアルは、デフォルトのキャスト受信動作へ戻ります。
:::

:::caution[VRChat Expressionsを再インストールしてください]
0.1.7では、既定の**フルプロファイル：合計28個、同期21個・77ビット + ローカル7個・0ビット**と、**軽量プロファイル：合計12個、同期10個・31ビット + ローカル2個・0ビット**を選べます。MingToon Managerの `フル調整メニューを使用` を選び、既存インストールを更新してからGesture Managerで確認してください。
:::

:::caution[ライティングの新しいデフォルト値は新規マテリアルとファクトリープリセットにのみ適用されます]
`シーンライトカラー影響`・`間接光補正`・`追加ライトPBR / トゥーンブレンド`など9個のデフォルト値を実用設定に合わせ、`2D透過光`はデフォルトOFFになりました。既存マテリアルに保存された値は変わりません。ファクトリープリセットを再適用するか、デフォルト値へリセットしたときだけ新しい値が入ります。
:::

:::caution[Face SDF StudioとMask Makerは別製品です]
この2つのツールはMingToonパッケージには同梱されません。インストール済みならInspectorとMingToon Managerから連携し、未インストールなら導入案内だけを表示します。MingToonシェーダーと基本オーサリング機能はそのまま動作します。
:::

## 新機能

### 顔オーサリングと深度

- **リアルタイム顔プロキシノーマル** — プロキシ中心・半径・形状・高さ・プロキシノーマル強度を変えると、SceneViewとGameViewへ即時反映されます。半径が曲率を直接変更し、小さい値は丸く、大きい値は緩やかになります。SceneViewパネルではノーマル線・プロキシボリュームの表示、線の長さ・密度、Fitを調整できます。アップロード時はアップロード用コピーだけを自動ベイクし、シーン原本には触れません。
- **球・円柱・カプセル顔プロキシ** — ノーマル方向と顔領域を同じプロキシに合わせられます。カプセルの高さと軸もシーンツールで編集できます。
- **深度のない画面での顔投影シャドウフォールバック** — 明示的にオプトインしたマテリアルは、深度テクスチャがなくても顔シャドウテクスチャ経路を維持できます。

### シャドウ・SSAO・リム

- **2Dリムサンプル品質1 / 2 / 4タップ** — 品質とコストをマテリアル単位、またはVRC品質ティアで調整します。
- **2Dシャドウ消失距離** — デフォルト12mで、遠距離ではタップ数も同時に減ります。画面端の誤検出と、近接する別メッシュ間の途切れも軽減しました。
- **深度エフェクトのランタイム切り替えオプトイン** — VRC FXから深度エフェクト全体を実際に無効化し、関連サンプルコストをスキップします。
- **Shadow Projectionランタイム切り替えオプトイン** — VRC品質メニューから投影シャドウだけを個別にON/OFFできます。
- **エッジリムグループのマスター・カラー・強度・上限** — 2Dリム、フレネルリム、バックライトなどシルエット系をまとめて調整し、別のHDRピーク上限を設定します。
- **内部反射・SSAOの`シャドウ内表示`** — 既存シャドウの中で各エフェクトをどれだけ残すか個別に指定します。WARUDO Built-inのポイント・スポット追加ライト反射には、このゲートは適用されません。
- **グリッターMatCap制限** — MatCapテクスチャで視線方向のグリッター領域を絞り込みます。

### ディテールと出力

- **エミッションレイヤー2** — 異なるマップ・カラー・強度を加算し、部位ごとの発光を作れます。
- **エミッションマップのアルファ強度マスク** — 2つのエミッションレイヤーとも、マップのアルファをピクセル単位の強度として使います。追加のテクスチャサンプルはありません。
- **エミッション時間アニメーション** — レイヤーごとにスクロール、点滅、暗いほど発光を設定します。
- **MatCap 5スロット拡張** — スロット別の回転・円形マスク・発光寄与と、共有MatCapノーマルマップ強度に対応します。
- **レンダー無効化** — 特定マテリアルの全パスを外し、ドローコール自体をなくします。Materialのパス状態であるため、ランタイム切り替えはRendererまたはGameObjectで行います。

### InspectorとMingToon Manager

- **マテリアル設定のコピー・貼り付け** — `すべて`・`値のみ`・`テクスチャのみ`・`キーワードのみ`・`レンダーキューのみ`の5方式とUndoに対応します。
- **固定ツールバーとセクションナビゲーション** — スクロールしても上部ツールが残り、カラーバーからグループ位置へ直接移動できます。
- **すべて折りたたむ / すべて展開 / 変更値のみ** — `変更値のみ`はシェーダーのデフォルトと異なる行だけを残し、関連セクションを自動展開します。
- **クイック設定とマテリアル負荷サマリー** — よく使う値と、ベイク後に予想されるコストをInspector上部で確認できます。
- **マテリアル役割指定フローの整理** — MingToon Managerのステップ1でFace / Skin / CommonをRendererとスロット別に指定し、変換ルックの適用先をすぐ確認できます。
- **MingToon Managerの4段階フロー** — `1 · 変換` → `2 · 設定` → `3 · 詳細設定` → `4 · 出荷`の順に整理し、現在の段階で必要な作業と保留理由を表示します。
- **Faceマテリアルのみ選択** — 顔プロキシ編集や顔の一括調整前に、Faceマテリアルだけを選択できます。
- **アップロード時テクスチャ解像度上限** — ベース・ノーマル・マスクなどスロット種別ごとの最大解像度を決め、アップロード用コピーだけを縮小します。原本テクスチャは変更しません。

### 変換・VRChat

- **ピンク色のMissing Shaderマテリアル変換** — 保存済みプロパティを読み取り、NiloToon・lilToon・Standard系を復旧変換します。
- **レンダー状態の完全保持** — ステンシル、レンダーキュー、Cull、Cutout・Fade・Premultiplyなどの透明モードを変換結果へ引き継ぎます。
- **中断に強い変換復旧** — 変換中にエラー・スクリプトリロード・Editor終了が起きても、Renderer・Mesh・マテリアル・Prefab override・dirty状態をジャーナルから復旧します。自動復旧が8回失敗した場合は`Advanced`メニューから再試行するか、対象を確認して復旧ジャーナルだけを破棄できます。
- **VRC品質ティア Low / Mid / High** — Highはオーサリング値を維持し、Midはサンプル数を制限します。Lowはサンプル数をさらに下げ、深度エフェクトマスターと投影シャドウフェザーを無効にします。どちらのプロファイルも明示的なHigh / Mid / Lowボタンと、独立したShadow Projectionを維持します。
- **8色 × 4段階の圧縮Palette** — フルではWarm・Gold・Mint・Cyan・Blue・Violet・Rose・RedとNeutral・Soft・Medium・Fullを1つのIntに格納します。Highlight・Shadow・Final Outputは同じパレットを共有しながら、Tintの適用量とIntensityを個別に選べます。
- **8種類のPhoto Looks** — フルではNeutral、Dark World Rescue、Flat Studio、Unlit Reference、Warm Portrait、Cool Portrait、No Emission、No Backlightを切り替えます。自分のアバターの結果を同期し、World/Udon権限が必要な他アバターの一括操作は含みません。
- **VRCのフル / 軽量プロファイル選択** — フルは合計28個 / 同期21個・77ビット / ローカル7個・0ビット、軽量は合計12個 / 同期10個・31ビット / ローカル2個・0ビットです。同期内訳はフルがBool 13 + Int 2 + Float 6、軽量がBool 7 + Float 3です。軽量でもVirtual Light基本操作、High/Mid/Low、Shadow Projection、Resetを維持し、Palette・Photo Looks・Highlight/Shadow/Final Output操作は除外します。Resetは選択中のプロファイルのインストール時既定値へ戻します。
- **プロファイル切り替え時のクリーンアップ** — `フル調整メニューを使用` を変更して再インストールすると、現在のプロファイルにないMingToonパラメーター・FXレイヤー・生成メニューを削除します。
- **VRC Light Volumes拡張** — 間接光だけでなく、ボリュームスペキュラー、ポイントライトシャドウ、ノーマルバイアスと強度に対応します。アバターアップロードでは必要なバリアントを自動有効化し、ワールドビルドではシーンにLight Volumesがある場合だけ有効化します。
- **Expressionsルートへの直接配置** — フォルダー方式はRootの1枠を使い、フルは8操作、軽量は7操作です。Root方式ではフルがVirtual Light / Master Adjust / Reset All、軽量がVirtual Light / Quality / Reset Allを配置します。どちらも3枠が必要で、収まらない場合はフォルダー方式へ戻ります。

## 変更

- **Inspector情報構造の再編** — `ライティング`は基本設定へ、`シャドウ`は独立グループへ移動しました。PBRサーフェス・トゥーンスペキュラー・領域マスクは`PBR`グループになり、深度セクションは結果を基準にした名前へ整理しました。
- **シンプルモードの再定義** — 実際の初期設定に必要な項目だけを残し、高度な診断と内部技術情報は正式ビルドで非表示にしました。バリアントダンプ・レコード、Depth Debug Post Processも`MINGTOON_DEV`ビルドでのみ表示されます。
- **追加ライト上限の意味変更** — ベースカラーの乗算ではなく、HDRピークを直接制限します。`リム・追加光にも上限`がオンなら、同じ値で主光源と追加光源がすべての加算系エフェクトへ与える強度も制限します（1は強度1、3は強度3）。
- **シャドウ境界の再設計** — キャストバンドは明るい側から満ち、シャドウコア直前でピークになります。すべてのシャドウ・SSAOより上、加算光より前に最後に合成され、統合シャドウ内に浮いていた輪郭を除去しました。
- **SSAO合成方式の変更** — SSAOカラーは既存シャドウの増分ではなく、SSAO全体のカバレッジへ適用されます。フォームシャドウや逆光でもカラー・明るさ設定が見えるようになりました。
- **`全体エフェクト`・`深度エフェクトマスター`範囲の整理** — 深度マスターをOFFにするとSSAOも同時にOFFになります。
- **投影フェザー範囲0～48px** — 品質ティアが実際に使用できる上限とUI範囲を一致させました。
- **リム色純度コントロール** — バックライト、フロントライト、フレネルリム、影内部リフレクション、2Dリム、透過光のエッジ/内側を個別に0〜10（既定値1）で調整できます。ベースカラーと色・ティント（透過光はHSVG・厚さ別の彩度差を含む）を合成した後に適用します。
- **`顔均一キャスト`・`顔キャスト安定化`を削除** — 動作しなかったプロパティとプリセットシードを削除しました。

## 改善

- **MatCapアップロード最適化** — Built-inでMatCap 2～5スロットの固定値も定数へ畳み込みます。5スロット計測でフラグメント命令数が1,286から117へ減り、URPとのコスト差もほぼなくなりました。
- **ベイクキャッシュ整合性** — プロキシ形状・軸・高さ・領域マスク・UV所有権とアップロード専用経路をキャッシュキーへ含めました。別キャラクターや編集用ベイク出力を上書きしません。
- **アップロード復元の安定性** — Renderer・Materialの復元を項目別に分離し、変更したアセットだけを保存します。一つの項目の失敗が残りの復元を妨げたり、無関係な作業物を保存したりしません。
- **プリセット保持範囲** — Surface Mode、Cutout、レンダーキュー、顔プロキシなど、マテリアルの識別情報とキャラクター別配置を保持します。
- **Mask Maker連携** — ペイント中に適用領域を表示し、モード切り替えとUndoでも編集状態を失いません。
- **シェーダーウォームアップ・キーワード復旧** — 現在のバックエンドと実際のパスキーワードだけをウォームアップし、中断箇所から再開します。メンテナンス用詳細診断は開発ビルドにのみ残ります。

## 修正

- 顔SDFライティングが正面中央を通過するとき、左右選択が不自然に跳ねていた問題。
- 顔領域の頂点マスクがShadowCaster・Depthパスで無視され、身体まで顔オフセットを受けていた問題。
- テクスチャ顔領域マスクをアップロードベイクが顔全体として誤認していた問題。この場合は同じ結果を保つためLive経路を維持します。
- 一つのRendererにある複数のFaceスロットが異なるプロキシ・ランタイムフレームを使っているのに、先頭スロットの値ですべてをベイクしていた問題。不一致の場合は安全にLive経路を維持するようにしました。
- プロキシのシーンツールが親・Rendererのスケールを無視し、クリック位置がずれていた問題。
- AlphaToCoverage CutoutのForwardAddが追加ライトで明るい輪郭フリンジを作る可能性があった問題。
- VRChatミラーが別カメラの深度を読んだり、深度ライトが実際には有効にならなかったりする問題。
- 2Dシャドウが近接する別メッシュで途切れ、画面端で誤検出される問題。
- SSAOが傾いた面を自己遮蔽し、バイアス0で四角い跡と階段状の境界を作る問題。
- lilToon変換でPBR・エミッション・レイヤー・アウトライン・アルファマスクのトグルが有効にならない問題。
- Missing Shader変換と通常変換でSurface状態の一部が失われる問題。
- ルックプリセットがアルファモードと顔プロキシ値を戻してしまう問題。
- 共有Meshのベイク、UVチャンネル競合、タンジェントのないパーツの失敗、再ベイク・復元中断の問題。
- 頂点ペイント対象FBXをRead/Write再インポートした後、失敗時のロールバックで古いMesh参照を復元していた問題。
- 複数ルートの顔プロキシ編集、保留編集の整理、複数選択の状態キーが互いに競合していた問題。
- Inspectorの狭い幅での切れ・ちらつき、スティッキーツールバーのDPI座標、プリセットトグルの折り返し、欠落していた一括編集項目。
