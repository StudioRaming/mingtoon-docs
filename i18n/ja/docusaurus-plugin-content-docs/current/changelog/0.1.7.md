*オープンベータ · 2026年9月7日*

## 一行まとめ

デプスシャドウを作り直し、プロパティ名とアドオン構成を整理しました。

:::warning[アップデート前の確認]
- アップグレード手順: `Assets/StudioRaming/MingToon`フォルダーを削除して、新しくインポートしてください。
- 自作のファイルは先にフォルダーの外へ移してください。`MingLightController`は削除しないでください。
- 0.1.6のマテリアルに保存された値は引き継がれません。新しい既定値から調整し直してください。
- アニメーション: プロパティIDから`_Ming`接頭辞が外れました。カーブをつなぎ直してください。
- 接頭辞を一括で削除しないでください。`_MingVirtualLight*`のように残る名前もあります。
- 再ベイク: ベイク成果物が無効になります。焼き直して、アバターは再アップロードしてください。
- ルックが変わる項目: 顔の陰影、影の形、追加ライトの明るさ、デプスリムライト。
- 別売りとして分離されたものは4つです。
Face SDF Studio, Mask Maker, Ming Light Controller, URPバックエンド。
:::

## 新機能

- **発光レイヤー2を使用** — 2番目の発光マップで部位ごとに違う色を出します。既定は無効です。
- **マップのアルファを強度マスクに** — 発光マップのアルファを強度マスクとして使います。両方のレイヤーにあります。
- **クイック設定** — マテリアル全体にすぐ効く項目を、インスペクターの最上部にまとめました。
- **ツーパスモード** （旧名: 両面デュアルパス） — 両面表面の裏面を、表面より先に描きます。
- スカートの裾が折り返す箇所のギザギザが消えます。BRP専用のため、URPマテリアルではこの行が隠れます。
- **透明深度プリパス** — `透明 (3000)`でアウトラインが表面を突き抜けないようにします。
- **距離フェードを使用** · **角度フェードを使用** — 距離と角度で表面を消していきます。
- **グラデーションLUTを使用** — ベースマップの色を、チャンネルごとのランプで再マッピングします。
- **色相回転の方式** — `OKLab`は明度と鮮やかさを保ったまま、色相だけを回します。
- **パフォーマンス距離 (m)** · **パフォーマンス距離倍率** — 離れると重いモジュールをまるごと無効にします。
- **今すぐメッシュだけ再ベイク** — ルックの値はそのままに、有効なメッシュチャンネルだけを焼き直します。
- **バックライトの合成モード** · **フロントライトの合成モード** — 色の混ぜ方を7種類から選びます。併せて追加された`ブレンド不透明度`は存在感だけを弱めます。既定は`Add`、1です。
- **キャスト抑制オフセット** — キャストシャドウが消える地点を暗い側へ押します。既定は0.25です。
- インスペクター上部に、マテリアル設定のコピー・ペーストボタンが付きました。Undoが効きます。
- Managerが`概要`·`準備`·`外観・ベイク`·`アップロード`·`最適化`の5タブになりました。`最適化`の`分析`ボタンは、このアバターに合った提案を4つ表示します。
- セクションヘッダーの`?`ボタンが、インスペクターの言語に合ったドキュメントページを開きます。

## 変わった既定値とルックの変化

- デプスシャドウ（旧名: 2Dシャドウ）が、シルエット1枚で作り直されました。
- 手前の物体が受信面から浮いている分だけ影が遠くに落ち、前後が読めるようになります。
- タブの項目が10個に整理されました。
  **影の幅** · **影の強度** · **深度伸び** · **深度カーブ** · **深度フェード**。
  **ソフトネス** · **ブラー** · **デプスシャドウバイアス** · **受信面プッシュバック** · **逆光シルエット抑制**。
- **デプスシャドウバイアス** の尺度が10倍変わりました。これからは1が10cmです。
- **Depth Blur** と **Light Pushback** は廃止されました。代替の項目は[デプスシャドウ](/guides/depth-effects#2d-그림자)にまとめてあります。
- カメラが見下ろすほど **深度伸び** が短くなります。調節項目はなく、自動です。
- **追加ライトの明るさ上限** が新しく追加されました。既定値が0.35なので、ポイント・スポットが抑えられます。
- **追加光の最終明度上限** が、最終出力ピークの絶対上限になりました。保存された数値の意味が変わります。
- **SSAO 半径** は0.001〜0.03で、既定値は0.005です。説明は[SSAO](/guides/depth-effects#ssao-화면-공간-차폐)にあります。
- **接触減衰** はメートルではなく、**SSAO 半径** の倍数(0.25〜4、既定1)になりました。
- 消失距離は **共通フェード距離** （既定200）に統合されました。以前の数値をそのまま移さないでください。
- デプスリムライト（旧名: 2Dデプスリム）に表示名を統一しました。**シーン照明の影響** が追加され、既定値は1です。
- 照明項目9個の既定値が変わり、**透過光を使う** は既定で無効になりました。
- **サーフェスモード** の名前にレンダーキューが付きました。
  不透明 (2000) · カットアウト (2450) · 半透明 (2499) · 透明 (3000)です。
- 統合シャドウのマテリアルは、環境光のあるシーンで投影シャドウが以前より明るくなります。
- **投影フェザー半径** がワールド幅の単位になり、0〜20（既定3.5）になりました。マテリアルを開くと自動で換算されます。
- **キャスト境界フェザー品質** が3種類に減りました。
  Light3Tap · Standard5Tap · High9Tapです。
- ファクトリールックの **リムライト** の色純度の既定値が、10から1に下がりました。
- **フレネルリムを使用** が有効なマテリアルは、追加のライトがあるシーンで縁の色が変わります。
- フレネルリムをURPで二重に受けていた点も、BRPと同じに揃えました。
- 上位の **リム** グループ名が **スタイルライティング** に変わりました。
- MingToonのメニューは、最上位の`StudioRaming > MingToon`に移動しました。
- **顔プロキシデプス** と **VRChat Preview** のメニューが削除されました。代替手段はありません。

:::note[SSAO 半径の範囲はその後また広がりました]
上の0.001〜0.03は0.1.7当時の範囲です。
現在のバージョンの **SSAO 半径** の範囲は0.001〜0.05 mです。
説明は[深度ベースの効果](/guides/depth-effects#ssao-화면-공간-차폐)にあります。
:::

## 修正された問題

- 光が顔の中央を通るときに、顔の影がぷつりと途切れて跳ねる問題が修正されました。
- 顔だけにかけた深度オフセットが、体まで押し出していた問題が修正されました。
- 顔プロキシのノーマルが正面光で反転したり、反応が狭くなったりする問題が修正されました。シーンビューのプレビューが生成されない問題も併せて修正しました。
- `グラデーションLUTを使用`を有効にしても何も起きない問題が修正されました。
- ベイク成果物を削除して焼き直すと、エディターを再起動しなければならない問題が修正されました。
- 2番目の発光スロットで`チャンネルソース`·`ソース色を反転`を選べない問題が修正されました。
- lilToon変換で、発光チャンネルの設定が変換前の値のまま残る問題が修正されました。
- アルファ・領域マスクのマテリアルで、ビルド用シェーダーがコンパイルに失敗する問題が修正されました。
- そのせいで編集用シェーダーがアバターに載り、アップロードが約5分長くなっていた問題も解消されます。
- すでにアップロード済みのアバターは、再アップロードしないとこの修正が反映されません。
- エディターを起動するたびに`Startup recovery is incomplete`が繰り返される問題が修正されました。
- インスペクターの幅を狭めると、スライダーと数値欄が切れて値を入力できない問題が修正されました。
- プリセット適用範囲トグルの文字が切れて読めない問題が修正されました。Undoボタンが項目ボックスの外へ外れて見える問題も修正しました。
- Face SDF Studioを先に開くと、インスペクターまで韓国語に固定される問題が修正されました。
- `レンダー無効`が透明深度プリパスのパスを無効にできない問題が修正されました。
- プレハブでルックプリセットを作ると、プロジェクト全体の変更まで保存される問題が修正されました。
- `1スロット / タイル領域`ウィンドウで、一度適用した領域を削除できない問題が修正されました。

## 既知の制限

- `グラデーションLUTを使用`をすでに有効にしていたマテリアルは、ルックが変わります。以前の絵が必要なら無効にしてください。
- Fur・Gem・屈折の変換と、旧マテリアルカーブの自動書き換えは、今回の版にはありません。
- 深度ライトの動作はエディターでの実測が基準です。VRChatクライアントでは検証していません。
- 精度に関する2件の修正は、シェーダーコンパイルでのみ確認しました。実機でのレンダー検証は行っていません。
- `1スロット / タイル領域`ウィンドウは、マテリアルの現在の値を読み込みません。適用前に構成を合わせてください。
- `MingToonManager`のpublicプロパティ3つが削除されました。
  `UseModularAvatarVrcIntegration` · `VrcFullExpressionMenu` · `VrcMenuAtExpressionsRoot`です。
- この名前を参照するユーザースクリプトがあるとコンパイルエラーになります。その参照を削除してください。
