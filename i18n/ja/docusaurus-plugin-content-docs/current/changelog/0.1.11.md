*オープンベータ · 2026年9月19日*

## 一行まとめ {#v0111}

変換・ビルドキャッシュが安定し、Light Volumeと既定ルック・インスペクターを整理しました。

:::warning[업데이트 전 확인]
- バックアップ: インストール前にプロジェクト全体をバックアップしてください。
- 再ベイク: ベイク済みマテリアルは編集用に復元してから焼き直してください。
- 再アップロード: VRChatアバターは再アップロードが必要です。
- ルックの変化: エッジリム、ボリュームスペキュラー、照明基準値、デプス影の重なりを確認してください。
- lilToon変換マテリアルは、より多くの元データを保つため再変換を推奨します。
:::

## 新機能

- **エッジリム** — 輪郭を包むリムをエッジリムとして整理しました。プリセットタブの旧`backlight`フォルダーは`edgerim`になり、同じアセットGUIDを保ちます。
- **プレビュー版を含める** — アップデーターでプレビューチャンネルを選べます。オフにすると、インストール済みプレリリースより番号が低くても安定版の最新版を案内します。
- **顔・ヘアシェーディング** — 顔領域 → シェーディング → 影方式 → 基準 → 詳細の順に再配置し、不要な折りたたみを削除しました。
- **パフォーマンス負荷** — インスペクター上部でアップロード基準の負荷を見て、開くと詳細値を確認できます。
- テクスチャカードとレイヤーで追加・有効化・移動・削除をまとめました。種類別の**最大解像度**・**圧縮品質**も一括適用できます。
- **プリセットの保存と管理** — 適用・保存ボタンをまとめ、最後に適用したプリセットを記憶します。

## 変わった既定値とルック

- ファクトリールックは**エッジリム**オフで始まります。タブプリセットから再度オンにできます。
- **ボリュームスペキュラー**の既定値がFullからOffになり、金属のようなLight Volumeハイライトが減ります。
- 照明基準値を再調整しました。**環境色の反映**1、**最終最小明るさ**0.2、**エッジリム最大倍率**0、**エッジリム最小倍率**0.5です。
- **暗さの反映**0.8、**法線バイアス**0.01、**画面空間の影の重なり深度**0.5です。シーン照明の影響行はすべて1です。
- BRPアウトラインはLight Volumeの明るさを頂点で1回だけ読みます。ピクセルごとの追加サンプルはありません。

## 修正された問題

- テクスチャのインポート時にシーン全体のマスク計画が動いていた問題を修正しました。選択した入力だけを準備します。
- マスク入力レシートは手動ベイクとアップロード前に1回だけ準備し、完了済みレシートを繰り返し検証しなくなりました。
- ビルド専用の値変更で毎回新しいシェーダープロファイルが作られていた問題を修正し、成功したビルド後は生成プロファイルとソースキャッシュを再利用します。
- lilToon変換の順序を`変換 → ルックプリセット → 色調プリセット`に固定しました。元の反射・バックライト・顔データは保ち、エッジリムはルックプリセットが所有します。
- 色調プリセットがシャドウカラーマップのUVとベースアルファまで上書きしていた問題を修正しました。
- コンバーターと色調プリセットが**画面空間の影の重なり深度**を0に戻していた問題を修正しました。
- 古いDLLインストールレシートをインストーラーの検証済み一覧から再構築し、以後の更新が可能になりました。bootstrap DLLは変更しません。
- VRC Light Volumes 3ワールドが公開する旧v2バッファーを読みます。v3ネイティブの影・クラスタリング・ライト別シェーディングは未使用です。

## 既知の制限

- v2・v3ワールドのVRC Light Volumeキャスト影は、0.1.10とまだ見え方が異なります。
- v3バッファー互換は旧間接光・ポイントデータのみです。v3専用機能は読みません。
- 初回のシェーダーコンパイルと初回アップロードは、キャッシュが空のため長くかかる場合があります。
