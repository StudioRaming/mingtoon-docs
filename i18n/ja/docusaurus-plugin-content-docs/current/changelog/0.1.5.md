*クローズドベータ・2026-08-07*

## アップグレード時の確認事項

:::caution[新規マテリアルの `Base HSVG` 色相の既定値が 0.02 から 0 になりました]
0.1.4 までに作成したマテリアルは保存された 0.02 をそのまま保持します。未編集のベースマップが約7度回って見えていた場合は、色相を 0 に戻すかプロパティ右クリックの既定値リセットを使ってください。
:::

:::caution[ファクトリールックプリセットが差し替わりました]
`SoftCartoon` が外れ、`Soft Toon`・`Hard Toon`・`Rim Shadow` の3種と、それぞれの `- Low` 軽量版になります。すでに適用済みのマテリアルの値はそのまま残り、選べる一覧だけが変わります。
:::

:::caution[lilToon 変換のメッシュアドレス規則が変わりました]
アップデート後の最初の変換ではメッシュを一度焼き直します。それ以降は同じアバターをシーンに何度出し直しても、すでに焼いたメッシュをそのまま使います。→ [ドキュメント](/workflow/liltoon-conversion)
:::

## 新機能

- **`SSAO (画面空間遮蔽)`** — カメラ深度をピクセルごとに読み直し、首・脇・服のしわ・足が床に接する場所を暗くします。新しいライトでもポストプロセスでもないため、深度がない場所では静かに消えます。→ [ドキュメント](/guides/depth-effects)
- **`シャドウカラーマップ`** — 統合シャドウの1色を UV マップで分布させ、髪や肌など部位ごとに違う影色を出せます。白が基準値なので、オンにしただけでは結果は変わりません。→ [ドキュメント](/guides/light-and-shadow#통합-그림자--겹칠-때-새까매지는-문제)
- **スクリーントーンの `パターン基準` に `Screen` を追加** — 格子を画面に固定し、キャラクターがその下を通ります。印刷物に重ねたスクリーントーンやポップアートのような見え方で、画角やカメラ角度が変わっても歪んだりちらついたりしません。→ [ドキュメント](/guides/shadow-pattern)
- **グリッターの `形マップを使用`** — 粒子ひとつひとつのシルエットをテクスチャに置き換えます。Star・Bloom・Sparkle・Heart・Hex・Flower の6種を `Textures/Glitter/` に同梱しました。→ [ドキュメント](/guides/detail-maps#글리터)
- **グリッターの `回転ランダム`** — 粒子ごとに形の角度を変えます。ハートのように向きのある形をまっすぐ立てたいときは 0 に下げてください。
- **グリッターの `色も一緒に使用`** — マスク1枚のアルファを領域、RGB を粒子の色として同時に使います。テクスチャの取得回数は増えません。
- **`フレネルリムの視線影響`** — リムの位置を視線とライトのどちらが決めるかを選びます。0 ではカメラを回してもリムがその場に留まります。→ [ドキュメント](/guides/rim#림-라이트)
- **プレハブからルックプリセットを作成** — プロジェクトウィンドウでプレハブを右クリック →`Studio Raming / MingToon / Create Look Preset From Prefab`。シェーディングを終えたキャラクターから Common・Face・Skin 一式をまとめて取り出します。
- **VRChat プレビュー** — `Tools / Studio Raming / MingToon / VRChat Preview` でエディター表示をアップロード後の状態に切り替えます。カメラ深度なし／ありの2種類があり、有効な間はシーンビューにバナーが出ます。→ [ドキュメント](/platforms/vrchat#깊이-효과가-어디까지-보장되나)

## 変更

- **`シャドウパターン（スクリーントーン）` が独立したタブになりました。** Shadow Color 内のグループではなく、独自のマスタートグル・プリセット行・コピー＆ペーストを持ちます。→ [ドキュメント](/guides/shadow-pattern)
- **スクリーントーンをゲーム内で切り替えられます。** オーサリングシェーダーでモジュールがコンパイルから外れなくなったため、`シャドウパターンを使用` を通常の float アニメーションや VRChat の表現メニューで操作できます。
- **`リム・追加ライト最大倍率` の既定値が 2 から 3 になりました。** ファクトリールックプリセットも同じ値に揃えており、ライティング明度制限グループの他の値は変更ありません。→ [ドキュメント](/guides/light-and-shadow#라이팅--어두운-씬에서-검게-뭉칠-때)
- **`MingToon 2D投影シャドウをキャスト` に名称変更しました** — 0.1.4 までの `…キャスター` です。動作は同じです。
- **ルックプリセットはマテリアルを軽くはできても、黙って重くはしません。** `- Low` プリセットが重いモジュールを切る動作はそのままに、コストを上げる方向だけを止めました。

## 改善

- **モジュールを切り替えたときに青いまま止まる時間を短縮しました。** よく切り替えるルックモジュール8種（マットキャップ・フレネルリム・トゥーンスペキュラー・逆光・正面光・リムシェード・エミッション・オクルージョン）をあらかじめオーサリングシェーダーに含めたため、以降は切り替えても再コンパイルが起きません。ベイク結果のコストは変わりません。
- **ライティングのバリアントをインストール直後に一度でコンパイルします。** 作業中に実際に作るディレクショナル・ポイント・スポット・頂点ライトの組み合わせを先に焼くため、ライトを消したり新しく追加したりしても止まりません。`Tools / Studio Raming / MingToon / Warm up shader variants` で再実行できます。
- **lilToon 変換がすでに焼いたメッシュを再利用します。** Unity がコピーに付ける `(1)` という接尾辞ひとつのせいで同じアバターが毎回新しいアドレスを受け取り、すべて焼き直していました。→ [ドキュメント](/workflow/liltoon-conversion)
- **深度マスクをフラグメントあたり1回だけ読みます。** SSAO と 2D シャドウが同じテクスチャを同じ UV で2回読んでいました。
- **`影内部リフレクション` のマスクに専用キーワードを付けました。** マスクを使わないマテリアルで命令数とテクスチャ取得が減ります。→ [ドキュメント](/guides/rim#그림자-내부-반사)

## 修正

- **`MingToon 2D投影シャドウをキャスト` をオフにしたマテリアルが全体的に暗くなる問題** — Transparent の深度プリパスが同じスイッチに縛られており、さらにオフのマテリアルの深度モジュールが自分の背後を読んで、眼鏡全体にリムと内部線を敷いていました。→ [ドキュメント](/guides/light-and-shadow#역광에서-몸에-캐릭터-모양-그림자가-겹칠-때)
- **スクリーントーンの `パターン境界のぼかし` を上げると、影のない明るい面にもマークが載る問題** — ぼかし幅をマークの大きさで抑えました。ぼかしが 0 のときの結果は従来と同一です。→ [ドキュメント](/guides/shadow-pattern)
- **スクリーントーンの `Overlay` が `Recolor` と区別できない問題** — インクが影の領域を越えて広がっていました。今後は影の内側にのみ載ります。
- **トゥーンスペキュラーの合成モード `Screen`・`Overlay` で反射面が黒くなる問題** — `[HDR]` の色や 1 を超える強度が入ると式が負に反転していました。同じ欠陥のあった `Hue`・`Color` も併せて修正しました。→ [ドキュメント](/guides/detail-maps#툰-스페큘러)
- **2D シャドウを切ったマテリアルでも顔補助のオフセットが働いていた問題** — プリセットから値だけ引き継いだマテリアルが顔で投影影を失い、代わりに受けるものもありませんでした。→ [ドキュメント](/guides/depth-effects#2d-그림자)
- **インスペクター表記の訂正** — `MingToon 2D投影シャドウをキャスト` のツールチップが実際の動作と逆の説明をしていた点を修正し、統合シャドウをオフにすると各層に保存された色が戻ってルックが一度に変わりうるという警告を追加しました。マテリアルがカメラ深度から外れているときは、各深度モジュールの画面にもその旨を表示します。

## ドキュメント

- マニュアルに `ライティング明度制限` と `統合シャドウ` の節を3言語で追加しました。統合シャドウは既定でオンのため新規マテリアルでは個別の影色が隠れますが、その理由がどこにも書かれていませんでした。
- SSAO の記述3点をコードの実動作に合わせて訂正しました — オクルージョンマップと乗算するのではなくトゥーンバンドとスクリーントーンの後で暗い方を採用すること、ピクセルごとのノイズを撒かないこと、消失距離のフェードはその値の75%地点から始まることです。
- VRChat 互換性ドキュメントの顔座標系の記述を、実際に出荷される経路に合わせて修正しました。→ [ドキュメント](/platforms/vrchat#깊이-효과가-어디까지-보장되나)
