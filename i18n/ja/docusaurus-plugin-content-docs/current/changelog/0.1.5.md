*クローズドベータ · 2026年8月7日*

## 一行まとめ

接する箇所を暗くするSSAOと、部位ごとの影色が追加されました。

:::warning[アップデート前の確認]
- ルックが変わる項目: 新規マテリアルの`ベースマップ HSVG`の色相の既定値が、0.02から0に変わります。
- 0.1.4までに作ったマテリアルは、保存された0.02をそのまま保ちます。
- 色が約7度回って見えていた場合は、色相を0に戻してください。
- プリセット一覧: **SoftCartoon** の一式が外れ、3つのルックとそれぞれのLow軽量版が入ります。
- すでに適用済みのマテリアルの値はそのまま残り、選択できる一覧だけが変わります。
- 再変換: アップデート後の初回変換では、メッシュを一度焼き直します。それ以降は焼いたメッシュを使います。
:::

## 新機能

- **SSAO (画面空間遮蔽)** — 首・脇・服のしわ・足が床に接する箇所を暗くします。
- 新しいライトでもポストプロセスでもありません。深度がない場所では静かに消えます。 → [ドキュメント](/guides/depth-effects#ssao-화면-공간-차폐)
- **シャドウカラーマップ** — 統合シャドウの1色をUVマップで分布させ、部位ごとに違う色を出します。
- 白が基準値なので、有効にするだけでは結果は変わりません。 → [ドキュメント](/guides/light-and-shadow#그림자-컬러맵)
- **Screen** — スクリーントーンの`パターン基準`に追加されました。格子を画面に固定し、キャラクターがその下を通ります。
- 画角や角度を変えても、歪んだり明滅したりしません。 → [ドキュメント](/guides/shadow-pattern#패턴-기준)
- **形マップを使用** — グリッターの粒子1つひとつのシルエットをテクスチャに差し替えます。
- Star · Bloom · Sparkle · Heart · Hex · Flowerの6種類を`Textures/Glitter/`に同梱しました。
- **回転ランダム** — 粒子ごとに形を違う角度で立てます。向きのある形は0に下げてください。
- **色も一緒に使用** — マスクのアルファを領域、RGBを粒子の色として同時に使います。
- テクスチャをもう一度読むことはありません。
- **フレネルリムの視線影響** — リムの位置を、視点とライトのどちらが決めるかを選びます。
- 0ならカメラを回してもリムがその位置に留まります。 → [ドキュメント](/guides/rim#림이-카메라를-따라다니는-게-싫다면)
- プレハブを右クリックして、シェーディングが完了したキャラクターから **共通** · **顔** · **肌** のプリセット一式を抽出します。
- `VRChat Preview`で、エディターの画面をアップロード後の状態に切り替えて確認します。深度なしと深度ありの2種類です。

## 変わった既定値とルックの変化

- `シャドウパターン（スクリーントーン）`が独立したタブになりました。専用のマスタートグルとプリセット行を持ちます。
- `影パターンを使用`を、floatアニメーションとVRChatの表現メニューでトグルできます。
- `リム・追加光の最大倍率`の既定値が2から3に上がりました。ファクトリールックも同じ値です。
- 照明の明るさ制限グループの残りの値はそのままです。 → [ドキュメント](/guides/light-and-shadow#라이팅--어두운-씬에서-검게-뭉칠-때)
- `MingToon 2D投影シャドウキャスター`が`MingToon 2D投影シャドウを落とす`になりました。動作は同じです。
- ルックプリセットが性能設定をひそかに上げないようにしました。`- Low`がモジュールを無効にする動作はそのままです。

## 修正された問題

- `MingToon 2D投影シャドウを落とす`を無効にしたマテリアルが、まるごと暗くなる問題が修正されました。
- 無効にしたマテリアルの深度モジュールが自分の体の裏を読み、メガネ全体に線を敷いていました。
- スクリーントーンの`パターン境界のぼかし`を上げると、明るい面にもマークが打たれる問題が修正されました。
- スクリーントーンの`Overlay`が`Recolor`と区別できない問題が修正されました。
- インクが影の領域の外まで滲んでいました。これからは影の内側にだけ置かれます。
- トゥーンスペキュラーの`Screen`·`Overlay`で、反射面が黒く出る問題が修正されました。
- 同じ欠陥のあった`Hue`·`Color`も併せて修正しました。 → [ドキュメント](/guides/detail-maps#툰-스페큘러)
- デプスシャドウ（旧名: 2Dシャドウ）を無効にしたマテリアルでも、顔の補助プッシュバックが動作する問題。
- `MingToon 2D投影シャドウを落とす`のツールチップが、実際の動作と逆に説明していたのを修正しました。
- モジュールをトグルするときに、青色で止まっている時間が短くなりました。ルックモジュール8種をあらかじめ読み込んでおきます。
- ライティングのバリアントを、インストール直後に一度でコンパイルします。ライトを切り替えたり新しく追加したりしても止まりません。
- lilToon変換が、すでに焼いたメッシュを再利用するよう修正しました。 → [ドキュメント](/workflow/liltoon-conversion)

## 既知の制限

- 体感の差は環境によって異なります。
- 統合シャドウを無効にすると、各層に保存された色が戻り、ルックが一度に変わることがあります。
- SSAOの消失距離フェードは、その値の75%の地点から始まります。
- SSAOはオクルージョンマップと乗算せず、トゥーンバンド・スクリーントーンのあとに、より暗い側を取ります。
- SSAOはピクセルごとのノイズを撒きません。
