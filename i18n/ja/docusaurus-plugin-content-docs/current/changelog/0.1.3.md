*クローズドベータ · 2026年8月3日*

## 一行まとめ

薄い部位が光を含む透過光と、マスター調整が追加されました。

:::warning[アップデート前の確認]
- コンポーネント: MingToonのコンポーネントを手動で削除しないでください。キャッシュされたレンダラー一覧も一緒に消えます。
- 顔の指定: `Auto`は名前からの推測をしません。元のマテリアルの顔フラグだけを読みます。
- StandardやURP Litから変換すると、すべてのスロットが`Regular`のまま残ります。自分で`Face`に指定してください。
- ルックが変わる項目: `顔の境界`が負の値を受け付けません。従来の−0.3は0として読まれます。
- 顔に影が少し多くかかります。顔マテリアルでこの値を調整し直してください。
- 統合シャドウで、投影シャドウが形状シャドウの上でより濃くなる動作がなくなりました。
- マネージャーの段階番号が **1 · 変換** · **2 · 設定** · **3 · 詳細設定** の順に変わりました。
:::

:::note[現在は]
MingToonコンポーネントの自動削除は保証されません。上の案内は0.1.3当時の基準です。
→ [VRChat](/platforms/vrchat)
:::

## 新機能

- **SSSSS（実験的）** （旧名: 深度透過光） — 髪先や服の裾が光を含みます。
- ライトの方向へ深度を2回読み、直接測ります。**全体の幅** とは無関係に動作します。 → [ドキュメント](/guides/depth-effects#깊이-투과광)
- **マスター調整** — インスペクターの最初のセクションです。シーンが変わったときに一度でまとめて合わせ直します。
- `光を加えるものすべて`·`影すべて`·`最終出力`の3つの束に、`明るさ倍数`と`ティント`をかけます。
- **スクリーンスペース影の重なり深度** （旧名: 2Dシャドウの重なり深度） — 重なった部分をより濃くします。
- 0なら完全に1色です。 → [ドキュメント](/guides/light-and-shadow#통합-그림자--겹칠-때-새까매지는-문제)
- **リム・追加光にも上限を適用** — リム系がすべて加算されたあとに明るさの上限をかけます。既定は無効です。
- 従来の`最終ライティングの最大倍率`は加算前にかかるため、リムを上げるとそのまま白飛びしていました。
- **Skin** — 素肌専用のルック値を受け取るスロット役割です。`肌レンダラーの直接指定`で一度に指定します。
- **アップロード準備の点検** — 階層とManifestを調べ、アップロードを妨げる問題を診断コードで報告します。
- **ステータスパネル** — マテリアル構成・シェーディング状態・顔スロットの同期・最適化範囲を、マネージャー上部に表示します。
- 顔の範囲を、マスクテクスチャなしで頂点ペイントで直接塗ります。アウトラインのチャンネルとは分離されています。
- セクション単位でプリセットを保存して適用します。テクスチャを含めるかどうかを選べます。
- WARUDO Runtime Rootが、カメラ深度と頭の向きをシェーダーへ供給します。

:::note[現在は]
別途のRuntime Rootをプレハブに付けることはしません。上の案内は0.1.3当時の基準です。
→ [MingToonマネージャー](/workflow/character-manager)
:::

## 変わった既定値とルックの変化

- lilToon以外に、Standard、URP Litなどからも変換できます。
- この場合、ベースカラー・テクスチャ・ノーマル・エミッション・オクルージョンとレンダーステートだけが移行されます。
- パーティクル/VFX、屈折/宝石、ファー/シェル、オーディオ反応、フリップブックは移行できないため、元のまま残します。
- ハルノーマルソースの既定値が`UV8TS`になりました。UV8を焼くだけで済みます。
- `キャラクタールート`が`MingToonマネージャー`に、`lilToonクイック変換`が`シェーダー変換`に名称変更されました。
- プリセットは数値と色だけを適用します。テクスチャ・レンダーキュー・RenderTypeタグには触れません。
- 顔SDF Bakerが別のエディターパッケージへ分離されました。ない場合は該当ボタンが開きません。
- ノーマル強度に負の値を入れられます。凹凸が逆に反転します。
- `顔SDF影を使用`が、顔SDFセクションの最上部のマスタートグルになりました。
- ノーマルマップのタイリングがスロットのすぐ下に出ました。外側のマスクのタイリングとは意図的に分けています。
- `顔シェーディング`はこのバージョンでは適用されません。有効になっていたマテリアルも、無効の状態として読まれます。

## 修正された問題

- MingToonを初めて導入すると、プロジェクトのすべてのテクスチャが再インポートされる問題が修正されました。
- 顔SDFとハーフトーンパターンのテクスチャが、VRChatのアップロードを妨げる問題が修正されました。
- 顔の形状シャドウの境界に、線がもう1本描かれる問題が修正されました。
- 顔として指定した領域にも投影シャドウがかかる問題が修正されました。
- 統合シャドウで、キャストとデプスシャドウ（旧名: 2Dシャドウ）が1色にまとまらない問題。
- デプスリムライト（旧名: 2Dデプスリム）のフォールバック側にだけ、マスターがかからない問題。
- シーンビューが数分間止まる問題が修正されました。シーンビューのイベントごとに全オブジェクトを走査していました。
- 焼いて作成したテクスチャが、VRChatのアップロードを妨げる問題が修正されました。
- 頂点ペイントで塗るたびに止まる問題が修正されました。

## 既知の制限

- 汎用シェーダーの変換は、対応しない値を既定値のままにします。
- 変換ペアの検査は時間がかかるため、ボタンを押したときにのみ実行されます。
- エディターのランタイムプレビューは、VRChatのアップロードには含まれません。
- UV7は顔ノーマルのベイクと顔SDFが共用するため、どちらか一方だけが所有できます。
