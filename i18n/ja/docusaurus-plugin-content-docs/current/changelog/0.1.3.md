*クローズドベータ*

## ホットフィックス 1 · 2026-08-03

- **MingToon を入れるとプロジェクト内のすべてのテクスチャが再インポートされる問題** — 顔 SDF のテクスチャインポーターがグローバルな `AssetPostprocessor` だったため、プロジェクト内の全テクスチャが MingToon に依存していました。テクスチャの多いプロジェクトでは初回インポートに数時間かかっていました。
- **顔 SDF とハーフトーンパターンのテクスチャが VRChat のアップロードを止めていた問題** — `Streaming Mip Maps` がオフのまま同梱されていました。

## アップグレード前に確認すること

:::danger[MingToon コンポーネントを手で削除しないでください]
VRChat のアップロード時に**自動で除去**されます。手で削除するとキャッシュされたレンダラー一覧も一緒に失われ、**アップロード最適化が対象範囲を失って**、最適化されないマテリアルがそのまま上がります。 → [VRChat](/platforms/vrchat)
:::

:::caution[顔の Auto 判定が名前から推測しなくなりました]
`Auto` は**元マテリアルが持つ顔フラグのみ**を読みます。Standard や URP Lit から変換すると**すべてのスロットが `Regular` のまま**になるため、顔として使うスロットは自分で `Face` に指定してください。 → [MingToon マネージャー](/workflow/character-manager#얼굴--피부-지정--가장-중요한-단계)
:::

:::caution[マネージャーのステップ番号が変わりました]
`1 · 変換` → `2 · 設定` → `3 · 詳細設定` の順です。以前のメモとは番号が異なります。
:::

:::caution[`顔の境界` が負の値を受け付けなくなりました]
0 未満では顔の影の境界が、頭部の法線がほとんど変化しない領域に置かれ、帯がポリゴンの辺に沿って階段状になっていました。従来の既定値 −0.3 のマテリアルは **0 として読まれ、顔の影がわずかに増えます。** 顔マテリアルでこの値を取り直してください。 → [ドキュメント](/guides/light-and-shadow#1-형태-그림자-경계--가장-먼저)
:::

:::caution[統合シャドウでキャストシャドウが常に単一色へ合流します]
投影影がフォーム影に重なった部分で濃くなる挙動がなくなりました。重なりを再び濃くしたい場合は **`2D影の重なり深度`** を上げてください。 → [ドキュメント](/guides/light-and-shadow#통합-그림자--겹칠-때-새까매지는-문제)
:::

## 新機能

- **深度透過光** — 毛先や裾のような薄い部分が光を含んでいるように見えます。光源方向へ深度を2回読み、光がキャラクターをどれだけ通過したかを直接測るため、`マスター幅` とは無関係に単独で動作します。 → [ドキュメント](/guides/depth-effects#깊이-투과광)
- **アップロード準備チェック** — 階層と Manifest を走査し、アップロードを妨げる問題を診断コードで報告します。 → [ドキュメント](/workflow/character-manager#업로드-준비-점검)
- **ステータスパネル** — マテリアル構成・シェーディング状態・顔スロットの同期・最適化範囲をマネージャー上部に常時表示します。
- **VRChat 事前チェック / Quest チェック** — 不足している標準プロパティと許可されないコンポーネントを数え、Quest で失われる項目を件数で示します。
- **`Skin` ロール** — 素肌専用のルック値を受け取るスロットロールが追加されました。`肌レンダラーを直接指定` で一括指定できます。
- **タブプリセット** — セクション単位でプリセットを保存・適用できます。テクスチャを含めるかどうかを選べます。
- **WARUDO Runtime Root** — Warudo モッドでカメラ深度と頭の向きをシェーダーへ供給する、独立したランタイムコンポーネントです。 → [Warudo](/platforms/warudo#내보내기-전-필수--warudo-runtime-root)
- **`マスター調整`** — インスペクターの最初のセクションです。`光を足すもの全部`・`影全部`・`最終出力` の3つに、それぞれ `明るさ倍率` と `ティント` を掛けて、シーンが変わったときに一度に取り直せます。
- **`リム・追加光にも上限`** — バックライト・フロントライト・フレネルリム・影の内部反射・2D深度リム・深度透過光・グリッターがすべて加算された後に明度の上限を掛けます。既存の `最終ライティング最大倍率` はそれらの前に掛かるため、リムを上げるとそのまま白飛びしていました。既定はオフです。 → [ドキュメント](/guides/light-and-shadow#라이팅--어두운-씬에서-검게-뭉칠-때)
- **`2D影の重なり深度`** — 統合シャドウモードで、2D影がフォーム影の内側に入ったときにどれだけ濃くするかを決めます。0 なら完全に単一色です。 → [ドキュメント](/guides/light-and-shadow#통합-그림자--겹칠-때-새까매지는-문제)
- **頂点ペイントで顔領域を指定** — マスクテクスチャなしで顔の範囲を直接塗れます。アウトラインが使うチャンネルとは別なので、両方を同じメッシュで使えます。
- **シェーダーバリアントの事前コンパイル** — 変換の最後に自動で実行され、`Tools > Studio Raming > MingToon > Prewarm Shader Variants` からも呼べます。

## 変更

- **lilToon 以外からも変換できます** — Standard、URP Lit なども対象です。その場合はベースカラー・テクスチャ・ノーマル・エミッション・オクルージョンとレンダー状態が引き継がれ、残りは MingToon の既定値になります。
- **変換対象外の系統** — パーティクル/VFX、屈折/宝石、ファー/シェル、オーディオリアクティブ、フリップブック/スクロール、アウトライン専用・補助パスは移行できないため、元のマテリアルをそのまま残します。 → [ドキュメント](/workflow/character-manager#변환되지-않는-슬롯)
- **ハルノーマルソースの既定値が `UV8TS` に** — UV8 を焼くだけで完了です。マテリアル側で切り替える必要はありません。 → [ドキュメント](/guides/mesh-bakes#아웃라인-스무스-노멀-uv8)
- **`キャラクタールート` から `MingToon マネージャー`** へ名称が変わりました。
- **`lilToon クイック変換` から `シェーダー変換`** へ名称が変わりました。
- **プリセットが持つ範囲** — 数値と色のみを適用します。テクスチャ・ベクター・レンダーキュー・インスタンシング・RenderType タグには触れません。
- **Face SDF Baker が別のエディターパッケージに分離**されました。未インストールの場合、そのボタンは開きません。
- **`ノーマル強度` に負の値を入力できます。** 凹凸が反転します。
- **`顔SDF影を使用` が顔 SDF セクション最上部のマスタートグル**になりました。オンにすると残りが展開されます。
- **ノーマルマップのタイリングがスロットの直下**に出ました。折りたたみの内側にあり、外側のマスクのタイリングと混同しやすかった問題を解消しました。2つの値は意図的に別々のままです。
- **`顔シェーディング` はこのバージョンでは適用されません。** 開発中のためセクションは非表示になり、オンだったマテリアルとプリセットもオフとして読み込まれます。顔の変換とその他の顔機能はそのまま動作します。

## 改善

- **UV チャンネル使用状況** — `UV4 · UV7 · UV8` がそれぞれ空きか使用中かを表示します。UV7 は顔ノーマルベイクと顔 SDF 投影が共用するため、どちらか一方しか所有できない旨も併せて案内します。
- **変換ペア検査** — 変換マテリアルと元マテリアルの対応を確認します。時間がかかるため、ボタンを押したときだけ実行されます。
- **顔モジュール同期** — 顔スロットのキーワードがマテリアル値とずれている場合に警告し、一括で揃えます。ずれたままベイクすると顔シェーディングが抜けます。
- **最適化範囲の警告** — レンダラーキャッシュが古い場合、何個が最適化されずにアップロードされるかを知らせます。
- **エディターランタイムプレビュー** — ルックプロファイルとランタイム顔方向をエディターで確認できます。VRChat のアップロードには載りません。
- **マテリアル負荷の見積もりが検索欄の横に**上がりました。1行で表示され、展開すると詳細が見えます。
- **頂点ペイント** — リアルタイムオーバーレイ、X 軸ミラー、ブラシの強さ・不透明度、ウィンドウ移動に対応します。塗るたびに固まる問題も解消しました。
- **変換タブ** — 直接指定したレンダラーがスロット要約に反映され、スキンを顔・通常とは別に数えます。影色・フレネルを上書きするかどうかを選べ、変換済みのキャラクターにルックプリセットだけを掛け直せます。
- **項目別プリセット・ルックプリセットの一覧**が分類ごとに展開して表示されます。

## 修正

- **顔の形状影の境界にもう 1 本線が描かれていた問題** — 境界が顔ではなく体のターミネーター位置に作られていました。
- **顔として指定した領域にも投影影が落ちていた問題。**
- **統合シャドウでキャストと 2D が 1 つの色に収束しなかった問題** — アウトラインハルと追加ライト経路が明るさ上限を通らず、そこだけ焼き付き続けていました。
- **2 種類あるデプスリムのうちフォールバックリムにマスターが掛からなかった問題** — デプスバッファのないカメラで結果が変わっていました。
- **シーンビューが数分間フリーズしていた問題** — ポストプロセス連携がシーンビューのイベントごとに全オブジェクトを走査し直していました。
- **ベイクで作ったテクスチャが VRChat のアップロードを止めていた問題** — マスクパック・サーフェス統合・顔 SDF の出力に `Streaming Mip Maps` がオフのままでした。
