*クローズドベータ・2026-08-18*

## アップグレード時の確認事項

:::danger[スキーマ移行を一度実行してください]
`Tools > Studio Raming > MingToon > Advanced > Migrate Project To Current Schema`

マテリアルスキーマが 10 から 11 に上がりました。新設の `リムライトマスクを使用`・`リム影マスクを使用` トグルは以前のマテリアルではオフとして読まれるため、**実行するまでそのマテリアルのリムマスクは適用されません。** 移行処理が、白の既定値ではないマスクを探してトグルをオンにします。 → [インストール](/getting-started/installation#이전-버전에서-올라왔다면)
:::

:::caution[ベイクキャッシュが再生成され、VRChat アバターは再アップロードが必要です]
生成シェーダーのキャッシュバージョンが 28 から 29 に上がり、既存のベイク成果物が無効になります。次のビルドで自動的に焼き直されるため手作業は不要ですが、その一回だけ時間がかかります。シェーダーはアバターのアセットバンドルに同梱されるため、**すでにアップロード済みのアバターは再アップロードするまで旧シェーダーのままです。**
:::

:::caution[`深度の可用性` の `Force On` がミラーを除外します]
`Force On` は「ホストが報告できない場合まで有効にする、**ただしミラーは除く**」を意味するようになりました。ミラー内ではどの値を選んでも深度モジュールは停止します。 → [ドキュメント](/guides/depth-effects#깊이-가용성)
:::

:::caution[Missing Depth Fallback（フレネルフォールバック）が削除されました]
深度がないときに `2D深度リム` がフレネルリムへ代替される機能がなくなりました。代替モードを Fresnel に指定していたマテリアルは**そのリムを失います。** これからは深度がなければ深度モジュールは静かに停止します。
:::

:::caution[アウトラインの `シェーディングを含める` の挙動が変わります]
アウトラインはベースマップの色とライティング応答だけで描かれるようになり、本体のシャドウパターン・投影シャドウ・深度エフェクトを線の上に描き直しません。`シェーディングを含める` をオンにすると、本体シェーディング全体を複製する代わりに、フォームシャドウの色に沿った軽い陰影バンドが適用されます。 → [ドキュメント](/guides/outline#아웃라인-색이-조명을-따라가게)
:::

:::caution[`Compile All Modules While Authoring` の既定がオンになりました]
作業中にトグルがシェーダーの再コンパイルを待たないようにするための変更です。初めてオンになるときコンソールに1行案内が出ます。不要な場合は一括編集パネルからオフにできます。オンのままビルドしても不要なキーワードは自動的に整理されるため、成果物への負担はありません。
:::

## 新機能

- **`色調補正マスク`** — `Base HSVG` の補正をマスクが白い部分にだけ適用します。顔はそのままで目だけ色を変える、といった部位限定の補正に使います。lilToon の色調補正マスクは変換でここへ入ります。 → [ドキュメント](/guides/basics#색조보정-범위-마스크)
- **`トゥーンスペキュラー色の指定方法` に `Mask Texture Color` を追加** — マスクに塗った RGB がハイライト色になり、髪のハイライトを房ごとに違う色へ分けられます。テクスチャを追加で読みません。 → [ドキュメント](/guides/detail-maps#하이라이트-색을-부위마다-다르게)
- **`影の方式` セレクター** — 前髪や小物の影をリアル影で受けるか、柔らかい2D影で描くかを1行で選びます。2つのタブに分かれていた値がまとめて設定されます。 → [ドキュメント](/guides/character#4단계-앞머리-그림자)
- **アウトライン UV8 ベイクの `ノーマルを編集したモデル用に計算`** — 球や円柱からノーマルを転写した髪やスカートで、アウトラインの方向をメッシュの面から計算し直します。既定はオフのため、変換済みキャラクターの線は変わりません。 → [ドキュメント](/guides/mesh-bakes#노멀을-편집한-모델용으로-계산)
- **`アップロード時に深度ライトを載せる`（既定オフ）** — VRChat のアップロード版にのみライトを1つ載せ、カメラが深度を描くようにします。コストを負担するのは見ている側なので、インスペクターが4つのコストを先に提示します。 → [ドキュメント](/platforms/vrchat#vrchat-깊이-라이트)
- **`リムライトマスクを使用`・`リム影マスクを使用`** — 2つのリムマスクが影内部反射マスクと同じ構造になり、マスクを使わないマテリアルはマスクテクスチャを一切読みません。マスクを使うにはトグルを先にオンにしてください。 → [ドキュメント](/guides/rim#림-마스크)
- **`深度の可用性` に `Diagnostic` を追加** — シェーダーが実際にどの深度テクスチャを見ていたかを単色で塗って示します。バグ報告専用です。 → [ドキュメント](/guides/depth-effects#diagnostic)
- **`VRCライトボリューム`（既定オフ）** — VRC Light Volumes を使うワールドで、キャラクターの間接光補正と影の色味が Unity のプローブではなくその部屋のボリュームに従います。Built-in 専用で、ボリュームがない環境ではプローブに戻ります。
- **`Heal Material Keywords (Project)` メニュー** — プロジェクト内すべての MingToon マテリアルの保存済みキーワードとパス状態を、インスペクターの値に一致させます。実行前に確認し、変更したファイルはバックアップされ、結果はコンソールに1行残ります。
- **アウトライン UV8 ベイクが必要ならマネージャーが先に知らせます** — `ノーマルソース` が `UV8TS` なのにメッシュに UV8 がない場合、MingToon マネージャー最上部に警告とベイクボタンが出ます。ボタンの上に、新しいメッシュをどこに作り、いくつのレンダラーを処理するかを事前に表示します。 → [ドキュメント](/guides/mesh-bakes#아웃라인-스무스-노멀-uv8)
- **一括編集パネルに `シャドウカラーマップを使用`・`カラーマップ適用量` を追加** — 複数マテリアルを選んで一度に設定できます。 → [ドキュメント](/guides/bulk-editing)

## 変更

- **Missing Depth Fallback（フレネルフォールバック）を削除しました。** 深度がなければ深度モジュールはそのまま停止します。
- **アウトライン（クラシックハル）のピクセルコストが約 1/3 になりました。** アウトラインが本体シェーディングを複製しません。 → [ドキュメント](/guides/outline#아웃라인-색이-조명을-따라가게)
- **`深度の可用性` の `Force On` がミラーを除外します。** → [ドキュメント](/guides/depth-effects#깊이-가용성)
- **`Compile All Modules While Authoring` の既定がオンになりました。**
- **`Prewarm Shader Variants` メニューがなくなりました。** 同じ処理を行う `Warm up shader variants` が残ります。

## 改善

- **インスペクターのトグルがシェーダーコンパイルを待たなくなりました。** `グリッターマスクを使用`・`マスクを使用`（影内部反射）・`2Dシャドウマスク`・`深度リムマスク`・`内側エッジマスク`・`領域マスクを使用`・`2段目の影を使用` の7つのトグル、レイヤードロップダウン、`Base Tint After HSVG`、`Face Shading Module` から、1回あたり2〜6秒の再コンパイルが消えました。描かれる絵と既定値はそのままです。
- **シェーダーのコンパイルがパッケージ導入時に一度で終わります。** インポート直後にキャンセル可能な進捗バーとともに並列で焼き、その後は変換・マテリアル選択・編集中にコンパイル待ちが発生しません。中断した地点から次回が引き継ぎます。
- **変換の進行状況が段階ごとに表示されます。** マテリアル変換 → ルックプリセット → メッシュベイク の進捗バーが出て、完了時に段階別の所要時間がコンソールに1行残ります。 → [ドキュメント](/workflow/liltoon-conversion)
- **レイヤーマスクが統合テクスチャへ自動合成されます。** サーフェススタック・ノーマル・マットキャップのマスクをまとめ、GPU が読むテクスチャ数を減らします。使い方と各調整値はそのままで、合成物は `MingToonGenerated/MaskPacks` に自動生成・共有されます。
- **アウトラインパネルがメッシュの UV8・頂点カラーの有無を報告します。** → [ドキュメント](/guides/outline#선-굵기를-부위마다-다르게)
- **アウトライン UV8 ベイクがベイク済みキャラクターを拒否しなくなりました。** MingToon が焼いた UV8 は読み飛ばし、ユーザーモデル本来の UV8 だけを拒否して、どのメッシュかを名前で知らせます。
- **インスペクターの表示修正** — ツールバーとセクションヘッダーの文字切れ、幅変更時のヘッダーのちらつきを修正し、案内・警告ボックスの文字を本文サイズにしました。

## 修正

- **アップロード最適化（ベイク）がオフにしたモジュールを強制的にオンにしていた不具合** — ミラーやポストのないカメラでアバターが真っ白に光るという報告の根本原因です。`エミッションを使用` をオフにしたのに既定の白マップで全面発光する、`2Dシャドウマスク` がオフなのに動作する、といった現象がなくなります。
- **VRChat のミラー内で `2Dシャドウ` と `2D深度リム` が体に追従せず滑っていた問題** — シェーダーがプレイヤーカメラの深度バッファを読み、他人のシルエットを使っていました。ミラー内では深度モジュールが自動的に停止します。 → [ドキュメント](/guides/depth-effects#깊이-가용성)
- **リアルタイムのディレクショナルライトがないワールドや Disable Pixel Lights のミラーで陰影が崩れ、白っぽくなっていた問題** — アンビエントプローブからキーライトを合成し、どこでも正常なシェーディングを保ちます。ディレクショナルライトのあるワールドでは変化ありません。 → [ドキュメント](/guides/light-and-shadow#라이팅--어두운-씬에서-검게-뭉칠-때)
- **lilToon 変換が値だけを移してモジュールはオフのまま出力していた問題** — `PBRサーフェスを使用`・`エミッションを使用`・`サーフェススタックを使用`・アウトラインマスター・`Classic Hullを使用` のトグルが一緒にオンになります。スタックの2段目・3段目のレイヤーや、アウトラインの方向と太さも正確に受け取ります。 → [ドキュメント](/workflow/liltoon-conversion)
- **`ノーマルソース` が `VertexColorTS` で頂点カラーがないメッシュでは、アウトラインが斜めにずれていた問題** — メッシュノーマルにフォールバックします。 → [ドキュメント](/guides/outline#각진-부분에서-선이-끊길-때)
- **タンジェントやノーマルがないパーツが1つあるだけで、アウトライン・顔・高さのベイクが同時に失敗していた問題** — そのレンダラーだけを飛ばし、どのメッシュかをコンソールに知らせます。
- **同じメッシュを複数のレンダラーが共有しているとき、ベイクがレンダラーの数だけコピーを作っていた問題** — ソースメッシュごとに1つのアセットを作り、全員がそれを共有します。
- **変換が `使用中のUVチャンネルを上書き` の設定と無関係にユーザーモデルの UV8 を消していた問題** — オプションがオフなら読み飛ばして報告します。
- **`Unified Shadow Color Map` をオフにしても全モジュールコンパイルモードでは効かないことがあった問題** — どのコンパイルモードでも確実にオフになります。 → [ドキュメント](/guides/light-and-shadow#통합-그림자--겹칠-때-새까매지는-문제)
- **アバター SDK のない VRChat ワールドプロジェクトで `VRCExpressionsMenu` のコンパイルエラー（CS0246）によりプロジェクトが壊れていた問題** — 表情メニューのインストーラーがワールドプロジェクトでは自動的にコンパイル対象から外れます。
- **Unity 2022 のプロジェクトでマテリアルを選択・編集した瞬間にベースが消えてアウトラインだけになる現象** — 根本原因を特定して修正しました。コンパイルを待っても再発していた環境でも起きません。 → [トラブルシューティング](/troubleshooting#작업-중-인스펙터가-무겁다)
- **変換時に選んだルックプリセットではなく一覧の先頭が適用されていた問題** — スクリプトのリロードやオブジェクトの選び直しの後も選択が保たれます。 → [ドキュメント](/workflow/character-manager#변환-시-룩-프리셋)
- **ルックプリセットが、変換で移ってきたマットキャップ・ノーマルレイヤー・サーフェススタックをオフにしたり、合成モードをすべて `Add` に変えていた問題** — ルックプリセットはルックだけを扱い、レイヤーの中身には触れません。
- **`[MingToon] VRChat build hook compiled and registered.` の確認ログが表示されなかった問題** — エディターセッションごとに一度コンソールに出ます。 → [VRChat](/platforms/vrchat)
- **トゥーンスペキュラーマスクを使わないマテリアルまでマスクテクスチャを読んでいた点** — 2つのリムマスクと同様に、使用トグルで分離しました。

## ドキュメント

- インスペクターと MingToon マネージャーの疑問符ボタンから、このサイトの該当セクションへ直接開きます。
- 項目リファレンスを現在のソースから再生成しました。削除された `代替表示` の節がなくなり、`深度の可用性`・`トゥーンスペキュラー色の指定方法`・`Face Shading Module` などの新規項目が3言語に入りました。
