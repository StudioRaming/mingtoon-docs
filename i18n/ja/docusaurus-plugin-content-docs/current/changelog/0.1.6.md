*クローズドベータ · 2026年8月18日*

## 一行まとめ

アバターが真っ白に光る問題を修正し、ミラー内の深度効果を正常化しました。

:::warning[アップデート前の確認]
- マイグレーション: `Migrate Project To Current Schema`を一度実行してください。
- 実行するまでは、既存マテリアルの`リムライトマスクを使用`·`リム影マスクを使用`が無効として読まれます。
- 再ベイク: ベイクキャッシュが無効になり、次のビルドで自動的に焼き直されます。
- 再アップロード: すでにアップロード済みのアバターは、再度アップロードしないと今回の修正が反映されません。
- ルックが変わる項目: アウトラインの`シェーディングを含む`、ミラー内の深度効果、暗いシーンの陰影。
- 深度がないときにデプスリムライトをフレネルリムで代替する機能は廃止されました。
:::

:::note[現在はAdvancedメニューの2つが表示されません]
`Migrate Project To Current Schema`と`Heal Material Keywords (Project)`は、
現在の公開ビルドには含まれていません（内部ツール専用）。
旧バージョンのマテリアルは、インスペクターの警告の案内に従ってください。
MingToonのメニューは、0.1.7で最上位の`StudioRaming > MingToon`に移動しました。
→ [0.1.7 パッチノート](/changelog/0.1.7)
:::

## 新機能

- **色調補正マスク** — `ベースマップ HSVG`の補正を、マスクが白い箇所だけにかけます。 → [ドキュメント](/guides/basics#색조보정-범위-마스크)
- **Mask Texture Color** — `トゥーンスペキュラー色の指定方法`に追加されました。マスクのRGBがハイライトの色になります。
- **顔の影の方式** — 前髪の影をリアルな影で受けるか、デプスシャドウで描くかを1行で選びます。
- **ノーマルを編集したモデル用に計算** — アウトラインのUV8ベイクで、輪郭線の向きをメッシュ面から計算し直します。
- **アップロード時に深度ライトを含める** — VRChatのアップロード版にのみライトを載せ、カメラに深度を描かせます。
- **リムライトマスクを使用** · **リム影マスクを使用** — マスクを使わないマテリアルはテクスチャを読みません。
- **Diagnostic** — `深度の可用性`に追加されました。シェーダーが見た深度テクスチャを単色で知らせます。
- **VRCライトボリューム（テスト用）** — ボリュームを使うワールドで、間接光と影の色調がボリュームに従います。
- `StudioRaming > MingToon > Advanced > Heal Material Keywords (Project)`メニューが追加されました。
- 保存されたキーワードとパスの状態を、インスペクターの値に合わせます。
- `ノーマルソース`が`UV8TS`なのにメッシュにUV8がない場合、Managerの最上部に警告とベイクボタンが表示されます。
- 一括編集パネルに`シャドウカラーマップを使用`·`カラーマップ適用量`が追加されました。

## 変わった既定値とルックの変化

- デプスシャドウ（旧名: 2Dシャドウ）とデプスリムライトは、深度がなければ静かに無効化されます。
- `深度の可用性`の`Force On`がミラーを除外します。ミラーの中ではどの値でも深度モジュールが無効になります。
- アウトラインが、ベースマップの色とライティングの応答だけで描かれます。本体のシェーディングを複製しません。
- `シェーディングを含む`を有効にすると、形状シャドウの色に従う軽い陰影バンドだけが適用されます。
- アウトラインのピクセル負荷が約1/3に減りました。
- `Compile All Modules While Authoring`が既定で有効になりました。一括編集パネルで無効にできます。
- `Prewarm Shader Variants`メニューがなくなり、`Warm up shader variants`だけが残ります。
- `ノーマルを編集したモデル用に計算`は既定で無効のため、すでにベイクしたキャラクターの線は変わりません。
- レイヤーマスクが1枚に合成され、GPUが読むテクスチャ数が減ります。調節値はそのままです。

## 修正された問題

- 鏡やポストのないカメラで、アバターが真っ白に光る問題が修正されました。
- アップロード最適化が、無効にしていたモジュールを強制的に有効にしていたのが原因です。
- VRChatの鏡の中で、デプスシャドウとデプスリムライトが体に追従せず滑る問題。
- ディレクショナルライトのないワールドと、Disable Pixel Lightsの鏡で、陰影が白っぽくなる問題。
- lilToon変換が値だけを移し、モジュールは無効のまま出力する問題が修正されました。
- 頂点カラーのないメッシュで、アウトラインが斜めにずれて飛び出す問題が修正されました。
- タンジェントやノーマルのないパーツ1つが、ベイク全体を落としてしまう問題が修正されました。
- 同じメッシュを複数のレンダラーで共有しているとき、ベイクがレンダラーの数だけ複製を作る問題。
- 変換がユーザーモデルのUV8を、オプションに関係なく削除する問題が修正されました。
- `Unified Shadow Color Map`を無効にしても、広域コンパイルモードでは有効になっている問題が修正されました。
- アバターSDKのないワールドプロジェクトで、CS0246のコンパイルエラーによりプロジェクトが壊れる問題。
- Unity 2022でマテリアルを選ぶと、ベースが消えてアウトラインだけが残る問題が修正されました。
- 変換時に選んでおいたルックプリセットではなく、一覧の先頭のプリセットが適用される問題が修正されました。
- ルックプリセットが、変換で移してきたレイヤーを無効にしたり、合成モードをすべて`Add`に変えたりする問題。
- `[MingToon] VRChat build hook compiled and registered.`の確認ログが表示されない問題。
- インスペクターのツールバー・セクションヘッダーの文字切れと、幅の調節時のヘッダーのちらつきが修正されました。
- インスペクターのトグル7種で、トグルごとに2〜6秒かかっていた再コンパイルがなくなりました。絵と既定値はそのままです。

## 既知の制限

- 代替モードをFresnelに指定していたマテリアルは、そのリムを失います。
- 初回のベイクはキャッシュを作り直すため、一度だけ時間がかかります。
- シェーダーコンパイルは、パッケージのインストール時に一度で終わります。中止した場合は次回の実行が引き継ぎます。
- `VRCライトボリューム（テスト用）`はBuilt-in専用です。
