*クローズドベータ · 2026年8月5日*

## 一行まとめ

金属と光沢を表現するハイブリッドPBRとトゥーンスペキュラーが追加されました。

:::warning[アップデート前の確認]
- パラメーター予算: VRChat Expression Parametersの残量を先に確認してください。
- `Modular Avatarで非破壊インストール`が、21個の同期パラメーターと154ビットを使います。
- 既存のアバターと合わせて256ビットを超えると、インストールが中断されます。
- ルックが変わる項目: 0.1.3で非表示になっていた`フェイスシェーディング`が再び表示されます。
- 既存の顔マテリアルは、マスク・境界・SDFマップを確認してから自分で有効にしてください。
:::

## 新機能

- **PBRサーフェスを使用** — トゥーンの拡散光を保ちつつ、メタリック・スムースネス・反射を加えます。 → [ドキュメント](/guides/detail-maps#pbr-표면)
- **トゥーンスペキュラー** — PBR全体を有効にせず、ハイライトだけを追加します。髪用の異方性もあります。
- IsotropicとAnisotropicから選びます。 → [ドキュメント](/guides/detail-maps#툰-스페큘러)
- **領域マスク** — RGBA1枚を4つの領域に分け、パーツごとに補正します。 → [ドキュメント](/guides/detail-maps#영역-마스크)
- **Single Channel (Grayscale)** — 顔SDFの形式に追加されました。Rチャンネル1枚を左右反転して使います。
- 顔の領域をSceneViewで直接塗ります。Paint·Harden·Smooth·Hard FaceとX対称に対応します。
- 連結アイランド、メッシュの分離、保存・破棄のフローを提供します。 → [ドキュメント](/guides/character#얼굴-영역을-sceneview에서-칠하기)
- **MingToon 2D投影シャドウキャスター** — メガネ・アクセサリーを、深度ベースの効果からのみ除外します。
- 通常のレンダーとUnityのリアルタイム影はそのまま維持されます。
- Face SDF Studioを同梱しました。Base·Nose·Cheek·Lip·Eye Socketを1枚に焼きます。
- MaskMakerと`MM`ボタンを同梱しました。マスクスロットから直接開いてPNGを適用します。
- 仮想光とHighlight·Shadow·Final OutputをVRCメニューで調節します。`Reset All`で復元します。

## 変わった既定値とルックの変化

- Face SDF StudioとMaskMakerが0.1.4パッケージに同梱されます。どちらもEditor専用です。
- ランタイムスクリプトは追加しません。
- Face SDF Studioの作業空間が、`準備 · 正面UV7`と`SDF制作 · プレビュー · ベイク`の2段階になりました。
- アウトラインの幅マスクが、幅の設定の近くへ移動しました。
- lilToon変換で、幅マスクのTiling/Offsetも併せて保持します。
- Inspectorの分類と説明を、ユーザー向けの表示名に統一しました。ガイドタブの代わりにツールチップを使います。
- VRCメニューのインストールが非破壊方式になりました。既存のRoot MenuとFXを維持し、ビルド用の複製でのみ統合します。

:::note[現在は]
Face SDF StudioとMask Makerは、0.1.7から同梱されません。別売り製品です。
インストールすると、インスペクターの同じ位置でそのまま連携します。 → [別売りアドオン](/guides/add-ons)
:::

:::note[現在は]
VRChatメニューの作成は、0.1.7で別売りアドオンのMing Light Controllerへ移りました。
MingToon本体はメニュー・パラメーター・FXを作成しません。 → [Ming Light Controller](/guides/ming-light-controller)
:::

## 修正された問題

- `フェイスシェーディング`を有効にするとBase Passが消える問題が修正されました。
- BRPの`ForwardBase`とURPの`UniversalForwardOnly`を復旧しました。
- 逆光の顔に白いジグザグの線が出る問題が修正されました。
- 形状シャドウの境界における画面微分の幅に上限をかけ、三角形の境界が出ないようにしました。
- 顔SDFの向き・座標がずれたり、切り替わりが一度に跳ねたりする問題が修正されました。
- マップを接続していないときの警告と復旧の経路を追加しました。
- lilToonのアウトライン幅マスクとTiling/Offsetが変換されない問題が修正されました。
- Managerの変換・保存・更新のあとに`EndLayoutGroup`エラーが出る問題が修正されました。
- エミッションマップがないときに色と強度が黒で乗算され、発光が消える問題が修正されました。
- 複数のマテリアルを編集する際に、インスペクター・プリセット・コストパネルが繰り返し更新されるのを減らしました。
- Bakeの中止と復元の境界を明確にしました。準備中の中止と最終保存を区別します。

## 既知の制限

- このバージョンのFace SDF StudioとMaskMakerはEditor専用です。ビルドには含まれません。
- パラメーター予算を超えるとインストールが中断されます。既存アバターの残量を先に空けてください。
