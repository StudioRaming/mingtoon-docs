*クローズドベータ・2026-08-05*

## アップグレード時の確認事項

:::caution[VRChat Expression Parameters の予算を先に確認してください]
`Modular Avatarで非破壊インストール` はデフォルトで有効で、Virtual Light と Master Adjust に **21個の同期パラメーター・154ビット**を使用します。既存アバターと合算して256ビットを超えるとインストールが中止されます。→ [VRChat](/workflow/character-manager#vrchat-표현식-메뉴)
:::

:::caution[0.1.3で非表示だったフェイスシェーディングが復活しました]
`フェイスシェーディング` は再び表示され、使用できるようになりました。既存の顔マテリアルはアップデート後にマスク・境界・SDFマップを確認してから手動で有効にしてください。→ [キャラクター表現](/guides/character#페이스-셰이딩)
:::

## 新機能

- **ハイブリッドPBR** — トゥーン拡散光を維持しながらメタリック・滑らかさ・直接ハイライト・環境反射を追加し、トゥーンブレンドで反射形状を整えます。→ [ドキュメント](/guides/detail-maps#pbr-표면)
- **`トゥーンスペキュラー`** — PBR全体を有効にせず、Isotropicまたは髪用Anisotropicハイライトを追加します。→ [ドキュメント](/guides/detail-maps#툰-스페큘러)
- **`領域マスク`** — 1枚のRGBAを4領域に分け、メタリック・滑らかさ・反射・トゥーンスペキュラーをパーツごとに補正します。→ [ドキュメント](/guides/detail-maps#영역-마스크)
- **Face SDF Studio同梱** — Base・Nose・Cheek・Lip・Eye Socketをリアルタイムでプレビューし、1枚の方向性SDFにベイクします。→ [ドキュメント](/guides/face-sdf#face-sdf-studio-작업-순서)
- **単一チャンネル顔SDF** — Rチャンネル1枚を左右反転して使用する`Single Channel (Grayscale)`形式を追加しました。→ [ドキュメント](/guides/face-sdf#sdf-맵-형식)
- **SceneView頂点・マスクペイント** — Paint・Harden・Smooth・Hard Face、X対称、連結アイランド、メッシュ分離と、明示的な保存・破棄フローを提供します。→ [ドキュメント](/guides/character#얼굴-영역을-sceneview에서-칠하기)
- **MaskMaker同梱と`MM`ボタン** — 実際のマスクスロットからSelection・Gradient・Bridge Random・Brush Paintを直接開き、PNGをスロットに適用します。
- **Virtual LightとMaster Adjust VRCメニュー** — Virtual LightとHighlight・Shadow・Final Outputの色・明るさ・強度をVRCメニューで調整し、`Reset All`で初期値に戻します。→ [ドキュメント](/workflow/character-manager#vrchat-표현식-메뉴)
- **`MingToon 2D投影シャドウキャスター`** — メガネ・アクセサリーを通常レンダーとUnityリアルタイムシャドウを維持したまま、MingToonの深度ベース効果から除外できます。→ [ドキュメント](/guides/light-and-shadow#역광에서-몸에-캐릭터-모양-그림자가-겹칠-때)

## 変更

- **Face SDF StudioとMaskMakerを1つの0.1.4パッケージに同梱**し、どちらもEditor専用のためランタイムスクリプトを追加しません。
- **Face SDF Studioのワークスペースを2段階に整理**しました — `準備・正面UV7`と`SDF作成・プレビュー・ベイク`だけを順に進めれば完了します。
- **アウトライン幅マスクを幅設定の近くへ移動**し、lilToon変換時にマスクのTiling/Offsetも保持します。
- **Inspectorの分類と説明をユーザー表示名に統一**し、別ガイドタブの代わりに必要な場所へツールチップを配置しました。

## 改善

- **Inspector・プリセット・マテリアルコストパネルの反復計算を削減**し、複数マテリアル編集時の不要な更新を減らしました。
- **Bake経路のRenderer・機能分析とMask Pack readbackを再利用**し、同じデータを繰り返し読み込まないようにしました。
- **Bakeのキャンセル・復元の安全性を強化**し、準備中のキャンセル、最終保存、メッシュ・ブレンドシェイプ・元マテリアル復元の境界を明確にしました。
- **VRCメニューのインストールを非破壊方式に変更**し、既存のRoot Menu・Expression Parameters・FXを保持してbuild cloneでのみ統合します。

## 修正

- **`フェイスシェーディング`を有効にするとBase Passが消える問題** — BRP `ForwardBase`とURP `UniversalForwardOnly`を復元し、D3D11リソース上限を超えていた開発用の全固定コンパイルを安全なデフォルトへ変更しました。
- **逆光の顔に白いジグザグ線が出る問題** — 形状シャドウ境界の画面微分幅に上限を設け、三角形の境界がシェーディングに現れないようにしました。
- **顔SDFの方向・座標がずれたり遷移が一度に跳ねる問題**を修正し、マップ未割り当て警告と復元経路を追加しました。
- **lilToonアウトライン幅マスクとTiling/Offsetが変換されない問題**を修正しました。
- **Managerの変換・保存・更新後に`EndLayoutGroup`エラーが発生する問題**を修正しました。
- **Emissionマップがないと色と強度が黒く乗算され発光が消える問題**を修正しました。

## ドキュメント

- 顔SDFとFace SDF Studio、フェイスシェーディング、ハイブリッドPBR・トゥーンスペキュラー・領域マスク、VRChat Virtual Lightのセットアップ文書を0.1.4基準で書き直しました。
