■ ホットフィックスとは

  バージョン番号を上げずに、同じバージョンのパッケージを再度公開した修正です。
  正式なリリースノートとは混ぜず、バージョンごとのホットフィックスページ1枚に次数別で積み上げます。
  ファイル名は`<バージョン>-hotfix.md`で、3言語とも同じ名前です。
  新しい次数は常にこのページの最上部に追加します。

■ frontmatter

  id:               v<バージョン>-hotfix
  title:            <バージョン> 핫픽스   (英語: <バージョン> Hotfix / 日本語: <バージョン> ホットフィックス)
  sidebar_position: リリースノートの値から0.5を引いた値
                    (0.1.7が-107なら、ホットフィックスは-107.5)
  slug:             /changelog/<バージョン>-hotfix
  description:      一行まとめと同じ文章

■ 必ず守ること

  1. 3言語を常に一緒に埋めます。韓国語だけを書くと、残りは韓国語にフォールバックします。
  2. リリースノートからホットフィックスの項目を外し、このページへ移します。
     リリースノートの末尾には、ホットフィックスページへのリンク1行だけを残します。
  3. `アップデート前の確認`には、再アップロード・再変換・手動で戻す値だけを書きます。
     1つのリストの中に「再アップロードが必要」と「不要」を一緒に書かないでください。
     対象のマテリアルを明示して1つにまとめます。
  4. 各項目は症状の文章で書きます。原因の説明は1行までにします。
  5. インストール先のように以降のバージョンで変わった案内は、`:::note[지금은]`の1ブロックで知らせます。
  6. UIラベルはインスペクターの文言そのまま、アンカーは韓国語の原文のまま。
     1文60字以内、1ページ80行以内、絵文字は禁止。
  7. まだ公開していない次数はコミットのみで、プッシュしません。
     サイトはプッシュすると即座に公開されます。

■ 書き終えたら

    npm run build
    node scripts/check-translations.mjs en
    node scripts/check-translations.mjs ja
