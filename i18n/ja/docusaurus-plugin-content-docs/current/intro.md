# MingToon

**VRChat アバターのためのキャラクター向けトゥーンシェーダー**です。

キャラクターを描くときに実際に触るもの — 影が落ちる位置とその色、顔に鼻の影がどう乗るか、アウトラインの太さ、逆光でシルエットが立つかどうか — を、それぞれ別々に決められるように分けてあります。ルックを作るインスペクターから、アバターに載せてアップロードする段階までが一式で入っています。

Built-in Render Pipeline(BRP) ベースで、Warudo と一般的な Unity プロジェクトでも使えます。

## 何が作れるか

- **影を3種類に分けて扱います** — 起伏が作る**フォームシャドウ**、リアルタイムの**シャドウプロジェクション**、画面深度を読んで前髪や手が体に落とす**2Dシャドウ**。3つが重なって真っ黒にならないよう1色にまとめる統合シャドウもあります。→ [ライトとシャドウ](/guides/light-and-shadow)
- **影を網点で刷ります** — スクリーントーン。表面に貼り付けてキャラクターと一緒に動かすことも、画面に固定して印刷物に重ね刷りしたように見せることもできます。→ [シャドウパターン](/guides/shadow-pattern)
- **顔は別に扱います** — ノーマルプッシュ、フェイス領域マスク、方向性 SDF。鼻や前髪の影が表情を壊さないように調整でき、SDF を焼くツールも同梱しています。→ [フェイス SDF](/guides/face-sdf)
- **アウトラインを深度なしで描きます** — 太さはシーンビューでブラシで直接塗ります。→ [アウトライン](/guides/outline)
- **シルエットを立たせます** — リムライト・リムシェード・逆光・正面光・シャドウ内部リフレクション。暗いシーンでキャラクターが背景に沈まないようにする側です。→ [リム](/guides/rim)
- **ディテールを重ねます** — テクスチャ・ノーマル・マットキャップレイヤー、ハイブリッド PBR、トゥーンスペキュラー、グリッター、エミッション。→ [ディテールマップ](/guides/detail-maps)
- **色は最後にまとめて調整します** — 光を足すもの全部・影全部・最終出力の3つの束にそれぞれ明るさとティントをかけ、シーンが変わったときに全体を一度で合わせ直します。→ [基本設定](/guides/basics)

## アバターに載せるまで

- **lilToon 変換** — すでに作ってあるアバターのマテリアルを MingToon に移します。テクスチャ・マスク・アウトライン幅マスクも一緒に持っていきます。→ [lilToon 変換](/workflow/liltoon-conversion)
- **MingToon マネージャー** — どのスロットが顔でどこが素肌かを指定し、アバター全体のルックを1画面で扱います。→ [MingToon マネージャー](/workflow/character-manager)
- **ビルド時の自動最適化** — アップロード時に実際に使う機能だけを残したシェーダーへ自動的に差し替え、終わったら編集用に戻します。作業は全部オンのままで、上がるものだけが軽くなります。→ [ビルド時の自動最適化](/workflow/build-optimization)
- **VRChat 表現メニュー** — バーチャルライトと明るさ・色の調整をゲーム内メニューから操作できます。Modular Avatar で非破壊インストールされます。→ [VRChat](/platforms/vrchat)
