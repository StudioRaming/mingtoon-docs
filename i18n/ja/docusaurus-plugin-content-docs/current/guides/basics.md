# 基本設定

[Manager から始める](/getting-started/first-material)の後、変換済みマテリアルを調整するガイドです。**アバタールートの MingToon Manager は残して**対象マテリアルを選びます。現在の Inspector の表面・色・照明設定に沿って説明します。表示名が異なる場合はバージョンを確認してください。**VCC で導入した場合は VCC で更新します。**

## 調整したい項目を探す

| 変えたいこと | 最初に開く場所 | 主な項目 |
|---|---|---|
| 暗さ・明るさ | ライティング → 基本ライト応答 / ライティング明度制限 | 明部の明るさ · 間接光の持ち上げ · 最終最小/最大明るさ |
| ワールド照明の色が強すぎる | ライティング → 基本ライト応答 | 環境色の反映 · ベースカラー保持 |
| テクスチャの色味 | ディテールマップ → サーフェスマップ | ベース HSVG · 色相回転の方式 · ベースカラー |
| 切り抜き・半透明 | サーフェス描画 / アルファ＆カットアウト | サーフェスモード · ベースマップ全体の不透明度 · アルファカットオフ |
| 裏面・衣装の重なり | サーフェス描画 | 表示する面 · 両面デュアルパス |
| 深度効果の遮蔽物として使う | サーフェス描画 | カメラ深度への記録 |

クイック設定で全体を整え、必要な項目だけ検索や**全設定**で開きます。**Face・Skin・Common は通常ビルドでもマテリアル上部から直接変更できます。** 複数選択中に役割や値を変えると、選択した対象全体へ適用されます。

## 明るさと照明の色を分けて調整する

**基本ライト応答**の4項目から始めます。

| 項目 | 変わること | 調整の目安 |
|---|---|---|
| 明部の明るさ | 光が当たる面の明るさ倍率 | 1が基準。上げたときの白飛びを確認 |
| 環境色の反映 | ライトプローブ・アンビエントの色味 | 肌や衣装に環境色が強く混ざる場合に下げる。明るさとは別 |
| 間接光の持ち上げ | 間接光が暗部を持ち上げる量 | 0は明るさの追加なし、1は基準強度 |
| ベースカラー保持 | 完成ベース色に混ざる照明の色味 | 高いほど元の色を優先。**明るさを保持・増加する機能ではない** |

暗すぎる場合は**間接光の持ち上げ**と**ライティング明度制限 → 最終最小明るさ**を確認します。明部が白く飛ぶ場合は**明部の明るさ**と**最終最大明るさ**を調整します。ベースカラー保持だけで暗さを解決しようとしないでください。

ポイント・スポットライトの影響は**追加ライト受信量**で調整します。照明色や応答カーブは詳細設定にあります。→ [ライトとシャドウ](/guides/light-and-shadow)

## ベース色とテクスチャ {#2-베이스-색}

**サーフェスマップ**でベーステクスチャと色補正を扱います。変換済みの場合は、再割り当て前に現在のテクスチャと変換結果を確認してください。

| 項目 | 役割 |
|---|---|
| ベースマップ | 元の表面テクスチャ |
| ベース HSVG | 色相・彩度・明度・ガンマ補正 |
| 色相回転の方式 | HSV または OKLab。既存の HSV ルックを維持する場合は変更しない |
| ベースカラー · ティント合成モード | Multiply はマップの陰影を残し、Normal は選択色で置き換える |
| ベースマップ全体の不透明度 | 最終ベースアルファに乗算する、**ティント強度とは独立した表面の不透明度** |

以前のティント不透明度の説明と、現在の**ベースマップ全体の不透明度**を混同しないでください。ティント合成強度は色合成の高度な互換設定で、最終的な表面アルファは変えません。透過させるには、下記のサーフェスモードも確認します。

### グラデーション LUT

**グラデーションLUTを使用**を有効にし、横方向のランプでベース色をチャンネルごとに再マッピングします。LUT は sRGB でインポートし、**グラデーション強度**で適用量を決めます。まず HSVG とベースカラーを調整し、必要に応じて追加してください。

### 一部の領域だけ色補正する {#색조보정-범위-마스크}

**色調補正マスク → マスクを使用**を有効にしてテクスチャを指定します。白は補正、黒は元の色を保持、グレーはその中間です。パッキングしたマップはチャンネルを選び、必要に応じて反転します。

マスクには**独自のタイリング・オフセット**があります。ベースマップの変更が自動的にマスクも揃えるとは考えず、目や肌など目的の範囲に合っているか確認してください。

## サーフェスモードを選ぶ {#1-표면-모드부터-정합니다}

変換結果が目的どおりなら、最初にモードを変更する必要はありません。不透明・切り抜き・重なり方に合わせて選びます。**サーフェス描画**と**アルファ＆カットアウト**は同じモード値を編集します。

| 現在の表示 | 用途 | 深度と重なり |
|---|---|---|
| 不透明 (2000) | 通常の肌・衣装 | アルファ合成せず深度を記録 |
| カットアウト (2450) | 髪・まつ毛などの切り抜き | カットオフ未満を破棄し、残りは深度を記録 |
| 半透明 (2499) | アルファ合成しつつ手前の面を優先 | 深度を書き込み、カメラ深度の対象になるキュー。重なった全層を透かす用途とは区別 |
| 透明 (3000) | 重なった布・ガラスなど | 通常の色パスは深度を書かず透明の順序で合成。一般的なカメラ深度効果の対象ではない |

以前のアウトライン用深度付き透明モードは、現在は**半透明 (2499)**と表示されます。どちらの透明系モードもアウトラインを維持できます。変更時は描画状態・既定キュー・内部アウトラインバッファを整え、アルファカットオフとアウトラインの有効・外観値は保持します。

**半透明を選ぶだけですべての深度効果が保証されるわけではありません。** カメラ深度の準備、深度への記録、モジュール、実際のレンダーキューも確認してください。→ [深度ベースの効果](/guides/depth-effects)

### カメラ深度への記録

**他マテリアルの2Dシャドウ・SSAO・2Dリムが、この材質を遮蔽物として読むか**を決めます。オフでその寄与を除外します。通常の色表示と実際のライト影は別です。このチェックだけでカメラ深度テクスチャが準備されるわけではありません。

### 表示する面と両面処理 {#표시할-면}

**表示する面**で前面のみ・背面のみ・両面・両面とアウトライン反転を選びます。布やスカートは必要に応じて両面にし、裏側の照明がおかしい場合は**背面ライティング法線を反転**を確認します。

**高度なカラーバッファ → 両面デュアルパス**は裏面を先に別パスで描きます。折れた布の重なりに問題がある場合に確認し、追加パスが生じるため必要な材質に適用してください。

### 透明パーツの重なりがおかしい場合 {#머리카락이-볼을-뚫고-보일-때}

まず**半透明 (2499)**の深度優先と**透明 (3000)**の層間合成から目的に合うものを選びます。透明 (3000) の**高度なカラーバッファ**には**透明深度プリパス**があります。これは透明ソート・アウトライン用の処理で、カメラ深度への記録やライト影とは別の制御です。すべての重なり問題で一律に有効にする必要はありません。

## アルファマスクとカットアウト {#3-투명도를-텍스처로-따로-지정하기}

**アルファ＆カットアウト**のヘッダースイッチを確認し、別の透過テクスチャが必要なら**アルファマスクを使用**を有効にします。マップ・チャンネル・反転・強度の後、**アルファカットオフ**で境界を調整します。不透明モードはアルファを下げても半透明合成には変わりません。

**Alpha To Coverage**は MSAA に依存します。MSAA が無効なら、強度だけを上げ続けても期待した輪郭平滑化にはなりません。半透明・透明モードに表示される**カメラ深度アルファカットオフ**は、色のアルファと別に深度シルエットを調整します。

距離・フレネル・方向によるアルファは必要なときに折りたたみを開いて設定します。まずマスク・表面不透明度・カットオフを整えてください。

## マスター調整とパフォーマンス距離

**マスター調整**の明るさ・ティントの編集行は MLC 導入時に表示されます。MLC がない場合、その行を探す必要はありません。**パフォーマンス距離**はアドオンなしでも使え、遠距離でサンプル上限や一部の効果を減らします。遠くで効果が消える場合は距離・倍率も確認してください。→ [Ming Light Controller](/guides/ming-light-controller)

## 共通マップ {#4-공통-맵}

ノーマルマップは凹凸、オクルージョンマップは間接光の遮蔽を扱います。テクスチャだけでなくモジュールと強度も確認します。追加ノーマル・Matcap・エミッション・PBR は[ディテールマップ](/guides/detail-maps)へ進んでください。

**レンダー無効化**はマテリアル自体を描かない設定で、**全体のエフェクト**は表現効果の親スイッチです。材質が消えた場合と、個別の効果だけ反応しない場合を分けて確認します。
