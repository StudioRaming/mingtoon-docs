# 基本設定

**このドキュメントを読むと** サーフェスモードを正しく選択でき、ベース色と透明処理をマスターできます。

インスペクターの**基本設定**グループ — `基本サーフェス`・`サーフェス描画`・`共通マップ`を扱います。全項目リストは[基本設定リファレンス](/reference/basics)にあります。

## 1. サーフェスモードを最初に決めます {#1-표면-모드부터-정합니다}

ベースマップを入れる前に**サーフェスモード**を最初に決定してください。後で変更するとレンダーキューが移動して、深度ベースエフェクトが全体的にオフになることがあります。

| サーフェスモード | 用途 | 留意点 |
|---|---|---|
| **不透明** | 身体、衣類、ほとんどのパーツ | 深度が完全に記録されており、全てのエフェクトが動作します |
| **カットアウト** | 髪、睫毛、カットアウトするパーツ | `アルファカットオフ`0.3～0.6が無難。0に近いと半透明エッジが汚く残ります |
| **透明・アウトライン深度記録** | 半透明でありながら深度エフェクトも使う必要があるパーツ | 深度を記録するため2Dシャドウ・深度リム・インナー2Dエッジが全て動作します。**半透明が必要な場合はこちらを最初に検討してください** |
| **透明** | 完全な半透明 | 深度を記録しないため**深度ベースモジュールが全てオフになります** |

:::note[サーフェスモードが変わるもの]
レンダー状態・既定レンダーキュー・内部アウトラインバッファ状態が一緒に調整されます。**アルファカットオフとアウトラインON/OFF、外観値は保持**されるためモード変更しても作業は失われません。
:::

:::danger[深度モジュールが有効なのに透明モードなら]
インスペクターがサーフェスモード横に`深度記録モードが必要です`と通知します。`透明・アウトライン深度記録`に変更してください。
:::

### 髪が頬を突き抜けて見える時 {#머리카락이-볼을-뚫고-보일-때}

`サーフェス描画`の**`透明深度プリパス`**をオンにしてください。色を描く前に表面深度を最初に記録することで、頬の後ろにある髪の毛が頬の上に描画されるのを防ぎます。`プリパスアルファ基準`でどのアルファから記録するかを決定します。

### 表示面 {#표시할-면}

| 値 | 結果 |
|---|---|
| **前面のみ表示（標準）** | 既定値 |
| **背面のみ表示** | |
| **OFF（両面）** | スカート、布 |
| **Flip（両面+アウトライン反転）** | 両面でありながらアウトライン方向を反転する必要がある時 |

両面マテリアルで背面が異様に暗い場合は`背面ライティング法線反転`をオンにしてみてください。

## 2. ベース色 {#2-베이스-색}

1. **ベースマップ**にキャラクターテクスチャを入れます。
2. 色補正は**ベースマップHSVG**で行います。テクスチャを再度ベイクするより高速で、変換結果を元と比較するのも簡単です。
3. **ベースカラー**でティントを重ねる場合、3つの項目がセットです。

| 項目 | 役割 |
|---|---|
| ベースカラー | 重ねる色 |
| ティント合成モード | `Multiply`はマップのコントラストを保ったまま色だけを重ねます・`Normal`はマップを上書きして単色になります |
| ティント不透明度 | **0なら上の2つの項目が全て無視されます** |

:::note[色を変えたのに何も変わらなかったら]
最初にティント不透明度が0でないか確認してください。MingToonにはこのような「上位値が0なら下位が全て無視される」構造が複数箇所あります。リファレンス表の説明にどの値が上位かが書かれています。
:::

### 色調補正を一部部位にのみ {#색조보정-범위-마스크}

`ベースマップHSVG`は基本的にマテリアル全体に適用されます。**目だけ色を変えて顔はそのまま**というように部位を限定したい場合は、すぐ下にある`色調補正マスク`グループを使用します。

1. `マスクを使用`をオンにします。**デフォルト値はオフ**であり、オフのままなら補正はこれまでのように全体に適用されます。
2. `マスク`に黒白画像を入れます。**白色が補正適用、黒色が元のまま**であり、グレーはその比率だけ混ざります。
3. 複数のマスクを1枚にパッキングしている場合は、`マスクチャンネル`で読み込むチャンネルを選択します。
4. 補正する場所が黒で描かれたマスクであれば`マスク反転`をオンにします。

マスクはベースマップと同じUV・タイリングで読み込まれます。ベースマップをタイリングしている場合は、マスクも一緒に従います。

:::note[lilToonから変換したマテリアルの場合]
lilToonの色調補正マスクがこの場所に入ります。黒白マスクなのでチャンネルはRに固定され、元にマスクがなかった場合はこの行はオフのままで出力されます。 → [lilToon マテリアル変換](/workflow/liltoon-conversion)
:::

## 3. 不透明度を別のテクスチャで指定 {#3-투명도를-텍스처로-따로-지정하기}

ベースマップのアルファではなく別画像で不透明度を与えるには**アルファマスク**を使用します。

1. `アルファマスク使用`をオンにします。
2. `マスク画像`にグレースケール画像を入れます。
3. `マスクチャンネル`で読み込むチャンネルを選択します。複数のマスクを1枚にパッキングしてあればR/G/B/Aのいずれか、RGB明度を使うなら`Luma`。
4. 削除すべき場所が白で描かれたマスクなら`マスク反転`をオンにします。

`リマップ開始`・`リマップ終了`・`フェザー`でマスクのグレー範囲を再度広げることができ、`グラデーション`項目で方向性のあるフェードを作成できます。

:::caution[サーフェスモードが不透明の場合はオンにしても見えません]
アルファマスクはカットアウトまたは透明系でのみ結果が得られます。
:::

## 4. 共通マップ {#4-공통-맵}

シンプルモードにも公開されている頻繁に使うマップです。

- **ノーマルマップ** — 表面凹凸。`ノーマル強度`が0なら入れてもフラットで、1が元の強度です。ノーマルレイヤー01に相当するため、[ノーマルレイヤー](/guides/detail-maps#노멀-레이어)モジュールがオフなら反映されません。
- **オクルージョンマップ** — 間接光が当たりにくい箇所を暗くします。**直接光には影響がないため、**正面から強い照明を受けると効果がほぼ見えません。`オクルージョン強度`が0なら入れても変化はありません。

エミッション・PBR・MatCapは[詳細マップ](/guides/detail-maps)で扱います。
