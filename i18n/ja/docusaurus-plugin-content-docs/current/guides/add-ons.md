# 別売アドオンと連携

> このページは、ロックされたボタンを押してここへ来た方のためのものです。
> そのボタンが何なのか、なくても済むのかが一度に分かります。

## 結論から

MingToon本体は、アドオンが1つもなくてもインストールでき、コンパイルでき、動作します。

アドオンはデータを **作る** 側だけを担当します。そのデータを **読む** 側は常にMingToonシェーダーです。

そのため、外部ツールで作ったテクスチャや頂点カラーを入れれば同じ結果になります。

## 3つのツール

| ツール | 何を作るか | ない場合は何で代替するか |
|---|---|---|
| **Mask Maker** | シーンビューでマスクと頂点カラーを直接塗ります | 外部ツールで作ったマスクテクスチャをスロットに直接入れます |
| **Face SDF Studio** | 顔の影のSDFマップを作ります | すでに持っているSDFテクスチャをスロットに入れます |
| **Ming Light Controller** | VRChatの表情メニューとパラメーターを作ります | インスペクターで値を直接調整します |

- [Mask Maker連携](/guides/mask-maker) — `MM` ボタンと頂点ペイント
- [顔SDFとFace SDF Studio](/guides/face-sdf) — SDFマップの形式と接続
- [Ming Light Controllerを使う](/guides/ming-light-controller) — ゲーム内メニューの生成

## ロックされたボタンがそのまま表示されているのはなぜですか

ボタンをグレーにして消してしまうと、そういう機能があるという事実自体が見えなくなります。

そのためボタンはそのまま残し、押すとそのツールの文書へ案内します。

:::note[アセンブリ参照ではありません]
MingToonは3つのツールをコンパイル時に参照しません。実行中に名前で探します。
3つすべてがなくても、MingToonのインストール・コンパイル・動作に影響はありません。
:::

## インストールしたのにボタンがロックされたままです

1. Unityのコンパイルが終わるまで待ってから、インスペクターを開き直します。
2. Consoleにコンパイルエラーがないか確認します。
3. マテリアルを1つだけ選択しているか確認します。複数選ぶと押せなくなるボタンがあります。
4. そのスロットがそのツールの対象か確認します。対象でない場合は、ボタン自体が付きません。
