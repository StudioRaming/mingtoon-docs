# ライティングとシャドウ

> このページは**フォームシャドウ**をはじめて調整する方のためのものです。
> キャラクターの明暗の境界をセルアニメのように作ります。約 5 分かかります。

## これは何ですか

MingToon の影は 3 種類です。
3 つはそれぞれ別のスライダーを使うので、まず区別してください。

| 種類 | インスペクターのセクション | 何が作るか |
|---|---|---|
| フォームシャドウ | **フォームシャドウ** | キャラクター自身の凹凸。トゥーンルックの本体 |
| 投影影 | **影の投影** | 他のオブジェクトと自分自身が落とすリアルタイムの影 |
| デプスシャドウ | **デプスシャドウ** | 画面の深度で描く前髪の影 |

## いつ使いますか

- 変換直後に明暗がぼやけていて、境界をはっきりさせたいとき。
- 影が重なった場所が真っ黒に潰れるとき。
- 暗いワールドでキャラクターが丸ごと黒く沈むとき。

## 30 秒で試す

1. 変換したボディのマテリアルを選びます。
2. **フォームシャドウ**をオンにします。
3. **1段目の影のぼかし**を 0.01 に下げます。
4. **1段目の影の明るさ**を 0.7 に下げます。

明暗の境界が 1 本の線としてきれいに出れば成功です。
何も変わらない場合は[トラブルシューティング](/troubleshooting#shadow)へ進んでください。

## 使い方

### 1. フォームシャドウの境界から {#1-형태-그림자-경계--가장-먼저}

**1段目の影のぼかし**が、この製品でもっともよく触る値です。
0.001 に近ければセルアニメ、0.3 以上ならグラデーションになります。
この値ひとつでルックの性格を決めてから、次へ進んでください。

### 2. 影の色を 1 色にまとめる {#통합-그림자--겹칠-때-새까매지는-문제}

3 つの影が同じ場所で重なると、3 回暗くなります。
**シャドウカラー**セクションの**統合シャドウを使用**をオンにすると、1 色に収束します。
**統合シャドウ色**のアルファが適用量です。アルファが 0 なら変化はありません。

:::note[統合をオンにすると保たれるものと無視されるもの]
影の境界の形と[シャドウパターン](/guides/shadow-pattern)はそのまま保たれます。
層ごとの色・ブレンド・明るさの値は画面に反映されず、保存されるだけです。
:::

### 3. 部位ごとに違う影の色 {#그림자-컬러맵}

髪を赤く、肌を黄色く分けたい場合は**シャドウカラーマップ**をオンにします。
白が基準値なので、オンにした直後は結果が変わりません。
**カラーマップ適用量**を上げると、塗った色が現れます。

:::caution[統合シャドウがオフだと読み込みません]
統合シャドウがオフの状態では、シェーダーはこのテクスチャをまったく読みません。
層ごとにすでに色を持っていて、分配する対象がないためです。
:::

### 4. 投影影を整える {#4-그림자-투영-캐스트-섀도우}

**影の投影**セクションの**受信強度**が 0 だと、以下の値がすべて無視されます。
まずこの値を 1 にしてください。
影が柔らかく流れる場合は、**PBR / トゥーン合成**を 1 に上げてトゥーンバンドで切ります。

### 5. 暗いワールドへの対策 {#라이팅--어두운-씬에서-검게-뭉칠-때}

VRChat ワールドの照明はアバター製作者には制御できません。
**ライティング**セクションの**間接光の持ち上げ**が暗い面を持ち上げます。
0.1.11の既定値は**環境色の反映**1、**ベースカラー保持**0.1、**最終最小明るさ**0.2です。
色付き照明が強すぎる場合は**シーン照明色の影響**を下げて、白い照明に近づけられます。

## よく触る値

| インスペクターのラベル | 何が変わるか | 推奨の開始値 | 上げると / 下げると |
|---|---|---|---|
| **1段目の影のぼかし** | 明暗の境界のぼかし幅 | 0.01 | 上げると柔らかくぼけ、下げるとインクの線になります |
| **1段目の影の明るさ** | 1 段目の影の色の明るさ倍率 | 0.7 | 下げると暗くなり、1 ならベースの色のままです |
| **統合シャドウを使用** | 3 つの影を 1 色にまとめる | オン | オンにすると重なっても暗くならず、オフにすると層ごとの色が戻ります |
| **受信強度** | 投影影を受ける量 | 既定値のまま(1) | 0 だと投影影と以下の値がすべて消えます |
| **セルフシャドウ・キャスターバイアス** | 自分の影を表面から押し出す | 0.02 | 上げるとまだらが消え、上げすぎると接地影が浮きます |
| **間接光の持ち上げ** | 環境光が暗い面を持ち上げる量 | 既定値のまま(1) | 上げると暗いワールドでも潰れにくく、0 だと黒く沈みます |
| **境界の幅** | 明暗の境界に載せる色帯の幅 | 0.5 | 上げると帯が太くなり、0 だと帯がまったく描かれません |

## よくある問題

### 逆光で体にキャラクターの形の影が重なるとき {#역광에서-몸에-캐릭터-모양-그림자가-겹칠-때}

光源に背を向けた面に、自分のシルエットがもう一度重なって見える症状です。
**影の投影**の**逆光シルエット抑制**をオンにしてください。
消え始める地点は**キャスト抑制オフセット**で合わせます。

### デプスシャドウと色がちぐはぐなとき {#2d-그림자와-색이-따로-놀-때}

前髪の影だけ色が浮いて見える症状です。
**影の投影**の**デプスシャドウと統合**をオンにしてください。
2 つの影が同じ色を使い、重なった場所も 2 回暗くなりません。

### 顔に影がかすめて通るとき {#얼굴의-스치는-그림자}

顔は体とは別のルールで調整する必要があります。
[キャラクター表現](/guides/character#4단계-앞머리-그림자)で**影の方式**を選んでください。
さらに悪化する場合は[トラブルシューティング](/troubleshooting#face)をご覧ください。
