# ライティングとシャドウ

**このドキュメントを読むと** 3種類のシャドウを区別でき、どの順序で調整すべきかが分かります。

インスペクターの**ライティングとシャドウ**グループ — `ライティング`・`影の色`・`フォームシャドウ`・`影投影`を扱います。全項目リストは[ライティングとシャドウリファレンス](/reference/light-and-shadow)にあります。

## まず：シャドウは3種類です

MingToonで「シャドウ」と呼ぶものは異なる3つです。これを区別できないと見当違いのスライダーを触り続けることになります。

| 種類 | インスペクターセクション | 何が作るのか |
|---|---|---|
| **フォームシャドウ** | フォームシャドウ | 表面法線と光源方向。キャラクター自身の曲がりで生じる明暗。**トゥーンルックの本体** |
| **キャストシャドウ** | 影投影 | Unityのリアルタイムシャドウマップ。他の物体と自分自身が落とすシャドウ |
| **2Dシャドウ** | 2Dシャドウ（[深度ベースエフェクト](/guides/depth-effects)） | カメラ深度テクスチャ。スクリーン空間で計算 |

## 作業順序

1. フォームシャドウ境界 → 2. 影の色 → 3. 2次段階 → 4. 影投影 → 5. 顔の例外 → 6. 境界装飾

---

## 1. フォームシャドウ境界 — 最初に {#1-형태-그림자-경계--가장-먼저}

**`1次シャドウ柔らかさ`がMingToonで最も頻繁に調整する値です。** ここでルックの性格が決まります。

| 値 | 結果 |
|---|---|
| 0.001近く | セルアニメーションのようにはっきり落ちる境界 |
| 0.05～0.15 | ほんのり柔らかいイラスト感 |
| 0.3以上 | 柔らかいグラデーション |

最初にこの値1つだけ動かして目的の性格を決定してから、残りに進んでください。`クイック設定`の`1次シャドウ柔らかさ`が同じ値です。

## 2. 影の色 {#2-그림자-색상}

`1次シャドウ明るさ`を下げると暗くなります。ただし：

:::caution[`影の色`セクションがオフなら]
`1次シャドウ明るさ`は反映されません。キャストシャドウも同じく、このセクションがオフなら単に暗くなるだけで`キャストシャドウ明るさ`は無視されます。
:::

### 統合シャドウ — 重なると真っ黒になる問題 {#통합-그림자--겹칠-때-새까매지는-문제}

フォーム・キャスト・2Dシャドウが同じ場所に重なると3回暗くなって真っ黒に潰れます。`影の色`内の**`統合シャドウ使用`**をオンにするとこの3つが**同じ色と調子に収束**してこの問題がなくなります。

:::note[統合モードで保持されるもの / 無視されるもの]
- **保持** — シャドウ境界の形態設定、シャドウパターン（スクリーントーン）
- **無視** — 個別シャドウの色・ブレンド・明るさコントロール（値自体は保存されるのでオフにすると戻ります）

`統合シャドウ色`の**アルファが適用量**です。アルファが0なら色を選んでもシャドウはベース色のままです。
:::

:::caution[オフにするとルックが一度に変わることがあります]
統合シャドウをオフにすると、各層に**保存されていた色がそのまま戻ります。** 統合で作業している間に個別の色を触っていなければ、オフにした瞬間に以前の値が一斉に現れます。
:::

### 部位ごとに違う影色 — シャドウカラーマップ {#그림자-컬러맵}

統合シャドウは色がひとつです。髪は赤み、肌は黄みのように**部位ごとに違う影色**が必要なら `シャドウカラーマップ` をオンにしてください。統合シャドウの1色を UV マップで分布させます。

- **白が基準値です。** 白い部分は統合シャドウの色そのままで出て、塗った部分だけがその色で乗算されます。オンにしただけでは結果は変わりません。
- `カラーマップ適用量` が0なら統合色ひとつだけ、1ならテクスチャの色をそのまま乗算します。テクスチャHSVGで色相・彩度・明度・ガンマを個別に調整できます。

:::note[統合シャドウ専用です]
統合シャドウがオフの場合、シェーダーはこのテクスチャを**まったく読みません。** レイヤー別シャドウモードは層ごとに色を持っているため分布させる対象がなく、取得コストもかかりません。
:::

:::tip[ハイライトマスクが残っているなら]
このマップと併せてマットキャップやスペキュラーのマスクとしても使うことをおすすめします。色の分布と光沢を分けて調整できます。
:::

## 3. 2次シャドウ — 3段セルシェーディング {#3-2차-그림자--3단-셀-음영}

`2次シャドウ使用`をオンにすると最も暗い側にもう1段階が生じます。

- `2次シャドウ明るさ`は**1次より低く**しておくべき段階が区別して見えます。
- `2次シャドウ柔らかさ`を1次より**狭く**しておくと内側の段階がはっきりします。

## 4. 影投影（キャストシャドウ） {#4-그림자-투영-캐스트-섀도우}

リアルタイムシャドウはトゥーンルックで最も問題を起こしやすい部分です。`キャストシャドウ受信`グループから見ます。

`受信強度`が**0ならキャストシャドウが完全に消え、**下の明るさ・ブレンド・間接光補正も結果に表れません。

### シャドウがトゥーンらしくない時

`PBR/トゥーン混合`を1に上げるとUnity既定の柔らかい減衰の代わりにトゥーンバンドでぴったり切れます。バンド幅は`キャストトゥーンバンド柔らかさ`が決定します。

### ムラムラなシャドウ {#얼룩덜룩한-그림자}

衣装の皺や身体にノイズのようなムラが出たら：

1. `セルフキャストシャドウ抑制`をオンにします。
2. `セルフシャドウキャスターバイアス`を**0.01～0.03**の間で調整します。

:::danger[バイアスを上げすぎると]
ムラは消えますが接地シャドウが浮き、薄い部分のシャドウが切れます。少しずつ上げてください。
:::

### 顔の掠めるシャドウ {#얼굴의-스치는-그림자}

0.1.7で動作していなかった`顔均一キャスト`と`顔キャスト安定化`は削除されました。顔の影は次の順で調整してください。

1. フェイスシェーディングの`影の方式`でリアルタイムシャドウ、または`柔らかい2Dシャドウ（顔補正）`を選びます。
2. 2Dアシストを使わない場合だけ`実シャドウキャスターオフセット`を調整します。アシストがOFFでない場合、この行は無効表示になります。
3. 顔プロキシ中心・ノーマル整列・Face SDFの遷移を先に合わせます。

### シャドウ境界がはしご状に粗い時 {#그림자-경계가-계단처럼-각질-때}

`投影フェザー`グループの`投影フェザー使用`をオンにし、`投影フェザー半径`・`投影フェザー強度`を調整します。半径範囲は実際の品質上限と同じ0～48pxです。Fast・Smoothは最大8px、Premiumは20px、Soft Bilinearは48pxまで有効なので、`キャスト境界フェザー品質`も一緒に確認してください。

:::note[フェザーは無い情報は復旧できません]
低解像度のシャドウマップに元々なかったディテールは柔らかくしても戻りません。最初に光源のシャドウマップ解像度とbias/normal bias、カスケードを確認してください。
:::

### シーンごとにシャドウが強すぎたり弱すぎたり

`キャスト間接光補正`を上げると環境光が明るい場所でキャストシャドウが薄れます。室内・屋外を行き来するアバターで照明差を自然に吸収します。

### 逆光で身体にキャラクター型シャドウが重なる時 {#역광에서-몸에-캐릭터-모양-그림자가-겹칠-때}

`逆光シルエット抑制`をオンにすると光源を向いた面にはキャストシャドウを描画しません。

### 2Dシャドウと色が別々に見える時 {#2d-그림자와-색이-따로-놀-때}

`2Dシャドウと統合`をオンにすると2Dシャドウがキャストシャドウと同じ色を使い、重なる場所で2回暗くなるのも防ぎます。

## 5. 顔は別々に調整します

→ [キャラクター表現](/guides/character)

## 6. 境界装飾 — 最後に {#6-경계-장식--마지막에}

明暗境界に色帯を重ねる演出です。ルックが全て決まった後にしてください。

1. `シャドウ境界使用`をオンにします。
2. `境界幅`を上げます。0なら下の項目はすべて無視されます。
3. `境界ブラー`で、明るい側から強いバンドまで満ちる長さを合わせます。
4. `境界強度`で不透明度を合わせます。

キャスト境界は明るい側から滑らかに満ち、シャドウコア直前で最も強くなってからコアで消えます。フォーム・キャスト・2Dシャドウ・SSAOの合成後に最後のシャドウレイヤーとして描かれるため、重なる部分でも色が埋もれません。統合シャドウ内部を横切るオクルーダー輪郭は消去され、空の縁取りのように浮きません。

:::tip[皮膚と髪が1つのマテリアルに混在してたら]
`境界ベースマップ混合`を上げてください。0なら単色の境界、1ならベースマップ色と混ざって部位ごとに異なる境界色が出ます。
:::

:::caution[境界が見えない条件]
`影の色`セクションがオンになっていて、フォームシャドウまたは投影シャドウのどちらかが実際に動作している必要があります。境界はすべてのシャドウ合成の最後に描画されます。
:::

## ライティング — 暗いシーンで真っ黒に潰れる時 {#라이팅--어두운-씬에서-검게-뭉칠-때}

VRChatワールドは照明をアバタークリエイターが制御できません。`ライティング`セクションの下の項目が防御線です。

| 項目 | 機能 |
|---|---|
| `ベース色保持` <br />（シンプルモード：ベース色保存） | 照明が暗くてもベースマップ色をどれだけ元に近く保つか。**照明を予測できない環境では高く** |
| `シーンライト色影響` <br />（シンプルモード：照明色反映） | 0なら何色の照明でも白い照明のように見えます。明度ではなく**色だけを**扱います |
| `間接光補正` | 環境光の明度だけ分フォームシャドウを持ち上げます。フォームシャドウがオンの時のみ計算されます |
| `VRC Light Volumes` | Built-inのVRChatアバターでボリューム間接光・スペキュラー・ポイントシャドウとバイアスを使用します。アップロード時に自動有効化され、ボリュームのない環境ではUnity Probeへフォールバックします |
| `最終最小明るさ` | いくら暗くてもこれ以下に下がりません |
| `最終最大明るさ` | いくら明るくてもこれ以上に上がりません。過度露光ワールド対策 |

`明るい面の明るさ`は光を受ける面全体の乗数です。1が基準で、上げると明るい面が白色に潰れやすくなります。

### 追加光源 {#추가-광원}

ポイント/スポットライトへの反応は別項目です。

- `追加光源受信`・`追加光源強度`（シンプルモード）
- `追加光源PBR/トゥーン混合`・`追加光源トゥーン閾値`・`追加光源トゥーン柔らかさ`（全設定）
- `追加光源最大明るさ` — ベースカラー倍率ではなく、追加光結果の絶対HDRピーク上限

`リム・追加光にも上限`をオンにすると、同じ値がディレクショナル主光源と追加光源の両方からリム、バックライト、フロントライト、透過光、マットキャップ、エミッション、グリッターへ届くシーンライト強度も制限します。1なら強度1まで、3なら強度3まで反映します。オフにすると最終加算上限と効果入力上限の両方が解除されます。

主光と同じトーンを保つには追加光源側のトゥーン閾値も一緒に合わせてください。絶対上限は暗いマテリアルのスペキュラーをベースカラーで押し潰さず、複数ライトの過露光を制限します。

### マスター調整とエッジリム {#마스터-조정과-가장자리-림}

`マスター調整`は明るい面・シャドウ・最終出力の色・明るさ・彩度を一箇所で補正します。`エッジリム`マスターは2Dリム・フレネルリム・バックライトなどシルエット系の強度、専用カラー、HDR上限をまとめて調整します。個別リム設定は[リム](/guides/rim)を参照してください。
