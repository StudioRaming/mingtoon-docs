# メッシュ UV ベイク

**この文書を読むと** シェーダー値だけでは解決できない 3 つの問題をメッシュにデータを焼き込むことで解決できます。

MingToon は 3 つの UV チャンネルを使用しています。すべて**任意**ですが、それぞれが特定の問題の唯一の解決策です。

| チャンネル | 解決する問題 | ない場合 |
|---|---|---|
| **UV8** | 角ばった部分でアウトラインが切れる | `法線ソース`を`メッシュ法線`だけで使用できます |
| **UV7** | 顔 SDF にランタイム スクリプトが必要 | スクリプトを削除するデプロイで顔シェーディングが不安定 |
| **UV4** | 高さに基づいた色グラデーション | キャラクター高さグラデーション自体が動作しない |

:::tip[変換時に一度に焼き込むのが最も便利です]
`MingToon マネージャー`の**1・変換**段階で`同時にベイクするメッシュチャンネル`をチェックすると、変換直後に自動的に焼き込みます。マテリアル変換が完了した後に実行されるため、**顔の法線ベイカーがどのサブメッシュが顔かを認識できます。** → [MingToon マネージャー](/workflow/character-manager#함께-구울-메쉬-채널)
:::

:::caution[焼き込まれた UV はレンダラーごとに 1 つの統合メッシュ資産に一緒に保存されます]
チャンネルを個別に複数回焼き込んでも、最終的には同じコピーに積み重ねられます。
:::

## アウトライン スムーズ ノーマル (UV8) {#아웃라인-스무스-노멀-uv8}

**何をするか** — 位置が同じ頂点の法線を平均化して UV8 に焼き込みます。ハード エッジで分割された法線が 1 つに統合されるため、ハル を押し出すときに線が広がりません。

UV8.w には**線の太さの比率値**も含まれています — 長い面は太く、頂点は細く。

### 手順

1. `MingToon マネージャー`の**3・詳細設定**の`アウトライン平滑ノーマル UV8`グループを開きます。
2. UV8 を既に使用しているメッシュがある場合は、`既存のUV8を上書き`をオンにします。
3. `キャラクター全体のUV8をベイク`をクリックします。
完了メッセージ: `アウトライン平滑ノーマル ベイクが完了しました。ハル法線ソースは既に UV8TS がデフォルト値であるため、変更する必要はありません。`

:::tip[マテリアル側は変更する必要はありません]
`法線ソース`の**デフォルト値は既に`UV8TS`** です。焼き込むだけで、角ばった部分で線が切れなくなります。
:::

:::danger[接線のないメッシュは拒否されます]
ベイク が失敗した場合は、モデル インポーターで接線を生成するように設定し、再度インポートしてください。
:::

:::note[UV8.w を使用するには]
`圧力ソース`を`OutlineNormalUV8`に設定すると、焼き込まれた太さの比率値がそのまま線の太さに反映されます。 → [アウトライン](/guides/outline#선-굵기를-부위마다-다르게)
:::

## 顔フロントビュー ノーマル (UV7) {#얼굴-프론트뷰-노멀-uv7}

**何をするか** — 現在のシーンの**フロントビューを複製メッシュの TEXCOORD6 (Unity UV7) に投影**します。

これを焼き込んでおくと、シェーダーだけで 4 方向の顔 SDF が動作します。**ランタイム法線プロバイダー コンポーネントが不要になるため**、スクリプトを削除する必要がある VRChat アップロードと Warudo モッドで顔シェーディングが安定して機能します。

### 手順

1. `MingToon マネージャー`の**ルック / 顔** → `顔 SDF UV の準備 (WARUDO / VRC)`。
2. `フロントビュー SDF TEXCOORD6 (Unity UV7) ベイカーを開く`。
3. シーン ビュー カメラで**顔を正面から**捉えます。この時点が焼き込まれます。
4. 焼き込みます。

完了ログ: `MingToon 顔照明法線を焼き込みました: レンダラー N 個、顔頂点 M 個。元の形状法線は変わりません。`

**元の形状法線は変わりません。** 照明用法線のみ別チャンネルに入ります。

### 元に戻す

`元のメッシュを復元`をクリックします。`MingToon 元のメッシュを復元しました: レンダラー N 個。`

:::danger[元のモデルを移動または再度インポートする前に、まず復元してください]
記録された元のメッシュが見つからない場合、このような警告が出ます。

> `'{mesh}' に記録された元のメッシュが見つからないため、レンダラー '{name}' は現在割り当てられているメッシュから焼き込みます。この状態では '元のメッシュを復元' が元のモデルまで戻すことはできません。`

この状態で続行すると、復元パスが切断されます。
:::

復元に失敗した場合は、`レンダラー N 個は記録された元のメッシュがプロジェクトにないため復元できませんでした。`が表示され、元のモデルを再度インポートするか、メッシュを直接割り当てる必要があります。

## キャラクター高さ (UV4) {#캐릭터-높이-uv4}

**何をするか** — キャラクター**全体**のルート基準の高さをすべてのメッシュの UV4.x に焼き込みます。

メッシュ単位ではなく**キャラクター単位**であることが重要です。上部と下部が別のメッシュであっても、1 つの連続した高さ軸を共有します。

### 手順 (MingToon マネージャーで)

1. `MingToon マネージャー`の`キャラクター高さ UV4`グループ。
2. ステータスを確認します。
   - `全メッシュにUV4高さをベイクできます。` → そのまま進める
   - `一部のメッシュでUV4が使用中です。` → `既存のUV4を上書き`を判断
3. `キャラクター全体のUV4をベイク`。
4. `子の全MingToonマテリアルに一括適用`でマテリアルの高さ設定を揃えます。

### 手順 (マテリアル インスペクターから)

マテリアル側にも同じ機能があります。`UV4 高さベイク`グループの`選択マテリアルのキャラクターUV4をベイク`。

選択したマテリアルを使用するキャラクターをシーンで見つけて焼き込みます。**すべてのマテリアルを選択して押しても、キャラクターごとに 1 回だけ実行**されます。

:::caution[シーンにキャラクターがない場合は失敗します]
`選択したマテリアルを使用するレンダラーが開いているシーンで見つかりません。` → キャラクターがあるシーンまたはプリファブを開いて再度試してください。
:::

→ [キャラクター高さ グラデーション の使用方法](/guides/character#캐릭터-높이-그라데이션)

## どのチャンネルを焼き込むかの判定

| 状況 | 必要なチャンネル |
|---|---|
| アウトラインが角ばった部分で切れている | **UV8** |
| VRChat / Warudo にアップロードするアバターの顔が安定している | **UV7** |
| 足元を暗くしたり、衣服の裾に色を付けたい | **UV4** |
| 上記のいずれにも該当しない | 焼き込む必要はありません |

焼き込まなくても MingToon は正常に動作します。各チャンネルは**対応する機能を使用するときのみ**必要です。
