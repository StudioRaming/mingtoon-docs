# メッシュUVベイク

> このページは **メッシュUVベイク** を初めて行う方のためのものです。
> アウトラインが角張った箇所で途切れる問題を直します。5分ほどかかります。

## これは何ですか

メッシュには、色を乗せるときに使う座標の枠がいくつもあります。
MingToonはそのうち3つの枠に、シェーダーが読む値をあらかじめ書き込みます。
書き込む作業をベイクと呼びます。ベイクしたあとは値を変更できません。

## どの枠が必要ですか

| 状況 | 必要な枠 |
|---|---|
| アウトラインがハードエッジで割れる | UV8 |
| キャラクター高さグラデーションを使う | UV4 |
| 顔SDFが正面投影座標を要求する | UV7 |
| 顔プロキシを編集しながら確認するだけ | ベイクしません |
| VRChatにアップロードするときに顔を軽くしたい | ベイクしません。アップロードが自動で行います |

ほとんどのユーザーはUV8を1つベイクするだけで十分です。

:::danger[すでに使われている枠を上書きしないでください]
他のシェーダーやモデル制作者がこの枠に値を入れている場合があります。
MingToonマネージャーの **UVチャンネルの使用状況** がUV4・UV7・UV8を表示します。
:::

## 30秒でオンにしてみる

1. MingToonマネージャーを選択します。
2. **アウトライン平滑ノーマル UV8** を展開します。
3. **UV8だけを個別にベイク** を押します。

角張った部分で途切れていたアウトラインがつながれば成功です。
何も変わらない場合は [ベイクのトラブルシューティング](/troubleshooting#bake) へ進んでください。

## よく触る値

| インスペクターのラベル | 何が変わるか | 推奨する初期値 | 上げると / 下げると |
|---|---|---|---|
| **既存のUV8を上書き** | 値が入っている枠を再度使うか | オフ | オンにすると再ベイクでき、オフだとそのメッシュでステップが失敗します |
| **ノーマルを編集したモデル用に計算** | アウトラインの方向を面から再計算する | 既定値のまま（オフ） | オンにすると線がメッシュに沿い、オフだと転写されたノーマルに従います |
| **アウトライン平滑ノーマル (UV8)** | 変換時にUV8も一緒にベイクするか | オン | オフにすると角張った箇所で線が割れます |
| **キャラクター高さグラデーション (UV4)** | 変換時にUV4も一緒にベイクするか | オフ | オフにすると高さグラデーションも一緒にオフになります |
| **顔フロントビューノーマル (UV7) — 通常はオフ** | 変換時に顔をあらかじめベイクするか | 既定値のまま（オフ） | オンにするとプロキシを触っても画面が変わらなくなります |
| **使用中のUVチャンネルを上書き** | 変換時に既存の枠を上書きするか | オフ | オンにすると再変換が通り、その枠を使っていた機能は値を失います |

## アウトライン平滑ノーマル (UV8) {#아웃라인-스무스-노멀-uv8}

同じ位置にある頂点どうしの方向を平均してUV8に書き込みます。
**ノーマルソース** の既定値がすでに `UV8TS` なので、ベイクするだけで済みます。
UV8の4番目の値には、線の太さのコントラスト用の値も一緒に入ります。

### ベイクの手順

1. MingToonマネージャーで **アウトライン平滑ノーマル UV8** を開きます。
2. 状態パネルで対象と既存のUV8を確認します。
3. 必要なら **ノーマルを編集したモデル用に計算** をオンにします。
4. 所有権を確認できた場合にだけ **既存のUV8を上書き** をオンにします。
5. **UV8だけを個別にベイク** を押します。

**圧力ソース** を `OutlineNormalUV8` にしておくと、太さのコントラストも一緒に使われます。
→ [圧力ソースを選ぶ](/guides/outline#압력-소스-고르기)

:::caution[タンジェントがないメッシュはスキップされます]
タンジェント（ノーマルマップの方向を計算するメッシュデータ。モデルのインポート設定でオンにします）が必要です。
ないメッシュだけが除外され、他のステップはそのまま進みます。オンにしてから再実行してください。
:::

### ノーマルを編集したモデル用に計算 {#노멀을-편집한-모델용으로-계산}

髪やスカートは、球・円柱からノーマルを転写している場合が多くあります。
そのままベイクすると、線はメッシュではなく転写元の球に沿ってしまいます。

この項目をオンにすると、メッシュの面から方向を再計算します。
シェーディングはそのままに、アウトラインだけがメッシュに沿います。
既定値はオフなので、すでにベイク済みのキャラクターの線は変わりません。

## 顔フロントビューノーマル (UV7) {#얼굴-프론트뷰-노멀-uv7}

顔プロキシのノーマルは、編集中にシェーダーがリアルタイムで計算します。
**プロキシ形状** ・中心・半径・軸を変えると、ベイクしなくてもすぐに反映されます。

**プロキシ形状** の最初の項目であり既定値でもあるのは `平面` です。
`球 (実験的)` ・ `円柱 (実験的)` ・ `カプセル (実験的)` はまだ実験段階です。
まず `平面` で合わせてみて、足りないときにだけ残りを試してください。

### VRChatにアップロードするとき

アップロード中、MingToonは一時的なコピーでのみ顔ノーマルを処理します。
シーンの元のメッシュとマテリアルはそのまま残します。
UV7がすでに埋まっている、または顔領域マスクを使うレンダラーはスキップします。

プロキシを動かしても画面が変わらない場合は、以前のベイクが残っています。
MingToonマネージャーの **ベイク顔ノーマルを解除** を押してください。
保存値の使用をオフにし、顔マップ座標を戻します。メッシュには触れません。

## キャラクター高さ (UV4) {#캐릭터-높이-uv4}

キャラクターのルートを基準にした高さを、すべてのメッシュのUV4に書き込みます。
上衣と下衣が別のメッシュでも、1つの連続した軸を共有します。

1. MingToonマネージャーで **キャラクター高さグラデーション (UV4)** をオンにします。
2. 既存のUV4と対象のレンダラーを確認します。
3. 所有権を確認できた場合にだけ上書きをオンにします。
4. ベイクを実行します。

:::note[UV4をベイクしないとグラデーションはオフになります]
ベイクしていないUV4の上でオンにしておくと、オンに見えたまま何も起こりません。
そのためチェックを外すと、高さグラデーションも一緒にオフになります。
:::

## 変換するときに一度にベイクする

MingToonマネージャーのステップ1の **同時にベイクするメッシュチャンネル** であらかじめ選べます。
チェックした枠は、マテリアル変換が終わった直後に自動でベイクされます。
**顔フロントビューノーマル (UV7) — 通常はオフ** は名前のとおりオフにしておいてください。

すでにベイク済みのキャラクターを再変換する場合は、
**使用中のUVチャンネルを上書き** をオンにしないとステップが失敗します。
