# テクスチャスロット共通UI

**用途:** MingToonのベースマップ、マスク、ノーマル、MatCap、エミッションで共通する調整順を確認します。マテリアルを選び、まずマップと**Tiling / Offset**を確認し、必要な場合だけ**UV Router**と詳細設定を開きます。

テクスチャスロットは次の順で読みます。

- マップ行：テクスチャ、対応時のティント、**Tiling / Offset**
- 任意の**UV Router**
- 詳細：チャンネル、反転、HSVG、ティントの順序
- 任意のマスク変換、UV Router、チャンネル、リマップ、フェザー、グラデーション

## テクスチャ詳細設定

### チャンネルソース {#채널-소스}

マップが読むチャンネルを選びます。

| 値 | 結果 |
|---|---|
| **Full RGBA** | 色全体を読みます |
| **R / G / B / A** | 1チャンネルだけ読みます |

1枚のテクスチャに複数の値をパックするときに使います。マスクスロットには**Luminance**もあり、RGBの明るさをマスク値にします。

### ソース色を反転

読み取った値を反転します。黒い部分に効果を出したい場合や、消したい場所を白で描いたマスクを再利用する場合に有効にします。

### HSVG {#hsvg}

| 項目 | 範囲 | 中立値 | 効果 |
|---|---:|---:|---|
| **Hue** | -1～1 | 0 | 色相を回転します |
| **Saturation** | 0～2 | 1 | 彩度を下げたり上げたりします |
| **Value** | 0～2 | 1 | 暗くしたり明るくしたりします |
| **Gamma** | 0.1～3 | 1 | 中間調のコントラストを変えます |

中立値では元の色を保ちます。例えば目のテクスチャは**Hue**だけを変えると、ファイルを焼き直さずに色を試せます。結果が想定外ならHSVGを0/1/1/1に戻して元と比較してください。

ティントを持つスロットの**Apply Tint After HSVG**は、HSVGの前後どちらでティントを掛けるかを選びます。同じティントでも順序で結果が変わります。

## タイリング、オフセット、UV Router {#uv-router}

マップ行の直下にある**Tiling / Offset**はそのマップ専用です。マスクにも別のTiling / Offsetがあるため、両者は連動しません。表面マップを30回繰り返し、マスクはUV全体に1回だけ置く構成もできます。

**UV Router**があるスロットでは次を設定できます。

- **UV Source:** UV0、UV1、UV2、UV3
- **Scroll:** X/Y移動
- **Rotation / Rotation Speed:** UIでは度数表示
- **Atlas:** グリッド最小1、フレーム数最小0、FPS、フレームスケール、中心ブレンド
- **Decal:** **Is Decal**を有効にしてから左右・コピー・ミラー項目が有効になります。**Should Copy**がオフなら**Flip Copy**は無効です。

このグループがない場合、そのシェーダースロットにはUV Routerプロパティがありません。通常のUV0スロットで詳細行が見えないことを、テクスチャが欠けた状態と判断しないでください。

## マスク詳細設定 {#마스크-세부-설정}

### マスクリマップの使い方 {#리맵을-쓰는-법}

マスクは効果を適用する範囲を制限します。マスク行にもマップ固有のTiling / Offsetと任意のUV Routerがあります。

| 項目 | 効果 |
|---|---|
| **Mask Channel** | R/G/B/Aまたは**Luminance**を選びます |
| **Invert** | 黒白を反転します |
| **Remap Start / End** | グレー入力の範囲を再マップします |
| **Boundary Blur** | 境界の遷移を滑らかにします |
| **Gradient Mode** | グラデーションを有効化。Angle、Start、End、Center(UV)は有効時だけ表示 |
| **Alpha Scale / Offset / Blend Mode** | 対応するアルファマスクの最終値を合成します |

まず**Start**を上げて範囲が狭くなることを確認し、**End**を下げて遷移を鋭くします。両方を同じにするとハードな境界に近づきます。Gradient Modeがオフなら方向と中心の行が隠れるのは正常です。アルファのブレンドモードは**Multiply、Replace、Add、Subtract**です。

## レイヤースロット {#레이어-수}

テクスチャスタックは最大10、ノーマルとMatCapはそれぞれ最大5レイヤーです。**Active Layers**が0ならそのモジュールは計算されません。マップが見えないときは、まずスロット番号までレイヤー数が達しているか確認します。最初のレイヤーヘッダーは既定で開き、**Up / Down**で順序を変えます。

インスペクターのポップアップは最初2レイヤーまで表示する場合があります。マテリアルがすでに3つ以上を使っている場合、または**Show up to N layers**を押した場合は、そのモジュールの実際の最大数まで広がります。この表示制限はシェーダーの最大数を変更しません。

:::caution[レイヤー順で結果が変わります]
Multiplyの上にNormalを置く場合と逆の場合では合成結果が異なります。順序を変えた後は各マップと不透明度・強度を確認してください。
:::

## 値のコピー / 貼り付け {#값-복사--붙여넣기}

プロパティまたはレイヤーヘッダーを右クリックすると、値・レイヤー・タブ単位のコピー項目が出ます。貼り付けは互換性のあるプロパティだけを書き込み、1つのUndo単位になります。MatCapレイヤーをノーマルに、色を数値スライダーに貼り付けることはできず、互換性のない項目はスキップされます。

適用数とスキップ数はConsoleログで確認できます。メニューや行が見えない場合は、検索で隠れていないか、そのスロットにプロパティがあるか、選択したレイヤー種別が一致しているかを確認します。

## 値が見えないとき

1. マップのオブジェクト欄にテクスチャが設定されているか確認します。
2. Active Layersとスロットの強度・不透明度が0でないか確認します。
3. マップとマスクのTiling / Offsetが意図したUVと合っているか確認します。
4. UV Router、Atlas、Decalのゲートを確認します。
5. HSVGを中立値に戻し、マスクで実際に塗ったチャンネルと比較します。
