# テクスチャスロット共通UI

**この文書を読むと** MingToonの**すべての**テクスチャスロットに共通して付く調整項目を一度に理解できます。

ベースマップ、ノーマル、マスク、MatCap、エミッション、レイヤー — 名前は異なっても**下の構造は同じ**です。一度学べば、残りのスロットは自動的に読めます。

```text
テクスチャスロット
├─ テクスチャ詳細設定      ← チャンネルソース・反転・HSVG・ティント順序
└─ マスク詳細設定          ← マスクマップ・チャンネル・反転・リマップ・フェザー・グラデーション
```

---

## テクスチャ詳細設定

### チャンネルソース {#채널-소스}

このテクスチャから**どのチャンネルを読むか**を決めます。

| 値 | 読むもの |
|---|---|
| `RGBA 全体` | カラーそのまま |
| `R` / `G` / `B` / `A` | 対応するチャンネルのみ |

複数のマスクを1つのテクスチャにパックした場合に使います。マスクスロット側には`RGBA 全体（輝度）`オプションが追加で用意されており、RGBの明度を使います。

### ソース色を反転

読み込んだ値の黒白を反転させます。**削除すべき場所が白色で描かれたマスク**をそのまま使う場合に使用します。

### HSVG {#hsvg}

| 項目 | 既定値 |
|---|---|
| `色相` | 0 |
| `彩度` | 1 |
| `明度` | 1 |
| `ガンマ` | 1 |

既定値から外れた値だけが結果に影響を与えます。インスペクターは各項目の既定値をツールヒントで知らせ、「既定のHSVGは色相0、彩度1、明度1、ガンマ1です。」というガイダンスも表示します。

:::tip[テクスチャを焼き直す代わりに]
色を少し変えたいときは、テクスチャを編集するよりHSVGを使う方がはるかに速く、元と比較するのも簡単です。
:::

### HSVGの後にティントを適用

ティント色を**HSVG補正の前に**掛けるか**後に**掛けるかを決めます。同じ値でも順序によって結果が変わります。

---

## マスク詳細設定 {#마스크-세부-설정}

適用範囲を制限します。ほとんどのモジュールが専用マスクを持つことができます。

| 項目 | 機能 |
|---|---|
| `マスクマップ` | グレースケール画像 |
| `マスクチャンネル` | R / G / B / A / RGBA 全体（輝度） |
| `反転` | 黒白を反転 |
| `リマップ開始` · `リマップ終了` | マスクのグレースケール範囲を再展開 |
| `境界のぼかし` | エッジのぼかし幅 |

### リマップの使い方 {#리맵을-쓰는-법}

マスクがぼやけて描かれていたり、範囲が広すぎる場合に使います。

- `リマップ開始`を上げる → 適用範囲が**狭くなります**
- `リマップ終了`を下げる → エッジが**急峻になります**
- **両方を同じにすると、エッジが完全にカリカリになります**（バイナリマスク）

### グラデーション

マスク画像を使わずに方向性のあるフェードを作ります。

| 項目 | 機能 |
|---|---|
| `グラデーションモード` | 線形 / 放射状など |
| `角度` | 方向 |
| `開始` · `終了` | フェード区間 |
| `中心 (UV)` | 放射状の場合の基準点 |

## レイヤースロット

テクスチャレイヤー・ノーマルレイヤー・MatCapレイヤーに共通です。

### レイヤー数 {#레이어-수}

| 表示 | 意味 |
|---|---|
| `0（無効）` | このモジュールが何も計算しない |
| `1レイヤー` | |
| `Nレイヤー` | |

:::danger[ここで設定した数より後ろのスロットは計算されません]
テクスチャを入れたのに何も見えない場合は、**ほとんどの場合レイヤー数が不足しています**。インスペクターのツールヒントも同じことを言っています。
:::

### 順序を変える

各レイヤーに`上へ` / `下へ`ボタンがあります。

:::caution[合成順序が変わると結果が変わります]
単純な整理機能ではありません。`乗算`の上に`通常`を置くのと、その逆は全く異なる絵です。
:::

## 値をコピー / 貼り付け {#값-복사--붙여넣기}

項目を右クリックすると出てきます。

| メニュー | 範囲 |
|---|---|
| `値をコピー` / `値を貼り付け` | 1つの項目 |
| `レイヤー値をコピー` / `レイヤー値を貼り付け` | レイヤー全体 |
| `タブ値をコピー` / `タブ値を貼り付け` | セクション全体 |
| `プロパティ名をコピー` | シェーダープロパティ名（アニメーション作成時） |

貼り付けの結果がログに出ます：`値を貼り付け：8個適用、2個スキップ。`

:::note[スキップされる場合]
- **レイヤー** — `同じモジュール種別のレイヤーを先にコピーしてください。`MatCapレイヤーをノーマルレイヤーに貼り付けることはできません。
- **値の型** — `コピーした値の型に互換性がありません。`色をスライダーに貼り付けることはできません。
- **対象がない** — `互換性のある貼り付け先プロパティがありません。`
:::

すべての貼り付けは1つのUndo単位です。
