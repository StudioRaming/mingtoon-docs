# 詳細マップ

**このドキュメントを読むと** ベースの上にレイヤーを積み重ね、PBR・MatCap・エミッションで質感を付けることができます。

インスペクターの**詳細マップ**グループ — `テクスチャレイヤー`・`ノーマルレイヤー`・`MatCapレイヤー`・`オクルージョン`・`エミッション`・`グリッター`・`PBRサーフェス`を扱います。全項目リストは[詳細マップリファレンス](/reference/detail-maps)にあります。

## 全てのレイヤーセクションが共有する罠

:::danger[レイヤー数を最初に上げてください]
`レイヤー数`より後ろにあるスロットは**計算そのものをスキップします。** テクスチャを入れたのに何も見えないなら、十中八九レイヤー数が足りないのです。

各レイヤーの`不透明度`（MatCapは`強度`）が0の時も同じ結果になります。
:::

テクスチャレイヤー・ノーマルレイヤー・MatCapレイヤーの3つも同じです。

---

## テクスチャレイヤー {#텍스처-레이어}

ベースの上に追加テクスチャを合成します。タトゥー、ロゴ、部分塗装、汚れ表現に使用します。

レイヤーごと：

- `合成モード` — `Normal`は完全に覆い、`Multiply`は下のコントラストを保ったまま色だけを乗せます。
- `不透明度` — 0ならレイヤー計算をスキップします。
- マスクで適用範囲を制限できます。

---

## ノーマルレイヤー {#노멀-레이어}

ノーマルマップを複数枚重ねます。レイヤー01は[基本設定](/guides/basics#4-공통-맵)の`ノーマルマップ`と同じスロットです。

- `ノーマルマップ` — レイヤー数より後ろにあるスロットは計算されません。
- `ノーマル強度` — このレイヤーが最終法線に混ざる強度。0ならテクスチャを入れても影響がありません。

---

## MatCapレイヤー {#맷캡-레이어}

球に描かれた照明・質感画像を視線基準で投影します。カメラが回転するとハイライトも追従します。

| 項目 | 機能 |
|---|---|
| `MatCapマップ` | 球画像 |
| `合成モード` | `Add`・`Screen`は明るい光沢、`Multiply`は暗い質感 |
| `コントラスト` | 1が元の状態。上げるとハイライトと暗い部分が分かれてセル感が強くなります |
| `強度` | 0ならレイヤー計算をスキップします |
| `MatCap / メッシ UV投影` | **0なら視線基準、1ならメッシ UVに固定** |
| `MatCap 回転` | 球をその中心を軸に回します。ハイライトの入る向きだけを変えたいとき、マップを描き直す代わりに使います |
| `MatCap 円形マスク半径` | **0は切り取らないという意味です。** 上げると中心からその半径の外側が切られ、球状のハイライトが円形になります。1が球の縁です |
| `MatCap 円形マスクのぼかし` | 円形マスクの境界を内側へぼかします。半径が0の間は効きません |
| `MatCap ノーマルマップ強度` | このレイヤーがモジュール共用の`MatCap ノーマルマップ`にどれだけ従うかです。MatCapの投影に使う法線だけを乱すため、**表面の陰影はそのままにハイライトだけが歪みます** |
| `MatCap 発光への寄与` | このレイヤーが実際に加えた明るさのうち、この割合を照明に依存しない発光としてもう一度加えます。暗所でもハイライトが残り、ブルームの閾値に届きます |

`MatCap ノーマルマップ`はレイヤー一覧の上、モジュール領域に一つだけあります。5つのスロットが同じマップを共有し、スロットごとに`MatCap ノーマルマップ強度`で従う度合いを決めます。

:::tip[タトゥー・フェイスペインティング]
`MatCap / メッシ UV投影`を1にすれば模様が表面に付き、カメラを回転させても動きません。
:::

:::tip[瞳のハイライト]
`MatCap 円形マスク半径`でハイライトを丸く整え、`MatCap 回転`で入ってくる向きを合わせ、`MatCap 発光への寄与`を上げれば暗いワールドでも瞳の光が残ります。
:::

## PBRサーフェス {#pbr-표면}

トゥーンルックではPBRは「使うか使わないか」ではなく**どこにどれだけ乗せるか**の問題です。金属装飾、エナメル靴、濡れた唇といったところだけに使うのが普通です。

調整順序：

1. **ワークフロー** — `Metallic`（金属度から反射色を生成）または`Specular`（反射色を直接指定）。Specularを選ぶと金属度スライダーは反映されません。
2. **反射光強度** — **0なら直接ハイライトと環境反射が一緒に消えます。**滑らかさをいくら上げても変化がないなら最初にここを見てください。
3. **滑らかさ** — トゥーンルックでは0.3～0.6が無難です。1に近いとハイライトが点のように小さくなります。
4. **シャドウ内表示量** — シャドウに入った部分でハイライトをどれだけ残すか。0ならシャドウ内で完全に消えます。トゥーンルックでは低めにしておく方がすっきりです。
5. **直接ハイライト強度** — 0ならハイライト計算そのものをスキップします。
6. **環境反射強度** — シーンにリフレクションプローブがなければ上げても殆ど変化がありません。
7. **ノーマルマップ影響** — 0ならメッシノーマルのみ、1なら積みあがったノーマルマップをそのまま反映。

### パッキングマスク {#패킹-마스크}

金属度・オクルージョン・滑らかさを1枚からチャンネル別に読みます。既定配置は**R=金属度、G=オクルージョン、A=滑らかさ**で、テクスチャが異なるなら設定でチャンネルを合わせます。

- ラフネスマップを入れたなら`ラフネスとして使用（反転）`をオンにします。
- `反射オクルージョン`が0ならPBRオクルージョンチャンネル・反転設定が結果に出現しません。

:::caution[パッキングマスクをオフにすると]
下のチャンネル・反転設定が**全て無視されて**金属度・滑らかさスライダー値だけが使われます。
:::

## トゥーンスペキュラー {#툰-스페큘러}

PBR全体を有効にせず、光方向のハイライトを追加します。髪・目・布のセルハイライトに適しています。

1. `トゥーンスペキュラー`を有効にします。
2. `形状方式`でIsotropicまたはAnisotropicを選択します。
3. `強度`と`滑らかさ`でサイズと明るさを設定します。
4. `しきい値`と`ソフトネス`でセル境界を調整します。
5. 髪ではAnisotropic方向とShiftを調整します。
6. 必要に応じてマスクとグラデーションで範囲を制限します。

| 方式 | 適した用途 |
|---|---|
| **Isotropic** | 目、金属ボタン、濡れた肌の丸いハイライト |
| **Anisotropic** | 髪、シルク、ブラッシュド面の長く流れるハイライト |

:::tip[PBRと併用できます]
環境反射とマテリアル応答にはPBRを、直接光のセルハイライトにはトゥーンスペキュラーを使います。両方を上げすぎるとハイライトが重なって白飛びします。
:::

### ハイライト色を部位ごとに異なるように {#하이라이트-색을-부위마다-다르게}

髪のハイライトを1色に固定しておくと、前髪から後ろ髪まで全部同じ色で光ります。毛束ごとに色を分けたい時は`トゥーンスペキュラー色の指定方法`を使用します。

| 値 | 結果 |
|---|---|
| `Single Color` (デフォルト) | 指定したハイライト色1つがメッシ全体に使用されます |
| `Mask Texture Color` | **トゥーンスペキュラー マスクに塗ってあるRGB色**がハイライト色になります |

`Mask Texture Color`に切り替えるとマスクが黒白範囲指定ではなく**色分布図**になります。明度はそのままハイライトが出る範囲を、RGBはその場所のハイライト色を定めます。

`トゥーンスペキュラーのマスク色適用量`で2色の間をブレンドします。0なら指定色そのまま、1(デフォルト)ならマスク色をそのまま使用します。`Single Color`ではこの値が無視されます。

:::note[コストは増えません]
マスクは範囲指定のため、どうせ読み込んでいたテクスチャです。色も一緒に使用するだけで、テクスチャをもう1度読み込むわけではありません。デフォルトの白マスクでは、`Mask Texture Color`に切り替えても結果は変わりません。
:::

## 領域マスク {#영역-마스크}

1枚のマテリアルを4つのRGBA領域に分け、表面応答を個別に調整します。

1. `領域マスクを使用`を有効にします。
2. `領域マスク`にRGBAテクスチャを割り当てます。
3. R/G/B/A各領域のメタリック、滑らかさ、環境反射、トゥーンスペキュラーの強度・滑らかさオフセットを調整します。

:::caution[PBRまたはトゥーンスペキュラーと併用]
領域マスクは表面応答を調整します。PBRとトゥーンスペキュラーの両方が無効なら調整対象がありません。
:::

### スタータープリセット

現在のバージョンには`MetalHybrid`・`SkinSubtle`・`EyeGlossy`・`ClothSheen`・`HairAnisotropic`・`MetalCel`・`CharacterParts`の開始プリセットがあります。プリセットは完成したルックではなく機能の組み合わせ例なので、実際のアバターとワールド照明でもう一度調整してください。

## エミッション {#이미션}

マップ × 色 × 強度です。

- `エミッション色`が**黒なら、マップがあっても光りません。**HDRなので1を超えてブルームを誘導できます。
- `エミッション強度` — シーンにブルーム後処理がなければ値を上げても広がらず、白色に飽和するだけです。

`クイック設定`にも`エミッション強度`があります。

### マップのアルファを強度マスクに {#맵-알파를-세기-마스크로}

`マップのアルファを強度マスクに` — **既定はオフ**

発光マップのアルファチャンネルをピクセル単位の強度マスクとして使います。アルファが1の場所は`強度`の値そのままで光り、0の場所は光らず、中間値はその分だけ光ります。1枚のマップの中で部位ごとの明るさを分けたいとき、マスクテクスチャを別に用意しなくて済みます。

:::note[テクスチャの読み取りは増えません]
アルファは色を読み取るときに一緒に取得されます。このトグルをオンにしてもテクスチャの読み取りは増えません。

マスクは**元のアルファ**から読みます。`チャンネルソース`や`ソース色を反転`を変えてもマスクは変わりません。
:::

既定がオフなので、既存マテリアルの見た目はそのままです。下の発光レイヤー2にも同じ項目があります。

### 時間アニメーション {#시간-애니메이션}

各発光レイヤーの`時間アニメーション`を展開すると、マップの流れと明るさの変化を個別に作れます。

- `スクロール速度` — 発光マップだけを1秒あたり何タイル動かすかを指定します。Xは横、Yは縦で、負の値は逆方向です。継ぎ目なく流すにはテクスチャのWrap Modeを`Repeat`にしてください。
- `点滅` — `Smooth`はサイン波で滑らかに脈動し、`Flashing`はONとOFFを即時に切り替えます。`速度`は1秒あたりの繰り返し回数です。
- `点灯比率` — `Flashing`でのみ使用します。下げると短く光り、長く消えます。
- `最暗時の明るさ` — 0では完全に消え、値を上げると点灯したまま明るさだけが上下します。
- `位相オフセット` — 複数のマテリアルや2つの発光レイヤーのタイミングをずらします。
- `暗いほど発光` — 計算済みのメイン光量を基準に、明るい場所の発光を減らします。`明るさ基準`と`遷移幅`で消える区間を決めます。

スクロール・点滅・暗いほど発光は、発光テクスチャを追加で読みません。レイヤー1と2は速度と位相を独立して設定できます。

:::note[Editorプレビュー]
時間アニメーションはビューが再描画されると進みます。Sceneビューで止まって見える場合は、Play ModeまたはVRChat・WARUDOで実際の動きを確認してください。
:::

### 発光レイヤー2 {#발광-레이어-2}

`発光レイヤー2を使用` — **既定はオフ**

2枚目の発光マップです。**部位ごとに異なる色で発光させたい**ときに使います。目は青、模様はピンクのように1つのマテリアルの中で色を分ける必要があるなら、マップを2枚に分けてそれぞれに色を指定します。

**2つのレイヤーは加算されます。** 後のスロットが前のスロットを上書きしないので、各部位の色は指定したまま残ります。

レイヤー2にはレイヤー1と同じ項目がそろっています — マップと色補正、`強度`、`影内の表示量`、`マップのアルファを強度マスクに`。`強度`が0ならレイヤーの計算をスキップします。

:::caution[テクスチャを1枚多く読みます]
アルファマスクとは違い、レイヤー2は**新しいテクスチャを読み込みます。** 必要なマテリアルでのみ有効にしてください。オフのままのマテリアルは従来と同じコストでコンパイルされます。
:::

:::danger[実行時に切り替えられません]
`発光レイヤー2を使用`は**制作時に決める値です。** オフのままアップロードしたマテリアルをアニメーションでオンにすることはできません — オフでコンパイルされたバリアントには2枚目のマップを読むコード自体が入っていないためです。発光そのものを切り替える`エミッションを使用`はアニメーション可能です。

すでにベイク済みのマテリアルでは、**ベイクキャッシュを焼き直さないと**レイヤー2が結果に出ません。
:::

:::note[lilToonから変換したマテリアル]
lilToonの2番目の発光（`_UseEmission2nd`）は**自動では移行されません。** UVモード・ブレンドモード・ブレンドマスクが1対1で対応しないため、中途半端に移す代わりに変換ログが損失として報告します。`発光レイヤー2を使用`をオンにして、2番目の発光マップ・色・強さを手で移してください。
:::

## オクルージョン {#오클루전}

間接光が当たりにくい部分を暗くする白黒マップです。**直接光には影響を与えないため、**正面から強い照明を受けると効果がよく見えません。

`オクルージョン強度`が0ならマップを入れても何も変化はありません。

---

## グリッター {#글리터}

Voronoi粒子キラメキです。距離安定化、視点感度、光源角度、サイズ・色ランダム化を設定します。

オンオフトグル+色+強度から始めて、詳細を調整してください。

### MatCapでキラメキ領域を制限 {#matcap으로-반짝임-영역-제한}

`MatCap制限`の`グリッターMatCapを使用`を有効にすると、専用MatCapの明るさでグリッターが見える視線角度を制限します。明るい部分だけで光るため、瞳のハイライトや金属の特定反射帯のようにカメラへ追従する領域を作れます。通常のMatCapレイヤーとは独立しています。

- `色も一緒に使用` — MatCapのRGBをグリッター粒子の色にも乗算します。OFFでは明るさだけを領域制限に使います。
- `反転` — MatCapの暗い部分でグリッターが見えるよう反転します。
- `強度` — 領域制限の適用量です。0では領域制限だけが消え、`色も一緒に使用`による着色はそのまま残ります。

機能をOFFにすると専用MatCapテクスチャを読みません。ONにするとテクスチャ読み取りが1回追加されます。

### 粒子の形を変える {#입자-모양-바꾸기}

`形マップを使用` をオンにして `形マップ` にテクスチャを入れると、粒子ひとつひとつのシルエットがその絵になります。`Textures/Glitter/` に **Star・Bloom・Sparkle・Heart・Hex・Flower** の6種を同梱しています。

- `形チャンネル` でシルエットを読むチャンネルを選びます。既定はAで、アルファ付きPNGならA、白黒画像ならRかLumaを使ってください。
- `回転ランダム` は粒子ごとに形の角度を変えます。既定は1で、**ハートのように向きのある形をまっすぐ立てたいときだけ** 0に下げてください。

:::caution[自分で描くときは余白を残してください]
形マップの正方形は丸い粒子の**内側に収まるように**配置されます。端まで詰めると角が切れます。背景は黒(またはアルファ0)にしてください。
:::

### マスク1枚で領域と色を同時に {#마스크-한-장으로-영역과-색}

`適用マスク` グループの `色も一緒に使用` をオンにすると、同じマスクテクスチャをRGBA全体として読み、**アルファがきらめきの出る領域、RGBが粒子の色**になります。テクスチャの取得回数は増えません。

オンの間、`チャンネル` の選択はアルファに固定されます — RGBが色として出ていくと、領域を選ぶチャンネルはアルファしか残らないためです。
