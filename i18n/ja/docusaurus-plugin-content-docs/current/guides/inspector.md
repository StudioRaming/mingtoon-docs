# インスペクター使用法

**このドキュメントを読むと** MingToonインスペクターの構造を把握し、目的の項目を素早く見つけて、複数のマテリアルに安全に適用できます。

## 表示モード {#보기-모드}

インスペクター上部の**表示**で3つの中から選びます。

| モード | 表示される内容 | 用途 |
|---|---|---|
| **シンプル** | ベースマップHSVG、ノーマル・エミッション・オクルージョン・PBR・MatCapのコア、ライティング、最終最小/最大明るさ | トーン調整、変換結果確認 |
| **全設定** | 以下のワークフローグループ全て | 本格作業 |
| **一括設定** | 複数のマテリアルで共通に使う値のみ | アバター全体を一度に |

## 全設定のワークフローグループ {#전체-설정의-워크플로-그룹}

**全設定**は以下の順序でまとめられています。このドキュメントの「ルック作成」項目も同じ順序です。

| グループ | 含まれるセクション | ドキュメント |
|---|---|---|
| **基本設定** | 基本サーフェス・サーフェス描画・共通マップ | [基本設定](/guides/basics) |
| **ライティングとシャドウ** | ライティング・影の色・フォームシャドウ・影投影 | [ライティングとシャドウ](/guides/light-and-shadow) |
| **リム** | リムシェード・リムライト・バックライト・影内部リフレクション・フロントライト | [リム](/guides/rim) |
| **深度ベースエフェクト** | 深度・深度リム・2Dシャドウ・インナー2Dエッジ | [深度ベースエフェクト](/guides/depth-effects) |
| **詳細マップ** | テクスチャレイヤー・ノーマルレイヤー・MatCapレイヤー・オクルージョン・エミッション・グリッター・PBRサーフェス | [詳細マップ](/guides/detail-maps) |
| **キャラクター表現** | フェイスシェーディング・キャラクター高さグラデーション | [キャラクター表現](/guides/character) |
| **アウトライン** | ノーマルアウトライン | [アウトライン](/guides/outline) |
| **出力と診断** | 高度なレンダリング・ステンシル設定・テクニカル | — |

:::note[インナー2Dエッジはアウトラインにはありません]
画面深度を読むため、**深度ベースエフェクト**グループに入っています。アウトライングループで探して見つからないことがよくあります。
:::

## 全エフェクト — 最上部のマスタースイッチ {#전체-효과--가장-위의-마스터-스위치}

`全エフェクト`がオフだと、下のセクション全体が無効状態になり、その状態では**どの値を変えても画面が変わりません。**

インスペクターが`このセクションは全エフェクトが無効なため不活性です。`と通知して、`全エフェクトをオン`ボタンを一緒に表示します。

:::danger[何も効かない時はここから]
値をいくら調整しても反応がなければ`全エフェクト`から確認してください。各セクションも独自のマスタートグルがあり、オフのセクションは`(モジュールオフ)`と表示されます。
:::

## クイック設定 {#빠른-설정}

`クイック設定`は頻繁に調整する値だけを一箇所に集めた領域です。

- 1次シャドウ境界・1次シャドウ柔らかさ・1次シャドウ混合量
- 2Dリム幅・2Dリム強度
- アウトライン幅・アウトライン色
- エミッション強度

対応モジュールがオフなら項目の横に`(モジュールオフ)`が付き、`このモジュールをオン`ボタンが出ます。複数のマテリアルを選んで値が異なると`(混合状態)`が表示されます。

## 検索

| ツール | 機能 |
|---|---|
| **検索** | 項目名でフィルター。韓国語/英語/日本語のエイリアスが登録されているため「外郭線」「outline」「윤곽선」全てがアウトラインを見つけます |
| **お気に入りのみ** | よく使う項目だけ残します。項目横の`お気に入りに追加`で登録 |
| **言語** | インスペクター表記言語。韓国語 / English / 日本語 |
| **診断情報** | 現在のマテリアルの状態情報 |

検索やお気に入りフィルターで結果がない場合、`検索結果なし`が表示されます。

## 複数マテリアル同時編集

値が異なる項目は**`混合値`**として表示されます。

:::caution[混合値を最初に確認してください]
そのフィールドを触ると**選択した全マテリアルに同じ値が上書きされ、**元々異なっていた値が消えます。書き込む前に何が混合状態なのか確認してください。
:::

## プリセット

`マテリアルプリセット`でルック全体を保存・読込できます。複数のマテリアルを選択すると`マテリアル一括プリセット`になります。

プリセットは全ての数値・色・ベクトル・レンダー状態を適用します。**対象マテリアルのテクスチャがシェーダー既定値と異なると、そのテクスチャとタイリング/オフセットは保持**されるため、キャラクターごとに異なるテクスチャを保ったままルックを統一できます。

`ファクトリープリセット`は付属のもの、`ユーザープリセット`は直接保存したものです。

## コピー / 貼り付け

`コピー`と`貼り付け`でセクション単位の値を別のマテリアルに移動できます。

## 編集パフォーマンスについて

編集用シェーダーは**全機能と最大レイヤー数を最初に一度にコンパイルして保持**します。そのため機能トグルのオン/オフの際、青いプレースホルダー色や変形コンパイル待ちが生じません。

使わない機能の削除と軽量化は[ビルド時](/workflow/build-optimization)のみ適用されます。**作業中は重いのが正常です。**
