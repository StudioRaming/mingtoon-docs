# インスペクター使用法

**このドキュメントを読むと** MingToon Inspectorの表示モード、固定ツールバー、グループ構成、複数マテリアル編集のルールを理解できます。

## マテリアルの役割 {#머티리얼-역할}

`Face`・`Skin`・`Common`の役割は、ルックプリセットがどのスロットの値を適用するかを決めます。正式ビルドではMingToon Managerの`1 · 変換`でRendererとマテリアルスロットごとに指定します。開発ビルドだけがメンテナンス用の役割オーバーライド行をInspector上部に表示します。

複数マテリアルを選択したとき役割が異なる場合は混合状態で表示されます。役割を変更すると、選択中の全マテリアルへ適用されます。

## 表示モード {#보기-모드}

| モード | 表示される内容 | 用途 |
|---|---|---|
| **シンプル** | サーフェス、ライティング、主要マップ、シャドウ・リム・顔・深度の代表項目 | 変換直後のルック調整、すばやい修正 |
| **全設定** | すべてのユーザー向けワークフローグループと高度なレンダー状態 | 本格的なオーサリング、問題解決 |
| **一括設定** | 選択した複数マテリアルへ共通適用できる安全な値 | アバター全体の統一 |

`シンプル`は機能全体を要約した画面です。必要な項目がなければ`全設定`へ切り替えてください。`診断情報`、内部技術名、バリアントダンプなどのメンテナンス機能は正式ビルドには表示されず、`MINGTOON_DEV`開発ビルドでのみ表示されます。

## 固定ツールバー {#고정-툴바}

Inspectorを下へスクロールしても上部ツールバーが残ります。

| ツール | 機能 |
|---|---|
| **検索** | 現在の言語だけでなく、韓国語・英語・日本語の別名でも項目を検索します |
| **お気に入りのみ** | お気に入りに登録したセクションと行だけを表示します。全設定専用です |
| **すべて折りたたむ / すべて展開** | ワークフローグループとセクションを一度に整理します |
| **変更値のみ** | シェーダーのデフォルト値と異なる行だけを残し、該当セクションを自動展開します |
| **コピー / 貼り付け** | マテリアル設定を別のマテリアルへ移します |
| **言語** | 한국어 / English / 日本語を切り替えます |

`変更値のみ`は、自分で変更した値やプリセットが変更した候補を見つける診断ツールです。テクスチャのデフォルトfallbackと実際の割り当て状態も区別します。変更された項目がなければ`変更された値なし`と表示されます。

ツールバー下のカラーナビゲーションバーは各ワークフローグループの位置を示します。色の区間を押すと、そのグループへ移動します。

## 全設定のワークフローグループ {#전체-설정의-워크플로-그룹}

| 順序 | グループ | 主なセクション | ドキュメント |
|---|---|---|---|
| 1 | **基本設定** | マスター調整・サーフェス描画・ライティング | [基本設定](/guides/basics)・[ライティングとシャドウ](/guides/light-and-shadow#라이팅--어두운-씬에서-검게-뭉칠-때) |
| 2 | **詳細マップ** | サーフェスマップ・ノーマル・MatCap・エミッション・オクルージョン・グリッター | [詳細マップ](/guides/detail-maps) |
| 3 | **シャドウ** | シャドウカラー・フォームシャドウ・シャドウ投影・パターン | [ライティングとシャドウ](/guides/light-and-shadow) |
| 4 | **キャラクター表現** | フェイスシェーディング・キャラクター高さ | [キャラクター表現](/guides/character) |
| 5 | **PBR** | PBRサーフェス・トゥーンスペキュラー・領域マスク | [詳細マップ](/guides/detail-maps#pbr-표면) |
| 6 | **深度ベースエフェクト** | マスター・2Dリム・2D透過光・2Dシャドウ・SSAO・インナーアウトライン | [深度ベースエフェクト](/guides/depth-effects) |
| 7 | **リム** | リムシェード・リムライト・フロント/バックライト・内部反射 | [リム](/guides/rim) |
| 8 | **高度** | ステンシル・レンダリングオプション | [プロパティリファレンス](/reference/basics) |

## 全体エフェクトとセクションマスター {#전체-효과--가장-위의-마스터-스위치}

`全体エフェクト`がOFFなら下位エフェクトは無効になり、値を変えても画面は変化しません。Inspectorが原因を説明し、`全体エフェクトを有効化`ボタンを表示します。

各セクションにも独自のマスターがあります。無効なセクションには`(モジュールOFF)`と表示され、検索で下位の行を見つけた場合は`このモジュールを有効化`を使用できます。

:::danger[値が反応しない場合]
`全体エフェクト` → 該当セクションのマスター → 必要なプラットフォーム前提条件の順に確認してください。深度エフェクトなら[深度の可用性](/guides/depth-effects#깊이-가용성)も確認する必要があります。
:::

## クイック設定 {#빠른-설정}

`クイック設定`は頻繁に調整するシャドウ境界、2Dリム、アウトライン、エミッションなどの値を一箇所にまとめます。実際の値を複製したUIなので、ここで変更すると元のセクションへ即時同期されます。

モジュールがOFFなら`(モジュールOFF)`、選択したマテリアルの値が異なる場合は`(混合状態)`と表示されます。

## 複数マテリアルの同時編集 {#여러-재질-동시-편집}

値が異なる行は`混合値`として表示されます。その行を変更すると、選択中の全マテリアルへ同じ値が記録されます。

顔プロキシのSceneView編集は、同じキャラクタールートにある互換性のあるFaceマテリアル同士で使用してください。異なるルートが混在すると、誤同期を防ぐため編集を開始しません。先にMingToon Managerの`Faceマテリアルのみ選択`を使うと安全です。

## プリセット {#프리셋}

`マテリアルプリセット`はルック値を選び、`適用`を押したときだけ適用します。選択やプレビューだけで自動適用されず、複数マテリアルを選択すると一括適用されます。

0.1.7のプリセットは、次のようなキャラクター固有の情報を保持します。

- Surface Mode、Cutout・Fade・Premultiply状態とレンダーキュー
- アルファマスクとカットオフ
- 顔プロキシの中心・半径・形状・軸・高さ
- 割り当て済みのキャラクター固有テクスチャとタイリング/オフセット

適用前に保留される値と理由がパネルに表示されます。役割別のFace / Skin / Common値は、MingToon Managerに記録されたマテリアルの役割に従って選択されます。

## コピー / 貼り付け {#복사--붙여넣기}

`コピー`後、貼り付けメニューから範囲を選びます。

- `すべて`
- `値のみ（テクスチャを除く）`
- `テクスチャのみ`
- `キーワードのみ`
- `レンダーキューのみ`

貼り付けは選択中の全対象へ適用され、Undoに対応します。

## マテリアル負荷 {#재질-부하}

代表値は、アップロードされる**ベイク後シェーダー**の推定コストです。編集用シェーダーはすべてのオーサリング機能を保持するため、より重くなります。詳細表では現在の編集状態とベイク後状態を分けて確認できます。

## 編集パフォーマンスと開発用ツール {#편집-성능에-대해}

編集用シェーダーは、トグルするたびに新しいバリアントを待たずに済むようオーサリング経路を保持します。未使用機能の削除と定数畳み込みは[ビルド時の自動最適化](/workflow/build-optimization)で行います。

正式パッケージでは、ユーザー作業に不要なバリアントダンプ・レコード、技術診断パネル、Depth Debug Post Process登録は表示されません。製品開発者が`MINGTOON_DEV`を定義したビルドでのみ再表示されます。
