# シャドウパターン（スクリーントーン）

**このドキュメントを読むと** シャドウを漫画スクリーントーンのようなハーフトーン網点に変え、好みの形のタイルを直接作成できます。

`ライティングとシャドウ`グループ内の`シャドウパターン（スクリーントーン）`を扱います。全項目リストは[ライティングとシャドウリファレンス](/reference/light-and-shadow)にあります。

## どう動作するか

フォームシャドウと2Dシャドウをハーフトーン網点で表現します。シャドウが深くなるほど点が**大きくなります** — 実際のプリント用ハーフトーンと同じ方式です。

格子は**計算だけで**描かれ、画面に固定されています。そのため：

- テクスチャを入れる必要がありません。
- 準備手順がありません。
- カメラが動いてもちらつきません。

`シャドウパターン使用`をオンにするとこの状態です。

<!-- SCREENSHOT: シャドウパターンオン/オフ比較 -->

:::note[統合シャドウと一緒に使っても大丈夫です]
[統合シャドウ](/guides/light-and-shadow#통합-그림자--겹칠-때-새까매지는-문제)をオンにした状態でもシャドウパターンはそのまま保持されます。
:::

## ランタイム値 {#런타임-값}

| 項目 | 機能 |
|---|---|
| **パターン適用対象** | フォームシャドウ、2Dシャドウ、または両方 |
| **パターン方式** | `Recolor` — シャドウカバレッジ自体を再描画します。点がシャドウ色をそのまま使用<br />`Overlay` — シャドウはそのままで`インク色`で上に重ねます |
| **パターン密度** | 画面1画面分を埋めるセル数。画面**高さ**基準なため解像度が変わっても同じサイズに見えます |
| **パターン回転** | 格子角度 |
| **パターン境界柔らかさ** | 点の端の柔らかさ |
| **パターン強度** | パターンが適用される強さ。**0なら何も見えません** |
| **距離補正** | 遠くなる時の点サイズ補正 |
| **画角/投影補正** | FOV変更時の補正 |
| **最も暗い場所にもパターンを保持** | 最暗部までドット網点を保つかどうか。`最も暗い場所の塗り詰め度`で量を決定します |

:::caution[2Dシャドウでは`Overlay`が`Recolor`に落ちます]
`パターン方式`が`Overlay`で`パターン適用対象`が`Depth2D`の場合、パターンはそのまま描かれますが、`インク色`ではなく影色を使います。`Overlay`は仕上がった陰影の上に線を重ねる方式で、合成地点を持つのはフォームシャドウ経路だけだからです。以前からこの動作でしたが、今回からその組み合わせでインスペクターが案内を表示します。

`Overlay`をそのまま使うには、`パターン適用対象`を`Form`または`Both`にしてください。
:::

:::tip[回転角度]
**45度近く**がプリント用網点のように自然です。**0度**は画面ピクセル格子と重なりモアレが起きやすいです。
:::

## パターン基準 — 表面に貼るか、画面に固定するか {#패턴-기준}

`パターン基準` — **既定は `Mesh`**

| 値 | 格子がどこにあるか |
|---|---|
| `Mesh` | 表面に貼り付き、キャラクターと**一緒に動きます。** 腕を上げれば腕の網点も付いてきます |
| `Screen` | 画面に固定され、**キャラクターがその下を通ります。** 印刷物への重ね刷り / ポップアート |

形状タイル・密度・回転は両方で同じものを使います。変わるのは格子が何に貼り付いているかだけです。

`Screen` では画角を変えてもカメラを回しても、パターンが歪んだりちらついたりしません。座標を短い軸で割ってセルを正方形に保つため、画面のアスペクト比が変わっても密度は同じです。

### 2つの基準で補正スライダーの意味が反転します

`距離補正` と `画角 / 投影補正` は**どちらでも動作します。** 反転するのは向きです。

- `Mesh` ではカメラ安定性を**取り除く**値です。0では表面に完全に固定され、1ではカメラの動きに対して大きさを補正します。
- `Screen` ではカメラ安定性を**加える**値です。既定の1では、近くで決めたマークの大きさと密度が遠くから見ても画角を変えても保たれます。0に下げると格子がピクセルに完全固定され、カメラが何をしても一切動きません。

:::tip[近くで作って遠くで確認]
`Screen` と `距離補正` 1 がまさにその組み合わせです。0.1.5 より前はこの2つのスライダーが `Screen` ではロックされていて使えませんでした。
:::

## パターン形状タイル {#패턴-모양-타일}

`パターン形状タイル使用` — **既定値オフ**

- **オフにすると** 計算で描く円形網点が使われ、テクスチャを1度も読みません。
- **オンにすると** セル内に描かれる**形状だけ**がタイル画像に変わります。格子・密度・トーン反応はそのままです。

### 付属タイル

`Assets/StudioRaming/MingToon/Textures/Patterns`フォルダに5種があり、インスペクターのボタンで直接入れることができます。

| ボタン | 形状 |
|---|---|
| **網点** | 標準ハーフトーン |
| **細かい網点** | 細い網点 |
| **線** | 平行線 |
| **交差線** | クロスハッチング |
| **点描** | スティプル |

<!-- SCREENSHOT: 5種タイルそれぞれの結果 -->

:::danger[タイルスロットが空いているとパターンが全く打たれません]
空のスロットは**白色**で読まれ、白色はどの濃度でも越えられない閾値です。インスペクターがこれを警告して、付属タイルボタンと一緒に表示します。
:::

### タイルは画像ではなく閾値マップです {#타일은-그림이-아니라-임계값-맵입니다}

ここを誤解するとタイルを直接作成するときは必ず失敗します。

タイルの各テクセルは**そのテクセルがインクに変わる濃度**を保持しています。「パターンを描いた画像」ではありません。そのためタイル1枚で**最初の点から完全に塗られるまで全て**が表現されます。

:::danger[既に二値化された点パターンを入れると]
シャドウ深度と無関係に**同じサイズの点だけ**が出ます。トーンに反応しません。
:::

### 直接作成する時のインポート設定

| 設定 | 値 | 理由 |
|---|---|---|
| `sRGB (Color Texture)` | **オフ** | sRGB変換がトーン曲線を歪めます |
| 圧縮（Compression） | **オフ** | ブロック圧縮がグラデーションを潰してパターンにムラを作ります |

全ての明度段階が**同じテクセル数**を占める必要があります。そうすることで点がサンプリング限界より小さくなった時に元の濃度に収束します。

### Tiling/Offsetがない理由

セル1マスが正確にタイル1回の繰り返しです。したがって密度は`パターン密度`が、方向は`パターン回転`がそのまま決定します。スロットにTiling/Offsetがないのはこのためです。
