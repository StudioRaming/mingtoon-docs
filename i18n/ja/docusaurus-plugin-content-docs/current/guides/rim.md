# リム

**このドキュメントを読むと** シルエットを活かす5つの手段を区別でき、どれからオンにすべきかが分かります。

インスペクターの**リム**グループ — `リムシェード`・`リムライト`・`バックライト`・`影内部リフレクション`・`フロントライト`を扱います。全項目リストは[リムリファレンス](/reference/rim)にあります。

## 何をオンにするか最初に選ぶ

| セクション | どこに出るのか | 用途 |
|---|---|---|
| **リムシェード** | シルエット内側、**暗く** | ボリューム感。イラストで縁に入れる陰影 |
| **リムライト** | シルエット内側、**明るく** | 逆光感覚、背景からキャラクターを分離 |
| **バックライト** | 表面裏側の主光が作る逆光帯 | 主光方向を活かす時 |
| **フロントライト** | カメラを向く面 | 正面強調 |
| **影内部リフレクション** | シャドウ内側のみ | シャドウが死なないように |

:::caution[重ねてオンにすると直ぐ過剰になります]
1つずつオンにして確認しながら上げてください。特にリムライトとバックライトを一緒に上げるとシルエットが真っ白に飛びます。
:::

この5つは全て**カメラ深度が不要です。** どんな環境でも動作するため、深度が使えないVRChat通常画面でシルエットを保つ手段として使用できます。深度を読む`深度リム`は[深度ベースエフェクト](/guides/depth-effects)にあります。

## リムライト {#림-라이트}

視線角度に反応する明るいふち光です。調整順序：

1. `強度` — **0なら色と幅を変えても画面に出現しません。** ここから上げてください。
2. `幅` — リムが始まる地点。0なら出ず、1に近いと表面全体が明るくなります。
3. `フレネル減衰` — 大きいほどシルエット端に細く集まります。1に近いほど最も鮮明です。
4. `柔らかさ` — 下げるとセルルックの硬い帯、上げるとグラデーション。

環境に合わせる項目：

| 項目 | 0 | 1 |
|---|---|---|
| `光源方向影響` | カメラ基準でシルエット全体にリム | 光源がある方向のみに残る |
| `ベース色影響` | 指定したリム色そのまま | ベースマップ色を掛けてマテリアルごとに異なるリム色 |
| `シーンライト影響` | シーンの明度と無関係に常に同じ強度 | 照明が暗くなるとリムも暗くなる |

:::tip[照明を制御できない環境なら]
`光源方向影響`と`シーンライト影響`を低めにしてください。どのワールドに入っても一定のリムが残ります。シーンに方向光がなければ`光源方向影響`は元々差がありません。
:::

### リムがカメラに付いてくるのが嫌なら {#림이-카메라를-따라다니는-게-싫다면}

`フレネルリムの視線影響` は**リムの位置を視線とライトのどちらが決めるか**を選びます。

| 値 | 結果 |
|---|---|
| 1 (既定) | カメラが見るシルエットに沿って回ります。カメラを動かすとリムも表面を滑ります |
| 0 | 光源方向だけに従います。**カメラを回してもリムはその場に留まります** |

フレネルはもともとカメラの事実なので、ライトが止まっていても視点を回すとリムが形状の上を滑ります。レンズ効果としては正しく、光としては誤った挙動です。

すぐ上の `光源方向影響` と紛らわしいですが、決めるものが違います — `光源方向影響` は**どちら側にリムを残すか**、視線影響は**リムがカメラに付いてくるか**です。併用できます。

`フレネルリムのカメラ安定化` グループの `距離補正`・`投影 / 画角補正` がリムの**太さ**を押さえる値なのに対し、こちらはリムの**位置**を押さえます。

:::note[方向光がなければ1と同じ挙動です]
基準にする光源方向がない場合は視線基準に戻ります。
:::

## リムシェード {#림-셰이드}

シルエット**内側に暗い帯**を入れてボリューム感を作ります。

- `影への寄与強度` — **0なら計算そのものをスキップするため、** 幅・減衰・柔らかさを変えても変化はありません。
- `リム影幅` — 帯が始まる地点。0なら出現しません。
- `リム減衰` — 大きいほど端に細く付きます。
- `境界柔らかさ` — 下げるとインクで引いた線のように硬くなります。

:::tip[リムライトより先にこちらを試してください]
明るく加える方より暗く引く方が、照明が予測不可能な環境でより安定しています。白く飛ぶ危険がありません。
:::

## バックライト・フロントライト・グリッター {#백라이트--프런트-라이트--글리터}

それぞれ**オンオフトグル + 色 + 強度**、3項目だけの軽いモジュールです。

| モジュール | 機能 |
|---|---|
| **バックライト** | 表面裏側の主光が作る独立した逆光帯 |
| **フロントライト** | カメラを向く面に加える正面強調光 |
| **グリッター** | Voronoi粒子キラメキ。距離安定化・視点感度・光源角度・サイズ・色ランダム化（[詳細マップ](/guides/detail-maps)グループ） |

バックライトはシーンの主光方向に依存するため、方向光がないワールドでは出現しません。そのような環境で逆光感覚が必要なら、リムライトの`光源方向影響`を低めにして使用してください。

## 影内部リフレクション {#그림자-내부-반사}

**シャドウ内側でのみ見える**フレネル反射帯です（インスペクター案内：`影内部専用エフェクト`）。シャドウが平らな黒い塊で死ぬのを防ぎます。暗い衣装や高コントラストキャラクターで効果が大きいです。

### 反射表現

最初に帯そのものを作ります。リムライトと同じ構造です。

| 項目 | 機能 |
|---|---|
| `反射色` | 帯の色 |
| `強度` | **0なら何も見えません。** ここから |
| `フレネル減衰` | 大きいほどシルエット端に細く集まる |
| `幅` | 帯が始まる地点 |
| `端の柔らかさ` | 境界ぼかし |
| `ノーマルマップ影響` | ノーマルマップをどれだけ追従するか |

### シャドウ範囲

**どこまでを「シャドウ内」と見なすか**を決定する部分です。このモジュールだけにある項目です。

| 項目 | 機能 |
|---|---|
| `シャドウ開始点` | この明度より暗い場所から反射が出現します |
| `シャドウ柔らかさ` | その判定の遷移幅 |

:::tip[反射が明るい面まで広がっているように見えたら]
`シャドウ開始点`を下げてください。逆に深いシャドウにだけ入れたいなら、さらに下げます。
:::

### 環境反応

照明が制御されない環境で帯が浮かないようにする項目たちです。

| 項目 | 0 | 1 |
|---|---|---|
| `ベース色影響` | 指定した反射色そのまま | ベースマップ色を掛ける |
| `シーンライト影響` | シーンの明度と無関係 | 照明を追従 |
| `光源方向影響` | 方向と無関係 | 光源側のみ |
| `環境光色影響` | 環境光色を無視 | 環境光色を反映 |
| `追加光源影響` | ポイント/スポットを無視 | 反映 |

### 専用マスク

`マスク使用`をオンにするとこのエフェクト専用のマスクを指定できます。マスク項目構成は[テクスチャスロット共通UI](/guides/texture-modules#마스크-세부-설정)と同じです。
