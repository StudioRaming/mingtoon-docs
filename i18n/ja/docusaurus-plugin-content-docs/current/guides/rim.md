# リム

> このページは**フレネルリムを使用**をはじめてオンにする方のためのものです。
> シルエットの縁を明るく、または暗くして背景から切り離します。約 5 分かかります。

## これは何ですか

シルエットの縁に帯を載せる手段が 5 つあります。
5 つとも画面の深度を読まないので、どこでも見えます。

| インスペクターのセクション | どこに出るか | 使いどころ |
|---|---|---|
| **リムシェード** | シルエットの内側、暗く | 立体感 |
| **リムライト** | シルエットの内側、明るく | 逆光感、背景からの分離 |
| **バックライト** | 主光源が後ろにあるときの逆光の帯 | 主光源の方向を活かす |
| **フロントライト** | カメラを向いた面 | 正面の強調 |
| **影内部リフレクション** | 影の内側だけ | 影を死なせない |

## いつ使いますか

- 暗いワールドでキャラクターが背景に埋もれるとき。
- 照明を制御できず、シルエットの下地を敷いておきたいとき。
- 影が平らな黒い塊として死んで見えるとき。

## 30 秒で試す

1. 変換したボディのマテリアルを選びます。
2. **フレネルリムを使用**がオンかを確認します。既定値はオンです。
3. **強度**を 3 に上げます。既定値は 1 です。
4. **幅**を 0.3 に下げます。既定値は 0.5 です。

シルエットの縁に細い光の帯が出れば成功です。
何も変わらない場合は[トラブルシューティング](/troubleshooting#shadow)へ進んでください。

## 使い方

1. 一度に 1 つだけオンにします。重ねてオンにするとシルエットが白く飛びます。
2. **強度**から上げます。0 だと色と幅を変えても見えません。
3. **幅**で帯が始まる地点を決めます。低いほど縁に薄く寄ります。
4. **柔らかさ**で境界を決めます。下げるとセルルックの硬い帯になります。
5. ワールドごとに明るさが跳ねる場合は**シーン照明の影響**を下げます。

:::tip[明るく足すより暗く引くほうが安全です]
照明が予測できないワールドでは、**リムシェード**のほうが安定します。
白く飛ぶ危険がないためです。
:::

### リムがカメラに追従するのが嫌なら {#림이-카메라를-따라다니는-게-싫다면}

**視線基準**は、リムの位置を視点と光源のどちらが決めるかを選びます。
1 ならカメラを動かしたときにリムが表面の上を滑ります。
0 なら光源方向だけに従うので、カメラを回してもその場に留まります。

**光源側の強調**と混同しやすいのですが、2 つは別のものを決めます。
光源側の強調は、リムをどちら側に残すかを決めます。
視線基準は、リムがカメラに追従するかを決めます。

:::note[ディレクショナルライトがないと 1 のように動作します]
基準にする光源の方向がない場合は、視線基準に戻ります。
シーンにディレクショナルライトがなければ、この値を下げても違いはありません。
:::

### リムを一部の部位だけに {#림-마스크}

マスクは、効果を適用する部分だけを白く塗った白黒画像です。
**リムライトマスクを使用**をオンにしないとマスクテクスチャを読みません。
**リムシェード**側は**リム影マスクを使用**が同じ役割をします。

:::caution[マスクを入れる前にトグルを先にオンにしてください]
2 つのトグルはどちらも既定値がオフです。
オフだとテクスチャを入れても読まれず、以下の設定が非アクティブに見えます。
:::

マスク項目の構成は[テクスチャスロット共通 UI](/guides/texture-modules#마스크-세부-설정)と同じです。

## 影内部リフレクション {#그림자-내부-반사}

影の内側だけで見える反射の帯です。
影が平らな黒い塊として死ぬのを防ぎます。
暗い服やコントラストの強いキャラクターで効果が大きくなります。

![影内部リフレクションをオフにした暗い服とオンにした暗い服の比較](/img/placeholder.png)
<!-- CAPTURE: guides/rim-02-shadow-interior-reflection.png | 어두운 옷 클로즈업, 그림자 내부 반사 끔(전) / 켬(후) 2컷 | 1200x700 -->

どこまでを影の内側と見なすかは、このモジュールにしかない項目が決めます。

- **影内部反射のしきい値**より暗い場所から反射が現れます。
- **キャストシャドウ内の表示量**は、投影影の中に反射を残す量です。
- **デプスシャドウ内の表示量**は、デプスシャドウの中に反射を残す量です。

:::caution[WARUDO Built-in の追加ライトには 2 つの値がかかりません]
ポイント・スポットの追加ライト経路には、主光源の影判定がありません。
主光源と URP のシングルパスには正常に適用されます。
:::

## よく触る値

| インスペクターのラベル | 何が変わるか | 推奨の開始値 | 上げると / 下げると |
|---|---|---|---|
| **強度** | フレネルリムの明るさ倍率 | 既定値のまま(1) | 0 だと色と幅を変えても見えません |
| **幅** | フレネルリムが始まる地点 | 0.3 (既定値 0.5) | 上げると表面の内側まで明るくなり、0 だと消えます |
| **柔らかさ** | フレネルリムの境界のぼかし | 既定値のまま(0.2) | 下げると硬い帯、上げるとグラデーションになります |
| **シーン照明の影響** | シーンの明るさに追従する度合い | 0.3 | 0 ならどのワールドでも同じ強さで残ります |
| **色純度** | 合成されたリム色の彩度 | 既定値のまま(1) | 0 は無彩色、1 より上げるとその層だけ過彩度になります |
| **影への寄与強度** | リムシェードの帯の強さ | 1 | 0 だと幅と柔らかさを変えても変化がありません |
| **影内部反射の強度** | 影の中の反射の帯の明るさ | 0.5 | 0 だと形を設定しても色を足しません |

## よくある問題

### シルエットが白く飛びます

リムライトとバックライトを一緒に上げた場合がほとんどです。
片方をオフにし、もう片方だけを残して確認してください。
4 つのレイヤーの合計は、**マスター調整**の**輪郭リムの最大倍率**が押さえます。

### バックライトがどのワールドでも出ません

バックライトはシーンの主光源の方向に依存します。
ディレクショナルライトのないワールドでは現れません。
そうした場所では、リムライトの**光源側の強調**を下げて使ってください。

### マスクを入れたのに変わりません

マスクの使用トグルがオフです。
上の[リムを一部の部位だけに](#림-마스크)を先に確認してください。
