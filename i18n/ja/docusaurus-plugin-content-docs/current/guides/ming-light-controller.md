# Ming Light Controller 連携

**このドキュメントを読むと**、今押したロックされたボタンがどの別売製品に属するのかが分かり、その製品が MingToon で何を開放するのか、それがなくても同じ目的を達成する方法があるのかを判断できます。

:::note[このボタンは別売製品がないと動作しません]
MingToon 0.1.7 オープンベータパッケージには Mask Maker・Face SDF Studio・Ming Light Controller は同梱されません。3 つとも別途販売される Editor ツールであり、MingToon は 3 つすべてがなくてもインストール・コンパイル・動作します。

インストールしていない状態でもボタンはインスペクターにそのまま表示され、押すとこのドキュメントへ移動します。該当製品をインポートすると、同じボタンがその場で有効になります。
:::

## まず区別してください

| 製品 | MingToon で開放されるもの | 状態 |
|---|---|---|
| **Ming Light Controller** | `マスター調整` セクション、`仮想キーライト` オーサリング、Manager の MLC インストール・アタッチアクション | 発売予定 |
| **Mask Maker** | マスクスロットの `MM` ボタン、`シーンビューでアウトライン幅を塗る`、`顔領域のペイント開始` | 販売中 |
| **Face SDF Studio** | 顔 SDF マップの制作・ベイク → [顔 SDF と Face SDF Studio](/guides/face-sdf) | 販売中 |

## Ming Light Controller とは {#ming-light-controller란}

MingToon アバターの表現メニュー（VRChat Expression Menu）を作成する Editor 専用アドオンです。シェーダーの値を着用者がインゲームで直接操作できるように、メニュー側を担当します。

**発売予定です。** 販売が開始されると、この場所に購入リンクが掲載されます。

### インストールで開放される MingToon 機能 {#설치하면-열리는-mingtoon-기능}

| 位置 | ロックされている機能 |
|---|---|
| インスペクター・最上部 | `マスター調整` セクション全体 |
| インスペクター・`ライティング` | `仮想キーライト` オーサリング行 |
| MingToon Manager | MLC インストール・アタッチアクション |

`マスター調整` は、光を加えるもの全部・影全部・最終出力のそれぞれに、明るさとティントを一度にかける上位の調整です。`仮想キーライト` は、シーンの照明とは無関係にキャラクターが持ち歩く光源の方向・色・明るさをマテリアル側で決める機能です。

どちらも着用者がランタイムで操作することを前提にした値なので、その値を公開するメニューが一緒にあってはじめて意味があります。そのメニューを作る側が MLC です。

### MLC がなくてもできること {#mlc-없이도-되는-것}

シェーダーのルック機能はすべてそのまま動作します。照明・影・リム・深度効果・アウトラインのいずれも MLC を必要としません。

`マスター調整` と `仮想キーライト` も、マテリアルに値が残っていればその値のままレンダリングされ続けます。MLC がないときに消えるのはインスペクターの **編集 UI** であって、シェーダーの動作そのものではありません。

:::note[ビルドポリシーは MLC の所有ではありません]
VRChat・WARUDO の Depth Light ビルドポリシーは、引き続き MingToon Manager が所有します。MLC をインストールしても削除しても、MingToon の VRC・WARUDO ビルド動作は変わりません。
:::

### パラメータープロファイル {#파라미터-프로필}

VRChat Expression Parameters の予算は、アバター全体で分け合う資源です。MLC は 2 つのプロファイルのうち 1 つでメニューを作成します。

| プロファイル | 同期ビット | 項目数 |
|---|---|---|
| **Smooth** | 84 ビット | 22 個 |
| **Compact** | 41 ビット | 51 個 |

`Auto` は、アバターに残っている VRC 予算に合わせて 2 つのうち 1 つを選びます。

### ルートメニュー構成 {#루트-메뉴-구성}

MLC のルートメニューは 7 枠です。

| 枠 | 名前 |
|---|---|
| 1 | Reset |
| 2 | Final Output |
| 3 | Hue/Saturation |
| 4 | Photo Looks |
| 5 | Virtual Light |
| 6 | Master Adjust |
| 7 | Performance |

## Mask Maker {#mask-maker}

マスクテクスチャとバーテックスペイントを Unity エディター内で処理するツールです。

**購入:** <https://raming.booth.pm/items/8606444> （BOOTH、製品名 `[Unity] MaskMaker`）

### インストールで開放される MingToon 機能 {#mask-maker-설치하면-열리는-mingtoon-기능}

| 位置 | ロックされている機能 |
|---|---|
| インスペクター・マスクテクスチャスロット | スロット横の `MM` ボタン — そのスロットのマスクをシーンビューで直接描きます |
| インスペクター・ノーマルアウトライン | `シーンビューでアウトライン幅を塗る` |
| インスペクター・フェイス／ヘアシェーディング | `顔領域のペイント開始` |

`MM` ボタンが付くスロットは、マスク系のテクスチャスロットです。

### Mask Maker がなくてもできること {#mask-maker-없이도-되는-것}

マスクテクスチャを他のツールで作成し、スロットへ直接入れれば済みます。すでに塗ってあるバーテックスカラーもそのまま読み取られます。アウトライン圧力と顔領域には、バーテックスペイントではなくテクスチャマスクの経路が別にあります。

外部 DCC でバーテックスカラーを塗るときに使うチャンネルは次のとおりです。

| 用途 | バーテックスカラーチャンネル |
|---|---|
| アウトライン圧力 | 赤またはアルファ |
| 顔領域 | 緑 |

## インストール確認 {#설치-확인}

MingToon は 3 つの製品を、アセンブリ参照ではなくリフレクションで探します。アドオンがなくても MingToon 側のコンパイルが壊れないのはこのためであり、逆にアドオンのアセンブリがコンパイルされない場合、MingToon はそのツールをインストールされていないものと見なします。

ボタンがロックされたままなら、まず Console にコンパイルエラーがないか確認してください。
