# タイルドマテリアルコンポーザー

> このページは **タイルドマテリアルコンポーザー** を初めて使う方のためのものです。
> 1つのマテリアル内の布・革・金属に、それぞれ別の表面を敷きます。7分ほどかかります。

## これは何ですか

衣装一式がマテリアル1つにまとまっていることはよくあります。
その中の布と金属に別の質感を与えるには、スロットを複数手作業で埋める必要があります。
コンポーザーは、白黒4チャンネルのマスク1枚でその作業を代行します。

小さな繰り返しテクスチャをそのまま使うため、元の画像を焼き直しません。
メッシュ・サブメッシュ・レンダラーには触れません。

:::note[ディテールマップの領域マスクとは異なります]
[領域マスク](/guides/detail-maps#영역-마스크) は部位ごとに反射の値を補正します。
コンポーザーは部位ごとに別のテクスチャを敷きます。
:::

## いつ使いますか

- 衣装の1マテリアルに布・革・金属が混ざっているとき
- 同じパターンを部位ごとに別の倍率で繰り返したいとき

## 30秒でオンにしてみる

1. `StudioRaming > MingToon > Tiled Material Composer` を開きます。
2. **MingToonマテリアル** に対象のマテリアルを入れます。
3. **パック済み領域マスク** にRGBAテクスチャを入れます。
4. **論理領域4つを適用** を押します。

ボタンが押せれば成功です。
グレーになっている場合は、上の2つの枠のどちらかが空です。

## 使い方

1. マスクを用意します。R・G・B・Aの各チャンネルが1つの部位を担当します。
2. ウィンドウを開き、マテリアルとマスクを入れます。
3. 使うカードだけ、タイトル左のチェックをオンにします。
4. 各カードの **マスクチャンネル** とマップを埋めます。
5. **論理領域4つを適用** を押します。

カードは常に4枚で、既定の名前とチャンネルが決まっています。

| カード | 既定の名前 | 既定のチャンネル |
|---|---|---|
| 01 | 布 | R |
| 02 | 革 | G |
| 03 | 金属 | B |
| 04 | ラベル | A |

名前とチャンネルはカード上で変更できます。

## よく触る値

| インスペクターのラベル | 何が変わるか | 推奨する初期値 | 上げると / 下げると |
|---|---|---|---|
| **マスクチャンネル** | このカードが読むチャンネル | 既定値のまま（01 R・02 G・03 B・04 A） | 実際に塗ったチャンネルと違うと、どこにも表示されません |
| **タイルサーフェス** | この部位に繰り返すサーフェスマップ | 小さいパターン1枚 | 空にすると、この部位のサーフェススロットが消去されます |
| **サーフェスタイリング** | そのマップの繰り返し回数 | 8, 8 | 上げると模様が細かくなり、1にすると1回だけ配置されます |
| **サーフェスティント** | サーフェスの色に掛ける色 | 白 | 色を入れるとその部位だけが染まります |
| **サーフェスの不透明度** | サーフェスが重なる量（0～1） | 1 | 下げると元の色が透け、0にすると消えます |
| **ノーマル強度** | 凹凸の強さ（0～2） | 1 | 上げると起伏が誇張され、0にすると平らになります |
| **MatCap強度** | 光沢の強さ（0～20） | 1 | 上げるとテカり、0にすると計算されません |

## 適用がマテリアルに書き込むもの

| カードの項目 | 書き込まれる先 |
|---|---|
| サーフェスマップ・タイリング・ティント・不透明度 | 同じ番号の追加テクスチャスロット |
| ノーマルマップ・タイリング・強度 | 同じ番号のノーマルレイヤー |
| MatCap・強度 | 同じ番号のMatCapレイヤー |
| マスクとチャンネル | 3つのモジュールのマスクスロットすべて |
| 最後に使った番号 | 各モジュールの使用スイッチとレイヤー数 |

適用は4枚のカードすべてを走査します。
オフのカードと空のマップは、そのスロットを明示的に消去します。
全体が1回のUndoとして記録されます。

:::caution[01番のノーマルカードは基本のノーマルマップスロットを使います]
コンポーザーが入れたものではない、手動で指定したノーマルマップは消しません。
マスクなしで入っているノーマルマップなら、適用後もそのまま残ります。
:::

## マスク作成の原則

各チャンネルの明るさが、その部位の重みになります。
同じピクセルで2つのチャンネルが明るいと、2つの部位が重なって合成されます。
境界が粗い場合は、マスクに滑らかな遷移を描いてください。

マスクは部位を分けるためのものです。
大きなイラスト1枚を4つに自動分割するものではありません。

:::caution[サーフェスモードは部位ごとに分けられません]
サーフェスモードとレンダーキューは、マテリアル1つにつき1つだけです。
異なるサーフェスモードが必要なら、マテリアルを分ける必要があります。
:::

## よくある問題

| 症状 | 原因 | 対処 |
|---|---|---|
| 適用ボタンがグレーになっている | マテリアルかマスクが空になっている | 2つの枠を両方埋めます |
| 1つの部位だけ表示されない | マスクチャンネルが実際に塗ったチャンネルと違う | カードのマスクチャンネルを変えます |
| 消した部位の値が残っている | そのカードをオフにせず、マップだけを空にした | カードをオフにして再度適用します |
