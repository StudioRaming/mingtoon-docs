# タイルド マテリアル コンポーザー

**このドキュメントを読むと** マテリアルスロット1つに異なるマテリアルテクスチャ4つを配置して、ドローコールを増やさずに衣服の布・革・金属・ラベルを区別できます。

`Tools > Studio Raming > MingToon > Tiled Material Composer`

## 解決する問題

1着の衣服に布、革、金属装飾が混在していると考えましょう。通常はマテリアルを3つに分けます。すると **ドローコールが3つ** になり、アバターのパフォーマンス等級にも影響します。

コンポーザーは代わりに **RGBA マスク1つで最大4つの論理的エリア** を1つのスロット内で区別します。

```text
マスク R チャンネル  →  エリア 1 (例: 布)
マスク G チャンネル  →  エリア 2 (例: 革)
マスク B チャンネル  →  エリア 3 (例: 金属)
マスク A チャンネル  →  エリア 4 (例: ラベル)
```

デフォルトのエリア名も `Cloth` · `Leather` · `Metal` · `Label` です。

## テクスチャ容量が増えないのはなぜか

ここがこのツールの核心です。

> マスクは **低周波(low-frequency)** で、サーフェスマップとノーマルマップは **小さなタイルテクスチャのままです。**

| | 解像度 | 理由 |
|---|---|---|
| **エリア マスク** | 低くても良い | どこが布でどこが革かだけを格納します。境界がぼやけていても問題ありません |
| **サーフェス・ノーマル マップ** | 小さなタイル | 布の織り目、革の質感のように **繰り返されるパターン** なので小さい画像を繰り返すだけで済みます |

つまり衣服全体を4Kで描画する代わりに、**低解像度マスク + 小さなタイルテクスチャ群** で同じ情報を保有します。

:::danger[これらのテクスチャは Reviewed High Quality ベイクでも平坦化されません]
タイルを UV 全体に展開してベイクすると、容量の利点が失われ解像度も低下します。ベイカーはこれを認識してスキップします。 → [ベイクが削除するもの](/internals/bake-internals#텍스처-최적화)
:::

## 手順

1. `MingToon Material` スロットに対象マテリアルを配置します。
2. `Packed Region Mask` に RGBA マスクを配置します。
3. 4つのエリアをそれぞれ設定します。
4. `Apply Four Logical Regions` をクリックします。

この3つのいずれかが空でも `material, mask and region are required` でブロックされます。

### エリア別の項目

| 項目 | 機能 |
|---|---|
| `Mask Channel` | このエリアが読み込むチャンネル (R/G/B/A) |
| サーフェス テクスチャ・ティント | テクスチャレイヤーに組み込まれます |
| `Normal Strength` | ノーマルレイヤーに組み込まれます |
| `MatCap Strength` | MatCapレイヤーに組み込まれます |

### 何に変換されるのか

`Apply` をクリックするとコンポーザーがマテリアルのレイヤーモジュールを直接構成します。

| エリア設定 | 組み込まれる場所 |
|---|---|
| サーフェス テクスチャ・ティント・マスク | **テクスチャレイヤー** (`_MingStack*`) |
| ノーマル マップ・強度・マスク | **ノーマルレイヤー** (`_MingNormal*`) |
| MatCap・強度・マスク | **MatCapレイヤー** (`_MingMatcap*`) |

対応するモジュールの `使用` トグルと `レイヤー数` も調整されます。

:::note[適用後は通常のレイヤーマテリアルです]
コンポーザーはレイヤーを **入力するツール** であり、独立したランタイムや特別なモードは作成しません。適用後は [ディテールマップ](/guides/detail-maps) と [テクスチャスロット共通 UI](/guides/texture-modules) で通常通り編集できます。
:::

## マスク作成時

| 推奨 | 理由 |
|---|---|
| チャンネルを **重ならないように** 塗る | 1ピクセルが2つのエリアに属すると2つのレイヤーが重なります |
| 境界は **少しぼかす** | キツく切ると階段状の境界が見えます。低周波マスクの利点を活かしましょう |
| **sRGB をオフにする** | マスクは色ではなく重みです |
| 圧縮は好み | マスクは低周波なので圧縮アーティファクトは目立ちません |

:::tip[4つのエリアすべてが必要ない場合]
チャンネルを空のままにしておけます。2つのエリアのみを使用しても、ドローコール削減効果は変わりません。
:::

## いつ使う・使わないのか

| 状況 | 判定 |
|---|---|
| 衣服1着にマテリアルテクスチャが複数ある | ✅ このツールの正確な用途です |
| アバターのパフォーマンス等級を下げる必要がある | ✅ マテリアル数が削減されます |
| 繰り返されない大きな絵（イラストテクスチャ） | ❌ タイリングが成立しません。ベースマップをそのまま使用してください |
| エリアごとにサーフェスモードを変える必要がある | ❌ 1つのマテリアルはサーフェスモードが1つです。マテリアルを分ける必要があります |

:::caution[サーフェスモードは分割できません]
不透明な布と半透明なレースを1つのスロットに入れることはできません。サーフェスモード・カルモード・レンダーキューはマテリアル単位のプロパティです。 → [シェーダー構造とパス](/internals/shader-structure#표면-모드가-실제로-바꾸는-값)
:::
