# 深度ベースエフェクト

**このドキュメントを読むと** 深度リム・2Dシャドウ・インナー2Dエッジが見えない理由を診断でき、各プラットフォームで深度を確保する方法が分かります。

インスペクターの**深度ベースエフェクト**グループ — `深度`・`深度リム`・`2Dシャドウ`・`インナー2Dエッジ`を扱います。全項目リストは[深度ベースエフェクトリファレンス](/reference/depth-effects)にあります。

## 何が深度を使うか

このグループの4つのセクションは全部**カメラ深度テクスチャ**を読みます。深度がないと値をいくら触っても画面に出現しません。

:::danger[値を触る前に深度を最初に確認してください]
インスペクターが状態を直接教えます。

- `深度エフェクトがオフなため、このモジュールは描画されません。` → `深度エフェクトをオン`
- `このエフェクトはDepthがオンのカメラでのみ見えます。`
- `2D深度リムと2Dシャドウは深度を記録する不透明またはカットアウトマテリアルが必要です。透明キューでは深度エフェクトが無効化されます。`
- `アクティブなScene/Gameカメラの深度テクスチャが準備されていません。`

このメッセージが出ている間、幅や強度を触るのは意味がありません。
:::

:::note[インナー2Dエッジがここにある理由]
アウトラインのように見えますが画面深度を読むため、**アウトラインではなくこのグループ**に入っています。アウトラインで探して見つからないことがよくあります。
:::

## プラットフォーム別深度確保 {#플랫폼별-깊이-확보}

### VRChat（主要対象）

| 状況 | 深度 |
|---|---|
| **Photo Camera有効中** | ✅ 公式契約でホスト深度が有効になります |
| **ワールドがScreen Camera depthをオンの場合** | ✅ |
| **通常プレイヤー画面（既定）** | ❌ アバターが強制できません |
| **ミラー・ストリーム内部パス** | ⚠️ 保証されません |

Screen Camera設定は**ワールド/Udon側の権限**です。任意のCameraやLightをアバターへ追加することは、サポートされる解決策ではありません。例外はMingToon Managerの`アップロード時に深度ライトを含める`です。このデフォルトOFFのオプトインは、アップロード用コピーへシャドウを有効にしたDirectional Lightを追加しますが、他ユーザーのdepth pass・アバターランク・ワールド照明へコストを加えます。→ [VRChat深度ライト](/platforms/vrchat#vrchat-깊이-라이트)

アップロードでは`Depth Availability`を変更しません。`Auto`はカメラごとに実際にバインドされた深度を判定し、`Force On`は作成者が直接選んだ場合だけ維持されます。詳しくは[VRChat](/platforms/vrchat)を見てください。

:::tip[深度がない画面への対策]
[リム](/guides/rim)のリムライト・リムシェードと[アウトライン](/guides/outline)のノーマルアウトラインは**深度が不要です。**深度ベースエフェクトだけに頼らず、この2つでシルエットの基盤を敷いてください。
:::

### 一般Unity（BRP） {#일반-unity-brp}

シーンに`Studio Raming/MingToon/Depth Texture Provider`コンポーネントを置くだけです。アクティブなGameCameraがレンダリングする直前に必要なdepthフラグとカメラ行列を提供し、既存のカメラフラグは保存します。

### URP 12

1. `Tools > Studio Raming > MingToon > URP > Install Depth Effects Renderer Feature`を実行します。
2. アウトラインも使うなら`Tools > Studio Raming > MingToon > URP > Install Outline Renderer Feature`も実行します。
3. 使用中のURP Renderer DataでDepth Textureを有効にします。

### Warudo

DepthをオンにしたWarudoカメラが必要です。アバターバンドルだけではホストカメラを変えられない場合があります。→ [Warudo](/platforms/warudo)

## 深度の可用性 {#깊이-가용성}

深度テクスチャが**あるか ないかをどう判定するか**決める値です。4つの中から選びます。

| 値 | 意味 |
|---|---|
| `Auto` (デフォルト) | シェーダーが自分で見つけます。**そのままにしておいてください** |
| `Force On` | 自動判定が reach しないホストで作成者が深度バッファを保証します。**ミラーは除外です** |
| `Force Off` | 深度エフェクトを完全に無効にします |
| `Diagnostic` | 判定状態を画面に色で塗ります。**バグ報告用** |

:::caution[`Force On`はミラーをオンにしません]
ミラーカメラは自分の深度テクスチャを描画しませんが、プレイヤーカメラの深度バッファはそのままバインドされています。そのまま読むとキャラクターが**他のシルエット**を自分の影として使います — 頭を回すたびに2D影と深度リムが体に従わずスライドしていた現象がこれです。

だから `Force On` は「ホストが報告できない場合までオンにする、**ただしミラーは除外**」を意味します。ミラーの中では、どの値を選んでも深度モジュールが自動的に下がります。
:::

### Diagnostic — 報告する時だけ {#diagnostic}

深度エフェクトがアバター全体に広がっているように見える時、シェーダーが**実際にどの深度テクスチャを見ていたか**単色で塗って教えます。ルック全体が変わるため、普通の作業には使わないでください。

| 色 | 意味 |
|---|---|
| 黒 | 深度テクスチャがまったくない |
| 赤 | テクスチャはあるがこの画面のバッファではない（サイズが違うか、ミラー） |
| 黄 | ある、かつサイズも合ってる |
| 青チャンネルが混ざっている | ホストが深度可用を直接報告 |

レンダリング自体は変えません。診断色の下で回る深度判定は `Auto` と完全に同じです。

:::note[VRChatで確認するには再アップロードが必要です]
シェーダーはアバター AssetBundle に含まれているため、既にアップロードされたアバターは古いシェーダーを使用し続けます。 → [VRChat](/platforms/vrchat)
:::

## 見えない時の診断順序

上から順に確認してください。

1. **全エフェクト** — マスターがオフになってないか（[インスペクター使用法](/guides/inspector#전체-효과--가장-위의-마스터-스위치)）
2. **深度エフェクト**セクションのマスタートグル
3. **サーフェスモード** — 透明（深度非記録）なら全部オフになります。`透明・アウトライン深度記録`に変更してください
4. **マスター幅** — 0なら各モジュールの幅を上げてもぜんぶ何も出ません
5. **各モジュールの強度** — `リム強度`が0ならリム計算をスキップします
6. **カメラ深度** — 上のプラットフォーム別項目
7. 続くなら`Tools > Studio Raming > MingToon > Validate Project`

## 深度エフェクトマスター {#깊이--공통-값}

`2Dリムライト`と`2Dシャドウ`が共有する値で、マスターをOFFにするとSSAO・2D透過光・インナーアウトラインを含む深度グループ全体が無効になります。ここを先に調整してから各モジュールへ進んでください。

| 項目 | 機能 |
|---|---|
| `マスター幅` | 2つのモジュールの画面オフセットに共通に掛かる乗数。**0なら全て出ません** |
| `幅モード` | `Screen Pixels`は画面ピクセル基準・`Distance Stable`は距離・FOVが変わっても厚さ一定 |
| `距離スケール` | `Distance Stable`時の基準距離。`Screen Pixels`なら無視されます |
| `マスターバイアス` | この値を超える深度差だけを境界と判定。**下げると**浅い凹凸にも線が付いて汚くなり、**上げると**薄い部分の線が消えます |
| `マスター柔らかさ` | 低いとカチカチのインク線、高いとぼんやりぼかした境界 |

:::tip[アバターはDistance Stable]
カメラ距離が常に変わる環境では`Distance Stable`が厚さを一定に保ちます。
:::

### ランタイム切り替え {#런타임-전환}

- `FX Animatorで深度エフェクトを切り替え` — VRChat FXなどのAnimatorから深度エフェクトマスターをON/OFFできるよう、ベイク時の定数畳み込みを保留します。
- `FXメニューでシャドウ投影を切り替え` — MingToon ManagerのVRC Qualityメニューに`Shadow Projection`を追加します。OFFにするとフェザーサンプル・キャスト合成・関連する透過光計算をスキップします。

どちらもデフォルトはOFFです。ランタイムで実際に切り替えるマテリアルだけ有効にしてください。オプトインすると該当コードをベイク時に削除できないため、High/ON状態でもわずかな維持コストがあります。

## 2Dリムライト {#깊이-림-2d-림}

最終厚さ = `マスター幅` × `リム幅乗数`です。

- `リム強度` — **0なら計算をスキップします。**色と幅を変えても何も見えません。
- `ベース色混合` — 0なら単色リム、1ならベースマップ色を掛けて部位ごとに異なるリム色。
- `360度リム` — 0なら光源方向側のみ、1ならシルエット全体を囲む。
- `2Dリム方向` — リムが押し出される方向。
- `リムサンプル品質` — Low 1タップ / Standard 2タップ / High 4タップ。幅は同じで、内部線の抑制とコストだけが変わります。1タップでは目・鼻・衣装境界がリムとして漏れたり、カメラ移動時に1テクセル揺れたりする場合があります。4タップは細い内部線までより確実に除外します。

:::tip[照明がないか方向がよく変わる環境]
`360度リム`を上げておくと安定しています。
:::

`シルエット開始点`と`シルエット遷移柔らかさ`は**同グループの外郭シルエット制限が0なら全く反映されません。**

`クイック設定`の`2Dリム幅`・`2Dリム強度`がこのセクションの値です。

## 2Dシャドウ {#2d-그림자}

キャラクターのシルエットを画面空間で押し出してシャドウを作ります。前髪がおでこに落とすシャドウをリアルタイムシャドウなしで描く時に主に使用します。

### 基本

| 項目 | 機能 |
|---|---|
| `シャドウ明るさ` | 低いほど暗くなります。[キャストシャドウと統合](/guides/light-and-shadow#2d-그림자와-색이-따로-놀-때)しておくとこの値が統合層の明るさとして使われます |
| `追加深度バイアス` | マスターバイアスに加わるこのモジュール専用値 |

### 方向

`シルエット移動方向` — シルエットをどちら側に押すか決定します。

| 値 | 結果 |
|---|---|
| `光源投影方向` | 光源が押す方向そのまま。物理的に自然 |
| `光源投影反対` | 反対側。演出意図で反転する時 |

`2Dシャドウ照明方向追従`をオンにするとシーン光源を追従し、オフにすると固定されます。

:::tip[照明が予測不可能なワールドなら]
方向追従をオフにして固定する方が安定しています。ワールドごとに前髪シャドウが変な方に付くのを防ぎます。
:::

`上下オフセット`と`前後オフセット`でシャドウ位置を微調整できます。

### 顔専用補助

顔は別項目があります。

| 項目 | 機能 |
|---|---|
| `顔2Dシャドウ補助` | 顔領域で2Dシャドウを補強 |
| `顔固定方向` | 顔が基準とする方向を固定 |
| `顔自己面抑制` | 顔自体の面にシャドウがぺったり付くのを抑制 |

→ [キャラクター表現](/guides/character#4단계-앞머리-그림자)

### 張り付きと減衰 {#눌어붙음과-감쇠}

| 項目 | 機能 |
|---|---|
| `身体表面ガード` | 身体表面そのものにシャドウが張り付くのを防ぎます |
| `2Dシャドウ消失距離` | エフェクトが完全に消える距離。デフォルトは12mで9mから薄くなります。0では距離制限とコスト削減を無効にします |
| `距離減衰範囲`（`距離減衰と境界`グループ） | 遠くなるほど効果を弱めます |

:::caution[シャドウが身体にシミのように張り付いたら]
`身体表面ガード`を最初に上げてください。それでも残るなら`マスターバイアス`や`追加深度バイアス`を上げます。
:::

0.1.7では受信側の距離と表面傾斜に応じて深度許容差を安定化し、画面端では画面外タップを減衰します。遠距離では消失区間に合わせてサンプル数も減り、群衆シーンのコストも下がります。

## SSAO (画面空間遮蔽) {#ssao-화면-공간-차폐}

折り目や物が接する場所を暗くします。首やあごの下、脇、服のしわ、足が床に接する部分です。

:::tip[影ではなく遮蔽です]
`フォームシャドウ` をオフにしたマテリアルにもそのまま入ります。トゥーンバンドとスクリーントーンを**通過したあとで**合流するため、影の境界を階段状にしたり網点で二重に刷られたりしません。
:::

### オクルージョンマップとの合わさり方

乗算しません。両者を別々に計算し、**暗いほうを採用します。** マップであらかじめ塗った遮蔽がすでに暗い場所を SSAO がさらに暗くすることはなく、SSAO はマップが扱えない実際の姿勢や周囲の物による遮蔽だけを加えます。

### 値を決める順番

| 項目 | 何をするか |
|---|---|
| `SSAO 半径` | 遮蔽を探すワールド距離。範囲は0.001～0.01m、デフォルトは0.005mです |
| `SSAO 強度` | 強さ。0では切ったのと同じ絵になりますが計算は走り続けるため、使わないときは `SSAOを使用` をオフに |
| `SSAO コントラスト` | 暗くなるカーブを締めます |
| `SSAO 品質` | ピクセルあたりの深度サンプル数(4/8/12/16)。キーワード変種ではなく均一ループなので変種は増えません |

0.1.7のSSAOはビュー空間の接平面を使って傾斜面の自己遮蔽を減らし、二値タップゲートを滑らかなランプへ変更しました。バイアス0でも深度量子化の跡を防ぐ小さな内部下限が適用されます。

キャラクターサイズの対象ではStandard品質とデフォルト半径0.005mから始め、広い染みを作るより必要な接触部だけを残してください。

### 距離と画角が変わっても同じに

`SSAO 距離補正` が既定の1なら、カメラが近づいても離れても、画角を変えても、同じしわに同じ太さの陰影が入ります。画角は専用のコントロールなしで自然に相殺されます。0に下げると1メートル以内で半径が縮む従来の挙動に戻ります。

`SSAO 消失距離` は効果が完全に消える距離です。フェードは**その値の75%地点から**始まるため、12にすると9mで薄くなり始め12mで消えます。0では使用しません。

### ライト方向・マスク・色

- `SSAO ライト方向反応` — 遮蔽を探す円をキーライト側へ傾けます。0ではライトと無関係な均一の遮蔽になり、上げるほど光の当たらない側に遮蔽が集まります。ライトがカメラ正面に近づくほど傾きは自然に小さくなります。
- `SSAO マスク強度` — 専用テクスチャを新設せず `2Dシャドウマスク (共有)` をそのまま借ります。チャンネル・反転・HSVG は2Dシャドウマスクの設定を共有し、**どちらの画面から直しても同じ1枚を直すことになります。**
- `SSAO ティント` · `SSAO 明度` · `SSAO 彩度` — SSAO全体のカバレッジへ適用されます。フォームシャドウや逆光の中でも見え、デフォルトの白・明度1では結果は同じです。

:::caution[深度がなければ静かに消えます]
新しいライトでもプロバイダーでもポストプロセスパスでもありません。このページ上部の[プラットフォーム別の深度確保](#플랫폼별-깊이-확보)がそのまま当てはまります — 2D深度シャドウが出る場所で出ます。深度がない場合は遮蔽が1(遮蔽なし)に固定されるため、ルックが壊れることはありません。
:::

## 2D透過光 {#깊이-투과광}

髪の毛の先や衣装の裾のような**薄い部位が光を透す**ように見えるようにします。

:::tip[このモジュールだけマスター幅に結ばれていません]
光源方向に深度を**2度読んで**光がキャラクターをどれだけ通り抜けたか直接読みます。そのため2Dリムライト・2Dシャドウと無関係に**独立して動作**します。`マスター幅`が0でも出ます。
:::

### 1. 薄さをどう測るか {#1-얇음을-어떻게-잴지}

| 項目 | 機能 |
|---|---|
| `透過強度` | 全体の明度乗数。**0なら計算をスキップします** |
| `測定幅` | 光源方向にどれだけ遠く見るか。大きくすると厚い部位まで薄いと判定され、小さくするとごく薄い先端部分だけ光ります |
| `深度範囲` | この分（m）後ろが空いていたら完全に透通ったと見なします |
| `殻最小厚さ` | 以下を参照 |

:::caution[髪の後ろの衣装が背景に誤認されて明るくなったら]
`深度範囲`を上げてください。少し後ろにある表面が「透通った」と読まれています。
:::

:::danger[空洞な衣装は必ず殻最小厚さを与えてください]
スカートやマントは画面上の幅が広い**ため厚いと測定されますが、実際の布はとても薄いです。**

- スカート・マント等の殻 → **0.8程度**。測定と無関係に常に薄く扱われます
- 皮膚・手のような中身が詰まった部位 → **0**。測定に任せます
:::

### 2. 光が広がる性質

| 項目 | 機能 |
|---|---|
| `密度` | 大きいほどごく薄い場所にだけ光が残って濃い材質のように見え、低いと広く広がります |
| `露出柔らかさ` | レスポンス曲線だけを変更します。**境界位置は移動しません** |
| `色分離` | 赤が青より深く深度に浸透する散乱を再現。チャンネルごとに減衰が異なって**ティントでは作れない**皮膚・髪特有のぼかしが生じます。0なら3チャンネルが同一 |

### 3. どの角度で光るか

| 項目 | 機能 |
|---|---|
| `逆光減衰` | 大きいほど正確な逆光でのみ狭く強くなります |
| `正面光床値` | 正面光で残る比率 |
| `ノーマル方向曲げ` | 光方向を表面法線方向に曲げ、正確な逆光でなくても曲面に沿って光が漏れ出るようにします |
| `視線方向曲げ` | 光方向をカメラ方向に曲げます |
| `シーンライト影響` | 0なら指定した色だけ、1ならシーン照明色をそのまま受けます |

:::danger[`正面光床値`を0にしないでください]
散乱は逆光では強くなりますが、**正面光では消えません。**0にすると皮膚が皮膚に見えません。
:::

:::tip[髪カードがちらつくなら]
平面カードはノーマルが信用できないため`ノーマル方向曲げ`だけでは光がついたり消えたりします。**`視線方向曲げ`がそれを防ぎます。**
:::

### 4. 2つの層で色を作る

縁層と内層が別々にあります。**片方の強度を0にすると、残りの1層だけがあるシングル層と完全に同じになります。**

| | 縁層 | 内層 |
|---|---|---|
| 明るくする場所 | シルエット外側 | シルエット内側 |
| 強度 | `縁強度` | `内強度` |
| 減衰 | `縁減衰` | `内減衰` |
| 色 | `縁色補正` → `縁ティント` | `内色補正` → `内ティント` |

:::tip[色補正はベース色から派生しています]
絶対色ではなく**ベースマップ色から作り出されます。**そのため金髪は黄色く、黒髪は暗く — **キャラクター全体が設定1つで揃います。**

既定値は内層の色相を赤側に回して彩度を上げ、縁は白い光に近く内側は暖かく光る髪の毛感を作ります。

中立値`(0,1,1,1)`なら補正をスキップします。
:::

## インナーアウトライン {#내부-2d-경계}

画面深度差で**表面内側**の境界線を描きます。追加ジオメトリがないのでノーマルアウトラインが壊れるメッシュにも使用できます。

:::danger[サーフェスモードが透明なら動作しません]
半透明が必要なら`透明・アウトライン深度記録`を使用してください。
:::

調整項目：

- `深度バイアス` — この値より大きい深度差だけを境界と判定します。**下げると**緩やかな凹凸にも線が付いてノイズになり、**上げると**薄い部分の線が消えます。
- `柔らかさ` — 0は硬い線、1は線幅全体が境界から内側端まで完全にぼかされます。
- `カメラ距離・画角安定化` — カメラが動いても線の厚さが一定に保たれます。

:::caution[インナー2Dエッジが全て消えたら]
`Inner Edge アウトラインに適用`トグルを確認してください。このトグルはノーマルアウトライングループ内にあります**がノーマルアウトラインをオフにしても内部2Dエッジに作用し続けます。**頂点カラーが黒いメッシュでオンになっていると内部2Dエッジが全て消えます。
:::

## 半透明表面と深度

サーフェスモードが2通りに分かれ、違いは**深度を記録するか**です。

- **透明・アウトライン深度記録** — 深度テクスチャを作る範囲**内**です。2Dシャドウ・深度リム・インナー2Dエッジが全て動作します。**半透明が必要なら最初にこちらを検討してください。**
- **透明** — その範囲**外**です。深度ベースモジュールはオフのままです。オンにするとキャラクターの後ろにあるものと比較することになります。

不透明とカットアウトは影響を受けず、常に完全な深度を持ちます。
