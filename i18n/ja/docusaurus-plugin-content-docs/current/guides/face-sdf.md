# 顔 SDF オーサリング

**このドキュメントを読むと** 光源が顔の周りを動くとき、影がアニメーションのように**すべらせ動く**顔が作成できます。

## SDF が解決する問題

顔のノーマルを押して鼻の影を消す場合([キャラクター表現ステップ 2](/guides/character#2단계-코-그림자-없애기))、顔はきれいになりますが**完全に平た**くなります。光源が横に動いても影の境界が生じません。

SDF は別のアプローチです。**顔の影がどの順序でカバーされるかをテクスチャに事前に描き、** 光源の角度に応じてそのテクスチャを閾値でカットして使用します。アニメーションで顔の影が鼻を沿ってするする動く動きは、このように作られます。

## 2 つを区別してください

MingToon には顔関連のベイクが**2 つ**あります。紛らわしいです。

| | 顔フロントビューノーマル (UV7) | 顔 SDF テクスチャ |
|---|---|---|
| **何** | メッシュに焼く**頂点データ** | 描いて作る**テクスチャ** |
| **どこから** | `MingToon マネージャ` → ルック / 顔 | 顔 SDF オーサリングウィンドウ |
| **役割** | シェーダが顔の正面方向を認識 | 影がカバーされる順序を定義 |
| **ドキュメント** | [メッシュ UV ベイク](/guides/mesh-bakes#얼굴-프론트뷰-노멀-uv7) | このドキュメント |

:::tip[通常は両方使います]
UV7 があれば**ランタイムスクリプトなしで** 4 方向 SDF が動作します。SDF テクスチャは影の形状を定義します。VRChat/Warudo にアップするアバタなら UV7 をまず焼き、SDF テクスチャを作成してください。
:::

## レイヤー形式顔 SDF 編集

オーサリングウィンドウは**部位ごとに別々に描いて最後に統合する**方式です。

> 基本シェーディング・鼻・頬・唇・アイホールをそれぞれ編集します。**プレビューと最終ベイクは RGBA 1 枚のみを使用します。**

### 5 つのレイヤー

| レイヤー | 担当 | 備考 |
|---|---|---|
| **基本シェーディング** | 顔全体がカバーされる大きな流れ | **必須** — なければベイクは拒否されます |
| **鼻詳細表現** | 鼻筋・鼻の付け根の影 | |
| **頬詳細表現** | 頬骨下の陰影 | **右側のみ描けば左は自動ミラー** |
| **唇表現** | 唇の周り | |
| **アイホール表現** | 眼窩の影 | **右側のみ描けば左は自動ミラー** |

:::note[ミラーは「見ている人基準の右」です]
ウィンドウにこのように案内されます。

> 見ている人基準右側のアイホールを配置すると左側は**顔の中央を基準に自動ミラー**されます。

半分だけ描けば済むので作業量が半減し、左右対称が自動保証されます。
:::

### レイヤー別調整項目 {#레이어별-조정-항목}

| 項目 | 機能 |
|---|---|
| `テクスチャ` | このレイヤーに使用するイメージ |
| `サイズ` | スケール |
| `位置` | 配置 |
| `反転` | グレースケール反転 |
| `ぼかし度` | 境界のソフトさ |
| `タイミング強度` | **このレイヤーが影の進行順序でどれだけ前/後ろに押されるか** |

:::tip[`タイミング強度` が SDF のコアです]
SDF は「どのくらい暗いか」ではなく**「いつカバーされるか」**を格納します。タイミングを調整すると、光源が回るとき鼻が先にカバーされるか、頬が先にカバーされるかが変わります。

アニメーション ルックでは通常**鼻 → 頬 → 眼窩 → 顔全体**の順序で動きます。
:::

## 作業順序

1. **基本分離レイヤーのロード** — 付属のデフォルトレイヤーセットで開始します。
2. `基本シェーディング` テクスチャを入れます。**これがないとベイクは拒否されます** (`基本シェーディングテクスチャが必要です。`)。
3. 部位別レイヤーを配置し、`サイズ`・`位置` を合わせます。
4. `タイミング強度` でカバー順序を調整します。
5. **ライブプレビュー**で確認します。
6. `出力サイズ` を決定してベイクします。

### ライブプレビュー

`ライブプレビュー即時更新` で現在の状態を直ちに反映します。更新中は `ライブプレビューを更新中です。` が表示されます。

:::tip[シーンビューで光源を回転させながら見てください]
静止画では タイミングが正確かどうかわかりません。方向光を左右に回しながら、影がスムーズにすべるかを確認してください。これが SDF を使う唯一の理由です。
:::

### 編集プロフィール

`レイヤー編集プロフィール作成` で現在のレイヤー構成を保存します。他のキャラに同じ構成を再利用したり、後で再度編集するときに使用します。

---

## 出力

| 項目 | 内容 |
|---|---|
| 最終結果 | **RGBA 1 枚** |
| ワークパス | `.../FaceSDF/Packed/MingFaceSDF_Author_{GUID 前 8 文字}` |
| プレビューパス | `.../FaceSDF/Preview/MingFaceSDF_Preview_{...}` |
| マテリアルスロット | `_FaceSdfMap` |

オーサリング設定は `_FaceSdfAuthoringEncoding` にエンコードされて**マテリアルに一緒に保存**されます。後でウィンドウを再度開くと、作業していたレイヤー構成が復元されます。

:::caution[マテリアルごと GUID でファイルが分かれます]
マテリアルを複製すると SDF ワークも新しい GUID に分かれます。複数のキャラが同じ SDF を共有したい場合、テクスチャを直接 `_FaceSdfMap` に指定してください。
:::

## SDF を使うか判断

| 状況 | 判断 |
|---|---|
| 光源が固定の演出 | **不要。** ノーマル押し + 顔境界で十分です |
| VRChat ワールドを歩き回るアバタ | **効果大。** 照明が予測不可能なほど価値があります |
| Warudo 配信 | **効果大。** 照明を変えながら使う場合 |
| 作業時間がない | スキップしてかまいません。残りの顔処理だけで十分きれいになります |
