# 顔 SDF と Face SDF Studio

**このドキュメントを読むと**、フェイスシェーディングと顔 SDF の違いを理解し、準備したSDFマップをInspectorへ直接接続して方向性のある顔の影を調整できます。

## まず区別してください

| 機能 | 内容 | 必要なデータ |
|---|---|---|
| **フェイスシェーディング** | 顔領域の法線、形状影の境界、キャスト動作を体と異なる方法で処理 | 顔領域マスクまたはプロキシ |
| **顔 SDF** | 光源方向に応じた鼻・頬・まぶたの覆われる順序をテクスチャで制御 | 顔 SDF マップ、必要に応じて正面 UV7 |
| **Face SDF Studio** | レイヤー編集、プレビュー、UV7 投影、最終 SDF ベイクのための別アドオン | 未リリース・必須ではない |

SDF がなくてもフェイスシェーディングは動作します。まず [フェイスシェーディング](/guides/character#페이스-셰이딩) で顔を整え、光源の移動に合わせたアニメーションのような影の切り替えが必要な場合に SDF を追加してください。

:::note[Face SDF Studioは別製品の未リリースアドオンです]
Face SDF Studioは公開MingToonパッケージに含まれない別製品で、このガイドの使用経路には必要ありません。準備したSDFテクスチャをMingToon Inspectorへ直接割り当ててください。Studioのインストール、メニュー、連携ボタンを前提にしません。

他の別売り連携については[Mask Maker 連携](/guides/mask-maker)と[Ming Light Controller 連携](/guides/ming-light-controller)を参照してください。
:::

## SDF マップ形式 {#sdf-맵-형식}

`SDF マップ形式` で次の 2 方式から 1 つを選びます。

| 形式 | チャンネル | 推奨する状況 |
|---|---|---|
| **Packed RGBA** | R=左、G=右、B=上、A=下 | 上下の照明も使う MingToon の基本方式 |
| **Single Channel Mirrored U** | R 1 枚、反対側の水平光は U を反転 | 既存の単一チャンネル SDF をすばやく取り込む場合 |

Single Channel は垂直光の影響を使用しません。上下方向の変化も必要な場合は Packed RGBA を使用してください。

### ベイク結果を確認する

Packed RGBA は1枚のテクスチャに4方向を保存します。**R=左・G=右・B=上・A=下**です。`Single Channel Mirrored U` はRだけを読み、反対側の水平光ではUを反転するため、垂直チャンネルは使用しません。

`Baked Front UV7` では、正面投影の結果がメッシュのUV7（TEXCOORD6）に書き込まれます。そのRendererではUV7をFace SDFが所有するため、同じUV7を顔ノーマルのベイクにも同時に使わないでください。マップの準備に使った形式・座標とInspectorの選択が一致することを確認し、左右と上下の照明コントロールを別々に動かして4方向が入れ替わっていないか確認します。

### 座標の選択

- `Base Texture UV (Legacy)` — 既存の UV0 をそのまま読み取ります。
- `Baked Front UV7` — Scene の正面構図を UV7 に投影します。顔メッシュ UV が複数の断片に分かれている場合や、VRChat・Warudo で正面基準を安定して維持したい場合に推奨します。

:::caution[UV7の所有権は1つだけです]
顔ノーマルは編集中にLiveで動作し、VRChatアップロード用コピーにのみ自動ベイクされます。Face SDFが`Baked Front UV7`を使用する場合はSDFがUV7を所有し、アップロード時の顔ノーマルベイクはそのRendererをスキップします。

古いtangent-normal UV7が残るマテリアルで`Baked Front UV7`を選ぶと座標を誤読します。`Base Texture UV (Legacy)`へ戻すか、そのマップと一緒に準備した正しいUV7 payloadがある場合だけ`Baked Front UV7`を選んでください。必要ならMingToon Managerの`顔ノーマルをリアルタイムへ戻す`を実行します。→ [メッシュ UV ベイク](/guides/mesh-bakes#얼굴-프론트뷰-노멀-uv7)
:::

## 準備したマップをInspectorに接続する {#face-sdf-studio-작업-순서}

Face SDF Studioなしでも、準備したマップを直接使用できます。

1. `フェイスシェーディング`をオンにします。
2. `SDF 顔の影を使用`をオンにします。
3. `SDF マップ形式`で`Packed RGBA`または`Single Channel Mirrored U`を選びます。
4. `顔 SDF マップ`へ準備したテクスチャを割り当てます。Packed RGBAはRGを左右、BAを上下に使い、Single ChannelはRを左右へミラーして使います。
5. `SDF座標`では`Base Texture UV (Legacy)`を選びます。マップと一緒に正しい正面投影UV7 payloadを準備済みの場合だけ`Baked Front UV7`を選択してください。
6. `左右の影響`・`上下の影響`・`SDF 影の量`を調整します。Single Channelでは上下の影響を使いません。
7. 実際のアバター照明で`境界オフセット`と`境界の滑らかさ`を調整します。
8. 左右と上下の照明コントロールを別々に動かし、4方向が入れ替わっていないか確認します。

:::tip[座標を準備したマップに合わせる]
Inspectorの`Baked Front UV7`は、マップと一緒に準備した既存のUV7 payloadを読みます。ベイクボタンではありません。対応する正面投影データがなければ`Base Texture UV (Legacy)`を使ってください。
:::

:::caution[マップが空の場合]
準備したマップを割り当てるか、`SDF 顔の影を使用`をオフにしてください。グレーの既定値では方向性のある影効果は生まれません。
:::

## トラブルシューティング

### フェイスシェーディングをオンにすると Base Pass が消える

リリースビルドでは内部コンパイル診断トグルは表示されません。次の順で確認してください。

1. Consoleのシェーダー・C#コンパイルエラーを先に解決します。
2. マテリアルを再選択し、スキーマとキーワードの同期を実行します。
3. ベイク済みマテリアルならMingToon Managerで編集用マテリアルへ復元してから再ベイクします。
4. それでも消える場合は、UnityバージョンとグラフィックスAPIを含むエラーログを提出してください。

メンテナンス用バリアントダンプと技術診断は`MINGTOON_DEV`開発ビルドでのみ使用できます。

### 左右が逆に動く

Packed RGBA の R/G チャンネル配置と顔の正面方向を確認してください。Single Channel は反対側の光源で U を自動反転するため、元のマップ自体を左右反転しません。

### 顔の境界に白いジグザグが見える

形状影の境界が跳ねる場合は、以前のMingToonシェーダーや古いベイク版が残っていないか確認してください。マテリアルを現在の編集シェーダーへ戻し、準備したFace SDFマップと座標をもう一度確認すると、最新の境界補正が適用されます。

## SDF を使うか判断する

| 状況 | 判断 |
|---|---|
| 光源が固定された演出 | フェイスシェーディングだけで十分な場合があります |
| VRChat ワールドを移動するアバター | 照明が予測できないため効果が大きいです |
| Warudo 配信 | 照明方向を変えて使うなら効果が大きいです |
| 作業時間が不足 | スキップしても残りの顔処理は正常に動作します |
