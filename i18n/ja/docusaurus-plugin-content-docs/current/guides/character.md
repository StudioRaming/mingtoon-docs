# キャラクター表現

> このページは**フェイスシェーディングモジュール**をはじめてオンにする方のためのものです。
> 鼻の影を消し、顔だけを体とは違う陰影ルールにします。約 8 分かかります。

## これは何ですか

顔には鼻とまぶたの実際の凹凸があります。
体と同じ影の設定を使うと、ほぼ必ず汚くなります。

0.1.11の**顔・ヘアシェーディング**タブは、顔領域 → 顔シェーディング → 影方式 → 基準とプロキシ → 詳細の順です。
顔プロキシとSDFはヘアマテリアルにも使え、不要な状態表示の折りたたみを削除しました。

![鼻の影が出た顔とフェイスシェーディングで整理した顔の比較](/img/placeholder.png)

## いつ使いますか

- 正面からの照明で鼻の影が顔を分断するとき。
- 前髪の影を照明と無関係に一定に保ちたいとき。

## 30 秒で試す

1. 変換した顔のマテリアルを選びます。
2. **フェイスシェーディングモジュール**をオンにします。
3. **プロキシノーマル強度**を 1 に上げます。
4. **顔の境界**を 0.25 に上げます。既定値は 0 です。

鼻とまぶたのまだらな陰影が消えれば成功です。
何も変わらない場合は[トラブルシューティング](/troubleshooting#face)へ進んでください。

## フェイスシェーディング {#페이스-셰이딩}

### ステップ 1: 顔の領域を指定 {#방법-a--얼굴-영역-마스크-권장}

マスクは、効果を適用する部分だけを白く塗った白黒画像です。

1. **顔領域マスクを使用**をオンにし、**顔領域マスク**にテクスチャを入れます。
2. **マスクチャンネル (RGBA)** に重みを入れます。G だけを使うなら `(0, 1, 0, 0)`。
3. 顔が黒く描かれたマスクなら**マスク反転**をオンにします。
4. **リマップ開始**と**リマップ終了**で境界を整えます。

4 つの指定方法が重なった場合は、上から 1 つだけが使われます。

| 順位 | 方法 | オンにする項目 |
|---|---|---|
| 1 | テクスチャの顔マスク | **顔領域マスクを使用** |
| 2 | 頂点ペイント | **頂点ペイントで顔領域を指定** |
| 3 | プロキシボリューム | **プロキシメッシュノーマルを使用** |
| 4 | マテリアル全体 | 上の 3 つがすべてオフの状態 |

**マスク強度**が 0 だと、マテリアル全体を顔として扱います。

### 顔の領域を SceneView で塗る {#얼굴-영역을-sceneview에서-칠하기}

1. **頂点ペイントで顔領域を指定**をオンにします。
2. **顔領域のペイント開始**を押します。
3. SceneView で顔を塗り、Shift を押しながら塗って消します。
4. 境界は Harden または Smooth で整理して保存します。
5. ペイントを使うときは**顔領域マスクを使用**をオフにします。

### ステップ 2: 鼻の影をなくす {#2단계-코-그림자-없애기}

プロキシは、シェーディング計算にだけ使う見えない基準形状です。

1. **プロキシメッシュノーマルを使用**をオンにします。
2. **プロキシ形状**で**平面**を選びます。リストの最初の項目です。
3. **プロキシノーマル強度**を上げます。0 は元のノーマル、1 はプロキシのノーマルです。
4. SceneView の顔プロキシツールで中心と半径を合わせます。
5. **プロキシ境界のぼかし**で首と生え際の遷移幅を合わせます。

:::note[残り 3 つの形状は実験的です]
**球（実験的）** · **円柱（実験的）** · **カプセル（実験的）** は結果が保証されません。
:::

### ステップ 3: 顔専用の陰影境界 {#3단계-얼굴-전용-음영-경계}

- **顔の境界**がもっともよく使う調整です。下げるほど遅く暗くなります。
- **既定の顔形状影を除去**を 1 にすると、顔のフォームシャドウが消えます。
- **フォームシャドウ**セクションがオフだと、顔の境界は反映されません。

### ステップ 4: 前髪の影 {#4단계-앞머리-그림자}

**顔の影の方式**グループの**影の方式**の 1 行で決めます。

| 値 | 結果 | 使いどころ |
|---|---|---|
| **体と同じリアル影** | シーンのリアルタイムの影をそのまま受けます | 顔を別扱いしないとき |
| **デプス影（顔補正）** | 顔でデプスシャドウが柔らかく落ちるよう補助します | アニメルック |
| **カスタム** | 値を自分で合わせた状態 | 上の 2 つの組み合わせから外れると自動表示 |

![デプス影の顔補正をオフにした額とオンにした額の比較](/img/placeholder.png)
<!-- CAPTURE: guides/character-02-bang-shadow-before-after.png | 앞머리가 있는 얼굴 정면, 그림자 방식 리얼 그림자(전) / 뎁스 그림자 얼굴 보정(후) 2컷 | 1200x700 -->

**デプス影（顔補正）** はカメラ深度がないと見えません。
深度は、カメラが測る「何がどれだけ手前にあるか」の情報です。
確保の方法は[深度ベースエフェクト](/guides/depth-effects#플랫폼별-깊이-확보)にあります。
リアルタイムの影がずれる場合は、**実シャドウキャスターオフセット**で押して合わせます。
顔が前髪の影をより受けやすくするには**受信面プッシュバック**を使います。
この値は[デプスシャドウ](/guides/depth-effects#2d-그림자)のタブにあります。

## よく触る値

| インスペクターのラベル | 何が変わるか | 推奨の開始値 | 上げると / 下げると |
|---|---|---|---|
| **プロキシノーマル強度** | 顔のノーマルをプロキシの曲率に置き換える量 | 1 | 0 なら元のノーマル、1 なら鼻の影が消えます |
| **顔の境界** | 顔にだけ適用される陰影境界の位置 | 0.25 (既定値 0) | 上げると早く暗くなり、下げると遅く暗くなります |
| **顔の柔らかさ** | 顔の陰影境界のぼかし幅 | 既定値のまま(0.15) | 上げると柔らかくなり、下げるとはっきりした線になります |
| **既定の顔形状影を除去** | 顔のフォームシャドウを消す量 | 0 | 1 なら鼻・頬の影が完全に消えます |
| **プロキシ境界のぼかし** | プロキシ境界で顔領域がほどける幅 | 既定値のまま(0.15) | 上げると首へつながり、0 だときっぱり切れます |
| **下部カラー** | キャラクターの下部に染みる色 | ベースより暗い色 | 白なら変化なし |

## キャラクター高さグラデーション {#캐릭터-높이-그라데이션}

キャラクターのルートを基準にした高さで、下部と上部を別の色に染めます。
足元を暗く敷いて接地感を作るときに使います。

1. **キャラクター高さグラデーション**をオンにします。
2. **下部カラー**をベースより少し暗くします。
3. **境界の高さ**と**境界の柔らかさ**で、混ざる地点と幅を合わせます。

:::danger[UV4 の高さベイクが先です]
キャラクター全体のルートを基準にした高さが UV4 にないと、位置が合いません。
メッシュ単位ではなくキャラクター単位です。
→ [メッシュ UV ベイク](/guides/mesh-bakes#캐릭터-높이-uv4)
:::

## よくある問題

### マスクを塗ったのに効きません

テクスチャマスクがオンだと、頂点ペイントとプロキシは無視されます。

### プロキシを動かしても反応がありません

以前のバージョンで顔のノーマルをベイクしたマテリアルの可能性があります。
MingToon マネージャーの**ベイク顔ノーマルを解除**を実行してください。

### 首と手まで顔になってしまいました

プロキシボリュームが大きすぎます。半径を小さくするか、マスクで指定してください。
