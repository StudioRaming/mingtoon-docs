# キャラクター表現

**このドキュメントを読むと** 鼻影と前髪影を制御でき、顔だけを身体と異なるシェーディングルールで作成できます。

インスペクターの**キャラクター表現**グループ — `フェイスシェーディング`・`キャラクター高さグラデーション`を扱います。全項目リストは[キャラクター表現リファレンス](/reference/character)にあります。

---

## フェイスシェーディング {#페이스-셰이딩}

### なぜ顔だけ別々に扱うのか

顔は鼻と目の上が実際の曲がりを持っているため、身体と同じフォームシャドウ設定を使うと**ほぼ常に汚くなります。**アニメーション調ルックで顔がきれいに見えるのは、顔のシェーディングルールが身体と異なるからです。

MingToonはこれを2段階で処理します。

1. **どこまでが顔か** — 顔領域を指定
2. **顔に何を違う様にするか** — 法線プレス、境界調整、シャドウ除去

<!-- SCREENSHOT: フェイスシェーディング適用前/後比較 -->

### 1段階：顔領域を指定

髪と身体が1つのマテリアルに混在していたら、どこまでが顔かを知らせる必要があります。

#### 方法A — 顔領域マスク（推奨） {#방법-a--얼굴-영역-마스크-권장}

1. `顔領域マスク使用`をオンにします。
2. マスクテクスチャを入れます。
3. `マスクチャンネル（RGBA）`にウェイトを入れます。Gチャンネルのみ使うなら`(0, 1, 0, 0)`。
4. 顔が黒く描かれたマスクなら`マスク反転`をオンにします。

境界を調整する項目：

- `マスク強度` — **0ならマスクを無視してマテリアル全体を顔と見なします。** 1がマスクそのまま。
- `リマップ開始` / `リマップ終了` — マスクのグレー範囲を再度広げます。開始を上げると顔の範囲が狭まり、終了を下げると境界が急になります。**両者が同じと境界が完全にカチカチになります。**

### SceneViewで顔領域をペイント {#얼굴-영역을-sceneview에서-칠하기}

マスクテクスチャを作らず、Meshの頂点値で顔領域を指定できます。

1. `頂点ペイントで顔領域を指定`を有効にします。
2. `顔領域のペイント開始`を押します。
3. SceneViewでPaintを使って顔を塗り、Shiftを押しながら塗ると消去します。
4. 境界はHardenまたはSmoothで整え、三角形を即座に塗る場合はHard Faceを使います。
5. `編集メッシュのみ表示`で対象Rendererを隔離し、必要に応じてX対称や`L`/`Shift+L`の連結アイランド塗りを使います。
6. 終了時に`保存`・`破棄`・`キャンセル`のいずれかを選びます。

:::caution[テクスチャ顔マスクが優先されます]
`顔領域マスクを使用`が有効な場合、頂点ペイントは無視されます。ペイントを使う場合はテクスチャマスクを無効にしてください。マスクが有効なままテクスチャが未設定だと、マテリアル全体が顔として扱われます。
:::

ペイントしたチャンネルはアウトライン圧力チャンネルと分けられるため、1つのMeshで両方の機能を使用できます。

#### 方法B — プロキシ球 {#방법-b--프록시-구}

マスクテクスチャなしで仮想球の内側を顔と見なします。

1. `プロキシ球を顔領域として使用`をオンにします。
2. シーンビューの**顔プロキシツール**で`プロキシ球中心`と`プロキシ球半径`を合わせます。数字を直接入力するより正確です。

:::caution[球が大きすぎると]
首や手まで顔として処理されます。画面で確認しながら減らしてください。
:::

:::note[両方オンにしたら]
`顔領域マスク使用`が優先され、プロキシ球オプションは無視されます。
:::

### 2段階：鼻影を取る {#2단계-코-그림자-없애기}

顔の法線を押して凹凸が作る影を消します。

1. `法線プレス量`を上げます。**0なら下の項目が全て無視されて**元々のメッシ法線がそのまま使われます。
2. `法線方式`を選択します。

| 値 | 結果 |
|---|---|
| 0 | 顔法線を**正面方向に完全に押して**鼻影が消える |
| 1 | プロキシ球に沿った緩やかな曲面 |

`法線方式`を1側で使うにはプロキシ球の中心・半径が合っている必要があります。

`顔固定方向`で顔が基準とする方向を調整できます。

### 3段階：顔専用シェーディング境界 {#3단계-얼굴-전용-음영-경계}

- `顔の境界` — 範囲は0～1、既定値は0.25です。**0に近いほど顔が遅く暗くなり**、1に近いほど早く暗くなります。最もよく使う調整です。
- `顔柔らかさ` — 顔領域の境界のぼかし幅。
- `基本フォームシャドウ除去` — 1なら顔領域のフォームシャドウを**完全に消します。**鼻・頬の影を消して2Dシャドウまたはシャドウテクスチャだけで顔の陰影を作る時に使用します。

:::caution[フォームシャドウセクションがオフなら]
`顔境界`と`顔柔らかさ`は反映されません。
:::

### 4段階：前髪影 {#4단계-앞머리-그림자}

2つの方向のいずれかを選択してください。

#### 実シャドウを使う

既定状態です。位置がズレたら`実シャドウキャスターオフセット`で顔のシャドウキャスターを前後に押して微調整できます。

#### 2Dシャドウだけで描く

1. `顔がリアルタイムシャドウをキャスト`を**オフにします。**顔メッシがリアルタイムシャドウを落とさなくなります。
2. おでこの影を[2Dシャドウ](/guides/depth-effects)またはシャドウテクスチャで描きます。

こちらがアニメーション調に近く、照明が変わっても前髪影の形が揺らぎません。

### 顔にリアルタイムシャドウのムラが出た時

`影投影`セクションの`顔キャスト安定化`で扱われます。→ [ライティングとシャドウ](/guides/light-and-shadow#얼굴의-스치는-그림자)

### 顔SDF — スクリプトなしで使う

付属のFace SDF Studioでは、Packed RGBA 4方向またはSingle Channelの顔SDFを作成できます。`Baked Front UV7`を使うとランタイムコンポーネントなしで方向性のある顔影が動作し、VRChatアップロードやWarudo Modに適しています。→ [顔SDFとFace SDF Studio](/guides/face-sdf)

:::tip[先にフェイスシェーディングを整えてください]
SDFは影が覆う順序を変える機能です。顔領域、法線の平坦化、`顔の境界`のずれを代わりに修正するものではありません。
:::

## キャラクター高さグラデーション {#캐릭터-높이-그라데이션}

キャラクター**ルートを基準とした高さをUV4に焼いておき、** その高さで色を染めます。足元を暗くしたり衣装の裾に色を乗せる時に使用します。

:::danger[最初にUV4を焼く必要があります]
キャラクター**全体**のルート基準高さがUV4.xにある必要があります。メッシ単位ではなくキャラクター単位です。→ [メッシ UV ベイク — キャラクター高さ（UV4）](/guides/mesh-bakes#캐릭터-높이-uv4)
:::

| 項目 | 機能 |
|---|---|
| `下部カラー` / `上部カラー` | 2つの色 |
| `グラデーション方向` | 上→下に変更すると2つの色の位置が入れ替わります |
| `境界の高さ` | 2つの色が半々に混ざる高さ |
| `境界の柔らかさ` | 境界を基準にぼかす幅。**0なら完全に切れます** |
| `カーブ指数` | 遷移曲線 |
| `影響度` | 全体の適用量 |

:::tip[よくある使用法]
`上部カラー`を白（変化なし）にして`下部カラー`だけ暗くすると、足元に向かって自然と沈み込む接地感が生じます。
:::
