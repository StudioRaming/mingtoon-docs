# アウトライン

**このドキュメントを読むと** ノーマルアウトラインを設定し、部位ごとに太さを調整できます。

インスペクターの**アウトライン**グループ — `ノーマルアウトライン` を扱います。全項目の一覧は[アウトラインリファレンス](/reference/outline)にあります。

:::note[内側2Dエッジはここにはありません]
表面内側の線を描く `内側2Dエッジ` は画面深度を読み取るため**深度エフェクト**グループにあります。 → [深度エフェクト](/guides/depth-effects#내부-2d-경계)
:::

## ノーマルアウトライン {#노멀-아웃라인}

メッシュを反転して拡張する方式です。追加パス1回で描画され、**深度テクスチャなしで動作**するため、どの環境でも安全です。VRChat通常画面のように深度が使えない場所でシルエットを捉える唯一の方法です。

### 基本設定 {#기본-설정}

1. `Classic Hullを使用`をオンにします。
2. `幅モード`を選びます。

| 幅モード | 動作 | 推奨 |
|---|---|---|
| `PixelStable` | 画面ピクセル基準。距離に関わらず厚さ一定 | **アバターはこちら** |
| `WorldSpace` | ワールドサイズ基準。遠くなると薄くなる | 固定カメラ演出 |

3. `アウトライン幅`と`アウトライン色`を調整します。（`クイック設定`にもあります）

**このようになれば正常です。** キャラクターシルエットの外側に線が描画されます。

## 線の太さを部位ごとに変える {#선-굵기를-부위마다-다르게}

### 圧力ソースを選ぶ {#압력-소스-고르기}

`圧力ソース`で太さを調整するペイントチャンネルを選びます。

| ソース | 読み込み内容 |
|---|---|
| `VertexRed` | 頂点カラー R |
| `VertexAlpha` | 頂点カラー A |
| `WidthMask` | 幅マスクテクスチャ |
| `OutlineNormalUV8` | UV8にベイクされたアウトライン法線。長い面は太く、頂点は細く |

:::danger[線が完全に消えた場合]
**頂点カラーが黒でインポートされたメッシュ**で `VertexRed` を選んだ場合です。圧力が0なら幅も0になります。圧力ソースを変更するか、頂点カラーを確認してください。
:::

`ハル圧力コントラスト`は太さの差を大きくします。**0なら圧力が完全に無視**され、1が元値、高いほど細い部分がより細くなります。

`Hull アウトラインに適用` / `Inner Edge アウトラインに適用`で圧力をどちらに反映させるか決めます。

:::caution[`Inner Edge アウトラインに適用`はノーマルアウトラインをオフにしても動作します]
このトグルはノーマルアウトライングループ内にありますが、[内側2Dエッジ](/guides/depth-effects#내부-2d-경계)に作用し続けます。頂点カラーが黒いメッシュでオンになっていると、内側2Dエッジが完全に消えます。
:::

### シーンビューで直接塗る {#씬-뷰에서-직접-칠하기}

太さを手で塗ることができます。

#### 準備

1. `圧力ソース`を**Vertex Alpha**または**Vertex Red**にします。そうでなければ、インスペクターが `頂点ペイントで厚さを調整するにはPressure Sourceが Vertex Alpha または Vertex Red である必要があります。` と共に `Vertex Alpha に切り替え` ボタンを表示します。
2. このマテリアルを使用するレンダラーが**現在の選択項目の下に**ある必要があります。MingToon マネージャーを選択すればOKです。
3. マテリアルは**1つだけ**選択します。

:::danger[チャンネル競合警告が出た場合は進めないでください]
`圧力ソース`が**Vertex Red**で、`ノーマルソース`が**VertexColorTS**の場合、両方が同じ頂点カラーを読み込みます。このままペイントすると、**RGBに保存されているアウトライン方向が上書きされ**、深度エフェクトマスクも赤チャンネルを一緒に読み込みます。

インスペクターがこれを警告して `それでも塗る` ボタンを表示します。進む前に以下のいずれかをしてください。
- `圧力ソース`を**Vertex Alpha**に変更
- アウトライン法線を**UV8TS**に移す → [メッシュUVベイク](/guides/mesh-bakes#아웃라인-스무스-노멀-uv8)
:::

#### 塗る

`シーンビューでアウトライン幅を塗る`をクリックするとシーンビューにオーバーレイが表示されます。

| 操作 | 動作 |
|---|---|
| ドラッグ | 塗る |
| **Shift** + ドラッグ | 消す |
| `[` `]` | ブラシサイズ |
| Esc | 終了 |

オーバーレイで調整できる値：

| 項目 | 機能 |
|---|---|
| `半径` | ブラシサイズ |
| `強度` | 一度に塗られる量 |
| `減衰` | ブラシ端のぼかし |
| `裏面まで塗る` | 画面に見えない裏面頂点も一緒に |

現在のチャンネルが `チャンネル: Vertex Red （Shift = 消す）` のように常に表示され、Vertex Red の場合は `赤チャンネルは深度エフェクトのマスクからも読み取られます。` と一緒に通知されます。

終わったら `アウトライン塗りを終了` または Esc。

<!-- SCREENSHOT: シーンビューのアウトライン幅ペイントオーバーレイ -->

#### 知っておくこと

:::danger[頂点ペイントはメッシュアセットをディスクに直接書き込みます]
- **プレイモードでは禁止されます。** Unityが戻してくれないためです。プレイを終了して再度開始してください。
- **同じメッシュを使う他のレンダラーも一緒に変わります。** インスペクターがどのメッシュアセットが影響を受けるかをリストで警告します。このレンダラーのみに適用したい場合は、**まずメッシュを複製してこのレンダラーに割り当ててから**塗ってください。
:::

:::note[インポートされたメッシュは自動的にコピーが作成されます]
元のFBXは触れず、編集可能なコピーを作成してレンダラーに割り当てます。

塗る途中で Undo で元のメッシュが復元されるとペイントが中断されます（`Undo で '{メッシュ}' の元のメッシュが復元され、塗っていたコピーは使用されなくなります。`）。再度開始すればOKです。
:::

塗れない場合と対策は[トラブルシューティング](/troubleshooting#씬-뷰에서-아웃라인-두께를-칠할-수-없다)にまとめられています。

## 角張った部分で線が切れる場合 {#각진-부분에서-선이-끊길-때}

`ノーマルソース`が原因です。

| ソース | 条件 |
|---|---|
| `MeshNormal` | メッシュ法線そのまま。ハードエッジで線が開きます |
| `VertexColorTS` / `UV8TS` | **スムーズされたアウトライン法線を頂点カラーまたはUV8にベイクしている場合のみ**有効 |

:::danger[ベイクされていないメッシュで `UV8TS`を選ぶと]
むしろ角張った部分で線が**さらに**切れます。ベイクされていなければ `MeshNormal` を使ってください。
:::

:::note[`VertexColorTS`なのに頂点カラーがないメッシュなら]
メッシ法線に落ちて動作します。線が対角線で全体的にズレて出ません。
:::

### 髪・スカートで線が形態を外れる時 {#헤어스커트에서-선이-형태를-벗어날-때}

球や円筒からノーマルを移してきたモデルは、シェーディング用ノーマルが実際の形態と異なります。そのまま焼き込むとアウトラインがメッシュではなく移してきた球を追ってしまいます。

UV8を焼く時、`ノーマルを編集したモデル用に計算`をオンにするとメッシの面から方向を再計算します。シェーディングはそのままにしておきながら、外郭線だけメッシを追います。デフォルト値はオフです。 → [メッシュUVベイク](/guides/mesh-bakes#노멀을-편집한-모델용으로-계산)

方向をテクスチャで直接指定することもできます。`指定ベクトル方向を使用`をオンにして`ベクトルUV`と`ベクトルスケール`を設定します。スケールを負の値にすると方向が反転します。オフにするとこの2項目は無視され、`ノーマルソース`が方向を決定します。

## 線が他のパーツに埋まる場合

`深度バイアス`でハル全体をカメラ側に引き寄せます。**引き寄せすぎると線が顔の前に浮いて見えます。**

ボディ内側に不要な線が出た場合、`内側線抑制オフセット`でハルを表面側に沈めます。

## アウトライン色が照明に従う {#아웃라인-색이-조명을-따라가게}

`シェーディングを含める`をオンにすると、本体の形態シャドウ色を追う**軽い明暗バンド**がアウトラインに適用されます。太いアウトラインで線が照明に従って暗くなる印象が残ります。オフにするとライティングに関わらず均一な色を保ちます。

:::note[アウトラインは本体シェーディングを複製しません]
アウトラインはベースマップ色と照明応答だけで描かれます。本体のシャドウパターン・投影シャドウ・深度エフェクトを線の上に再度描きません。そのためピクセルコストが低いです。

スクリーントーンを線にも塗りたいなら、`アウトラインシャドウパターン`を別にオンにしてください。 → [シャドウパターン](/guides/shadow-pattern)
:::

## 他のシェーダーと重なる場合

`ステンシル設定`は他のシェーダーのマスクと連動する時だけ触ります。デフォルト値ではステンシルがアウトラインに影響を与えません。

`カラーマスク`が0ならアウトラインが画面に全く記録されません。デフォルト値15がRGBA全体です。
