# 複数のマテリアルを一度に

**このドキュメントを読むと**、アバター全体のルックを一度の操作で調整でき、誤って値を潰す事故を避けられます。

3つの方法があります。

| 方法 | 使用場所 |
|---|---|
| **一括設定パネル** | アバター全体の共通値を一度に。取り消しも一度 |
| **マテリアルプリセット** | ルック全体を保存・再利用 |
| **コピー / ペースト** | セクション・レイヤー・値単位で移動 |

---

## 一括設定パネル {#일괄-설정-패널}

インスペクター **View** を `Bulk` に変更すると表示されます。

> 重複を削除したMingToonマテリアルを事前に確認し、プリセットと共通外形値を**一度の取り消しユニット**で適用します。

<!-- SCREENSHOT: 一括設定パネル -->

### 1. 範囲を決定する

| 範囲 | 対象 |
|---|---|
| `Selected Objects` | 現在選択したもの以下 |
| `MingToon Manager` | MingToonマネージャーが管理する範囲 |
| `Active Scene` | 現在のシーン全体 |
| `Loaded Scenes` | 開かれているすべてのシーン |

`Include Inactive` をオンにすると、オフになっている衣装パーツも含まれます。**衣装トグルがあるアバターではオンにしてください。** そうしないと、現在オフになっている衣装だけルックが異なったままになります。

### 2. フィルター

| フィルター | 値 |
|---|---|
| `Material Kind` | All / Standard / **Face** |
| `Surface Kind` | All / 不透明 / カットアウト / 透明 |

:::tip[顔だけを個別に調整]
`Material Kind` を `Face` にすると、顔のマテリアルだけが選択されます。顔は身体と異なる値を使う必要があるため、このフィルターがよく必要になります。
:::

### 3. プレビュー確認

`Preview Material Count` で何個が選択されたかを確認し、`Select Preview Materials` でプロジェクトウィンドウで実際に何が選択されたかを確認します。

衣装を変更した場合は、`Refresh Preview` を最初にクリックしてください。

`No MingToon materials match the current scope and filters。` が表示される場合は、範囲またはフィルターを広げてください。

### 4. 共通外形を適用

`Common Look` には、複数のマテリアルに**安全に**同じ値を入力できる項目だけが表示されます。4つのグループにまとめられています。

| グループ | 項目 |
|---|---|
| **Base & Lighting** | すべてのエフェクト・Base Tint・ベース色保存・ライティング色影響・最小明度・最大明度 |
| **Shadows** | Shadow Border・Shadow Softness・Shadow Strength・統合シャドウ使用・統合シャドウ色・統合シャドウHSVG・シャドウ境界使用・境界線幅/ブラー/強度・キャストシャドウ受け取り量 |
| **Stylization** | 2Dリム幅・2Dリム強度・2Dシャドウ幅/強度・2Dシャドウキャスト到達距離・顔2Dシャドウアシスト・2Dシャドウライティング方向追従・顔固定方向・顔セルフサーフェス抑制・2Dシャドウ上下/前後オフセット・距離減衰範囲・フェイスシェーディング |
| **Outline & Emission** | アウトラインカラー・アウトライン幅・エミッション強度 |

`Search Properties` でフィルターでき、結果がなければ `No safe bulk properties match the search and selected materials。` が表示されます。

:::tip[アバター全体のトーンを合わせる最速の方法]
1. 範囲 = `MingToon Manager`、`Include Inactive` をオンに
2. `Material Kind` = `Standard`
3. `Shadow Softness`・ベース色保存・最小明度を調整
4. `Material Kind` = `Face` に変更して、顔だけを個別に調整
:::

## 複数のマテリアルを単に選択した場合 {#여러-재질을-그냥-선택했을-때}

一括パネルを使わずにプロジェクトウィンドウでマテリアルを複数選択しても編集できます。この場合、インスペクターの上に案内が表示されます。

- `N個のマテリアルを一緒に編集中です。変更は互換性のあるプロパティにすべて適用されます。`
- `N個のMingToonマテリアルの異なるシェーダーを一緒に編集中です。共通プロパティのみが表示されます。` — BRPとURPマテリアルを混在させた場合、または一部がベイク済みマテリアルの場合

値が異なる項目は、**`(Mixed State)`** として表示されます。

:::danger[混合値に触ると取り消せません]
そのフィールドに触れた瞬間に、**選択したすべてのマテリアルに同じ値が上書きされ**、元々異なっていた値は消えます。取り消しでのみ戻ります。使用する前に、何が混合状態であるかを必ず確認してください。
:::

`クイック設定` では、値が分かれる項目に `(Mixed State)` が付けられます。

## マテリアルプリセット {#머티리얼-프리셋}

ルック全体を保存して、再び適用します。選択状態によって名前が変わります — `Material Presets` / `Character Material Presets` / `Bulk Material Presets`。

### 適用 {#적용}

1. `Preset` ドロップダウンから選択します。`Factory Preset` は同梱されたもの、`User Preset` は直接保存したものです。
2. `Apply Selected Preset (N個のマテリアル)`。

:::note[プリセットが変更すること / 保存すること]
- **適用** — すべての数値・色・ベクトル・レンダー状態
- **保存** — 対象マテリアルのテクスチャがシェーダーのデフォルト値と異なる場合、**そのテクスチャとタイリング/オフセットはそのまま保存します**

そのため、キャラクターごとに異なるテクスチャを維持しながら、ルックだけを統一できます。
:::

### 保存 {#저장}

`Save User Preset` で現在のマテリアルの値をアセットに焼き込みます。保存元が何であるかは `Save Source: {マテリアル}` で表示されます。

`Advanced / Direct Assignment` を選択すると、`Preset Asset` スロットにアセットを直接入力できます。

## コピー / ペースト

項目の右クリックメニューです。詳しくは [テクスチャスロット共通UI](/guides/texture-modules#값-복사--붙여넣기) にあります。

| メニュー | 範囲 |
|---|---|
| `Copy Value` / `Paste Value` | 項目1つ |
| `Copy Layer Values` / `Paste Layer Values` | レイヤー全体1つ |
| `Copy Tab Values` / `Paste Tab Values` | セクション全体 |
| `Copy Property Name` | シェーダープロパティ名 |

---

## シーン全体のマテリアルを検索

`Select All MingToon Materials in Scene` で現在のシーンのMingToonマテリアルを一度に選択できます。MingToonマネージャーがないシーンで役立ちます。
