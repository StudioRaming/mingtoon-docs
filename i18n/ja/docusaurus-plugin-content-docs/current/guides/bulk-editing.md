# 複数マテリアルを一度に編集

**用途:** 複数のMingToonマテリアルへ同じ値を適用し、ルックプリセットを保存・再利用します。最初にインスペクターの**一括設定**を開き、範囲とフィルターを選び、**プレビューマテリアル数**を確認します。

使い分けは次の3つです。

| 手段 | 用途 |
|---|---|
| **一括設定パネル** | 選択、Manager、シーン範囲へ共通値を適用 |
| **マテリアルプリセット** | 値中心のルックを保存・再利用 |
| **コピー / 貼り付け** | プロパティ、レイヤー、タブを互換対象へ移動 |

## 一括設定パネル {#일괄-설정-패널}

インスペクターの**表示**を**一括設定**に切り替えます。現在の範囲から重複を除いたMingToonマテリアルを先に集め、共通プロパティを表示します。

### 範囲とフィルター

| 項目 | 選択肢と意味 |
|---|---|
| **範囲** | 選択オブジェクト、MingToon Manager、アクティブシーン、ロード済みシーン |
| **非アクティブオブジェクトを含める** | 無効な衣装やオブジェクトも検索。既定はオン |
| **マテリアル種別** | すべて、Standard、Face |
| **表面種別** | すべて、Opaque、Cutout、Transparent |

**MingToon Manager**範囲では、**Character Root**に指定したアバターのルートから子レンダラーを検索します。アバターや衣装を編集するときは、アバタールートにあるManagerを選びます。Faceフィルターは**MingToonSurfaceKind=Face**タグ、Standardはその逆です。表面フィルターは_MingSurfaceModeを読み、0=Opaque、1=Cutout、2以上=Transparentに分類します。

### プレビューと適用 {#적용}

1. 範囲、非アクティブを含める設定、フィルターを決めます。
2. **プレビューマテリアル数**を読みます。
3. 衣装やシーンを変更したら**更新**を押します。
4. 必要なら**選択**を押し、結果をUnityの選択状態にします。
5. **共通ルック**のグループを開き、値を編集します。

MingToonマテリアルだけが残り、重複は1回だけ入ります。複数マテリアルへの編集は1つのUndo単位です。各行はそのプロパティを持つ対象にだけ書き込むため、一部のマテリアルだけに適用されることがあります。

### 共通ルックのグループ

パネルには**Base Lighting**、**Shadows**、**Stylization**、**Outline / Emission**があります。Base Lightingには全効果、ベース色、**Base Map Opacity**、出力強度・ティント・彩度、色の保持、光色の影響、明るさの範囲、ノーマル強度、スムースネスなどが含まれます。対象シェーダーが宣言した場合だけ、影・スタイル・アウトライン・エミッション項目が表示されます。

**プロパティ検索**はプロパティ名、表示ラベル、登録済みの別名を検索します。検索中はグループが自動で開きます。結果がない場合は検索を消すか対象を確認してください。

## マテリアルプリセット {#머티리얼-프리셋}

**ユーザープリセットを保存**で現在のMingToonのルックをアセットとして保存します。適用するときはドロップダウンから**Factory**または**User**を選び、**Apply**を押します。複数対象では、上書き前に対象数と適用範囲を確認します。

既定のキャプチャーと適用は値中心です。現在のシェーダーがルック値として分類した浮動小数点、色、ベクトルを保存します。レンダーキューなどマテリアル固有の状態はルックプリセットに書き込みません。パネルの通常プリセットは各対象のテクスチャを保持します。テクスチャを明示的に含めるキャプチャーだけが、空でないテクスチャとTiling / Offsetを保存・適用します。

**キャプチャー範囲**を開くと、マテリアル全体または選択したタブだけを保存できます。タブを何も選ばない場合はマテリアル全体です。**Shadow Color**と**Fresnel**のチェックは適用時に含めるかを決めます。プリセットの選択とApplyは別の操作で、適用はUndoできます。

## コピー / 貼り付け

プロパティまたはレイヤーヘッダーを右クリックして値・レイヤー・タブのメニューを開きます。互換性のあるプロパティだけを書き込み、別モジュールのレイヤーや型が違う値はスキップします。適用数・スキップ数はConsoleログで確認します。メニュー一覧は[テクスチャスロット共通UI](/guides/texture-modules#값-복사--붙여넣기)を参照してください。

## 見つからない、見えない場合

- プレビュー数が0なら、範囲、アバタールートのManager、非アクティブを含める設定、Face/Surfaceフィルターを順に確認します。
- 行がない場合は、選択したマテリアルの少なくとも1つがそのプロパティを持つか確認します。
- 変更が見えない場合は、混合値、モジュールの有効化、レイヤー数、強度を確認します。
- プリセットが適用されない場合は、選択したプリセット、対象数、スキーマエラーダイアログを確認します。
