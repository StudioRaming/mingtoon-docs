# Mask Maker連携

> このページは `MM` ボタンやペイントボタンを押してここへ来た方のためのものです。
> まず、なしで行う方法からお伝えします。

## 30秒でオンにしてみる

Mask Makerをすでにインストールしている場合は、次の手順で1枚作ってみてください。

1. 変換したマテリアルを1つだけ選びます。
2. **マスク画像** スロット右側の `MM` ボタンを押します。
3. シーンビューで適用したい部分を塗ります。
4. 保存すると、そのスロットにマスクテクスチャが入ります。

スロットに今塗ったテクスチャが入れば成功です。
`MM` ボタンが表示されない場合は [マスクスロットのMMボタン](#mm-버튼) を見てください。

## Mask Makerなしで行う方法

マスクと頂点カラーは、すべて別の経路でも入れられます。

| やりたいこと | Mask Makerなしで |
|---|---|
| マスクテクスチャ | 外部ツールで作り、該当するスロットに直接入れます |
| アウトライン幅の調整 | **圧力ソース** を `WidthMask` にして **幅マスク** テクスチャを使います |
| 顔領域の指定 | **顔領域マスク** テクスチャを使います |
| すでに塗られた頂点カラー | そのまま読み取ります。外部DCCで塗った値も有効です |

### 頂点カラーのチャンネル整理

| 用途 | チャンネル |
|---|---|
| アウトライン幅（圧力） | 赤（R）またはアルファ（A） |
| 顔領域 | 緑（G） |

どのチャンネルを読むかは **圧力ソース** が決めます。

## Mask Makerが開く機能

Mask Makerは別途販売されているエディターツールです。MingToonオープンベータパッケージには同梱されていません。

| 位置 | ボタン | 機能 |
|---|---|---|
| マスクテクスチャスロット | `MM` | そのスロットのマスクをシーンビューで直接描きます |
| `ノーマルアウトライン` | **シーンビューでアウトライン幅を塗る** | 線の太さを調整する頂点カラーを塗ります |
| `フェイス/ヘアシェーディング` | **顔領域のペイント開始** | 顔として扱う範囲を頂点カラーで塗ります |

### マスクスロットのMMボタン {#mm-버튼}

`MM` はマスク系のテクスチャスロットにだけ付きます。

**マスク画像** 、 **PBRパックマスク** 、 **顔領域マスク** 、 **SDF適用マスク** が代表的です。

スロットの横に `MM` が見えれば対応スロットです。見えない場合、そのスロットは対象ではありません。

:::tip[マテリアルを1つだけ選択した状態で使います]
`MM` は1つのマテリアルの1つのスロットを編集します。複数のマテリアルを一緒に選ぶと押せません。
:::

### アウトライン幅を塗る

`ノーマルアウトライン` タブから始めます。塗った値は頂点カラーの赤（R）またはアルファ（A）に入ります。

**圧力ソース** がまだ頂点チャンネルでない場合は、インスペクターが先に案内します。 **頂点カラーのアルファ（VertexAlpha）に切り替え** ボタンが表示されます。

→ [アウトライン](/guides/outline#씬-뷰에서-직접-칠하기)

### 顔領域のペイント

`フェイス/ヘアシェーディング` タブから始めます。塗った値は頂点カラーの緑（G）に入ります。

顔の範囲を体と別に処理するには、この情報が必要です。
→ [フェイスシェーディング](/guides/character#페이스-셰이딩)

:::caution[頂点ペイントはメッシュアセットを直接書き換えます]
同じメッシュを共有する他のレンダラーの結果も一緒に変わります。
個別に塗るには、先にメッシュを複製してください。
:::
