# Mask Maker 連携

**このドキュメントを読むと**、Mask Maker が MingToon 内でどのボタンを開放するのか、インストールしていないときに同じ目的をどう達成するのか、製品をどこで入手できるのかが分かります。

## 今押したボタンは別売製品が必要です

Mask Maker は別途販売される Editor ツールです。MingToon 0.1.7 オープンベータパッケージには同梱されません。

MingToon 自体は Mask Maker がなくてもインストール・コンパイル・動作します。マスクを**読み取る**側が MingToon シェーダーで、Mask Maker はそのマスクを**作成する**側だけを担当します。

**購入:** <https://raming.booth.pm/items/8606444>（BOOTH・`[Unity] MaskMaker`）

:::note[MingToon はアドオンをアセンブリとして参照しません]
MingToon は Mask Maker、Face SDF Studio、Ming Light Controller をアセンブリ参照ではなくリフレクションだけで探します。そのため 3 つすべてがなくても MingToon は正常にインストール・コンパイル・動作します。

インストールすると該当のボタンがその場で有効になります。インストールしていない場合、ボタンはそのまま表示され、押すとこのドキュメントへ移動します。
:::

## Mask Maker が開放する MingToon 機能

| 位置 | ボタン | 内容 |
|---|---|---|
| インスペクター・マスクテクスチャスロット | `MM` | そのスロットのマスクをシーンビューで直接描きます |
| インスペクター・`ノーマルアウトライン` | `シーンビューでアウトライン幅を塗る` | 線の太さを調整する頂点カラーを塗ります |
| インスペクター・`フェイス／ヘアシェーディング` | `顔領域のペイント開始` | 顔として扱う範囲を頂点カラーで塗ります |

### マスクスロットの `MM` ボタン {#mm-버튼}

マスク系のテクスチャスロットの横にのみ表示されます。たとえば `マスク画像`、`PBRパックマスク`、`顔領域マスク`、`SDF適用マスク` などのスロットです。スロットの横に `MM` が見えれば対応スロットで、見えなければそのスロットは対象外です。

:::tip[マテリアルを 1 つだけ選択した状態で使います]
`MM` はシーンビューで 1 つのマテリアルの 1 つのスロットを編集します。複数のマテリアルを同時に選択した状態では押せません。
:::

### `ノーマルアウトライン` — アウトライン幅を塗る

`ノーマルアウトライン` タブから開始します。塗った値は頂点カラーの**赤（R）またはアルファ（A）**チャンネルに入り、どちらのチャンネルを読み取るかは同じタブの `圧力ソース` が決めます。

`圧力ソース` がまだ頂点チャンネルでない場合、インスペクターは案内文と `頂点カラーのアルファ（VertexAlpha）に切り替え` ボタンを先に表示します。

### `フェイス／ヘアシェーディング` — 顔領域のペイント

`フェイス／ヘアシェーディング` タブから開始します。塗った値は頂点カラーの**緑（G）**チャンネルに入ります。顔の範囲を体と異なる方法で処理するには、この範囲情報が必要です。→ [キャラクター表現 — フェイスシェーディング](/guides/character#페이스-셰이딩)

## Mask Maker なしで行う方法

どちらの機能にもテクスチャマスクの経路が別に用意されています。Mask Maker はそのデータを Unity 内で作成できるようにするツールであって、唯一の入力経路ではありません。

| やりたいこと | Mask Maker なしの場合 |
|---|---|
| マスクテクスチャ | 外部ツールで作成し、インスペクターの該当スロットへ直接設定します |
| アウトライン幅の調整 | `圧力ソース` を `WidthMask` にして、幅マスクテクスチャを使います |
| 顔領域の指定 | `顔領域マスク` テクスチャを使います |
| すでに塗られた頂点カラー | そのまま読み取ります。外部 DCC で塗ってインポートした値も有効です |

### 頂点カラーチャンネルの整理

| 用途 | チャンネル |
|---|---|
| アウトライン幅（圧力） | 赤（R）またはアルファ（A） |
| 顔領域 | 緑（G） |

## 一緒にロックされる他のアドオン

3 つのアドオンの全一覧とインストール確認手順は [別売アドオン](/guides/add-ons) にあります。

### Face SDF Studio

光源方向に応じた顔の影マップを作成する別売ツールです。なくてもフェイスシェーディングは動作し、すでに持っている SDF テクスチャはスロットへ直接設定して使えます。→ [顔 SDF と Face SDF Studio](/guides/face-sdf)

### Ming Light Controller {#ming-light-controller}

MingToon のアバター表現メニュー（VRChat Expression Menu）を作成する Editor 専用アドオンです。

**発売予定です。** 販売が開始されると、この場所に購入リンクが掲載されます。

| 位置 | ロックされている機能 |
|---|---|
| インスペクター・最上部 | `マスター調整` セクション |
| インスペクター・ライティング | `仮想キーライト` のオーサリング行 |
| MingToon Manager | MLC のインストール・アタッチアクション |

パラメータープロファイルは、アバターに残っている VRChat 予算に合わせて選びます。

| プロファイル | 同期ビット | 項目数 |
|---|---|---|
| Smooth | 84 | 22 |
| Compact | 41 | 51 |
| Auto | 残りの予算に合わせて上の 2 つから 1 つを選択 | — |

ルートメニューは 7 枠です：`Reset`、`Final Output`、`Hue/Saturation`、`Photo Looks`、`Virtual Light`、`Master Adjust`、`Performance`。

#### MLC なしでもできること

シェーダーのすべてのルック機能はそのまま動作します。`マスター調整` と `仮想キーライト` は、マテリアルに値が残っていてもインスペクターに編集 UI が表示されないだけで、シェーダーの動作自体がなくなるわけではありません。

VRChat・WARUDO の Depth Light ビルドポリシーは、MLC ではなく MingToon Manager が引き続き所有します。MLC を削除しても、MingToon の VRChat・WARUDO ビルド動作は変わりません。
