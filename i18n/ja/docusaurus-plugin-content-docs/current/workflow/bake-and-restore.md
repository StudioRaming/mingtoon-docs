# 手動ベイクと復元

**このドキュメントを読むと** 手動ベイクがいつ必要かを判断でき、安全に実行してから編集状態に戻すことができます。

## まず: ほとんどの場合必要ありません

:::tip[一般的なアップロード・配布にはビルド時自動最適化で十分です]
[ビルド時自動最適化](/workflow/build-optimization)はビルド中だけシェーダを変更し、終わったら戻します。マテリアルアセットも Renderer もそのままです。

手動ベイクは**新しいマテリアルを作成し Renderer スロットを置き換えます。** 作業を続けるには手動で戻す必要があります。
:::

手動ベイクを使う場合:

- ベイク済み結果そのものをアセットとして渡す必要があるとき
- 自動最適化より攻撃的に削減し、その結果を目で確認しながら作業するとき
- スクリプトがまったくないマテリアルのみを残す配布条件があるとき

---

## 手順 {#절차}

1. `MingToon Manager` コンポーネントインスペクタで変換/編集結果を確認します。
2. アニメーションまたはランタイムマテリアル変更が必要なら**`動的パス保存`**をオンにします。静的アバタはより攻撃的に削減できます。
3. ベイクを実行します。
4. `Assets/StudioRaming/MingToonGenerated` 下に生成シェーダ・ベイク済みマテリアル・manifest が作成され、Renderer スロットがベイク済みマテリアルに置き換えられます。

<!-- SCREENSHOT: MingToon Manager インスペクタのベイク領域 -->

:::danger[ベイク前にバックアップしてください]
元の `.mat` とアニメーションをバージョン管理に入れるか、別途コピーしてください。manifest がなくなったり Renderer/スロット構成が変わったら自動復元が不可能になります。
:::

## 復元

ベイク済みマテリアルを選択すると、インスペクタ**上部の復元ボタン**で記録された元の編集用マテリアルを再度接続できます。

:::caution[復元ボタンが非活性の場合]
以下を確認してください。

- ベイク manifest が残っているか
- 元の編集マテリアルの GUID が生きているか
- ベイク後に Renderer 階層またはマテリアルスロット構成が変わらなかったか
:::

---

## 何がカットされるか

ベイク生成器は**実際に使用しない**以下の機能をベイク済みシェーダからコンパイルタイムに除外できます。

- フレネルリム
- 2次フォームシャドウ
- 深度エフェクト
- 2D リム
- 2D シャドウ

`AnimationClip` のみならずコンポーネントのネスト/配列シリアライズフィールドに含まれる Animator Controller 参照まで検査し、**実際にアニメーション**されるプロパティに必要なモジュールのみを保存します。

アウトラインは直接描画される Hull と カメラ深度を読む Inner Edge のみサポートし、画面合成用別ランタイムは使用しません。

## テクスチャベイクポリシー

### LosslessOnly (デフォルト) {#losslessonly-기본값}

元のテクスチャの texel を**上書きしません。** ロスレス構造最適化のみを適用します。

- depth mask が数学的に恒等であることが証明されている場合
- PBR/AO が同じ Texture オブジェクト・同じ UV 式を使用している場合

### ReviewedHighQuality {#reviewedhighquality}

:::caution[レビュー済み静的マテリアルでのみ明示的に選択してください]
surface/normal flatten と一般 RGBA mask repack を許可します。したがって、imported texture readback、color space、mip 再生成、プラットフォーム圧縮のため**ピクセルが変わる可能性があります。**

Animation dependency と`Keep Editable` 条件は引き続き検査されますが、**アニメーション結果と対象プラットフォームの mip/圧縮ルックをベイク前後のキャプチャで直接比較する必要があります。**
:::

一般 mask repack は mask スロットを共有 texture アセットに統合しますが、**シェーダ sample 数は削減されません。**

---

## Keep Editable {#keep-editable}

特定のプロパティを最適化対象から除外したい場合、マテリアル単位で マークできます。アニメーションされていないが、後でスクリプトで変更する値に使用してください。
