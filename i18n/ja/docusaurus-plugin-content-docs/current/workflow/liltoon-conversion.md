# lilToon マテリアル変換

:::tip[実作業はMingToon マネージャーで行います]
顔・肌の指定、変換時のルックプリセット、同時にベイクするメッシュチャンネル、元を復元するまで全部1つのインスペクターにあります。 → [MingToon マネージャー](/workflow/character-manager#1--변환)

このドキュメントは、変換が**何を移行でき、何ができないか**を説明します。
:::

**このドキュメントを完了すると**、既存のilToonアバターがMingToon編集用マテリアルに変換され、何が失われたかを理解します。

## 変換ができることとできないこと

- **元のマテリアルを保持します。** 新しく作られるのはMingToon編集用マテリアルです。
- ベース、サーフェスモード、AO、法線、MatCap、レイヤーとマスクの**多くの値**を移行します。

:::caution[ルックの完全な一致は保証されません]
異なるシェーダーの数式と機能の意味は同じではありません。変換は**相互運用ツール**であり、別のシェーダーを数学的に複製する機能ではありません。
:::

## 手順

1. アバターまたは衣装の**最上位GameObject**を選択します。
2. `GameObject > Studio Raming > MingToon > Add MingToon Manager`を実行します。
3. **顔に使用するRenderer / マテリアルスロットを明示的に指定します。**
4. 変換出力パスとオプションを確認した後、変換します。
5. 完了ログの`lossy` / `unsupported`項目を**すべて読んで**元と比較します。

<!-- SCREENSHOT: MingToon マネージャー インスペクター -->

:::danger[3番目のステップをスキップしないでください]
顔の自動判定は**補助手段**です。名前だけで完全な判定を保証しません。顔スロットが間違って捉えられると、顔の影の安定化が無関係なメッシュに適用されるか、実際の顔に適用されない場合があります。
:::

## 変換後の確認

**このようになっていれば正常です。** 指定した出力パスにMingToon編集用マテリアルが生成され、Rendererスロットがそのマテリアルに置き換えられ、元のマテリアルはそのまま残ります。

完了ログを読んだ後、実際のモデルで以下を確認してください。インスペクタープレビュー球では判定できません。

- マスクチャンネルと反転
- テクスチャST (Tiling / Offset)
- AO
- サーフェスモード（不透明 / カットアウト / 透明）
- 顔スロット判定
