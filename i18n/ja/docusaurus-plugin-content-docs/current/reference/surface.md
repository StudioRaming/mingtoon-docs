# サーフェスとテクスチャ

ベースカラー、透明処理、その上に重ねるテクスチャレイヤー — キャラクターの「塗り」にあたる項目です。

:::note
このページの項目名と説明は、MingToonインスペクターが実際に表示する文言をソースからそのまま取得しています。
:::

## 基本サーフェス

基本テクスチャ、色、UV変換を設定します。

| 項目 | 説明 | シェーダープロパティ |
|---|---|---|
| **ベースマップ** | キャラクターの基本カラーテクスチャです。アルファチャンネルはサーフェスモードがCutoutまたはTransparentのときだけ使われます。 | `_MainTex` |
| **ベースカラー** | ベースマップの上に重ねる色です。合成方法はティント合成モード、強さはティント不透明度が決めるため、不透明度が0だと色を変えても何も起きません。 | `_Color` |
| **アルファカットオフ** | サーフェスモードがCutoutのときだけ機能します。アルファがこの値未満のピクセルを切り捨てます。髪やまつげは0.3〜0.6が無難で、0に近いと半透明の縁が汚く残ります。 | `_Cutoff` |
| **ティント合成モード** | ベースカラーをベースマップとどう混ぜるかを決めます。既定のMultiplyはマップの陰影を残して色だけ乗せ、Normalはマップを完全に置き換えて単色になります。 | `_ColorBlendMode` |
| **ティント不透明度** | ベースカラーの適用強度です。0ではベースカラーと合成モードの両方が無視されます。 | `_ColorBlendOpacity` |

## サーフェス描画

表面タイプ、カリング、アルファ処理を設定します。

| 項目 | 説明 | シェーダープロパティ |
|---|---|---|
| **アルファマスクを使用** | ベースマップのアルファではなく別画像で透明度を指定します。オフの間は下のマスク画像・チャンネル・反転はすべて無視され、サーフェスモードがOpaqueだとオンにしても結果は見えません。 | `_AlphaMaskEnabled` |
| **マスク画像** | 透明度として使うグレースケール画像です。アルファマスクがオフの間は反映されません。 | `_AlphaMask` |
| **マスクチャンネル** | マスク画像から読み取るチャンネルです。複数のマスクを1枚にパックした場合はR/G/B/Aを選び、LumaはRGBの明るさを使います。 | `_AlphaMaskChannel` |
| **マスク反転** | マスクの白黒を反転します。消したい部分が白で描かれているマスクをそのまま使うときに有効にします。 | `_AlphaMaskInvert` |

## 共通マップ

よく使うノーマル、エミッション、オクルージョン、PBR、MatCapマップをすばやく設定します。

| 項目 | 説明 | シェーダープロパティ |
|---|---|---|
| **ノーマルマップ** | 表面の凹凸を擬似的に表現するノーマルマップです。ノーマルレイヤー01に相当し、ノーマルモジュールがオフの間は反映されません。 | `_BumpMap` |
| **ノーマル強度** | ノーマルマップの凹凸の強さです。0ではマップを入れても平坦に見え、1が元の強さ、それ以上は誇張されます。 | `_BumpScale` |
| **オクルージョンマップ** | 間接光が届きにくい部分を暗くするグレースケールマップです。直接光には影響しないため、正面から強い光が当たると効果が見えにくくなります。 | `_OcclusionMap` |
| **オクルージョン強度** | オクルージョンマップの適用量です。0ではマップを入れても変化しません。 | `_OcclusionStrength` |

## テクスチャレイヤー

追加のサーフェステクスチャレイヤーを合成します。

| 項目 | 説明 | シェーダープロパティ |
|---|---|---|
| **合成モード** | このスタックレイヤーを下の結果とどう混ぜるかです。Normalは完全に覆い、Multiplyは下の陰影を残して色だけ乗せます。 | `_MingStackBlendMode` |
| **不透明度** | このレイヤーの適用量です。0ではレイヤーの計算を飛ばすためテクスチャを入れても見えず、レイヤー数より後ろのスロットも計算されません。 | `_MingStackOpacity` |

## ノーマルレイヤー

複数のノーマルマップと合成強度を設定します。

| 項目 | 説明 | シェーダープロパティ |
|---|---|---|
| **ノーマルマップ** | このレイヤーのノーマルマップです。レイヤー数より後ろのスロットは計算されないため、マップを入れても反映されない場合はまずレイヤー数を確認してください。 | `_MingNormalMap` |
| **ノーマル強度** | このレイヤーが最終ノーマルに混ざる強さです。0ではテクスチャを入れても影響しません。 | `_MingNormalStrength` |
