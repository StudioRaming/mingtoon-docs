# キャラクター表現

顔とキャラクター全体を対象にする項目です。顔は鼻や眉の落とす影のせいで、体と同じ設定ではほぼ必ず汚れるため別に扱います。

:::note
このページの項目名と説明は、MingToonインスペクターが実際に表示する文言をソースからそのまま取得しています。
:::

## フェイスシェーディング

キャラクター顔専用のマスクと陰影方向を設定します。

| 項目 | 説明 | シェーダープロパティ |
|---|---|---|
| **既定の顔形状影を除去** | 1にすると顔領域のフォームシャドウを完全に消します。鼻や頬の影をなくし、2Dシャドウや影テクスチャだけで顔の陰影を作るときに使います。 | `_FaceFormShadowLift` |
| **顔の境界** | 顔領域だけに適用されるフォームシャドウの境界です。胴体より低め（マイナス側）にすると顔が遅れて暗くなり、イラストのように綺麗に保てます。フォームシャドウがオフの場合は反映されません。 | `_FaceFormShadowMidPoint` |
| **顔の柔らかさ** | 顔領域のフォームシャドウ境界のぼかし幅です。フォームシャドウがオフの場合は反映されません。 | `_FaceFormShadowSoftness` |
| **顔領域マスクを使用** | 頭と体が同じマテリアルに混在する場合に、どこまでが顔かをテクスチャで指定します。オフの間は下のチャンネル・強度・反転・リマップはすべて無視されます。 | `_FaceAreaMaskEnabled` |
| **プロキシ球を顔領域として使用** | 顔マスクテクスチャなしでプロキシ球の内側を顔とみなします。顔領域マスクがオンの場合はマスクが優先されるため、このオプションは無視されます。 | `_FaceAreaProxyMaskEnabled` |
| **プロキシ球の中心** | 頭部の代わりとなる仮想球の中心です。シーンビューのフェイスプロキシツールで合わせる方が正確です。ノーマル押し込み量が0のときは使われません。 | `_FaceProxyCenterOS` |
| **プロキシ球の半径** | 仮想球の半径です。顔領域マスクの代わりにプロキシ球を使う場合、この球の内側が顔と判定されるため、大きすぎると首や手まで顔として扱われます。 | `_FaceProxyRadiusOS` |
| **マスクチャンネル (RGBA)** | マスクテクスチャから読み取るチャンネルの重みです。Gチャンネルだけを使うなら(0, 1, 0, 0)のように入力します。 | `_FaceAreaMaskChannel` |
| **マスク強度** | 0ではマスクテクスチャを無視してマテリアル全体を顔として扱い、1ではマスクをそのまま使用します。 | `_FaceAreaMaskStrength` |
| **マスク反転** | 顔領域マスクの白黒を反転します。顔が黒で描かれたマスクをそのまま使うときに有効にします。 | `_FaceAreaMaskInvert` |
| **リマップ開始** | マスクのグレー値を再展開する開始点です。上げると顔と判定される範囲が狭くなります。開始と終了が同じ値だと境界は完全に硬くなります。 | `_FaceAreaMaskRemapStart` |
| **リマップ終了** | マスクのグレー値を再展開する終了点です。下げると顔の境界が急になります。開始と終了が同じ値だと境界は完全に硬くなります。 | `_FaceAreaMaskRemapEnd` |
| **顔自身のリアルタイム影** | 顔メッシュがリアルタイム影を落とすかを決めます。オフにすると前髪が顔に実影を落とさなくなるため、額の影を2Dシャドウだけで描きたいときに有効です。 | `_FaceShadowCasterEnabled` |
| **実シャドウキャスターオフセット** | 顔のシャドウキャスターを前後に押し出して前髪の影が落ちる位置を微調整します。顔自身のキャストがオフの場合は反映されません。 | `_FaceShadowCasterOffset` |
| **ノーマル方式** | 0では顔のノーマルを正面方向へ完全に押し込み鼻の影を消し、1ではプロキシ球に沿った緩やかな曲面になります。ノーマル押し込み量が0の場合、この値は反映されません。 | `_FaceNormalMode` |
| **ノーマル押し込み量** | 顔ノーマル補正をどれだけ適用するかを決めます。0ではノーマル方式・プロキシ球の中心・プロキシ球の半径がすべて無視され、元のメッシュノーマルがそのまま使われます。 | `_FaceNormalFlattenAmount` |
