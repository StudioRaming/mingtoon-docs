# キャラクター表現

顔とキャラクター全体を対象にする項目です。顔は鼻や眉の落とす影のせいで、体と同じ設定ではほぼ必ず汚れるため別に扱います。

:::note
このページの項目名と説明は、MingToonインスペクターが実際に表示する文言をソースからそのまま取得しています。
:::

## フェイス／ヘアシェーディング

顔のマスクと陰影方向を設定します。プロキシボリュームとSDFはヘアにも使えます。

| 項目 | 説明 | シェーダープロパティ |
|---|---|---|
| **フェイスシェーディングモジュール** | 顔専用の陰影モジュールを有効にします。顔マテリアルでのみ使用してください。体マテリアルに使うと陰影が顔のルールに従って不自然になります。 | `_MingFaceShadingEnabled` |
| **顔領域マスクを使用** | 頭と体が同じマテリアルに混在する場合に、どこまでが顔かをテクスチャで指定します。オフの間は下のチャンネル・強度・反転・リマップはすべて無視されます。 | `_FaceAreaMaskEnabled` |
| **頂点ペイント顔領域** | 既定はオフです。顔頂点ペイント値を顔領域として使います。テクスチャ顔マスクが有効ならそちらが優先されます。 | `_FaceAreaVertexMaskEnabled` |
| **プロキシ球を顔領域として使用** | 顔マスクテクスチャなしでプロキシ球の内側を顔とみなします。顔領域マスクがオンの場合はマスクが優先されるため、このオプションは無視されます。 | `_FaceAreaProxyMaskEnabled` |
| **顔の境界** | 顔領域だけに適用されるフォームシャドウの境界です。範囲0～1、既定値0.25です。0に近いほど顔が遅く暗くなり、1に近いほど早く暗くなります。フォームシャドウがオフの場合は反映されません。 | `_FaceFormShadowMidPoint` |
| **顔の柔らかさ** | 顔領域のフォームシャドウ境界のぼかし幅です。フォームシャドウがオフの場合は反映されません。 | `_FaceFormShadowSoftness` |
| **プロキシ球の中心** | 頭部の代わりとなる仮想球の中心です。シーンビューのフェイスプロキシツールで合わせる方が正確です。ノーマル押し込み量が0のときは使われません。 | `_FaceProxyCenterOS` |
| **プロキシ球の半径** | 仮想球の半径です。顔領域マスクの代わりにプロキシ球を使う場合、この球の内側が顔と判定されるため、大きすぎると首や手まで顔として扱われます。 | `_FaceProxyRadiusOS` |
| **プロキシ境界のぼかし** | プロキシ球の境界で顔領域が半径の何割にわたって薄れるかを決めます。顔領域はフォームシャドウの境界とぼかしを顔用の値へ切り替え、同じ範囲でノーマルも押し込むため、値が小さいと耳やあご周りにシェーディングの帯が出ます。半径の位置は変わらず、切り替わる幅だけが広がります。 | `_FaceProxyEdgeSoftness` |
| **プロキシ形状** | Sphere(0、既定)は丸い頭、Cylinder(1)は軸方向に無限の筒、Capsule(2)は長さの決まった筒です。軸はCylinderとCapsule、高さはCapsuleのみに適用されます。 | `_FaceProxyShape` |
| **プロキシ軸** | オブジェクト空間の長手方向です。既定(0,1,0)は頭上方向です。CylinderとCapsuleで使い、ゼロは避けます。 | `_FaceProxyAxisOS` |
| **カプセルの高さ** | Capsuleの軸線分の長さです。範囲0.001～4、既定値0.3です。0に近づくとSphereと同じになり、大きすぎると首や髪も顔になります。 | `_FaceProxyHeightOS` |
| **顔SDF影を使用** | 既定はオフです。方向性SDF顔影を作ります。テクスチャ参照と演算が増えるため必要な顔だけで有効にします。 | `_FaceSdfEnabled` |
| **SDF座標** | Base UV(0)は元のUV島、Baked Front UV7(1、既定)は連続正面投影です。SDFがUV7を使う間はジオメトリノーマルへ戻ります。 | `_FaceMapUvMode` |
| **ベイク顔ノーマル状態** | Manager管理の非表示出力です。1でUV7ベイクノーマルを使い、データ不足やSDFのUV7使用時はジオメトリへ戻ります。直接編集しないでください。 | `_FaceNormalBaked` |
| **既定の顔形状影を除去** | 1にすると顔領域のフォームシャドウを完全に消します。鼻や頬の影をなくし、2Dシャドウや影テクスチャだけで顔の陰影を作るときに使います。 | `_FaceFormShadowLift` |
| **顔領域マスク** | ベースUVで顔領域を指定します。白が顔、黒が顔以外で、使用トグルがオフなら読みません。既定の白では全体が顔になります。 | `_FaceAreaMask` |
| **顔自身のリアルタイム影** | このマテリアルの顔領域がリアルタイム影を落とすかを決めます。オフにすると、顔が首や服など他の面に落とす影だけが消えます。前髪の影はヘアマテリアルが落とすため、このトグルでは消えません。カメラ深度への書き込みは維持され、2Dシャドウや深度リムはそのまま動作します。 | `_FaceShadowCasterEnabled` |
| **深度オフ時は投影影** | 「顔用2Dシャドウ補正」は、2D影に顔を任せるため顔から投影影を外します。この項目をオンにすると、深度エフェクトのマスターがオフの間や「深度の可用性」がForce Offの間は、その投影影を顔に戻します。深度がオンの間は何も変わりません。 | `_FaceDepthOffProjectedShadowEnabled` |
| **実シャドウキャスターオフセット** | 顔領域のシャドウキャスターを法線方向へ押し出し、リアルタイム影が顔自身に重なる度合いを調整します。「顔2D影アシスト」がオンのときだけ適用されます。前髪の影の位置は変わりません — その影はヘアマテリアルが落とします。 | `_FaceShadowCasterOffset` |
| **マスクチャンネル (RGBA)** | マスクテクスチャから読み取るチャンネルの重みです。Gチャンネルだけを使うなら(0, 1, 0, 0)のように入力します。 | `_FaceAreaMaskChannel` |
| **マスク強度** | 0ではマスクテクスチャを無視してマテリアル全体を顔として扱い、1ではマスクをそのまま使用します。 | `_FaceAreaMaskStrength` |
| **マスク反転** | 顔領域マスクの白黒を反転します。顔が黒で描かれたマスクをそのまま使うときに有効にします。 | `_FaceAreaMaskInvert` |
| **リマップ開始** | マスクのグレー値を再展開する開始点です。上げると顔と判定される範囲が狭くなります。開始と終了が同じ値だと境界は完全に硬くなります。 | `_FaceAreaMaskRemapStart` |
| **リマップ終了** | マスクのグレー値を再展開する終了点です。下げると顔の境界が急になります。開始と終了が同じ値だと境界は完全に硬くなります。 | `_FaceAreaMaskRemapEnd` |
| **ノーマル押し込み量** | 顔ノーマル補正をどれだけ適用するかを決めます。0ではノーマル方式・プロキシ球の中心・プロキシ球の半径がすべて無視され、元のメッシュノーマルがそのまま使われます。ベイク済みマテリアルでもこの値がライブで適用量を決めます。0では元のノーマルになります。 | `_FaceNormalFlattenAmount` |
| **ノーマル方式** | 0では顔のノーマルを正面方向へ完全に押し込み鼻の影を消し、1ではプロキシ球に沿った緩やかな曲面になります。ノーマル押し込み量が0の場合、この値は反映されません。 | `_FaceNormalMode` |
| **共通横スケール** | 中心基準の横スケールです。範囲0.1～4、既定値0.5です。Tilingへ追加で掛かるため片方ずつ調整します。 | `_FaceMapScaleX` |
| **共通縦スケール** | 中心基準の縦スケールです。範囲0.1～4、既定値0.5です。Tilingと併用され、外側は反復しません。 | `_FaceMapScaleY` |
| **共通横位置** | 拡縮後のSDFを横移動します。範囲-1～1、既定値0です。目と鼻の中心線を小刻みに合わせます。 | `_FaceMapOffsetX` |
| **共通縦位置** | 拡縮後のSDFを縦移動します。範囲-1～1、既定値0です。タイル状ならWrap ModeがClampか確認します。 | `_FaceMapOffsetY` |
| **SDFテスト表示** | 既定はオフです。元SDFを無照明グレー表示し位置とチャンネルを診断します。ベイクシェーダーでは除去されます。 | `_FaceSdfTestMode` |
| **テスト表示チャンネル** | R=左、G=右、B=上、A=下です。Maximum(4、既定)は最大値で全体位置を確認します。 | `_FaceSdfTestChannel` |
| **SDFマップ形式** | Packed RGBA(0、既定)はR/G=左右、B/A=上下です。Single Channel(1)はRのgrayscaleをU反転して再利用し、上下影響を無視します。 | `_FaceSdfMode` |
| **顔SDFマップ** | 境界順序テクスチャで既定はグレーです。PackedはRG左右・BA上下、単一はRです。Clamp/Bilinearを推奨し参照コストが増えます。 | `_FaceSdfMap` |
| **左右の影響** | 左右光への反応量です。範囲0～1、既定値1です。0で変化なし、1で完全に使います。 | `_FaceSdfHorizontalStrength` |
| **上下の影響** | 上下光への反応量です。範囲0～1、既定値1です。PackedのB/Aだけに作用し、単一grayscaleでは無視します。 | `_FaceSdfVerticalStrength` |
| **SDF影の量** | SDF暗部の最終強度です。範囲0～1、既定値1です。0で非表示、1で完全適用します。 | `_FaceSdfShadowAmount` |
| **境界オフセット** | 影開始のしきい値を移動します。範囲-1～1、既定値0です。マップ位置ではないため小刻みに調整します。 | `_FaceSdfThresholdOffset` |
| **境界の柔らかさ** | 明暗の遷移幅です。範囲0.001～0.5、既定値0.04です。小さすぎると解像度や圧縮ノイズが見えます。 | `_FaceSdfSoftness` |
| **SDF適用マスクを使用** | 既定はオフです。耳や後頭部などをベースUVマスクで除外します。顔領域マスクとは別です。 | `_FaceSdfMaskEnabled` |
| **SDF適用マスク** | ベースUVで読み、白はSDF適用、黒は元の陰影を維持します。使用トグルがオフなら参照しません。 | `_FaceSdfMask` |
| **SDFマスク強度** | マスク制限の強さです。範囲0～1、既定値1です。0で無視、1で描画値を完全使用します。 | `_FaceSdfMaskStrength` |

## キャラクター高さグラデーション

ルート基準のUV4高さでキャラクター下部をグレーディングします。

| 項目 | 説明 | シェーダープロパティ |
|---|---|---|
| **キャラクター高さグラデーション** | キャラクターの高さに応じて下部と上部を別の色に染めるグラデーションを有効にします。足元をわずかに暗く沈める用途が代表的です。正確な位置にはUV4高さベイクが必要です。 | `_MingCharacterHeightGradientEnabled` |
| **下部カラー** | キャラクター下部に染まる色です。白なら変化はありません。足元を沈めたい場合はベースより少し暗い色を使ってください。 | `_MingCharacterHeightLowColor` |
| **上部カラー** | キャラクター上部に染まる色です。白なら変化はありません。 | `_MingCharacterHeightHighColor` |
| **下部カラー** |  | |
| **上部カラー** |  | |
| **グラデーション方向** | 上→下に切り替えると2色の位置が入れ替わります。 | |
| **境界の高さ** | 2色が半分ずつ混ざる高さです。 | |
| **境界の柔らかさ** | 境界を中心に広がる幅です。0で硬いエッジになります。 | |
