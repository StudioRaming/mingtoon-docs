# キャラクター表現

顔とキャラクター全体を対象にする項目です。

このページは値を探すための表です。オンにする順序が必要な場合は [キャラクター表現ガイド](/guides/character) を見てください。

見出しと目次は、インスペクターのセクション名と表示順をそのまま踏襲しています。

マップとマスクのスロット内の項目は、すべてのスロットで共通です。
チャンネル・リマップ・フェザー・マスクUVは [テクスチャスロット共通UI](/guides/texture-modules) に一度だけ記載しています。

## フェイス／ヘアシェーディング {#페이스헤어-셰이딩}

| インスペクターのラベル | 形式 | 範囲 | 既定値 | 役割 |
|---|---|---|---|---|
| **フェイスシェーディングモジュール** | オン/オフ | - | オフ | 顔専用の陰影モジュールを有効にします |
| **正面方向（オブジェクト空間）** | 実数 | 4つの値 | 0, 0, 1, 0 | 顔が向いている方向をオブジェクト座標で指定します |
| **既定の顔形状影を除去** | 実数 | 0 ~ 1 | 0 | 1にすると顔領域のフォームシャドウを完全に消します |
| **顔の境界** | 実数 | -1 ~ 1 | 0 | 顔領域だけに適用されるフォームシャドウの境界です |
| **顔の柔らかさ** | 実数 | 0.001 ~ 2 | 0.15 | 顔領域のフォームシャドウ境界のぼかし幅です |
| **頂点ペイントで顔領域を指定** | オン/オフ | - | オフ | 既定はオフです |
| **顔領域マスクを使用** | オン/オフ | - | オフ | 頭と体が同じマテリアルに混在する場合に、どこまでが顔かをテクスチャで指定します |
| **顔領域マスク** | テクスチャ | - | なし | ベースUVで顔領域を指定します |
| **顔用デプスシャドウ補正** | オン/オフ | - | オフ | 既定はオフです |
| **顔自身のリアルタイム影** | オン/オフ | - | オン | このマテリアルの顔領域がリアルタイム影を落とすかを決めます |
| **顔SDF影を使用** | オン/オフ | - | オフ | 既定はオフです |
| **SDF座標** | 実数 | - | 1 | Base UV(0)は元のUV島、Baked Front UV7(1、既定)は連続正面投影です |
| **共通横スケール** | 実数 | 0.1 ~ 4 | 0.5 | 中心基準の横スケールです |
| **共通縦スケール** | 実数 | 0.1 ~ 4 | 0.5 | 中心基準の縦スケールです |
| **共通横位置** | 実数 | -1 ~ 1 | 0 | 拡縮後のSDFを横移動します |
| **共通縦位置** | 実数 | -1 ~ 1 | 0 | 拡縮後のSDFを縦移動します |
| **SDF テスト表示** | オン/オフ | - | オフ | 既定はオフです |
| **表示チャンネル** | 選択 | R / G / B / A / Maximum | Maximum | R=左、G=右、B=上、A=下です |
| **マップ形式** | 選択 | Packed RGBA / Single Channel Mirrored U | Packed RGBA | Packed RGBA(0、既定)はR/G=左右、B/A=上下です |
| **単一チャンネルSDFマップ（R/グレースケール、左右ミラー）** | テクスチャ | - | なし | 4方向SDFマップ (RG左右 / BA上下) |
| **左右の影響** | 実数 | 0 ~ 1 | 1 | 左右光への反応量です |
| **上下の影響** | 実数 | 0 ~ 1 | 1 | 上下光への反応量です |
| **SDF影の量** | 実数 | 0 ~ 1 | 1 | SDF暗部の最終強度です |
| **境界オフセット** | 実数 | -1 ~ 1 | 0 | 影開始のしきい値を移動します |
| **境界の柔らかさ** | 実数 | 0.001 ~ 0.5 | 0.04 | 明暗の遷移幅です |
| **SDF 適用マスクを使用** | オン/オフ | - | オフ | 既定はオフです |
| **SDF 適用マスク（耳・後頭部を除外）** | テクスチャ | - | なし | ベースUVで読み、白はSDF適用、黒は元の陰影を維持します |
| **マップと強さ・マスク強度** | 実数 | 0 ~ 1 | 1 | マスク制限の強さです |
| **プロキシ形状** | 選択 | Sphere / Cylinder / Capsule / Plane | Plane | Sphere(0、既定)は閉じた球、Cylinder(1)は有限の閉じた円柱… |
| **プロキシメッシュノーマルを使用** | オン/オフ | - | オフ | 実際のプロキシメッシュのスムースノーマルを顔頂点へ転送します |
| **プロキシ中心** | 実数 | 4つの値 | 0, 0, 0, 1 | 実際の球・円柱・カプセルプロキシメッシュのオブジェクト空間中心です |
| **プロキシ半径** | 実数 | 0.001 ~ 2 | 0.12 | 実際のプロキシメッシュの半径です |
| **プロキシ境界のぼかし** | 実数 | 0 ~ 1 | 0.15 | 選択したプロキシボリュームの境界で顔領域が半径の何割にわたって薄れるかを決めます |
| **プロキシ軸（0 = 自動）** | 実数 | 4つの値 | 0, 1, 0, 0 | Cylinder・Capsuleの長手方向です |
| **プロキシ長さ** | 実数 | 0.001 ~ 4 | 0.3 | Cylinderでは円柱全体の高さです |
| **マスクチャンネル（RGBA）** | 実数 | 4つの値 | 0, 1, 0, 0 | マスクテクスチャから読み取るチャンネルの重みです |
| **マスクマッピング・マスク強度** | 実数 | 0 ~ 1 | 1 | 0ではマスクテクスチャを無視してマテリアル全体を顔として扱い、1ではマスクをそのまま使用します |
| **マスク反転** | オン/オフ | - | オフ | 顔領域マスクの白黒を反転します |
| **リマップ開始** | 実数 | 0 ~ 1 | 0 | マスクのグレー値を再展開する開始点です |
| **リマップ終了** | 実数 | 0 ~ 1 | 1 | マスクのグレー値を再展開する終了点です |
| **実シャドウキャスターオフセット** | 実数 | -0.05 ~ 0.05 | 0 | 顔領域のシャドウキャスターを法線方向へ押し出し、リアルタイム影が顔自身に重なる度合いを調整します |

## キャラクター高さグラデーション {#캐릭터-높이-그라데이션}

| インスペクターのラベル | 形式 | 範囲 | 既定値 | 役割 |
|---|---|---|---|---|
| **キャラクター高さグラデーション** | オン/オフ | - | オフ | キャラクターの高さに応じて下部と上部を別の色に染めるグラデーションを有効にします |
| **下部カラー** | 色 | - | 0.67, 0.5, 0.47, 1 | キャラクター下部に染まる色です |
| **上部カラー** | 色 | - | 白 | キャラクター上部に染まる色です |
