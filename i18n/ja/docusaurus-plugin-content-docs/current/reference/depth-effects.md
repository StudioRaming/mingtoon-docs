# 深度ベースエフェクト

カメラ深度テクスチャを読んで画面空間で描くエフェクトです。深度がない環境では丸ごと出ないので、値を触る前にまず深度を確認してください。内部2Dエッジもこのグループに含まれます。

:::note
このページの項目名と説明は、MingToonインスペクターが実際に表示する文言をソースからそのまま取得しています。
:::

## 深度エフェクトマスター

深度ベース効果の範囲とマスクを設定します。

| 項目 | 説明 | シェーダープロパティ |
|---|---|---|
| **深度エフェクト** | 2Dリムライト・深度透過光・2Dシャドウなど深度エフェクト全体のマスタースイッチです。オフにすると3つのモジュールがすべて止まります。これらの効果はカメラ深度テクスチャが必要です。 | `_DepthEffectsEnabled` |
| **マスター幅** | 2Dリムライトと2Dシャドウの画面オフセットに共通で掛かる倍率です。ここを0にすると、各モジュールの幅をいくら上げても何も出ません。 | `_DepthWidth` |
| **幅モード** | Screen Pixelsは画面ピクセル基準のため遠ざかるほど線が相対的に太く見え、Distance Stableは距離やFOVが変わっても太さが一定に見えます。Screen Pixelsを選ぶと距離スケールは機能しません。 | `_DepthWidthMode` |
| **距離スケール** | 幅モードがDistance Stableのときの太さの基準距離を決めます。Screen Pixelsでは反映されません。 | `_DepthDistanceScale` |
| **マスターバイアス** | 画面深度の差がこの値を超えたときだけ前後の境界と判定します。下げると浅い凹凸にも線が付いて汚くなり、上げると薄い部位の線が消えます。 | `_DepthBias` |
| **マスターの柔らかさ** | 深度境界判定の遷移幅です。低いと硬いインク線、高いと柔らかくぼけた境界になります。 | `_DepthSoftness` |
| **FXアニメーターで深度エフェクトを切り替え** | 深度エフェクトのマスターをアニメーター（VRChatのFXなど）でオン/オフできるようにします。深度テクスチャの無いワールドでは普段オフにして、カメラを構えた時だけオンにする用途です。これをオフにするとベイクがマスターを定数化し、アニメーションは何も起きません。 | `_MingDepthEffectsRuntimeToggle` |

## 実行時の切り替え

| 項目 | 説明 | シェーダープロパティ |
|---|---|---|
| **VRCランタイム操作を使う** | VRChat EXメニューの仮想ライト・パレット・マスター調整・写真ルック・品質操作をこのマテリアルに適用します。シャドウ投影には別のFXスイッチも必要です。オフにするとベイクが関連値を定数化し、メニュー操作はこのマテリアルに届きません。 | `_MingVrcQualityMenuEnabled` |
| **FXメニューでシャドウ投影を切り替え** | 「シャドウ投影」をVRChatのEXメニューでオン/オフできるようにします。影をオンのままアップロードし、人の多いインスタンスではメニューでオフにする用途です。実行時にオフにすると、投影影のぼかしサンプル・キャスト合成・透過光のキャスト計算がピクセルごとにスキップされます。このオプションをオフにするとベイクが「シャドウ投影」を定数化し、メニューは何も起きません。 | `_MingCastShadowRuntimeToggle` |
| **品質ティアのプレビュー** | ゲーム内メニューがこの値を動かします。ここで直接変えると、Low/Midの見え方をエディターで確認できます。保存時はHighに戻してください — この値が材質の初期状態になります。 | `_MingVrcQualityTier` |

## 2Dリムライト

画面深度差から生成するリム効果を設定します。

| 項目 | 説明 | シェーダープロパティ |
|---|---|---|
| **2Dリムライト** | シルエットの深度差で描く2Dリムライトのオン/オフです。法線ベースのフレネルリムと異なり、外周に均一な太さの線が出ます。カメラ深度テクスチャが必要です。 | `_DepthRimEnabled` |
| **輪郭リムの最小倍率** | 照明に従うリム、つまりバックライト・フレネルリム・2Dリムライトが暗い場所でも維持する最小の照明倍率です。上の最大倍率が上限なら、この値はその対になる下限です。0はこれまでとまったく同じで、上げると暗いライトボリュームの中でもシルエットが完全には消えなくなります。 | `_EdgeRimLightResponseFloor` |
| **2Dリムライトマスク** | 2Dリムを特定部位に限定するマスクを有効にします。金属装飾だけにリムを残す、といった用途です。 | `_DepthRimMaskEnabled` |
| **チャンネル** | リムマスクから読み取るチャンネルです。複数のマスクを1枚にパックしている場合はチャンネルを分けて使います。 | `_DepthRimMaskChannel` |
| **反転** | リムマスクの白黒を反転し、適用部位を逆にします。 | `_DepthRimMaskInvert` |
| **強度** | マスクがリムを削る度合いです。1ではマスクの黒い部分でリムが完全に消え、下げると部分的に残ります。 | `_DepthRimMaskStrength` |
| **リム色** | 2Dリムの色です。HDRカラーなので強度を上げればブルームと合わせて光らせることもできます。 | `_DepthRimColor` |
| **色純度** | ベース色と2Dリムティントを合成した後の彩度範囲0〜10、既定値1です。0は無彩色、1は合成色を維持し、1を超えると過彩度になります。 | `_DepthRimColorPurity` |
| **シーン照明の影響** | 2Dリムがシーン照明にどれだけ従うかを決めます。1ではバックライトと同じ方式でシーン照明の応答を受けるため、暗いライトボリュームの中ではリムも一緒に暗くなります。0では照明の色だけを受けて明るさは設定した値のまま残るので、体が暗くなってもリムだけが明るく浮きます。 | `_DepthRimSceneLightInfluence` |
| **リム幅の倍率** | マスター幅に掛かる2Dリム専用の倍率です。最終的な太さはマスター幅×この値のため、マスター幅が0だとここを上げても意味がありません。 | `_DepthRimWidth` |
| **リム強度** | 2Dリムの明るさ倍率です。0ではリムの計算を飛ばすため、色や幅を変えても何も見えません。 | `_DepthRimIntensity` |
| **フレネルを適用** | 検出した2Dリムにフレネル領域を掛け、内側の境界を徐々にフェードできます。オフでは従来の2Dリム形状をそのまま使います。 | `_DepthRimFresnelEnabled` |
| **幅** | 範囲は0-1、既定値は1です。0ではフレネル領域なし、1では領域全体を使います。柔らかさを変えてもこの幅の外側へは広がりません。 | `_DepthRimFresnelWidth` |
| **柔らかさ** | 範囲は0-1、既定値は1です。0は硬い境界、1は選択した幅全体を使う柔らかなグラデーションです。幅は変わりません。 | `_DepthRimFresnelSoftness` |
| **領域を反転** | 選択した幅を保ったままフレネル領域を反対側へ移します。エッジ側の領域は内側・中心方向へ移ります。 | `_DepthRimFresnelAreaInvert` |
| **ベースカラー合成** | 0では指定したリム色が単色で出て、1ではベースマップの色を掛けて部位ごとに異なるリム色になります。 | `_DepthRimBaseColorMix` |
| **360度リム** | 0では光源側だけにリムが出て、1ではシルエット全体を囲みます。照明がない、または方向がよく変わる環境では上げると安定します。 | `_DepthRim360` |
| **リムサンプル品質** | 2Dリムがピクセルごとに読む深度サンプル数を選びます。標準(2タップ)が既定値です。低(1タップ)は内部線の抑制がなくなるため、目・鼻・口の線や衣装の境界がリムとして漏れ、カメラが動くとリムの内側境界がテクセル単位で揺れます。高(4タップ)は同じチェック範囲をより細かく走査して狭い内部線まで除去しますが、深度サンプルを2つ多く使います。リム幅はどのティアでも変わりません。 | `_DepthRimSampleQuality` |
| **シルエット開始点** | 表面がカメラからどれだけ傾いたらシルエットとみなすかを決めます。この値と下の遷移の柔らかさは、同じグループの外周シルエット制限が0の場合まったく反映されません。 | `_DepthRimSilhouetteThreshold` |
| **シルエット遷移の柔らかさ** | シルエット判定の遷移幅です。同じグループの外周シルエット制限が0の場合は反映されません。 | `_DepthRimSilhouetteSoftness` |
| **ブレンド不透明度** | リム色が結果に混ざる割合です。リムが強すぎるときは強度より先にこの値を下げてみてください。0ではリムが見えません。 | `_DepthRimColorBlendOpacity` |

## 2Dシャドウ

前面オブジェクトの画面深度シルエットをライトの反対方向へずらして描く軽量キャラクターシャドウです。深度伸びを有効にすると、受信面から浮いたオブジェクトほど影が長くなり、深度フェードを有効にするとその分だけ段階的に薄くなって奥にあるように見えます。サンプル数・フェード距離はDepth Commonタブの共通設定に従います。

| 項目 | 説明 | シェーダープロパティ |
|---|---|---|
| **2Dシャドウ** | 深度差で作る2Dシャドウのオン/オフです。前髪が顔に落とす影が代表的な用途です。カメラ深度テクスチャが必要です。2Dシャドウは遠い遮蔽物も投影影のように落とす硬い一枚が持ち味で、接触部の柔らかい陰影はSSAOの担当です — 併用するとSSAOが接触部を上から描き足します。 | `_DepthShadowEnabled` |
| **MingToon 2D投影シャドウをキャスト** | このマテリアルをMingToonのカメラ深度へ書くかを決めます。眼鏡やアクセサリーでオフにするとOpaque・Cutout・Transparentすべてが2D投影影のキャスターから外れます。通常のカラー描画、Transparentの深度プリパス、UnityのリアルタイムShadowCaster影はすべて維持されるため、自己ソートと輪郭はオンのときと同じです。オフのマテリアルは自分自身が深度に存在しないため、そのマテリアルの2Dリムライト・Inner 2D Edge・2Dシャドウ・深度透過光は背後を見られません。眼鏡自体にリムが必要な場合は深度を使わないFresnel Rimを使ってください。 | `_2DShadowCasterEnabled` |
| **2Dシャドウマスク** | 2Dシャドウを特定部位に限定するマスクを有効にします。不要な場所に落ちる2D影を消すときに使います。 | `_DepthShadowMaskEnabled` |
| **チャンネル** | 2Dシャドウマスクから読み取るチャンネルです。複数のマスクを1枚にパックしている場合はチャンネルを分けて使います。 | `_DepthShadowMaskChannel` |
| **反転** | 2Dシャドウマスクの白黒を反転し、適用部位を逆にします。 | `_DepthShadowMaskInvert` |
| **2Dシャドウ色** | 2Dシャドウの色です。髪が顔に落とす深度ベースの影がこの色で塗られます。他の影色とトーンを合わせてください。 | `_DepthShadowColor` |
| **スクリーンスペース影の重なり深度** | 2DシャドウまたはSSAOが別の影と重なる部分だけを追加で濃くする量です。0では同じ統合影色に溶け込み、上げるほど重なりが乗算されて形が残ります。 | `_DepthShadowColorBlendOpacity` |
| **影の明るさ** | 2Dシャドウ色の明るさ倍率です。下げるほど暗くなります。2Dシャドウとキャストシャドウを統合している場合は、統合されたレイヤーの明るさとして使われます。 | `_DepthShadowBrightness` |
| **深度の可用性** | 深度テクスチャの有無を判定する方式です。基本はAutoのままにしてください。Force Onは自動判定が届かないホストで作者が深度バッファを保証できる場合のみ、Force Offは深度効果を完全に遮断、Diagnosticは判定状態を画面に表示します。 | `_DepthAvailabilityMode` |
| **共用品質** | 2Dシャドウの尾とSSAOが共有する深度サンプル段階です。Low 4、Standard 8、High 16。両エフェクトはそれぞれこの数だけ読みます。 | `_ScreenSpaceShadowQuality` |
| **共通フェード距離** | 2DシャドウとSSAOが共に消えるカメラ距離です。最後の25%で滑らかに消え、0は距離制限なしです。 | `_ScreenSpaceShadowFadeDistance` |
| **顔2D影アシスト** | 既定はオフです。顔領域を指定後に有効にすると、カメラ深度ベース投影影の自己重なりを抑えます。同じ深度を使う2Dリムライトや内部エッジも変化する場合があります。 | `_DepthShadowFaceAssistEnabled` |
| **強度** | マスクが2Dシャドウを削る度合いです。1ではマスクの黒い部分で影が完全に消え、下げると部分的に残ります。 | `_DepthShadowMaskStrength` |
| **深度カーブ** | 深度伸びが距離に応じて伸びる形です。0では浮いている距離に正比例して押されます。上げるほど近くに浮いたオブジェクトはほとんど動かず、遠くに浮いたものだけがますます遠くへ押され、接したものはそのまま、遠いものだけ奥へ送ります。 | `_DepthShadowDepthCurve` |
| **ブラー** | 描き終えた影の縁をこの半径（m）だけ四方に柔らかくぼかします。半径はこの値（m）だけで決まります。影を先に完成させた後で最後に適用されるため元の大きさの外側まで広がり、ピクセルごとに位相が変わるノイズ（中心1回＋回転ディスク4回）で滑らかになります。共用品質段階とは無関係です。影の境界の色帯はこのようにシルエットが柔らかくなった場所にだけ乗るため、この値を上げると境界の演出も一緒に広がります。0なら追加の深度サンプル費用はありません。 | `_DepthShadowBlur` |
| **2Dシャドウバイアス** | 前面オブジェクトが受信面よりこの分以上手前にあるときだけ影と認めます。1が10cm、0.03が3mmです。0では深度精度の余裕だけが残ります。この値はすべての遮蔽物から等しく引かれるため、上げるほど浅い接触影から先に消えます - 鼻の高さは額に触れる前髪との隙間より大きいので、鼻の汚れが消える値ではその前髪の影も既に消えています。顔自体の起伏だけを取り除きたい場合は、この値ではなく受信面プッシュバックを使ってください - そちらは値を入れたマテリアルだけを奥に押すため、押していない髪が作る隙間はそのまま残ります。 | `_DepthShadowSelfReject` |

## SSAO (画面空間遮蔽)

カメラ深度テクスチャをピクセルごとに読み直し、折れ目や接触部を暗くします。フォーム・投影・2Dシャドウがすべて塗られた後に乗算で重ねるオーバーレイなので、すでに影になっている場所でも接触部はさらに深くなります。半径・バイアスはワールド基準なので、カメラ距離や画角が変わっても同じ形を保ちます。サンプル数・フェード距離はDepth Commonタブの共通設定に従い、受信面プッシュバック（カメラ）は2Dシャドウタブの値を共用します。深度テクスチャがない環境では静かに消えます。

| 項目 | 説明 | シェーダープロパティ |
|---|---|---|
| **SSAOを使用** | カメラ深度テクスチャを放射状に読み、折れ目や接触部を柔らかく暗くします。フォーム・投影・2Dシャドウの上でも接触陰影は維持されます。オフでは計算がコンパイルから外れます。 | `_SsaoEnabled` |
| **SSAO 強度** | 効果の強さです。0では切ったのと同じ絵になりますが計算は走り続けるため、使わないときはSSAOを使用をオフにしてください。 | `_SsaoIntensity` |
| **SSAO コントラスト** | 遮蔽のコントラストです。上げると深くくぼんだ部分だけが残り、薄い遮蔽は消えます。 | `_SsaoPower` |
| **SSAO 半径** | 遮蔽を探すワールド半径（0.001〜0.05m）です。主なぼかし幅で、大きいほど接触陰影が広く柔らかくなります。 | `_SsaoRadius` |
| **SSAO バイアス** | 自己面を遮蔽と誤認しないための余裕を、SSAO半径の比率で指定します（0.4 = 半径の40%）。半径比なのでカメラ距離や半径が変わっても見た目は変わりません。深度テクセルに合わせた最小余裕は自動で敷かれるため、0でも平らな面がムラになりません。浅い折れ目が消えるなら下げ、曲面に汚れが残るなら上げます。 | `_SsaoBias` |
| **接触減衰** | 手前を遮るものがどれだけ近ければ遮蔽と認めるかを、`SSAO 半径`の倍数で指定します。1なら半径1つ分、2なら2つ分まで認め、それを超えると重みが0へ落ちるため、遠くの壁がシルエット全体を暗くしません。メートルではなく倍数なので、半径を変えても比率がそのまま追従します。 | `_SsaoFadeRange` |
| **SSAO マスク強度** | 2Dシャドウマスクをそのまま借りて、SSAOが入る範囲を制限します。0ではマスクを使わず、上げるほどマスクが覆う場所から遮蔽が抜けます。チャンネル・反転・HSVGは2Dシャドウマスクに設定した値を共有します。 | `_SsaoMaskStrength` |
| **SSAO ティント** | 遮蔽が入った箇所にのみ乗算される色です。白なら何も着色せず、既存の影色をそのまま残します。 | `_SsaoColor` |
| **色純度** | SSAOが継承した影色にティントを掛けた後の彩度です。範囲0〜10、既定値1です。0は無彩色、1は掛けた色をそのまま維持し、1を超えると過彩度になります。純度→明るさ→ガンマの順で適用され、その中で最初に入ります。 | `_SsaoColorPurity` |
| **カラー明るさ** | 純度を適用した後のSSAO色の明るさ倍率です。範囲0〜4、既定値1は従来の見た目をそのまま保ちます。ガンマより先に適用されます。 | `_SsaoColorBrightness` |
| **カラーガンマ** | 純度と明るさの後に適用するSSAO色のガンマです。明度軸だけを曲げ、色相と彩度は維持します。範囲0.1〜3、既定値1は中立です。 | `_SsaoColorGamma` |

## 2D透過光

光がキャラクターをどれだけ通り抜けたかを光源方向に計測し、薄い部分が光を含んでいるように見せます。

| 項目 | 説明 | シェーダープロパティ |
|---|---|---|
| **透過光を使う** | 髪先や裾のような薄い部分が光を含んでいるように見せます。光源方向に深度を2回読み、光がキャラクターをどれだけ通り抜けたかを直接計測するため、2Dリムライトとは無関係に単独で動作します。 | `_TranslucencyEnabled` |
| **計測幅** | 光が通ってきた距離を測るため、光源方向にどこまで見るかを決めます。大きくすると太い部分まで薄いと判定され、小さくすると先端だけが光ります。 | `_TranslucencyWidth` |
| **深度レンジ** | この距離（メートル）だけ後ろが空いていれば完全に貫通しているとみなします。髪の後ろの服のようにわずかに奥の面が背景と誤認されて光る場合は上げてください。 | `_TranslucencyDepthRange` |
| **シェル下限** | スカートやマントのような中空の衣装は画面上の幅が広いため厚いと計測されますが、布自体はごく薄いものです。そうした素材に0.8程度を与えると計測に関係なく常に薄いものとして扱われます。肌や手のような中身の詰まった部位は0のままにして計測に任せてください。 | `_TranslucencyShellFloor` |
| **透過強度** | 透過光全体の明るさ倍率です。0では計算そのものを飛ばします。 | `_TranslucencyStrength` |
| **エッジ強度** | シルエットの外側だけを明るくするレイヤーの強さです。0にすると内側レイヤーだけの単層とまったく同じになります。 | `_TranslucencyEdgeIntensity` |
| **幅** | 範囲は0-1、既定値は0.8です。0では領域なし、1では領域全体を使います。柔らかさを変えてもこの幅の外側へは広がりません。 | `_TranslucencyEdgeWidth` |
| **柔らかさ** | 範囲は0-1、既定値は1です。0は硬い境界、1は選択した幅の内側の柔らかなグラデーションです。幅は変わりません。 | `_TranslucencyEdgeSoftness` |
| **領域を反転** | エッジリムが生成する内側と外側の領域を入れ替えます。幅と柔らかさより先に適用されます。 | `_TranslucencyEdgeAreaInvert` |
| **エッジ色** | エッジ透過光に掛けるHDR色です。白では派生した色をそのまま通します。 | `_TranslucencyEdgeColor` |
| **色純度** | ベース色、エッジティント、HSVGを合成した後の彩度範囲0〜10、既定値1です。0は無彩色、1は合成色を維持し、1を超えると過彩度になります。 | `_TranslucencyEdgeColorPurity` |
| **エッジ明るさ** | エッジ色の純度を適用した後の明るさ倍率です。既定値1は従来の見た目を保ちます。 | `_TranslucencyEdgeColorBrightness` |
| **エッジガンマ** | 純度と明るさの後に適用するエッジ色のガンマです。既定値1は中立です。 | `_TranslucencyEdgeColorGamma` |
| **内側強度** | シルエットの内側を明るくするレイヤーの強さです。0にするとエッジレイヤーだけの単層とまったく同じになります。 | `_TranslucencyCenterIntensity` |
| **幅** | 範囲は0-1、既定値は0.8です。0では領域なし、1では領域全体を使います。柔らかさを変えてもこの幅の外側へは広がりません。 | `_TranslucencyCenterWidth` |
| **柔らかさ** | 範囲は0-1、既定値は1です。0は硬い境界、1は選択した幅の内側の柔らかなグラデーションです。幅は変わりません。 | `_TranslucencyCenterSoftness` |
| **領域を反転** | 内側リムが生成する内側と外側の領域を入れ替えます。幅と柔らかさより先に適用されます。 | `_TranslucencyCenterAreaInvert` |
| **内側の色** | 内側透過光に掛けるHDR色です。白では派生した色をそのまま通します。 | `_TranslucencyCenterColor` |
| **色純度** | ベース色、内側ティント、HSVGを合成した後の彩度範囲0〜10、既定値1です。0は無彩色、1は合成色を維持し、1を超えると過彩度になります。 | `_TranslucencyCenterColorPurity` |
| **内側の明るさ** | 内側色の純度を適用した後の明るさ倍率です。既定値1は従来の見た目を保ちます。 | `_TranslucencyCenterColorBrightness` |
| **内側ガンマ** | 純度と明るさの後に適用する内側色のガンマです。既定値1は中立です。 | `_TranslucencyCenterColorGamma` |
| **逆光減衰** | カメラと光源がどれだけ正確に向かい合ったときに最も強くなるかを決めます。値が大きいほど正確な逆光でのみ狭く強まり、順光で残る量は順光の下限が決めます。 | `_TranslucencyLightPower` |
| **順光の下限** | 正面から光を受けたときに残る透過光の割合です。散乱は逆光で強まるだけで順光でも消えないため、0にすると肌が肌らしく見えなくなります。 | `_TranslucencyAmbient` |
| **法線方向の曲げ** | 光の向きを表面法線側へ曲げ、正確な逆光でなくても曲面に沿って光が漏れるようにします。0では純粋な逆光反応だけが残ります。 | `_TranslucencyDistortion` |
| **視線方向の曲げ** | 光の向きをカメラ側へ曲げます。ヘアカードのように法線が当てにならない平面では、法線方向の曲げだけでは光が点いたり消えたりしますが、この値がそれを防ぎます。 | `_TranslucencyViewBend` |
| **ノーマルマップの影響** | 透過光の形にノーマルマップを反映する度合いです。0ではメッシュ法線のみ使用します。強いノーマルマップでグロウが表面ノイズのように割れる場合は下げてください。 | `_TranslucencyNormalInfluence` |
| **シーン照明の影響** | 0ではシーンの光の色を無視して指定した色だけを使い、1では光の色をそのまま受けます。ワールドごとに照明が大きく違うため両方必要です。 | `_TranslucencySceneLightInfluence` |
| **露出の柔らかさ** | 深度レンジで正規化した値の始点と終点の折れを滑らかにします。0でちょうど直線ランプになり、この値は応答カーブだけを変えて境界の位置は動かしません。 | `_TranslucencySoftness` |
| **密度** | 薄さが明るさに変わる減衰の強さです。大きいほど非常に薄い場所だけに光が残り密度の高い素材に見え、下げると広く広がります。 | `_TranslucencyDensity` |
| **色の分離** | 赤が青より深くまで散乱する性質を再現します。チャンネルごとに減衰が変わり光の届く範囲の大きさが変わるため、ティントでは作れない肌や髪特有のにじみが出ます。0で三チャンネルが完全に一致します。 | `_TranslucencyChannelSpread` |

## インナーアウトライン

画面深度を使って表示面の内側に描く2Dエッジを設定します。

| 項目 | 説明 | シェーダープロパティ |
|---|---|---|
| **Inner 2D Edgeを使用** | 画面深度の差から表面内側の境界線を描きます。追加ジオメトリが不要でノーマルアウトラインが破綻するメッシュにも使えますが、カメラ深度テクスチャが必要で、サーフェスモードがTransparentでは動作しません。 | `_OutlineInnerEdgeEnabled` |
| **圧力ソース** | 線の太さを調整するペイントチャンネルを選びます。VertexRedは頂点カラーのR、VertexAlphaはA、WidthMaskは幅マスクテクスチャを使います。頂点カラーが黒でインポートされたメッシュでVertexRedを選ぶと線が完全に消えます。 | `_OutlineHullPressureSource` |
| **内側エッジマスク** | 内側エッジを特定部位に限定するマスクを有効にします。顔などで不要な線が出る部位を消すときに使います。 | `_OutlineInnerEdgeMaskEnabled` |
| **チャンネル** | 内側エッジマスクから読み取るチャンネルです。複数のマスクを1枚にパックしている場合はチャンネルを分けて使います。 | `_OutlineInnerEdgeMaskChannel` |
| **反転** | 内側エッジマスクの白黒を反転し、適用部位を逆にします。 | `_OutlineInnerEdgeMaskInvert` |
| **強度** | マスクが内側エッジを削る度合いです。1ではマスクの黒い部分で線が完全に消え、下げると部分的に残ります。 | `_OutlineInnerEdgeMaskStrength` |
| **内側エッジ色** | 内側2Dエッジの色です。襟や顎、しわなどシルエット内側の深度段差に描かれる線がこの色になります。 | `_OutlineInnerEdgeColor` |
| **カラーガンマ** | インナーアウトライン色の明度軸にガンマを適用し、色相と彩度を維持します。1は変化なしで、アルファ・不透明度・幅には影響しません。 | `_OutlineInnerEdgeColorGamma` |
| **幅** | 内側2Dエッジの太さです。ノーマルアウトラインより細くしておくのが一般的です。 | `_OutlineInnerEdgeWidth` |
| **インナーアウトラインに適用** | ペイントした圧力をInner 2D Edgeの太さにも反映します。このトグルと圧力ソースはノーマルアウトライングループ内にありますが、この値はノーマルアウトラインをオフにしてもInner Edgeに作用し続けます。頂点カラーが黒のメッシュでオンだとInner Edgeが完全に消えます。 | `_OutlineInnerEdgePressureApply` |
| **深度バイアス** | この値より大きい深度差だけを境界と認めます。下げると緩やかな凹凸にも線が付いてノイズになり、上げると薄い部位の線が消えます。 | `_OutlineInnerEdgeBias` |
| **柔らかさ** | 内側エッジの空間グラデーション幅です。0は硬い線、1は線幅全体を境界から内側端まで連続的に0へぼかします。 | `_OutlineInnerEdgeSoftness` |
| **ブレンド不透明度** | 内側エッジ色が混ざる割合です。0では内側エッジが見えません。 | `_OutlineInnerEdgeColorBlendOpacity` |
