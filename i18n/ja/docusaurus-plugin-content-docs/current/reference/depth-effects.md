# 深度ベースエフェクト

カメラ深度テクスチャを読んで画面空間で描くエフェクトです。深度がない環境では丸ごと出ないので、値を触る前にまず深度を確認してください。内部2Dエッジもこのグループに含まれます。

:::note
このページの項目名と説明は、MingToonインスペクターが実際に表示する文言をソースからそのまま取得しています。
:::

## 深度

深度ベース効果の範囲とマスクを設定します。

| 項目 | 説明 | シェーダープロパティ |
|---|---|---|
| **マスター幅** | 2Dリムと2Dシャドウの画面オフセットに共通で掛かる倍率です。ここを0にすると、各モジュールの幅をいくら上げても何も出ません。 | `_DepthWidth` |
| **幅モード** | Screen Pixelsは画面ピクセル基準のため遠ざかるほど線が相対的に太く見え、Distance Stableは距離やFOVが変わっても太さが一定に見えます。Screen Pixelsを選ぶと距離スケールは機能しません。 | `_DepthWidthMode` |
| **距離スケール** | 幅モードがDistance Stableのときの太さの基準距離を決めます。Screen Pixelsでは反映されません。 | `_DepthDistanceScale` |
| **マスターバイアス** | 画面深度の差がこの値を超えたときだけ前後の境界と判定します。下げると浅い凹凸にも線が付いて汚くなり、上げると薄い部位の線が消えます。 | `_DepthBias` |
| **マスターの柔らかさ** | 深度境界判定の遷移幅です。低いと硬いインク線、高いと柔らかくぼけた境界になります。 | `_DepthSoftness` |

## 深度リム

画面深度差から生成するリム効果を設定します。

| 項目 | 説明 | シェーダープロパティ |
|---|---|---|
| **リム幅の倍率** | マスター幅に掛かる2Dリム専用の倍率です。最終的な太さはマスター幅×この値のため、マスター幅が0だとここを上げても意味がありません。 | `_DepthRimWidth` |
| **リム強度** | 2Dリムの明るさ倍率です。0ではリムの計算を飛ばすため、色や幅を変えても何も見えません。 | `_DepthRimIntensity` |
| **ベースカラー合成** | 0では指定したリム色が単色で出て、1ではベースマップの色を掛けて部位ごとに異なるリム色になります。 | `_DepthRimBaseColorMix` |
| **360度リム** | 0では光源側だけにリムが出て、1ではシルエット全体を囲みます。照明がない、または方向がよく変わる環境では上げると安定します。 | `_DepthRim360` |
| **シルエット開始点** | 表面がカメラからどれだけ傾いたらシルエットとみなすかを決めます。この値と下の遷移の柔らかさは、同じグループの外周シルエット制限が0の場合まったく反映されません。 | `_DepthRimSilhouetteThreshold` |
| **シルエット遷移の柔らかさ** | シルエット判定の遷移幅です。同じグループの外周シルエット制限が0の場合は反映されません。 | `_DepthRimSilhouetteSoftness` |

## 2Dシャドウ

前面オブジェクトの画面深度シルエットを使う軽量キャラクターシャドウを設定します。

| 項目 | 説明 | シェーダープロパティ |
|---|---|---|
| **影の明るさ** | 2Dシャドウ色の明るさ倍率です。下げるほど暗くなります。2Dシャドウとキャストシャドウを統合している場合は、統合されたレイヤーの明るさとして使われます。 | `_DepthShadowBrightness` |

## 深度透過光

光がキャラクターをどれだけ通り抜けたかを光源方向に計測し、薄い部分が光を含んでいるように見せます。

| 項目 | 説明 | シェーダープロパティ |
|---|---|---|
| **透過光を使う** | 髪先や裾のような薄い部分が光を含んでいるように見せます。光源方向に深度を2回読み、光がキャラクターをどれだけ通り抜けたかを直接計測するため、2Dデプスリムとは無関係に単独で動作します。 | `_TranslucencyEnabled` |
| **計測幅** | 光が通ってきた距離を測るため、光源方向にどこまで見るかを決めます。大きくすると太い部分まで薄いと判定され、小さくすると先端だけが光ります。 | `_TranslucencyWidth` |
| **深度レンジ** | この距離（メートル）だけ後ろが空いていれば完全に貫通しているとみなします。髪の後ろの服のようにわずかに奥の面が背景と誤認されて光る場合は上げてください。 | `_TranslucencyDepthRange` |
| **シェル下限** | スカートやマントのような中空の衣装は画面上の幅が広いため厚いと計測されますが、布自体はごく薄いものです。そうした素材に0.8程度を与えると計測に関係なく常に薄いものとして扱われます。肌や手のような中身の詰まった部位は0のままにして計測に任せてください。 | `_TranslucencyShellFloor` |
| **透過強度** | 透過光全体の明るさ倍率です。0では計算そのものを飛ばします。 | `_TranslucencyStrength` |
| **エッジ強度** | シルエットの外側だけを明るくするレイヤーの強さです。0にすると内側レイヤーだけの単層とまったく同じになります。 | `_TranslucencyEdgeIntensity` |
| **エッジ減衰** | エッジレイヤーがシルエットにどれだけ狭く集まるかを決めます。値が大きいほど輪郭に細く寄ります。 | `_TranslucencyEdgePower` |
| **エッジ色補正** | エッジレイヤーの色をベースカラーから作ります。絶対色ではなく派生なので、金髪は黄色く、黒髪は暗く、一つの設定でキャラクター全体に合います。中立値(0,1,1,1)では補正を飛ばします。 | `_TranslucencyEdgeHSVG` |
| **エッジティント** | 色補正後のエッジ色に最後に掛ける色です。白では何も変わりません。 | `_TranslucencyEdgeTint` |
| **内側強度** | シルエットの内側を明るくするレイヤーの強さです。0にするとエッジレイヤーだけの単層とまったく同じになります。 | `_TranslucencyCenterIntensity` |
| **内側減衰** | 内側レイヤーが正面を向いた面にどれだけ狭く集まるかを決めます。 | `_TranslucencyCenterPower` |
| **内側色補正** | 内側レイヤーの色をベースカラーから作ります。既定値は色相を赤寄りに回し彩度を上げるため、外縁は白に近く内側は暖かく光る髪になります。 | `_TranslucencyCenterHSVG` |
| **内側ティント** | 色補正後の内側の色に最後に掛ける色です。白では何も変わりません。 | `_TranslucencyCenterTint` |
| **逆光減衰** | カメラと光源がどれだけ正確に向かい合ったときに最も強くなるかを決めます。値が大きいほど正確な逆光でのみ狭く強まり、順光で残る量は順光の下限が決めます。 | `_TranslucencyLightPower` |
| **順光の下限** | 正面から光を受けたときに残る透過光の割合です。散乱は逆光で強まるだけで順光でも消えないため、0にすると肌が肌らしく見えなくなります。 | `_TranslucencyAmbient` |
| **法線方向の曲げ** | 光の向きを表面法線側へ曲げ、正確な逆光でなくても曲面に沿って光が漏れるようにします。0では純粋な逆光反応だけが残ります。 | `_TranslucencyDistortion` |
| **視線方向の曲げ** | 光の向きをカメラ側へ曲げます。ヘアカードのように法線が当てにならない平面では、法線方向の曲げだけでは光が点いたり消えたりしますが、この値がそれを防ぎます。 | `_TranslucencyViewBend` |
| **シーンライトの影響** | 0ではシーンの光の色を無視して指定した色だけを使い、1では光の色をそのまま受けます。ワールドごとに照明が大きく違うため両方必要です。 | `_TranslucencySceneLightInfluence` |
| **露出の柔らかさ** | 深度レンジで正規化した値の始点と終点の折れを滑らかにします。0でちょうど直線ランプになり、この値は応答カーブだけを変えて境界の位置は動かしません。 | `_TranslucencySoftness` |
| **密度** | 薄さが明るさに変わる減衰の強さです。大きいほど非常に薄い場所だけに光が残り密度の高い素材に見え、下げると広く広がります。 | `_TranslucencyDensity` |
| **色の分離** | 赤が青より深くまで散乱する性質を再現します。チャンネルごとに減衰が変わり光の届く範囲の大きさが変わるため、ティントでは作れない肌や髪特有のにじみが出ます。0で三チャンネルが完全に一致します。 | `_TranslucencyChannelSpread` |

## 内側2Dエッジ

画面深度を使って表示面の内側に描く2Dエッジを設定します。

| 項目 | 説明 | シェーダープロパティ |
|---|---|---|
| **Inner 2D Edgeを使用** | 画面深度の差から表面内側の境界線を描きます。追加ジオメトリが不要でハルが破綻するメッシュにも使えますが、カメラ深度テクスチャが必要で、サーフェスモードがTransparentでは動作しません。 | `_OutlineInnerEdgeEnabled` |
| **圧力ソース** | 線の太さを調整するペイントチャンネルを選びます。VertexRedは頂点カラーのR、VertexAlphaはA、WidthMaskは幅マスクテクスチャを使います。頂点カラーが黒でインポートされたメッシュでVertexRedを選ぶと線が完全に消えます。 | `_OutlineHullPressureSource` |
| **Inner Edge アウトラインに適用** | ペイントした圧力をInner 2D Edgeの太さにも反映します。このトグルと圧力ソースはClassic Hullグループ内にありますが、この値はHullをオフにしてもInner Edgeに作用し続けます。頂点カラーが黒のメッシュでオンだとInner Edgeが完全に消えます。 | `_OutlineInnerEdgePressureApply` |
| **深度バイアス** | この値より大きい深度差だけを境界と認めます。下げると緩やかな凹凸にも線が付いてノイズになり、上げると薄い部位の線が消えます。 | `_OutlineInnerEdgeBias` |
| **柔らかさ** | 内側エッジの空間グラデーション幅です。0は硬い線、1は線幅全体を境界から内側端まで連続的に0へぼかします。 | `_OutlineInnerEdgeSoftness` |
