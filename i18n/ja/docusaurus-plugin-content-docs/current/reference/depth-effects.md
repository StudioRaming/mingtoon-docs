# 深度ベースのエフェクト

カメラの深度テクスチャを読み、スクリーンスペースで描画する項目です。深度がないと、まるごと表示されません。

このページは値を探すための表です。オンにする順序が必要な場合は [深度ベースのエフェクトのガイド](/guides/depth-effects) を見てください。

見出しと目次は、インスペクターのセクション名と表示順をそのまま踏襲しています。

マップとマスクのスロット内の項目は、すべてのスロットで共通です。
チャンネル・リマップ・フェザー・マスクUVは [テクスチャスロット共通UI](/guides/texture-modules) に一度だけ記載しています。

## 深度エフェクトマスター {#깊이-효과-마스터}

| インスペクターのラベル | 形式 | 範囲 | 既定値 | 役割 |
|---|---|---|---|---|
| **深度エフェクト** | オン/オフ | - | オフ | デプスリムライト・SSSSS（実験的）・デプスシャドウなど深度エフェクト全体のマスタースイッチです |
| **深度の可用性** | 選択 | Auto / Force On / Force Off / Diagnostic | Auto | 深度テクスチャの有無を判定する方式です |
| **全体幅** | 実数 | 0 ~ 16 | 1 | デプスリムライトとデプスシャドウの画面オフセットに共通で掛かる倍率です |
| **幅モード** | 選択 | Screen Pixels / Distance Stable | Distance Stable | Screen Pixelsは画面ピクセル基準のため遠ざかるほど線が相対的に太く見え、Distance… |
| **距離スケーリング** | 実数 | 0 ~ 4 | 1 | 幅モードがDistance Stableのときの太さの基準距離を決めます |
| **近距離カメラ幅補正** | 実数 | 0 ~ 1 | 1 | カメラが面に近い時にデプス効果の幅が過度に広がるのを抑えます |
| **全体バイアス** | 実数 | 0 ~ 1 | 0.02 | 画面深度の差がこの値を超えたときだけ前後の境界と判定します |
| **全体の柔らかさ** | 実数 | 0.0001 ~ 1 | 0.08 | 深度境界判定の遷移幅です |

| **キャストシャドウ内の表示量** | 実数 | 0 ~ 1 | 0.5 | 0ではキャストシャドウ内で非表示、1では完全に表示します |

| **ベースカラーを混合** | 実数 | 0 ~ 1 | 0.5 | 0では指定したリム色が単色で出て、1ではベースマップの色を掛けて部位ごとに異なるリム色になります |
| **360度リム** | 実数 | 0 ~ 1 | 0.3 | 0では光源側だけにリムが出て、1ではシルエット全体を囲みます |
| **内部線の抑制** | オン/オフ | - | オン | 周辺の深度サンプルがすべて外周と判定された場合のみリムを残し、目・鼻・口や分割法線の偽線を除去します |
| **内部線チェック範囲** | 実数 | 0 ~ 1 | 0.2 | 偽の内部線を除外する周辺範囲です |
| **デプスリムサンプル品質** | 選択 | Low1Tap / Standard2Tap / High4Tap | Standard2Tap | デプスリムがピクセルごとに使う深度サンプル数です |
| **外周シルエット制限** | 実数 | 0 ~ 1 | 1 | 元のメッシュ法線で正面内部のリムを抑えます |
| **シルエット開始点** | 実数 | 0 ~ 1 | 0.12 | 表面がカメラからどれだけ傾いたらシルエットとみなすかを決めます |
| **シルエット遷移の柔らかさ** | 実数 | 0.001 ~ 0.25 | 0.04 | シルエット判定の遷移幅です |

|---|---|---|---|---|
| **SSAOを使用** | オン/オフ | - | オフ | カメラ深度テクスチャを放射状に読み、折れ目や接触部を柔らかく暗くします |
| **SSAO 強度** | 実数 | 0 ~ 2 | 1 | 効果の強さです |
| **SSAO コントラスト** | 実数 | 0.5 ~ 4 | 1 | 遮蔽のコントラストです |
| **SSAO バイアス** | 実数 | 0 ~ 1 | 0.4 | 自己面を遮蔽と誤認しないための余裕を、SSAO半径の比率で指定します（0.4 = 半径の40%） |
| **SSAO 半径** | 実数 | 0.001 ~ 0.05 | 0.005 | 遮蔽を探すワールド半径（0.001〜0.05m）です |
| **接触減衰** | 実数 | 0.25 ~ 4 | 1 | 手前を遮るものがどれだけ近ければ遮蔽と認めるかを、`SSAO 半径`の倍数で指定します |

| **SSAO マスク強度** | 実数 | 0 ~ 1 | 0 | デプスシャドウマスクをそのまま借りて、SSAOが入る範囲を制限します |

| **色純度** | 実数 | 0 ~ 10 | 1 | SSAOが継承した影色にティントを掛けた後の彩度です |
| **カラー明るさ** | 実数 | 0 ~ 4 | 1 | 純度を適用した後のSSAO色の明るさ倍率です |
| **カラーガンマ** | 実数 | 0.1 ~ 3 | 1 | 純度と明るさの後に適用するSSAO色のガンマです |
