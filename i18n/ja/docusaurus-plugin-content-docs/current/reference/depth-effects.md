# 深度ベースエフェクト

カメラ深度テクスチャを読んで画面空間で描くエフェクトです。深度がない環境では丸ごと出ないので、値を触る前にまず深度を確認してください。内部2Dエッジもこのグループに含まれます。

:::note
このページの項目名と説明は、MingToonインスペクターが実際に表示する文言をソースからそのまま取得しています。
:::

## 深度

深度ベース効果の範囲とマスクを設定します。

| 項目 | 説明 | シェーダープロパティ |
|---|---|---|
| **深度エフェクト** | 2D深度リム・深度透過光・2Dシャドウなど深度エフェクト全体のマスタースイッチです。オフにすると3つのモジュールがすべて止まります。これらの効果はカメラ深度テクスチャが必要です。 | `_DepthEffectsEnabled` |
| **深度の可用性** | 深度テクスチャの有無を判定する方式です。基本はAutoのままにしてください。Force Onは自動判定が届かないホストで作者が深度バッファを保証できる場合のみ、Force Offは深度効果を完全に遮断、Diagnosticは判定状態を画面に表示します。 | `_MingDepthAvailabilityMode` |
| **マスター幅** | 2Dリムと2Dシャドウの画面オフセットに共通で掛かる倍率です。ここを0にすると、各モジュールの幅をいくら上げても何も出ません。 | `_DepthWidth` |
| **幅モード** | Screen Pixelsは画面ピクセル基準のため遠ざかるほど線が相対的に太く見え、Distance Stableは距離やFOVが変わっても太さが一定に見えます。Screen Pixelsを選ぶと距離スケールは機能しません。 | `_DepthWidthMode` |
| **距離スケール** | 幅モードがDistance Stableのときの太さの基準距離を決めます。Screen Pixelsでは反映されません。 | `_DepthDistanceScale` |
| **マスターバイアス** | 画面深度の差がこの値を超えたときだけ前後の境界と判定します。下げると浅い凹凸にも線が付いて汚くなり、上げると薄い部位の線が消えます。 | `_DepthBias` |
| **マスターの柔らかさ** | 深度境界判定の遷移幅です。低いと硬いインク線、高いと柔らかくぼけた境界になります。 | `_DepthSoftness` |
| **MingToon 2D投影シャドウをキャスト** | このマテリアルをMingToonのカメラ深度へ書くかを決めます。眼鏡やアクセサリーでオフにするとOpaque・Cutout・Transparentすべてが2D投影影のキャスターから外れます。通常のカラー描画、Transparentの深度プリパス、UnityのリアルタイムShadowCaster影はすべて維持されるため、自己ソートと輪郭はオンのときと同じです。オフのマテリアルは自分自身が深度に存在しないため、そのマテリアルのDepth Rim・Inner 2D Edge・2Dシャドウ・深度透過光は背後を見られません。眼鏡自体にリムが必要な場合は深度を使わないFresnel Rimを使ってください。 | `_Ming2DShadowCasterEnabled` |

## 深度リム

画面深度差から生成するリム効果を設定します。

| 項目 | 説明 | シェーダープロパティ |
|---|---|---|
| **2D深度リム** | シルエットの深度差で描く2Dリムライトのオン/オフです。法線ベースのフレネルリムと異なり、外周に均一な太さの線が出ます。カメラ深度テクスチャが必要です。 | `_DepthRimEnabled` |
| **リム幅の倍率** | マスター幅に掛かる2Dリム専用の倍率です。最終的な太さはマスター幅×この値のため、マスター幅が0だとここを上げても意味がありません。 | `_DepthRimWidth` |
| **リム強度** | 2Dリムの明るさ倍率です。0ではリムの計算を飛ばすため、色や幅を変えても何も見えません。 | `_DepthRimIntensity` |
| **深度リムマスク** | 2Dリムを特定部位に限定するマスクを有効にします。金属装飾だけにリムを残す、といった用途です。 | `_DepthRimMaskEnabled` |
| **チャンネル** | リムマスクから読み取るチャンネルです。複数のマスクを1枚にパックしている場合はチャンネルを分けて使います。 | `_DepthRimMaskChannel` |
| **反転** | リムマスクの白黒を反転し、適用部位を逆にします。 | `_DepthRimMaskInvert` |
| **強度** | マスクがリムを削る度合いです。1ではマスクの黒い部分でリムが完全に消え、下げると部分的に残ります。 | `_DepthRimMaskStrength` |
| **リム色** | 2Dリムの色です。HDRカラーなので強度を上げればブルームと合わせて光らせることもできます。 | `_DepthRimColor` |
| **ベースカラー合成** | 0では指定したリム色が単色で出て、1ではベースマップの色を掛けて部位ごとに異なるリム色になります。 | `_DepthRimBaseColorMix` |
| **360度リム** | 0では光源側だけにリムが出て、1ではシルエット全体を囲みます。照明がない、または方向がよく変わる環境では上げると安定します。 | `_DepthRim360` |
| **シルエット開始点** | 表面がカメラからどれだけ傾いたらシルエットとみなすかを決めます。この値と下の遷移の柔らかさは、同じグループの外周シルエット制限が0の場合まったく反映されません。 | `_DepthRimSilhouetteThreshold` |
| **シルエット遷移の柔らかさ** | シルエット判定の遷移幅です。同じグループの外周シルエット制限が0の場合は反映されません。 | `_DepthRimSilhouetteSoftness` |
| **ブレンド不透明度** | リム色が結果に混ざる割合です。リムが強すぎるときは強度より先にこの値を下げてみてください。0ではリムが見えません。 | `_DepthRimColorBlendOpacity` |

## 2Dシャドウ

前面オブジェクトの画面深度シルエットを使う軽量キャラクターシャドウを設定します。

| 項目 | 説明 | シェーダープロパティ |
|---|---|---|
| **2Dシャドウ** | 深度差で作る2Dシャドウのオン/オフです。前髪が顔に落とす影が代表的な用途です。カメラ深度テクスチャが必要です。 | `_DepthShadowEnabled` |
| **2Dシャドウマスク** | 2Dシャドウを特定部位に限定するマスクを有効にします。不要な場所に落ちる2D影を消すときに使います。 | `_DepthShadowMaskEnabled` |
| **チャンネル** | 2Dシャドウマスクから読み取るチャンネルです。複数のマスクを1枚にパックしている場合はチャンネルを分けて使います。 | `_DepthShadowMaskChannel` |
| **反転** | 2Dシャドウマスクの白黒を反転し、適用部位を逆にします。 | `_DepthShadowMaskInvert` |
| **2Dシャドウ色** | 2Dシャドウの色です。髪が顔に落とす深度ベースの影がこの色で塗られます。他の影色とトーンを合わせてください。 | `_DepthShadowColor` |
| **ブレンド不透明度** | 2Dシャドウ色が結果に混ざる割合です。統合シャドウモードでは重なり深度として働きます — 0ではフォームシャドウと完全に同色になり、上げるほど2D影がその中で濃く残ります。 | `_DepthShadowColorBlendOpacity` |
| **影の明るさ** | 2Dシャドウ色の明るさ倍率です。下げるほど暗くなります。2Dシャドウとキャストシャドウを統合している場合は、統合されたレイヤーの明るさとして使われます。 | `_DepthShadowBrightness` |
| **顔2D影アシスト** | 既定はオフです。顔領域を指定後に有効にすると、カメラ深度ベース投影影の自己重なりを抑えます。同じ深度を使うデプスリムや内部エッジも変化する場合があります。 | `_DepthShadowFaceAssistEnabled` |
| **強度** | マスクが2Dシャドウを削る度合いです。1ではマスクの黒い部分で影が完全に消え、下げると部分的に残ります。 | `_DepthShadowMaskStrength` |

## SSAO (画面空間遮蔽)

カメラ深度テクスチャをピクセルごとに読み直し、折れ目や接触部を暗くします。オクルージョンマップと乗算されるのではなく、トーンバンドとスクリーントーンを通過した後に暗い方を採用する形で合流します。深度テクスチャがない環境では静かに消えます。

| 項目 | 説明 | シェーダープロパティ |
|---|---|---|
| **SSAOを使用** | カメラ深度テクスチャをピクセルごとに読み直し、折れ目や接触部を暗くします。結果はオクルージョンマップと同じ場所に合流するため影の一部として読まれ、オフの間は計算がコンパイルから外れて費用はゼロです。 | `_MingSsaoEnabled` |
| **SSAO 強度** | 効果の強さです。0では切ったのと同じ絵になりますが計算は走り続けるため、使わないときはSSAOを使用をオフにしてください。 | `_MingSsaoIntensity` |
| **SSAO コントラスト** | 遮蔽のコントラストです。上げると深くくぼんだ部分だけが残り、薄い遮蔽は消えます。 | `_MingSsaoPower` |
| **SSAO 半径** | 遮蔽を探す半径で、単位はメートルです（0.001〜0.1は1mm〜10cm）。画面ピクセルではなくワールド基準のため、カメラが離れても画角が変わっても太さが保たれます。ただしこれは`SSAO 距離補正`が1（既定値）のときに成り立ち、下げると1メートル以内で半径が縮みます。 | `_MingSsaoRadius` |
| **SSAO 品質** | ピクセルあたりの深度サンプル数です。Low 4・Medium 8・High 12・Ultra 16で、この費用はマテリアルごとに一度ではなく画面に見えるフラグメントごとに発生します。キャラクターの大きさでは品質を下げて半径を上げる方が概ね良い絵になります。 | `_MingSsaoQuality` |
| **SSAO バイアス** | 自分の面を遮蔽と誤って数えるのを防ぐ余裕（メートル）です。平らな面にムラが出たら少し上げ、折れ目が平坦なら下げます。 | `_MingSsaoBias` |
| **SSAO フェード範囲** | 手前を遮るものがどれだけ近ければ遮蔽と認めるかの距離（メートル）です。この範囲を超えると重みが滑らかに0へ落ちるため、遠くの壁がシルエット全体を暗くしません。 | `_MingSsaoFadeRange` |
| **SSAO 消失距離** | 効果が完全に消える距離（メートル）です。フェードはこの値の75%地点から始まるため、12にすると9mから薄くなり12mで0になります。0で距離フェードを使いません。 | `_MingSsaoFarDistance` |
| **SSAO 距離補正** | 1では半径が実際のワールドサイズに固定され、カメラが近づいても画角が変わっても同じ位置に同じ形の陰影が入ります。0では1メートル以内で半径が縮む従来の近接補正に戻ります。 | `_MingSsaoDistanceCompensation` |
| **SSAO ライト方向反応** | 0ではライトに関係なく均一な遮蔽です。上げると探索範囲がライト側へ傾き、光の届かない反対側に遮蔽が集まります。ライトがカメラ正面に近づくほど傾きは自動的に小さくなり、正面光で陰影が片側に寄りません。 | `_MingSsaoLightDirectionInfluence` |
| **SSAO マスク強度** | 2Dシャドウマスクをそのまま借りて、SSAOが入る範囲を制限します。0ではマスクを使わず、上げるほどマスクが覆う場所から遮蔽が抜けます。チャンネル・反転・HSVGは2Dシャドウマスクに設定した値を共有します。 | `_MingSsaoMaskStrength` |
| **SSAO ティント** | 遮蔽が入った箇所にのみ乗算される色です。白なら何も着色せず、既存の影色をそのまま残します。 | `_MingSsaoColor` |
| **SSAO 明度** | 遮蔽部分をどれだけ暗くするかです。1では追加の暗さはつかず、下げるほどその箇所だけ濃くなります。 | `_MingSsaoBrightness` |
| **SSAO 彩度** | 遮蔽部分の彩度です。1でそのまま、0でグレーに抜け、1を超えるとその箇所だけ色が濃くなります。 | `_MingSsaoSaturation` |

## 深度透過光

光がキャラクターをどれだけ通り抜けたかを光源方向に計測し、薄い部分が光を含んでいるように見せます。

| 項目 | 説明 | シェーダープロパティ |
|---|---|---|
| **透過光を使う** | 髪先や裾のような薄い部分が光を含んでいるように見せます。光源方向に深度を2回読み、光がキャラクターをどれだけ通り抜けたかを直接計測するため、2Dデプスリムとは無関係に単独で動作します。 | `_TranslucencyEnabled` |
| **計測幅** | 光が通ってきた距離を測るため、光源方向にどこまで見るかを決めます。大きくすると太い部分まで薄いと判定され、小さくすると先端だけが光ります。 | `_TranslucencyWidth` |
| **深度レンジ** | この距離（メートル）だけ後ろが空いていれば完全に貫通しているとみなします。髪の後ろの服のようにわずかに奥の面が背景と誤認されて光る場合は上げてください。 | `_TranslucencyDepthRange` |
| **シェル下限** | スカートやマントのような中空の衣装は画面上の幅が広いため厚いと計測されますが、布自体はごく薄いものです。そうした素材に0.8程度を与えると計測に関係なく常に薄いものとして扱われます。肌や手のような中身の詰まった部位は0のままにして計測に任せてください。 | `_TranslucencyShellFloor` |
| **透過強度** | 透過光全体の明るさ倍率です。0では計算そのものを飛ばします。 | `_TranslucencyStrength` |
| **エッジ強度** | シルエットの外側だけを明るくするレイヤーの強さです。0にすると内側レイヤーだけの単層とまったく同じになります。 | `_TranslucencyEdgeIntensity` |
| **エッジ減衰** | エッジレイヤーがシルエットにどれだけ狭く集まるかを決めます。値が大きいほど輪郭に細く寄ります。 | `_TranslucencyEdgePower` |
| **エッジ幅** | シルエット際を回る透過光の帯の幅です。縁のグロウが内側まで広がりすぎる場合は下げてください。 | `_TranslucencyEdgeWidth` |
| **エッジの柔らかさ** | エッジの帯が消える境界の緩やかさです。上げると柔らかくにじみ、下げるとくっきりした帯になります。 | `_TranslucencyEdgeSoftness` |
| **エッジ色補正** | エッジレイヤーの色をベースカラーから作ります。絶対色ではなく派生なので、金髪は黄色く、黒髪は暗く、一つの設定でキャラクター全体に合います。中立値(0,1,1,1)では補正を飛ばします。 | `_TranslucencyEdgeHSVG` |
| **エッジティント** | 色補正後のエッジ色に最後に掛ける色です。白では何も変わりません。 | `_TranslucencyEdgeTint` |
| **内側強度** | シルエットの内側を明るくするレイヤーの強さです。0にするとエッジレイヤーだけの単層とまったく同じになります。 | `_TranslucencyCenterIntensity` |
| **内側減衰** | 内側レイヤーが正面を向いた面にどれだけ狭く集まるかを決めます。 | `_TranslucencyCenterPower` |
| **内側の幅** | 正面を向いた内側の透過光の帯の幅です。耳や指先のような薄い部位の中央が透けて見える範囲を調整します。 | `_TranslucencyCenterWidth` |
| **内側の柔らかさ** | 内側の帯が消える境界の緩やかさです。上げると柔らかくにじみ、下げるとくっきりします。 | `_TranslucencyCenterSoftness` |
| **内側色補正** | 内側レイヤーの色をベースカラーから作ります。既定値は色相を赤寄りに回し彩度を上げるため、外縁は白に近く内側は暖かく光る髪になります。 | `_TranslucencyCenterHSVG` |
| **内側ティント** | 色補正後の内側の色に最後に掛ける色です。白では何も変わりません。 | `_TranslucencyCenterTint` |
| **逆光減衰** | カメラと光源がどれだけ正確に向かい合ったときに最も強くなるかを決めます。値が大きいほど正確な逆光でのみ狭く強まり、順光で残る量は順光の下限が決めます。 | `_TranslucencyLightPower` |
| **順光の下限** | 正面から光を受けたときに残る透過光の割合です。散乱は逆光で強まるだけで順光でも消えないため、0にすると肌が肌らしく見えなくなります。 | `_TranslucencyAmbient` |
| **法線方向の曲げ** | 光の向きを表面法線側へ曲げ、正確な逆光でなくても曲面に沿って光が漏れるようにします。0では純粋な逆光反応だけが残ります。 | `_TranslucencyDistortion` |
| **視線方向の曲げ** | 光の向きをカメラ側へ曲げます。ヘアカードのように法線が当てにならない平面では、法線方向の曲げだけでは光が点いたり消えたりしますが、この値がそれを防ぎます。 | `_TranslucencyViewBend` |
| **ノーマルマップの影響** | 透過光の形にノーマルマップを反映する度合いです。0ではメッシュ法線のみ使用します。強いノーマルマップでグロウが表面ノイズのように割れる場合は下げてください。 | `_TranslucencyNormalInfluence` |
| **シーンライトの影響** | 0ではシーンの光の色を無視して指定した色だけを使い、1では光の色をそのまま受けます。ワールドごとに照明が大きく違うため両方必要です。 | `_TranslucencySceneLightInfluence` |
| **露出の柔らかさ** | 深度レンジで正規化した値の始点と終点の折れを滑らかにします。0でちょうど直線ランプになり、この値は応答カーブだけを変えて境界の位置は動かしません。 | `_TranslucencySoftness` |
| **密度** | 薄さが明るさに変わる減衰の強さです。大きいほど非常に薄い場所だけに光が残り密度の高い素材に見え、下げると広く広がります。 | `_TranslucencyDensity` |
| **色の分離** | 赤が青より深くまで散乱する性質を再現します。チャンネルごとに減衰が変わり光の届く範囲の大きさが変わるため、ティントでは作れない肌や髪特有のにじみが出ます。0で三チャンネルが完全に一致します。 | `_TranslucencyChannelSpread` |

## 内側2Dエッジ

画面深度を使って表示面の内側に描く2Dエッジを設定します。

| 項目 | 説明 | シェーダープロパティ |
|---|---|---|
| **Inner 2D Edgeを使用** | 画面深度の差から表面内側の境界線を描きます。追加ジオメトリが不要でハルが破綻するメッシュにも使えますが、カメラ深度テクスチャが必要で、サーフェスモードがTransparentでは動作しません。 | `_OutlineInnerEdgeEnabled` |
| **圧力ソース** | 線の太さを調整するペイントチャンネルを選びます。VertexRedは頂点カラーのR、VertexAlphaはA、WidthMaskは幅マスクテクスチャを使います。頂点カラーが黒でインポートされたメッシュでVertexRedを選ぶと線が完全に消えます。 | `_OutlineHullPressureSource` |
| **内側エッジマスク** | 内側エッジを特定部位に限定するマスクを有効にします。顔などで不要な線が出る部位を消すときに使います。 | `_OutlineInnerEdgeMaskEnabled` |
| **チャンネル** | 内側エッジマスクから読み取るチャンネルです。複数のマスクを1枚にパックしている場合はチャンネルを分けて使います。 | `_OutlineInnerEdgeMaskChannel` |
| **反転** | 内側エッジマスクの白黒を反転し、適用部位を逆にします。 | `_OutlineInnerEdgeMaskInvert` |
| **強度** | マスクが内側エッジを削る度合いです。1ではマスクの黒い部分で線が完全に消え、下げると部分的に残ります。 | `_OutlineInnerEdgeMaskStrength` |
| **内側エッジ色** | 内側2Dエッジの色です。襟や顎、しわなどシルエット内側の深度段差に描かれる線がこの色になります。 | `_OutlineInnerEdgeColor` |
| **幅** | 内側2Dエッジの太さです。ノーマルアウトラインより細くしておくのが一般的です。 | `_OutlineInnerEdgeWidth` |
| **Inner Edge アウトラインに適用** | ペイントした圧力をInner 2D Edgeの太さにも反映します。このトグルと圧力ソースはClassic Hullグループ内にありますが、この値はHullをオフにしてもInner Edgeに作用し続けます。頂点カラーが黒のメッシュでオンだとInner Edgeが完全に消えます。 | `_OutlineInnerEdgePressureApply` |
| **深度バイアス** | この値より大きい深度差だけを境界と認めます。下げると緩やかな凹凸にも線が付いてノイズになり、上げると薄い部位の線が消えます。 | `_OutlineInnerEdgeBias` |
| **柔らかさ** | 内側エッジの空間グラデーション幅です。0は硬い線、1は線幅全体を境界から内側端まで連続的に0へぼかします。 | `_OutlineInnerEdgeSoftness` |
| **ブレンド不透明度** | 内側エッジ色が混ざる割合です。0では内側エッジが見えません。 | `_OutlineInnerEdgeColorBlendOpacity` |
