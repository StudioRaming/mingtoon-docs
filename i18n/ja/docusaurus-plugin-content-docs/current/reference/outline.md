# アウトライン

メッシュを拡張して描くアウトラインの項目です。カメラの深度は使いません。

このページは値を探すための表です。オンにする順序が必要な場合は [アウトラインガイド](/guides/outline) を見てください。

見出しと目次は、インスペクターのセクション名と表示順をそのまま踏襲しています。

マップとマスクのスロット内の項目は、すべてのスロットで共通です。
チャンネル・リマップ・フェザー・マスクUVは [テクスチャスロット共通UI](/guides/texture-modules) に一度だけ記載しています。

## ノーマルアウトライン {#노멀-아웃라인}

| インスペクターのラベル | 形式 | 範囲 | 既定値 | 役割 |
|---|---|---|---|---|
| **ノーマルアウトラインを使用** | オン/オフ | - | オン | メッシュを法線方向へ拡張して線を描きます |
| **アウトライン色** | 色 | - | 0.75, 0.6, 0.6, 1 | ノーマルアウトラインの線の色です |
| **ライトボリューム色の反映** | 実数 | 0 ~ 1 | 1 | ワールドのライトボリュームの色と明るさをアウトライン線に掛けます |
| **アウトライン色の合成** | 選択 | Normal / Multiply | Multiply | アウトラインの基本色に色を合成する方法です |
| **アウトライン色の合成強度** | 実数 | 0 ~ 1 | 1 | 選んだ合成方法をアウトラインの基本色に適用する強さです |
| **ベースマップに追従** | オン/オフ | - | オフ | ベースマップとすべてのテクスチャレイヤーを合成したRGBをアウトラインの基本色に使います |
| **アルファに追従** | オン/オフ | - | オン | オンでは元のサーフェスアルファをアウトライン出力に反映します |
| **アウトライン幅** | 実数 | 0 ~ 10 | 1 | アウトラインの太さです |
| **頂点カラーのアルファ（VertexAlpha）に切り替え** | 選択 | Constant / VertexAlpha / VertexRed / WidthMask / OutlineNormalUV8 | Constant | 線の太さを調整するペイントチャンネルを選びます |
| **ノーマルアウトラインに適用** | オン/オフ | - | オン | ペイントした圧力をノーマルアウトラインの太さに反映します |
| **インナーアウトラインに適用** | オン/オフ | - | オフ | ペイントした圧力をInner Depth Edgeの太さにも反映します |
| **圧力コントラスト** | 実数 | -4 ~ 4 | 2 | 圧力値を指数で押して線の太さの差を広げます |
| **内側線抑制オフセット** | 実数 | 0 ~ 1 | 0.004 | 値を上げると画面位置と幅を保ったまま輪郭線のラスタ深度基準だけを奥へ移動し、本体との深度差が小さい内側線から隠します |
| **DOFからアウトラインを保護** | オン/オフ | - | オン | アウトラインが深度を書き込み、被写界深度（DOF）ブラーが線を消せないよう保護します |
| **遠距離最小ピクセル** | 実数 | 0 ~ 4 | 0.95 | 遠距離でもアウトラインがこのスクリーンピクセル数より細くならないよう維持します |
| **幅モード** | 選択 | PixelStable / WorldSpace | WorldSpace | PixelStableは画面ピクセル基準のため距離に関わらず線の太さが一定で… |
| **法線ソース** | 選択 | MeshNormal / VertexColorTS / UV8TS | MeshNormal | アウトラインをどの方向へ押し出すかを決めます |
| **作成済みベクトル方向** | オン/オフ | - | オフ | アウトラインを押し出す方向をテクスチャで直接指定します |
| **ベクトルスケール** | 実数 | -10 ~ 10 | 1 | 指定した方向ベクトルの強さです |
| **深度バイアス** | 実数 | -0.1 ~ 0.1 | 0 | ノーマルアウトライン全体をカメラ側に引き寄せたり奥へ押したりして、他のパーツに埋もれたアウトラインを引き出します |
| **ライティングを適用** | オン/オフ | - | オン | フォームシャドウ・リム・フロントライトをアウトラインに適用します |
| **フロントライト色** | 色 | - | 白 | 「ライティングを適用」がオンのときにフロントライトへ混ぜる色です |
| **フロントライト強度** | 実数 | 0 ~ 1 | 0 | 表面法線と主光源方向の内積を0～1に制限した値でフロントライト色を混ぜる量です |
