# アウトライン

方式が2つあります。Hullはメッシュを拡張して描くのでどこでも動作し、Inner Edgeは画面深度を読んで表面の内側の線まで描けますが深度が必要です。

:::note
このページの項目名と説明は、MingToonインスペクターが実際に表示する文言をソースからそのまま取得しています。
:::

## アウトライン

輪郭線の幅、色、マスク、距離補正を設定します。

| 項目 | 説明 | シェーダープロパティ |
|---|---|---|
| **Classic Hullを使用** | メッシュを反転・拡張する方式のアウトラインです。追加パス1回で描画され、カメラ深度テクスチャなしで動作します。 | `_OutlineHullEnabled` |
| **幅モード** | PixelStableは画面ピクセル基準のため距離に関わらず線の太さが一定で、WorldSpaceはワールドサイズ基準のため遠ざかるほど細くなります。アバターにはPixelStableが安全です。 | `_OutlineHullWidthMode` |
| **圧力ソース** | 線の太さを調整するペイントチャンネルを選びます。VertexRedは頂点カラーのR、VertexAlphaはA、WidthMaskは幅マスクテクスチャを使います。頂点カラーが黒でインポートされたメッシュでVertexRedを選ぶと線が完全に消えます。 | `_OutlineHullPressureSource` |
| **ハル圧力コントラスト** | 圧力値を指数で押して線の太さの差を広げます。0で圧力を完全に無視、1が元の値、上げるほど細い部分がより細くなります。Pressure SourceがOutlineNormalUV8なら広い面は太く、頂点は細くなります。 | `_OutlineHullPressureContrast` |
| **ノーマルソース** | ハルをどの方向へ押し出すかを決めます。MeshNormalはメッシュノーマルをそのまま使い、VertexColorTSとUV8TSは平滑化したアウトライン用ノーマルを頂点カラーやUV8にベイクしてある場合のみ有効です。ベイクしていないメッシュで選ぶと角の部分で線が途切れます。 | `_OutlineHullNormalSource` |
| **指定ベクトル方向を使用** | アウトラインを押し出す方向をテクスチャで直接指定します。オフの間は下のベクトルUVとベクトルスケールが無視され、ノーマルソースが方向を決めます。 | `_OutlineVectorEnabled` |
| **ベクトルUV** | アウトライン方向テクスチャを読むUVチャンネルです。指定ベクトル方向がオフの間は無視されます。 | `_OutlineVectorUVMode` |
| **ベクトルスケール** | 指定した方向ベクトルの強さです。マイナスにすると向きが反転します。指定ベクトル方向がオフの間は無視されます。 | `_OutlineVectorScale` |
| **深度バイアス** | ハル全体をカメラ側に引き寄せたり奥へ押したりして、他のパーツに埋もれたアウトラインを引き出します。引き寄せすぎると線が顔の前に浮いて見えます。 | `_OutlineHullZBias` |
| **シェーディングを含める** | フォーム・キャスト・2Dシャドウと2Dリムを最終アウトライン色へ反映します。オフにすると照明に依存しない均一な線色を保ちます。 | `_OutlineIncludeFormShadow` |
| **ステンシル参照値** | アウトラインパスが使うステンシル値です。他のシェーダーのマスクと合わせるときだけ変更してください。既定値ではステンシルは描画結果に影響しません。 | `_OutlineStencilRef` |
| **ステンシル読み取りマスク** | ステンシルバッファを読むときに適用するビットマスクです。他のシェーダーのステンシルマスクと連携する場合にのみ使用します。 | `_OutlineStencilReadMask` |
| **ステンシル書き込みマスク** | ステンシルバッファに書き込むときに適用するビットマスクです。他のシェーダーのステンシルマスクと連携する場合にのみ使用します。 | `_OutlineStencilWriteMask` |
| **ステンシル比較** | ステンシル値をどう比較してピクセルを通すかを決めます。Alwaysではステンシルがアウトラインを隠しません。他のシェーダーでアウトラインを切り抜くときだけ変更してください。 | `_OutlineStencilComp` |
| **ステンシル通過時の動作** | ステンシルと深度の両テストに通過したときにステンシルバッファへ行う動作です。既定のKeepはバッファを変更しません。 | `_OutlineStencilPass` |
| **ステンシル失敗時の動作** | ステンシルテストに失敗したときにステンシルバッファへ行う動作です。既定のKeepはバッファを変更しません。 | `_OutlineStencilFail` |
| **深度失敗時の動作** | ステンシルには通過したが深度テストに失敗したときの動作です。既定のKeepはバッファを変更しません。 | `_OutlineStencilZFail` |
| **カラーマスク** | アウトラインパスが書き込むカラーチャンネルです。15がRGBA全体で、0だとアウトラインは画面にまったく書き込まれません。 | `_OutlineColorMask` |
| **Hull アウトラインに適用** | ペイントした圧力をHullアウトラインの太さに反映します。圧力ソースがConstantの場合、オンにしても変化しません。 | `_OutlineHullPressureApply` |

## 内側2Dエッジ

画面深度を使って表示面の内側に描く2Dエッジを設定します。

| 項目 | 説明 | シェーダープロパティ |
|---|---|---|
| **Inner 2D Edgeを使用** | 画面深度の差から表面内側の境界線を描きます。追加ジオメトリが不要でハルが破綻するメッシュにも使えますが、カメラ深度テクスチャが必要で、サーフェスモードがTransparentでは動作しません。 | `_OutlineInnerEdgeEnabled` |
| **Inner Edge アウトラインに適用** | ペイントした圧力をInner 2D Edgeの太さにも反映します。このトグルと圧力ソースはClassic Hullグループ内にありますが、この値はHullをオフにしてもInner Edgeに作用し続けます。頂点カラーが黒のメッシュでオンだとInner Edgeが完全に消えます。 | `_OutlineInnerEdgePressureApply` |
| **深度バイアス** | この値より大きい深度差だけを境界と認めます。下げると緩やかな凹凸にも線が付いてノイズになり、上げると薄い部位の線が消えます。 | `_OutlineInnerEdgeBias` |
| **柔らかさ** | 内側エッジの空間グラデーション幅です。0は硬い線、1は線幅全体を境界から内側端まで連続的に0へぼかします。 | `_OutlineInnerEdgeSoftness` |
