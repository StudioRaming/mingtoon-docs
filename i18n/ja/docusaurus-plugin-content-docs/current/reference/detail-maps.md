# ディテールマップ

ベースの上に積むレイヤーと質感です。レイヤー系はレイヤー数から上げる必要があります。

このページは値を探すための表です。オンにする順序が必要な場合は [ディテールマップガイド](/guides/detail-maps) を見てください。

見出しと目次は、インスペクターのセクション名と表示順をそのまま踏襲しています。

マップとマスクのスロット内の項目は、すべてのスロットで共通です。
チャンネル・リマップ・フェザー・マスクUVは [テクスチャスロット共通UI](/guides/texture-modules) に一度だけ記載しています。

## 追加テクスチャ（最大10枚） {#추가-텍스처-최대-10장}

サーフェスレイヤーは最大10枚です。レイヤーを増やすと、下の項目が1枚ごとに同じ形で繰り返されます。

| インスペクターのラベル | 形式 | 範囲 | 既定値 | 役割 |
|---|---|---|---|---|
| **サーフェススタックを使用** | オン/オフ | - | オフ | 複数のテクスチャを順番に表面色へ合成します |
| **サーフェススタックレイヤー数** | 整数 | 0 ~ 10 | 0 | 数を超えたスロットは評価されず、増やすほどテクスチャ・マスク・合成の負荷が累積します |
| **合成モード** | 選択 | Normal / Multiply / Add / Screen / Color / Overlay | Multiply | このスタックレイヤーを下の結果とどう混ぜるかです |
| **不透明度** | 実数 | 0 ~ 1 | 1 | このレイヤーの適用量です |

| インスペクターのラベル | 形式 | 範囲 | 既定値 | 役割 |
|---|---|---|---|---|
| **ノーマルレイヤーを使用** | オン/オフ | - | オフ | 積層ノーマルマップを照明・リムなどで使います |
| **ノーマルレイヤー数** | 整数 | 0 ~ 5 | 0 | この数のスロットだけを評価し、数を超えたスロットはサンプリングしません |

| **回転ランダム** | 実数 | 0 ~ 1 | 1 | 粒子ごとに形をどれだけ違う角度に向けるかを決めます |
| **スケール** | 実数 | 1 ~ 512 | 379 | 粒子セルの細かさを決めます |
| **粒子サイズ** | 実数 | 0 ~ 1 | 0.39 | 粒子が画面で占める大きさで、高いと大きく、低いと小さな点になります |
| **サイズランダム化** | 実数 | 0 ~ 1 | 1 | 粒子サイズをランダム化し、0は均一、1は自然ですが不規則になります |
| **粒子コントラスト** | 実数 | 0.25 ~ 128 | 50 | 粒子内のコントラストで、高いほど鮮明ですが段差やちらつきが増えることがあります |
| **ポストコントラスト** | 実数 | 0.1 ~ 8 | 1 | 粒子パターン後の全体コントラストで、1が中立、高いほど暗い点が消えやすくなります |
| **感度** | 実数 | 0.01 ~ 64 | 0.25 | 視点変化への感度で、高いほどカメラ移動で輝きが大きく変わります |
| **速度** | 実数 | 0 ~ 4 | 0.3 | 視点依存のきらめきを動かします |
| **視線パララックス** | 実数 | 0 ~ 1 | 0.52 | 視点移動で粒子が滑る量で、高いほど奥行きが出ますがちらつくことがあります |
| **ノーマル影響度** | 実数 | 0 ~ 1 | 1 | メッシュと積層ノーマルの向きをきらめきに使い、ノーマルレイヤーがオフならメッシュノーマルに戻ります |
| **光源角度の影響** | 実数 | 0 ~ 1 | 1 | 粒子と光源方向の角度がきらめきに与える影響です |
| **光源方向の影響** | 実数 | 0 ~ 1 | 1 | きらめきが光源方向に従う強さで、低いと視点反応が中心になります |
| **カラーランダム化** | 実数 | 0 ~ 1 | 1 | 粒子ごとの色をランダム化し、0は単色、1は多彩ですが複雑になります |
| **影内の表示量** | 実数 | 0 ~ 1 | 0.54 | 影の中できらめきをどれだけ残すかで、0は隠し、1は影を無視します |
| **ベースカラー影響** | 実数 | 0 ~ 1 | 0 | 0はグリッター色をそのまま使い、1はベースマップ色を掛けます |
| **シーンライトの影響** | 実数 | 0 ~ 1 | 0.5 | シーン照明の明るさできらめきが暗くなる度合いです |
