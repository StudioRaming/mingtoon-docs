# ディテールマップ

ベースの上に積むレイヤーと質感です。レイヤー系はレイヤー数から上げる必要があります。

このページは値を探すための表です。オンにする順序が必要な場合は [ディテールマップガイド](/guides/detail-maps) を見てください。

見出しと目次は、インスペクターのセクション名と表示順をそのまま踏襲しています。

マップとマスクのスロット内の項目は、すべてのスロットで共通です。
チャンネル・リマップ・フェザー・マスクUVは [テクスチャスロット共通UI](/guides/texture-modules) に一度だけ記載しています。

## 追加テクスチャ（最大10枚） {#추가-텍스처-최대-10장}

サーフェスレイヤーは最大10枚です。レイヤーを増やすと、下の項目が1枚ごとに同じ形で繰り返されます。

| インスペクターのラベル | 形式 | 範囲 | 既定値 | 役割 |
|---|---|---|---|---|
| **サーフェススタックを使用** | オン/オフ | - | オフ | 既定値はオフです |
| **サーフェススタックレイヤー数** | 整数 | 0 ~ 10 | 0 | 範囲は0-10、既定値は0です |
| **合成モード** | 選択 | Normal / Multiply / Add / Screen / Color / Overlay | Multiply | このスタックレイヤーを下の結果とどう混ぜるかです |
| **不透明度** | 実数 | 0 ~ 1 | 1 | このレイヤーの適用量です |
