# ディテールマップ

ベースの上に重ねるレイヤーと質感です。レイヤー系はすべて同じ罠を共有します — レイヤー数より後ろのスロットは計算自体をスキップします。

:::note
このページの項目名と説明は、MingToonインスペクターが実際に表示する文言をソースからそのまま取得しています。
:::

## テクスチャレイヤー

追加のサーフェステクスチャレイヤーを合成します。

| 項目 | 説明 | シェーダープロパティ |
|---|---|---|
| **サーフェススタックを使用** | 既定値はオフです。複数のテクスチャを順番に表面色へ合成します。アクティブなレイヤーごとにテクスチャ・マスク・合成の負荷が増えます。 | `_MingStackEnabled` |
| **サーフェススタックレイヤー数** | 範囲は0-10、既定値は0です。数を超えたスロットは評価されず、増やすほどテクスチャ・マスク・合成の負荷が累積します。 | `_MingStackLayerCount` |
| **合成モード** | このスタックレイヤーを下の結果とどう混ぜるかです。Normalは完全に覆い、Multiplyは下の陰影を残して色だけ乗せます。 | `_MingStackBlendMode` |
| **不透明度** | このレイヤーの適用量です。0ではレイヤーの計算を飛ばすためテクスチャを入れても見えず、レイヤー数より後ろのスロットも計算されません。 | `_MingStackOpacity` |

## ノーマルレイヤー

複数のノーマルマップと合成強度を設定します。

| 項目 | 説明 | シェーダープロパティ |
|---|---|---|
| **ノーマルレイヤーを使用** | 既定値はオフです。積層ノーマルマップを照明・リムなどで使います。アクティブなレイヤーごとにテクスチャ取得と合成の負荷が増え、レイヤー数が0なら結果はありません。 | `_MingNormalEnabled` |
| **ノーマルレイヤー数** | 範囲は0-5、既定値は0です。この数のスロットだけを評価し、数を超えたスロットはサンプリングしません。レイヤーごとにテクスチャ・マスク・合成の負荷が増えます。 | `_MingNormalLayerCount` |
| **ノーマルマップ** | このレイヤーのノーマルマップです。レイヤー数より後ろのスロットは計算されないため、マップを入れても反映されない場合はまずレイヤー数を確認してください。 | `_MingNormalMap` |
| **ノーマル強度** | このレイヤーが最終ノーマルに混ざる強さです。0ではテクスチャを入れても影響しません。 | `_MingNormalStrength` |

## MatCapレイヤー

MatCapテクスチャ、合成方式、投影を設定します。

| 項目 | 説明 | シェーダープロパティ |
|---|---|---|
| **MatCapレイヤーを使用** | 既定値はオフです。視線基準のMatCapレイヤーを表面へ合成します。アクティブなレイヤーごとにテクスチャ取得と合成の負荷が生じ、レイヤー数が0なら変化しません。 | `_MingMatcapEnabled` |
| **MatCapレイヤー数** | 範囲は0-5、既定値は0です。数を超えたスロットは評価されず、アクティブなレイヤーごとにマップ・マスク・合成の負荷が増えます。 | `_MingMatcapLayerCount` |
| **金属領域のみMatCap** | 既定値はオフです。PBRのメタリック値が高い領域だけに全MatCapレイヤーを制限します。PBRや金属マスクがオフだと判定基準がなく効果は弱くなります。 | `_MingMatcapMetallicOnly` |
| **MatCap反射の脱彩度** | 範囲は0-1、既定値は0.25です。MatCapの色を灰色へ寄せてベース色を保ち、1では色相をほぼすべて除きます。 | `_MingMatcapDesaturation` |
| **MatCapマップ** | 球体に描かれた照明・質感の画像です。視線基準で投影されるため、カメラが回るとハイライトも一緒に動きます。 | `_MingMatcapMap` |
| **合成モード** | MatCapを表面色とどう混ぜるかを決めます。AddとScreenは明るい光沢に、Multiplyは暗い質感表現に向きます。 | `_MingMatcapBlendMode` |
| **コントラスト** | MatCap画像のコントラストです。1が元の状態で、上げるとハイライトと暗部が分離してセル感が強まります。 | `_MingMatcapContrast` |
| **強度** | このレイヤーの適用量です。0ではレイヤーの計算を飛ばすため、マップや合成モードを変えても変化しません。レイヤー数より後ろのスロットも計算されません。 | `_MingMatcapStrength` |
| **MatCap / メッシュUV投影** | 0では視線基準のMatCap投影、1ではメッシュUVに固定されます。1にするとカメラを回しても模様が表面に貼り付いたままになり、タトゥーやペイント表現に向きます。 | `_MingMatcapProjectionBlend` |

## PBRサーフェス

メタリック、スムースネス、スペキュラー、環境反射を設定します。

| 項目 | 説明 | シェーダープロパティ |
|---|---|---|
| **PBRサーフェスを使用** | 既定値はオフです。メタリック・スムースネス・反射を使う経路を有効にします。トゥーン照明の結果が変わり、ノーマルや環境反射の負荷が増えることがあります。 | `_MingPbrEnabled` |
| **ワークフロー** | Metallicはメタリック値から反射色を作り、Specularはスペキュラーカラーを直接指定します。Specularを選ぶとメタリックのスライダーは結果に反映されません。 | `_WorkflowMode` |
| **パックマスクを使用** | メタリック・オクルージョン・スムースネスを1枚のテクスチャからチャンネル別に読み取ります。オフの間は下のチャンネル・反転設定は無視され、メタリックとスムースネスのスライダー値だけが使われます。 | `_MingPbrMaskMapEnabled` |
| **PBRパックマスク** | 既定の配置はR=メタリック、G=オクルージョン、A=スムースネスです。テクスチャの配置が異なる場合は下のチャンネル設定で合わせられます。 | `_MaskMap` |
| **メタリック** | 0が非金属、1が金属です。パックマスク使用時はマスク値と乗算されるため、マスクが黒い箇所は金属になりません。 | `_Metallic` |
| **スムースネス** | 高いほど反射が小さく鮮明になります。トゥーン表現では0.3〜0.6が無難で、1に近いとハイライトが点のように小さくなります。 | `_Smoothness` |
| **スペキュラー強度** | 範囲は0-2、既定値は1です。スペキュラー反射の強さで、0にすると直接ハイライトと環境反射の両方が消えるためスムースネスや反射強度を上げても変化しません。 | `_MingPbrSpecularStrength` |
| **メタリックチャンネル** | パックマスクのどのチャンネルからメタリックを読むかです。パックマスクがオフの間は無視されます。 | `_MingPbrMetallicChannel` |
| **メタリックを反転** | 読み取ったメタリック値を反転します。非金属を白で描いたマスクをそのまま使うときに有効にします。 | `_MingPbrMetallicInvert` |
| **PBRオクルージョンチャンネル** | パックマスクのどのチャンネルから反射オクルージョンを読むかです。反射オクルージョンが0の場合、この設定は結果にまったく反映されません。 | `_MingPbrOcclusionChannel` |
| **PBRオクルージョンを反転** | 読み取った反射オクルージョン値を反転します。反射オクルージョンが0の場合は無視されます。 | `_MingPbrOcclusionInvert` |
| **反射オクルージョン** | 範囲は0-1、既定値は0です。パックマスクのオクルージョンチャンネルで環境反射を抑える量で、0ではチャンネル・反転設定があっても結果に現れません。 | `_MingPbrOcclusionStrength` |
| **スムースネスチャンネル** | パックマスクのどのチャンネルからスムースネスを読むかです。パックマスクがオフの間は無視されます。 | `_MingPbrSmoothnessChannel` |
| **ラフネスとして使用（反転）** | スムースネスではなくラフネスのマップを入れた場合にオンにします。チャンネル値を1から引いて使用します。 | `_MingPbrSmoothnessInvert` |
| **スペキュラーカラーマップ（RGB）を使用** | 反射色をテクスチャで指定します。オフの間はスペキュラーカラーマップと反転設定が無視されます。ワークフローがMetallicの場合、反射色はメタリックから作られるため効果は限定的です。 | `_MingPbrSpecularMapEnabled` |
| **スペキュラーカラーマップを反転** | スペキュラーカラーマップのRGBを反転します。スペキュラーカラーマップがオフの間は無視されます。 | `_MingPbrSpecularInvert` |
| **直接ハイライト強度** | 範囲は0-4、既定値は1です。光源から直接来るハイライトの強さで、0ではハイライト計算自体を飛ばすためスムースネスを上げても輝きは出ません。 | `_MingPbrDirectStrength` |
| **環境反射の強度** | 範囲は0-4、既定値は0です。リフレクションプローブやスカイボックスの映り込み量で、シーンにプローブがないと上げてもほとんど変化しません。 | `_MingPbrReflectionStrength` |
| **影の中での表示量** | 範囲は0-1、既定値は0です。影の中でPBRハイライトをどれだけ残すかを決め、0では影の中で完全に消え、1では影に関係なくそのまま見えます。 | `_MingPbrShadowVisibility` |
| **ノーマルマップ影響** | 範囲は0-1、既定値は1です。0ではメッシュノーマルのみ、1では積み重ねたノーマルマップをそのまま反映します。ノーマルマップがない場合は値によらず結果は同じです。 | `_MingPbrNormalInfluence` |
| **ハイライトのトゥーン化** | 範囲は0-1、既定値は0です。GGXハイライトの減衰をトゥーン化する量で、0は物理ローブのまま、高いと縁が生じしきい値も働きます。 | `_MingPbrDirectToonAmount` |
| **ハイライトのトゥーン境界** | 範囲は0-1、既定値は0.5です。ローブをハイライト形状へ切る位置で、低いと広く高いと狭くなり、トゥーン化が0なら無視されます。 | `_MingPbrDirectToonThreshold` |
| **環境反射のぼかし補正** | 範囲は-1-1、既定値は0です。物理的なスムースネスより環境反射をぼかし、または鮮明にします。負は鮮明化で瞳や濡れた面に向きます。 | `_MingPbrReflectionSmoothnessBias` |
| **環境反射の脱彩度** | 範囲は0-1、既定値は0です。環境反射の色をどれだけ灰色に寄せるかで、1では輝度だけを残し素材本来の色を保ちやすくなります。 | `_MingPbrReflectionDesaturation` |
| **環境反射ティント** | HDR環境反射の色補正で、既定値は(1, 1, 1)です。脱彩度と併用され、高いと反射だけが白飛びすることがあります。 | `_MingPbrReflectionTint` |
| **PBRフレネル指数** | 範囲は1-8、既定値は5です。斜め角度で反射が明るくなる減衰で、低いと内側へ広がり高いとシルエット際に集まります。 | `_MingPbrFresnelPower` |

## 領域マスク

1つのマテリアル内で領域ごとにハイライトと表面反応を分けます。

| 項目 | 説明 | シェーダープロパティ |
|---|---|---|
| **領域マスクを使用** | 既定値はオフです。1枚のRGBAテクスチャを4つのregionマスクに分けて材質値を補正します。マスク取得と計算が増え、UVが合わないと境界がずれます。 | `_MingRegionMaskEnabled` |
| **領域メタリック補正** | 範囲は-1-1、既定値は0です。R/G/B/A各領域のメタリック加算値で、素材値に足されるため大きな正値は急に金属へ寄せます。 | `_MingRegionMetallic` |
| **領域環境反射補正** | 範囲は-4-4、既定値は0です。領域ごとの環境反射加算値で、肌や布は負、硬い面は正が使いやすいです。 | `_MingRegionReflection` |
| **領域トゥーンスペキュラー強度補正** | 範囲は-8-8、既定値は0です。領域ごとのトゥーンスペキュラー強度加算値で、大きいとハイライトが白飛びすることがあります。 | `_MingRegionSpecularStrength` |
| **領域トゥーンスペキュラーのスムースネス補正** | 範囲は-1-1、既定値は0です。領域ごとのトゥーンスペキュラーのスムースネス加算値で、正は鋭く負は広がります。 | `_MingRegionSpecularSmoothness` |

## エミッション

自己発光の色、テクスチャ、強度を設定します。

| 項目 | 説明 | シェーダープロパティ |
|---|---|---|
| **エミッションを使用** | 既定値はオフです。マップとHDR色で照明後に自己発光を加えます。ブルームや白飛びが起こることがあり、オフではマップと強度を無視します。 | `_EmissionEnabled` |
| **エミッション強度** | 発光の明るさの倍率です。シーンにブルームのポストプロセスがないと、上げても滲まず白飛びするだけです。 | `_EmissionIntensity` |
| **エミッションマップ** | 自己発光する領域を指定するテクスチャです。エミッション色と乗算されるため、色が黒だとテクスチャがあっても光りません。 | `_EmissionMap` |
| **エミッション色** | 発光色です。HDRのため1を超える値でブルームを誘発でき、黒にするとエミッションを切ったのと同じになります。 | `_MingEmissionTint` |
| **影内のエミッション表示** | 範囲 0-1、既定値1。0は影の可視量に従って発光を隠し、1は影の可視量を無視して発光を完全に維持します。 | `_EmissionShadowVisibility` |

## オクルージョン

間接光オクルージョンと強度を設定します。

| 項目 | 説明 | シェーダープロパティ |
|---|---|---|
| **オクルージョンを使用** | 既定値はオフです。オクルージョンマップで間接光が遮られた部分を暗くします。直接光や影の代わりにはならず、オフではマップと強度の計算を省略します。 | `_OcclusionEnabled` |

## グリッター

ボロノイ粒子の距離安定化、視線感度、光源角度、サイズ・カラーのランダム化を設定します。

| 項目 | 説明 | シェーダープロパティ |
|---|---|---|
| **グリッターを使用** | 既定値はオフです。ボロノイ粒子のきらめきを加えます。オンではピクセルごとに手続きパターンとライト反応を計算するため負荷を確認してください。 | `_MingGlitterEnabled` |
| **グリッター色** | HDRきらめきの色で、既定値は(1, 1, 1)です。最終色は強度とベース色影響にも左右されます。 | `_MingGlitterColor` |
| **グリッター強度** | 範囲は0-8、既定値は8です。明るさ倍率で、0ではパターンを計算しても見えません。 | `_MingGlitterStrength` |
| **グリッターマスクを使用** | 既定値はオフです。グリッターを別マスクの領域に制限します。オフではマスクのテクスチャ・チャンネル・反転を無視して取得を省きます。 | `_MingGlitterMaskEnabled` |
| **色も一緒に使用** | 既定値はオフです。オンにすると同じマスクテクスチャをRGBA全体として読み、アルファが領域、RGBが粒子の色になります。テクスチャの取得回数は増えません。オンの間、チャンネル選択はアルファに固定されます。 | `_MingGlitterMaskUseColor` |
| **形マップを使用** | 既定値はオフです。オンにすると粒子ひとつひとつの形をテクスチャに置き換えます(星、ハートなど)。オフでは従来の丸い粒子で、形マップは読みません。 | `_MingGlitterShapeEnabled` |
| **形マップ** | 粒子ひとつの形です。正方形の領域は粒子の内側に収まるように配置されるため、端まで詰めず余白を残して描いてください。背景は黒(またはアルファ0)にします。 | `_MingGlitterMap` |
| **形チャンネル** | 既定値はAです。形マップのどのチャンネルからシルエットを読むかを選びます。アルファ付きPNGならA、白黒画像ならRかLumaを使います。 | `_MingGlitterShapeChannel` |
| **回転ランダム** | 範囲は0-1、既定値は1です。粒子ごとに形をどれだけ違う角度に向けるかを決めます。0ではすべての粒子が同じ方向を向き、押し型のような模様に見えます。1では一回転の中で均等に散ります。ハートのように向きのある形をまっすぐ立てたいときだけ下げてください。 | `_MingGlitterShapeRotation` |
| **グリッター密度** | 範囲は1-512、既定値は379です。粒子セルの細かさを決めます。高いほど細かなきらめきになりますがちらつき・エイリアスと計算量が増えることがあります。 | `_MingGlitterDensity` |
| **グリッター粒子サイズ** | 範囲は0-1、既定値は0.39です。粒子が画面で占める大きさで、高いと大きく、低いと小さな点になります。 | `_MingGlitterSize` |
| **グリッターサイズのランダム化** | 範囲は0-1、既定値は1です。粒子サイズをランダム化し、0は均一、1は自然ですが不規則になります。 | `_MingGlitterScaleRandomize` |
| **グリッター粒子コントラスト** | 範囲は0.25-128、既定値は50です。粒子内のコントラストで、高いほど鮮明ですが段差やちらつきが増えることがあります。 | `_MingGlitterContrast` |
| **グリッター後コントラスト** | 範囲は0.1-8、既定値は1です。粒子パターン後の全体コントラストで、1が中立、高いほど暗い点が消えやすくなります。 | `_MingGlitterPostContrast` |
| **グリッター視点感度** | 範囲は0.01-64、既定値は0.25です。視点変化への感度で、高いほどカメラ移動で輝きが大きく変わります。 | `_MingGlitterSensitivity` |
| **グリッター速度** | 範囲は0-4、既定値は0.3です。視点依存のきらめきを動かします。0では固定され、高いほど変化が速くちらつきが目立つことがあります。 | `_MingGlitterSpeed` |
| **グリッター視差** | 範囲は0-1、既定値は0.52です。視点移動で粒子が滑る量で、高いほど奥行きが出ますがちらつくことがあります。 | `_MingGlitterViewParallax` |
| **グリッターのノーマル影響** | 範囲は0-1、既定値は1です。メッシュと積層ノーマルの向きをきらめきに使い、ノーマルレイヤーがオフならメッシュノーマルに戻ります。 | `_MingGlitterNormalInfluence` |
| **グリッターの光源角度** | 範囲は0-1、既定値は1です。粒子と光源方向の角度がきらめきに与える影響です。 | `_MingGlitterLightAngle` |
| **グリッターの光源方向** | 範囲は0-1、既定値は1です。きらめきが光源方向に従う強さで、低いと視点反応が中心になります。 | `_MingGlitterLightDirection` |
| **グリッター色のランダム化** | 範囲は0-1、既定値は1です。粒子ごとの色をランダム化し、0は単色、1は多彩ですが複雑になります。 | `_MingGlitterColorRandomize` |
| **グリッターの影での可視性** | 範囲は0-1、既定値は0.54です。影の中できらめきをどれだけ残すかで、0は隠し、1は影を無視します。 | `_MingGlitterShadowVisibility` |
| **グリッターのベース色影響** | 範囲は0-1、既定値は0です。0はグリッター色をそのまま使い、1はベースマップ色を掛けます。 | `_MingGlitterBaseColorInfluence` |
