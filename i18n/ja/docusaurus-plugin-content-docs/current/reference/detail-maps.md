# ディテールマップ

ベースの上に重ねるレイヤーと質感です。レイヤー系はすべて同じ罠を共有します — レイヤー数より後ろのスロットは計算自体をスキップします。

:::note
このページの項目名と説明は、MingToonインスペクターが実際に表示する文言をソースからそのまま取得しています。
:::

## テクスチャレイヤー

追加のサーフェステクスチャレイヤーを合成します。

| 項目 | 説明 | シェーダープロパティ |
|---|---|---|
| **合成モード** | このスタックレイヤーを下の結果とどう混ぜるかです。Normalは完全に覆い、Multiplyは下の陰影を残して色だけ乗せます。 | `_MingStackBlendMode` |
| **不透明度** | このレイヤーの適用量です。0ではレイヤーの計算を飛ばすためテクスチャを入れても見えず、レイヤー数より後ろのスロットも計算されません。 | `_MingStackOpacity` |

## ノーマルレイヤー

複数のノーマルマップと合成強度を設定します。

| 項目 | 説明 | シェーダープロパティ |
|---|---|---|
| **ノーマルマップ** | このレイヤーのノーマルマップです。レイヤー数より後ろのスロットは計算されないため、マップを入れても反映されない場合はまずレイヤー数を確認してください。 | `_MingNormalMap` |
| **ノーマル強度** | このレイヤーが最終ノーマルに混ざる強さです。0ではテクスチャを入れても影響しません。 | `_MingNormalStrength` |

## MatCapレイヤー

MatCapテクスチャ、合成方式、投影を設定します。

| 項目 | 説明 | シェーダープロパティ |
|---|---|---|
| **MatCapマップ** | 球体に描かれた照明・質感の画像です。視線基準で投影されるため、カメラが回るとハイライトも一緒に動きます。 | `_MingMatcapMap` |
| **合成モード** | MatCapを表面色とどう混ぜるかを決めます。AddとScreenは明るい光沢に、Multiplyは暗い質感表現に向きます。 | `_MingMatcapBlendMode` |
| **コントラスト** | MatCap画像のコントラストです。1が元の状態で、上げるとハイライトと暗部が分離してセル感が強まります。 | `_MingMatcapContrast` |
| **強度** | このレイヤーの適用量です。0ではレイヤーの計算を飛ばすため、マップや合成モードを変えても変化しません。レイヤー数より後ろのスロットも計算されません。 | `_MingMatcapStrength` |
| **MatCap / メッシュUV投影** | 0では視線基準のMatCap投影、1ではメッシュUVに固定されます。1にするとカメラを回しても模様が表面に貼り付いたままになり、タトゥーやペイント表現に向きます。 | `_MingMatcapProjectionBlend` |

## PBRサーフェス

メタリック、スムースネス、スペキュラー、環境反射を設定します。

| 項目 | 説明 | シェーダープロパティ |
|---|---|---|
| **ワークフロー** | Metallicはメタリック値から反射色を作り、Specularはスペキュラーカラーを直接指定します。Specularを選ぶとメタリックのスライダーは結果に反映されません。 | `_WorkflowMode` |
| **パックマスクを使用** | メタリック・オクルージョン・スムースネスを1枚のテクスチャからチャンネル別に読み取ります。オフの間は下のチャンネル・反転設定は無視され、メタリックとスムースネスのスライダー値だけが使われます。 | `_MingPbrMaskMapEnabled` |
| **PBRパックマスク** | 既定の配置はR=メタリック、G=オクルージョン、A=スムースネスです。テクスチャの配置が異なる場合は下のチャンネル設定で合わせられます。 | `_MaskMap` |
| **メタリック** | 0が非金属、1が金属です。パックマスク使用時はマスク値と乗算されるため、マスクが黒い箇所は金属になりません。 | `_Metallic` |
| **スムースネス** | 高いほど反射が小さく鮮明になります。トゥーン表現では0.3〜0.6が無難で、1に近いとハイライトが点のように小さくなります。 | `_Smoothness` |
| **スペキュラー強度** | スペキュラー反射の強さです。0にすると直接ハイライトと環境反射の両方が消えるため、スムースネスや反射強度を上げても変化しません。 | `_MingPbrSpecularStrength` |
| **メタリックチャンネル** | パックマスクのどのチャンネルからメタリックを読むかです。パックマスクがオフの間は無視されます。 | `_MingPbrMetallicChannel` |
| **メタリックを反転** | 読み取ったメタリック値を反転します。非金属を白で描いたマスクをそのまま使うときに有効にします。 | `_MingPbrMetallicInvert` |
| **PBRオクルージョンチャンネル** | パックマスクのどのチャンネルから反射オクルージョンを読むかです。反射オクルージョンが0の場合、この設定は結果にまったく反映されません。 | `_MingPbrOcclusionChannel` |
| **PBRオクルージョンを反転** | 読み取った反射オクルージョン値を反転します。反射オクルージョンが0の場合は無視されます。 | `_MingPbrOcclusionInvert` |
| **反射オクルージョン** | パックマスクのオクルージョンチャンネルで環境反射を抑える量です。0ではチャンネル・反転設定があっても結果に現れません。 | `_MingPbrOcclusionStrength` |
| **スムースネスチャンネル** | パックマスクのどのチャンネルからスムースネスを読むかです。パックマスクがオフの間は無視されます。 | `_MingPbrSmoothnessChannel` |
| **ラフネスとして使用（反転）** | スムースネスではなくラフネスのマップを入れた場合にオンにします。チャンネル値を1から引いて使用します。 | `_MingPbrSmoothnessInvert` |
| **スペキュラーカラーマップ（RGB）を使用** | 反射色をテクスチャで指定します。オフの間はスペキュラーカラーマップと反転設定が無視されます。ワークフローがMetallicの場合、反射色はメタリックから作られるため効果は限定的です。 | `_MingPbrSpecularMapEnabled` |
| **スペキュラーカラーマップを反転** | スペキュラーカラーマップのRGBを反転します。スペキュラーカラーマップがオフの間は無視されます。 | `_MingPbrSpecularInvert` |
| **直接ハイライト強度** | 光源から直接来るハイライトの強さです。0ではハイライト計算自体を飛ばすため、スムースネスを上げても輝きは出ません。 | `_MingPbrDirectStrength` |
| **環境反射の強度** | リフレクションプローブやスカイボックスの映り込み量です。シーンにプローブがないと上げてもほとんど変化しません。 | `_MingPbrReflectionStrength` |
| **影の中での表示量** | 影の中でPBRハイライトをどれだけ残すかを決めます。0では影の中で完全に消え、1では影に関係なくそのまま見えます。 | `_MingPbrShadowVisibility` |
| **ノーマルマップ影響** | 0ではメッシュノーマルのみ、1では積み重ねたノーマルマップをそのまま反映します。ノーマルマップがない場合は値によらず結果は同じです。 | `_MingPbrNormalInfluence` |

## エミッション

自己発光の色、テクスチャ、強度を設定します。

| 項目 | 説明 | シェーダープロパティ |
|---|---|---|
| **エミッション強度** | 発光の明るさの倍率です。シーンにブルームのポストプロセスがないと、上げても滲まず白飛びするだけです。 | `_EmissionIntensity` |
| **エミッションマップ** | 自己発光する領域を指定するテクスチャです。エミッション色と乗算されるため、色が黒だとテクスチャがあっても光りません。 | `_EmissionMap` |
| **エミッション色** | 発光色です。HDRのため1を超える値でブルームを誘発でき、黒にするとエミッションを切ったのと同じになります。 | `_MingEmissionTint` |
