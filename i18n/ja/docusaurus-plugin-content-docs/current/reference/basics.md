# 基本設定

ベースカラー、サーフェスモード、よく使うマップ。マテリアルを作って最初に触る項目です。

:::note
このページの項目名と説明は、MingToonインスペクターが実際に表示する文言をソースからそのまま取得しています。
:::

## 基本サーフェス

基本テクスチャ、色、UV変換を設定します。

| 項目 | 説明 | シェーダープロパティ |
|---|---|---|
| **ベースマップ** | キャラクターの基本カラーテクスチャです。アルファチャンネルはサーフェスモードがCutoutまたはTransparentのときだけ使われます。 | `_MainTex` |
| **ベースカラー** | ベースマップの上に重ねる色です。合成方法はティント合成モード、強さはティント不透明度が決めるため、不透明度が0だと色を変えても何も起きません。 | `_Color` |
| **アルファカットオフ** | サーフェスモードがCutoutのときだけ機能します。アルファがこの値未満のピクセルを切り捨てます。髪やまつげは0.3〜0.6が無難で、0に近いと半透明の縁が汚く残ります。 | `_Cutoff` |
| **ティント合成モード** | ベースカラーをベースマップとどう混ぜるかを決めます。既定のMultiplyはマップの陰影を残して色だけ乗せ、Normalはマップを完全に置き換えて単色になります。 | `_ColorBlendMode` |
| **ティント不透明度** | ベースカラーの適用強度です。0ではベースカラーと合成モードの両方が無視されます。 | `_ColorBlendOpacity` |
| **マスクチャンネル** | 範囲マスクから読み取るチャンネルです。複数のマスクを1枚にパックしている場合はチャンネルを分けて使います。 | `_MingBaseAdjustMaskChannel` |
| **マスク反転** | 範囲マスクの白黒を反転し、色調補正が適用される部位を逆にします。 | `_MingBaseAdjustMaskInvert` |

## サーフェス描画

表面タイプ、カリング、アルファ処理を設定します。

| 項目 | 説明 | シェーダープロパティ |
|---|---|---|
| **アルファマスクを使用** | ベースマップのアルファではなく別画像で透明度を指定します。オフの間は下のマスク画像・チャンネル・反転はすべて無視され、サーフェスモードがOpaqueだとオンにしても結果は見えません。 | `_AlphaMaskEnabled` |
| **マスク画像** | 透明度として使うグレースケール画像です。アルファマスクがオフの間は反映されません。 | `_AlphaMask` |
| **マスクチャンネル** | マスク画像から読み取るチャンネルです。複数のマスクを1枚にパックした場合はR/G/B/Aを選び、LumaはRGBの明るさを使います。 | `_AlphaMaskChannel` |
| **マスク反転** | マスクの白黒を反転します。消したい部分が白で描かれているマスクをそのまま使うときに有効にします。 | `_AlphaMaskInvert` |
| **ソフトカットアウト** | カットアウトのギザギザした輪郭を画面のアンチエイリアスでなめらかにします。ヘアカードやレースなど切り抜きの多いメッシュほど差が出ます。サーフェスモードがCutoutのときだけ使え、他のモードに変えると自動的にオフになります。 | `_MingAlphaToCoverage` |
| **輪郭のシャープさ** | なめらかにする幅です。1が画面1ピクセル分で、上げると幅が狭まりくっきりし、下げると広がってぼやけます。毛先がぼやけすぎるときは上げてください。 | `_MingAlphaToCoverageSharpness` |
| **カラーマスク** | アウトラインパスが書き込むカラーチャンネルです。15がRGBA全体で、0だとアウトラインは画面にまったく書き込まれません。 | `_OutlineColorMask` |

## アルファフェード

| 項目 | 説明 | シェーダープロパティ |
|---|---|---|
| **距離フェードを使用** | カメラからの距離に応じて表面を消していきます。一人称で自分の頭やアクセサリーが視界を塞がないようにしたり、遠ざかるほど消したい場合に使います。オンにした直後は既定の範囲が何も隠さないので、下の距離を指定してください。サーフェスモードがOpaqueだと結果は見えません。 | `_MingAlphaDistanceFadeEnabled` |
| **角度フェードを使用** | 表面がカメラを向いている度合いに応じて透明度を変えます。輪郭だけを透けさせたり、逆に輪郭だけを残す表現に使います。ノーマルマップではなくメッシュ自体の向きを見るため、シルエットに沿います。サーフェスモードがOpaqueだと結果は見えません。 | `_MingAlphaFresnelEnabled` |
| **近距離・完全に消える距離** | カメラがこの距離より近いと完全に消えます。単位はメートルです。0なら近距離フェードは使いません。 | `_MingAlphaFadeNearStart` |
| **近距離・完全に見える距離** | カメラがこの距離より遠ければ元どおり見えます。消える距離との間が徐々に薄くなる区間です。2つの値が同じだとその地点で切り替わります。 | `_MingAlphaFadeNearEnd` |
| **遠距離・薄れ始める距離** | カメラがこの距離より遠ざかると薄れ始めます。単位はメートルです。最大値なら遠距離フェードは使いません。 | `_MingAlphaFadeFarStart` |
| **遠距離・完全に消える距離** | カメラがこの距離より遠いと完全に消えます。開始距離と同じにするとその地点で切り替わります。 | `_MingAlphaFadeFarEnd` |
| **正面の不透明度** | カメラを正面から向いている面の不透明度です。1で元のまま、0で完全に透明になります。 | `_MingAlphaFresnelFacing` |
| **輪郭の不透明度** | シルエット部分の不透明度です。正面の値より低いと輪郭が透け、高いと輪郭だけが残ります。2つの値が方向を決めるため、モード選択はありません。 | `_MingAlphaFresnelEdge` |
| **輪郭の幅** | 正面から輪郭へ移り変わる速さです。上げると浅い角度にだけ輪郭の値が効いて帯が狭まり、下げると広がります。 | `_MingAlphaFresnelPower` |

## ステンシル設定

通常パスとノーマルアウトラインパスのステンシル状態を個別に設定します。

| 項目 | 説明 | シェーダープロパティ |
|---|---|---|
| **基準値** | 通常パスがステンシルバッファと比較・書き込みする基準値(0-255)です。前髪越しに眉を透かすようなステンシル連携を組むときだけ変更し、それ以外は0のままにしてください。 | `_StencilRef` |
| **読み取りマスク** | ステンシル比較時に参照するビットマスクです。複数の効果でステンシルビットを分け合うときだけ変更します。 | `_StencilReadMask` |
| **書き込みマスク** | ステンシルへ書き込むときのビットマスクです。複数の効果でステンシルビットを分け合うときだけ変更します。 | `_StencilWriteMask` |
| **比較** | ステンシルの比較関数です。Alwaysならステンシルテストなしで常に描画します。他のマテリアルが書いた値に反応させるときだけ変更してください。 | `_StencilComp` |
| **パス動作** | ステンシルと深度の両テストを通過したときにバッファへ行う動作です。他のマテリアルに目印を残すにはReplaceを使います。 | `_StencilPass` |
| **失敗動作** | ステンシルテストに失敗したときにバッファへ行う動作です。通常はKeepのままにします。 | `_StencilFail` |
| **Z失敗動作** | ステンシルは通過したが深度テストに失敗したときに行う動作です。通常はKeepのままにします。 | `_StencilZFail` |

## 共通マップ

よく使うノーマル、エミッション、オクルージョン、PBR、MatCapマップをすばやく設定します。

| 項目 | 説明 | シェーダープロパティ |
|---|---|---|
| **ノーマルマップ** | 表面の凹凸を擬似的に表現するノーマルマップです。ノーマルレイヤー01に相当し、ノーマルモジュールがオフの間は反映されません。 | `_BumpMap` |
| **ノーマル強度** | ノーマルマップの凹凸の強さです。0ではマップを入れても平坦に見え、1が元の強さ、それ以上は誇張されます。 | `_BumpScale` |
| **オクルージョンマップ** | 間接光が届きにくい部分を暗くするグレースケールマップです。直接光には影響しないため、正面から強い光が当たると効果が見えにくくなります。 | `_OcclusionMap` |
| **オクルージョン強度** | オクルージョンマップの適用量です。0ではマップを入れても変化しません。 | `_OcclusionStrength` |
