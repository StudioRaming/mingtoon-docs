# 基本設定

マテリアルを作ったとき、最初に触る項目です。ベースカラー、サーフェスモード、透明度、ステンシルを扱います。

このページは値を探すための表です。オンにする順序が必要な場合は [基本設定ガイド](/guides/basics) を見てください。

見出しと目次は、インスペクターのセクション名と表示順をそのまま踏襲しています。

マップとマスクのスロット内の項目は、すべてのスロットで共通です。
チャンネル・リマップ・フェザー・マスクUVは [テクスチャスロット共通UI](/guides/texture-modules) に一度だけ記載しています。

## 基本サーフェス {#기본-표면}

| インスペクターのラベル | 形式 | 範囲 | 既定値 | 役割 |
|---|---|---|---|---|
| **ベースマップ** | テクスチャ | - | なし | キャラクターの基本カラーテクスチャです |
| **ベースカラー** | 色 | - | 白 | ベースマップの上に重ねる色です |
| **ティント合成モード** | 選択 | Normal / Multiply / Add / Screen / Color / Overlay | Multiply | ベースカラーをベースマップとどう混ぜるかを決めます |
| **ベースマップ全体の不透明度** | 実数 | 0 ~ 1 | 1 | ベーステクスチャのアルファに最後に乗算する値です |
| **マスクを使用** | オン/オフ | - | オフ | ベース色調補正(HSVG)をマスクが白い部分にのみ適用し、黒い部分は元の色を保ちます |
| **基本色補正マスク** | テクスチャ | - | なし | - |
| **グラデーションLUTを使用** | オン/オフ | - | オフ | ベースマップの色をR・G・Bチャンネルごとのランプで再マッピングします |
| **グラデーションLUT** | テクスチャ | - | なし | 横方向のランプテクスチャです |
| **グラデーション強度** | 実数 | 0 ~ 1 | 0 | 元の色とランプ結果を混ぜる比率です |

| **背面ライティング法線を反転** | オン/オフ | - | オン | - |
| **ブレンド演算** | 選択 | Add / Subtract / ReverseSubtract / Min / Max | Add | - |

| **透明深度プリパス** | オン/オフ | - | オフ | - |
| **深度テスト** | 選択 | Disabled / Never / Less / Equal / LessEqual / Greater / NotEqual / GreaterEqual / Always | LessEqual | - |

## アルファとカットアウト {#알파와-컷아웃}

| インスペクターのラベル | 形式 | 範囲 | 既定値 | 役割 |
|---|---|---|---|---|
| **アルファとカットアウト効果を使用** | オン/オフ | - | オン | アルファマスク・カットオフ・ソフトカットアウト・距離・フレネル・方向アルファ変換をまとめて有効化／バイパスします |
| **カットアウトしきい値** | 実数 | 0 ~ 1 | 0 | カットアウトを使用すると、このしきい値未満のアルファを持つピクセルを切り抜きます |
| **ソフトカットアウト** | オン/オフ | - | オフ | カットアウトのギザギザした輪郭を画面のアンチエイリアスでなめらかにします |
| **輪郭のシャープさ** | 実数 | 0.25 ~ 4 | 1 | なめらかにする幅です |
| **アルファマスクを使用** | オン/オフ | - | オフ | 別画像とベースマップのアルファを選択した合成方法で組み合わせます |
| **マスク画像** | テクスチャ | - | なし | 透明度として使うグレースケール画像です |
| **アルファ合成モード** | 選択 | Multiply / Replace / Add / Subtract | Multiply | ベースアルファとマスクの合成方法です |
| **マスク値倍率** | 実数 | - | 1 | チャンネル・反転・リマップ・フェザー・グラデーション処理後のマスク値に乗算します |
| **マスク値オフセット** | 実数 | - | 0 | マスク値倍率の適用後に加算します |
| **カメラ深度カットオフ** | 実数 | 0 ~ 1 | 0.5 | 透明サーフェスがカメラ深度テクスチャに残すシルエットを切る基準です |
| **距離フェードを使用** | オン/オフ | - | オフ | カメラからの距離に応じて表面を消していきます |
| **近距離・完全に消える距離** | 実数 | 0 ~ 5 | 0 | カメラがこの距離より近いと完全に消えます |
| **近距離・完全に見える距離** | 実数 | 0 ~ 5 | 0 | カメラがこの距離より遠ければ元どおり見えます |
| **遠距離・薄れ始める距離** | 実数 | 0 ~ 200 | 200 | カメラがこの距離より遠ざかると薄れ始めます |
| **遠距離・完全に消える距離** | 実数 | 0 ~ 200 | 200 | カメラがこの距離より遠いと完全に消えます |
| **角度フェードを使用** | オン/オフ | - | オフ | 表面がカメラを向いている度合いに応じて透明度を変えます |
| **アルファフェード・正面の不透明度** | 実数 | 0 ~ 1 | 1 | カメラを正面から向いている面の不透明度です |
| **輪郭の不透明度** | 実数 | 0 ~ 1 | 0 | シルエット部分の不透明度です |
| **輪郭の幅** | 実数 | 0.1 ~ 10 | 3 | 正面から輪郭へ移り変わる速さです |
| **方向ビューアルファを使用** | オン/オフ | - | オフ | メッシュローカル軸またはFace Provider基準のカメラ方向で表面の不透明度を調整します |
| **視方向別の不透明度・正面の不透明度** | 実数 | 0 ~ 1 | 1 | 選択した基準の正面から見たときの不透明度です |
| **背面の不透明度** | 実数 | 0 ~ 1 | 1 | 選択した基準の背面から見たときの不透明度です |
| **左側の不透明度** | 実数 | 0 ~ 1 | 1 | 選択した基準の左側から見たときの不透明度です |
| **右側の不透明度** | 実数 | 0 ~ 1 | 1 | 選択した基準の右側から見たときの不透明度です |
| **上側の不透明度** | 実数 | 0 ~ 1 | 1 | 選択した基準の上方向から見たときの不透明度です |
| **下側の不透明度** | 実数 | 0 ~ 1 | 1 | 選択した基準の下方向から見たときの不透明度です |
| **方向遷移のソフトネス** | 実数 | 0 ~ 1 | 0.5 | 6方向の端点を混ぜる幅です |
| **方向基準** | 選択 | Object / Face Provider | Object | Objectはメッシュローカル軸を使います |
| **正面軸 (ローカル)** | 実数 | 4つの値 | 0, 0, 1, 0 | Object基準で正面として使うローカル軸です |
| **上軸 (ローカル)** | 実数 | 4つの値 | 0, 1, 0, 0 | Object基準で上方向として使うローカル軸です |
| **ビュー領域マスク強度** | 実数 | 0 ~ 1 | 0 | 4領域マスクが方向ビューアルファに効く強さです |
| **ビュー領域マスクの重み** | 実数 | 4つの値 | 1, 1, 1, 1 | 共用Region Maskの4チャンネルの重みです |
| **ビュー領域マスクを反転** | オン/オフ | - | オフ | 解決した領域結果を反転します |
| **領域マスクを使用** | オン/オフ | - | オフ | 1枚のRGBAテクスチャを4つのregionマスクに分けて材質値を補正します |
| **リージョンマスク (RGBA = 4領域)** | テクスチャ | - | なし | - |
| **スムースネス ±** | 実数 | 4つの値 | 0, 0, 0, 0 | この領域だけハイライトを締めたり緩めたりします |
| **メタリック ±** | 実数 | 4つの値 | 0, 0, 0, 0 | R/G/B/A各領域のメタリック加算値で、素材値に足されるため大きな正値は急に金属へ寄せます |
| **環境反射 ±** | 実数 | 4つの値 | 0, 0, 0, 0 | 肌や布からワールド反射を取り除く値です |
| **トゥーンスペキュラー強度 ±** | 実数 | 4つの値 | 0, 0, 0, 0 | 領域ごとのトゥーンスペキュラー強度加算値で、大きいとハイライトが白飛びすることがあります |
| **トゥーンスペキュラーのスムースネス ±** | 実数 | 4つの値 | 0, 0, 0, 0 | 領域ごとのトゥーンスペキュラーのスムースネス加算値で、正は鋭く負は広がります |

## ステンシル設定 {#스텐실-설정}

| インスペクターのラベル | 形式 | 範囲 | 既定値 | 役割 |
|---|---|---|---|---|
| **通常パス・参照値** | 整数 | 0 ~ 255 | 0 | 通常パスがステンシルバッファと比較・書き込みする基準値(0-255)です |
| **通常パス・読み取りマスク** | 整数 | 0 ~ 255 | 255 | ステンシル比較時に参照するビットマスクです |
| **通常パス・書き込みマスク** | 整数 | 0 ~ 255 | 255 | ステンシルへ書き込むときのビットマスクです |
| **通常パス・比較** | 選択 | Disabled / Never / Less / Equal / LessEqual / Greater / NotEqual / GreaterEqual / Always | Always | ステンシルの比較関数です |
| **通常パス・通過時** | 選択 | Keep / Zero / Replace / IncrementSaturate / DecrementSaturate / Invert / IncrementWrap / DecrementWrap | Keep | ステンシルと深度の両テストを通過したときにバッファへ行う動作です |
| **通常パス・失敗時** | 選択 | Keep / Zero / Replace / IncrementSaturate / DecrementSaturate / Invert / IncrementWrap / DecrementWrap | Keep | ステンシルテストに失敗したときにバッファへ行う動作です |
| **通常パス・Z失敗時** | 選択 | Keep / Zero / Replace / IncrementSaturate / DecrementSaturate / Invert / IncrementWrap / DecrementWrap | Keep | ステンシルは通過したが深度テストに失敗したときに行う動作です |
| **ノーマルアウトラインパス・参照値** | 整数 | 0 ~ 255 | 0 | アウトラインパスが使うステンシル値です |
| **ノーマルアウトラインパス・読み取りマスク** | 整数 | 0 ~ 255 | 255 | ステンシルバッファを読むときに適用するビットマスクです |
| **ノーマルアウトラインパス・書き込みマスク** | 整数 | 0 ~ 255 | 255 | ステンシルバッファに書き込むときに適用するビットマスクです |
| **ノーマルアウトラインパス・比較** | 選択 | Disabled / Never / Less / Equal / LessEqual / Greater / NotEqual / GreaterEqual / Always | Always | ステンシル値をどう比較してピクセルを通すかを決めます |
| **ノーマルアウトラインパス・通過時** | 選択 | Keep / Zero / Replace / IncrementSaturate / DecrementSaturate / Invert / IncrementWrap / DecrementWrap | Keep | ステンシルと深度の両テストに通過したときにステンシルバッファへ行う動作です |
| **ノーマルアウトラインパス・失敗時** | 選択 | Keep / Zero / Replace / IncrementSaturate / DecrementSaturate / Invert / IncrementWrap / DecrementWrap | Keep | ステンシルテストに失敗したときにステンシルバッファへ行う動作です |
| **ノーマルアウトラインパス・Z失敗時** | 選択 | Keep / Zero / Replace / IncrementSaturate / DecrementSaturate / Invert / IncrementWrap / DecrementWrap | Keep | ステンシルには通過したが深度テストに失敗したときの動作です |
| **カラーマスク** | 整数 | 0 ~ 15 | 15 | アウトラインパスが書き込むカラーチャンネルです |
