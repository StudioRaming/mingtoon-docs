# リム

シルエットを立て、キャラクターを背景から切り離すグループです。重ねるとすぐ過剰になるので、ひとつずつ確認しながら上げてください。

:::note
このページの項目名と説明は、MingToonインスペクターが実際に表示する文言をソースからそのまま取得しています。
:::

## リムシェード

シルエット内側の陰影帯を設定します。

| 項目 | 説明 | シェーダープロパティ |
|---|---|---|
| **リムシェードを使用** | 既定値はオフです。シルエット内側の陰影帯を形状影マスクへ加えます。色を加える効果ではなく、オフでは評価を省略します。 | `_RimShadeEnabled` |
| **影への寄与強度** | 範囲は0-1、既定値は1です。シルエット内側の陰影帯の強さで、0ではリムシェードの計算自体を飛ばすため幅と柔らかさを変えても変化しません。 | `_RimShadeIntensity` |
| **幅** | 範囲は0-1、既定値は0.2です。0では領域なし、1では領域全体を使います。柔らかさを変えてもこの幅の外側へは広がりません。 | `_RimShadeWidth` |
| **柔らかさ** | 範囲は0-1、既定値は0.4です。0は硬い境界、1は選択した幅の内側の柔らかなグラデーションです。幅は変わりません。 | `_RimShadeSoftness` |
| **リムシェードのノーマル影響** | 範囲は0-1、既定値は1です。0はメッシュノーマル、1は積層ノーマルをリム影の形状に使います。ノーマルレイヤーがオフならメッシュノーマルに戻ります。 | `_RimShadeNormalInfluence` |

## リムライト

視線角度に反応するリムライトを設定します。

| 項目 | 説明 | シェーダープロパティ |
|---|---|---|
| **フレネルリムを使用** | 既定値はオンです。斜めに見えるシルエットの縁へリム光を合成します。オフでは値を保持しつつこのパスを省略します。 | `_FresnelRimEnabled` |
| **フレネルリム色** | HDRリム光の色で、既定値は(26.17, 26.17, 26.17)です。合成不透明度と掛け合わされ、ブルームがないと高い値で白飛びすることがあります。 | `_FresnelRimColor` |
| **フレネルリムの合成モード** | Normal・Multiply・Add・Hue・Screen・Color・Overlayからリムの合成方法を選びます。既定値はAdd(2)で明るさを加えるため、HDR色や不透明度が高いと白飛びやブルームが起こることがあります。 | `_FresnelRimBlendMode` |
| **ブレンド不透明度** | フレネルリムが結果に混ざる割合です。リムの色や強度はそのままに存在感だけを抑えるときに使ってください。0ではリムが完全にオフになります。 | `_FresnelRimBlendOpacity` |
| **色純度** | ベース色とFresnelリムティントを合成した後の彩度範囲0〜10、既定値1です。0は無彩色、1は合成色を維持し、1を超えると過彩度になります。 | `_FresnelRimColorPurity` |
| **強度** | 範囲は0-20、既定値は0.52です。フレネルリムの明るさ倍率で、0ではリムの色や幅を変えても画面に現れません。 | `_FresnelRimIntensity` |
| **幅** | 範囲は0-1、既定値は0です。0では領域なし、1ではフレネル領域全体を使います。柔らかさを変えてもこの幅の外側へは広がりません。 | `_FresnelRimWidth` |
| **柔らかさ** | 範囲は0-1、既定値は0.64です。0は硬い境界、1は選択した幅全体を使う柔らかなグラデーションです。幅は変わりません。 | `_FresnelRimSoftness` |
| **光源側の強調** | 0ではリム輝度を全周で均一にし、1では現在のメイン／Virtual Lightが当たる側だけを残します。反対側は完全に0まで下がるため、ライト回転がすぐ見えます。領域位置は下の視線基準で決まります。 | `_FresnelRimLightDirectionInfluence` |
| **視線基準** | リム領域を置く基準軸です。1はカメラのシルエットに沿う通常のフレネル、0は現在のメイン／Virtual Light軸に固定した帯です。 | `_FresnelRimViewStrength` |
| **フレネルリムの影内表示** | 範囲 0-1、既定値0。0は影でリムを隠し、1は影でも完全に表示します。 | `_FresnelRimShadowVisibility` |
| **ベースカラーの影響** | 0ではリム色をそのまま使い、1ではベースマップの色を掛けて素材ごとに異なるリム色になります。 | `_FresnelRimBaseColorInfluence` |
| **シーン照明の影響** | 0ではシーンの明るさに関係なく一定の強さで出て、1では照明が暗くなるほどリムも暗くなります。 | `_FresnelRimSceneLightInfluence` |
| **フレネルリム法線マップの影響** | 範囲 0-1、既定値1。0はメッシュ法線だけを使い、1は積層ノーマルマップを完全に使います。 | `_FresnelRimNormalInfluence` |
| **フレネルリム距離補正** | 範囲 0-1、既定値1。0は従来の生の幅を使い、1はカメラ距離が変わってもフレネルリム幅を安定させます。 | `_FresnelRimDistanceCompensation` |
| **フレネルリム投影補正** | 範囲 0-1、既定値1。0はFOVや正投影で生の幅が変わり、1はFOVや正投影でも幅を安定させます。 | `_FresnelRimProjectionCompensation` |

## バックライト

表面の背後にある主光源が作る独立した逆光帯を設定します。

| 項目 | 説明 | シェーダープロパティ |
|---|---|---|
| **バックライトを使用** | 既定値はオンです。メインライトが表面の後ろにあるとき逆光のアクセントを加えます。オフでは値を保持しつつ色への寄与とピクセル計算を省略します。 | `_BacklightEnabled` |
| **バックライト色** | HDR逆光の色で、既定値は(2, 2, 2)です。強度と掛け合わされ、ブルームがないと高い値で白飛びすることがあります。 | `_BacklightColor` |
| **バックライトの合成モード** | Normal・Multiply・Add・Hue・Screen・Color・Overlayからバックライトの合成方法を選びます。既定値のAddは従来の加算結果を維持します。 | `_BacklightBlendMode` |
| **ブレンド不透明度** | バックライトが最終色へ混ざる割合です。色と強度を変えずに存在感だけを抑え、0で完全に消えます。 | `_BacklightBlendOpacity` |
| **色純度** | ベース色とバックライトティントを合成した後の彩度範囲0〜10、既定値1です。0は無彩色、1は合成色を維持し、1を超えると過彩度になります。 | `_BacklightColorPurity` |
| **バックライト強度** | 範囲は0-10、既定値は0.29です。逆光の明るさ倍率で、0では色や境界を変えても見えません。 | `_BacklightStrength` |
| **幅** | 範囲は0-1、既定値は0.34です。0では領域なし、1では領域全体を使います。柔らかさを変えてもこの幅の外側へは広がりません。 | `_BacklightBorder` |
| **柔らかさ** | 範囲は0-1、既定値は0.5です。0は硬い境界、1は選択した幅の内側の柔らかなグラデーションです。幅は変わりません。 | `_BacklightSoftness` |
| **バックライト指向性** | 範囲は0-1、既定値は0.5です。ライト方向への追従度で、0は広く、1は背面条件に敏感になります。 | `_BacklightDirectivity` |
| **逆光の視線影響** | 範囲は0-1、既定値は1です。視線方向が逆光形状へ与える影響で、0は視点変化が少なく、1はカメラで縁の反応が大きく変わります。 | `_BacklightViewStrength` |
| **逆光のノーマル影響** | 範囲は0-1、既定値は1です。0はメッシュノーマル、1は積層ノーマルを逆光の縁に使います。ノーマルレイヤーがオフなら1でも差はありません。 | `_BacklightNormalInfluence` |
| **逆光の影での可視性** | 範囲は0-1、既定値は0.5です。影の中で逆光をどれだけ残すかで、0は隠し、1は影に関係なく表示します。 | `_BacklightShadowVisibility` |
| **逆光のベース色影響** | 範囲は0-1、既定値は0.5です。0は逆光色をそのまま使い、1はベースマップ色を完全に掛けます。 | `_BacklightBaseColorInfluence` |
| **逆光のシーン照明影響** | 範囲は0-1、既定値は1です。シーン照明の明るさで逆光が暗くなる度合いで、0は一定の演出光、1はシーン輝度に従います。 | `_BacklightSceneLightInfluence` |

## 影内部リフレクション

影の内側だけに現れるフレネル反射帯を設定します。

| 項目 | 説明 | シェーダープロパティ |
|---|---|---|
| **影内部反射を使用** | 既定値はオンです。照明・キャスト・2Dシャドウで暗くなった領域の中だけに反射帯を加えます。オフでは影判定を含めて効果全体を省略します。 | `_ShadowReflectionEnabled` |
| **影内部反射色** | HDR影内部反射の色で、既定値は(3.81, 3.81, 3.81)です。合成不透明度と強度も掛かり、ブルームがないと高い値で白飛びします。 | `_ShadowReflectionColor` |
| **影内部反射の合成モード** | Normal・Multiply・Add・Hue・Screen・Color・Overlayから影内部反射の合成方法を選びます。既定値はAdd(2)で明るさを加えますが、表示範囲は影ゲートと不透明度でも制限されます。 | `_ShadowReflectionBlendMode` |
| **ブレンド不透明度** | 影の内部反射レイヤーが結果に混ざる割合です。影の中の照り返しが強すぎる場合は下げてください。0でオフになります。 | `_ShadowReflectionBlendOpacity` |
| **色純度** | ベース色と影内反射ティントを合成した後の彩度範囲0〜10、既定値1です。0は無彩色、1は合成色を維持し、1を超えると過彩度になります。 | `_ShadowReflectionColorPurity` |
| **影内部反射の強度** | 範囲は0-20、既定値は0.5です。影領域内の反射の明るさ倍率で、0では影の形を設定しても色を加えません。 | `_ShadowReflectionIntensity` |
| **幅** | 範囲は0-1、既定値は0.9です。0では領域なし、1では領域全体を使います。柔らかさを変えてもこの幅の外側へは広がりません。 | `_ShadowReflectionWidth` |
| **柔らかさ** | 範囲は0-1、既定値は0.5です。0は硬い境界、1は選択した幅の内側の柔らかなグラデーションです。幅は変わりません。 | `_ShadowReflectionSoftness` |
| **影内部反射のノーマル影響** | 範囲は0-1、既定値は1です。0はメッシュノーマル、1は積層ノーマルを反射形状に使います。ノーマルレイヤーがオフならメッシュノーマルに戻ります。 | `_ShadowReflectionNormalInfluence` |
| **影内部反射のしきい値** | 範囲は0-1、既定値は0.8です。このしきい値を超える暗い影で反射が始まり、高いほど深い影だけに限られます。 | `_ShadowReflectionShadowThreshold` |
| **影内部反射の影の柔らかさ** | 範囲は0.001-1、既定値は0.5です。明部と影内部反射の遷移幅で、高いほど広くなじみます。 | `_ShadowReflectionShadowSoftness` |
| **影内部反射のベース色影響** | 範囲は0-1、既定値は0.7です。0は反射色のみ、1はベースマップ色を完全に掛けます。 | `_ShadowReflectionBaseColorInfluence` |
| **影内部反射のシーン照明影響** | 範囲は0-1、既定値は1です。シーン照明の明るさで反射が暗くなる度合いで、0は一定の演出光を保ちます。 | `_ShadowReflectionSceneLightInfluence` |
| **影内部反射の光源側強調** | 範囲 0-1、既定値1。0は反射輝度を全周で均一にし、1はメイン・追加ライトが当たる側だけを残します。領域位置ではなく明るい側の選択を調整します。 | `_ShadowReflectionLightDirectionInfluence` |
| **影内部反射の環境光影響** | 範囲 0-1、既定値1。0はライトプローブと環境SHの色を無視し、1は環境色を影内部の反射に完全に加えます。 | `_ShadowReflectionAmbientInfluence` |
| **影内部反射の追加ライト影響** | 範囲 0-1、既定値1。0は追加のポイント・スポットライトを無視し、1は各ライトの方向、色、影、減衰を反射に完全に反映します。 | `_ShadowReflectionAdditionalLightInfluence` |
| **キャストシャドウ内の表示量** | 0ではキャストシャドウ内で内部反射を非表示、1では完全に表示します（既定値）。投影影の中でハイライトが光るのを避けたいときに下げます。WARUDO（ビルトイン）のポイント・スポット追加ライトによる反射にも適用されます。2DシャドウとSSAOは追加ライトパスでは再計算されません。 | `_ShadowReflectionCastShadowVisibility` |

## フロントライト

カメラ側を向く面に加える独立した正面アクセント光を設定します。

| 項目 | 説明 | シェーダープロパティ |
|---|---|---|
| **フロントライトを使用** | 既定値はオンです。現在のライトと視線を使って正面向きの面に独立したアクセントを加えます。オフでは計算を省略します。 | `_FrontLightEnabled` |
| **フロントライト色** | HDR正面アクセントの色で、既定値は(1, 1, 1)です。最終色は強度と表面合成にも左右されます。 | `_FrontLightColor` |
| **フロントライトの合成モード** | Normal・Multiply・Add・Hue・Screen・Color・Overlayからフロントライトの合成方法を選びます。既定値は明るいアクセント向けのAddです。 | `_FrontLightBlendMode` |
| **ブレンド不透明度** | フロントライトが最終色へ混ざる割合です。色と強度を変えずに存在感だけを抑え、0で完全に消えます。 | `_FrontLightBlendOpacity` |
| **色純度** | ベース色とフロントライトティントを合成した後の彩度範囲0〜10、既定値1です。0は無彩色、1は合成色を維持し、1を超えると過彩度になります。 | `_FrontLightColorPurity` |
| **フロントライト強度** | 範囲は0-10、既定値は0.2です。正面アクセントの明るさ倍率で、0では領域や色の設定も画面に寄与しません。 | `_FrontLightStrength` |
| **領域サイズ** | 範囲は0-1、既定値は0.25です。0で消え、1で正面全体がアクセントの使用可能領域になります。丸い形状では、画面上に見える円形アクセントの半径に近く動作します。 | `_FrontLightSize` |
| **柔らかさ** | 範囲は0-1、既定値は0.35です。0は硬い外周、1は選択領域の内側全体で滑らかに減衰します。領域サイズの外側境界は動きません。 | `_FrontLightSoftness` |
| **ハイライト中心サイズ** | 範囲は0-1、既定値は0.4です。外側領域の中で、より明るく強調する中心部の相対サイズです。0では中心領域を作りません。 | `_FrontLightCoreSize` |
| **ハイライト中心強度** | 範囲は0-2、既定値は0.25です。中心部へ追加する明るさです。0では外側領域を保ったまま中心強調だけを無効にします。 | `_FrontLightCoreIntensity` |
| **光源方向の影響** | 範囲は0-1、既定値は0.5です。キャップ軸へ加える主光源方向の重みです。視線方向の影響とは独立しており、同じ視線値でも上げるほどDirectional Light側へ移動します。 | `_FrontLightLightDirectionInfluence` |
| **視線方向の影響** | 範囲は0-1、既定値は0.5です。キャップ軸へ加えるカメラ視線方向の重みです。0ではカメラを回しても主光源軸に固定され、上げるほど同じ光源値でもカメラ正面側へ移動します。光源と視線の両方を0にするとフロントライトは無効になります。 | `_FrontLightViewDirectionInfluence` |
| **正面光のノーマル影響** | 範囲は0-1、既定値は1です。0はメッシュノーマル、1は積層ノーマルを使います。ノーマルレイヤーがオフなら差はありません。 | `_FrontLightNormalInfluence` |
| **正面光の影での可視性** | 範囲は0-1、既定値は0.3です。影の中で正面アクセントをどれだけ残すかを決めます。 | `_FrontLightShadowVisibility` |
| **正面光のベース色影響** | 範囲は0-1、既定値は0.5です。0はアクセント色をそのまま使い、1はベースマップ色を完全に掛けます。 | `_FrontLightBaseColorInfluence` |
| **正面光のシーン照明影響** | 範囲は0-1、既定値は1です。シーン照明の明るさが正面アクセントへ与える影響で、0は一定の演出光を保ちます。 | `_FrontLightSceneLightInfluence` |
