# リム

シルエットを立たせ、キャラクターを背景から切り離す項目です。重ねてオンにすると、すぐに過剰になります。

このページは値を探すための表です。オンにする順序が必要な場合は [リムガイド](/guides/rim) を見てください。

見出しと目次は、インスペクターのセクション名と表示順をそのまま踏襲しています。

マップとマスクのスロット内の項目は、すべてのスロットで共通です。
チャンネル・リマップ・フェザー・マスクUVは [テクスチャスロット共通UI](/guides/texture-modules) に一度だけ記載しています。

## リムシェード {#림-셰이드}

| インスペクターのラベル | 形式 | 範囲 | 既定値 | 役割 |
|---|---|---|---|---|
| **リムシェードを使用** | オン/オフ | - | オフ | シルエット内側の陰影帯を形状影マスクへ加えます |
| **影への寄与強度** | 実数 | 0 ~ 1 | 1 | シルエット内側の陰影帯の強さで、0ではリムシェードの計算自体を飛ばすため幅と柔らかさを変えても変化しません |
| **幅** | 実数 | 0 ~ 1 | 0.2 | 0では領域なし、1では領域全体を使います |
| **柔らかさ** | 実数 | 0 ~ 1 | 0.4 | 0は硬い境界、1は選択した幅の内側の柔らかなグラデーションです |
| **ノーマルマップ影響** | 実数 | 0 ~ 1 | 1 | 0 = メッシュ法線、1 = 積層ノーマルマップを完全適用 |
| **リム影マスクを使用** | オン/オフ | - | オフ | - |

|---|---|---|---|---|

| **強度** | 実数 | 0 ~ 20 | 1 | フレネルリムの明るさ倍率で、0ではリムの色や幅を変えても画面に現れません |
| **リムライトマスクを使用** | オン/オフ | - | オフ | - |
| **幅** | 実数 | 0 ~ 1 | 0.5 | 0では領域なし、1ではフレネル領域全体を使います |
| **柔らかさ** | 実数 | 0 ~ 1 | 0.2 | 0は硬い境界、1は選択した幅全体を使う柔らかなグラデーションです |
| **光源側の強調** | 実数 | 0 ~ 1 | 0.8 | 0ではリム輝度を全周で均一にし、1では現在のメイン／Virtual Lightが当たる側だけを残します |

| **影内の表示量** | 実数 | 0 ~ 1 | 0 | 0は影でリムを隠し、1は影でも完全に表示します |
| **ベースカラー影響** | 実数 | 0 ~ 1 | 0.5 | 0ではリム色をそのまま使い、1ではベースマップの色を掛けて素材ごとに異なるリム色になります |
| **シーンライトの影響** | 実数 | 0 ~ 1 | 1 | 0ではシーンの明るさに関係なく一定の強さで出て、1では照明が暗くなるほどリムも暗くなります |
| **ノーマルマップ影響** | 実数 | 0 ~ 1 | 1 | 0はメッシュ法線だけを使い、1は積層ノーマルマップを完全に使います |
| **距離補正** | 実数 | 0 ~ 1 | 1 | 0は従来の生の幅を使い、1はカメラ距離が変わってもフレネルリム幅を安定させます |
| **投影 / FOV補正** | 実数 | 0 ~ 1 | 1 | 0はFOVや正投影で生の幅が変わり、1はFOVや正投影でも幅を安定させます |
