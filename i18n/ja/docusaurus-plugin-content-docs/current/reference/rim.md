# リム

シルエットを立て、キャラクターを背景から切り離すグループです。重ねるとすぐ過剰になるので、ひとつずつ確認しながら上げてください。

:::note
このページの項目名と説明は、MingToonインスペクターが実際に表示する文言をソースからそのまま取得しています。
:::

## リムシェード

シルエット内側の陰影帯を設定します。

| 項目 | 説明 | シェーダープロパティ |
|---|---|---|
| **リムシェードを使用** | 既定値はオフです。シルエット内側の陰影帯を形状影マスクへ加えます。色を加える効果ではなく、オフでは評価を省略します。 | `_MingRimShadeEnabled` |
| **影への寄与強度** | 範囲は0-1、既定値は1です。シルエット内側の陰影帯の強さで、0ではリムシェードの計算自体を飛ばすため幅・減衰・柔らかさを変えても変化しません。 | `_MingRimShadeIntensity` |
| **リム減衰** | 範囲は0.01-32、既定値は0.3です。値が大きいほど陰影帯がシルエット際の細い帯に寄ります。 | `_MingRimShadePower` |
| **リム影の幅** | 範囲は0-1、既定値は0.2です。陰影帯が始まる位置で、0では帯が現れません。 | `_MingRimShadeWidth` |
| **境界の柔らかさ** | 範囲は0.001-2、既定値は0.4です。陰影帯の境界のぼかし幅で、低くするとインクで引いた線のように硬くなります。 | `_MingRimShadeSoftness` |
| **リムシェードのノーマル影響** | 範囲は0-1、既定値は1です。0はメッシュノーマル、1は積層ノーマルをリム影の形状に使います。ノーマルレイヤーがオフならメッシュノーマルに戻ります。 | `_MingRimShadeNormalInfluence` |

## リムライト

視線角度に反応するリムライトを設定します。

| 項目 | 説明 | シェーダープロパティ |
|---|---|---|
| **フレネルリムを使用** | 既定値はオンです。斜めに見えるシルエットの縁へリム光を合成します。オフでは値を保持しつつこのパスを省略します。 | `_MingFresnelRimEnabled` |
| **フレネルリム色** | HDRリム光の色で、既定値は(26.17, 26.17, 26.17)です。合成不透明度と掛け合わされ、ブルームがないと高い値で白飛びすることがあります。 | `_MingFresnelRimColor` |
| **フレネルリムの合成モード** | Normal・Multiply・Add・Hue・Screen・Color・Overlayからリムの合成方法を選びます。既定値はAdd(2)で明るさを加えるため、HDR色や不透明度が高いと白飛びやブルームが起こることがあります。 | `_MingFresnelRimBlendMode` |
| **ブレンド不透明度** | フレネルリムが結果に混ざる割合です。リムの色や強度はそのままに存在感だけを抑えるときに使ってください。0ではリムが完全にオフになります。 | `_MingFresnelRimBlendOpacity` |
| **強度** | 範囲は0-20、既定値は0.52です。フレネルリムの明るさ倍率で、0ではリムの色や幅を変えても画面に現れません。 | `_MingFresnelRimIntensity` |
| **幅** | 範囲は0-1、既定値は0です。リムが始まる位置で、0ではリムが出ず、1に近いと表面全体が明るくなります。 | `_MingFresnelRimWidth` |
| **柔らかさ** | 範囲は0.001-2、既定値は0.64です。リム境界のぼかし幅で、低いとセル調の硬い帯、高いと柔らかいグラデーションになります。 | `_MingFresnelRimSoftness` |
| **フレネル減衰** | 範囲は0.01-32、既定値は0.54です。値が大きいほどリムがシルエット際の細い帯に寄ります。幅と連動し、下げるほど柔らかく広がります。通常は2〜8の範囲で使います。 | `_MingFresnelRimPower` |
| **光源方向の影響** | 0ではカメラ基準でシルエット全体にリムが回り、1では光源側だけに残ります。シーンに平行光がない場合は差が出ません。 | `_MingFresnelRimLightDirectionInfluence` |
| **フレネルリムの視線影響** | リムの位置を視線と光源のどちらが決めるかです。1ではこれまでどおりカメラから見たシルエットを回り、カメラを動かすとリムも動きます。0では光源方向だけに従い、カメラを回してもリムはその場に留まります。 | `_MingFresnelRimViewStrength` |
| **フレネルリムの影内表示** | 範囲 0-1、既定値0。0は影でリムを隠し、1は影でも完全に表示します。 | `_MingFresnelRimShadowVisibility` |
| **ベースカラーの影響** | 0ではリム色をそのまま使い、1ではベースマップの色を掛けて素材ごとに異なるリム色になります。 | `_MingFresnelRimBaseColorInfluence` |
| **シーン照明の影響** | 0ではシーンの明るさに関係なく一定の強さで出て、1では照明が暗くなるほどリムも暗くなります。 | `_MingFresnelRimSceneLightInfluence` |
| **フレネルリム法線マップの影響** | 範囲 0-1、既定値1。0はメッシュ法線だけを使い、1は積層ノーマルマップを完全に使います。 | `_MingFresnelRimNormalInfluence` |
| **フレネルリム距離補正** | 範囲 0-1、既定値1。0は従来の生の幅を使い、1はカメラ距離が変わってもフレネルリム幅を安定させます。 | `_MingFresnelRimDistanceCompensation` |
| **フレネルリム投影補正** | 範囲 0-1、既定値1。0はFOVや正投影で生の幅が変わり、1はFOVや正投影でも幅を安定させます。 | `_MingFresnelRimProjectionCompensation` |

## バックライト

表面の背後にある主光源が作る独立した逆光帯を設定します。

| 項目 | 説明 | シェーダープロパティ |
|---|---|---|
| **バックライトを使用** | 既定値はオンです。メインライトが表面の後ろにあるとき逆光のアクセントを加えます。オフでは値を保持しつつ色への寄与とピクセル計算を省略します。 | `_MingBacklightEnabled` |
| **バックライト色** | HDR逆光の色で、既定値は(2, 2, 2)です。強度と掛け合わされ、ブルームがないと高い値で白飛びすることがあります。 | `_MingBacklightColor` |
| **バックライト強度** | 範囲は0-10、既定値は0.29です。逆光の明るさ倍率で、0では色や境界を変えても見えません。 | `_MingBacklightStrength` |
| **バックライト境界** | 範囲は0-1、既定値は0.66です。逆光が始まる境界で、高いほど面に広がり、低いほどシルエット近くに限られます。 | `_MingBacklightBorder` |
| **バックライトの柔らかさ** | 範囲は0.001-1、既定値は0.5です。境界の遷移幅で、低いと硬いセル帯、高いと柔らかなグラデーションになります。 | `_MingBacklightSoftness` |
| **バックライト指向性** | 範囲は0-1、既定値は0.5です。ライト方向への追従度で、0は広く、1は背面条件に敏感になります。 | `_MingBacklightDirectivity` |
| **逆光の視線影響** | 範囲は0-1、既定値は1です。視線方向が逆光形状へ与える影響で、0は視点変化が少なく、1はカメラで縁の反応が大きく変わります。 | `_MingBacklightViewStrength` |
| **逆光のノーマル影響** | 範囲は0-1、既定値は1です。0はメッシュノーマル、1は積層ノーマルを逆光の縁に使います。ノーマルレイヤーがオフなら1でも差はありません。 | `_MingBacklightNormalInfluence` |
| **逆光の影での可視性** | 範囲は0-1、既定値は0.5です。影の中で逆光をどれだけ残すかで、0は隠し、1は影に関係なく表示します。 | `_MingBacklightShadowVisibility` |
| **逆光のベース色影響** | 範囲は0-1、既定値は0.5です。0は逆光色をそのまま使い、1はベースマップ色を完全に掛けます。 | `_MingBacklightBaseColorInfluence` |
| **逆光のシーン照明影響** | 範囲は0-1、既定値は1です。シーン照明の明るさで逆光が暗くなる度合いで、0は一定の演出光、1はシーン輝度に従います。 | `_MingBacklightSceneLightInfluence` |

## 影内部リフレクション

影の内側だけに現れるフレネル反射帯を設定します。

| 項目 | 説明 | シェーダープロパティ |
|---|---|---|
| **影内部反射を使用** | 既定値はオンです。照明・キャスト・2Dシャドウで暗くなった領域の中だけに反射帯を加えます。オフでは影判定を含めて効果全体を省略します。 | `_MingShadowReflectionEnabled` |
| **影内部反射色** | HDR影内部反射の色で、既定値は(3.81, 3.81, 3.81)です。合成不透明度と強度も掛かり、ブルームがないと高い値で白飛びします。 | `_MingShadowReflectionColor` |
| **影内部反射の合成モード** | Normal・Multiply・Add・Hue・Screen・Color・Overlayから影内部反射の合成方法を選びます。既定値はAdd(2)で明るさを加えますが、表示範囲は影ゲートと不透明度でも制限されます。 | `_MingShadowReflectionBlendMode` |
| **ブレンド不透明度** | 影の内部反射レイヤーが結果に混ざる割合です。影の中の照り返しが強すぎる場合は下げてください。0でオフになります。 | `_MingShadowReflectionBlendOpacity` |
| **影内部反射の強度** | 範囲は0-20、既定値は0.5です。影領域内の反射の明るさ倍率で、0では影の形を設定しても色を加えません。 | `_MingShadowReflectionIntensity` |
| **影内部反射の減衰** | 範囲は0.01-32、既定値は3.9です。高いほど反射がシルエット際の細い帯に集まります。 | `_MingShadowReflectionPower` |
| **影内部反射の幅** | 範囲は0-1、既定値は0.9です。影の中で反射帯が占める幅で、0では消え、1に近いほど広く覆います。 | `_MingShadowReflectionWidth` |
| **影内部反射の柔らかさ** | 範囲は0.001-1、既定値は0.5です。反射帯の縁の遷移幅で、低いと硬く、高いと柔らかくなります。 | `_MingShadowReflectionSoftness` |
| **影内部反射のノーマル影響** | 範囲は0-1、既定値は1です。0はメッシュノーマル、1は積層ノーマルを反射形状に使います。ノーマルレイヤーがオフならメッシュノーマルに戻ります。 | `_MingShadowReflectionNormalInfluence` |
| **影内部反射のしきい値** | 範囲は0-1、既定値は0.8です。このしきい値を超える暗い影で反射が始まり、高いほど深い影だけに限られます。 | `_MingShadowReflectionShadowThreshold` |
| **影内部反射の影の柔らかさ** | 範囲は0.001-1、既定値は0.5です。明部と影内部反射の遷移幅で、高いほど広くなじみます。 | `_MingShadowReflectionShadowSoftness` |
| **影内部反射のベース色影響** | 範囲は0-1、既定値は0.7です。0は反射色のみ、1はベースマップ色を完全に掛けます。 | `_MingShadowReflectionBaseColorInfluence` |
| **影内部反射のシーン照明影響** | 範囲は0-1、既定値は1です。シーン照明の明るさで反射が暗くなる度合いで、0は一定の演出光を保ちます。 | `_MingShadowReflectionSceneLightInfluence` |
| **影内部反射のライト方向影響** | 範囲 0-1、既定値1。0は光源方向を無視して反射リムを全体に残し、1はメイン・追加ライトの方向に沿って明るい側に配置します。 | `_MingShadowReflectionLightDirectionInfluence` |
| **影内部反射の環境光影響** | 範囲 0-1、既定値1。0はライトプローブと環境SHの色を無視し、1は環境色を影内部の反射に完全に加えます。 | `_MingShadowReflectionAmbientInfluence` |
| **影内部反射の追加ライト影響** | 範囲 0-1、既定値1。0は追加のポイント・スポットライトを無視し、1は各ライトの方向、色、影、減衰を反射に完全に反映します。 | `_MingShadowReflectionAdditionalLightInfluence` |
| **キャストシャドウ内の表示量** | 0ではキャストシャドウ内で内部反射を非表示、1では完全に表示します（既定値）。投影影の中でハイライトが光るのを避けたいときに下げます。WARUDO（ビルトイン）ではポイント・スポット追加ライトによる反射には適用されません。 | `_MingShadowReflectionCastShadowVisibility` |

## フロントライト

カメラ側を向く面に加える独立した正面アクセント光を設定します。

| 項目 | 説明 | シェーダープロパティ |
|---|---|---|
| **フロントライトを使用** | 既定値はオンです。現在のライトと視線を使って正面向きの面に独立したアクセントを加えます。オフでは計算を省略します。 | `_MingFrontLightEnabled` |
| **フロントライト色** | HDR正面アクセントの色で、既定値は(1, 1, 1)です。最終色は強度と表面合成にも左右されます。 | `_MingFrontLightColor` |
| **フロントライト強度** | 範囲は0-10、既定値は0.2です。正面アクセントの明るさ倍率で、0では境界や色の設定も画面に寄与しません。 | `_MingFrontLightStrength` |
| **フロントライト境界** | 範囲は0-1、既定値は0.9です。正面アクセントが始まる境界で、高いほど広く、低いほど正面中心に限られます。 | `_MingFrontLightBorder` |
| **フロントライトの柔らかさ** | 範囲は0.001-1、既定値は0.17です。境界の遷移幅で、低いとくっきり、高いと柔らかくなります。 | `_MingFrontLightSoftness` |
| **フロントライト指向性** | 範囲は0-1、既定値は0.5です。ライト方向と正面条件への追従を調整します。 | `_MingFrontLightDirectivity` |
| **正面光の視線影響** | 範囲は0-1、既定値は0.65です。視線方向が正面光の領域へ与える影響で、高いほどカメラ移動で変化します。 | `_MingFrontLightViewStrength` |
| **正面光のノーマル影響** | 範囲は0-1、既定値は1です。0はメッシュノーマル、1は積層ノーマルを使います。ノーマルレイヤーがオフなら差はありません。 | `_MingFrontLightNormalInfluence` |
| **正面光の影での可視性** | 範囲は0-1、既定値は0.3です。影の中で正面アクセントをどれだけ残すかを決めます。 | `_MingFrontLightShadowVisibility` |
| **正面光のベース色影響** | 範囲は0-1、既定値は0.5です。0はアクセント色をそのまま使い、1はベースマップ色を完全に掛けます。 | `_MingFrontLightBaseColorInfluence` |
| **正面光のシーン照明影響** | 範囲は0-1、既定値は1です。シーン照明の明るさが正面アクセントへ与える影響で、0は一定の演出光を保ちます。 | `_MingFrontLightSceneLightInfluence` |
