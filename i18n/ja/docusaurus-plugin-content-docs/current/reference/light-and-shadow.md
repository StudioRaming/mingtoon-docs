# ライティングと影

トゥーンの印象を最も大きく左右するグループです。フォームシャドウ（光の向きによる陰影）とシャドウ投影（実時間で落ちる影）は別セクションなので区別して見てください。

:::note
このページの項目名と説明は、MingToonインスペクターが実際に表示する文言をソースからそのまま取得しています。
:::

## マスター調整

光を足すもの全部・影全部・最終出力を、それぞれ一度に乗算しティントします。

| 項目 | 説明 | シェーダープロパティ |
|---|---|---|
| **明るさ倍率** | 光を足すレイヤー全部（バックライト・フロントライト・フレネルリム・影の内部反射・2Dリムライト・深度透過光）の明るさを一度に調整します。新しいシーンでリム系が全体的に強すぎる・弱すぎるときは、各モジュールを直す代わりにこの値を動かしてください。1が基準です。 | `_MingRimMasterIntensity` |
| **基本色** | 光を足すレイヤー全部に乗算される色です。各モジュールの色はそのままに、全体の色味だけをシーンに合わせるときに使います。白が基準です。 | `_MingRimMasterTint` |
| **カラーパッド X** | 基本色の上に重ねるカラーホイール座標です。XとYが両方0なら色は変わらず、中心から離れるほどその方向の色に強く染まります。 | `_MingRimMasterColorX` |
| **カラーパッド Y** | カラーパッド Xと対でカラーホイール上の位置を決めます。両方0なら色は変わりません。 | `_MingRimMasterColorY` |
| **明るさ** | カラーパッドで作った色の明るさです。1が基準で、下げるとパッドが中央でも対象レイヤー全体が暗くなります。 | `_MingRimMasterColorValue` |
| **明るさ倍率** | フォーム・AO・リムシェード・キャスト・2D影がすべて合成された後、影の部分だけをもう一度調整します。影全体が重すぎる・浅すぎるときに使ってください。明部は変わりません。 | `_MingShadowMasterIntensity` |
| **基本色** | 影の領域全体に乗算される色です。各影レイヤーの色を保ったまま、影全体を寒色・暖色に傾けるときに使います。影になっている分だけ適用されます。 | `_MingShadowMasterTint` |
| **カラーパッド X** | 影用の基本色の上に重ねるカラーホイール座標です。XとYが両方0なら色は変わらず、中心から離れるほどその方向の色に染まります。 | `_MingShadowMasterColorX` |
| **カラーパッド Y** | カラーパッド Xと対でカラーホイール上の位置を決めます。両方0なら色は変わりません。 | `_MingShadowMasterColorY` |
| **明るさ** | カラーパッドで作った色の明るさです。下げると影の部分だけがさらに暗くなります。1が基準です。 | `_MingShadowMasterColorValue` |
| **全体の明るさ倍率** | 全エフェクト適用後の最終的なキャラクター全体の明るさ倍率です。画面上でキャラクターが丸ごと暗い・明るいときに使う最後のつまみです。フォグより前に適用されるため距離の影響を受けません。 | `_MingOutputMasterIntensity` |
| **全体の色補正** | 最終出力全体に乗算される色です。キャラクター全体の色味をシーンに合わせて最後に傾けるときに使います。白が基準です。 | `_MingOutputMasterTint` |
| **カラーパッド X** | 最終出力の基本色の上に重ねるカラーホイール座標です。XとYが両方0なら色は変わらず、中心から離れるほどその方向の色に染まります。 | `_MingOutputMasterColorX` |
| **カラーパッド Y** | カラーパッド Xと対でカラーホイール上の位置を決めます。両方0なら色は変わりません。 | `_MingOutputMasterColorY` |
| **明るさ** | カラーパッドで作った色の明るさです。下げると最終出力全体が暗くなります。1が基準です。 | `_MingOutputMasterColorValue` |
| **輪郭リム倍率** | 2Dリムライト・フレネルリム・バックライト・深度透過光のエッジ層、この4つにだけ追加で乗算します。上の倍率より一段下なので、下げてもフロントライト・影の内部反射・透過光の内側はそのままです。1が基準です。 | `_MingEdgeRimMasterIntensity` |
| **輪郭リムの最大倍率** | 上の4つをすべて加算した後の上限です。各効果の設定はそのままに合計だけを抑えるので、4つを同時に最大にしても輪郭が白飛びしません。0は上限なしで、それが既定値です。 | `_MingEdgeRimBrightnessMaximum` |
| **最終最小明るさ** | どんなに暗いシーンでもキャラクターがこれより暗くならないようにする下限です。暗いワールドでキャラクターが真っ黒に沈む場合は上げてください。完成ベース色に対する倍率です。 | `_MingLightBrightnessMinimum` |
| **最終最大明るさ** | 明るいシーンでキャラクターがこれ以上明るく飛ばないようにする上限です。1ならライトの色味を保ちつつ原画より明るくなりません。強い照明で白飛びする場合は下げてください。 | `_MingLightBrightnessMaximum` |

## ライティング

直接光と間接光への反応を設定します。

| 項目 | 説明 | シェーダープロパティ |
|---|---|---|
| **ベースカラー保持** | シーンの照明が暗くてもベースマップの色をどれだけ元のまま保つかを決めます。1では照明の強さに関わらず原画の色が残り、0では照明の明るさにそのまま従います。照明が予測できないVRChatワールドでは高めが安全です。 | `_BaseColorPreservation` |
| **シーン照明色の影響** | シーン光源の色をキャラクターにどれだけ反映するかを決めます。0ではどんな色の照明でも白色光のように見え、1では赤い照明でキャラクターも赤くなります。明るさではなく色だけを扱います。 | `_LightColorInfluence` |
| **追加ライト受信量** | ポイントライトやスポットライトなどの追加ライトを受ける量です。ワールドの雑多な光でキャラクターが光りすぎる場合は下げてください。0で追加ライトを完全に無視します。 | `_MingAdditionalLightReceive` |
| **追加ライト強度** | 受け取った追加ライトの明るさ倍率です。受けるかどうかは追加ライト受信量で決め、受けた光が強すぎる・弱すぎるときにこの値を調整してください。ライトの色は変わりません。 | `_MingAdditionalLightIntensity` |
| **追加ライト時のベース色維持** | 1で元のベース色を最大限維持し、0で追加ライト色を完全に反映します。 | `_MingAdditionalLightBasePreservation` |
| **左右角度** | 仮想キーライトの左右角度です。顔に落ちる陰影の方向を見ながら決めてください。ゲーム内メニューで動かす分は左右オフセットにあります。 | `_MingVirtualLightYaw` |
| **上下角度** | 仮想キーライトの上下角度です。上から照らすと自然で、下から照らすとホラー照明になります。ゲーム内メニューで動かす分は上下オフセットにあります。 | `_MingVirtualLightPitch` |
| **光源色** | 仮想キーライトの色です。ワールドライトの代わり、またはその上に重なってキャラクターを照らす色なので、白から始めてシーンの雰囲気にわずかに寄せるのが安全です。 | `_MingVirtualLightColor` |
| **カラーパッド X** | 光源色の上に重ねるカラーホイール座標です。XとYが両方0なら色は変わらず、中心から離れるほどその方向の色に染まります。 | `_MingVirtualLightColorX` |
| **カラーパッド Y** | カラーパッド Xと対でカラーホイール上の位置を決めます。両方0なら色は変わりません。 | `_MingVirtualLightColorY` |
| **明るさ** | カラーパッドで作った色の明るさです。光源の明るさと乗算されるため、通常は1のままにして光源の明るさ側を調整します。 | `_MingVirtualLightColorValue` |
| **光源の明るさ** | 仮想キーライトの明るさです。置換モードではこれがキーライトの明るさそのもので、加算モードではワールドライトに上乗せする量です。 | `_MingVirtualLightIntensity` |
| **明部の明るさ** | 光の当たる面全体の明るさ倍率です。1が基準で、上げると明部が白飛びしやすくなります。 | `_LitBrightness` |
| **間接光の持ち上げ** | 環境光（ライトプローブ・アンビエント）の明るさだけフォームシャドウを持ち上げ、暗いシーンで黒つぶれするのを防ぎます。フォームシャドウがオンのときだけ計算され、キャストシャドウには別途キャスト間接光補正があります。 | `_IndirectStrength` |
| **VRCライトボリューム（テスト用）** | エディタ確認用のトグルです。VRChatへのアップロード時はこの値に関係なく自動的にオンになり、ワールドが配置したVRC Light Volumesをライトプローブの代わりに読み込みます。ボリュームのないワールドではプローブに戻るため、絵は変わりません。エディタでオンにするとバリアントが1つ増えTexture3Dの読み取りが加わるため、ボリュームワールドでの見た目を確認したいときだけオンにしてください。Built-in専用で、URPマテリアルではこの行は表示されません。 | `_MingLightVolumesEnabled` |
| **ボリューム強度** | ワールドが配置したボリュームから読み込んだ間接光全体に掛かります。1がワールドのベイクそのままで、上げるとその部屋の環境光が強くなったように見えます。ボリュームのないワールドではプローブに戻るため、この値が何であっても絵は変わりません。 | `_MingLightVolumesIntensity` |
| **ノーマルバイアス** | ボリュームをサンプルする位置を表面ノーマル方向へ押し出します。壁や床に密着した面が暗いグリッドを拾ってムラになるときに上げてください。上げすぎると陰影が面から浮いて見えるので、ムラが消える最小値で止めるのがおすすめです。 | `_MingLightVolumesNormalBias` |
| **ポイントライトの影** | ワールドがベイクした遮蔽をボリュームのポイントライトがどれだけ守るかを決めます。1が既定の挙動で、0にするとポイントライトが影なしでそのまま入ります。遮蔽をベイクしていないワールドでは値に関わらず差は出ません。 | `_MingLightVolumesPointShadows` |
| **ボリュームスペキュラー** | ボリュームの方向成分から環境ハイライトを作ります。PBRサーフェスがオンである必要があり、反射強度とは独立して動作するため、反射を0にしたトゥーンマテリアルでも使えます。Dominantは方向一つだけを使う低コスト段階、Fullは色軸三つをそれぞれ計算します。トゥーンのバンディングを通さない柔らかいハイライトです。 | `_MingLightVolumesSpecularMode` |
| **ボリュームスペキュラー強度** | ボリュームスペキュラーの強さです。ボリュームスペキュラーがオフの間は何の影響もありません。 | `_MingLightVolumesSpecularStrength` |

## フォームシャドウ

形状ベースの陰影境界と柔らかさを設定します。

| 項目 | 説明 | シェーダープロパティ |
|---|---|---|
| **フォームシャドウ** | 光の向きに応じて落ちるフォームシャドウ（トゥーン陰影）のオン/オフです。オフにすると明暗の段が消え、キャスト影と2D影だけが残ります。 | `_FormShadowEnabled` |
| **第1シャドウ境界** | 第1シャドウが始まる境界位置です。上げると影が明るい側へ広がり、下げると光の反対側へ後退します。影の面積が気に入らないときに最初に触る値です。 | `_FormShadowMidPoint` |
| **1段目の影のぼかし** | 陰影境界のぼかし幅です。0.001付近ではセルアニメのようなくっきりした境界、0.3以上では柔らかいグラデーションになります。本製品で最も頻繁に調整する値です。 | `_FormShadowSoftness` |
| **第1シャドウ色** | 第1フォームシャドウの色です。真っ黒よりベースをやや暗くした落ち着いた色の方が柔らかく見えます。統合シャドウモードがオンの間はこの色の代わりに統合色が使われます。 | `_FormShadowColor` |
| **1段目の影の明るさ** | 1段目フォームシャドウ色の明るさ倍率です。下げるほど暗くなり、「影の色」モジュールがオフの間は反映されません。 | `_FormShadowBrightness` |
| **第2シャドウ色** | 第2（より深い）フォームシャドウの色です。第1より暗くするのが一般的です。第2シャドウを有効にしたときのみ表示されます。 | `_FormShadow2ndColor` |
| **2段目の影の明るさ** | 2段目フォームシャドウ色の明るさ倍率です。1段目より低くしないと段階が見分けられません。2段目の影がオフの間は反映されません。 | `_FormShadow2ndBrightness` |
| **ブレンド不透明度** | 第1シャドウ色が結果に混ざる割合です。影色が濃く覆いすぎる場合は下げてください。0では色がまったく適用されません。 | `_FormShadowColorBlendOpacity` |
| **2段目の影を使用** | 最も暗い側に2段目の影を追加して3階調のセル陰影にします。オフの間は2段目の明るさとぼかしはどちらも無視されます。 | `_FormShadow2ndEnabled` |
| **第2シャドウ境界** | 第2シャドウの境界位置です。第1境界より暗い側に置くと2つの段が自然に分かれます。 | `_FormShadow2ndMidPoint` |
| **2段目の影のぼかし** | 2段目の影の境界のぼかし幅です。1段目より狭くすると内側の段階がはっきりします。2段目の影がオフの間は反映されません。 | `_FormShadow2ndSoftness` |
| **影の境界を使用** | 明部と影の間のカラー境界効果全体を切り替えます。オフでは関連する境界演算も省略します。 | `_MingShadowBorderEnabled` |
| **境界色** | 第1シャドウの境界線に乗せる色です。肌の明暗境界にほんのり赤みを入れる用途が代表的です。ブレンド不透明度を0にすると無効になります。 | `_ShadowBorderColor` |
| **境界線の配置** | 境界カラーの帯を陰影境界の両側にまたがらせるか、影側の内部だけに残すかを決めます。オンでは明部側にもかかり太い色境界の演出になり、オフでは影の内側だけに残って端正になります。 | `_MingShadowBorderOverlay` |
| **境界の幅** | 陰影境界に乗る色帯の幅です。0では帯自体が描かれず、境界の色・ぼかし・強度はすべて無視されます。「影の色」モジュールがオンで、フォームシャドウかキャストシャドウのどちらかが動作している必要があります。 | `_ShadowBorderWidth` |
| **境界のぼかし** | 境界カラー帯の縁のぼかし幅です。境界の幅が0の場合は反映されません。 | `_ShadowBorderBlur` |
| **境界の強度** | 境界カラー帯の不透明度です。0では幅をいくら上げても帯は見えません。 | `_ShadowBorderStrength` |
| **境界のベースマップ合成** | 0では指定した境界色が単色で出て、1ではベースマップの色と混ざり部位ごとに異なる境界色になります。肌と髪が同じマテリアルにある場合は上げると自然です。 | `_ShadowBorderBaseColorMix` |
| **ブレンド不透明度** | 第2シャドウ色が結果に混ざる割合です。0では色がまったく適用されません。 | `_FormShadow2ndColorBlendOpacity` |
| **ブレンド不透明度** | 境界色が混ざる割合です。0では境界色が完全に無効になります。 | `_ShadowBorderColorBlendOpacity` |

## シャドウカラー

トゥーン影の段階別カラーと合成を設定します。

| 項目 | 説明 | シェーダープロパティ |
|---|---|---|
| **シャドウカラー** | 影に色を乗せる処理全体のオン/オフです。オフにするとフォーム・キャスト・2D影用に指定した色と境界色が適用されません。 | `_ShadowColorEnabled` |
| **統合シャドウ色** | すべての影が収束する色です。RGBはベース色に乗算され、アルファが適用量のため、アルファが0だとどの色を選んでも影はベース色のままになります。統合シャドウがオフのときは使われません。 | `_MingUnifiedShadowColor` |
| **統合シャドウを使用** | フォーム・キャスト・2Dの各シャドウを1つの最終色にまとめ、重なりによる過度な暗化を防ぎます。オンの間は個別の影色・合成・明るさのコントロールは結果に反映されません（値は保持されます）。 | `_MingUnifiedShadowEnabled` |
| **影への環境光の影響** | 影を環境光の色味に寄せる度合いです。夕焼けのワールドで影だけ浮いて見えるときに上げてください。明るさではなく色だけを取り込み、影になっている部分にのみ適用されます。 | `_MingShadowAmbientInfluence` |

## 影の投影

このマテリアルへ投影されるキャストシャドウと境界フェザーを設定します。

| 項目 | 説明 | シェーダープロパティ |
|---|---|---|
| **シャドウ投影** | 他のオブジェクトや自身が落とす投影影（キャストシャドウ）を受けるかどうかです。オフにするとシーンの影がキャラクターに落ちません。 | `_CastShadowEnabled` |
| **受信強度** | 他のオブジェクトや自分自身が落とすリアルタイム影をどれだけ受けるかを決めます。0ではキャストシャドウが完全に消え、下の明るさ・合成・間接光補正も結果に現れません。 | `_CastShadowReceiveStrength` |
| **PBR / トゥーン合成** | 0ではUnity標準の影のように滑らかに減衰し、1ではトゥーンの帯にはっきり分かれます。帯の幅はキャストトゥーン帯の柔らかさが決めます。 | `_CastShadowToonBlend` |
| **2Dシャドウと統合** | 2Dシャドウをキャストシャドウと同じ色に結び付け、重なる箇所で二重に暗くなるのを防ぎます。オンの間は2Dシャドウ色の代わりにキャストシャドウ色が使われます。 | `_LinkDepthShadowToCastShadow` |
| **セルフキャストシャドウ抑制** | メッシュが自分自身に落とすリアルタイム影を減らします。顔や服のしわにまだらな影が出るときにオンにします。オフの間は下のバイアス値は無視されます。 | `_SelfShadowCasterBiasEnabled` |
| **セルフシャドウ・キャスターバイアス** | シャドウキャスターを表面からどれだけ押し出すかを決めます。大きくするとまだらは消えますが、接地影が浮き、薄い部位の影が途切れます。0.01〜0.03が無難です。セルフキャストシャドウ抑制がオフの間は反映されません。 | `_SelfShadowCasterBias` |
| **キャスト間接光補正** | 環境光が明るい場所でキャストシャドウを薄くし、屋内外の照明差を自然に吸収します。1に近いと明るいシーンでキャストシャドウがほぼ消えます。 | `_CastShadowIndirectLift` |
| **逆光シルエット抑制** | 光源に背を向けた面にはキャストシャドウを描きません。逆光時にキャラクター型の影が体の上に二重に現れる現象を防ぎます。 | `_CastShadowBackfaceSuppression` |
| **キャストシャドウ色** | 受け取ったキャストシャドウに乗せる色です。第1シャドウ色とトーンを合わせておくと、重なっても違和感が出ません。統合シャドウモードがオンの間は無視されます。 | `_CastShadowColor` |
| **キャストシャドウの明るさ** | キャストシャドウ色の明るさ倍率です。「影の色」モジュールがオフの場合、キャストシャドウは単純な暗化になりこの値は無視されます。 | `_CastShadowBrightness` |
| **ブレンド不透明度** | キャストシャドウ色が結果に混ざる割合です。0では色がまったく適用されません。 | `_CastShadowColorBlendOpacity` |

## shadow.pattern.group

| 項目 | 説明 | シェーダープロパティ |
|---|---|---|
| **影パターンを使用** | フォームシャドウ、2Dシャドウ、または両方にスクリーントーンを適用します。格子はメッシュ／レストポーズ座標に固定され、距離や画角が変わっても同じ部位のマーク数を保ちます。 | `_ShadowPatternEnabled` |
| **パターン適用対象** | フォームシャドウ、2Dシャドウ、または両方を選びます。リアルタイムのキャストシャドウサンプリング自体は対象外です。 | `_ShadowPatternTarget` |
| **パターンスタイル** | リカラーは影の範囲をスクリーントーンの形で描き直し、線が影色になります。オーバーレイは影をそのままに、その上へインク色で模様を刷ります。 | `_ShadowPatternStyle` |
| **インク色** | オーバーレイスタイルでスクリーントーンの線を刷るインク色です。リカラースタイルは影色をそのまま使うため、この色は使われません。 | `_ShadowPatternColor` |
| **ブレンド不透明度** | インク色が混ざる割合です。下げるとトーンが控えめになり、0ではインクが見えません。 | `_ShadowPatternColorBlendOpacity` |
| **パターン密度** | メッシュ投影1単位を埋めるセル数です。1セルがタイル1リピートなので、形状タイルを有効にしても表面密度は変わりません。 | `_ShadowPatternScale` |
| **距離補正** | 1ではセル数がメッシュに完全固定されます。下げると以前の画面密度固定に近づきますが、パターンの位相は引き続きメッシュを追従します。 | `_ShadowPatternDistanceCompensation` |
| **画角 / 投影補正** | 1では透視画角や平行投影サイズが変わっても同じメッシュ部位の密度を保ちます。0ではカメラ投影の変化が密度に反映されます。 | `_ShadowPatternProjectionCompensation` |
| **パターン回転** | パターン格子の角度です。45度付近が印刷の網点らしく自然で、0度は画面のピクセル格子と重なりモアレが出やすくなります。 | `_ShadowPatternRotation` |
| **パターン境界のぼかし** | マークの縁のぼかし幅です。実際に使われる幅はこの値とピクセルフットプリントの大きい方なので、カメラが離れても縁がジャギーに割れません。0に近いと近距離でジャギーが見えることがあり、0.02〜0.1程度が無難です。 | `_ShadowPatternSoftness` |
| **パターン強度** | 元の滑らかな影とパターン化した影の混合比です。0ではパターンがまったく見えません。 | `_ShadowPatternStrength` |
| **最暗部でパターンを維持** | 最も暗い部分でもパターンが完全に埋まらないようにします。オフの間は下の塗り量が無視され、深い影は単色で埋まります。 | `_ShadowPatternFullShadowEnabled` |
| **最暗部の塗り量** | 1に近いほど単色に近づき、下げるほど最暗部でもパターンがはっきり残ります。最暗部でパターンを維持がオフの間は反映されません。 | `_ShadowPatternFullShadowLevel` |
| **パターン形状タイルを使用** | セル内に描かれる形をタイル画像に差し替えます。オフのままなら計算で描く円形の網点が使われ、テクスチャを一度も読まないためコストは増えません。 | `_ShadowPatternTileEnabled` |
| **パターン形状タイル** | 同梱タイル5種（網点・細かい網点・線・クロスハッチ・点描）は Assets/StudioRaming/MingToon/Textures/Patterns にあります。タイルは模様の絵ではなくしきい値マップで、各テクセルがインクに変わる濃度を保持します。だから1枚で最初の点から完全な塗り潰しまでを表現できます。自作する場合はsRGBをオフにし、すべての階調が同じテクセル数を占めるようにしてください。格子1セルがタイル1リピートなので Tiling/Offset はありません。 | `_ShadowPatternTile` |
