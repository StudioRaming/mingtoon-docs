# ライティングと影

トゥーンルックの印象を最も大きく左右する項目です。フォームシャドウとシャドウ投影は別のセクションです。

このページは値を探すための表です。オンにする順序が必要な場合は [ライティングと影のガイド](/guides/light-and-shadow) を見てください。

見出しと目次は、インスペクターのセクション名と表示順をそのまま踏襲しています。

マップとマスクのスロット内の項目は、すべてのスロットで共通です。
チャンネル・リマップ・フェザー・マスクUVは [テクスチャスロット共通UI](/guides/texture-modules) に一度だけ記載しています。

| **パターン形状タイル** | テクスチャ | - | なし | 同梱タイル5種（網点・細かい網点・線・クロスハッチ・点描）は… |
| **パターン適用対象** | 選択 | Form / Depth / Both | Form | フォームシャドウ、デプスシャドウ、または両方に適用します |
