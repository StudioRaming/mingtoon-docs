# リムとアクセント光

シルエットを立て、キャラクターを背景から切り離す項目です。重ねるとすぐ過剰になるので、ひとつずつ確認しながら上げてください。

:::note
このページの項目名と説明は、MingToonインスペクターが実際に表示する文言をソースからそのまま取得しています。
:::

## リムライト

視線角度に反応するリムライトを設定します。

| 項目 | 説明 | シェーダープロパティ |
|---|---|---|
| **強度** | フレネルリムの明るさ倍率です。0ではリムの色や幅を変えても画面に現れません。 | `_MingFresnelRimIntensity` |
| **フレネル減衰** | 値が大きいほどリムがシルエット際の細い帯に寄ります。幅と連動し、下げるほど柔らかく広がります。通常は2〜8の範囲で使います。 | `_MingFresnelRimPower` |
| **幅** | リムが始まる位置です。0ではリムが出ず、1に近いと表面全体が明るくなります。 | `_MingFresnelRimWidth` |
| **柔らかさ** | リム境界のぼかし幅です。低いとセル調の硬い帯、高いと柔らかいグラデーションになります。 | `_MingFresnelRimSoftness` |
| **光源方向の影響** | 0ではカメラ基準でシルエット全体にリムが回り、1では光源側だけに残ります。シーンに平行光がない場合は差が出ません。 | `_MingFresnelRimLightDirectionInfluence` |
| **ベースカラーの影響** | 0ではリム色をそのまま使い、1ではベースマップの色を掛けて素材ごとに異なるリム色になります。 | `_MingFresnelRimBaseColorInfluence` |
| **シーン照明の影響** | 0ではシーンの明るさに関係なく一定の強さで出て、1では照明が暗くなるほどリムも暗くなります。 | `_MingFresnelRimSceneLightInfluence` |

## リムシェード

シルエット内側の陰影帯を設定します。

| 項目 | 説明 | シェーダープロパティ |
|---|---|---|
| **影への寄与強度** | シルエット内側の陰影帯の強さです。0ではリムシェードの計算自体を飛ばすため、幅・減衰・柔らかさを変えても変化しません。 | `_MingRimShadeIntensity` |
| **リム減衰** | 値が大きいほど陰影帯がシルエット際の細い帯に寄ります。 | `_MingRimShadePower` |
| **リム影の幅** | 陰影帯が始まる位置です。0では帯が現れません。 | `_MingRimShadeWidth` |
| **境界の柔らかさ** | 陰影帯の境界のぼかし幅です。低くするとインクで引いた線のように硬くなります。 | `_MingRimShadeSoftness` |
