# トラブルシューティング

症状をそのまま探してください。原因はほとんどの場合 1 つです。上位の値が 0 かオフだと、下位の値はすべて無視されます。

## どの値も効かない {#아무-값도-안-먹힌다}

上から順に確認してください。

1. **全エフェクト**をオンにします。オフだとすべてのセクションが非アクティブです。
2. 該当セクションのマスタートグルをオンにします。オフだと `クイック設定` に `(モジュールOFF)` が付きます。
3. 下の表で、その機能の上位の値を上げます。

| 見えないもの | まず確認する上位の値 |
|---|---|
| ベースのティント | **ティント合成強度** |
| 表面全体が透明すぎる、または不透明すぎる | **ベースマップ全体の不透明度** |
| デプスリムライト · デプスシャドウ | **全体幅**、次に各モジュールの強度 |
| PBR のハイライトと環境反射 | **スペキュラー強度** |
| 追加のテクスチャレイヤー | **サーフェススタックレイヤー数** |
| ノーマルマップのレイヤー | **ノーマルレイヤー数** |
| MatCap のレイヤー | **MatCapレイヤー数** |
| 影の境界の帯 | **境界の幅**、次に**境界の強度** |
| シャドウパターン | **パターン強度** |
| 顔のノーマル補正 | **プロキシノーマル強度** |
| 顔領域マスク | **マスク強度**。0 だとマテリアル全体を顔と見なします |
| PBR パックマスクのチャンネル設定 | **パックマスクを使用** |
| キャストシャドウの明るさと合成 | **受信強度** |
| アルファマスク | サーフェスモードが**不透明 (2000)** だと、オンにしても見えません |

## インストール {#install}

### マテリアルがピンク色（マゼンタ）に見えます

| 原因 | 対処 |
|---|---|
| レンダーパイプラインの不一致 | 合うバックエンドのシェーダーに差し替えます |
| シェーダーモデル 4.5 に未達 | `StudioRaming > MingToon > Validate Project` を実行。PC のみ対応です |
| URP のバージョンが範囲外 | Unity 2021.3 + URP 12.x に合わせます |

:::danger[この場合はエラーメッセージが 1 つも出ません]
SubShader が丸ごと脱落するため、ログは静かなままです。ピンク色が唯一の手がかりです。
:::

### Validate Project が Unity のバージョンを指摘します

| コード | いつ出るか | 意味 |
|---|---|---|
| `MING-ENV-UNITY-VERSION` (エラー) | エディターが 2021.3 でも 2022.3 でもないとき | 対応していないストリームです |
| `MING-VRC-UNITY-VERSION` (警告) | VRC SDK があるのに 2022.3 ではないとき | このプロジェクトにはアバターのアップロード対応がありません |
| `MING-ENV-BUILD-TARGET` (エラー) | ビルドターゲットがシェーダーモデル 4.5 を満たせないとき | Android・Quest・iOS・WebGL です。Windows に戻してください |

2022.3.22f1 は正式対応のバージョンなので、何も指摘されません。 → [Validate Project コード](/reference/validator)

### レンダーパイプラインを変えたらマテリアルが全部壊れました

切り替えダイアログで、プロジェクトの MingToon マテリアルを合うバックエンドへ一括で切り替えます。ダイアログを逃しても、マテリアルインスペクターの警告から再実行できます。

| 切り替えが止まる理由 | 対処 |
|---|---|
| マテリアルが他のアセットに含まれている | サブアセットから抽出 |
| マテリアルが読み取り専用パッケージ内にある | パッケージ外へコピー |
| マテリアルが読み取り専用、またはチェックアウトされていない | 読み取り専用の解除、またはチェックアウト |

閉じているシーンと AssetBundle のマテリアルは検査できません。別途開いて切り替えてください。

## 変換 {#conversion}

### 変換後にルックが元と違います

変換ログの `lossy` と `unsupported` の項目をまず読んでください。そのあと、マスクのチャンネルと反転、テクスチャの Tiling・Offset を比べます。AO、サーフェスモード、顔マテリアルの判定も元と合っているかを見ます。 → [変換レポートの読み方](/internals/conversion-internals)

### 変換やベイクが失敗します

| メッセージ | 対処 |
|---|---|
| 変換できるマテリアルスロットがありません | MingToon マネージャーの位置を確認し、**子レンダラーを再検索** |
| MingToon の元シェーダーが見つかりません | インストールが不完全です。パッケージを再インポート |
| 生成したシェーダーをインポートできません | プロジェクトフォルダーの書き込み権限を確認して再試行 |
| 生成されたシェーダーにコンパイルエラーがあります | MingToon のインクルードフォルダーが元のパスにあるかを確認 |
| MingToon マネージャーが複数選択されています | 一度に 1 つだけ選択 |

## 影 {#shadow}

### 影が重なる場所だけ真っ黒です

`シャドウカラー`セクションの**統合シャドウを使用**をオンにしてください。フォーム・キャスト・デプスの影が 1 色にまとまります。 → [ライティングとシャドウ](/guides/light-and-shadow#통합-그림자--겹칠-때-새까매지는-문제)

オンにしたあと個別の影の色が効かなくなるのは正常です。値は残っているので、オフにすれば戻ります。

### キャストシャドウがまだらです

| 場所 | 対処 |
|---|---|
| 服のしわと体全般 | **セルフキャストシャドウ抑制**をオンにし、**セルフシャドウ・キャスターバイアス**を 0.01 から 0.03 の間に |
| 境界が階段状に角張る | **投影フェザーを使用**をオンにし、**投影フェザー半径**・**投影フェザー強度**を調整 |
| 全体的にちらつく | 光源の shadow map 解像度、bias、cascade の順に確認 |
| 逆光で体の上にキャラクターの形が重なる | **逆光シルエット抑制**をオンにします |

:::note[フェザーは存在しない情報を復元できません]
解像度の低い shadow map にそもそもなかったディテールは、柔らかくしても戻りません。
:::

### シャドウパターンがまったく出ません

| 原因 | 対処 |
|---|---|
| **パターン形状タイルを使用**はオンなのにタイルのスロットが空 | 空のスロットは白として読まれ、白はどんな濃度でも越えられません。同梱タイルを使ってください |
| **パターン強度**が 0 | 上げます |
| 適用対象が合っていない | **パターン適用対象**を確認 |
| 点がトーンに反応せず、大きさが一定 | 二値化された点の絵を入れています。タイルは[しきい値マップ](/guides/shadow-pattern#타일은-그림이-아니라-임계값-맵입니다)である必要があります |

### 暗いワールドでキャラクターが黒く潰れます

**ベースカラー保持**、**最終最小明るさ**、**間接光の持ち上げ**、**キャスト間接光補正**を順に上げてください。明るいワールドで白く飛ぶ場合は**最終最大明るさ**を下げます。

## デプスエフェクト {#depth}

### デプスリムライトやデプスシャドウが見えません

| 原因 | 対処 |
|---|---|
| **全エフェクト**または**深度エフェクト**がオフ | インスペクターがオンにするボタンを表示します |
| **全体幅**が 0 | 上げます |
| 各モジュールの強度が 0 | 上げます |
| サーフェスモードが**透明 (3000)** | **半透明 (2499)** に変えます |
| **カメラ深度への記録**がオフ | オンにします |
| VRChat の通常画面 | アバターからは強制できません → [VRChat](/platforms/vrchat#깊이-효과가-어디까지-보장되나) |
| URP | Renderer Feature のインストールと Depth Texture の有効化 |
| WARUDO | Depth Bridge のインストール → [Warudo](/platforms/warudo#warudo-depth-bridge) |

インスペクターに深度テクスチャが用意されていないという案内が出た場合は、その案内どおりに進めてください。**SSAO 半径**を上げても広がらない場合は、上限に達しています。範囲は 0.001 から 0.05m です。

### インナーアウトラインだけ消えました

**Inner Depth Edgeを使用**は `インナーアウトライン` セクションにあります。このセクションは `スクリーン空間エフェクト` グループの中にあります。

| 原因 | 対処 |
|---|---|
| **インナーアウトラインに適用**がオンで、頂点カラーが黒い | トグルをオフにするか、**圧力ソース**を変えます |
| サーフェスモードが**透明 (3000)** | **半透明 (2499)** に変えます |
| カメラ深度がない | 上の項目を参照 |

ノーマルアウトラインは深度がなくても描かれます。ノーマルアウトラインだけ見えるなら、深度の問題です。

### 髪が頬を突き抜けて見えます

サーフェスモードを**半透明 (2499)** に変えてください。このモードはアルファ合成を使いながら深度も記録します。

**透明深度プリパス**は**透明 (3000)** 専用です。半透明 (2499) でオンにしても何も変わりません。

## アウトライン {#outline}

### ノーマルアウトラインが丸ごと消えました

| 原因 | 対処 |
|---|---|
| 頂点カラーが黒いのに**圧力ソース**が VertexRed | 圧力ソースを変えるか、頂点カラーを確認 |
| **圧力コントラスト**が 0 | 圧力が完全に無視されます。上げてください |
| **カラーマスク**が 0 | 15 に戻します |
| **アウトラインマスター**がオフ | オンにします。インナーアウトラインもこのゲートを使います |

### アウトラインが角張った部分で途切れます

**ノーマルソース**が VertexColorTS または UV8TS なのに、スムージングした輪郭線ノーマルをベイクしていないメッシュです。MeshNormal に変えてください。 → [アウトライン平滑ノーマル UV8](/guides/mesh-bakes#아웃라인-스무스-노멀-uv8)

### シーンビューでアウトラインの太さを塗れません {#씬-뷰에서-아웃라인-두께를-칠할-수-없다}

インスペクターが理由を文章で知らせます。メッセージごとの対処は[シーンビューで直接塗る](/guides/outline#씬-뷰에서-직접-칠하기)にあります。

### 塗ったら結果がおかしくなりました

**圧力ソース**が Vertex Red で**ノーマルソース**が VertexColorTS だと、同じチャンネルを上書きします。圧力ソースを Vertex Alpha に変えるか、アウトラインのノーマルを UV8 へ移してください。

他のオブジェクトまで一緒に変わった場合は、複数の Renderer が同じメッシュアセットを共有しています。メッシュを複製してその Renderer にだけ割り当ててから、塗り直してください。

## 顔 {#face}

### 顔マスクを塗ったのに効きません

**マスク強度**が 0 だと、マスクを無視してマテリアル全体を顔と見なします。0 より大きく上げてください。マスクはテクスチャ、頂点ペイント、プロキシ、マテリアル全体の順に優先されます。 → [フェイスシェーディング](/guides/character#페이스-셰이딩)

### 顔に影が 1 つも出ません

**深度の可用性**が `Force Off` だと、デプスシャドウは決して描かれません。顔用の自動補正は、顔から投影影を外しています。Face マテリアルの**深度オフ時は投影影**をオンにすると、深度がないときに投影影へ戻ります。

## VRChat {#vrchat}

### アップロードしたのに最適化がかかっていないようです

1. Unity のバージョンが 2022.3.22f1 かを確認します。2021.3 では VRChat のフックがコンパイルされません。
2. Console に `[MingToon] VRChat build hook compiled and registered.` があるかを見ます。
3. MingToon マネージャーの `最適化` タブで**ビルド・アップロード時に自動最適化（全体共通）**がオンかを見ます。
4. プロジェクトフォルダーの隣の `StudioRaming/MingToonOptimizeReport.txt` を開きます。

→ [きちんとかかったかを確認する](/workflow/build-optimization#제대로-걸렸는지-확인하기)

### 自分の画面では見えるのに、他人にはデプスエフェクトが見えません

既定値がそうなっています。深度エフェクトは本人とフレンドにだけ見えます。マネージャーの `はじめに` タブの**非フレンドにも深度エフェクトを表示**をオンにすると、全員に見えます。ただし相手側の負荷が増えます。

ミラーで出ないのも意図した動作です。ミラーが他人のシルエットを影として使わないように遮断しています。 → [深度エフェクトがどこまで保証されるか](/platforms/vrchat#깊이-효과가-어디까지-보장되나)

## WARUDO {#warudo}

### WARUDO でデプスエフェクトが全部出ません

Depth Bridge がインストールされていません。Playground のパスと `.cs` 拡張子、`installed` ログを確認してください。 → [WARUDO Depth Bridge](/platforms/warudo#warudo-depth-bridge)

メイン画面だけ正常で Spout・NDI の出力が異なる場合は、そのカメラの `depth enabled for camera=` ログを確認してください。ログがなければ、処理されていないカメラです。

## 性能 {#performance}

### 作業中にインスペクターが重いです {#작업-중-인스펙터가-무겁다}

正常です。編集用のシェーダーは、すべての機能と最大レイヤー数を一度にコンパイルして保持します。そのおかげで、機能をオンにするたびにコンパイルを待たずに済みます。その代わり、Unity エディター内では同じマテリアルがビルド結果の約2倍の GPU 時間を使います（実測）。エディターのフレームレートやプロファイラーの数値でアバターの重さを判断しないでください。軽量化は[ビルドするとき](/workflow/build-optimization)にだけ適用されます。

### アバターが重すぎると言われます

深度エフェクトをすべてオフにすると、深度ライトもビルドから自動で外れます。これがもっとも軽い経路です。 → [VRChat 深度ライト](/platforms/vrchat#vrchat-깊이-라이트)

## ベイクと復元 {#bake}

### baked マテリアルの復元ボタンが非アクティブです

ベイクの Manifest が残っているかを確認してください。元の編集用マテリアルの GUID も生きている必要があります。ベイク以降、Renderer の階層とマテリアルスロットがそのままかも見ます。 → [手動 Bake と復元](/workflow/bake-and-restore)

### ベイクのあとにオンにした機能が動きません

ベイク時点でオフで、保存対象として検出されなかった機能はコードから削除されます。あとからスクリプトでオンにする値は、**ベイク除外（実行時変更）**として印を付けてください。

## それでも解決しない場合

[公式 Discord サーバー](https://discord.gg/Zsj6pkWKKs)のバグ報告チャンネルに、次の内容を一緒に残してください。

1. Unity のバージョンと対象プラットフォーム (VRChat PC / WARUDO / 一般 Unity)
2. レンダーパイプライン (BRP / URP 12.x)
3. MingToon のバージョン
4. Console ログの全文
5. 再現手順
