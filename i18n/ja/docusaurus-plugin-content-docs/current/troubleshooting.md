# トラブルシューティング

症状から探してください。ほとんどは **「上位の値が0であるか無効になっていると、下位がすべて無視される」** という構造が原因です。

## 何の値も反映されない {#아무-값도-안-먹힌다}

上から順に確認してください。

1. **全体効果** — インスペクター最上部のマスタースイッチ。無効になっていると以下のセクション全体が非活性になり、`このセクションは全体効果が無効になっているため非活性です。` が表示されます。
2. **セクションマスタートグル** — 各セクションにも独自のトグルがあります。無効になっていると `クイック設定` に `(モジュール無効)` が付きます。
3. **上位の値** — 下の表を参照してください。

| 見えないもの | まず確認する上位の値 |
|---|---|
| ベースティント | `ティント不透明度` |
| 深度リム / 2Dシャドウ | `マスター幅` → 各モジュールの `強度` |
| PBRハイライト・環境反射 | `反射光強度` |
| テクスチャ/ノーマル/マットキャップレイヤー | `レイヤー数` → 各レイヤーの `不透明度`/`強度` |
| リムライト | `強度` → `幅` |
| リムシェード | `影への寄与強度` → `リム影幅` |
| 影の境界ストライプ | `境界幅` → `境界強度` |
| 影パターン | `パターン強度` |
| 顔ノーマル補正 | `ノーマル圧縮量` |
| 顔領域マスク | `マスク強度` (0の場合は全体を顔として扱います) |
| PBRパッキングマスクのチャンネル設定 | `パッキングマスク使用` |
| キャスト影の明るさ・ブレンド | `受信強度` |
| アルファマスク | サーフェスモードが不透明の場合は有効にしても表示されません |
| `1次影の明るさ`・`キャスト影の明るさ` | `影の色` セクションが有効になっているか |

## マテリアルがピンク色(マゼンタ)に見える

| 原因 | 確認 | 対処 |
|---|---|---|
| レンダーパイプラインの不一致 | BRPプロジェクトでURPシェーダーを使用している、またはその逆 | 正しいバックエンドのシェーダーに置き換えます |
| **シェーダーモデル4.5未満** | `Tools > Studio Raming > MingToon > Validate Project` | サポート対象はPC(DX11+/Vulkan/Metal)のみ。Android・Quest・iOS・WebGLは非対応 |
| URPバージョン範囲外 | URP 12.xであるか | Unity 2021.3 + URP 12.xに合わせます |

:::danger[この場合、他のエラーメッセージは表示されません]
SubShaderが丸ごと脱落するためログは静かなままです。ピンク色が唯一の信号です。
:::

## Validate ProjectがUnityバージョンを指摘する

| コード | 条件 | 意味 |
|---|---|---|
| `MING-ENV-UNITY-VERSION` (エラー) | エディターが **2021.3でも2022.3でもない場合** | 非対応のストリームです。Unity Hubでどちらかで開いてください |
| `MING-VRC-UNITY-VERSION` (警告) | VRC SDKがあるのにエディターが **2022.3ストリームでない場合** | VRChat連携は2022.3でのみコンパイルされるため、**このプロジェクトにはアバターアップロードのサポートがありません。** 他のターゲットには影響しません |

2022.3.22f1は正式なサポート対象バージョンなので、何の指摘も出ません。 → [Validatorコード全体](/reference/validator)

## 深度リム / 2Dシャドウ / 内部2D境界が見えない

| 原因 | 対処 |
|---|---|
| `全体効果` または `深度効果` が無効 | インスペクターに `深度効果を有効にする` ボタンが表示されます |
| `マスター幅` が0 | 上げてください |
| 各モジュールの強度が0 | 上げてください |
| サーフェスモードが **透明** | `透明・アウトライン用深度記録` に変更します。インスペクターが `深度記録モードが必要です` と知らせます |
| **カメラ深度がない** | [深度ベースの効果](/guides/depth-effects) のプラットフォーム別設定 |
| VRChat通常画面 | アバターからは強制できません。Photo Camera・ミラーでそれぞれ確認してください |
| URP | Renderer Featureのインストール + Depth Textureの有効化 |
| Warudo | Depthを有効にしたカメラ、またはhost depth bridgeが必要 |

インスペクターに `アクティブなScene/Gameカメラの深度テクスチャが準備されていません。` が表示される場合はSceneビューを開き直し、それでも続く場合は `Validate Project` を実行してください。

## 内部2D境界だけが消えた

| 原因 | 対処 |
|---|---|
| `Inner Edge アウトラインに適用` が有効で頂点カラーが黒い | トグルを無効にするか、圧力ソースを変更します |
| サーフェスモードが透明 | 深度記録モードに変更します |
| カメラ深度がない | 上の項目を参照してください |

ノーマルアウトラインはカメラ深度がなくても動作します。**ノーマルアウトラインは見えるのに内部2D境界だけがない場合は深度の問題です。**

## アウトラインが見つからない

`内部2D境界` は **アウトライングループではなく深度ベースの効果グループ** にあります。画面の深度を読み取るためです。

## ノーマルアウトラインが丸ごと消えた

| 原因 | 対処 |
|---|---|
| **頂点カラーが黒くインポートされたメッシュで `圧力ソース` が `VertexRed`** | 圧力ソースを変更するか、頂点カラーを確認します |
| `ハル圧力コントラスト` が0 | 圧力が完全に無視されます |
| `カラーマスク` が0 | 15(RGBA全体)にします |

## アウトラインが角ばった部分で途切れる

`ノーマルソース` が `VertexColorTS` または `UV8TS` なのに、**スムージングしたアウトラインノーマルをベイクしていない** メッシュです。`MeshNormal` に変更してください。

## シーンビューでアウトラインの太さを塗れない {#씬-뷰에서-아웃라인-두께를-칠할-수-없다}

| インスペクターのメッセージ | 対処 |
|---|---|
| `Pressure SourceがVertex AlphaまたはVertex Redである必要があります。` | `Vertex Alphaに切り替え` ボタンを使用します |
| `現在の選択項目の下にこのマテリアルを使用するレンダラーがありません。` | ミントゥーンマネージャー(またはその下のオブジェクト)を選択します |
| `頂点ペイントはマテリアルを1つだけ選択した場合に使用できます。` | 1つだけ選択します |
| `頂点ペイントは ... Playモードを終了してもUnityが元に戻してくれません。` | Playモード終了後に再開します |
| `塗れるメッシュがありません。` | レンダラーにメッシュがあるか、そのメッシュがこのマテリアルの描画するサブメッシュを含むか確認します |
| `レンダラーにメッシュがありません。` | Mesh FilterまたはSkinned Mesh RendererのMeshスロットにメッシュを割り当てます |
| `レンダラーにMesh Filterがなく...` | 同じオブジェクトにMesh Filterを追加するか、Skinned Mesh Rendererのあるオブジェクトを選択します |
| `メッシュ '{...}' から頂点を読み取れず...` | モデルを再インポートします |
| `メッシュ '{...}' はランタイムに生成され...` | メッシュアセットとして保存し、そのアセットをレンダラーに割り当てます |
| `...再インポート後も読み取れずコピーできませんでした。` | モデルファイルが読み取り専用でないか確認します |
| `編集用メッシュコピーを '{...}' に書き込めませんでした。` | フォルダの書き込み権限とディスク空き容量を確認します |
| `編集用メッシュコピーを保存する '{...}' フォルダを作成できませんでした。` | プロジェクトフォルダの書き込み権限を確認します |
| `'{...}' のモデルインポーターを開けず...` | モデルファイルがプロジェクト内にあり、インポートに成功しているか確認します |

### 塗ったらアウトラインの向きが壊れた

`圧力ソース` が **Vertex Red** で `ノーマルソース` が **VertexColorTS** のため、同じ頂点カラーを上書きした場合です。インスペクターは塗る前に警告します。

対処: `圧力ソース` を **Vertex Alpha** に変更するか、アウトラインノーマルを [UV8へ移してください](/guides/mesh-bakes#아웃라인-스무스-노멀-uv8)。

### 他のオブジェクトのアウトラインまで一緒に変わった

複数のレンダラーが **同じメッシュアセット** を共有しています。頂点ペイントはメッシュアセットを直接編集します。

対処: メッシュを複製して該当レンダラーにのみ割り当ててから、もう一度塗ってください。

## レンダーパイプラインを変更したらマテリアルが全部壊れた

パイプラインが変わると `MingToon レンダーパイプライン不一致` ダイアログが表示され、プロジェクトのMingToonマテリアルを正しいバックエンドへ一括変換するか尋ねられます。開いているシーンのマテリアルも一緒に検査します。

:::caution[ロードされていないシーンとAssetBundleは検査できません]
そちらのマテリアルは個別に開いて変換する必要があります。
:::

ダイアログを見逃しても、マテリアルインスペクターに残る警告からいつでも再実行できます。

変換が **ブロックされる場合**:

| 理由 | 対処 |
|---|---|
| `マテリアルが他のアセットに含まれています。` | サブアセットから抽出します |
| `マテリアルが読み取り専用パッケージ内にあります。` | パッケージの外へコピーします |
| `マテリアルが読み取り専用であるかチェックアウトされていません。` | 読み取り専用属性を解除するか、バージョン管理からチェックアウトします |

## 変換/ベイクが失敗する

| メッセージ | 対処 |
|---|---|
| `このルートの下に変換するマテリアルスロットが見つかりませんでした。` | ミントゥーンマネージャーを正しく付けたか、`下位レンダラーを再検索` を押したか確認します |
| `MingToonオリジナルシェーダー '{...}' が見つからずベイクできません。` | インストールが不完全です。パッケージを再インポートします |
| `生成したMingToonシェーダー '{...}' をインポートできませんでした。` | プロジェクトフォルダの書き込み権限を確認してから再試行します |
| `生成したMingToonシェーダー '{...}' にコンパイルエラーがあります。` | MingToonインクルードフォルダが元のパスにあるか確認します。この結果はキャッシュされないため、パスを直して再度ベイクすれば再生成されます |
| `ミントゥーンマネージャーが複数選択されています。` | 一度に1つだけ選択します |

## キャスト影がまだらになる

| 場所 | 対処 |
|---|---|
| 服のしわ・体全般 | `セルフキャストシャドウ抑制` を有効にして `セルフシャドウキャスターバイアス` を0.01〜0.03に |
| 顔 | 前髪・髪キャスターの `影の方式` と `実シャドウキャスターオフセット`、Face SDF、`顔2Dシャドウアシスト` を調整。動作しなかった顔キャスト安定化オプションは0.1.7で削除されました |
| 上下方向 | `上下補正強度`・`上下到達しきい値` (低いほど広く) |
| 境界が階段状にギザつく | `投影フェザー使用` + `投影フェザー半径`・`強度` |
| 全般的にちらつく | 光源のshadow map解像度 · bias/normal bias · cascade の順に確認 |

:::note[フェザーは存在しない情報を復元できません]
低解像度のshadow mapにもともとなかったディテールは、ぼかしても戻ってきません。
:::

## 影が重なるところだけ真っ黒になる

`影の色` セクションの `統合影を使用` を有効にしてください。フォーム・キャスト・2Dシャドウが同じ色とトーンに収束します。 → [ライティングと影](/guides/light-and-shadow#통합-그림자--겹칠-때-새까매지는-문제)

## 統合影を有効にしたら個別影の色が反映されない

正常です。統合モードでは個別影の色・ブレンド・明るさは結果に反映されません。値は保持されるので、無効にすれば戻ります。個別値を統合値に合わせるには `統合値を個別影にコピー` を使ってください。

## 逆光で体の上にキャラクター型の影が重なる

`逆光シルエット抑制` を有効にしてください。

## 暗いワールドでキャラクターが黒く潰れる

| 項目 | 対処 |
|---|---|
| `ベース色維持` (シンプルモード: ベース色保持) | 上げてください |
| `最終最小明るさ` | 上げてください |
| `間接光補正` | 上げてください |
| `キャスト間接光補正` | 上げてください |

明るいワールドで白飛びする場合は `最終最大明るさ` を下げてください。

## 影パターンがまったく出ない

| 原因 | 対処 |
|---|---|
| `パターン形状タイル使用` が有効なのにタイルスロットが空 | 空のスロットは **白** として読み込まれ、白はどんな濃度でも超えられないしきい値です。インスペクターの組み込みタイルボタンを使ってください |
| `パターン強度` が0 | 上げてください |
| 適用対象が合っていない | `パターン適用対象` を確認します |

## パターンのドットがトーンに反応せずサイズが一定になる

**すでに二値化されたドットパターン** をタイルに入れた場合です。タイルは絵ではなく、しきい値マップである必要があります。 → [影パターン](/guides/shadow-pattern#타일은-그림이-아니라-임계값-맵입니다)

## 髪が頬を貫通して見える

サーフェスモードを `透明・アウトライン用深度記録` にして、`透明深度先行記録` を有効にしてください。

## 変換後のルックが元と違う

変換ログの `lossy` / `unsupported` 項目をまず読み、以下を元と比較してください。

- マスクチャンネルの選択と反転
- テクスチャST (Tiling / Offset)
- AO
- サーフェスモード
- 顔スロットの判定

## ベイク済みマテリアルの復元ボタンが無効になっている

| 確認 |
|---|
| bake manifestが残っているか |
| 元の編集マテリアルのGUIDが生きているか |
| ベイク以降にRenderer階層 / マテリアルスロットが変わっていないか |

## アップロードしたのに最適化がかかっていないようだ

1. Unityバージョンが **2022.3.22f1** であるか。2021.3ではVRChatフックがコンパイルされません。
2. Consoleに `[MingToon] VRChat build hook compiled and registered.` があるか。
3. `Tools > Studio Raming > MingToon > Optimize Shaders On Build` にチェックが入っているか。
4. プロジェクトフォルダの隣の `StudioRaming/MingToonOptimizeReport.txt` を確認。

→ [ビルド時の自動最適化](/workflow/build-optimization#제대로-걸렸는지-확인하기)

## 作業中にインスペクターが重い {#작업-중-인스펙터가-무겁다}

正常です。編集用シェーダーは全機能と最大レイヤー数を最初に一度でコンパイルして保持します。おかげで機能のトグル時にバリアントのコンパイル待ちや青いプレースホルダー色が発生しません。軽量化は [ビルド時](/workflow/build-optimization) にのみ適用されます。

## それでも解決しない場合

`studioraming@gmail.com` へ以下を一緒に送ってください。

1. Unityバージョンと対象プラットフォーム (VRChat PC / Warudo / 一般Unity)
2. レンダーパイプライン (BRP / URP 12.x)
3. MingToonバージョン
4. Consoleログ全文
5. 再現手順
