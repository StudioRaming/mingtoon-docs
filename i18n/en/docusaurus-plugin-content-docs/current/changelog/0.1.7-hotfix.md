*0.1.7 hotfix 1 · 7 September 2026 · package version stays 0.1.7*

## In one line

A 0.1.7 redistribution fixing the face proxy, stencils, fallback emission and blocked builds.

:::warning[Check before updating]
- How to get it: download the same 0.1.7 package again and overwrite.
- Re-upload: only avatars using materials with `Enable Emission` on need uploading again.
- Convert those materials again, or press `Sync Fallback Properties` once in the Manager.
- Reconversion: lilToon converted materials that use stencils need converting again, or restore the stencil values by hand.
- The face proxy only needs the overwrite. It takes effect as soon as you open the scene.
:::

:::info[How to read a hotfix]
This is a fix redistributed as the same package without raising the version number.
Check `Docs/PATCH_NOTES_0.1.7.md` inside the package to see which rounds it contains.
:::

:::note[As of now]
The install path at the time of 0.1.7 was `Assets/StudioRaming/MingToon`.
From 0.1.8 it is `Packages/com.studioraming.mingtoon`. → [Installation](/getting-started/installation)
:::

## Fixed

- Fixed: an adjusted face proxy reverted to the original normals on every scene save, play and reload.
- The shader now computes the proxy normals directly on the editable material. Realtime and bake use the same formula.
- Fixed: on a Skinned Mesh Renderer with a Root Bone, the `Proxy Area Mask` center landed off the face.
- Fixed: converting a lilToon material with no outline left the outline alone in ignoring the stencil mask.
- Eyes made to show through the fringe had a visible surface, but their lines stayed hidden behind the hair.
- The outline now inherits the surface stencil value when the source has no outline.
- Fixed: an avatar that dropped to the fallback shader came out white with only the outline left.
- The fallback emission color is now always black. Emission in the MingToon shader itself is unchanged.
- Fixed: after one NDMF avatar build, every VRChat build was blocked by `Material recovery is incomplete`.
- Missing materials are now judged by whether the file actually exists, and leftover records are cleared on the next restore.
- Fixed: the factory look preset applied right after conversion reset the source's stencil values to 0.
- The two stencil units (surface and outline, 14 items) are now neither stored in nor applied by a preset.

## Known limitations

- A project that was blocked from building needs one editor restart after the overwrite to clear.
- New rounds are added to the top of this page.
