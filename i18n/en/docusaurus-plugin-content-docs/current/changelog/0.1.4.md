*Closed Beta · 2026-08-05*

## Check Before Upgrading

:::caution[Check your VRChat Expression Parameters budget first]
`Non-Destructive Modular Avatar Install` is enabled by default and uses **21 synced parameters · 154 bits** for Virtual Light and Master Adjust. Installation stops if the total exceeds 256 bits when combined with the existing avatar. → [VRChat](/workflow/character-manager#vrchat-표현식-메뉴)
:::

:::caution[Face Shading hidden in 0.1.3 is back]
`Face Shading` is visible and usable again. After updating, check the masks, boundaries, and SDF map on existing face materials, then enable it manually. → [Character Expression](/guides/character#페이스-셰이딩)
:::

## New Features

- **Hybrid PBR** — Adds metallic, smoothness, direct highlights, and environment reflections while retaining toon diffuse lighting, then shapes reflections with toon blending. → [Docs](/guides/detail-maps#pbr-표면)
- **`Toon Specular`** — Adds Isotropic or hair-specific Anisotropic highlights without enabling full PBR. → [Docs](/guides/detail-maps#툰-스페큘러)
- **`Region Mask`** — Divides one RGBA texture into four regions to adjust metallic, smoothness, reflection, and Toon Specular per part. → [Docs](/guides/detail-maps#영역-마스크)
- **Face SDF Studio included** — Previews Base, Nose, Cheek, Lip, and Eye Socket in real time and bakes them into one directional SDF. → [Docs](/guides/face-sdf#face-sdf-studio-작업-순서)
- **Single-channel face SDF** — Adds the `Single Channel (Grayscale)` format, which mirrors one R channel for both sides. → [Docs](/guides/face-sdf#sdf-맵-형식)
- **SceneView vertex and mask painting** — Provides Paint, Harden, Smooth, Hard Face, X symmetry, connected islands, mesh isolation, and explicit save/discard flow. → [Docs](/guides/character#얼굴-영역을-sceneview에서-칠하기)
- **MaskMaker included with the `MM` button** — Opens Selection, Gradient, Bridge Random, and Brush Paint directly from actual mask slots and applies PNGs to slots.
- **Virtual Light and Master Adjust VRC menu** — Adjusts the color, brightness, and intensity of Virtual Light, Highlight, Shadow, and Final Output from the VRC menu, with `Reset All` restoring defaults. → [Docs](/workflow/character-manager#vrchat-표현식-메뉴)
- **`MingToon 2D Projection Shadow Caster`** — Excludes glasses and accessories from MingToon's depth-based effect while preserving regular rendering and Unity real-time shadows. → [Docs](/guides/light-and-shadow#역광에서-몸에-캐릭터-모양-그림자가-겹칠-때)

## Changed

- **Face SDF Studio and MaskMaker are included in one 0.1.4 package**; both are Editor-only and add no runtime scripts.
- **The Face SDF Studio workspace is organized into two steps** — follow only `Preparation · Front UV7` and `SDF Creation · Preview · Bake`.
- **The outline width mask was moved closer to the width settings**, and its Tiling/Offset are now preserved during lilToon conversion.
- **Inspector categories and descriptions now use the user-facing names**, with tooltips placed where needed instead of a separate guide tab.

## Improved

- **Reduced repeated calculations in the Inspector, presets, and material cost panel** to cut unnecessary updates when editing multiple materials.
- **Reused Renderer/feature analysis and Mask Pack readback in the Bake path** to avoid reading the same data repeatedly.
- **Improved Bake cancellation and restore safety**, clarifying boundaries for cancellation during preparation, final save, and restoration of meshes, blend shapes, and original materials.
- **Changed VRC menu installation to a non-destructive workflow**, preserving existing Root Menu, Expression Parameters, and FX and merging only in the build clone.

## Fixed

- **Base Pass disappeared when enabling `Face Shading`** — restored BRP `ForwardBase` and URP `UniversalForwardOnly`, and replaced the development full-fixed compilation that exceeded D3D11 resource limits with a safe default.
- **White zigzag lines appeared on backlit faces** — capped the screen-derivative width of shape-shadow boundaries so triangle edges no longer show through shading.
- **Face SDF direction/coordinates were misaligned or transitions jumped abruptly**; added an unassigned-map warning and recovery path.
- **lilToon outline width masks and Tiling/Offset were not converted**.
- **`EndLayoutGroup` errors occurred after Manager conversion, saving, or refreshing**.
- **Emission disappeared because color and intensity were multiplied to black when no emission map was assigned**.

## Documentation

- Rewrote the face SDF and Face SDF Studio, Face Shading, Hybrid PBR/Toon Specular/Region Mask, and VRChat Virtual Light installation documentation for 0.1.4.
