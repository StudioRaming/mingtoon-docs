*Open beta · 19 September 2026*

## In one line {#v0111}

Conversion and build caches are steadier, and Light Volumes, factory looks and the Inspector were cleaned up.

:::warning[업데이트 전 확인]
- Backup: back up the whole project before installing.
- Re-bake: restore baked materials to editable, then bake them again.
- Re-upload: VRChat avatars need uploading again to receive this.
- Look changes: check Edge Rim, Volume Specular, the lighting baseline and Depth Shadow overlap.
- Re-convert lilToon materials when possible; the converter now preserves more source data.
:::

## New features

- **Edge Rim** — the rim that hugs the contour is now Edge Rim. The old `backlight` preset folder is renamed to `edgerim` with the same asset GUIDs.
- **Include preview versions** — opt into the preview channel from the updater. Clearing it offers the latest stable release even when its number is lower than the installed prerelease.
- **Face / Hair Shading** — regrouped as Face Area → Shading → Shadow Mode → Reference → Advanced, with dead folds removed.
- **Performance Cost** — the compact header shows the upload-basis load and opens into the detailed readings.
- Texture cards and layers now keep add, enable, move and delete together. Bulk **Max Size** and **Quality** settings apply by texture type.
- **Preset Capture & Management** — apply and save controls are grouped, and the last applied preset is remembered.

## Changed defaults and look changes

- Factory looks now ship with **Edge Rim** off. The tab presets can turn it back on.
- **Volume Specular** now defaults to Off instead of Full, reducing metallic-looking Light Volume highlights.
- The lighting baseline changed: **Environment Color Influence** 1, **Minimum Final Brightness** 0.2, **Edge Rim Brightness Maximum** 0 and **Edge Rim Light Response Floor** 0.5.
- **Darkening Influence** is 0.8, **Normal Bias** is 0.01 and **Screen-Space Shadow Overlap Depth** is 0.5. Every Scene Light Influence row is 1.
- The BRP outline now reads Light Volume brightness once per vertex. It adds no per-pixel volume samples.

## Fixed

- Importing a texture no longer starts scene-wide mask planning. Only the selected inputs are prepared.
- Mask input receipts are prepared once before a manual bake or upload, without repeated validation of completed receipts.
- Build-only value changes no longer mint a new shader profile every upload. Successful builds reuse the generated profile and source cache.
- lilToon conversion now runs `convert → look preset → color preset`. Source reflection, backlight and face data are kept, while Edge Rim stays owned by the look preset.
- Fixed: color presets overwrote the shadow color map UVs and base alpha.
- Fixed: the converter and color presets forced **Screen-Space Shadow Overlap Depth** back to 0.
- A stale DLL installation receipt is rebuilt from the installer's verified inventory, so later updates can install. The bootstrap DLL is unchanged.
- The bridge accepts the legacy v2 buffers published by VRC Light Volumes 3 worlds. Native v3 shadows, clustering and per-light shading are not used.

## Known limitations

- VRC Light Volume cast-shadow appearance in v2 and v3 worlds still differs from 0.1.10.
- v3 buffer compatibility covers the legacy indirect and point data only. MingToon does not read v3-only features.
- The first shader compile and first upload can take longer because the cache is cold.
