*Closed Beta · 2026-08-18*

## Check Before Upgrading

:::danger[Run the schema migration once]
`Tools > Studio Raming > MingToon > Advanced > Migrate Project To Current Schema`

The material schema moved from 10 to 11. The new `Enable Fresnel Rim Mask` and `Enable Rim Shade Mask` toggles read as off on older materials, so **until you run this, those materials apply no rim mask at all.** The migration finds masks that are not the plain white default and switches the toggles on. → [Installation](/getting-started/installation#이전-버전에서-올라왔다면)
:::

:::caution[Bake caches regenerate, and VRChat avatars must be re-uploaded]
The generated shader cache version moved from 28 to 29, which invalidates existing bake output. The next build rebakes it automatically — nothing to clean up by hand, but that one build takes longer. Shaders are bundled in the avatar asset bundle, so **an avatar already uploaded keeps the old shader until you upload it again.**
:::

:::caution[`Force On` in `Depth Availability` now excludes mirrors]
`Force On` now means "enable even where the host cannot report it, **except in mirrors**". Inside a mirror the depth modules stand down whatever you picked. → [Docs](/guides/depth-effects#깊이-가용성)
:::

:::caution[Missing Depth Fallback (the Fresnel fallback) has been removed]
Depth Rim no longer falls back to a Fresnel rim when depth is missing. A material that had the fallback mode set to Fresnel **loses that rim.** Depth modules now simply stand down when there is no depth.
:::

:::caution[`Include Shading` on the outline behaves differently]
The outline is now drawn from the base map colour and the lighting response alone; it no longer redraws the body's shadow pattern, cast shadows, or depth effects on top of the line. `Include Shading` now applies a light shading band that follows the form shadow colour instead of duplicating the whole body shading. → [Docs](/guides/outline#아웃라인-색이-조명을-따라가게)
:::

:::caution[`Compile All Modules While Authoring` now defaults to on]
This is what keeps a toggle from waiting on a shader recompile while you work. The console prints one line the first time it turns on, and you can switch it off in the bulk edit panel. Unnecessary keywords are still stripped on build, so leaving it on costs the shipped avatar nothing.
:::

## New Features

- **`Color Adjust Mask`** — limits the `Base HSVG` adjustment to where the mask is white, so you can recolour the eyes and leave the face alone. lilToon's colour adjust mask lands here on conversion. → [Docs](/guides/basics#색조보정-범위-마스크)
- **`Mask Texture Color` added to `Toon Specular Color Source`** — the RGB painted into the mask becomes the highlight colour, so hair highlights can differ strand by strand. No extra texture read. → [Docs](/guides/detail-maps#하이라이트-색을-부위마다-다르게)
- **`Shadow Mode` selector** — one row decides whether bangs and props cast real shadows on the face or are drawn as a soft 2D shadow. Values that used to be split across two tabs are now set together. → [Docs](/guides/character#4단계-앞머리-그림자)
- **`Compute For Edited-Normal Models` on the outline UV8 bake** — re-derives the outline direction from the mesh's own faces, for hair and skirts whose normals came off a sphere or a cylinder. Off by default, so an already baked character keeps the line it has. → [Docs](/guides/mesh-bakes#노멀을-편집한-모델용으로-계산)
- **`Carry Depth Light on Upload` (off by default)** — adds one light to the VRChat upload only, so the camera draws depth. Everyone who sees you pays for it, which is why the inspector states the four costs before the box can matter. → [Docs](/platforms/vrchat#vrchat-깊이-라이트)
- **`Enable Fresnel Rim Mask` · `Enable Rim Shade Mask`** — the two rim masks now work like the shadow reflection mask: a material that does not use one never samples the texture. Turn the toggle on before you assign a mask. → [Docs](/guides/rim#림-마스크)
- **`Diagnostic` added to `Depth Availability`** — paints the avatar a flat colour that says which depth texture the shader was actually reading. For bug reports only. → [Docs](/guides/depth-effects#diagnostic)
- **`VRC Light Volumes` (off by default)** — in a world that uses VRC Light Volumes, the character's indirect light lift and shadow tint follow the room's volume instead of Unity's probes. Built-in only, and it falls back to probes where there are no volumes.
- **`Heal Material Keywords (Project)` menu** — brings every MingToon material's stored keywords and pass state back in line with its inspector values. It confirms first, backs up what it changes, and logs one line.
- **The Manager says up front when the outline UV8 bake is needed** — if `Normal Source` is `UV8TS` and the mesh has no UV8, a warning and a bake button appear at the top of the MingToon Manager. The button states where the new meshes go and how many renderers it will process. → [Docs](/guides/mesh-bakes#아웃라인-스무스-노멀-uv8)
- **`Use Shadow Color Map` and `Color Map Amount` added to the bulk edit panel** — set them across a multi-material selection in one pass. → [Docs](/guides/bulk-editing)

## Changes

- **Missing Depth Fallback (the Fresnel fallback) has been removed.** Depth modules stand down when there is no depth.
- **The outline (classic hull) costs about a third of what it did per pixel.** It no longer duplicates the body's shading. → [Docs](/guides/outline#아웃라인-색이-조명을-따라가게)
- **`Force On` in `Depth Availability` now excludes mirrors.** → [Docs](/guides/depth-effects#깊이-가용성)
- **`Compile All Modules While Authoring` now defaults to on.**
- **The `Prewarm Shader Variants` menu is gone.** `Warm up shader variants` does the same job and stays.

## Improvements

- **Inspector toggles no longer wait on a shader compile.** The 2–6 second recompile is gone from `Enable Glitter Mask`, `Use Mask` (shadow reflection), `2D Shadow Mask`, `Depth Rim Mask`, `Inner Edge Mask`, `Enable Region Mask`, `Enable 2nd Shadow`, the layer dropdowns, `Base Tint After HSVG`, and `Face Shading Module`. The picture it draws and the defaults are unchanged.
- **Shader compilation finishes once, at package import.** It runs in parallel behind a cancellable progress bar, and afterwards there is no compile wait during conversion, material selection, or editing. A cancelled run is picked up where it stopped.
- **Conversion reports its progress by stage.** A progress bar walks material conversion → look preset → mesh bakes, and the per-stage timings land in the console on completion. → [Docs](/workflow/liltoon-conversion)
- **Layer masks are composited into one packed texture automatically.** Surface stack, normal and MatCap masks are combined so the GPU reads fewer textures. How you use them and every adjustment stays the same; the composites are generated and shared under `MingToonGenerated/MaskPacks`.
- **The outline panel reports whether the mesh has UV8 and vertex colours.** → [Docs](/guides/outline#선-굵기를-부위마다-다르게)
- **The outline UV8 bake no longer rejects an already baked character.** It skips UV8 that MingToon baked, rejects only the user model's own UV8, and names the mesh.
- **Inspector text fixes** — toolbar and section header labels no longer clip, the sticky header no longer flickers while you resize the inspector, and help and warning boxes are set at body size.

## Fixes

- **Upload optimisation (baking) was forcing disabled modules back on** — the root cause behind avatars glowing white in mirrors and in cameras without post. Turning `Enable Emission` off no longer produces full-screen emission from the default white map, and a disabled `2D Shadow Mask` stays disabled.
- **2D Shadow and Depth Rim slipped instead of following the body inside a VRChat mirror** — the shader was reading the player camera's depth buffer, so it wore a stranger's silhouette. Depth modules now stand down inside mirrors. → [Docs](/guides/depth-effects#깊이-가용성)
- **Shading collapsed into pale flatness in worlds without a realtime directional light and in Disable Pixel Lights mirrors** — the ambient probe now synthesises a key light so shading holds everywhere. Worlds with a directional light are unchanged. → [Docs](/guides/light-and-shadow#라이팅--어두운-씬에서-검게-뭉칠-때)
- **lilToon conversion carried the values but left the modules off** — `Enable PBR Surface`, `Enable Emission`, `Enable Surface Stack`, `Outline Master` and `Enable Classic Hull` now come out on. Stack layers 2 and 3 arrive, and outline direction and thickness are correct. → [Docs](/workflow/liltoon-conversion)
- **Outlines shifted diagonally with `Normal Source` set to `VertexColorTS` on a mesh with no vertex colours** — it now falls back to mesh normals. → [Docs](/guides/outline#각진-부분에서-선이-끊길-때)
- **One part with no tangents or normals killed the outline, face, and height bakes together** — only that renderer is skipped now, and the console names the mesh.
- **Baking made one copy per renderer when several renderers shared a mesh** — one asset per source mesh now, shared by all of them.
- **Conversion erased the user model's UV8 regardless of `Overwrite Occupied UV Channels`** — with the option off it skips and reports.
- **`Unified Shadow Color Map` would not switch off while the global compile mode was on** — it now switches off reliably in any compile mode. → [Docs](/guides/light-and-shadow#통합-그림자--겹칠-때-새까매지는-문제)
- **Dropping MingToon or a converted avatar into a VRChat world project broke it with a `VRCExpressionsMenu` compile error (CS0246)** — the expression menu installer compiles away in world projects.
- **Selecting or editing a material in a Unity 2022 project made the base vanish and left only the outline** — the root cause is fixed, including on setups where waiting for the compile never helped. → [Troubleshooting](/troubleshooting#작업-중-인스펙터가-무겁다)
- **The first conversion applied the top look preset instead of the one you picked** — the selection now survives a script reload and a reselect. → [Docs](/workflow/character-manager#변환-시-룩-프리셋)
- **Look presets switched off the MatCap, normal layers and surface stack that conversion had brought across, and forced every blend mode to `Add`** — look presets now handle the look only and leave layer content alone.
- **The `[MingToon] VRChat build hook compiled and registered.` confirmation never appeared** — it now prints once per editor session. → [VRChat](/platforms/vrchat)
- **Materials that never used the toon specular mask were sampling it anyway** — split behind a use toggle, along with the two rim masks.

## Documentation

- The property reference was regenerated from the current source. The deleted `Fallback Display` section is gone, and new rows — `Depth Availability`, `Toon Specular Color Source`, `Face Shading Module` and others — are in all three languages.
