*Open beta · 8 September 2026*

## In one line {#v018}

Uploads got faster, and avatars looking white after a bake are fixed.

:::warning[Check before updating]
- Backup: back up the project before installing.
- Re-bake: materials you already baked need baking again for this fix to apply.
- Re-upload: upload your VRChat avatars again.
- Only when moving from an old install: pull out files you saved inside `Assets/StudioRaming/MingToon` first.
- Do not delete `MingLightController` or the whole `StudioRaming` folder.
:::

## New features

- **Color Presets** — save and apply the whole Shadow Color tab, the rim and depth tints, and HSVG.
- The factory palettes are seven: `Neutral`, `Warm Tone 1`, `Warm Tone 2`, `Cool Tone 1`, `Cool Tone 2`, `High Saturation` and `Low Saturation`.
- **Overall Saturation** — applies to the entire final output. 0 is monochrome, 1 is neutral.
- **SSAO Color** · **Rim Shade Color** — set them directly in Quick Settings alongside the band colors.
- **UV Source** · **Mask UV Source** — choose the normal layer's UV and the mask's UV separately, from UV0 to UV3.
- Importing a DLL downloaded from BOOTH installs the required packages automatically.
- It checks for a new version when Unity starts and shows a notice. It installs only when you press `Update`.
- The Manager's update panel shrank to two lines, with `Check`, `Update` and `Patch Notes` gathered in one place.

## Changed defaults and look changes

- When **Rim Shade Color** has a blend opacity of 0, it uses `1st Shadow Color` just as before.
- The default texture bake policy `LosslessOnly` does not rewrite original pixels.
- It runs only when both `Reviewed Texture Rewrites On Build (Opt-In)` and `Optimize On Build / Upload (Applies To Everything)` are on.
- With those on, texture layers and normal layers are each merged into one texture right before upload.
- Individual masks are packed into RGBA, and the `Outline` tab's `Width Mask` goes in too.
- Color space, mips and compression can change pixels. Compare before and after the bake yourself.
- If both of the normal layer's UVs are the default UV0, the UV router is not compiled.
- Install and update notices follow the system language; Manager labels follow the inspector language.

## Fixed

- Fixed: uploads took far too long. First uploads are 3 to 50% faster.
- Mostly fixed: characters uploaded after a bake looked white.
- Fixed: an MLC issue where a BRP-only project checked for URP that was not there and blocked the upload.
- Fixed: lilToon conversion changed the SSAO color purity.
- Fixed: conversion turned the emission mask off, and compression altered the mask data.
- Fixed: outline normal correction varied with model size.
- Fixed: when a bake was interrupted, partially generated files contaminated the next run.
- The Manager's `Patch Notes` button now links to the latest documentation.

## Known limitations

- How much faster it gets depends on the avatar and the environment.
- The fix that makes fallback emission black is in 0.1.7 hotfix 1.
- Materials baked before 0.1.7 hotfix 1 need baking again and re-uploading.
- Cleaning up an old install is a one-time job. It does not repeat on every later update.
- Users who installed through VCC keep updating from VCC directly.
