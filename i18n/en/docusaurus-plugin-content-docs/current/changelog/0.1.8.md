*Open Beta · 2026-09-08*

## 0.1.8 {#v018}

[Permanent link: 0.1.8 patch notes](/changelog/0.1.8#v018)

### Major fixes and usability improvements

- **First-upload time** — Improved the excessive time required for uploads. User measurements report a 3–50% improvement for a first upload; results vary by environment.
- **White VRC-baked characters** — Mostly fixed characters appearing white after a VRC bake and upload.
- **MLC build conflicts** — Mostly fixed builds failing when MLC conflicted with certain assets.
- **Installation path transition** — This release introduces the previously announced VCC/VPM-based installation and update path. After the initial DLL import, the required MingToon package is installed automatically without an additional install button. Later, Unity automatically checks for new versions at startup and shows a notice for versions that have neither been installed nor skipped. The user must click the `Update` button in the notice to install; restarting Unity does not install it automatically. `Skip` applies only to that version, and the next new version is announced again. VCC installations continue to be maintained and updated manually through VCC.
- **Recovery after an install failure** — If installation fails, delete only the existing shader folder `Assets/StudioRaming/MingToon` and reinstall; authored materials can then reconnect to the same shader GUID. Move any `.mat` or texture files you saved directly inside that folder elsewhere first.
- **Conversion stability** — Fixed lilToon conversion changing SSAO color purity, disabling emission masks, or changing mask data through compression.
- **Manager controls** — Update status and installed/latest versions now fit in two rows at about one third of the previous height, with `Check`, `Update`, and `Notes` in one place.
- **Installation and update paths** — For the DLL path, importing the DLL from the unitypackage automatically installs the required MingToon package without an additional install button. Later, Unity automatically checks for new versions at startup and installs a version only after the user clicks the `Update` button in the notice shown for versions that have neither been installed nor skipped. If Unity is playing, compiling, or building, it waits and checks again after reload; restarting Unity does not install a version automatically. `Skip` applies only to that version, and the next new version is announced again. Users who installed through VCC continue to maintain and update it manually through VCC.
- **Existing asset preservation** — Existing 0.1.7 installations and inventories are recognized; package updates touch only managed files and preserve existing materials, scenes, prefabs, and Unity-created `package.json.meta` files.

### New features

- **Color Presets** — Use `Color Presets` to apply shadow, rim, depth, tint, and HSVG settings together, or apply a factory palette to selected materials. Textures, render state, and keywords stay intact, and Undo is supported.
- **Band and rim color controls** — Quick settings expose overall saturation and emission intensity, plus direct `Rim Shade Color` and shadow-band color controls.
- **Per-layer UV selection** — Choose the UV channel for each normal layer and mask.

### Changes

- **Language display** — Installation and update messages select Korean, Japanese, or English for other system languages; Manager labels continue to follow the Inspector language selection.
- **Conversion output** — Converted materials retain RGBA emission-mask data, surface-alpha blending, and the authored UV choices for normals and masks.

### Improvements

- **Shader baking** — Identical requests are grouped to reduce duplicate work during repeated bakes while preserving existing generated output and state.
- **Generated-output recovery** — Interrupted bakes now recover without leaving partial files that can poison the next generated-shader cache.

### Documentation

- Manager `Notes` opens the latest localized documentation, while the current and latest versions remain visible together.
