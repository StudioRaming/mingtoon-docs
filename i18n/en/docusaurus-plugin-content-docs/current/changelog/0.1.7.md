*Closed Beta · 2026-08-19*

## Check Before Upgrading

:::caution[Bake caches regenerate, and VRChat avatars must be re-uploaded]
The generated shader cache version moved up, which invalidates existing bake output. The next build rebakes it automatically — nothing to clean up by hand, but that one build takes longer. **This release's MatCap optimisation only applies once you rebake** — an old cache looks correct but stays far more expensive on MatCap materials. Shaders are bundled in the avatar asset bundle, so **an avatar already uploaded must be uploaded again to receive this fix.**
:::

:::caution[Face shading and shadow shape change on some materials]
In both cases the old behaviour was the bug. Shading that popped hard as the light crossed the centre of the face now moves across smoothly, and the face depth offset that was wrongly applied to the whole body on a unified material with the face region vertex-painted is gone.
:::

:::caution[Lighting defaults changed — this applies only to newly created materials and the factory presets]
Nine lighting defaults, including `Light Color Influence`, `Indirect Strength` and `Additional Light Toon Blend`, were retuned to match a real production setup, and `Enable Translucency` now defaults to off. **Materials you already made are left untouched.** Re-applying a factory preset moves them to the new defaults.
:::

:::caution[Face SDF Studio and Mask Maker are no longer bundled from this release on]
Both tools are now separate products. Buy either one and drop it into the project, and the matching place in the inspector integrates with it exactly as before. Without it, that button becomes a notice — nothing else is affected.
:::

## New Features

- **`Enable Emission Layer 2`** — a second emission map, so different areas can glow in different colours. The two layers are added, so each area keeps its own colour. Off by default. → [Docs](/guides/detail-maps)
- **`Map Alpha Masks Intensity`** — uses the emission map's alpha channel as a per-pixel intensity mask. The alpha is already read along with the colour, so **it costs no extra texture read.** Present on both emission layers. → [Docs](/guides/detail-maps)
- **Copy and paste material settings** — copy and paste buttons were added to the inspector's top bar. Paste comes in five variants — `All`, `Values Only (No Textures)`, `Textures Only`, `Keywords Only` and `Render Queue Only` — so you can carry settings across while leaving each material's own textures in place. Undo (Ctrl+Z) works.
- **`Quick Settings` card** — the controls that take effect across the whole material are gathered in one place at the top of the inspector, `Unified Shadow Color` among them.

## Changes

- **Three PBR-related sections moved out into their own `PBR` group.** `PBR Surface`, `Toon Specular` and `Region Mask` were mixed into the character group and are now a separate one. It sits after `Character` and before `Depth Effects`. Values and defaults are unchanged.
- **Leaving `Pattern Style` on `Overlay` and switching `Pattern Target` to `Depth2D` now shows a notice.** `Overlay` prints line work over finished shading, so it only works on the form shadow; on 2D it falls back to `Recolor`. That has always been the case, but nothing said so.
- **Inspector section order and naming were cleaned up.** The lighting controls moved into a `Shadow` section inside `Basic Settings`, ordered `Form Shadow` → `Cast Shadow` → `Shadow Color` → `Shadow Pattern`; the rim family reads `Rim Light` → `Rim Shade` → `Front Light` → `Back Light` → `Shadow Bounce Light`, and the depth family `Depth Effects Master` → `2D Rim Light` → `2D Translucency` → `2D Shadow` → `Inner Outline`. Values and defaults are unchanged.
- **The `Material Cost` meter now shows the post-bake figure by default.** What actually gets uploaded is the baked shader, so that is the right headline number. The figure for the material you are editing is available under the detail breakdown.

## Improvements

- **Upload optimisation works far better on materials that use MatCap.** MatCap layers 2–5 were not being folded to constants by the optimisation. The more MatCap layers a material uses, the bigger the effect. Materials that do not use MatCap are unchanged.
- **The same material no longer costs different amounts on Built-in and URP.** The optimisation above was already working on URP and was missing only on Built-in. Both backends now cost the same.
- **Upload optimisation now shows it when it misses even one value.** The old check passed if any one value applied, so missing a hundred of them was silent. That is why the defect above went unseen for so long.

## Fixes

- **Shading popped hard as the light crossed the centre of the face** — the SDF face's persistent channel was crossing over differently from the threshold channel.
- **The face depth offset applied to the whole body on a unified material with the face vertex-painted** — the shadow-casting pass was not reading the face region assignment.
- **Baking, deleting the output and baking again in the same session failed** — the deleted path still read as occupied, so no name could be made.
- **The second emission slot's `Channel Source` and `Invert Source Colors` rows were missing from the inspector entirely** — the shader was reading those values with nowhere to set them.
- **Two preset scope toggles were clipped in Korean and Japanese** — `Overwrite Shadow Colors Too` and `Overwrite Fresnel Too` are now split across two lines.
- **Sliders and number fields in the middle of the inspector were clipped when the panel was narrowed** — the label column was squeezing the value column out at narrow widths.
- **The revert button sat outside its row's box and the right margin was too wide** — the button now shares the same margin as the box it belongs to.
- **Opening Face SDF Studio first locked every tool to Korean** — with no language ever chosen, Korean was being force-saved. It now follows the system language.

## Documentation

- The emission section now covers how to turn layer 2 on and what the map alpha mask does.
- The shadow pattern section now explains that `Overlay` only prints line work on the form shadow.
